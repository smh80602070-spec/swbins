# 사가(Saga) — 이 세상에 없는 게임 다섯

역사 인물 500명과 짐승 105종이 나오는 게임 다섯 판을 만듭니다(표시 이름은 전부 가명).
판마다 한 장르의 명작들을 함께 녹여, 어느 한 게임의 따라 하기가 아니라 **그 장르의 좋은 것을 다 가진 게임**을 목표로 합니다.
같은 다섯 판을 브라우저(웹)와 두 3D 엔진(Godot·Unity)으로 나란히 짓습니다.

## 어떻게 "이 세상에 없는 게임"으로 가나

- **게임성 장부** — [`tasks/gameplay/`](tasks/gameplay/README.md). 판마다 넣을 메커니즘을 한 줄씩, 웹·고돗·유니티 세 칸에
  상태를 적습니다. 새로 떠오른 것은 그 자리에서 더하고, 판의 정체성에 안 맞는 것은 지우지 않고 "뺌"으로 남깁니다.
  목록이 곧 좋은 게임은 아니어서, 모든 줄은 그 판의 "플레이어 판타지"에 꿰일 때만 들어갑니다.
- **그래픽 기준선** — 기준은 원신급(셀 셰이딩·얼굴 그림자·림 라이트·후처리). 다섯 판 중 가장 좋은 쪽을 기준으로
  나머지를 맞추고, 자동 점검이 다섯 판이 같은 기능을 켜고 있는지 매번 확인합니다(장부 README 그래픽 절).
- **세 트랙** — 웹에서 먼저 만들어 검증하고, Godot·Unity 가 같은 장부를 보고 엔진의 장점(물리·조명·애니메이션)으로
  한 단 더 올립니다. 두 3D 트랙은 코드를 나누지 않는 별개 프로젝트입니다.
- **직접 만든 그림·소리** — 그림·3D 몸·소리는 로컬 AI(상업 허용 모델)와 코드로 생성하고, 파일마다 출처를 남깁니다.
  원작의 그림·소리·데이터는 가져오지 않습니다.

### 웹엔 한계가 없다 — 1만리 기술 시연(W-0310)

브라우저에서 안 된다고 여기는 다섯을 한 들판에 같이 띄운다: 군중 300(인스턴싱 + 뼈 텍스처) · 날씨(GPU 비·눈 2만, 번개, 빛줄기) · 물리(래그돌·굴러가는 돌·풀 눕힘, 외부 라이브러리 없음) · 지평선 2.2km(먼 땅 고리·숲 임포스터·산 테) · WebGPU 손잡이(못 켜면 WebGL 로).

- 주소: <https://smh80602070-spec.github.io/swbins/saga-web/saga-go/_demo.html#limitless> (`,weather=rain` · `,n=600` · `,webgpu=1` 을 붙일 수 있다)
- 수치(이 PC Radeon Pro 570X 급, HIGH): 다섯 기능 합 +3.6ms · 그리기 +24 · 받는 용량 +32KB · 메모리 +0~30MB — 판 바탕(마을 HIGH 18.9fps)이 병목이라 그쪽이 다음 티켓. 표는 `tasks/sheets/web-limitless-20261018.md`.

트랙마다 상세 상태는 `saga-web/STATE.md`·`saga-godot/docs/PROJECT_STATE.md`·`saga-unity/docs/PROJECT_STATE.md` 에 있습니다.

## 해 보기(내 컴퓨터에서)

각 판 폴더의 `run.bat` 을 누르면 로컬 서버가 뜨고 브라우저가 열립니다(Node 필요). 손으로 띄우려면:

```text
node saga-web/tools/serve-game.mjs 8791 saga-web/saga-go
```

포트는 1만리 8791 · 2나락 8792 · 3마을 8793 · 4종횡 8794 · 5천하 8795 입니다.
1만리는 위치(GPS)를 쓰고, 폰에서는 HTTPS 가 필요합니다(`run-phone.bat`). 위치를 못 쓰면 키보드 이동으로 넘어갑니다.
3D 트랙은 `saga-godot/`(Godot 4.7)·`saga-unity/`(Unity 6)으로 엽니다.

## 검증과 운영

- **공개 배포**: `main` 에 웹(`saga-web/`·루트 `index.html`)이 바뀐 푸시가 오면 `.github/workflows/pages.yml` 이 웹만 묶어 GitHub Pages 에 한 번에 바꿔 끼운다(약 3분, 배포 중에도 옛 판이 그대로 열림 · 겹치면 줄 서서 차례로). 다른 갈래 푸시는 배포하지 않는다. 되돌림: Settings → Pages → Source 를 브랜치로.

사람이 매번 해 보지 않아도 되게, 기계가 사람처럼 놀아 보고 확인합니다.

```text
node tools/test-web.mjs <판>                 # 함수 단위 자가진단 — RESULT n/n
node tools/qc.mjs --game <판>                # 번들·진단·재미 표준·촬영·플레이 QC·배포 확인 한 번에
node saga-web/tools/playcheck/pw-play.mjs    # 다섯 판을 PC·폰으로 직접 조작(이동·창·새로 고침)
node saga-web/tools/ops/ops.mjs              # 운영 콘솔 :8802 — 현황·공지·점검·사용자 세이브 읽기
```

커밋 전에는 `tools/precheck.sh` 가 구문·에셋·문서 크기를 봅니다(Claude Code 세션은 훅이 자동으로 돌립니다).
제작 도구(콘텐츠·맵 편집기)는 `saga-web/tools/run-tools.bat` 으로 한꺼번에 띄웁니다. 전체 도구 목록은 [`tools/README.md`](tools/README.md).

## 만든 것에 대해

개인 취미로 만든 것입니다. 참고한 게임들의 구조를 공부 삼아 옮겼고, 그 게임들의 그림·소리·데이터는 쓰지 않았습니다.
인물 이름은 가명이고, 실존 인물의 열전은 사료를 요약해 직접 썼습니다.
