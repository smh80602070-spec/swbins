# 사가(Saga) — 역사 인물로 노는 다섯 판

브라우저에서 그냥 열리는 웹 게임 다섯과, 그 다섯을 3D 로 다시 짓는 두 트랙(Godot·Unity)이
한 저장소에 있습니다. 한국사·중국사·일본사·세계사 인물 105인과 짐승 105종이 나옵니다.
처음엔 그림을 전부 코드(캔버스)가 그렸지만, 지금은 CC0(저작권 무료) 실제 에셋을 판마다 최대한
받아다 씁니다(기준은 [`SAGA-DESIGN.md`](SAGA-DESIGN.md) §7 에셋) — 원작의 그림·소리·데이터는
하나도 가져오지 않았습니다. 원작이 있는 판은 원작의 **축(구조)**만 옮겼습니다.

## 창작 방향 — 그냥 원작 모방에 머물지 않는다

다섯 판은 각자 원작 하나씩을 오마주하며 시작했지만, 거기서 멈추지 않습니다.
**"어느 게임이 이걸 잘 만들었더라"를 계속 훔쳐 오고**, 더 나아가 **시대(과거·현대·미래)와
장르를 넘나드는 파격적인 퓨전**(몬스터·다른 시대 인물 허용)을 다섯 판 모두의 지향점으로 삼았습니다
— "이 세상에 없는 나만의 게임"이 목표입니다. 판마다 따라 배울 참고 게임과 재미 기준은
[`SAGA-DESIGN.md`](SAGA-DESIGN.md), 선언문·후보 목록은 [`SAGA-HANDOFF.md`](SAGA-HANDOFF.md)
"창작 방향" 절에 있습니다.

## 앞으로

**웹 판은 Three.js 3D 로 단계를 나눠 옮기고**, 따로 **Godot·Unity 두 트랙이 다섯 판을 처음부터 3D 로**
다시 짓습니다. 계획은 판·트랙마다 제 폴더의 `PLAN.md` 에 있습니다 — 이 README 와 각 폴더 README 는
**지금까지 만든 것**, `PLAN.md` 는 **앞으로 갈 곳**입니다.

| 게임 | 어디로 |
|---|---|
| **사가만리** | 걸어 다니는 3D 역사 탐험 RPG — 인물·짐승·사건을 눈으로 만난다 |
| **사가나락** | 넓은 필드를 도는 top-down 3D 핵앤슬래시 |
| **사가마을** | 바이옴이 갈리는 3D 오픈 필드 생활 게임 |
| **사가종횡** | 깊이가 있는 3D 횡스크롤 액션 |
| **사가천하** | 오픈월드 3D 삼국지 — 전략과 액션 전투를 붙인다 |

다섯 판 모두 궁극적으로는 지역이 끊기지 않고 걸어서(또는 정복해서) 이어지는 **오픈월드**를
지향합니다. 사가천하는 삼국지 국토에 갇히지 않고 **실제 세계 지리를 바탕으로 영토를 넓혀 가는**
것이 최종 목표입니다(중국 삼국지 배경 자체는 그대로 둡니다).

계획들이 함께 박아 둔 못이 넷입니다.

- **처음부터 새로 만들지 않습니다(웹 판).** 지금 코드·데이터·UI 를 먼저 읽고, 살릴 것을 정한 뒤
  단계적으로 옮깁니다. 한 번에 다 갈아엎는 방식은 금지했습니다. 3D 두 트랙은 새 프로젝트지만
  기획·데이터(인물 id·도감)는 웹 판을 이어받습니다.
- **판정 층과 화면 층을 가릅니다.** 3D 는 화면 층에 얹는 계층이지 게임 규칙을 대체하지 않습니다
  — 그래야 자가진단이 계속 돕니다.
- **원작의 그림·소리·데이터는 가져오지 않습니다.** 3D 로 가도 같습니다.
- **인물 이름은 모방(오마주)이지 복제가 아닙니다.** 실존·원작 인물과 완전히 똑같이 겹치지 않도록
  표시 이름은 가명으로 임의(랜덤) 정합니다. 괴물·무기·세트 이름도 이 판 것으로 짓습니다.

큰 작업이라 판·트랙마다 폴더에 `CLAUDE.md` 를 두어, 그 폴더를 열면 `PLAN.md` 부터 읽게 했습니다.

## 해 보기(내 컴퓨터에서)

각 폴더의 `run.bat` 을 누르면 로컬 서버가 뜨고 브라우저가 열립니다. 손으로 띄우려면:

```
cd saga-web/saga-go
python -m http.server 8791      # Windows 에서 python 이 안 되면 py -m http.server 8791
# http://127.0.0.1:8791/
```

포트는 관습적으로 사가만리 8791 · 사가나락 8792 · 사가마을 8793 · 사가종횡 8794 · 사가천하 8795 를 씁니다.

**사가만리는 위치(GPS)를 씁니다.** `127.0.0.1` 은 보안 컨텍스트라 그냥 되지만,
폰에서 열려면 HTTPS 가 필요합니다(`run-phone.bat` — 인증서는 직접 만들어야 합니다,
`saga-web/saga-go/server/README.md` 참고). 위치를 못 쓰면 조용히 키보드 이동으로 넘어갑니다.

**파일 하나로 만들기** — 판마다 `build-pc.bat` 을 돌리면 css·js 를 전부 녹인
`dist/<게임>.html` 이 나옵니다. 더블클릭으로 열립니다(서버가 필요 없습니다).

**3D 트랙** — `saga-godot/` 은 Godot 4.7 표준판, `saga-unity/` 는 Unity 6 으로 엽니다.
실기 조작법은 `saga-godot/docs/HOW_TO_PLAYTEST.md` 처럼 트랙마다 `docs/` 에 있습니다.

**만드는 도구** — `saga-web/tools/run-tools.bat` 이 콘텐츠 편집기(:8799)·맵 편집기(:8800)·
사가 엔진(:8801, 코드 없이 3D 게임을 만드는 편집기 — 별도 저장소 [swbins4](https://github.com/smh8627-jpg/swbins4) 로 떼어냈고, 이 저장소 옆에 받아 두면 같이 뜹니다)을 한꺼번에 띄웁니다. 저장소 전체 도구 목록은
[`tools/README.md`](tools/README.md) 에 있습니다.

## 어떻게 만들어졌나

- **다섯 판은 완전히 별개 프로젝트입니다.** `data.js`·`sprite.js`·`core.js`·`hero.js` 를
  다섯 벌 복사해 나눠 들고 있습니다 — 일부러 그렇게 두었습니다. 한 판의 균형을 고치다
  다섯 판이 같이 흔들리는 것보다 낫다고 봤습니다.
- **판정 층과 화면 층을 갈라 두었습니다.** 실시간 요소(전투·자동 순행·3D)는 화면 없이도
  굴러가는 함수로 판정하고, 그리기는 그 위에 얹습니다. 그래서 헤드리스 브라우저에서
  자가진단이 그대로 돕니다.
- **자가진단** — 각 폴더의 `_test.html` 을 열면 그 자리에서 채점합니다.
  무작위는 씨앗으로 고정돼 있어 몇 번을 돌려도 같은 수가 나옵니다.
  ```
  chrome --headless=new --disable-gpu --virtual-time-budget=45000 \
         --dump-dom http://127.0.0.1:8791/_test.html      # RESULT n/n (전부 통과면 n/n)
  ```
  3D 트랙은 헤드리스 엔진으로 장면을 띄워 도는 자동 점검(Godot `tools/godot_regress.sh`·`probe_*.gd`)을 씁니다.
- **눈으로 보기** — `_demo.html#<장면>` 이 정지 화면을 만들어 줍니다.
  `_admin.html` 은 세이브와 균형 손잡이를 만지는 운영판입니다.
- **커밋 전 점검** — `tools/precheck.sh` 가 js 구문·바뀐 에셋·문서 크기 상한을 봅니다(`bash tools/precheck.sh`.
  Claude Code 세션에서는 `git commit` 전에 훅 `tools/hooks/gate.js` 가 저절로 돌립니다).

## 만든 것에 대해

개인 취미로 만든 것입니다. 원작 게임들의 **구조**를 공부 삼아 옮긴 것이고,
원작의 에셋(그림·소리·데이터)은 하나도 가져오지 않았습니다.
도감에 실린 실존 인물의 열전은 사료를 요약해 직접 썼습니다.
