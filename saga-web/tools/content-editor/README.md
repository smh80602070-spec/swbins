# saga-web 콘텐츠 에디터

다섯 판(`saga-go`·`saga-dungeon`·`saga-forest`·`saga-story`·`saga-realm`)이 나눠 든
`js/data.js` 의 `HEROES`(인물)·`PETS`(펫)·`BIOS`(열전)을 웹 UI로 편집하고,
다섯 벌에 동시에 반영하는 로컬 전용 도구다. 게임 서버가 아니다 — 이 도구를
켜도 게임 다섯 판은 그대로 안 켜져 있고, 반대로 게임을 켜 둔 상태에서 이
도구로 데이터를 고치면 게임 쪽은 새로고침해야 반영된다.

## 실행

```
run-editor.bat
```

브라우저가 자동으로 `http://127.0.0.1:8799/` 를 연다. 창을 닫거나 Ctrl+C 로
끄면 된다.

## ▶ 실행

위 줄 **▶ 실행**(F5)이 고른 판을 이 편집기 안 오른쪽 창에 띄운다(`/play/<판>/`, 연습용 세이브 — 실제 게임 세이브와 따로).
저장하면 열린 창을 새로 띄운다. 자세한 것은 `../map-editor/README.md` "▶ 실행".

## 무엇을 하는가

- 왼쪽 트리에서 인물(era 별)·펫(분류별)을 고르면 오른쪽에 필드가 뜬다
  (이름·세력·능력치·등급·대사 등). 인물을 고르면 그 인물의 열전(BIOS) 도
  같이 편집할 수 있다.
- **저장하면 다섯 판 `data.js` 에 동시에 반영된다** — 한 판만 고치고 나머지
  네 판을 깜빡하는 실수를 원천적으로 없앤다. 상단 배지가 다섯 판의 콘텐츠가
  실제로 일치하는지 보여준다(초록 = 동기화됨).
- id 는 수정 화면에서는 잠겨 있다 — 세이브·연성·도감이 전부 id 로 물려
  있어서 한번 정하면 바꾸면 안 된다(`../../CLAUDE.md` "하지 말 것" 참고).
  새로 만들 때만 직접 정한다.

## 어떻게 다섯 벌에 반영하는가

`saga-go` 를 기준판으로 삼아 편집 전 항목의 원문을 그대로 찾아(`indexOf`,
정확히 한 번만 걸릴 때) 다섯 판 파일에서 그 부분만 바꿔치기한다. 이미 다섯
판이 어긋나 있어서 원문이 안 걸리거나 두 번 걸리면 그 판은 실패로 보고하고
건드리지 않는다 — 자동으로 밀어붙이지 않는다. `HEROES`/`PETS`/`BIOS` 세
구간만 손대므로 사가만리 전용 코드(등급 이름, 일본어/중국어 열전 생성기 등)는
안 건드린다.

## 3D 자산 탭

상단 "3D 자산" 버튼을 누르면 판을 하나 골라(`js/asset3d.js`의 `DEFAULTS` 표는
`data.js`와 달리 판마다 완전히 다르다 — 공유하지 않는다) 그 판의 GLB 자산을
다룰 수 있다.

- 왼쪽 트리 위 칸은 `DEFAULTS` 항목, 아래 칸은 `assets/models/` 밑의 모든
  GLB/webp 파일 목록이다. 아무거나 고르면 오른쪽에 실제 3D 뷰포트(드래그로
  회전, 휠로 확대/축소)가 뜬다.
- `DEFAULTS` 항목 중 **"편집가능"** 태그가 붙은 것만 파일을 바꿔 저장할 수
  있다 — `'beast': ANIMALS + 'Wolf.glb'` 처럼 접두 상수+파일명이거나 순수
  문자열 리터럴인 단순한 값만 해당한다.
- **"복잡" 태그**가 붙은 항목(`HERO_RECIPES` 같은 변수 참조, 후보군 배열
  등)은 읽기 전용이다 — 자동으로 손대면 표현식이나 그 옆의 라이선스/교체
  이력 주석이 깨질 위험이 있어서 일부러 안 건드린다. 이런 항목은 원본
  코드를 직접 열어 고친다.
- 이 탭은 **판마다 따로** 저장한다(HEROES/PETS처럼 다섯 판에 동시 반영 안
  함) — 애초에 판마다 내용이 다르기 때문이다.
- 파일 목록은 `assets/models/`뿐 아니라 `assets/textures/`도 훑는다. 순수
  이미지(webp/png/jpg)를 고르면 3D 뷰포트 대신 `<img>`로 바로 보여준다.
- 상단 "업로드(FBX·OBJ·GLB·이미지)" 버튼으로 로컬 파일을 추가할 수 있다(여러 개 한꺼번에 골라도 된다).
  GLB/GLTF·이미지는 그대로 `assets/models/_uploaded/`·
  `assets/textures/_uploaded/`에 들어가고, **FBX는 자동으로 GLB로
  변환**돼 들어간다(저장소 루트에 `npm install fbx2gltf`로 깐 로컬 변환
  도구를 그 자리에서 부른다 — 없으면 에러 메시지로 알려주고 멈춘다).
  이미 있는 이름은 절대 덮어쓰지 않고 `-2`, `-3`처럼 번호를 붙인다.
- **OBJ 는 자동으로 GLB 로 변환**된다(`obj2glb.js`, 의존성 없음 — `obj2gltf` 는 cesium 을 통째로 끌고 와 안 썼다).
  OBJ 하나에 `.mtl`·텍스처(png/jpg/webp)를 **함께 골라** 올리면 GLB 하나로 합친다 — 텍스처는 GLB 안에 들어가고
  따로 파일을 남기지 않는다(webp 는 `EXT_texture_webp`). MTL 의 `map_Kd` 경로는 파일 이름만 보고 짝을 찾는다.
  - 읽는 것: `v`·`vt`·`vn`·`f`(삼각형·사각형·n각형, `v/vt/vn`·`v//vn`·음수 색인)·`usemtl`·`mtllib`, MTL 의 `Kd`·`d`/`Tr`·`map_Kd`.
    재질마다 primitive 하나, 전체는 메시·노드 하나. `o`·`g`·`s`·선·점은 무시한다.
  - `vn` 이 없으면 같은 위치끼리 면 법선을 모아 **부드러운** 법선을 만든다(각진 모양은 내보낼 때 법선을 넣어 둘 것).
    `vt` 의 v 는 glTF 규약대로 뒤집는다. 금속성 0·거칠기 1 고정.
  - MTL·텍스처가 없거나 모르는 재질이면 **경고만** 하고 회색/무텍스처로 넣는다(결과 줄에 "경고:" 로 찍힘).
    크기가 1000 을 넘으면 cm/mm 단위일 수 있다고 경고한다(크기는 안 바꾼다).
  - **거절**: OBJ 가 없거나 둘 이상 · 꼭짓점이나 면이 없음 · 숫자가 아닌 값 · 범위 밖 색인 · MTL 혼자.
  - 압축(Meshopt·WebP)은 하지 않는다 — 게임에 쓸 거면 `tools/glb-compress/compress.mjs` 를 따로 돌린다.
  - API: `POST /api/upload-obj/<판>` 몸 `{ files: [{ name, data(base64) }] }`. OBJ 하나만이면 기존 `/api/upload` 로도 된다.

## 안 하는 것

- `data.js` 밖의 파일(`sprite.js`·`core.js`·`hero.js`, 각 판의 `_admin.html` 등)은
  건드리지 않는다. 새 인물을 추가해도 초상화·전용 3D 자산은 따로 챙겨야 한다.
- git add/commit/push 를 하지 않는다 — 저장된 변경사항은 그냥 워킹트리 변경이고,
  커밋 여부는 사용자가 직접 판단한다.
- 실명은 **알려진 목록만** 막는다(아래 "실명 가드") — 목록에 없는 실명은 못 잡으니 새 인물은 사람이 한 번 더 훑는다.

## 대사·퀘스트 편집기 (`story.html`, 2026-09-23)

위 줄 **대사·퀘스트 →** 또는 `http://127.0.0.1:8799/story.html`. 다섯 판에 흩어진 퀘스트·대사·문답 표 15개를 **칸으로** 고친다
(판별 표 탭은 항목 원문을 통째로 고치는 것, 여기는 모양에 맞춘 입력 칸 + 미리보기 + 참조 검사).

| 무리 | 표(판 · 파일 · 변수) |
|---|---|
| 퀘스트 | 사가종횡 사명 `data-quest.js` QUESTS · 사가나락 메인/구출 이벤트/지역/무작위 현상 `data-quest.js` MAIN·EVENT·REGION·RANDOM_POOL · 사가만리 사명 `quest.js` KINDS |
| 대사 | 사가종횡 마을 사람 말 `NPC_TALK` · 첫 발 장면 `STORY`([누가, 감정, 말]) · 잡담 `NPC_CHAT` (`data-side.js`) · 사가나락 마을 사람 `town.js` NPC_DEFS · 사가만리 낮/밤/비 말 `npc.js` LINES · 길 위 사건 `event.js` EVENTS · 사가마을 주민 대화 `folk.js` TOPICS·EVENT_TOPIC |
| 문답 | 사가천하 `data-quiz.js` BANK(실명 가드 예외 파일) |

- **바뀐 값의 글자 자리만 바꾼다**(`jslit.js`): 표를 값마다 글자 위치를 기억한 나무로 읽고, 고친 문자열·숫자만 그 자리에서 바꾼다 —
  주석·줄 맞춤·다른 값은 한 글자도 안 움직인다. 키가 늘거나 준 작은 그릇·길이가 바뀐 배열만 새로 쓰고(그 안 주석이 사라지면 경고), 맨 윗단 항목은
  **끼우고 옮길 수 있다** — 남은 항목들의 글자 자리는 그대로 두고 그 자리에 들어갈 항목 글자만 바꿔 넣는다(항목 사이 머리말 주석은 자리에 남고, 항목 안 주석은 따라간다).
  id 없는 표(잡담·주민 대화)는 편집기가 항목마다 옛 자리 번호(`origin`)를 들고 다녀 무엇을 옮겼는지 안다.
- **코드 속 대사**: 함수가 섞인 자리(사가만리 사건의 결과 `out`, 사가나락 무작위 현상의 `descOf`)는 코드는 잠그고 그 안의 `text:`·`label:` 같은 문자열만 고친다.
- **칸**: 값 모양대로(글·숫자·켬끔·목록·[누가, 감정, 말] 줄) · 고를 값이 정해진 칸은 고르기(목표 종류·사냥터·채집물·주문서·방 종류·사람·감정·갈래) ·
  더할 수 있는 칸은 "+ 칸"(예: 목표에 `stage`) · 표지(`{town}` …) 넣기 단추 · 줄 ↑↓×.
- **항목 차례**: "＋ 새 항목"·"본뜨기"는 고른 것 바로 뒤에 끼운다(안 골랐으면 끝) · 목록 위 ↑↓ 나 `Alt+↑/↓` 로 옮긴다.
  사가나락 지역 퀘스트는 자리 번호가 곧 지역이라 못 옮기고(↑↓ 꺼짐·저장 막음), 사가나락 메인·구출은 세이브가 `mainIdx`·`eventIdx`(자리 번호)로
  진행을 쥐어 옛 항목 차례가 바뀌면 **경고**한다(하던 세이브는 건너뛰거나 되풀이). 나머지 표는 게임이 key·id 로 찾거나 무작위로 뽑아 차례가 상관없다.
- **막는 것**(저장 안 함): md5 충돌 · 고친 파일 구문 오류 · **되읽기 불일치**(고친 파일을 다시 읽은 값 ≠ 화면 값) · 표마다 참조 검사
  (없는 사냥터·방 종류·주문서, 장면의 모르는 사람·감정, 사냥터가 쓰는 마을 사람 지우기, 문답 답 번호 …) · **있던 id·키 지우기/바꾸기**(세이브·코드가 쥔다) ·
  잠금 칸(사가만리 사명 `kind`, 사가나락 NPC `sheet`) · 사건·지역처럼 코드가 자리 수를 정한 표의 더하기 · 새 글자의 실명(`realname.js`).
- **경고만**: 표지가 한 줄에 두 번(게임의 `replace` 는 첫 번째만 채운다) · 모르는 표지 · 빈 설명 · 어느 마을에도 안 서는 새 마을 사람.
- 저장하면 그 판 `sw.js` VERSION 을 올리고(서버 실행당 한 번), 열린 ▶ 실행 창을 새로 띄운다. 되돌리기 `Ctrl+Z`(글 칸 밖) · 저장 `Ctrl+S`.
- 표를 더하려면 `story.js` `adapters()` 에 한 덩이(파일·변수·id 칸·고르기·검사)를 넣는다.

## 판별 표 탭 (`data-*.js`, 2026-09-23)

상단 **판별 표(data-*.js)** 탭 — 각 판 `js/data-*.js` 의 `var NAME = [ {…}, … ]` 배열(현재 88개: 퀘스트·아이템·적·도시·던전 등)을
항목 하나씩 **원문 그대로** 고친다. `data.js` 와 달리 다섯 벌이 아니라 **그 판 한 벌**만 쓴다(`tables.js`).
저장 전에 서버가 ① 그새 파일이 안 바뀌었는지(다른 세션과 충돌 방지) ② 항목·파일 전체 구문 ③ 실명을 확인하고,
통과하면 그 바이트 구간만 바꾼다. 키·id 는 세이브·진단이 물고 있을 수 있으니 바꾸지 않는다.

## 실명 가드 (`realname.js`)

인물·펫·열전·판별 표를 저장할 때 표시 글자에 알려진 실명이 있으면 **저장을 거절**하고 걸린 이름을 알려 준다.
목록은 다섯 판 `_test.html` "가명 정책" 진단과 같다(늘릴 땐 둘 다). 역사 퀴즈 `saga-realm/js/data-quiz.js` 는 예외.

## sw.js VERSION 자동 올림 (`swbump.js`)

편집기가 판 `js/` 를 쓰면 그 판 `sw.js` 의 VERSION 가운데 숫자를 하나 올린다(서버를 켠 동안 판마다 한 번) —
안 올리면 옛 서비스워커 캐시가 계속 나온다(각 판 PLAN §7 함정). 저장 결과 줄에 새 VERSION 이 찍힌다.
