# U-0019 `EnvironmentMaterial`×4 → `Saga.Core.EnvironmentMaterial`
종류: 통합      판: GO·DUNGEON·REALM·STORY      등급 목표: (체제) — 복제 23 중 씬 참조 없는 한 덩어리      상태: 작성됨(R-0)

**목표(한 줄)**: 네 판 `World/EnvironmentMaterial.cs`(정적 클래스, 25~53줄)를 `SagaCore/EnvironmentMaterial.cs` 하나로 합치고 호출부 `using` 만 바꾼다.

**출처**: BACKLOG §3.3 "같은 이름 복제 23개 → SagaCore 이관"(U-0007 `MountRig` 다음 덩어리). 큐가 비어 R-0 로 고름.

**조사(R-0)**: GO·REALM·STORY 셋은 주석·네임스페이스만 다르고 `MakeTiled(template, w, d)` 본문 동일. DUNGEON 은 그 위에 `wearTier`(기본 0, 0 이면 `ApplyWear` 즉시 return) 를 얹은 **상위집합** → DUNGEON 본문이 합친 버전. 정적 클래스라 씬·프리팹 GUID 참조 없음(remap 불필요 — `DebugHud`·`DialogueLabel`·`LocalizedButtonLabel` 은 씬 참조가 있어 이 티켓 밖). 다섯 `*.asmdef` 모두 `SagaCore` 참조 이미 있음. 호출부(.cs): DUNGEON `DungeonCorridorBuilder`(4)·`DungeonRoomBuilder`(10) · GO `LandmarksBuilder`(8)·`PropsBuilder`·`RegionPropsBuilder`·`Watchtower` · REALM `RealmCityBuilder`(6) · STORY `StoryTerrainBuilder` · 에디터 `Editor/BuildPropsMaterialSplit.cs`(`using Saga.Go.World;` → 이 클래스를 쓴다).

**파일**: `saga-unity/Assets/SagaCore/EnvironmentMaterial.cs`(새, `.meta` 는 Unity 가 만든다) · `Games/{SagaGo,SagaDungeon,SagaRealm,SagaStory}/World/EnvironmentMaterial.cs`(+`.meta`, 삭제) · 위 호출부 9개 파일

**본보기**: `Games/SagaDungeon/World/EnvironmentMaterial.cs` — 그대로 옮기고 네임스페이스만 `Saga.Core`. 주석은 "다섯 판 공용" 한 단락으로 줄인다.

**단계**
1. `SagaCore/EnvironmentMaterial.cs` 작성(DUNGEON 본문, `Saga.Core`). 컴파일 확인 전엔 아직 옛 파일 둔다 — 같은 이름이 `using` 두 개로 모호(CS0104)해지므로 2·3 은 한 커밋 안에서.
2. 네 판 옛 `EnvironmentMaterial.cs`·`.meta` 삭제(`git rm`).
3. 호출부 9개에 `using Saga.Core;` 추가(이미 있으면 건너뜀). 판 네임스페이스 `using Saga.<판>.World;` 는 다른 타입 때문에 남긴다.
4. 배치 컴파일 → `error CS` 0 → 진단 → 설정 4파일 원복 → 커밋.

**검증**
```
cd saga-unity && U="/c/Program Files/Unity/Hub/Editor/6000.3.24f1/Editor/Unity.exe"
bash tools/unity-batch.sh -- "$U" -batchmode -nographics -projectPath . -executeMethod Saga.EditorTools.PlaytestHeadless.Run -logFile .utmp/u0019.log ; grep -E "\[PlaytestHeadless\] (OK|FAIL)|error CS" .utmp/u0019.log   → OK, error CS 0
```

**완료 조건**: 위 · `class EnvironmentMaterial` 한 곳 · 호출부 동작 불변(`MakeTiled` 시그니처·`wearTier` 기본값 0 유지) · 세이브·도감 id·표시 글자 불변 · 설정 4파일 원복 · worktree 가 아니면 남의 미커밋 `.cs` 는 건드리지 않는다.
