# U-0052 사가만리 경험치 곡선 — 레벨 58 부터 int 를 넘어 `AddExp` 가 멈추는 버그(곡선 완만 + long)
종류: 버그 · 유니티      판: GO      상태: 작성됨(R-0 2026-10-07)      등급 목표: D1

**목표(한 줄)**: `done/U-0045` 메모 "발견": `PlayerStats.ExpForLevel = 80×1.35^(레벨−1)` 이 레벨 58 부터 int 상한(≈2.1e9)을 넘어 `AddExp` 의 `while (Exp >= ExpToNext)` 가 음수 문턱에서 끝나지 않는다(진단이 실제로 멈춤). 이야기 마지막 장 문턱(레벨 85)·재출항(U-0045)에 보통 플레이로 닿을 수 있게 곡선을 완만하게 하고 자료형을 long 으로 바꾼다.

**결정(페이블 10-07, 사용자 거부권)**: ① 레벨 상한은 두지 않는다(이야기 문턱 85 유지) ② 곡선: Lv.30 까지 지금 식 그대로(세이브 호환), Lv.31 부터 한 레벨 증가분을 직전 증가분 ×1.08 로(웹 사가종횡 `st.data-quest` "Lv.25 까지 그대로, 그 뒤 완만" 과 같은 꺾기) → Lv.85 문턱 ≈ 3e7, 누적 ≈ 4e8 로 long 안 ③ `Exp`·`ExpToNext`·`ExpForLevel` 은 long, UI 표시는 `N0` 서식.

**파일**: `ExpForLevel` 이 있는 `.cs`(단계 1 grep 으로 확정 — `PlayerStats.cs` 로 추정) · 세이브 상태 `.cs`(exp 칸이 int 면 long, 옛 int 세이브는 그대로 읽힘) · `saga-unity/Assets/Editor/PlaytestGoCycle.cs`(레벨 60 돌리는 줄이 있으면 85 로) · 새 `saga-unity/Assets/Editor/PlaytestGoExpCurve.cs` · `saga-unity/features.json`(`un.go.exp-curve` 새 항목 D1) · `saga-unity/docs/PROJECT_STATE.md`(열린 결정 1번 줄 삭제)
※ 자리는 `grep -rln "ExpForLevel" saga-unity/Assets --include=*.cs` 로 단계 1에서 확인하고 이 칸을 실제 경로로 고쳐 적는다.

**단계**
1. 자리 확인(grep) → `ExpForLevel(int level)` 을 long 반환으로: L≤30 은 `(long)(80*Math.Pow(1.35,L-1))`, L>30 은 루프로 증가분 ×1.08 누적(85회라 비용 없음). 결과를 배열(1~200)에 캐시.
2. `AddExp(long)`: `while (Exp >= ExpToNext && Level < 200)` — 200 은 안전장치(레벨 상한 아님).
3. `PlaytestGoExpCurve`: ① L1~30 값이 옛 식과 같다 ② 모든 L≤200 에서 `ExpForLevel(L) > ExpForLevel(L−1) > 0` ③ `AddExp(long.MaxValue/4)` 가 1초 안에 끝난다 ④ Lv.85 문턱 ≤ 5e7 ⑤ 옛 int 세이브(exp 1000·Lv.10)를 읽어도 값 그대로.
4. PROJECT_STATE "열린 결정" 1번 삭제 · features · 큐 줄 · 메모.
