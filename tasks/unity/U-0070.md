# U-0070 사가만리 지상 탈것 속도 배율이 Windows 대상에서 안 먹음(안드로이드 대상은 OK)
종류: 버그 · 유니티(사가만리)      상태: 초안(R-5 2026-10-09 — U-0068 리뷰 재검증 중 발견, 나머지 칸은 R-0)      등급 목표: 없음(회귀 지움)

**재현**
1. 활성 빌드 대상을 Windows 로 두고(`-buildTarget StandaloneWindows64`) `PlaytestHeadless` 장면 판.
2. `PlaytestGoMount.CheckSpeed` → `mount FAIL - 흰 말 걷는 거리 배율 1.00 ≠ 2.1 (안 탄 3.00m · 탄 3.00m)` — 말에는 탐(TryRide 참, 10-09 진단 보강으로 확인).
3. 같은 코드로 `-buildTarget Android` 면 mount OK·판 전체 OK(10-09 16:01).

**기대**: 대상과 무관하게 탄 채 걷는 거리 ×2.1. (의심: Teleport 직후 첫 Step 에서 Mode≠Ground → `PlayerController` 203행 Dismount — 대상별 품질·지형 높이 차이? 미확인)

**메모(체크포인트)**: 9/29 안드로이드 빌드 뒤로 이번 주 유니티 진단은 모두 안드로이드 대상에서 돌았다 — Windows 대상 회귀는 이 하나만 봄(다른 판 장면 판 셋은 Windows 대상 OK).
