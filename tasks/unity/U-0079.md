# U-0079 미래 땅 하늘 덧층 — 은하 나루·틈새 갈림길 위 사실 하늘에 행성·오로라·별 더하기
종류: 그래픽 · 유니티(GO)      상태: 작성됨(R-0 다시 씀 2026-10-10 — U-0083 뒤 다시 판단)      등급 목표: 새 항목 un.go.era-sky D2

**목표(한 줄)**: 사실 하늘(`Saga/SkyReal`) 하나로 다섯 판을 덮은 채, 미래 땅에 서 있을 때만 하늘이 미래답게(낮 큰 행성·고리, 밤 오로라·짙은 별) 바뀐다.

**다시 판단(Claude, 10-10 — 근거)**
- U-0083 으로 기본 하늘이 시각 공식 사실 하늘이 됐다(그림 파노라마는 `SAGA_SKY_PANO=1` 때만). 사실 하늘엔 지평선 그림이 없어 **과거·현대 땅의 "마을 뒤 도시" 어긋남은 이미 사라졌다 → 할 일 없음**. 옛 표(그림 12장 고르기)는 버린다.
- 남은 차이는 미래 땅뿐: `GoAreas` 의 `skyport`(명소 미래 7/15)·`crossing`(시간 틈 갈림길). 둘에서도 지금은 과거 마을과 같은 파란 하늘 — 땅·소품만 미래다. 하늘에 미래 표지를 얹는다(퓨전 원칙 그대로 — 사람·소품은 섞이고, 하늘은 그 땅 성격).
- 그림 하늘 쪽은 한 줄만: `SkyPass.Era` 기본 `"present"` → `"past"`, 미래 땅에선 `"future"`(되돌리기 모드에서도 도시가 안 뜨게).

**설계**
- `SkyReal.shader` 새 uniform `_Future`(0~1, 기본 0 — 0 이면 지금과 픽셀 같음): ① 낮·밤 행성 = 고정 방향(방위 북동·고도 ~24°) 큰 원반(반지름 ~7°)+얇은 고리, 해 쪽 반달 명암, 낮엔 대기에 묻혀 옅게(알파 ~0.35)·밤 또렷 ② 밤 오로라 = 북쪽 하늘 띠, 2D 노이즈 커튼이 `_Time` 으로 천천히 흔들림(초록→보라) ③ 별 밀도 ×2.5 ④ 지평선 띠 보랏빛 살짝. 셋 다 구름 밀도(`dens`)·흐림 아래로 가려진다. 노이즈는 기존 `Noise`/`Fbm` 재사용(새 겹 최대 2 — 성능 U-0083 표 기준 ±3% 안).
- `SkyPass`: `public static float FutureTarget`(GO 가 쓴다) · Runner 에 `Update` 로 `_Future` 를 2초에 걸쳐 따라감(그 값이 바뀔 때만 SetFloat) · `Era = FutureTarget > 0.5f ? "future" : "past"`.
- GO: `GoAreas.Area` 에 `bool SkyFuture`(Skyport·Crossing = true) · `AreaField.Update` 의 `CheckEverySec` 자리와 `Travel` 직후에 `SkyPass.FutureTarget = (AreaAt(feet)?.SkyFuture ?? false) ? 1f : 0f`. 다른 판(숲·스토리)은 안 씀 → 0.
