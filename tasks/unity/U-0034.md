# U-0034 Unity 사람 몸을 VRoid 로 — Mixamo 사람 42자리 교체 + CC0 동작 8종(K-0018 이어받기, 코드만)
종류: 새기능 · 유니티      상태: **진행중 · 단계 1 끝, 단계 2~는 K-0062 대기**(R-0 2026-10-04) — 시작 조건: 없음(`CharactersVroid` GLB 28·`unity_bodies.json` 이미 있음)      등급 목표: D2

**목표(한 줄)**: 사용자 판정(2026-10-02 "VRoid 변경하고 Mixamo 제거")을 Unity 가 받는다. K-0018 이 만든 계획표 `tools/char-forge/data/unity_bodies.json`(61자리 = 사람 42 + 사람 아닌 19)의 **사람 42자리**를 Mixamo 몸에서 VRoid GLB(`Assets/Art/CharactersVroid/*.glb` 28벌, 겹침 7명은 variant)로 바꾸고, Godot 과 같은 CC0 8동작을 Unity 클립으로 쓴다. 사람 아닌 19자리와 Mixamo 4.2GB 제거는 이 티켓 밖(끝에 메모만).

**파일(확인함)**: `saga-unity/Assets/Editor/SetupNpcCharacterImports.cs`(`ForgeSwap` 표 — 확장 대상) · `Editor/ForgeSwapScenes.cs`(교체 뒤 빌드 씬에 풀어 박힌 옛 몸 새로고침) · 읽는 `tools/char-forge/data/unity_bodies.json`(`bodies`·`vroid_pool`) · `saga-unity/Assets/Art/CharactersVroid/`(GLB 28, 이미 배치) · 동작 원본 Godot `saga-godot/assets/characters_vroid/anim`·`anim_cc0`(읽기만 — 옮겨 쓰기 전 Unity 에 이미 같은 클립이 있는지 `Assets/Animators` 먼저 확인) · 배치 `bash saga-unity/tools/unity-batch.sh -- …` · 에셋·`.meta` 는 만들거나 고치지 않는다(K-0019 몫).

**단계**
1. 현황표: `unity_bodies.json` 의 사람 42자리 ↔ 지금 Unity 가 쓰는 Mixamo 몸·`ForgeSwap` 이 이미 바꾼 자리 — 안 바뀐 자리만 목록(`grep` 으로 추측 없이).
2. 시험 1벌: `ForgeSwap` 이 VRoid GLB 를 프리팹으로 읽어(키 1.70m·피봇 발) 한 자리를 바꾸게 하고 `unity-batch` 컴파일·임포트 오류 0.
3. 사람 42자리 전부 + 8동작 연결(걷기·달리기·대기·공격·피격 등 — 목록은 Godot `anim_cc0` 기준, 모자라는 동작은 지금 클립 유지).
4. 진단: 자리마다 몸이 읽히고 키 범위·애니메이터 클립이 있다(규칙 층 함수만). GUI 촬영 한 장 확인.

**검증**
```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath saga-unity -logFile <로그> -executeMethod Saga.EditorTools.<새 진단>.Run   → [..] OK, 컴파일 오류 0
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 사람 자리마다 VRoid 몸이 뜬다 · 사람 아닌 19자리는 그대로(U-0035 후속).

**불변 규칙**: 에셋 안 만든다 · 도감 인물 id·세이브 키 불변 · 이름 정책 · **Mixamo 4.2GB 는 이 티켓에서 지우지 않는다**(`mixamo_purge.py` 는 씬 빌더 12개 참조를 다 바꾼 뒤 별도 확인) · 다른 세션이 엔진을 쓰는 중이면 먼저 확인.

**메모(체크포인트, 2026-10-04)**: ✔ 단계 1 현황표(`unity_bodies.json` 대 `SetupNpcCharacterImports.ForgeSwap`): 사람 42자리 중 **14자리는 이미 공방 FBX**(09-28 판정, 표의 15번째 `Boss` 는 사람 목록 밖), **28자리는 Mixamo**, VRoid 로 연결된 자리 **0**. VRoid GLB 28벌은 `Assets/Art/CharactersVroid` 에 있으나 **동작 클립이 없어** `SetupForge` 식(FBX 안 상태 클립 이름으로 컨트롤러 굽기)으로는 못 굽는다 — 동작이 구워진 FBX 를 자체툴에 요청: **K-0062**(요청, 이 티켓은 에셋을 안 만든다). K-0062 가 놓이면 단계 2~4 를 이어서(`ForgeSwap` 표를 `unity_bodies.json` 에서 채움 → 배치로 프리팹 굽기 → 진단·GUI 한 장).
