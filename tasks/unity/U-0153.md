**목표(한 줄)**: 유니티 창은 `SagaUi.NewPanel`·`NewButton` 의 단색 사각형(Panel·ButtonIdle·ButtonAccent) + 판마다 손으로 그린 `Image` 84 자리 → 웹과 같은 규칙 **틀은 하나, 색 옷만 판별**: 창 = window, 모달 = popup, 카드 = card, 탭 = tab_on/off, 단추 = btn_normal/hover/pressed/disabled 를 `Image.Type.Sliced` 로. 8px 격자·안쪽 여백 16·24·제목 띠 아래 금빛 가는 줄·닫기 40px 둥근 단추(웹 W-0252 결정 ①~④ 그대로).

**잰 것(R-0 10-21)**: 스킨 원본 `saga-web/shared/assets/ui/<go|dungeon|forest|story|realm>/*.png`(+`ui_parts.json` 크기·slice px: window 32·popup 36·card 28·tab 14·btn 24) · 유니티엔 UI 스킨 0(`SagaCore/Resources/` 에 UI 폴더 없음) → **K 요청 필요**(스프라이트 border 는 `.meta` — K 몫).

**파일(확인함 10-21)** — 머리 `saga-unity/Assets/`: `SagaCore/SagaUi.cs`(17~23 색 · 115 `NewPanel` · 135 `NewButton` · 50 `NewHudCanvas`) · 일시정지 `SagaCore/SagaFlow.cs`(112 `SagaPauseButton` · 141 `SagaPauseMenu`) · 타이틀 `Games/SagaTitle/TitleScreen.cs` · 판별 창 예 `Games/SagaGo/UI/MenuHubUi.cs`·`Games/SagaForest/UI/EncounterUiKit.cs`·`Games/SagaGo/UI/EncounterUiKit.cs`·`Games/SagaStory/UI/StoryPickUi.cs` · 판 이름 → 짧은 이름: 씬 `SagaCore/SkyPass.cs` 74 `ModeFor(sceneName)` 꼴 · 배치 점검 `Editor/UiLayoutCheck.cs`.

**단계**
1. K 요청(`tasks/tools/` 최대+1, 상태 **요청**): 다섯 판 스킨 png 를 `SagaCore/Resources/UI/<판>/` 로 place(sprite·border = ui_parts slice·Full Rect·mip 끔), 출처 그대로 — 이 티켓 메모에 번호.
2. `SagaUi` 에 `Skin`(현재 판 짧은 이름 — 씬 이름에서) + `Sprite Part(string part)`(Resources.Load, 없으면 null) · `NewPanel(... , part)`·`NewButton` 이 스킨 있으면 Sliced + 흰 색조, 없으면 지금 단색(스킨 없는 PC·K 전에도 그대로 돔).
3. 단추 상태: `Button.transition = SpriteSwap`(hover·pressed·disabled) · 글자 Ink.
4. 공용 셋 먼저(일시정지·타이틀·설정 창) → 판별 창은 `NewPanel` 을 부르는 것부터(손 `Image` 는 U-0154 에서 같이).
