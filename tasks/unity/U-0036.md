# U-0036 Unity 자연 소품 교체 — 나무·덤불·풀·꽃·바위를 K-0052·0058 통일 세트로(코드만)
종류: 새기능 · 유니티      상태: **작성됨**(R-0 2026-10-04) — 시작 조건: 없음(GLB 이미 `Resources/World`)      등급 목표: D1

**목표(한 줄)**: 유니티가 쓰는 나무·풀·꽃·바위는 옛 Kenney 계열이다(`Assets/Art/Vegetation`). 자체툴이 올린 통일 세트(`Resources/World`: `tree_broadleaf_01~03`·`tree_pine_01~03`·`tree_pine_01_snow`·`tree_birch_01`·`tree_dead_01`·`bush_01·02`·`grass_tuft_01·02`·`flower_patch_01`·`rock_*`)를 식생·지형 소품 자리에 쓴다. 고돗 G-0017·G-0019 와 같은 세트.

**파일(확인함)**: `saga-unity/Assets/Games/SagaGo/World/VegetationBuilder.cs`(식생 바이옴) · `Editor/PlaytestGoVegetation.cs` · `Editor/SetupForestCreatureModels.cs`(`Art/Vegetation` 참조) · 다른 판의 나무 자리는 `grep -rn "Art/Vegetation\|Kenney"` 로 먼저 표 · 재질 `SagaCore/Region/RegionMaterials.FromGltf`(툰).

**단계**
1. 현황표: 식생·지형 소품을 만드는 코드 자리(판별)와 지금 쓰는 모델, 대응할 새 GLB 이름(뜻이 맞는 것만).
2. GO `VegetationBuilder` 부터: 바이옴별 나무·풀·꽃·바위를 새 GLB 로(없으면 기존). 인스턴싱·그림자 규칙은 기존대로(화질 안 깎기).
3. 다른 판의 나무 자리 이어서(숲·스토리 등) — 판별로 한 커밋씩.
4. 진단: 새 GLB 읽힘·재질 툰·삼각형 예산(기존 `PlaytestGoVegetation` 값 안), GUI 촬영 한 장.

**검증**
```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath saga-unity -logFile <로그> -executeMethod Saga.EditorTools.<새 진단>.Run   → [..] OK, 컴파일 오류 0
기존 관련 Playtest 같은 값 · bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 마을·들판 식생이 새 세트로 뜬다 · 없는 칸은 기존.

**불변 규칙**: 에셋(GLB·그림·`.meta`)은 만들거나 고치지 않는다(K 갈래·K-0019 몫) · 세이브 키·id 불변 · 이름 정책 · 다른 세션이 엔진을 쓰는 중이면 먼저 확인.
