# U-0042 Unity 이름 없는 군중 — 인물 299 로 마을·광장에 행인을 세운다(U-0040 후속)
종류: 새기능 · 유니티      상태: **초안**(R-0 2026-10-04, 사용자 결정 "이름 없는 군중에만") — 시작 조건: 없음(299 몸·공용 동작은 로컬 설치됨, U-0040)      등급 목표: D1

**목표(한 줄)**: 사용자 결정(2026-10-04): 인물 299 는 **이름 없는 군중**에만 쓰고, 시대 역할 인물(GO 역참 행인 15·시대 사람·마을 사람)은 VRoid 42자리를 유지한다. 유니티엔 이름 없는 군중이 아직 없다 — 마을·광장에 8~12명이 천천히 걷고 서 있는 한 자리를 만든다.

**파일(확인함)**: `SagaCore/CrowdBodies.cs`(`Available`·`IndexFor(key)`·`Spawn(key, parent, height, yaw)`) · `CrowdBodyAnimator`(대기·걷기 `SetWalking`) · 참고 구현 `Games/SagaForest/World/ForestVisitorNpc.cs` 의 Build(299 → 기존 몸 → 캡슐 순) · 걷는 틀 `Games/SagaGo/World/FolkWalker.cs`(왕복 걷기) · 자리 후보 GO 마을(`TestVillage`)·숲 마을 광장. 에셋·`.meta` 는 안 만든다.

**단계**
1. 자리·수 정하기(열린 질문 참조) 후 현황: 그 자리에 이미 서 있는 NPC·충돌·그림자 규칙.
2. `SagaCore/AnonymousCrowd.cs` — 자리 중심·반지름·수·시드(`mulberry32` 고정, 판별 영속 없음)로 군중 키를 고르고 `CrowdBodies.Spawn` 으로 세운다. 299 가 없는 PC 는 아무것도 안 세운다(캡슐 대체 금지). 키는 군중끼리 겹치지 않게 서로 다른 인물 id.
3. 걷기: 일부는 서 있고 일부는 왕복(`SetWalking`) — `FolkWalker` 를 재사용할 수 있으면 그걸로, 아니면 작은 전용 이동.
4. 진단: 수·서로 다른 인물·키 범위·299 없는 PC 에서 0명 · 기존 진단 값 안 바뀜. GUI 촬영은 사용자 요청 때만.

**검증**
```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath . -logFile <로그> -executeMethod Saga.EditorTools.<새 진단>.Run   → [..] OK, 컴파일 오류 0
기존 PlaytestHeadless(GO)·숲 진단 같은 값 · bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 한 자리에 군중이 서고 걷는다 · 299 없는 PC 에서도 기존 진단 통과 · 시대 역할 인물은 그대로.

**불변 규칙**: 에셋 안 만든다 · 시대 역할 인물(`GoEras.Roles`·`EraFolk` 류)을 299 로 바꾸지 않는다 · 세이브·id 불변 · 이름 정책(군중에 이름표·대사 안 단다 — 이름 없음) · 성능: 한 자리 12명 이하·`CullUpdateTransforms` 유지.

**열린 질문(R-0)**: ① 어느 자리부터 — 추천 GO 마을 광장(사람이 가장 자주 보는 곳), 다음 숲 광장 · ② 수 — 추천 10명(서 있기 4·걷기 6) · ③ 걷는 틀 — 추천 `FolkWalker` 재사용(없으면 작은 전용).
