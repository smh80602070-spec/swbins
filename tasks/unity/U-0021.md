**목표(한 줄)**: 지금 다섯 판은 `Bgm.Play("<판>", "main", clip, …)` 로 곡 하나(`CC0_BGM` 의 3곡)만 반복한다. `Saga.Core.Bgm` 은 이미 `Resources/Audio/Bgm/<판>-<장면>` 로 장면별 곡을 찾으니(U-0014), 자체 생성 곡 15(`saga-web/shared/audio/bgm/<판>-<장면>.ogg`, ACE-Step 1.5 MIT·상업 OK)를 그 자리에 두고 장면(마을·들판·전투)에 맞게 키를 불러 준다.

**파일(확인함)**: `saga-unity/Assets/SagaCore/Bgm.cs`(규약: 키 `<판>-<장면>`, `Loader`, 곡 없으면 폴백→무음) · `Assets/Games/Saga{Dungeon,Forest,Go,Realm,Story}/{Audio,World}/*Bootstrap.cs`·`*Audio.cs`(`PlayBgm(clip)` 호출 자리) · `Assets/Games/SagaGo/World/GoBgmScene.cs`(사가고 본보기 — 이미 장면 키가 있는지 단계 1에서 확인) · 새 `Assets/Resources/Audio/Bgm/*.ogg`(+`.meta`, Unity 가 만든다) · `Assets/Editor/PlaytestBgm.cs`(진단) · `docs/HOW_TO_PLAYTEST.md` §18

**단계**
1. `GoBgmScene.cs` 와 판별 `*Audio.cs` 를 읽어 지금 장면 키를 어떻게 정하는지 확인하고, 나머지 네 판에 같은 방식으로 `Bgm.Play(판, 장면, clip, vol)` 를 장면 상태(마을/들판/전투)에서 부르게 한다. 코드 변경은 최소.
2. 곡 15 를 `Resources/Audio/Bgm/` 에 복사하고 Unity 를 한 번 열어 `.meta`·임포트(Vorbis, 로드 타입 Streaming, 모바일 용량 확인)를 만든다 — `bash tools/unity-batch.sh -- …`(설정 4파일 원복, 다른 세션이 Unity 를 쓰는 중이면 기다린다).
3. `PlaytestBgm` 에 15키 모두 `Loader` 가 클립을 돌려주는지 검사 추가.

**검증**: `bash tools/unity-batch.sh -- -executeMethod …PlaytestBgm` 통과 · 곡 합계 ≤ 15MB 증가(`git count-objects` 전후 메모) · `audit.py --quick` 🔴 0 · `precheck.sh` OK.

**완료 조건**: 단계 1~3 · 다섯 판에서 장면이 바뀌면 곡이 바뀐다(사용자 확인 시트) · 기존 CC0 곡은 폴백으로 남김.

**불변 규칙**: PlayerPrefs 키·세이브 불변 · 컴파일 확인은 배치 로그로만 · 사용자 확인 전 기본 음량 안 바꿈.
