2. 지역 표: 유니티 성 55 의 웹 `prov` 를 `RealmEnemyCity` 에 `ProvOf(id)` 로 — 웹 `data-city.js` 의 `id→prov` 중 유니티 `AllIds` 와 겹치는 것만 스크립트(스크래치패드 node)로 뽑아 넣는다(확인: 교주 `jiao` 는 nanhai·cangwu·yulin·hepu·jiaozhi·jiuzhen·rinan 겹침, 균열 `fu`·폐허 `pf`·서역 `xi` 는 겹침이 없을 수 있음 — 겹침 0 이면 `prov` 우선은 건너뛰고 웹과 같이 땅 → 병력 순으로 떨어진다).
3. 상태·흐름: `PickTarget(near, prov)` = 우리 성(`ActiveCityIds`)에서 칠 수 있는(`AttackFromCityId` 가 우리 성) 안 차지된 적 성, 정렬 = prov 맞음 0·땅(Plain/River) 맞음 1·그 외 2 → 병력 적은 순 → id. 없으면 단계 안 열고 지금 동작 그대로. 열리면 `{id, target, since=TurnNow}` 와 토스트·기록 "🎯 제목 — 성이름 을(를) N달 안에 차지하라". 열려 있는 동안 본 사슬(`CARDS`)은 쉬고 곁 사슬은 흐른다. 차지 판정 = 목표 `Captured`(또는 `ActiveCityIds` 에 듦) → 이긴 결과, `TurnNow - since >= months` → 진 결과. 결과 카드(`<id>_end`, 단추 하나 "확인")를 낸 뒤 `Resolve` 가 fx 를 적용하고 단계를 닫는다.
4. 세이브: 단계 세 값(없으면 단계 없음 — 옛 세이브·이미 끝낸 카드는 영향 0). 새 값은 `RealmSaveState` 버전 그대로.
5. 진단: ① 표 여섯·`months` 10/10/12/12/12/12 ② 목표 성 선택(prov→땅→병력 순·없으면 안 열림) ③ 열린 동안 본 사슬이 쉼 ④ 목표를 차지(함락 편입)하면 이긴 결과 카드 + fx ⑤ 달 수를 넘기면 진 결과 카드 + fx ⑥ 단계 중 세이브 왕복 ⑦ 옛 세이브(필드 없음) ⑧ 설전·일기토·열전 카드는 동작 불변. 현지화 키(`scenario.stage.*`·`.title`·win/lose 글 한·영) 추가 후 `py tools/loc-missing.py`(saga-unity 에서) 빠짐 0.
