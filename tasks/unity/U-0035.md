# U-0035 Unity Mixamo 몸 제거 — 씬 빌더 참조 정리 뒤 `mixamo_purge`(U-0034 다음)
종류: 새기능 · 유니티      상태: **작성됨**(R-0 2026-10-04) — 시작 조건: U-0034 끝(사람 42자리가 VRoid 로 읽힘)      등급 목표: D1

**목표(한 줄)**: U-0034 로 사람 몸이 VRoid 가 된 뒤, 사용자 지시(2026-10-02 "Mixamo 제거")대로 Unity `Assets/Art/CharactersRealistic`(Mixamo, 약 4.2GB)를 옮겨 낸다. 지금은 Editor 씬 빌더 12개 파일이 이 경로를 참조해 먼저 지우면 Unity 몸이 전부 사라진다.

**파일(확인함)**: `saga-unity/Assets/Editor/*.cs`(`grep -ln "CharactersRealistic"` 로 참조 12개 확인) · `tools/char-forge/mixamo_purge.py`(`--group unity --yes`, 옮기기만·`--restore` 복원) · `tools/char-forge/data/unity_bodies.json` · 사람 아닌 19자리가 `_cmp_real_*` FBX 를 쓰면 그것은 지우지 않는다.

**단계**
1. `grep` 으로 `CharactersRealistic`·Mixamo 이름 참조 전부 표(파일·줄). 사람 자리 참조는 U-0034 가 바꿨는지, 사람 아닌 자리 참조는 남기는지 가른다.
2. 남기는 참조 말고 옛 참조를 새 몸 경로로 바꾸거나 없앤다(컴파일 오류 0).
3. 빌드 씬 여섯을 `SagaRebuildScenes` 없이 열어 누락 몸 0(진단). 없는 PC 는 `realistic-pack.sh verify` 먼저.
4. 통과하면 `py tools/char-forge/mixamo_purge.py --group unity --yes`(복원 가능). 몸이 전부 보이는지 PlaytestHeadless 한 번.

**검증**
```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath saga-unity -logFile <로그> -executeMethod Saga.EditorTools.<새 진단>.Run   → [..] OK, 컴파일 오류 0
기존 관련 Playtest 같은 값 · bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 옮긴 뒤 PlaytestHeadless OK · `--restore` 로 되돌릴 수 있음을 메모.

**불변 규칙**: 복구 불가 삭제 금지(옮기기만) · 에셋(GLB·그림·`.meta`)은 만들거나 고치지 않는다(K 갈래·K-0019 몫) · 세이브 키·id 불변 · 이름 정책 · 다른 세션이 엔진을 쓰는 중이면 먼저 확인.
