# U-0023 첫 10분 사명 — FOREST (U-0013·U-0020 의 넷째 판)
종류: 새기능(P0)      판: FOREST      등급 목표: D1(Playtest)      상태: 작성됨(R-0)

**목표(한 줄)**: 새 FOREST 세이브의 목표판 첫 줄(`ForestSessionTracker.GoalLineNow`)에 사명 5개가 차례로 뜨고, 다 하면 평소 줄로 돌아간다. 세이브 `tutDone`. 옛 세이브는 전부 끝난 것으로 본다. (BACKLOG §1 P0-1 — GO·DUNGEON U-0013, STORY U-0020 다음. REALM 은 그다음 티켓.)

**확인한 사실(R-0)**: `SagaCore/TutorialSteps.cs` 재사용, 본보기 `Games/SagaStory/Data/StoryTutorial.cs`(U-0020, 걷기 판정 포함). `ForestSessionTracker.GoalLineNow()` 는 101행, 첫 줄에 시나리오·택배가 먼저라 **그 앞**에 튜토리얼을 둔다. 판정 API: 걷기=플레이어 위치(`FindWithTag("Player")`) · 존 `ForestZoneTracker.Instance.CurrentZone>=0`(−1 이 마을, `ForestBiomeData.ZoneAt`) · 채집 `ForestMuseumState.DiscoveredCountOf(category)` 합 ≥1(`Items` 키가 카테고리) · 택배 `ForestDeliveryState.DeliveredCount>=1` · 저장 `SagaFlow.LastAutoSaveReason!=null`(ForestBootstrap 26행이 `SagaFlow.Enter("forest", ForestSaveState.Save)`). 세이브 `ForestSaveState.SaveVersion=9`(16행) — 새 칸은 "버전 그대로" 관례(`scenarioJson`·`mountSel`). **함정(U-0020)**: `JsonUtility` 는 없는 `List` 를 null 이 아닌 빈 목록으로 읽는다 → 옛 세이브 구분은 `public int tutV`(0=없음)로.

**파일**: `Games/SagaForest/Data/ForestTutorial.cs`(새) · `Games/SagaForest/UI/ForestSessionTracker.cs`(`GoalLineNow` 머리 3줄) · `Games/SagaForest/Data/ForestSaveState.cs` · `Assets/Editor/PlaytestTutorial.cs`(FOREST 줄·표 5개 검사) · `Assets/Editor/PlaytestForestHeadless.cs`(80행 옆에 `ForestTutorial.Enabled=false`)

**본보기**: `StoryTutorial.cs`·U-0020 의 `StorySaveState`(`tutV`·`tutDone`)·`PlaytestTutorial.CheckStorySave`.

**단계**
1. `ForestTutorial.cs`: `Steps` = ① walk(시작 자리에서 30m) ② zone(마을 밖 존에 들어서기) ③ gather(도감 아이템 하나 모으기) ④ deliver(택배 한 건) ⑤ save. Ko/En 한 줄씩(이름 정책: 실명 없음). `Enabled`·`Line`·`Ids`·`AllIds`·`Restore`.
2. `GoalLineNow()` 머리: `var tut = ForestTutorial.Line(); if (tut != null) return tut;`(`_player==null` 검사보다 앞).
3. 세이브: `public int tutV; public List<string> tutDone;` — 저장 `tutV=1; tutDone=ForestTutorial.Ids()`, 로드 `ForestTutorial.Restore(data.tutV==0 ? AllIds() : data.tutDone)`. 버전은 안 올린다.
4. `PlaytestTutorial` 에 FOREST 추가(`CheckStorySave` 복제: `"tutV":1` 있음·새 게임 줄 있음·`,"tutV":1` 제거한 옛 세이브는 줄 없음·되돌리면 다시 줄) + `CheckIds("FOREST", …)`. 포리스트 Headless 는 시작 때 `Enabled=false`.
