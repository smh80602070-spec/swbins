# U-0252 5천하 진영 — 장비·상점·대화·전투 전 사건
종류: 게임성·배선 · 유니티(5천하)      상태: 작성됨(R-0 2026-10-27; U-0250·0251 완료 후 실행)      등급 목표: D2

**목표**: W-0450의 진영 네 탭(편성·장비·상점·대화), 전투 앞 설전/일기토를 유니티 장 흐름에 연결. 수신함 10-25 장비 다양화의 5천하 몫도 여기로 연결한다.
**R-0 조사(2026-10-27)**:
- 기존 Unity 소지품 체계는 도시 경영판의 `RealmMounts`뿐(말 한 필/장수, 소유·잠금·장착·세이브 API). 캠페인 장비 가방·상점은 없다. `RealmCityState.TrySpendGold/AddGold`는 쓸 수 있지만, 장 흐름의 별도 골드는 U-0250 `RealmCampaign` 전용 잔액 API를 사용한다.
- `RealmOfficer`에는 무력·지력·통솔·등급이 있고 전용 기술은 없다. 장비는 새 순수 C# 데이터 표로 구현 가능하며 에셋 요청 불필요. 웹 정본 `tasks/web/done/W-0453.md`: 슬롯 3(무기·방어구·장신구) × 종류 4 × 등급 5 = 60종, 효과는 공격·피해 감소·체력·명중·치명·이동. 자기 장수에만 적용하고, 기존 보물은 별도 네 번째 슬롯로 보존한다. 웹의 처음 가방(낡은 검·가죽 갑옷), 장별 상점 해금·구매가·전투 보상 수치는 U-0252 구현 때 `saga-web/saga-realm/js/realm-gear.js`와 `campaign.js`에서 실제 숫자를 확인해 옮긴다. 파일/표 이름은 `Data/RealmCampaignGear.cs`로 한다.
- `RealmTactics`는 이미 SRPG 설전·일기토 명령과 결과를 제공한다(`Debate`, `Duel`, `DuelChance`, `CmdOut`). `RealmDebateState`는 기존 등용 전용이라 재사용하거나 학당 상태를 바꾸지 않는다. W-0450의 장 전 사건은 설전 3·6·14장, 일기토 9·12장; 성공 시 적 병력 ×0.85/×0.80, 실패 시 보정 없음. 장수 영입은 원작 인물 ID/실명을 새로 쓰지 않고 기존 풀의 실제 ID만 사용한다.
- `RealmSupport`는 저장되는 지원 단계·전투 보정·장수별 관계 줄을 이미 제공하므로 대화 탭에서 편성 쌍의 지원 단계와 상승 가능한 진행을 노출한다. 지원 수치 증가는 기존 `OnBattleEnd` 규칙을 따른다.
- 세이브는 `RealmSaveState` v4이며 필드 추가는 버전 상승 없이 nullable JSON 필드로 하위 호환한다. U-0250의 캠페인 저장 객체에 gear/gold/party 상태를 함께 기록하고, 기존 도시 운영 save 필드는 그대로 유지한다.
