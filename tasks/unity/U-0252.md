# U-0252 5천하 진영 — 장비·상점·대화·전투 전 사건
종류: 게임성·배선 · 유니티(5천하)      상태: 초안(U-0251 및 물품 체계 조사 후 R-0)

**목표**: W-0450의 진영 네 탭(편성·장비·상점·대화), 전투 앞 설전/일기토를 유니티 장 흐름에 연결. 수신함 10-25 장비 다양화의 5천하 몫도 여기로 연결한다.
**확인된 파일**: `Assets/Games/SagaRealm/Data/RealmOfficer.cs`·`RealmOfficerPool.cs`·`RealmScenario.cs`, U-0250·0251에서 만들 `RealmCampaign.cs`·`RealmCampaignUi.cs`.
**선행 조사**: 유니티의 보물·가방·구매 API 유무와 설전/일기토 결과 API를 심볼로 확인한다. 웹 11종을 그대로 복사할 수 있는지, 표 생성 요청이 필요한지 판정한다. 기존에 없는 물품 체계를 있다고 가정하지 않는다.
**단계(설계)**: 편성 셋→장비 착탈/가방→잔액 검사 구매→장수 대화→전투 전 사건 결과를 이번 장 보정으로 연결. 수치·가격은 W-0450 실제 코드 또는 기존 유니티 표에서 인용 후 확정.
**검증 계획**: 실제 탭 버튼→착탈 능력 반영·중복 구매/잔액 부족 거절·저장 왕복·전투 전 사건 보정 1회→출진 진단. 실행 가능한 메서드·명령·촬영 대상을 R-0에서 확정한다.
**완료 조건**: R-0에서 파일·수치·검증 명령을 확정해 작성됨으로 전환 후 별도 실행. 현재 초안은 실행하지 않는다.
**불변**: 세이브·id 보존·실명 금지·새 에셋은 K 요청·플레이어 빌드 없음.
