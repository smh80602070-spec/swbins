2. `Revive()`(≈1062)가 `ClearReactionStates()`·`_knock` 을 안 비운다. `TakeHit`(Damage.cs ≈140)의 불붙음·감전·가속 분기는 `ApplyDamage` 가 죽인 뒤에도 상태를 다시 세워(`Freeze` 만 `Alive` 가드) 90초 뒤 부활한 적이 안 받은 틱을 맞는다. `Return` 도착(Tick)도 `ResetShields()` 만 하고 반응 상태를 안 비운다.

**리뷰어 주장 — 아직 안 읽어 봄(R-0 에서 확인)**
3. 비활성(SetActive false) 적은 `_all` 에서 빠져 `RescaleAll` 을 놓치고 `OnEnable` 에서 월드 레벨을 다시 안 먹는다(FrostWild·서리왕·쓰러진 수호자).
4. `_siegeStrike` 는 `ResolveStrike` 에서만 해제 — 얼음·방패 깨짐·`ForceReturn`·사망으로 전조가 끊기면 남아 다음 전조가 제단만 친다.
5. `Freeze()` 가 경고 고리는 끄지만 `_alertText` "!" 는 켜 둠(`Chase→Return` 에서도 안 숨김).
6. 과부하(Overload) 루프가 `other._knock` 을 직접 써 `CanBeKnocked`(수호자·주간/이야기 두목 거절)를 우회하고, 사망 뒤에도 값을 남겨 부활 첫 프레임에 밀린다.
7. `DomainFoe` 가 `playerOk == false` 로 Chase 에 있으면 포기 분기를 건너뛰고 `fc.transform`(null 이면 NRE)으로 걷는다(≈808).
8. 성능: `Grounded()` 의 `Physics.RaycastAll`(→NonAlloc)·`RefreshHeadUi` 문자열 매 Tick·AoE 의 `_all.ToArray()`·고리의 `_warnRing.material`(→sharedMaterial)·`_bubbleMat`/`_orbMat` 파괴 안 함.
9. `Die()`/`Yield()` 정리 블록 중복, `MeasureLength`/`MeasureHeight` 중복(정리 — 우선순위 낮음).
