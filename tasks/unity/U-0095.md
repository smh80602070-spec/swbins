# U-0095 3마을 제작대 — 채집 손 승급 + 승급마다 3택(빠른 손·넉넉한 손·눈 밝은 손) (웹 리뉴얼 ③ W-0103 이식)
종류: 새기능(이식) · 유니티(FOREST)      상태: 작성됨(R-0 10-11 — 수신함 10-11 "웹 리뉴얼 반영 검토" · 사용자 "묻지말고 최대한 해봐")      등급 목표: un.fs.craft 새 D2

**목표(한 줄)**: "사면 끝"인 판에 성장 선택을 — 집 앞 **제작대**에서 열매로 **채집 손**을 Lv.1→4 로 승급하고, 승급마다 서로 다른 축 셋 중 하나를 고른다(재미표준 D). 거절하면 열매 소량 돌려받고 다음 승급 때 다시.

**근거(R-0 이 확인한 것)**
- 웹 W-0103 은 잠자리채·삽 도구 승급 + 가구·공사 자재 짓기. **이 트랙엔 도구가 아예 없다**(채집은 다가가면 자동 — `World/ForestCollectSpot.cs`(쿨 2초 `GatherCooldownSec`, 존 어휘 중 무작위 `pool[_rng.Next]` → `ForestMuseumState.Record`)·`World/ForestFruitTree.cs`(쿨 2초, 열매 1 × 축제 배율)). 재화는 열매 하나(`Data/ForestState.FruitCount`·`SpendFruit`).
- 그래서 도구 대신 **채집 손** 하나를 승급한다(웹 바꾼 점 ①과 같은 결 — "1회 시간 칸이 없어 속도 축 = 손이 빨라짐"). 축 셋: **빠른 손**(두 채집 쿨 ×0.8) / **넉넉한 손**(열매 나무 +1 확률 30%) / **눈 밝은 손**(채집 자리에서 도감에 없는 것이 나올 확률 ×1.5 — 이 트랙엔 희귀 등급이 없어 "새 것"이 희귀 자리). 같은 축 한 장에 둘 금지(셋뿐이라 늘 셋 다), 같은 축을 두 번 고르면 곱으로 쌓임(상한: 쿨 ×0.6·+1 확률 60%·새 것 ×2).
- 가구 짓기는 이 트랙 가구 가게(`World/ForestFurnitureStall.cs`, 열매로 삼)가 이미 같은 일을 해 **뺀다** — 웹의 "공사 자재"도 이 트랙 공사 체계가 없어 뺀다(제작대는 승급 하나).
- 세이브 v9(`Data/ForestSaveState.cs:17`) — `handLv`·`handPerks`(정수 배열) 두 칸, 버전 그대로(없으면 Lv.1·없음 — 다른 칸들이 써 온 관례).
- 제작대 소품: 에셋 0 — 기존 가구 모델(`Data/ForestFurnitureModels`) 중 탁자류를 집 앞 고정 자리에(없으면 상자 대역 + 이름표). 곁에서 F(또는 단추) → 제작대 창.
