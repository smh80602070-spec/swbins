# U-0123 2나락 `PlayerController.HeightAboveGround` 발밑 레이가 제 CharacterController 를 맞히지 않게 (U-0122 선행)
종류: 버그 · 유니티(DUNGEON)      상태: 진행중 · 작성(R-0 10-13)      등급 목표: 등급 변화 없음 — 2나락 진단 OK 수 그대로(54)

**목표(한 줄)**: 2나락 발밑 높이 레이(마스크 `~0`)가 플레이어 자신의 `CharacterController` 에 걸리면 높이가 ~0 으로 나와 탈것 오름·활공·땅 판정이 틀린다. 레이 결과에서 자기 몸(제 트랜스폼 아래 충돌체)을 빼고 가장 가까운 남의 충돌체로 높이를 잰다. U-0122(85곳 `Colliders.Strip`)가 이것 때문에 2나락 mount FAIL 로 멈췄다.

**근거(R-0 10-13)** — 경로 머리 `saga-unity/Assets/Games/SagaDungeon/Player/PlayerController.cs`
- 153~159행 `HeightAboveGround()`: `Physics.Raycast(transform.position + up*0.3, down, 100f, ~0, Ignore)` 첫 맞음 그대로 → 제 CC 를 맞힐 수 있다. 부르는 곳 150·396·552행 + `Editor/PlaytestDungeonMount.cs` 232행(`Alt`).
- U-0122 메모 탐침: autoSyncTransforms 꺼짐이라 CC 의 물리 자세가 옛 자리(땅)에 남아 있을 때, 몸은 2.08m 위인데 레이가 CC 를 맞혀 높이 ~0 → `mount FAIL 용 0.4초 오름 0.36m`.
- 같은 파일 616행 `ProbeWall`·666행 꼭대기 스캔도 `~0` 이다 — 이 티켓에선 **건드리지 않는다**(벽 쪽은 1만리 524행처럼 이미 `CharacterController` 를 거르는지 확인만 하고 메모).
- 1만리·3마을 `PlayerController.HeightAboveGround` 도 같은 꼴이지만 진단이 지나므로 손대지 않는다(후속 후보로 큐 머리말에만).

**파일**
- `saga-unity/Assets/Games/SagaDungeon/Player/PlayerController.cs` 하나:

  - 주석 한 줄: 왜 자기 몸을 빼는지(U-0122·이 티켓).
