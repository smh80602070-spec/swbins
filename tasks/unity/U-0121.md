# U-0121 1만리 동료 교체 뒤 무기 빛이 꺼짐 — `ApplyLook` 의 `ClearTint`(빈 블록)가 `ApplyGlow` 를 덮는 순서 고치기 (U-0120 후속 후보)
종류: 버그(그래픽) · 유니티(GO)      상태: 작성됨 · 작성(R-0 10-13)      등급 목표: `un.go.track` D2 유지 — note 에 교체 뒤 무기 빛 유지

**목표(한 줄)**: U-0120 으로 무기 빛(강화 단계 1~11 의 금빛 외곽선·림)이 보이게 됐다. 그런데 들판에서 동료를 바꾸면 빛이 사라질 수 있다. 교체·되돌림 뒤에도 장착 무기의 빛 단계가 그대로 보이게 한다.

**근거(R-0 코드 읽기, 10-13 — 화면으로는 아직 확인 안 함)** — 경로 머리 `saga-unity/Assets/`
- `Games/SagaGo/Combat/FieldCombat.cs` 1006~1015행 `ApplyLook` 이 일어나는 순서:
  1. 먼저 `_bodies.Show(Active.Id, motion)` 을 부른다.
  2. 그 안에서(`Player/PartyBodies.cs` 214행 `Shown?.Invoke`) `WeaponVisual.OnShown` → `RefreshModel` → `ApplyGlow` 가 돈다. 무기 렌더러에 MaterialPropertyBlock(외곽선 두께·색·림)이 칠해진다.
  3. 그다음 `ActiveIndex == 0 || ownBody` 이면 `CharacterVisual.ClearTint(player.Visual.gameObject)` 를 부른다.
- `Games/SagaDungeon/World/CharacterVisual.cs` 72~79행 `ClearTint` 는 `player.Visual` 아래 모든 렌더러에 빈 블록을 넣는다. 무기 소켓도 `player.Visual` 아래다(`WeaponVisual.cs` 99·143행 `FindOrCreateWeaponSocket`). 그래서 3이 2를 덮어 빛이 꺼질 것으로 추정한다.
- `Tint`(61~70행)는 `GetPropertyBlock` 뒤 `_BaseColor` 만 더하므로 빛은 남는다(무기도 원소 색으로 옅게 물듦 — 지금 결과 그대로 둠).
- 같은 함수를 쓰는 다른 판(2나락 `PlayerController` 302행 회피 무적 틴트 등)에는 무기 빛이 없다(`ApplyGlow` 는 GO 만).

**파일**
- `Games/SagaGo/Player/WeaponVisual.cs`: `ApplyGlow` 를 밖에서 다시 부를 수 있게 공개 `ReapplyGlow()` 한 줄을 둔다(이름은 자유, 몸·모델은 다시 만들지 않음).
- `Games/SagaGo/Combat/FieldCombat.cs` `ApplyLook`: 틴트·지우기 바로 뒤에 그 무기의 빛을 다시 칠한다. `WeaponVisual` 은 `player` 에서 `GetComponent` 로 찾고, 없으면 넘어간다.
  - `CharacterVisual.ClearTint` 자체는 바꾸지 않는다(다섯 판 공용·적 틴트가 빈 블록에 기댐).
- `Editor/PlaytestShowcaseGui.Seq.cs`: `weaponglow:<n>` 뒤에 `swap` 을 두 번(다음 동료 → 다시 주인공) 이어 쓸 수 있으면 그대로 쓰고, 막히면 그 순서를 지원하게만 고친다.
  - 장마다 `weaponglow` 로그 한 줄(tier·outlineW)이 다시 찍히게 해서, 교체 뒤 외곽선 두께가 0 이 아닌지 숫자로 본다.
- 결과 `saga-unity/docs/playcheck/d2-u0121-20261013.json`·`features.json` `un.go.track` note.

**단계**
1. 고치기 전에 한 판 찍는다: 1만리 `TestVillage`, `SAGA_SHOT_ACT=weaponglow:11+swap+swap`.
   - 공통 `SAGA_SHOT_HOUR=12 SAGA_SHOT_TARGETS=gamecam;screen SAGA_SHOT_SEQ=4,30`, 동료 편성은 `party` 동작 등 `done/U-0120.md` 메모대로.
