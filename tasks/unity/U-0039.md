# U-0039 Unity 건물 실내 방 연결 — K-0026 실내 방(`int_*` 12종)으로 "들어가기"(작게 시작)
종류: 새기능 · 유니티      상태: **B 구현 끝(10-05, 화면 확인 OK) · 실제 걸어 들어가기만 사용자 눈**(설계 B 승인 2026-10-05) — 시작 조건: 없음(GLB 이미 `Resources/World/int_*`)      등급 목표: D1

**목표(한 줄)**: 자체툴이 건물마다 들어갈 수 있는 방(`int_hanok_01`·`int_inn_01`·`int_forest_cottage_01` 등 12종)을 올렸다. 유니티 건물은 겉만 있다. 사가고 마을 건물 하나에서 문으로 들어가면 방이 보이는 한 판을 먼저 만든다(나머지 판은 같은 방식으로 후속).

**파일(확인함)**: `saga-unity/Assets/Editor/BuildTestVillageScene.cs`(마을 건물 자리) · 입구 `Games/SagaGo/World/*`(문·상호작용 선례 `ForestHouse` 의 `IndoorRoom` 은 `Games/SagaForest/World/ForestHouse.cs`) · `Resources/World/int_*.glb`(12) · 재질 `FromGltf`.

**단계**
1. 입장 방식 결정: 숲 `ForestHouse.IndoorRoom`(밖 상호작용 → 실내 방으로 이동) 선례를 따를지 GO 에 맞게 단순화할지 표로 비교하고 추천 하나로 정한다(질문하지 말고 선례를 따른다).
2. GO 마을 건물 하나: 문 앞에서 상호작용 → 방 GLB 안으로 옮기고 나오면 복귀.
3. 진단: 방 GLB 읽힘·입구/출구 위치 규칙, GUI 촬영 한 장.

**검증**
```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath saga-unity -logFile <로그> -executeMethod Saga.EditorTools.<새 진단>.Run   → [..] OK, 컴파일 오류 0
기존 관련 Playtest 같은 값 · bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~3 · 한 건물에서 들어갔다 나온다 · 나머지 건물·판은 후속 티켓 메모.

**불변 규칙**: 에셋(GLB·그림·`.meta`)은 만들거나 고치지 않는다(K 갈래·K-0019 몫) · 세이브 키·id 불변 · 이름 정책 · 다른 세션이 엔진을 쓰는 중이면 먼저 확인.

**메모(착수 전 점검, 2026-10-04)**: 숲 집 `IndoorRoom` 은 `ForestHouse.BuildIndoorRoom` 이 **도형 방**(바닥 큐브+벽 셋)을 짓고, 벽 색·바닥 마감 상점(`ForestHomeState.CurrentWall·CurrentFloor`, `WallFinishColors`)이 이름 `Wall` 자식을 칠하고 가구 격자 18칸(`CellToLocal`)이 그 방 크기에 묶여 있다 — `int_forest_cottage_01` 로 방 껍데기를 통째로 바꾸면 마감 상점·가구 놓기가 깨진다. GO 마을 건물은 문·입장 동작이 아예 없다(새 상호작용). 그래서 "선례를 따라 단순 교체"로는 안 되고 설계가 먼저다. **결정 필요**: (A) 숲 집은 그대로 두고, 방 GLB 를 **껍데기 장식 레이어**로만 얹기(벽 색·격자는 도형 방이 계속 맡고 GLB 는 시각 덧씌움 — 겹침·크기 맞춤 시험이 필요), (B) GO 마을 건물 한 곳에 **새 입장 동작**(문 앞 상호작용 → 방 GLB 로 이동 → 나오면 복귀)을 만들기 — 카메라·충돌·조명·저장 위치까지 걸리는 중형 기능이라 별도 PLAN 한 절이 먼저, (C) 보류. 추천 B 를 PLAN 절부터(코드 전에 사용자 확인).

**설계안 B(승인 2026-10-05)**: 숲 `ForestHouse` 포켓 공간 선례를 GO 에 맞춰 줄임 — 문 앞 근접 입장·방 안 출구 근접 퇴장·자동 복귀 안전장치·방 안 저장은 밖 복귀 자리로 치환. 위험이던 카메라·세이브는 아래 실행 메모대로 풀었다.

**실행 메모(2026-10-05)**: 설계 B 그대로 — 새 `Games/SagaGo/World/GoHouseInterior.cs`(`GameBootstrap.Start` 가 `Install`, 씬 재빌드 없이): `House_2` 몸통 `Wall` 박스 남쪽 면 가운데 = 문(`DoorOutdoor`), 방 `World/int_hanok_01` 을 마을 +(0,0,1000) 포켓에 ×2 로 세움(K-0026 빈 노드 `door_out`·`spawn_in`·`light_*` 사용, `FromGltf` 툰), 충돌체는 GLB 에 없어 바닥 박스+벽 박스 넷(천장 안 닫음 — 카메라가 위에서 내려다봄). 문 앞 1.8m 안 → 입장(`PlayerController.Teleport`), 방 안 문 1.2m 안 → 퇴장, 쿨다운 1.5초(튕김 방지: 들어온 자리는 출구에서 ≥2.6m·나온 자리는 문에서 4.5m), 방에서 떨어지거나 60m 밖이면 자동 복귀. **저장**: `SaveState` 가 방 안이면 밖 복귀 자리(`GoHouseInterior.SavePosition`)를 써서 불러와도 포켓에 안 떨어진다. 진단 `PlaytestGoHouseInterior`(`PlaytestHeadless` 가 부름) → `house interior OK - 방 12.8×10.8×6.5m·점광 2·포켓 마을 격자 밖·순간이동 왕복·방 안 저장 치환`. 화면(`PlaytestShowcaseGui` 에 `house` 모드 추가): 한옥식 실내(나무 마루·들보·창·종이빛 벽)에 플레이어가 서고, 실제 게임 카메라는 위에서 내려다봐 벽에 안 막힌다. **남은 것**: 실제로 걸어서 문 앞에 가면 들어가지는지(자동 입장 반경 1.8m)·나오는지 사용자 눈 / 나머지 건물·판(같은 방식, 방 12종 중 건물마다) / 방 안 소품·가구 배치(2b 실내 물건 세트)는 후속.
