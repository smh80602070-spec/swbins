# 유니티 갈래 큐 — "사가유니티 이어해"

경로: `saga-unity/`. 배치 실행은 항상 `bash tools/unity-batch.sh -- …`(설정 4파일 원복). 사실 몸 묶음 없는 PC 면 `realistic-pack.sh verify` 먼저, 없으면 `SagaRebuildScenes` 금지.

**에셋(그림·소리·모델·`.import`·`.meta`·출처 문서)은 이 갈래가 만들거나 고치지 않는다 — 자체툴(K) 갈래 몫**(사용자 2026-10-01). 이 갈래는 코드 배선만, 에셋이 필요하면 K 티켓(K-0019 배치)을 기다린다.

| 순서 | 티켓 | 종류 | 상태 |
|---|---|---|---|
| 1 | [U-0022](U-0022.md) Unity 를 Godot 과 같은 툰 노선으로 — 셰이더·재질 규칙(코드만) | 새기능 | 진행중 · 단계 1~2 끝, 사용자 판정 대기(HOW_TO §20) |
| 2 | [U-0023](U-0023.md) Unity 사가고 마을을 마을 배치표로 짠다(코드만) | 새기능 | 진행중 · 코드 끝(PlaytestRegions OK), 시안 대조(사용자 눈) 대기 — HOW_TO §21 |
| 3 | [U-0027](U-0027.md) REALM 시나리오 단계(2) — 설전 셋·일기토 둘(앞 단 UI 콜백) | 새기능(이식) | 진행중 · 단계 1 시작 (뒤로 U-0028 이계 군주 열전) |
