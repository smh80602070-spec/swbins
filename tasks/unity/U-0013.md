# U-0013 첫 10분 사명 (GO·DUNGEON)
종류: 새기능(P0)      판: GO 먼저 → DUNGEON      등급 목표: D1(Playtest)

**목표(한 줄)**: 새 세이브의 목표판(`GoalBoard`) **첫 줄**(`GoalLineNow`)에 사명 5개가 차례로 뜨고, 다 하면 평소 줄로 돌아간다. 세이브 `tutDone`. 옛 세이브는 전부 끝난 것으로 본다. W-0015(웹)·G-0012(고돗)와 같은 결.

**확인한 사실(R-0)**: `IGoalSource.GoalLineNow()` 는 `GoSessionTracker`(131행)·`DungeonSessionTracker`(106행)가 구현, 보드가 주기로 부른다 → 폴링 판정이면 별도 컴포넌트·이벤트가 필요 없다. 판정에 쓸 기존 API — GO: `PartyState.MemberIds`(등용 수) · `GoTreasure.Chests`+`WorldEventState.IsTriggered(GoTreasure.EventKey(c))`(상자) · `AchieveState.Stat("react")`(원소 반응) · `SagaFlow.LastAutoSaveReason`(저장). DUNGEON: `HeroState.Exp/Level`(첫 처치·레벨 2) · `QuestState.Current`(첫 사명 단계 넘김) · `SagaFlow.LastAutoSaveReason`. 걷기는 새 계산 — 플레이어(`FindWithTag("Player")`)가 첫 호출 자리에서 30m 떨어짐. 세이브: GO `SaveVersion` 28·`MigrateStep` 있음(`SaveMigrator`), DUNGEON 14·`data.version >= N ?` 조건부 읽기. 기존 진단이 `GoalLineNow` 를 검사하므로 튜토리얼이 켜져 있으면 깨진다 → `Enabled` 끄기 필요(`DungeonScenario.Enabled` 본보기).

**파일**: `Assets/SagaCore/TutorialSteps.cs`(새) · `Games/SagaGo/Data/GoTutorial.cs`·`SagaDungeon/Data/DungeonTutorial.cs`(새) · `SagaGo/UI/GoSessionTracker.cs`·`SagaDungeon/UI/DungeonSessionTracker.cs`(`GoalLineNow` 머리 3줄) · `SagaGo/Data/SaveState.cs`·`SagaDungeon/Data/SaveState.cs` · `Assets/Editor/PlaytestTutorial.cs`(새) · `PlaytestHeadless.cs`·`PlaytestDungeonHeadless.cs`(1줄: `Enabled=false`)

**본보기**: `Games/SagaDungeon/Data/DungeonScenario.cs`(`Enabled`·세이브 칸) · `SaveMigrator`(U-0005)

**단계**
1. `TutorialSteps`(Saga.Core): 단계 `{Id, Text(ko/en), Func<bool> Done}` 목록 + `HashSet<string> done` · `string Line()`(지금 단계 문구 `"첫걸음 n/5: …"`, 끝났거나 `Enabled==false` 면 null · 호출 때 현재 단계 `Done()` 이 참이면 완료 처리하고 다음 단계로) · `Restore(ids)`·`Ids`(저장용)·`CompleteAll()`.
2. GO: 단계 5 = 걷기·등용(`MemberIds.Count>=1`)·상자·원소 반응(`Stat("react")>=1`)·저장. `GoalLineNow` 머리에 `var t = GoTutorial.Line(); if (t != null) return t;`. 세이브 `tutDone`(List) · `SaveVersion` 29 · `MigrateStep(28)` 이 `CompleteAll` 한 목록을 채움. DUNGEON: 단계 5 = 걷기·첫 처치(`Exp>0||Level>1`)·레벨 2·사명 한 단계(`QuestState.Current` 가 처음과 다름)·저장, `SaveVersion` 15 · `data.version >= 15 ? data.tutDone : 전부`.
3. `Enabled` 정적 필드(기본 true). 두 Headless 첫 프레임에 `GoTutorial.Enabled=false`(Dungeon 도).
4. `PlaytestTutorial.Run`(PlaytestKit·세이브 격리): ① `TutorialSteps` 가짜 `Done` 으로 순서·완료·`Enabled=false`·Restore 왕복 ② GO·DUNGEON 단계 id 가 다섯·중복 0 ③ GO `ApplyJson`(현재 `ToJson` 의 `"version":29`→`28`)이면 `Line()==null`, 새 게임 기본값이면 `Line()!=null` ④ DUNGEON 도 같게(`15`→`14`).

**검증**
```
배치 컴파일 error CS 0 · PlaytestTutorial OK · PlaytestSaveMigration OK(GO v29 fixture 갱신)
PlaytestHeadless(GO)·PlaytestDungeonHeadless OK(목표판 진단 포함)
```

**완료 조건**: 위 · 옛 세이브 `Line()==null` · 실제 세이브 md5 전후 동일.

**불변 규칙 확인**: 전투·이동 판정 0 변경 · 세이브 키·파일 이름 불변(칸 추가만) · 다른 세션이 Unity 를 쓰는 중이면 미룬다.
