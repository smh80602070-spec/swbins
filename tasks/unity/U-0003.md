# U-0003 5곳 동일 복제 → SagaCore(`PlatformVolumeProfile`·`DebugHud`)
종류: 통합      판: 다섯      등급 목표: (체제) — 복제 23 중 첫 둘, GUID 재매핑 도구 포함

**목표(한 줄)**: 다섯 판에 똑같이 있는 `PlatformVolumeProfile.cs`(27줄)·`DebugHud.cs` 를 `Assets/SagaCore/` 하나로 옮기고, 씬·프리팹이 가리키던 옛 스크립트 GUID 를 새 GUID 로 바꾸는 `tools/remap-guid.mjs` 를 만든다(뒤 복제 이관이 전부 이 도구를 쓴다).

**파일**: `saga-unity/Assets/SagaCore/PlatformVolumeProfile.cs`·`DebugHud.cs`(+`.meta`, `git mv` 로 GO 사본에서) · 나머지 4판 사본 8파일 삭제(+`.meta`) · `saga-unity/tools/remap-guid.mjs`(새) · 참조하는 `.unity`·`.prefab`

**본보기**: 없음(새 도구). `.meta` 의 `guid:` 와 씬의 `m_Script: {fileID: 11500000, guid: <32hex>, type: 3}` 꼴.

**단계**
1. `diff` 로 다섯 사본이 정말 같은지(`DebugHud` 는 62~79줄로 차이 있음 — 차이가 판 이름 문자열뿐이면 `[SerializeField] string label` 로 뺀다, 로직 차이면 이 티켓은 `PlatformVolumeProfile` 만 하고 DebugHud 는 메모).
2. `git mv Assets/Games/SagaGo/World/PlatformVolumeProfile.cs{,.meta} Assets/SagaCore/` → namespace `Saga.Core` 로, 판 코드의 `using` 은 이미 `Saga.Core` 를 쓰는지 grep.
3. `remap-guid.mjs <old.meta들> <new.meta>`: 옛 `.meta` 들의 guid 를 읽어 `Assets/**/*.{unity,prefab,asset}` 에서 `guid: <old>` → `guid: <new>` 치환(바이너리 모드, 바뀐 파일 수 출력). 그 뒤 옛 `.cs`+`.meta` 삭제. `--check` 는 옛 guid 잔존 0 확인.
4. 배치 컴파일 `error CS` 0 → `ButtonWiringCheck`(씬 전체 Missing Script 도 잡는지 `grep -n "Missing" Assets/Editor/ButtonWiringCheck.cs`) → 판별 Playtest 짧은 것 하나.
5. 씬 재빌드(`SagaRebuildScenes`)는 **하지 않는다**(사실 몸 묶음 없는 PC 규칙). 클래스 하나 끝날 때마다 커밋.

**검증**
```
node saga-unity/tools/remap-guid.mjs --check   → 옛 guid 가 Assets 에 0건
(배치 컴파일) grep -c "error CS" → 0 · ButtonWiringCheck OK · (Playtest 하나) OK
```

**완료 조건**: 위 · 도구 설명 5줄을 `saga-unity/docs/HOW_TO_PLAYTEST.md` 끝에.

**불변 규칙 확인**: `.meta` 를 `git mv` 로 옮겨 GUID 하나는 유지 · `*.playable` 은 안 건드림 · 설정 4파일 원복 · 다른 세션이 Unity 를 쓰는 중이면 미룬다.
