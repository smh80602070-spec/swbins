# U-0033 사가의숲 집 가구를 K-0026 실내 물건 3D 로 — 도형(원기둥·상자) 자리 교체(코드만)
종류: 새기능 · 유니티      판: FOREST      상태: **완료**(R-0·실행 2026-10-04)      등급 목표: D1

**목표(한 줄)**: 유니티 사가의숲 집 꾸미기(`ForestFurniturePlacer.SpawnVisual`)는 가구를 원기둥·상자 도형으로 그린다(`IsCylinder`, "실제 GLB 없음"). 자체툴 K-0026 이 `Resources/World` 에 올린 실내 물건 GLB(탁자·방석·등잔·화로·병풍 등 40종)를 가구 id 에 맞춰 보이고, 맞는 모델이 없는 id 는 지금 도형 그대로 둔다.

**파일(확인함)**: `saga-unity/Assets/Games/SagaForest/World/ForestFurniturePlacer.cs`(`SpawnVisual`) · 새 `Data/ForestFurnitureModels.cs`(id → `World/<이름>` 표) · 재질 규칙 `SagaCore/Region/RegionMaterials.FromGltf`(툰) · 읽는 `Data/ForestHomeData.cs`(`FurnitureItem` 14+잔치 손님 가구) · 새 진단 `Editor/PlaytestForestFurnitureModels.cs`. 모델 GLB·`.meta` 는 K-0019 가 이미 놓았다(`Resources/World/*_01.glb`) — 이 티켓은 안 놓는다.

**단계**
1. 표: 가구 id ↔ 실내 물건 이름(뜻이 맞는 것만. 족자·거문고·바둑판·어탁·나비 표본은 맞는 모델이 없어 도형 유지).
2. `SpawnVisual`: 모델이 있으면 `Resources.Load<GameObject>("World/…")` 로 올려 콜라이더를 떼고 재질을 `FromGltf` 로 툰으로, 한 칸(1m) 안에 들어오게 크기를 맞추고 바닥을 칸 높이에 붙인다. 없으면 기존 도형.
3. 진단: 표의 모든 id 가 실제 가구·모델로 읽히고 크기가 정상 범위, 툰 재질 변환 뒤 불투명 glTF 가 안 남는다.

```
bash saga-unity/tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -projectPath saga-unity -logFile <로그> -executeMethod Saga.EditorTools.PlaytestForestFurnitureModels.Run   → [PlaytestForestFurnitureModels] OK, 컴파일 오류 0
기존 PlaytestForestFurniture 같은 값

```

**불변 규칙**: 에셋 안 만든다(GLB·`.meta` 는 K 갈래) · 가구 id·가격·세이브 불변 · 다른 세션이 엔진을 쓰는 중이면 먼저 확인.
