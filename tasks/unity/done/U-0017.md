# U-0017 게임패드 1차 — `Saga.Core.SagaPad` + 사가고·사가블로 전투 버튼
종류: 새기능(P1)      판: GO·DUNGEON(플래그십)      등급 목표: D1      상태: 작성됨(R-0)

**목표(한 줄)**: 키보드만 읽는 전투·회피·상호작용 입력에 게임패드를 더한다. 이동은 이미 `InputSystem_Actions.inputactions` 의 `Move`(leftStick)로 된다 — 빠진 건 `Keyboard.current` 직접 읽기(게임 38파일·46곳, `Gamepad` 참조 0).

**출처**: `SAGA-BACKLOG.md` §1-4 "게임패드"(Unity 상용화·PC 판에 필요, "InputSystem 액션에 패드 바인딩만 추가"). 새 기능이지만 `features.json` D0+D1 이 100 이상이라 P3 제한(10 미만)과 무관한 입력 보강.

**조사(R-0)**: GO 전투 입력은 `FieldCombat.cs`(Update 348~356 근처)에 `kb.jKey`(공격·길게)·`eKey`(스킬)·`qKey`(폭발)·`lKey`/`leftCtrlKey`(회피)·`rKey`(활 조준)로 박혀 있다. DUNGEON `PlayerCombat.cs`(149~160)는 `spaceKey`·`leftAltKey`·`eKey`, `PlayerController.cs`(287~292)는 `leftCtrlKey`·`fKey`. 카메라는 마우스/터치 드래그(`CameraRig.cs`). UI 는 씬 빌더가 `InputSystemUIInputModule` 을 쓰고 액션 에셋의 `UI/Navigate·Submit·Cancel` 에 패드가 이미 묶여 있다.

**파일**: `saga-unity/Assets/SagaCore/SagaPad.cs`(새) · `Assets/Games/SagaGo/Combat/FieldCombat.cs`(Update 한 곳)·`Player/CameraRig.cs` · `Assets/Games/SagaDungeon/Player/PlayerCombat.cs`·`PlayerController.cs` · `Assets/Editor/PlaytestGamepad.cs`(새)

**본보기**: `SagaCore/VirtualJoystick.cs`·`UiScale` 류 `static` 도우미(U-0006) · 진단은 `PlaytestKit`(HOW_TO_PLAYTEST 13장).

**단계** (끝날 때마다 메모에 ✔ 와 커밋)
1. `SagaPad`(static): `Btn { Attack, Skill, Burst, Dodge, Jump, Interact, Aim, Map, Menu }` ↔ 패드 버튼 — 공격 X(`buttonWest`)·상호작용 Y(`buttonNorth`)·스킬 `leftShoulder`·폭발 `rightTrigger`·조준 `rightShoulder`·회피 B(`buttonEast`)·점프 A(`buttonSouth`)·지도 `select`·메뉴 `start`. `Pressed(btn)`·`Held(btn)`·`Stick(Left/Right)` 은 `Gamepad.current` 가 null 이면 false/zero.
2. GO `FieldCombat.Update`: 각 `kb.xKey.wasPressedThisFrame` 줄 옆에 `|| SagaPad.Pressed(…)` 를 더한다(기존 키·`AttackHeldByUi` 동작 불변).
3. GO `CameraRig`: 오른쪽 스틱으로 시점 돌리기(드래그 입력과 같은 함수에 더한다).
4. DUNGEON `PlayerCombat`·`PlayerController`: 공격·회피·점프·스킬에 같은 식으로.
5. `PlaytestGamepad`: `InputSystem.AddDevice<Gamepad>()` 로 가짜 패드를 달고 `QueueStateEvent`+`InputSystem.Update()` 로 버튼·스틱을 눌러 `SagaPad` 의 눌림·유지·스틱 값·패드 없음(null)을 확인, 끝에 장치 제거.
6. `docs/HOW_TO_PLAYTEST.md` 에 패드 버튼표 한 절.
