# U-0005 `SaveMigrator` + 공통 마이그레이션, REALM 도
종류: 통합      판: 다섯(REALM 행동 변경)      등급 목표: (체제) — 옛 세이브를 버리지 않는다

**목표(한 줄)**: GO `SaveState.Migrate` 루프를 `Saga.Core.SaveMigrator` 로 올려 다섯 판이 버전 검사를 공유하고, `RealmSaveState` 의 "버전 다르면 실패"(221행)를 v3→v4 마이그레이션으로 바꿔 옛 세이브가 이어지게 한다.

**조정**: `*SaveState` 는 static class·`SaveData` 는 private 중첩이라 `ISaveState` 를 구현할 수 없다 → 제네릭 정적 헬퍼로 대신(SAGA-ARCH §4.4-3 의 목적 = 공유). DUNGEON·FOREST·STORY 는 `data.version >= N ?` 조건부 읽기라 그대로 둔다.

**파일**: `saga-unity/Assets/SagaCore/SaveMigrator.cs`(새) · `Games/SagaGo/Data/SaveState.cs`(`Migrate` 367행) · `SagaDungeon/Data/SaveState.cs`(194)·`SagaForest/Data/ForestSaveState.cs`(186)·`SagaStory/Data/StorySaveState.cs`(183)(미래 버전 검사 한 줄) · `SagaRealm/Data/RealmSaveState.cs` · `Assets/Editor/PlaytestSaveMigration.cs`(새)

**본보기**: GO `Migrate`(`while (version < SaveVersion)` 루프, 경로 없거나 미래 버전이면 null) · Playtest 는 `PlaytestKit`(HOW_TO_PLAYTEST 13장).

**단계**
1. `SaveMigrator.Run<T>(T data, int current, Func<T,int> getVersion, Func<int,T,T> step)` = GO 루프 그대로(null 이면 null, 끝에 `version > current` 면 null) + `IsFuture(int v, int current)`. 30줄 안.
2. GO `Migrate` 본문을 `Run(data, SaveVersion, d => d.version, MigrateStep)` 한 줄로. `MigrateStep` 은 손대지 않는다. 나머지 셋은 `version > SaveVersion` 줄을 `IsFuture` 로.
3. REALM: `SaveData` 에 v3 필드를 되살린다(`git show 618dcaba -- saga-unity/Assets/Games/SagaRealm/Data/RealmSaveState.cs` 의 `-` 줄: `xiaopeiWall·MaxWall·Troops·Train·Tech` int, `xiaopeiCaptured` bool, "마이그레이션 전용" 주석). `ApplyJson` 221행을 `Run(data, SaveVersion, d => d.version, RealmStep)` + null 이면 false 로. `RealmStep(3)` 은 `enemies` 를 `EnemySave{enemyId=RealmEnemyCity.XiaopeiId, wall…captured=위 필드}` 하나로 채우고 `version=4`, 그 밖 from 은 null. 머리 주석의 "옛 v3 자동 무시" 를 고친다. `SaveVersion` 값 4 그대로.
4. `PlaytestSaveMigration.Run`(PlaytestKit: `Begin`·`IsolatedSaves()`·`ErrorCounter`·`Summary`·`EditorApplication.Exit`): ① REALM — 현재 `ToJson()` 에서 `"version":4`→`3`, `"enemies"` 제거, `xiaopeiWall`·`xiaopeiCaptured` 추가한 fixture → `ApplyJson` true, `RealmWarState.Snapshot(XiaopeiId)` wall·captured 일치 · `99` 는 false ② GO `"version":28`→`27` 은 true, `99` false ③ DUNGEON·FOREST·STORY: 현재 `ToJson()` true, `99` false. 끝에 상태 `Restore`.
5. `HOW_TO_PLAYTEST.md` 끝에 3줄.
