# U-0012 프로젝트 6000.3.24f1 승격 커밋 + 원복 래퍼를 폰트 오염용으로
종류: 통합 · 설정      등급 목표: (체제) — 배치 뒤 `git status` 가 비는 상태

**목표(한 줄)**: 설치판(.24f1)이 배치 때마다 고쳐 쓰는 버전 파일들을 한 번 커밋해 "고쳐 쓰고 원복" 우회를 끝내고, 원복 래퍼(`tools/unity-batch.sh`)는 진짜 오염인 폰트 SDF 만 되돌리게 한다.

**조사(R-0, 맨몸 `Unity.exe -batchmode -quit` 한 번 돌려 `git diff origin/main` 으로 확인)**: 승격으로 바뀌는 건 **셋**이다 — `ProjectVersion.txt`(6000.3.23f1 → 24f1 · 4e7b9b5b6244) · `Packages/manifest.json`(`com.unity.cloud.gltfast` 6.9.0 → **6.14.1**) · `packages-lock.json`(gltfast 의존: burst 1.8.24·collections 1.2.4·mathematics 1.2.6·searcher 4.9.5). `EditorSettings.asset` 은 안 바뀐다. 지금까지 모든 배치·빌드가 이미 6.14.1 로 돌았다(원복은 끝난 뒤 파일만). `git status` 의 `M` 다섯은 **원인이 둘**: ① `Assets/Settings/{Mobile,PC}_RPAsset.asset`·`DefaultVolumeProfile.asset` = URP 에셋 포맷 승격(`k_AssetVersion 12→13`)·셰이더 prefilter 플래그(렌더 값 renderScale·MSAA 등은 안 바뀜); `DefaultVolumeProfile` 은 `components` 목록에서 항목 둘이 빠짐 — 확인 필요 ② `Art/Fonts/*SDF.asset` 셋 = Playtest 가 동적 글꼴 아틀라스에 글자를 써 넣은 오염(Regular 만 +42,751줄) — 승격과 무관, 커밋하면 안 됨. GLTFast 를 코드가 직접 부르는 곳은 없다(임포터만).

**파일**: `saga-unity/ProjectSettings/ProjectVersion.txt` · `Packages/manifest.json`·`packages-lock.json` · `Assets/Settings/{Mobile_RPAsset,PC_RPAsset,DefaultVolumeProfile}.asset` · `tools/unity-batch.sh` · `CLAUDE.md`(15행)·`docs/HOW_TO_PLAYTEST.md`(15~19행)

**단계**
1. 다른 세션이 Unity 를 안 쓰는지 확인 → 맨몸 배치 한 번(위 조사 그대로) 돌려 세 파일 + RP 에셋 셋 생성. `DefaultVolumeProfile` 의 빠진 `fileID` 둘이 파일 안에 정의가 없는(끊긴) 참조면 그대로 커밋, 정의가 있는 컴포넌트면 그 파일은 **뺀다**(원복).
2. 승격 커밋(위 파일만, worktree 에서 `bash tools/precheck.sh` 파이프 없이).
3. `unity-batch.sh`: 원복 목록(`ProjectVersion·EditorSettings·manifest·packages-lock`)을 폰트 SDF 셋(`NotoEmoji SDF`·`NotoSansKR-Bold SDF`·`NotoSansKR-Regular SDF`)으로 바꾸고 머리 주석을 "동적 아틀라스 오염 원복"으로.
4. 문서: CLAUDE.md·HOW_TO 의 설치판 표기 23f1 → 24f1(PROJECT_STATE 는 크기 15KB 한계라 늘리지 않는다 — 알려진 오류 "함정" 줄이 있으면 한 줄 정정만).
5. 멱등 검사: 래퍼로 컴파일 배치를 **두 번** 돌려 두 번째 뒤에도 `git status --porcelain saga-unity` 가 비어야 한다. RP 에셋이 매번 prefilter 값을 뒤집으면 그 파일도 원복 목록에 더하고 메모.

**검증**
```
cd saga-unity && bash tools/unity-batch.sh -- "<Unity.exe>" -batchmode -nographics -quit -projectPath . -logFile .utmp/u0012.log  (두 번) → git status --porcelain saga-unity 빈다 · grep -c "error CS" 0
PlaytestHeadless(GO — mobile graphics OK 줄 포함)·PlaytestDungeonHeadless OK
```

**완료 조건**: 위 · 승격 파일 외 변경 0 · 게임 코드 0 · 폰트 SDF 는 커밋 안 됨.

**불변 규칙 확인**: 렌더 값(renderScale 0.8·MSAA 2·그림자) 불변 — `PlaytestMobileGraphics` 가 확인 · 다른 PC 는 24f1 설치 필요(HOW_TO 에 적음) · 다른 세션이 Unity 를 쓰는 중이면 미룬다.

**메모(체크포인트)**: ✔ 1~5 (2026-10-01). 승격 9783dc16. 빠진 컴포넌트 둘(Outline·OasisFog)은 스크립트 없는 끊긴 참조. 래퍼=폰트 SDF 원복. 멱등: 컴파일 2회·GO/DUNGEON Headless 뒤 origin 과 diff 0, error CS 0. 함정: 공유 트리가 낡아 git status 대신 origin 대비 diff.
