# U-0020 첫 10분 사명 — STORY (U-0013 의 셋째 판)
종류: 새기능(P0)      판: STORY      등급 목표: D1(Playtest)      상태: 완료

**목표(한 줄)**: 새 STORY 세이브의 목표판 첫 줄(`StorySessionTracker.GoalLineNow`)에 사명 5개가 차례로 뜨고, 다 하면 평소 줄로 돌아간다. 세이브 `tutDone`. 옛 세이브는 전부 끝난 것으로 본다. (BACKLOG §1 P0-1 — GO·DUNGEON 은 U-0013 에서 끝, FOREST·REALM 은 다음 티켓.)

**확인한 사실(R-0)**: `TutorialSteps`(SagaCore)가 있고 본보기는 `GoTutorial.cs`. 판정 API — `StoryQuestState.Kills`·`StoryJobState.Level`·`StorySkillState.SpSpent`·`SagaFlow.LastAutoSaveReason`(GameBootstrap 이 `SagaFlow.Enter("story", …)`). 세이브는 `StorySaveState.SaveVersion=6`, 새 칸은 버전 그대로 두는 관례.

**파일**: `Games/SagaStory/Data/StoryTutorial.cs`(새) · `Games/SagaStory/UI/StorySessionTracker.cs`(`GoalLineNow` 머리 3줄) · `Games/SagaStory/Data/StorySaveState.cs` · `Assets/Editor/PlaytestTutorial.cs`(STORY 줄 추가) · `Assets/Editor/PlaytestStorySlice*.cs`(1줄: `StoryTutorial.Enabled=false`, 첫 목표판 줄 검사가 있는 곳)

**본보기**: `Games/SagaGo/Data/GoTutorial.cs` · GO `SaveState.cs`(`tutDone` 137·274·344·623행).

**단계**
1. `StoryTutorial.cs`: `Steps` = ① walk(30m, 시작 자리 기준 — GoTutorial.Walked 그대로) ② kill(`StoryQuestState.Kills>=1`) ③ level(`StoryJobState.Level>=2`) ④ skill(`StorySkillState.SpSpent>=1`) ⑤ save. 문구 ko/en 한 줄씩(`SagaUi.L` 쓰지 않고 Step.Ko/En). `Enabled`·`Line`·`Ids`·`AllIds`·`Restore`.
2. `GoalLineNow()` 머리에 `var tut = StoryTutorial.Line(); if (tut != null) return tut;`.
3. 세이브: `public List<string> tutDone;` 추가, 저장 `tutDone = StoryTutorial.Ids()`, 로드 `if (data.tutDone == null) StoryTutorial.Restore(StoryTutorial.AllIds()); else StoryTutorial.Restore(data.tutDone);`(옛 세이브=끝난 것). `SaveVersion` 6→7. 진단이 세이브 버전을 하드코딩한 곳 `grep -rn "version" Assets/Editor/*Story*.cs` 로 찾아 함께 올린다.
4. `PlaytestTutorial` 에 STORY 추가(GO 줄 본보기): 새 세이브 첫 줄이 `첫걸음 1/5` · 단계 조건을 코드로 채우면 차례로 넘어감 · `Enabled=false`/옛 세이브면 줄 없음. 다른 STORY 진단은 시작 때 `StoryTutorial.Enabled=false`.
