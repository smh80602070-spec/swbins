# U-0178 2나락 장비 숙련 — 무기는 처치로, 갑주는 맞아서 오르는 단계 (고돗 G-0317 짝)
종류: 게임성(성장) · 유니티(DUNGEON)      상태: **끝**(10-23)(R-0·실행 10-23 Opus — 큐 빔·장부에 웹·고돗 둘 다 끝인 줄 없음 → 고돗이 먼저 한 줄, 장부 dungeon.md "장비가 써서 오르는 레벨" 우선 3 · 웹 "없음")      등급 목표: D1

**목표(한 줄)**: 장비는 주운 그대로다 → 든 무기는 처치마다, 갑주는 맞을 때마다 숙련 +1, 문턱 10·30·60·100·150 에서 단계(최고 5). 무기 단계마다 공격 +3%, 갑주 단계마다 받는 피해 −2%.

**잰 것(R-0 10-23)** — 머리 `saga-unity/Assets/Games/SagaDungeon/`:
- 장비 칸 = 무기 갑·을(`Data/HeroState.cs` U-0131)·보석 하나뿐, 갑주 칸 없음 → **갑주 = 몸에 걸친 한 벌** 하나로 셈. 갈 부위가 없어 고돗의 "다른 부위 갈면 절반 물려받기"는 없음(고돗도 무기는 물려받지 않음).
- 무기 숙련은 id 마다 따로(을로 내려도·다시 쥐어도 그대로) · 처치는 `World/DungeonEnemy.cs` `Die()` 한 곳 — 소환·동행 처치도 든 무기로 셈(고돗과 같음).
- 공격 = `HeroState.HitDamage` 끝에 곱 하나 · 받는 피해 = `TakeDamage` 의 체력 깎는 식에 곱 하나, 실제로 깎였을 때만 갑주 +1(무적·0 피해 제외).
- 「내 정보」 창이 없어 HUD 무기 이름 뒤 `★n`·체력 뒤 `🛡n`(0 단계면 안 보임) · 단계가 오를 때만 토스트.
