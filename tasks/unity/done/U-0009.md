# U-0009 시나리오 표 → `Resources/scenario_<판>.json` + 로더
종류: 통합      판: FOREST·STORY·DUNGEON·REALM(이 순서)      등급 목표: (체제) — 표를 코드 밖으로

**목표(한 줄)**: 코드에 박힌 시나리오 표(`Forest/Dungeon/Story/RealmScenarioData.cs` + `RealmScenarioSideData.cs`)를 JSON 으로 내보내고 그 `.cs` 는 로더만 남긴다. 공개 API(`Casts·Scenes·Chapters·CastOf…`, REALM `Cards·Get·Side`)는 불변.

**조사(R-0)**: 표는 `public sealed class`(공개 필드)+정적 배열이라 `JsonUtility` 로 되나 한계가 있다 — ① 루트 배열 불가 → 래퍼 클래스 ② `readonly struct Line`(FOREST·DUNGEON·STORY)·`Fx`(REALM)는 읽기전용이라 일반 struct 로 ③ **null 문자열·배열·객체를 빈 값으로 쓴다**(`Scene.Choice = null`, `Card.FromId = null` 이 빈 객체·`""` 로 돌아옴 → 소비 코드의 null 검사가 깨짐) ④ REALM `Card.TextByKo/TextByKKo` 는 `Dictionary` 라 불가. 패키지 추가(Newtonsoft)는 manifest 를 건드려 안 한다.

**파일**: `Assets/SagaCore/ScenarioJson.cs`(새) · `Assets/Editor/ScenarioJsonExport.cs`·`PlaytestScenarioJson.cs`(새) · `Games/Saga<판>/Data/*ScenarioData.cs`·`RealmScenarioSideData.cs` · `Games/Saga<판>/Resources/scenario_<판>.json`(새 4; REALM 은 side 도 같은 파일)

**본보기**: `PlaytestKit`(HOW_TO_PLAYTEST 13장) · 소비 코드는 `Games/**/*Scenario.cs`(표는 `XxxScenarioData.Scenes` 로만 읽음).

**단계**
1. `ScenarioJson.Load<T>(res)`(Resources TextAsset → `JsonUtility` → `Normalize`; 없으면 `LogError`+빈 T) · `Normalize(obj)`: 공개 필드를 재귀로 돌며 `""`→null, 전부 기본값인 중첩 객체→null · `DeepEqual(a,b)`.
2. 판마다 1커밋(FOREST→STORY→DUNGEON→REALM): ① 표 타입에 `[Serializable]`, `Line`·`Fx` 는 일반 struct(생성자 유지), 루트 `File` 래퍼(소문자 필드 `casts·scenes·chapters·seasons` / REALM `timeFolk·cards·side`), REALM 사전 둘은 `Kv[]` 직렬화 필드 + 로드 뒤 사전 채움 ② `ScenarioJsonExport`(메뉴·executeMethod)가 옛 표를 JSON 으로 쓰고 **같은 파일을 `Load` 로 다시 읽어 옛 표와 `DeepEqual` 0 차이**를 확인, 옛 표가 `""` 를 명시한 필드(By·AwardKo·Key·Scene)는 null 이 돼도 소비 코드가 `IsNullOrEmpty` 로 봄을 확인 · 장/카드 수를 찍어 메모 ③ 표 본문을 `Load<File>` 로 교체(시그니처 불변).
3. `PlaytestScenarioJson.Run`(PlaytestKit): 네 파일 로드·② 에서 적은 개수와 일치·id 중복 0·`Scene.ChapterId` 가 `Chapters` 에 있음. HOW_TO 3줄.
