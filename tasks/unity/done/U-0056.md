**파일**: 새 `saga-unity/Assets/Editor/SetupVroidHero.cs` · `saga-unity/Assets/Games/SagaGo/Player/PartyBodies.cs`(`UseVroidHero`) · `saga-unity/Assets/Editor/PlaytestShowcaseGui.cs`(촬영 전 30프레임 AlwaysAnimate) · 구운 결과 `Assets/Art/CharactersRealistic/Resources/HeroBody/hero_vroid.prefab`·`hero_vroid_avatar.asset`(로컬 전용 — `.gitignore` CharactersRealistic/)

1. 주인공 몸: VRoid 몸은 공용 동작 Generic 이라 등반·활공·수영 상태를 못 돈다 → `J_Bip_*` 뼈 52로 Humanoid 아바타(AvatarBuilder)를 만들어 `Maria.controller` 를 리타깃. `-executeMethod Saga.EditorTools.SetupVroidHero.Bake`.
2. `PartyBodies.Start` → `UseVroidHero()`: `Resources/HeroBody/hero_vroid` 가 있으면 Maria 를 끄고 그 몸을 주인공 몸으로(`SetBody`·키 3.4m·무기는 `Shown`). 없는 PC 는 Maria 그대로. 이름은 `HeroVroid`(진단이 "Body_" 를 동료 몸으로 센다).

**검증**: Bake OK · `PlaytestHeadless` OK(10 frames, no errors — field combat·traversal·party bodies·weapon model OK) · GUI 촬영 `PlaytestShowcaseGui`(주인공·역참 사람·미래 적) · precheck.

**완료 조건**: 주인공이 VRoid 로 서고 테스트 통과 · VRoid 사람이 T자세 아님.
