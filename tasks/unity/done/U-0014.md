# U-0014 배경음 `Saga.Core.Bgm` — 장면 키·페이드, 판별 복제 5곳 통합
종류: 새기능(P0) · 통합      판: 다섯(GO 만 장면 전환)      등급 목표: D1(Playtest)

**목표(한 줄)**: 판마다 복사된 BGM 재생(곡 하나 반복)을 `Saga.Core.Bgm` 하나로 합치고, 판·장면 키(`<판>-<장면>`)로 `Resources` 곡을 찾아 **페이드로 바꾸는** 길을 만든다. 곡 파일이 없으면 지금 쓰는 곡으로 조용히 폴백. K-0004 곡이 오면 이름만 맞춰 넣으면 붙는다.

**조사(R-0)**: BGM 은 **이미 있다** — `GoAudio`·`ForestAudio`·`StoryAudio`·`RealmAudio`·`SfxPlayer`(DUNGEON)가 각자 `PlayBgm(AudioClip)`(AudioSource 하나, loop, 한 곡)·`RefreshBgmVolume`·`BgmVolume`(PlayerPrefs `saga_go_vol_bgm` 꼴)을 복사해 갖고, 부트스트랩이 한 번 `PlayBgm(bgmClip)`(곡 = `Assets/Art/Audio/CC0_BGM/` 다섯, 크레딧 `SagaCredits` "bgm" 줄 있음)을 부른다. 설정의 BGM 켜기/끄기(`*SettingsState.Bgm`, 0/1)도 이미 있다 → **설정 UI 는 안 건드린다**(음량 슬라이더는 안 함). 없는 것: 장면별 곡·페이드·공통 코드. K-0004 곡(`<판>-<장면>.ogg` 15곡)은 아직 없다.

**파일**: `Assets/SagaCore/Bgm.cs`(새) · 판별 `Audio/{GoAudio,ForestAudio,StoryAudio,RealmAudio,SfxPlayer}.cs`(`PlayBgm`·`RefreshBgmVolume` 위임, `_bgmSource` 삭제) · `Games/SagaGo/World/GoBgmScene.cs`(새) · `GameBootstrap.cs`(GO, 한 줄) · `Assets/Editor/PlaytestBgm.cs`(새)

**본보기**: `GoAudio.PlayBgm`(64~96행) · 곡 폴더 규칙 = `Assets/SagaCore/Resources/Audio/Bgm/<판>-<장면>.ogg`(판 id `go·dungeon·forest·story·realm`, 장면 `main·field·battle`).

**단계**
1. `Bgm`(static + 숨은 `DontDestroyOnLoad` 구동자): `Play(game, scene, fallbackClip, Func<float> volume)`(그 판의 폴백·음량 제공자를 기록하고 장면 시작) · `SetScene(scene)` · `RefreshVolume()` · `Func<string,AudioClip> Loader`(기본 `Resources.Load`, 진단이 바꿈) · `Tick(dt)`(구동자 Update 와 진단이 부름) · `CurrentKey`·`CurrentClip`. 곡 고르기 = Loader(`<판>-<장면>`) → 없으면 폴백 → 없으면 조용(오류 0). 두 AudioSource 를 1.5초 교차 페이드, 같은 곡이면 안 바꿈, 최종 음량 = 제공자 값(`Master×Bgm`).
2. 판별 5곳: `PlayBgm(clip)` → `Bgm.Play("<판>", "main", clip, () => MasterVolume * BgmVolume)`, `RefreshBgmVolume` → `Bgm.RefreshVolume()`. 호출부·설정 코드·PlayerPrefs 키는 그대로.
3. GO: `GoBgmScene`(MonoBehaviour, 0.5초 폴링) — `FieldCombat.Instance != null && FieldCombat.Instance.InCombat()` 이면 `battle`, 아니면 `main` → `Bgm.SetScene`. `GameBootstrap` 에서 `AddComponent`. 곡 파일이 없으면 아무 일도 안 일어난다.
4. `PlaytestBgm.Run`(PlaytestKit·ErrorCounter, `AudioClip.Create` 로 가짜 곡): ① 폴백만 있을 때 `Play` → `CurrentClip==폴백`, `Tick(2)` 뒤 음량 = 제공자 값 ② `SetScene("battle")` 인데 곡 없음 → 그대로(오류 0) ③ `Loader` 가 `test-battle` 에 곡 B 를 주면 `Tick` 으로 페이드 뒤 `CurrentClip==B`, `main` 으로 되돌리면 폴백 ④ 제공자 0 → 소리 0 ⑤ 폴백도 곡도 없을 때 `Play` 오류 0.

**검증**
```
배치 컴파일 error CS 0 · PlaytestBgm OK
PlaytestHeadless(GO)·PlaytestDungeonHeadless·PlaytestForestHeadless(기존 mount 한 줄 외 FAIL 0)·PlaytestStorySlice·PlaytestRealmSlice OK
```

**완료 조건**: 위 · 다섯 판의 `_bgmSource` 0개 · 설정 UI·PlayerPrefs 키 불변 · 곡 파일 0개로도 오류 0.

**불변 규칙 확인**: 크레딧(`SagaCredits` 표)은 새 곡이 들어올 때(K-0004 뒤) 같은 커밋에서 줄 추가 · 세이브 불변 · 다른 세션이 Unity 를 쓰는 중이면 미룬다.

**메모(체크포인트)**: ✔ 1~4 (2026-10-01). 커밋 19985411. 소리원은 씬과 함께 사라지는 기존 수명 유지(DontDestroyOnLoad 쓰면 타이틀에서 음악이 이어짐). 곡이 들어오면 SagaCredits 줄 추가.
