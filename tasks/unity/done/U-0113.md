**목표(한 줄)**: `RealmTacticsView`·`RealmBattlefield`·`RealmFigure` 가 각자 들고 있는 "기본 도형 만들고 충돌체 떼고 색 재질 입히기"·여덟모 뿔 메시·`Dictionary<Color, Material>` 캐시 셋을 새 정적 클래스 `RealmPrims` 하나로 모은다. 재질은 (색, 매끈함) 열쇠로 한 캐시 — 같은 색·같은 매끈함이면 세 화면이 한 재질을 같이 쓴다. 화면 모습은 그대로(셰이더·색·매끈함 0.12/0.15/0.25 각자 유지).

**근거(R-0 확인, 10-13)** — 경로 머리 `saga-unity/Assets/Games/SagaRealm/World/`
- `RealmBattlefield.cs` 49~50행 `Mats`·`_cone`, 255~311행 `Spawn`·`Cone`·`Mat`(매끈함 0.15, 이름 "Battlefield (generated)")·`ConeMesh`("BattlefieldCone").
- `RealmTacticsView.cs` 59~60행 `Mats`·`_cone`, 605~660행 같은 넷(매끈함 0.12, "Tactics (generated)"·"TacticsCone") — Battlefield 와 글자까지 같다.
- `RealmFigure.cs` 35행 `Mats`, 362~385행 `Part`(재질 캐시를 몸 안에 품음, 매끈함 0.25)·`Kill`(130·162·370행이 씀).
- 재질 이름·뿔 이름을 찾는 코드는 저장소에 없다(grep `(generated)`·`*Cone` — 세 파일 밖 0건).

**파일**
- 새 `Assets/Games/SagaRealm/World/RealmPrims.cs`(+ Unity 가 만드는 `RealmPrims.cs.meta` — 새 스크립트의 .meta 는 커밋한다, 본보기 `SagaCore/MetricBox.cs.meta`) — `namespace Saga.Realm.World`, `internal static class RealmPrims`:
  - `Material Mat(Color c, float smoothness)` — `c.a = 1`, 열쇠 `(Color, float)` 캐시(파괴된 재질이면 다시 만듦), URP/Lit, 이름 "Realm (generated)".
  - `Mesh Cone()` — 지금 `ConeMesh` 그대로(밑 반지름 1·높이 1·여덟모), 이름 "RealmCone", 한 번만.
  - `GameObject Prim(string name, PrimitiveType type, Transform parent, Vector3 localPos, Vector3 scale, Color color, float smoothness)` — 지금 `Spawn`/`Part` 몸 그대로(SetParent false·충돌체 `Kill`).
  - `GameObject ConeObj(string name, Transform parent, Vector3 localPos, float radius, float height, Color color, float smoothness)` — 지금 `Cone` 몸.
  - `void Kill(Object o)` — 플레이 중 Destroy, 아니면 DestroyImmediate.
- 세 파일: 캐시 필드·`Mat`·`ConeMesh` 몸을 지우고, `Spawn`/`Cone`/`Part`/`Kill` 은 **이름·인자 그대로 한 줄 위임**(`const float Smooth = 0.15f` 꼴 상수 하나씩) — 부르는 자리는 손대지 않는다.
