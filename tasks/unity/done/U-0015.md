# U-0015 GO FieldEnemy 코드 리뷰 지적 정리 (R-5, 2026-10-01)
종류: 닫기(버그)      판: GO      등급 목표: —      상태: 완료

**목표(한 줄)**: R-5 `/code-review high`(FieldEnemy*.cs)가 낸 지적 중 코드로 확인된 상태 잔존·NaN 버그를 고친다(성능·중복 정리는 이 티켓 밖).

**파일**: `saga-unity/Assets/Games/SagaGo/Combat/FieldEnemy.cs`·`FieldEnemy.Damage.cs`·`FieldEnemy.Visual.cs` · 진단 `Assets/Editor/PlaytestGoFieldCombat.cs`(GO `PlaytestHeadless` 안에서 돈다)

**본보기**: `Die()`·`BreakShield()` 가 이미 `ClearReactionStates()`·`_alertText` 끄기를 한다 — 같은 정리를 빠진 길에 붙인다.

**단계** (한 단계 끝날 때 메모에 ✔ 와 함께 커밋)
1. NaN: `RefreshHeadUi`(FieldEnemy.cs 1255 근처) `_shieldFill.localScale` 의 `ShieldHp / ShieldMax` 를 `ShieldMax > 0f ? … : 0f` 로. `MakeWeeklyBoss`(369)는 `ShieldMax = 0` 인데 `_shieldBar` 가 남는다.
2. 부활·귀가 정리: `Revive()`(1062)와 `Return` 도착(833, `ResetShields()` 옆)에서 `ClearReactionStates()` + 감전 카운터(`_chargedLeft`) 0 + `_knock = Vector3.zero` + `_siegeStrike = false`.
3. 죽은 뒤 상태 재설정 막기: `TakeHit`(Damage.cs 139~148) 불붙음·가속 분기와 감전(`StartCharged`) 분기는 `Alive` 일 때만(`Freeze` 의 가드와 같게). 과부하 루프(Damage.cs 76~85)도 `other.Alive` 일 때만 `_knock` 을 쓴다.
4. `Freeze()`(Damage.cs 155 근처)가 전조(`Telegraph`)를 끊을 때 `_alertText` 도 끄고 `_siegeStrike = false`.
5. 읽고 확인 후 판단(코드를 먼저 읽는다 — 아니면 메모에 "아님/보류" 와 사유만): (a) `OnEnable`·`RescaleAll`(713)이 비활성 적을 놓치는가 — 고친다면 `ApplyWorld` 호출 한 줄, 세이브·도메인 적(`DomainFoe`)에 영향 없는지 확인 (b) Chase 분기(800~808)에서 `DomainFoe`·`playerOk == false`·`fc == null` 일 때 `fc.transform` 접근 — `fc == null` 가드 한 줄.
6. 진단: 위 1·2·3 을 `PlaytestGoFieldCombat.Run` 에 작은 검사로(공개 진단 훅 `SetHpForTest`·`SetShieldForTest` 등 사용, 모자라면 `…ForTest` 한 줄): 주간 두목형(보호막 0)에서 막대 스케일이 NaN 아님 / 불붙인 채 죽여 `ReviveNow()` 하면 `BurningLeft == 0`.
