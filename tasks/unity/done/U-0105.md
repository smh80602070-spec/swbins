# U-0105 2나락·4종횡·1만리 "내가 맞았다" 신호 — 가장자리 붉게 번쩍·체력 30% 밑 맥박(공용 `HurtVignette`) + 2나락 붉은 피해 숫자·흔들림
종류: 손맛·통합 · 유니티(DUNGEON·STORY·GO)      상태: 완료(10-12) ← 작성됨(R-0 10-12, 고돗 G-0203 짝)      등급 목표: 새 features `un.dg.hurt-signal`·`un.st.hurt-signal` D2

**목표(한 줄)**: 유니티 2나락은 맞아도 체력 바만 준다(숫자·흔들림·화면 신호 0), 4종횡은 붉은 숫자·흔들림뿐, 1만리는 붉은 숫자뿐 → 공용 화면 가장자리 붉은 번쩍 + 체력 30% 밑 맥박을 세 판에, 2나락은 붉은 숫자·작은 흔들림까지.

**근거(R-0 확인)**: 2나락 `Data/HeroState.TakeDamage` → `Hurt` 이벤트(구독은 `World/MountField` 하나) · 부르는 곳 DungeonEnemy 610·LordSigRunner 184·TempleBomb 86 · 흔들림 `Player/CameraRig.Shake(mag,sec)`(PlayerCombat 이 `_cameraRig` 로 씀) · 숫자 `SagaCore/DamagePopup.Spawn(pos, amount, Color)`(109-11-1 플레이어 피해 빛깔). 4종횡 `Player/StoryPlayerVitals.OnHurt` 52(숫자·`StoryCameraFollow.Shake`) · 체력 `Data/StoryPlayerHp.Hp/HpMax`. 1만리 `Combat/FieldCombat.cs` 845 붉은 숫자(맞는 자리, `m.Hp`/`m.Down`). 셋 다 가장자리 신호·맥박 없음(grep vignette 0). 고돗 본보기 `saga-godot/saga_core/ui/hurt_vignette.gd`(flash·set_low, 82줄).

**파일** — 머리 `saga-unity/Assets/` : 새 `SagaCore/HurtVignette.cs`(정적 `Flash()`·`SetLow(bool)`·`Bind(Func<float> hpFrac)` — 처음 부를 때 Screen Space Overlay 캔버스(sortingOrder 높게, raycastTarget 끔) + 가장자리만 붉은 Image 를 **코드로 만든 방사형 텍스처**(Texture2D, 새 에셋 파일 0)로 붙임 · 번쩍 알파 0.45→0 약 0.4초 · 맥박 0.6~1.2Hz 0.15~0.3 · 장면이 바뀌면 같이 사라지고 다음 부름에 다시 · 진단용 `Alpha`·`FlashCount`·`ResetForTest`) · `Games/SagaDungeon/Player/PlayerController.cs`(OnEnable/OnDisable `HeroState.Hurt` 구독 → Flash·`DamagePopup.Spawn(머리 위, 깎인 값, 붉음)`·`CameraRig.Shake` 작게, Bind(Hp/HpMax)) · `HeroState.cs`(깎인 값 `LastDealt` 하나만 — 값·규칙 불변) · `Games/SagaStory/Player/StoryPlayerVitals.cs`(OnHurt 에 Flash, OnEnable 에 Bind) · `Games/SagaGo/Combat/FieldCombat.cs`(845 옆 Flash, Bind 활성 인물 Hp/HpMax) · 새 `Editor/PlaytestHurtSignal.cs` + 사슬 한 줄씩(`PlaytestDungeonHeadless`·`PlaytestStorySlice`·`PlaytestHeadless`) · `saga-unity/features.json` 두 줄 · `docs/HOW_TO_PLAYTEST.md` 한 줄 · 촬영 동작은 `Editor/PlaytestShowcaseGui*.cs`(`SAGA_SHOT_ACT=hurt`).

**단계**
1. `HurtVignette` — 화면 가운데는 안 가림(가운데 알파 0, 가장자리 25% 폭만), 시간은 `Time.unscaledDeltaTime`(치명 멈춤 중에도 사라짐), Bind 가 없으면 맥박 없음.
2. 2나락 — Hurt 구독(번쩍·숫자·흔들림 0.08/0.12초 = PlayerCombat HitShake 보다 작게), Update 에서 `SetLow(Hp < HpMax*0.3)`. 받는 피해·무적·사망 규칙 손대지 않음.
3. 4종횡·1만리 — OnHurt/맞는 자리에 Flash 한 줄, Bind 한 줄(1만리는 편성 활성 인물, 쓰러짐 교체 뒤 새 인물).
4. 진단 `PlaytestHurtSignal`(판별 Run(tag)): ① Flash → Alpha>0.3, 0.5초 뒤(수동 Tick) 0 ② Bind 0.2 → 맥박 알파>0, 0.5 → 0 ③ 2나락 진짜 `TakeDamage` → FlashCount+1·`DamagePopup` 하나·체력 되돌림(U-0104 PlaytestSfxSelf 처럼 리플렉션) ④ 4종횡 `StoryPlayerHp` 피해 → FlashCount+1(체력·무적 되돌림) ⑤ 캔버스 하나뿐(두 번 불러도) · raycastTarget false.
5. 촬영(GUI, 세이브 다섯 백업·판마다 복원): 2나락·4종횡 각각 맞는 순간 + 체력 25% 상태, 가로 1600×900. Claude 눈 ○ = 가장자리 붉음·붉은 숫자·가운데 안 가림.
6. features 두 줄 D2 · HOW_TO · 큐 · 메모 · `node tools/qc.mjs --branch unity`.
