# U-0011 AAB 790MB — 크기 분포 도구·기록 (화질 걸린 절감은 사용자 결정)
종류: 닫기 · 빌드      등급 목표: (체제) — 크기를 숫자로 보고 정한다

**목표(한 줄)**: 지난 빌드(`Build/Android/SAGA_assets.txt`)의 포함 에셋 크기를 폴더별로 집계하는 `tools/aab-breakdown.py` 와 `docs/store/size.md`(분포·한도·절감안)를 만든다. 화질을 건드리는 절감은 **하지 않는다** — 사용자 결정으로 남긴다.

**조사(R-0, 새 빌드 없이)**: ① **PAD 분할은 이미 됨** — `SAGA_report.txt`(2026-09-29): AAB 790.1MB = base 38.2MB(한도 200) + `UnityDataAssetPack` 751.2MB(한도 1536), `PlaytestSagaAab` 가 검사. BACKLOG 의 "PAD 미실측"은 낡은 표기(공통 파일이라 이 티켓에서 안 고침, 메모만). ② **2K 상한도 이미 적용** — `CharactersForge/Textures` PNG 525개 전부 `maxTextureSize 2048`(+Android 오버라이드 2048, 압축 Normal). ③ 분포(포장 크기 합 1,208MB, 4,583개): `CharactersForge/Textures` 622MB(292) · `CharactersRealistic` 325MB(Mixamo 몸) · 공방 기타 124MB · `Props` 86MB · 나머지 35MB 미만. 공방 몸(105벌, `CharactersForge/Resources/ForgeHero`, 로컬 전용 `.gitignore`)은 Resources 라 전부 실린다(게임은 `PartyBodies.ForgeHero` 가 한 벌씩 읽음). 참조된 것만 실리므로 "씬이 안 쓰는 몸 제외"는 사실상 성립.

**사용자 결정 필요(이 티켓 밖)**: 더 줄이려면 화질·구조가 걸린다 — (a) 공방 텍스처 ASTC 6×6→8×8(importer `textureCompression` Low, ≈ -40% ≈ -250MB 추정) (b) 조연 인물 텍스처 1K (c) `ForgeHero` 를 설치 후 내려받는 on-demand 팩으로(Addressables, 구조 변경). §6.1-B "화질은 안 낮춘다" 때문에 임의로 못 한다.

**파일**: `saga-unity/tools/aab-breakdown.py`(새) · `saga-unity/docs/store/size.md`(새)

**단계**
1. `aab-breakdown.py [assets.txt] [--fail-over MB]`: `<크기>\t<경로>` 줄을 읽어 `Assets/Art/<둘째 폴더>` 단위(공방은 Textures·Resources·기타로 나눔)·확장자별 합계를 큰 순으로 찍고, 합이 `--fail-over` 를 넘으면 종료 코드 1.
2. `size.md`: 위 분포표 · 모듈 한도 · 지난 측정(날짜·크기) · 결정 필요 (a)(b)(c) 와 추정 절감량(미적용 표시).

**검증**
```
py saga-unity/tools/aab-breakdown.py saga-unity/Build/Android/SAGA_assets.txt   → 위 숫자(622·325·124·86 MB, 합 1208)와 ±1MB
py saga-unity/tools/aab-breakdown.py saga-unity/Build/Android/SAGA_assets.txt --fail-over 100   → 종료 코드 1
```
`Build/` 는 gitignore 라 파일이 없으면(다른 PC) "빌드 먼저" 메시지만.

**완료 조건**: 위 · 두 파일 커밋 · 게임 코드·임포트 설정 0 변경 · 보고에 (a)(b)(c) 를 사용자에게 묻는다.

**불변 규칙 확인**: 화질·렌더 값·텍스처 설정 불변 · 새 빌드 안 돌림(필요하면 `bash tools/unity-batch.sh` 로 따로 티켓) · 공통 파일(BACKLOG) 수정 금지.

**메모(체크포인트)**: ✔ 1~2 (2026-10-01). aab-breakdown.py: 4,583개·1,208MB, 622/325/124/86MB 일치, --fail-over 100→종료 1·5000→0, 파일 없으면 2. size.md 작성. 결정 대기: (a) ASTC 8×8 (b) 조연 1K (c) ForgeHero on-demand — 사용자 몫. BACKLOG 3.3 '실측 대기' 문구는 낡음(공통 파일이라 안 고침).
