# U-0006 나머지 복제 5개 → SagaCore (LocalizedButtonLabel 제외)
종류: 통합      판: GO·DUNGEON·FOREST·STORY      등급 목표: (체제) — 복제 23 중 다음 다섯

**목표(한 줄)**: `VirtualJoystick`·`GroundDecal`·`HitSpark`·`DamagePopup`·`NpcIdle` 을 U-0003 도구(`tools/remap-guid.mjs`)로 하나씩 `Assets/SagaCore/`(namespace `Saga.Core`)로 옮긴다. 클래스마다 커밋.

**조사(R-0)**: 주석·namespace 만 다른 **동일 코드** — VirtualJoystick(GO·DUNGEON·FOREST) · GroundDecal(GO·DUNGEON) · HitSpark(DUNGEON·STORY). **상위집합** — DamagePopup: STORY 가 DUNGEON 의 `Spawn(pos,amount,bool)` 에 `Spawn(pos,amount,Color)` 를 더한 것(파라미터 이름만 heavy/crit). NpcIdle: GO·FOREST·STORY 동일(`SpawnRigged(prefab,parent,float height,float yaw,string state)`), DUNGEON 은 `SetState(string)` 과 `SpawnRigged(prefab,parent,string state,float yaw)` 가 더 있고 높이 맞춤이 없다(시그니처가 달라 한 클래스에 두 오버로드로 합친다). 씬 참조: LayoutWalk·TestDungeon·TestField·TestVillage·TestVillageForest.
**제외**: `LocalizedButtonLabel` 4사본은 판별 `*Localization.CurrentLanguage/T` 를 직접 불러(`GoLocalization` 등) 한 클래스로 못 합친다 — `SagaFlow.CurrentGame` 으로 고르는 등록부가 필요한 설계 판단이라 새 티켓 후보(메모에 적고 여기선 안 한다).

**파일**: `saga-unity/Assets/SagaCore/{VirtualJoystick,GroundDecal,HitSpark,DamagePopup,NpcIdle}.cs`(+`.meta`) · 판별 사본 삭제 · 위 씬 · 호출부 `.cs`(`Games/**`·`Assets/Editor/Build*Scene*.cs`)에 `using Saga.Core;` 만 추가.

**본보기**: U-0003 `PlatformVolumeProfile`(`git mv` 로 기준 사본을 SagaCore 로 → namespace `Saga.Core` → 나머지 `remap-guid --delete`). 기준 사본: VirtualJoystick·GroundDecal·NpcIdle = GO, HitSpark = DUNGEON, DamagePopup = STORY(상위집합이라 그대로). NpcIdle 은 옮긴 뒤 DUNGEON 의 `SetState`·`SpawnRigged(…string state…)` 를 더한다.

**단계(클래스마다 반복)**
1. `git mv` 기준 `.cs`·`.meta` → SagaCore, `namespace Saga.Core`.
2. `node tools/remap-guid.mjs --delete <나머지 .meta들> <새 .meta>`.
3. 배치 컴파일(`-quit`만) → `error CS0246/CS0103` 난 파일에 `using Saga.Core;` 추가, 다시. 다른 오류면 되돌리고 메모.
4. `remap-guid.mjs --check` 잔존 0 → `PlaytestMissingScripts.Run` OK → 커밋(`git commit -F <파일> -- <경로>`, 커밋 전 `bash tools/precheck.sh` 는 파이프 없이).
마지막에 다섯 클래스가 끝난 뒤 5·6 을 한 번.
5. Playtest: `PlaytestDungeonHeadless`·`PlaytestForestHeadless`·`PlaytestHeadless`(GO)·`PlaytestStorySlice`(실제 `save_story.json` 이 있으면 치우고 돌린 뒤 복원) 각 OK.
