# W-0197 3D 걸음 — 달리기 클립이 안 나오는 버그 + 클립 속도를 이동 속도에 맞추기(1만리 먼저, 다섯 판)
종류: 버그·손맛 · 웹(1만리 → 2나락·3마을·4종횡·5천하 3D)      상태: 작성됨(Opus R-0 10-14 — 사용자 "3D 먼저", 목록 3D-2 확인 뒤 "웹 이어해")      등급 목표: D2

**목표(한 줄)**: 3D 사람이 움직이는 속도에 맞는 클립(걷기·달리기)을 맞는 빠르기로 틀어 발이 땅에서 미끄러지지 않게.

**잰 것(R-0, 10-14)**
- **버그**: `saga-go/js/asset3d.js` 1426 `want = walking ? (o.speed > 1.6 ? 'run' : 'walk') : 'idle'` 인데 `saga-go/src/world3d/04-actors.js` 110 `actor3d.step(a.node, { t, walking, phase, anim })` 에 speed 가 없고 `js/actor3d.js` 781 이 그대로 넘김 → 늘 walk, 1배속(`asset3d.js` 1431 `mixer.update(dt)`).
- 속도: 걷기 8 m/s(`src/world/01.js` 41) · 달리기 ×2.2(293) · `player.speed`(381, m/s). 3D "걷는 중" = `mot.speed > 1.5`(`04-actors.js` 286). 사람 걷기 클립 본래 빠르기 ≈1.4 m/s, 달리기 ≈5 m/s(손잡이로 둠 — 단계 1 에서 촬영으로 맞춤).
- `asset3d.js` 다섯 벌은 판마다 다르다(sync-shared 밖) — step 만 같은 꼴로 고친다.

**파일**: `saga-web/saga-go/js/asset3d.js`(step 1420~1433) · `saga-web/saga-go/js/actor3d.js`(781) · `saga-web/saga-go/src/world3d/04-actors.js`(110·286) · 나머지 네 판 `js/asset3d.js` 의 step · 판별 `_test.html`·`sw.js`·`features.json`

**단계**
1. 1만리: 04-actors 110 에 `speed: mot.speed`(나·동행·NPC 모두) 넘김.
2. `asset3d.step`: 속도 v → 클립·빠르기. v < 0.3 idle · v < `anim3d.runFrom`(3.0) walk, timeScale = v / `anim3d.walkMps`(1.4) · 그 위 run, timeScale = v / `anim3d.runMps`(5.0). timeScale 은 0.6~1.7 로 묶음(넘는 속도는 몸이 미끄러지는 대신 다리가 미친 듯 돌지 않게). 걷기↔달리기 바뀔 때 0.25초 섞기(기존 play 의 0.2초 넘김 재사용).
3. 몸 기울기: 방향을 틀 때 진행 쪽으로 최대 8° 기울임(손잡이 `anim3d.lean`, 0 이면 끔) — 나만.
4. 같은 step 고침을 네 판 asset3d 에(각 판이 step 에 speed 를 넘기는지 확인 — 안 넘기면 부르는 자리도).
5. 진단 +1(1만리, 판마다 가능하면): step 에 speed 2 → walk·timeScale≈1.4 · 8 → run·≈1.6 · 0 → idle.
6. 번들 · sw VERSION +1.
