# W-0328 다섯 판 타격 VFX — 슬래시 궤적·원소 알갱이·피격 섬광을 공용 `hitfx3d` 로(지금은 숫자·흔들림뿐)
종류: 새 기능(그래픽·손맛) · 웹(다섯 판 — 1만리·5천하 플래그십 먼저)      상태: 작성됨(페이블 R-0 10-18 — 장부 proposals.md 그래픽 우선 1 ①)

**목표(한 줄)**: 때리면 **눈이 먼저 안다** — 맞은 몸이 0.08초 하얗게 번쩍(emissive 섬광) · 맞은 자리에 원소 색·모양 알갱이(불=치솟는 불꽃 · 물=푸른 물방울 · 번개=지그재그 가시 · 얼음=육각 결정 · 바위=갈색 조각 · 풀=잎 · 바람=흰 소용돌이 · 물리=주황 불똥) · 휘두름마다 궤적 띠(1만리 slash3d 를 공용으로 올림) · 치명은 알갱이 두 배 + 화면 0.05초 멈춤 + 가산 섬광 — 다섯 판 3D 전투 전부 같은 조각 하나, 2D 는 있는 vfx2d(K-0039 시트)로 같은 뜻.

**지금(10-18 조사)**: 1만리 3D = 검기 띠(`js/slash3d.js`, W-0173) + 주황 육각 알갱이 셋(원소 구분 없음) · 2나락 3D = `js/fx3d.js`(섬광·흔들림·알갱이·궤적·숫자 풀 — 가장 앞섬, 원소 색 일부) · 4종횡 = 2D `vfx2d` 시트(spark_hit·crit_flash…) 만, `side-view3d` 엔 없음 · 3마을 = 적대 조우(`ai.js`·`game.js`) 에 타격 그림 없음 · 5천하 = `battle3d.js` 디오라마에 피격 표시 없음(일기토도). 공용 조각은 **2나락 fx3d 의 알갱이·섬광·멈춤을 뽑아** 다섯 판에 건다(2나락은 자기 fx3d 를 공용으로 갈아 끼우고 숫자 풀·궤적은 그대로).

**참고**: 원신(원소 반응 색·피격 섬광 80ms) · PoE2(치명 멈춤·화면 흔들림 짧게) · 장부 `tasks/gameplay/README.md` 그래픽 절 · `tasks/gameplay/proposals.md` 그래픽 표 1줄.

**파일**: 새 `saga-web/shared/js/hitfx3d.js`(정본 → `tools/sync-shared.mjs` 로 다섯 판 `js/` 사본) — `DG.hitfx3d.make(three, scene)` → `h.hit(pos, {el, crit, dir})`·`h.flash(mesh, span)`·`h.slash(pos, ang, w, step)`·`h.freeze(ms)`·`h.update(dt)`·`h.dispose()` · Points 한 덩이(풀 512, 원소별 색·크기·중력·수명을 attribute 로 — 그리기 1) · 궤적 띠는 slash3d 의 `arcSpec()` 그대로 옮김(1만리 slash3d 는 공용을 부르는 한 줄로) · 부르는 쪽: 1만리 `src/world3d/04-actors.js`(피격 이벤트 자리 끝 한 줄, 원소 `f.el`: fire·water·elec·ice·rock·grass·wind) + `js/battle3d.js`(결투) · 2나락 `js/fx3d.js`(알갱이·섬광 → 공용, 원소 `elem` el 표는 vfx2d.js:22 와 같게) · 4종횡 `js/side-view3d.js`(2D fx 'hit' 가 생길 때 3D 자리로 투영해 한 번) · 3마을 적대 조우 3D 화면 · 5천하 `js/battle3d.js`(합마다 `frames`·`duel.hits` 자리) · 다섯 판 `manifest.json`·번들 `dist/app.js`·`sw.js` · 손잡이 `hitfx.on`(1)·`hitfx.n`(512)·`hitfx.freeze`(1) · 측정 `pw-gfx.mjs` "타격 VFX" 칸(한 번 때리고 0.1초 안 알갱이 ≥8 · 섬광 픽셀 밝기 차 ≥ 60) · `features.json` 다섯 판 한 줄(D1, ticket W-0328).

**단계**: ① hitfx3d.js(알갱이 풀·원소 표·섬광·멈춤·궤적) + 자가진단(`arcSpec`·원소 표는 three 없이 돈다) ② 1만리 들판·결투(slash3d 를 공용 호출로) ③ 2나락 fx3d 갈아 끼우기(숫자 풀·흔들림은 그대로, 중복 코드 삭제) ④ 5천하 전장·일기토 ⑤ 4종횡 side-view3d ⑥ 3마을 조우 ⑦ pw-gfx 칸 + qc 줄 ⑧ 폰 예산(알갱이 풀 256·멈춤 끔 손잡이 자동 단계).

**검증**: `node tools/test-web.mjs <판>` 다섯 · `node saga-web/tools/playcheck/pw-gfx.mjs` "타격 VFX" 다섯 판 ○ · `node tools/qc.mjs --branch web` PASS · 촬영 한 장씩(치명 한 번, 원소 셋) 눈 판정(C).

**완료 조건**: 다섯 판 3D 전투에서 섬광·알갱이·궤적이 한 조각으로 돌고 pw-gfx 칸 다섯 ○ · 그리기 +2 이내(알갱이 1 + 궤적 1) · 2나락 fx3d 에서 중복 코드 사라짐 · features.json 다섯 줄 · 장부 proposals.md 그 줄 `끝 W-0328` · done/.

**불변 규칙**: 판정(field-combat·dungeon·side·war)은 한 자도 안 바꾼다 — 이벤트가 날 때 한 줄만 부른다 · 에셋 없음(알갱이는 코드 모양·색, 궤적은 가산 띠 — 시트 그림은 K 몫, 오면 2D vfx2d 처럼 갈아 끼움) · big-files 꽉 찬 파일(field-combat·04-actors)은 기존 줄 끝 연결 · 조각 정본은 src/ 고치고 `build-parts` · 폰 자동 단계에서 멈춤(freeze)은 끈다(입력 지연으로 느껴짐).
