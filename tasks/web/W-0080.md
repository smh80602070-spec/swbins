**규칙(수치 근거)** — 처음 값, W-0082 시트로 조정
- 시작 `start(seed, diff)`: `state.create(seed, diff)` 위에 `s.tb={turn:1, side:0, acted:{}, cd:{}, auto:false}`. 아군 = 영웅 3(`heroes.roster()` 앞 셋, `statsOf`) + 보병 3·궁병 2·기병 1, 거점 앞 적 쪽 4~6칸. 적 = 같은 꼴 병사 수 × `rules.DIFF.wave[diff]`(0.7·1·1.4, 반올림·최소 1) + 적장 1(roster 끝), **두 거점 가운데**에서 적 기지 쪽 4칸. 칸은 `units.nearestWalkable`.
- 이동력 = `round(UDEF.speed×2)`(보병 4·궁병 4·기병 7·영웅 5~6). 4방향, 풀 1·숲 2·언덕 2, 물·건물은 `units.walkable` 대로 못 감, 적 칸 못 지남, 아군 칸은 지나되 못 멈춤.
- 사거리(맨해튼): `UDEF.range ≤1.4` 는 1, 궁병 2~3(붙은 적 못 쏨). 적 기지(3×3)·내 거점도 칸 거리로 친다.
- 피해 = `round(atk×3×combat.mult(공,수)×땅)` — 상성 1.5(`BEAT`), 맞는 쪽이 숲·언덕이면 ×0.85(PLAN §5-6 매복 배율). 맞은 쪽이 살아 있고 공격자가 제 사거리 안이면 **반격** ½ 한 번.
- 일격(영웅, 공격 대신): `combat.cast` 식 `atk×(1+지력/100)×2`, 둘레 맨해튼 2, 쿨다운 3턴.
- 한 유닛 한 턴 = 이동 0~1 + 행동 1(공격·일격·대기) → `acted`. 승: 적 전멸 또는 적 기지 hp 0. 패: 아군 전멸 또는 `s.cHp` 0 또는 30턴 넘김.
- AI `plan(s,u)`(난수 없음): 닿는 칸×대상 중 (준 피해 + 죽이면 50 − 받을 반격) 최대, 같으면 숲·언덕 칸 → id 작은 대상. 칠 게 없으면 가장 가까운 상대 유닛(없으면 상대 거점)으로 `units.findPath` 길 위 이동력 안 가장 먼 칸. `autoTurn(s, team)` = 그 편 id 순 plan 적용. 적 차례는 늘 이것, `tb.auto` 면 아군도.

**단계**
1. `tactics.js`: `start·reach·targets·move·attack·cast·wait·endTurn·autoTurn·plan·serialize·restore` 를 `DG.rts.tactics` 에. `endTurn` = 적 `autoTurn` → turn+1 → cd 줄이기 → acted 비움. 저장 꼴은 `{v:1, seed, diff, tb, units, cHp, shp}`(지형은 시드로).
