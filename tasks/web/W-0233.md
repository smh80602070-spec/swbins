**목표(한 줄)**: 2D 들판 전투에서 적(짐승)이 내 몸(≈120px) 발밑 20~40px 에 겹쳐 싸우던 것을, 3D 와 같은 몸 대비 거리·빠르기로 — 사거리 ≈ 몸 2개, 적이 몸 2~3개/초로 덮친다. 싸움이 붙어도 내 걸음이 8m/초로 떨어지지 않는다.

**잰 것(R-0, 10-15 촬영 shots/w233/w224_3.png)**

**방식(셋 중 B 추천)**
- A 그림만 펼침(판정 그대로) — 땅은 8m/초로 흐르는데 적만 빨리 보여 어긋남, 안 함.
- **B 2D 판정 배율 k2d = body2dM ÷ 1.7**(3D 사람 키): 거리 함수들과 적 빠르기에 ×k2d, 시간 상수(쿨·hitstop·i-frame)는 그대로. 내 걸음은 2D 값 그대로(전투 중 8m/초 떨어짐 없앰). 3D 는 k=1 로 지금 그대로. AGGRO_R·LEASH_R 은 무리 간격 때문에 ×min(k2d, 무리 간격÷(2×기본)) 상한.
- C 2D 지도 척도(칸 48m) 자체 — 너무 큼, 안 함.
