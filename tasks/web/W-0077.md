# W-0077 사가블로 피해 숫자가 한자리에 겹쳐 쌓여 못 읽는다

**목표(한 줄)**: 한 적에게 잇달아 뜬 피해 숫자가 칸을 나눠(옆·위로 비켜) 각각 읽힌다. 3D·2D 같은 칸 값.

**재현(10-06 Claude 화면 판정, 시트 saga-dungeon-20261004 3번 메모)**: ① `_demo.html#dg`(굴혈 3D) ② 한 적을 연달아 친다(평타·Shift·Z) ③ 숫자가 한자리에 포개진다.

**기대**: 0.35초 안에 같은 몸에서 뜬 숫자는 0·1·2·3 번 칸으로 나뉘어 좌우 번갈아·한 단씩 위로 비킨다.

3. 2D: `02.js` 1000~ 의 숫자 자리에 같은 `f.nslot`(없으면 0)으로 x ±·y − (글자 13/18px 기준 같은 배수). build-parts.
4. 진단 `_test.html` 5104 줄 근처(fx3d plan 진단 옆): 같은 자리 hit 셋 → nslot 0·1·2, 멀리 떨어진 것·0.35초 지난 것 → 0, 0 칸 plan dx 0·1 칸 dx>0·2 칸 dx<0·rise 1 칸 > 0 칸.
