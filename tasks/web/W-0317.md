# W-0317 QC 빈틈 ⑦⑨ — 촬영 전 가리는 창 닫기(공용) · 푸시 뒤 배포 재확인 자동
종류: 체제(QC 도구·push) · 웹(다섯 판)      상태: **작성됨**(페이블 R-0 10-18 — `tasks/sheets/qc-gaps-20261018.md` #7·#9)

**목표(한 줄)**: ⑦ 4종횡 Esc 가 메뉴를 열고 서막 대화가 늦게 떠 촬영이 엉뚱한 화면을 찍었다 → 촬영 스크립트마다 제각각인 `clearIntro` 를 공용 하나(`saga-web/tools/playcheck/overlay.mjs`: 열린 오버레이 목록 = 대화·이야기·도움말·☰ 메뉴·일시정지·가입 창 → 닫기 → 남은 목록 반환)로 모으고, 촬영 직전에 부르며 남은 게 있으면 **FAIL 이 아니라 닫고 한 번 더**, 그래도 남으면 결과 json `covered` 에 목록. ⑨ 푸시 전 QC 의 배포 확인은 늘 "배포 버전 ≠ 로컬" WARN → `tools/push.sh` 가 푸시 뒤 **분리 프로세스**로 5분 기다려 `pw-deploy` 를 한 번 더 돌리고 `tools/_out/deploy-last.md`(날짜·판별 배포 버전·PASS/WARN·실패 단계) 에 남긴다. 다음 `qc` 는 그 파일을 읽어 "배포(푸시 뒤)" 줄로 보여 준다(사람이 다시 안 돌려도).

**파일**: 새 `saga-web/tools/playcheck/overlay.mjs`(`clearOverlays(page, game)` — `pw-phone-budget.mjs` 의 `clearIntro` 와 `pose-games.mjs`:10 의 것을 합침, 판별 차이는 표로: 4종횡은 Esc 금지·`DG.menuGrid.close`) · 부르는 쪽 `pw-look2d.mjs`·`pw-visual-close.mjs`·`pose-games.mjs`·`pose-sheet.mjs`·`pw-play.mjs`(촬영·HUD 겹침 전)·`pw-rts-shot.mjs`·`pw-gfx.mjs`·`pw-phone-budget.mjs`(자기 것 지우고 공용) · `tools/push.sh`(푸시 성공 뒤 `node tools/qc.mjs --deploy-later` 를 `setsid`/`start /b` 로 분리 — 셸이 끝나도 돈다) · `tools/qc.mjs`(`--deploy-later`: 300초 대기 → `pw-deploy` → `_out/deploy-last.md` / `checkDeploy()` 끝에 "배포(푸시 뒤)" 줄 — 파일이 있고 24시간 안이면 그 결과, 없으면 WARN "푸시 뒤 결과 없음")

**단계**: ① overlay.mjs(목록·닫기·남은 것) ② 여덟 스크립트 갈아 끼우기 — 자기 clearIntro 는 지움(중복 금지) ③ 재촬영 1회 규칙·`covered` 칸 ④ `--deploy-later` + push.sh 분리 실행(Git Bash 에서 `nohup … &` 또는 `cmd //c start //b`) ⑤ checkDeploy 줄 ⑥ 4종횡 서막 상태로 pose-games 를 돌려 `covered` 가 비는지, 한 번 푸시해 5분 뒤 `deploy-last.md` 가 생기는지

**검증**: `node saga-web/tools/playcheck/pose-games.mjs saga-story` 결과 `covered: []` 이고 PNG 에 메뉴·대화창 없음(눈) · `node tools/qc.mjs --branch web` 2D 한 장·3D 장면 줄 PASS(가려짐 0) · `bash tools/push.sh` 뒤 5분 → `tools/_out/deploy-last.md` 생김 · `node tools/qc.mjs --branch web --no-shots` "배포(푸시 뒤)" 줄 PASS

**완료 조건**: 공용 overlay 하나·개별 clearIntro 0 · 촬영 결과에 `covered` · push 뒤 자동 재확인 파일·qc 줄 · done/.
