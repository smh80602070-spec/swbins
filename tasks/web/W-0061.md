# W-0061 사가국지 RTS 화면을 스타크래프트식으로 — 하단 콘솔(미니맵·선택 정보·명령 카드)·우클릭 명령·가장자리 스크롤·부대 번호
종류: 새기능 · 웹(사가국지 RTS)      상태: **코드분 끝**(2026-10-05) — 사용자 눈 확인 대기("스타크래프트 화면 같은가")      등급 목표: D1→D2

**목표(한 줄)**: 사가국지 RTS(`rts.html`)의 화면 구성과 조작을 스타크래프트의 기본 문법(위에서 내려다보는 지도 + 맨 아래 한 줄 콘솔 + 우클릭 명령)에 가깝게 바꾼다. 에셋은 만들지 않는다.

**지금 상태(확인함, `css/rts.css`·`js/rts/view.js`)**
- 위에서 내려다보는 타일 지도는 이미 맞다. 그러나 HUD 가 흩어져 있다: 자원 줄 `#rts-top` 가운데 위, 속도 `#rts-speed` 오른쪽 위, 옵션 `#rts-opts`, 안내 `#rts-tip` 왼쪽 위, **도구 띠 `#rts-tools` 가운데 아래(건설 9칸)**, **미니맵 `#rts-mini` 오른쪽 아래(192×120, 떠 있음)**, 선택 정보 `#rts-sel` 왼쪽 아래(190px 상자).
- 조작: 왼쪽 드래그 = 상자 선택(있음), **오른쪽 클릭 = 이동 명령, 오른쪽을 끌면 지도 이동**(`pointerdown`·`up`, `view.js` 309~335), 가운데 버튼·Shift = 지도 이동, 휠 = 확대, 화살표·WASD = 지도 이동. 가장자리 스크롤·부대 번호(Ctrl+1)·공격 이동(A)·정지(S) 없음.

**제안(확정 — 사용자 되물을 것 없음, 단계는 쪼개서 간다)**
1. **하단 콘솔**(데스크톱): 화면 맨 아래 가로 한 줄 띠(높이 ~160px) — 왼쪽 미니맵(정사각 ~150px), 가운데 선택 정보(초상·이름·체력 막대·공격·방어, 여럿이면 작은 칸 격자), 오른쪽 **명령 카드 3×3**(건설 도구 9칸이 여기로 옮겨 들어가고, 군영을 고르면 생산 단추, 병사를 고르면 이동·정지·공격 이동). 위 가운데 자원 줄은 **오른쪽 위 한 줄**(금·식량·인구)로. 폰(폭 ≤ 780)은 지금 배치를 유지한다.
2. **조작**: 오른쪽 클릭 = 이동/공격 명령 고정(끌어도 지도는 안 움직임 — 지도 이동은 가운데 버튼·화살표·**화면 가장자리 스크롤**·미니맵 클릭). **A + 클릭** 공격 이동, **S** 정지, **Ctrl+1~9 부대 지정 / 1~9 호출**, **Space** 사건이 난 곳으로.
3. **전장 안개**(검은 막 + 한 번 본 땅은 어둡게)는 이 티켓에서 뺀다 — 규칙 층 변경이라 별도 티켓(필요하면 W-0062).

**파일**: `saga-realm/rts.html`(콘솔 마크업) · `css/rts.css` · `js/rts/view.js`(입력·콘솔 그리기, 33KB — 입력 부분만) · 새 `js/rts/console.js`(콘솔 그리기를 따로 — view.js 가 커지는 걸 막는다, `index.html`/`rts.html` 스크립트 목록·`manifest`·`gen-index` 갱신) · `_test.html`(진단) · `sw.js`. 상태 파일은 `js/rts/state.js`(세이브 키·id 불변).

**단계**: 1. 콘솔 마크업·CSS(하단 띠, 폰은 기존 유지) + 미니맵·선택 정보·명령 카드 옮기기 2. 입력 개편(오른쪽 클릭 고정·가장자리 스크롤·미니맵 클릭) 3. 단축키(A·S·Ctrl+숫자·Space) 4. 진단 + 헤드리스 촬영(1280×720·1920×1080, 폰 390×844 둘 다) 5. 눈 확인 시트.

**검증**: `node tools/test-web.mjs saga-realm`(사가국지는 180초 예산, 현재 통과 수에서 줄지 않을 것) 3 회 동일 · `precheck` OK · `playcheck` 으로 콘솔 촬영(미니맵·정보·명령 카드가 서고 건설 단추가 명령 카드에서 눌림, 오른쪽 클릭이 이동, 가장자리 스크롤).

**완료 조건**: 단계 1~5 · 사용자 눈("스타크래프트 화면 같은가"). 안 같다고 하면 어느 부분인지 한 줄 받아 다음 티켓.

**불변 규칙**: 세이브 키·id 불변 · 에셋 안 만든다(콘솔 틀은 CSS 로, 아이콘은 있는 K-0061 것) · 이름 정책 · 경영·문답 규칙 건드리지 않음(턴제 쪽 `ui-rtk` 안 건드림) · 도감 안 건드림.
