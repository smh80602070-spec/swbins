# W-0083 사가국지 확인 닫기 ① 내정·경제·재해·나이·보물·계략 — D1 6개 → D2
종류: 닫기 · 웹(사가국지)      상태: 작성됨(R-0 10-07, 사용자 "사가국지 확인 닫기")      등급 목표: D1→D2

**목표(한 줄)**: 사가국지 D1 25개(WIP 25/10 초과) 중 `rk.rtk-2`·`rk.rtk-3`·`rk.rtk-4`·`rk.officer-2`·`rk.data-item`·`rk.diplo-2` 를 실제 화면에서 한 번씩 해 보는 playcheck 로 D2 에 올린다(SAGA-ARCH §2 등급 규칙: D2 = playcheck 스크립트 + 결과 파일).

**파일**: `saga-web/tools/playcheck/pw-rk-domestic.mjs`(새) · `saga-web/tools/playcheck/results/pw-rk-domestic.json`(새, 생성물) · `saga-web/saga-realm/features.json`(위 6개 level·note 만)

**단계**
1. `pw-rk-domestic.mjs` — 준비는 `pw-rk-sheet.mjs` 13~27줄 그대로 복사(계정 → 이어하기 → `pick-scen` 첫째 → `pick-force` 첫째, `clearCards`·`nextMonth`).
2. 검사 6개(이름 앞에 feature id):
   - `rk.rtk-2` 내 첫 성에서 `DG.rtk.order(성, 무장, 'farm')` → 그 성 농업이 오른다. 그 성 농업을 `DG.rtk.capOf(성,'farm')` 로 맞춘 뒤 다른 무장으로 또 개간 → 값이 상한을 넘지 않는다.
   - `rk.rtk-3` 성 창의 `[data-act="trade"][data-dir="buy"]` 단추를 실제로 누른다 → 금이 줄고 군량이 는다. `DG.rtk.marketRate(성)` 이 0.35~0.7.
   - `rk.rtk-4` 내 성 하나에 `c.disaster = DG.rtk.DISASTERS[0].key` 를 넣고 ▶ 다음 달 → 보고 카드(또는 `monthReport`)에 그 재해 이름이 나온다. `DISASTERS.length === 5`.
   - `rk.officer-2` 무장 하나의 `DG.off.age(id)` 가 숫자이고, `birthYear` 가 130~178, 다음 해 1월까지 넘기면 나이가 1 오른다(▶ 다음 달 반복, 최대 12번).
   - `rk.data-item` `DG.item.ITEMS.length === 11` · 보물 하나를 `DG.off.equip` 으로 무장에 끼우면 `DG.off.stats` 능력이 `statBonus` 만큼 오르고 `unequip` 하면 돌아온다.
   - `rk.diplo-2` 금을 넉넉히 준 뒤 이웃 적 성에 계략 단추(`[data-act="plot"]` 첫째)를 실제로 누른다 → 금이 들고 결과 글(성공/실패)이 뜬다. `DG.diplo.PLOTS.length >= 4`.
3. 끝에 콘솔 오류 0 검사 + `results/pw-rk-domestic.json`(pw-rk-sheet 꼴).
4. `features.json` 6개: `level: "D2"`, note 앞에 `D2: saga-web/tools/playcheck/pw-rk-domestic.mjs n/n — results/pw-rk-domestic.json.` (기존 note 는 뒤에 남김).

**검증**: `cd saga-web/tools/playcheck && (node serve.mjs C:/swbins/saga-web 8871 &) && node pw-rk-domestic.mjs && node pw-rk-sheet.mjs` → 둘 다 실패 0(끝나면 그 서버 PID 만 끔) · `node tools/test-web.mjs saga-realm` RESULT n/n · `bash tools/precheck.sh` OK · `node tools/status.mjs` 에서 saga-realm D1 25 → 19.
