# W-0005 확인 시트 `status.mjs --sheet <판>`
종류: 측정      판: 웹 다섯      등급 목표: (체제) — D1·D2 → D3 로 올리는 유일한 길

**목표(한 줄)**: 판 하나의 `features.json` 에서 D1·D2 기능 10개를 골라 사람이 폰에서 10분 안에 볼 수 있는 시트(조작 3줄·기대 1줄·○/× 칸)를 `tasks/sheets/<판>-<YYYYMMDD>.md` 로 낸다.

**파일**: `tools/status.mjs`(`--sheet` 분기 추가) · `tools/features-schema.json`(`sheet` 칸 추가) · `tasks/sheets/.gitkeep`

**본보기**: `SAGA-ARCH.md` §3.2. 시트 한 줄 꼴: `| n | 기능 | 여는 법 | 조작 1·2·3 | 기대 | ○/× | 메모 |`.

**단계**
1. 스키마에 선택 칸 `sheet: {open: "<url 뒤 해시·쿼리>", steps: ["…","…","…"], expect: "…"}` 를 더한다(없어도 유효).
2. `--sheet <판>`: `level` 이 D1·D2 인 기능을 `since` 오래된 순으로 10개. `sheet` 가 있는 것을 앞에, 없는 것은 `조작 미작성` 으로 뒤에 둔다(그래도 표에 넣는다 — R-2 가 채운다).
3. `여는 법` 열: `https://smh8627-jpg.github.io/swbins/saga-web/<판>/index.html` + `sheet.open`. `_admin.html` QA 프리셋이 있으면 그 링크(`grep -n "preset" saga-web/<판>/_admin.html` 로 이름만 확인, 없으면 생략).
4. 머리에 3줄: 판 · 날짜 · "○/× 만 적어 주세요, 10개 넘게 보지 않아도 됩니다".
5. `--sheet` 결과를 `tasks/sheets/` 에 쓰고 경로를 찍는다. 같은 날 같은 판이면 덮어쓴다.
6. `sheet` 칸 첫 채우기는 이 티켓에서 **사가고 5개만**: PLAN §5 의 9필드 "UI·조작" 줄을 그대로 옮긴다(`grep -n "UI·조작" saga-web/saga-go/PLAN.md`).

**검증**
```
node tools/status.mjs --sheet saga-go   → tasks/sheets/saga-go-<날짜>.md 생성, 표 10줄, 앞 5줄에 조작이 차 있음
node -e "JSON.parse(require('fs').readFileSync('tools/features-schema.json'))"
```

**완료 조건**: 위 둘 · 시트 파일 3KB 안 · 다른 네 판도 `--sheet` 가 오류 없이(조작 미작성이어도) 나온다.

**불변 규칙 확인**: 게임 코드 수정 0 · features.json 은 사가고 5개 기능의 `sheet` 칸만 추가.
