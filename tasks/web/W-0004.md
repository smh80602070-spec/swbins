# W-0004 precheck 게이트 확장
종류: 통합      판: 저장소 전체      등급 목표: (체제) — 뒤 티켓이 기대는 문

**목표(한 줄)**: `tools/precheck.sh` 에 문서 상한 전체·파일 크기·features/티켓 검사·`--full` 러너를 넣어, 규칙 위반 커밋을 기계가 막는다.

**파일**: `tools/precheck.sh` · `tools/hooks/gate.js`(PreToolUse Edit 검사에 티켓 2KB 한 줄) · `tools/README.md`(표 갱신)

**본보기**: 지금 `precheck.sh` 의 `limit()` 함수와 "== 문서 크기" 절. 같은 꼴로 늘린다.

**단계**
1. 문서 상한 추가(FAIL): `saga-godot/PLAN.md` 102400 · `saga-unity/PLAN.md` 102400(지금 217KB·372KB 라 **당장 FAIL 한다** → 이 둘만 이번 커밋에서 `WARN` 으로 두고 값을 적어 둔다, K-0002 뒤 FAIL 로) · `SAGA-ARCH.md` 40960 · `SAGA-BACKLOG.md` 30720 · `tasks/**/*.md` 4096 · `saga-web/STATE.md`·`saga-godot/docs/STATE.md`·`saga-unity/docs/STATE.md` 8192(없으면 건너뜀) · `tools/char-forge/README.md` 16384(지금 107KB → WARN, archive 뒤 FAIL).
2. 파일 크기(FAIL): 이번 커밋에서 바뀐 `saga-web/*/js/*.js`(vendor 제외)·`saga-godot/**/*.gd`·`saga-unity/Assets/**/*.cs`(Library 제외) 중 **새로** 1,500줄을 넘는 파일. 이미 넘던 파일은 `tools/big-files.txt`(이 티켓에서 생성: 지금 1,500줄 초과 목록)에 있으면 줄 수가 **늘었을 때만** FAIL. 바뀐 파일 목록은 `git diff --cached --name-only` + 인자 폴더.
3. features(FAIL): `saga-web/*/features.json` 이 있으면 `node -e` 스키마 검사(W-0002 검증 한 줄을 그대로 옮김).
4. 진단 수(WARN): `_test.html` 의 `grep -c "t('"` 가 `tools/_out/testcount.json`(이 티켓에서 생성) 보다 줄면 WARN 하고 파일을 갱신.
5. `--full`: W-0001 이 이미 넣은 분기 유지. 인자 파싱은 지금 `targets` 배열 앞에서 `--full` 만 빼낸다.
6. gate.js: `PreToolUse Edit/Write` 에 `tasks/**/[WGUK]-*.md` 가 4096B 를 넘으면 block(메시지 한 줄).
7. `saga-godot/tools/check_refs.sh` 가 있으면(G-0003 산출) precheck 가 부르고 종료 1 이면 FAIL(없으면 건너뜀).
8. `tools/README.md` 점검 표의 precheck 줄을 새 항목으로 갱신.

**검증**
```
bash tools/precheck.sh                              → PRECHECK OK (Godot·Unity PLAN·char-forge README 는 WARN 줄로 보임)
echo x >> saga-web/saga-story/js/game.js 를 하지 말고, 대신 임시로 tools/big-files.txt 에서 한 줄을 지운 뒤 bash tools/precheck.sh → 그 파일 FAIL 확인 → git checkout -- tools/big-files.txt
```

**완료 조건**: 위 둘 · `tools/big-files.txt`·`tools/_out/testcount.json` 생성(`_out` 은 gitignore, big-files 는 커밋) · gate.js 티켓 크기 block.

**불변 규칙 확인**: 게임 코드 수정 0 · precheck 기본 실행 시간이 지금보다 5초 이상 늘지 않는다(`time bash tools/precheck.sh`).
