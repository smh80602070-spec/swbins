# W-0499 1만리·2나락 맵을 3마을처럼 — 성김·넓음·로딩 없음 (사용자 10-29 「전부 3마을식」)
종류: 화면·기능 · 웹      상태: 진행(1단계 1만리 끝)      등급 목표: D2

## 목표
1만리 2D·2나락이 3마을처럼 오브젝트·몹이 듬성듬성하고, 조금 걸었을 뿐인데 불러오기 막이 뜨지 않는다.

## 단계(서로 독립)
1. 밀도 손잡이 — 1만리 `go.propDens`(소품 확률 배율 기본 0.45)·`go.spawnDens2d`(2D 야생 상한 배율 0.65, 14→9). 2나락 `dg3d.fieldDens`·소품 쪽은 아직. 몬스터(`dg.fieldCap` 18)는 사용자가 2를 기준으로 삼았으니 그대로.
2. 3마을식 바이옴 큰 셀 + 빈 땅 게이트(BIOME_CELL 22칸, hgate 0.55) — 1만리 `field2d.propsAt`·2나락 `field3d.kindOf/chunkAt`.
3. 로딩 막 줄이기 — 1만리 `zone-wire.js` 구역 경계 `cut`·`go.zoneBuild`, 2나락 `load-veil.js` `region:enter` 막(`dungeon.zoneCut`). 첫 진입 한 번만 허용, 솟음은 `mode2d.fadeIn`.
4. (선택·위험) 유한 맵화 — `save.player.pos`·`town.seen` 깨짐. 1~3 효과를 본 뒤.

## 파일·검증
`saga-web/saga-go/js/field2d.js`·`src/world/01.js`·`zone-wire.js` · `saga-dungeon/js/field3d.js`·`load-veil.js` · 진단 `node tools/test-web.mjs saga-go|saga-dungeon` · 폰 실기.
