# W-0013 사가고 회피 여유 진단 + 타격음 측정 바로잡기
종류: 측정(새기능에서 재정의) · 사가고      상태: **작성됨**(R-0 완료 2026-10-01)

**목표(한 줄)**: BACKLOG 의 "회피 거저·타격음 단일" 전제가 코드와 다르다는 것을 값으로 못박는다 — 회피 여유(초)를 재는 진단 1개를 더하고, W-0012 의 `재미표준 C` 가 타격음을 잘못 센 것을 고친다. **게임 값은 안 바꾼다**(조일지는 사람 실기 판단).

**확인한 사실(코드)**: ① 타격음은 이미 **3종 라운드로빈**이다 — `audio.js` `HIT_RATES = [0.92, 1.0, 1.12]`(같은 mp3 를 음높이 셋으로, 원작 에셋 금지 규칙 때문), `DG.audio.HIT_RATES` 로 내보냄. W-0012 C 는 mp3 **파일 수**(1)를 세서 △ 가 됐다(오판). ② 회피는 거저가 아니다 — `rogue-action.js foeMoves()`: 강타 예고 1.1s·반경 5.5×1.55=8.525m, 돌진 0.825s·8.8m, 휩쓸기 1.485s·13.475m. 필요 거리 = 반경 − `MY_REACH()`(3.0m), 걷기 8m/s(`world.js speed`) → 여유 = 예고초 − 필요거리/8 ≈ **강타 0.41s · 돌진 0.10s · 휩쓸기 0.18s**(사람 반응 0.25s 안팎이라 돌진·휩쓸기는 미리 움직여야). 저스트 창 `JUST_WINDOW()`=0.25s(토벌). 원신식 들판 전투는 스태미나 20·무적 0.35s(`field-combat.js`). BACKLOG/PLAN §4 의 "5.5m·1.1s" 는 옛 기본값이다.

**파일**: `saga-web/saga-go/_test.html`(진단 1개 추가 + C 진단 고침) · `saga-web/saga-go/features.json`(`go.rogue-action` `fun.C`)

**단계**
1. W-0012 `재미표준 C 손맛(측정)`: `hit`·`hit2`·`hit3` mp3 존재 확인을 `DG.audio.HIT_RATES`(서로 다른 값 개수 ≥3)로 바꾼다. 문자열을 "타격음 3종(음높이 …)" 으로. 그러면 hitstop 70~110 과 합쳐 ○.
2. 새 진단 `재미표준 C 회피 여유(측정)`: `DG.rogueAction.foeMoves()` 각 항목마다 `slack = tellSec − max(0, range − MY_REACH()) / 8` 를 구해 `키 slack초` 로 나열. 판정: 가장 작은 slack ≥ 0.25 → `○`, 0 이상 0.25 미만 → `△ — 미리 움직여야 함`, 음수 → `× — 못 피함`, 모든 slack > 0.6 → `× — 거저`. 지금 값이면 `△`. **게임 값은 읽기만**.
3. `features.json`: `go.rogue-action` `fun.C` 를 `○` 로.
4. 진단 수 836→837(새 1개), 실패 이름은 기존 불안정 1개 이하.
