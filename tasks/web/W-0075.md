# W-0075 갈래별 작업 폴더(git worktree) — 한 저장소, 갈래마다 제 트리·제 세션
종류: 도구(체제) · 공통(이 티켓이 tasks/README·QUEUE·루트 CLAUDE.md·.claude/settings 손대기를 허락한다)      상태: **작성됨**(2026-10-06, 사용자 "워크트리 방식으로 티켓 만들어줘")      등급 목표: D2

**목표(한 줄)**: 네 갈래(웹·고돗·유니티·자체툴) 세션이 한 작업 폴더(C:\swbins)를 같이 쓰며 생기는 충돌(남의 미커밋 파일이 pull·rebase·precheck 를 막음, autostash 가 남의 변경을 먹음, 낡은 사본이 되돌림처럼 보임)을 **갈래마다 제 worktree 폴더**로 없앤다. 저장소·origin·Pages 는 그대로 하나.

**왜(확인함, 10-06)**: 오늘 한 세션에서 pull 차단(자체툴 미커밋) 2회·push 거부 2회(sw.js 버전 겹침)·고돗 done/ 이동이 되돌림처럼 보임 1회. 메모리 함정 7개 남짓이 같은 원인(`feedback_push_rejected_shared_dirty_tree`·`feedback_autostash_eats_uncommitted`·`feedback_worktree_commit_gate_checks_main_tree`·`saga_main_tree_stale_hook_block_1002` 등). 고돗·유니티를 다른 저장소로 옮기는 안보다 싸다(K 배치·precheck·문서 경로 그대로).

**확인한 사실**
- 훅: `.claude/settings.json`(추적됨)이 `node tools/hooks/gate.js` 를 **세션 폴더 기준**으로 부른다 → 세션을 worktree 폴더에서 켜면 precheck 도 그 트리를 본다(지금 "worktree 커밋도 메인 트리 검사" 문제의 원인 = 세션을 메인에서 켜고 worktree 에 커밋했기 때문).
- Claude 메모리는 프로젝트 경로별(`~/.claude/projects/C--swbins/memory`) — 새 폴더에서 켜면 메모리가 안 따라온다.
- `C:/swbins` 박힌 파일 42개(추적, archive·md 제외): `saga-web/tools/playcheck` 22 · `tools/ai-art/batches` 18 · world-forge 1 · saga-godot/tools 1.
- 엔진 캐시(`saga-unity/Library`·`saga-godot/.godot`)·로컬 전용물(인물 변환본 — `tools/char-forge/setup_local.sh`, VRoid 설치물, certs)은 gitignore — 새 트리엔 없다. 유니티 Library 는 매우 커서(du 가 5분 넘게 못 끝냄) 옮기면 재임포트가 길다.
- 지금 남의 worktree `C:/wtk`(자체툴 세션) 하나가 있다 — 건드리지 않는다.

**배치(제안 — 단계 0 에서 확정)**
| 갈래 | 폴더 | 이유 |
|---|---|---|
| 유니티 | `C:\swbins`(메인, 그대로) | Library 가 가장 커서 안 옮긴다 |
| 고돗 | `C:\sw-g` | .godot 재임포트 한 번 + setup_local |
| 웹 | `C:\sw-w` | 캐시 없음, 서버 포트 8791~8795 는 이 갈래만 |
| 자체툴 | `C:\sw-k` | `_src`·`_out` 같은 로컬 전용 큰 폴더는 junction(`mklink /J`)으로 메인 것을 가리킨다 |
짧은 경로 + `git config core.longpaths true`(메모리 함정). 각 트리는 제 브랜치 `lane/<갈래>`(origin/main 추적).

**파일**: 새 `tools/worktree/setup.sh`(트리 만들기·junction·메모리 연결·멱등) · `tools/worktree/sync.sh`(pull --rebase → push HEAD:main, 거부되면 한 번 더) · `saga-web/tools/playcheck/*.mjs`·`tools/ai-art/batches/*.json` 등 절대 경로 42 → 스크립트 기준 상대 경로 · `tasks/README.md`(절차 ④ 커밋·푸시) · `tasks/QUEUE.md`(표에 "작업 폴더" 칸) · 루트 `CLAUDE.md` git 절 · `tools/hooks/gate.js`(SessionStart 에서 지금 폴더 ↔ 갈래 안내, 남의 갈래 경로 커밋 경고).

**단계**
0. 잼: 엔진 캐시·로컬 전용 폴더 목록과 크기(`git status --ignored` 갈래별) → 위 배치표 확정을 티켓 메모에. 남의 세션이 돌고 있으면(트리 dirty) 만들기만 하고 메인은 안 건드린다.
1. `setup.sh <갈래>`: `git worktree add -b lane/<갈래> <폴더> origin/main` · longpaths · 로컬 전용 junction · `~/.claude/projects/<폴더키>/memory` 를 `C--swbins/memory` 로 junction(메모리 공유) · 이미 있으면 아무 것도 안 함.
2. 절대 경로 42개 → `path.resolve(__dirname, …)`·배치 json 은 저장소 기준 상대(읽는 코드가 루트를 붙인다). `git grep -i "c:/swbins[^234]"` 0(md·archive 제외).
3. `sync.sh`: 제 트리는 제 파일만 dirty 라 `pull --rebase` 가 안전 — 커밋 뒤 `sync.sh` 한 줄로 rebase·push. 문서 절차를 이걸로 바꾼다(`-- <경로>` 커밋 규칙은 유지).
4. gate.js SessionStart: 폴더 → 갈래 표시("이 폴더 = 웹 갈래"), 커밋 경로가 다른 갈래 경로면 경고(막지는 않음 — 티켓이 명시한 공통 파일 때문).
5. 문서: tasks/README·QUEUE 표·루트 CLAUDE.md git 절 갱신(≤6KB 유지). 사용법 한 줄 "웹은 `cd C:\sw-w && claude`".
6. 사람 몫 한 줄(시트): 각 갈래를 새 폴더에서 한 번씩 켜 보기 — 바탕화면 바로가기는 사용자 선택.

**검증**: 각 트리에서 `bash tools/precheck.sh` OK · 웹 트리 `node tools/test-web.mjs all` 전과 같은 수 · 두 트리에서 동시에 작은 문서 커밋 → 둘 다 `sync.sh` 로 푸시 성공(거부 0, autostash 0) · 웹 트리 세션에서 `git commit` 시 훅 precheck 가 **그 트리**를 검사(메인에 깨진 파일을 일부러 둬도 웹 커밋 통과) · `git grep` 절대 경로 0 · 메모리 MEMORY.md 가 새 폴더 세션에서 보임.

**완료 조건**: 단계 0~5 · 네 갈래 폴더 생성(유니티는 메인) · 검증 전부 · 메모리 함정 항목에 "W-0075 뒤로는 해당 없음" 한 줄.

**불변 규칙**: origin·브랜치 main·Pages 경로 그대로 · 남의 worktree(`C:/wtk`)·남의 미커밋 파일 건드리지 않음 · 엔진 캐시 지우지 않음 · `.gitignore` 의 certs 규칙 유지 · 강제 푸시 금지.
