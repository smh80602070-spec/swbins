# W-0384 4종횡 자동 사냥이 "들판을 비운다" 에서 줄만 오르내리고 남은 적이 안 준다(첫 10분 막힘)
종류: 버그 · 웹(4종횡)      상태: **초안**(10-23 W-0381 첫 10분 점검이 찾음 — 나머지 칸은 R-0)

**재현**:
1. `node saga-web/tools/playcheck/pw-first10.mjs saga-story --min=10`(새 계정 → 자동 퀘스트 ▶)
2. 사명 "📜 들판을 비운다" 에서 "⚔️ 허창 들판 · 남은 적 10" 뒤로 4분 넘게 "🪜 줄을 타고 올라간다 / 내려간다" 만 되풀이 — 남은 적 수가 안 줄어듦
3. 끝에 이야기 창(story)·건너뛰기 단추가 남아 있음(점검 도구가 15초마다 닫는데도 다시 뜸) — 이야기 창이 자동 사냥을 쉬게 하는지 함께 볼 것

**기대**: 자동 사냥이 남은 적이 있는 발판으로 가서 들판을 비우고, 첫 10분 안에 사명이 넘어간다.

**메모**: 결과 `saga-web/tools/playcheck/results/pw-first10.json` log · 원인 후보 = side 자동의 발판 고르기(가장 가까운 적이 위·아래 층을 번갈아 바뀜) 또는 이야기 창이 열려 있는 동안 자동이 멈춤.
