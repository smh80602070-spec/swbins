# W-0102 사가나락 — 은총 자리 + 사망 카드 + 2분 복귀 (리뉴얼 ②, 엘든링 참고 · 재미표준 F)
종류: 새기능 · 웹(사가나락)      상태: 작성됨(R-0 페이블 2026-10-07)      등급 목표: D2

**목표(한 줄)**: 죽음이 "끝" 이 아니라 루프가 되게 — 층마다 첫 방의 사당(`room.shrine`, 방 종류 `'shrine'`)이 **은총 자리**가 되어, 쓰러지면 **사망 카드 3줄**(어디서·누구에게·무슨 피해 + "남는 것: 도감·인물·공적") 뒤 「은총에서 다시」 한 번으로 그 층 은총 자리에서 재시작한다(유품은 그 자리에 그대로, 적은 다시 선다). 재미표준 F 규격(사망→재도전 조작 ≤3 · 회복 ≤2분) 을 채운다. PLAN §4 "가장 큰 구멍 1 루프 부재(A·B·F)".

**설계(페이블)**
- 은총 = 층당 1(첫 방 shrine 자리, 없으면 첫 방 들머리). 밟으면 `run.grace = {floor, roomIdx}` + 체력 100%(물약 그대로). 사당 기능(`shrine.used`)은 그대로 둔다 — 은총은 그 위에 "표식" 만 얹는다.
- `die()`(결사·난입·부적·시련 분기 **뒤**, 보통 사망만): 유품 남기기(기존)는 그대로 → `core.emit('dungeon:end', {reason:'dead', …, where:{floor, room, enemy, dmgKind}})` 에 **어디서·누구·무슨 피해**를 얹는다(마지막 피해를 `run.lastHit = {enemy, kind}` 로 strike 쪽에서 기록).
- 카드(`goals.js buildCard` dead 분기): `card.where·who·how` 세 칸 + `card.keep = '도감·인물·공적은 그대로'` + `card.next = '제N층 은총에서 다시(유품 회수)'` + `card.restart = true`.
- 화면(`ui.js` 세션 카드, 806행 부근 '💀 패퇴했다'): 세 줄 표시 + 「🕯️ 은총에서 다시」 단추 → `dungeon.restartAtGrace()` = 같은 층 `enter({floor, atGrace:true})` 한 번(조작: 카드 → 단추 → 시작 = 2회). 결사·난입·부적은 단추 없음.
- 재미표준 F 측정 진단(사가만리 `_test.html` "재미표준 F 실패와 회복(측정)" 꼴)을 이 판에도: 비용 = 유품(노획물 100%, 상한 없음 — 회수 가능하니 규격의 "10~20% 소지 재화" 와 같은 결)·복귀 조작 2·회복 ≤2분(restartAtGrace 가 즉시).

**파일**: `saga-web/saga-dungeon/src/dungeon/02-run.js`(enter·descend·run 구조 — `grace`·`atGrace`·`restartAtGrace`) · `saga-web/saga-dungeon/src/dungeon/03-items.js`(134행 `die()` — where 얹기) · `saga-web/saga-dungeon/src/dungeon/04-field.js` 또는 strike 가 있는 조각(`run.lastHit` 기록 — 단계 1 grep `strike(` 로 확정) · `saga-web/saga-dungeon/js/goals.js`(248행 `buildCard`) · `saga-web/saga-dungeon/src/ui/*.js`(세션 카드 그리기 — 정본은 src, `js/ui.js` 는 산출) · `saga-web/saga-dungeon/_test.html`(진단 4 + F 측정) · `saga-web/saga-dungeon/features.json`(`dg.dungeon-9` 새) · `saga-web/saga-dungeon/PLAN.md` §5.2 보강 세 줄 · `sw.js` VERSION

**단계**
1. 02-run: `run.grace` 세팅(첫 방 진입·shrine 밟기) · `enter(opts)` 에 `atGrace` → 그 층 그 방에서 시작, 적 재배치 · `restartAtGrace()` 공개. strike 조각에 `run.lastHit`.
2. 03-items `die()` 보통 사망 분기에 where/who/how 얹기(유품 로직 불변). goals `buildCard` 세 칸 + restart.
3. ui 카드: 세 줄 + 단추(결사·난입·부적·시련은 없음). 조립·번들·sw.
