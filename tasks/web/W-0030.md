# W-0030 사가국지 RTS P2 — 시설(우물·망루·성벽)·행복·세율·수요·보기 겹침
종류: 새기능 · 웹(사가국지)      상태: **코드분 끝**(2026-10-03) — 사용자 눈 확인 대기      등급 목표: D1→D2

**목표(한 줄)**: W-0028 P2. P1 샌드박스에 심시티의 **"도시가 살아 있다"** 층을 더한다 — 시설이 주거를 행복하게 하고, 세율이 금과 행복을 맞바꾸며, 수요가 "무엇을 더 지을지" 알려 준다.

**파일**: `js/rts/rules.js`(건물 표 +우물·망루·성벽, `free` = 도로 불필요) · `js/rts/econ.js`(행복·생산 배율·세율·수요, 순수 함수) · `js/rts/state.js`(`tax` 저장·복원, 옛 저장은 보통) · `js/rts/view.js`(도구·행복·수요 막대·세율 단추·보기 겹침) · `css/rts.css` · `_test.html`

**규칙**
- 우물 💧 25금 반경 6 행복 +20 · 망루 🗼 40금 반경 8 행복 +10(유지비 1) · 성벽 🧱 4금 방어 5(전투는 P3). 반경 안(시설 중심↔주거 중심 거리)의 주거만 오른다. 셋 다 **도로 없이** 선다.
- 행복 = 50 + 주거 평균 시설 보정 + 식량(넉넉 +8·모자람 −15) + 세율(낮음 +12·높음 −20) − 과밀(−5) − 실업(−8), 0~100. 생산 배율 = 0.8 + 0.4×행복/100(50 = ×1.0). 행복 25 미만이면 하루 5%가 떠나고, 높을수록 이민이 빠르다.
- 세율: 낮음 0.2 · 보통 0.4 · 높음 0.7 금/인구/일. 수요(0~1): 주거·일터·식량 — 막대가 길수록 더 지어야 한다.
- 보기: 없음 · 행복(주거 칸 색 빨강→초록+숫자) · 닿는 범위(우물·망루 원, 닿은 주거 초록 테두리). 우물·망루를 놓을 때 반경 원이 따라온다.

**검증**: 진단 +4(280 → 284) · 폰 점검 0건 · precheck OK · 헤드리스로 시설 12개를 놓고 세율 낮음(행복 92)↔높음(행복 60, 금/일 9→18.9)·두 보기 겹침 확인.

**완료 조건**: 시설·행복·세율·수요·겹침이 돌고 저장에 세율이 남는다 · 턴제 진단 그대로 · 사용자 눈 확인(재미).
