**목표(한 줄)**: W-0107 규칙 층을 화면에 올린다 — 개입형 전투(`war.js` 629행 `marchInteractive` 의 ⚔️돌격·🛡️수비·➡️정공·↩️퇴각) 에 다섯째 명령 **「♟️ 전술」** 을 더해, 고르면 6×8 격자 판이 뜨고(2D SVG — `map2d.js`·`ui-rtk.js` 지도와 같은 그리기 결, 3D 아님) 3턴을 손으로 두며, 끝나면 `tactics.apply` 보정값을 그 공략 판정에 넣는다. 전사한 장수는 「열전」(명부 화면 한 줄 + 사연 카드 1장) 에 남는다.

**설계(페이블)**
- 「전술」 은 **플레이어 출진만**(개입형 전투 규칙 그대로), AI 끼리는 없다(규칙 층 `outcome` 을 AI 가 자동으로 돌리지도 않는다 — 판정 두 벌 방지).
- 판 화면: 48칸 SVG, 지형 색은 지도 팔레트(`SAGA-DESIGN §6.0`), 유닛은 장수 초상 원형(`portrait3d` 이름표 자리 그대로) + hp 띠. 칸 누르기 → 이동 가능 칸 밝힘 → 적 누르기 → 명중 % 글 → 공격. 「턴 끝」·「물러나기」(= 무승부로 끝) 단추. 폰 세로에서 칸 ≥ 44px(PLAN §2.4).
- 결과 카드: 전술 결과 한 줄 + 보정값 → 기존 공략 결과 카드로 이어짐. 전사 → `save.rtk.annals` 기록 + 사연 카드 1장("○○, ○○성 아래에서 쓰러지다" — 가명).
- 명부(`officer` 화면)에 「열전」 탭 또는 줄: 전사자 목록(언제·어디서·누구에게).
