# W-0497 2D 모드 탈것 — 말 3·학·푸른 용 타고 다니는 모습(사용자 10-29)
종류: 기능 · 웹(2나락 먼저)      상태: 초안

**까닭**: 2나락 `mount.js` 에 탈것 5종(말 3 지상 · 학·푸른 용 비행)이 있으나 2D 모드엔 탈것을 그리는 코드가 없다(`mount.js` 는 3D 몸 `bodyRef` 만 씀, `actor2d.js`·`mode2d.js` 에 탈것 처리 없음). 시트는 K-0206 이 만든다.
**파일**: saga-web/saga-dungeon/js/mount.js(`current`·`isFly`·`bodyRef`·`lift`) · saga-web/saga-dungeon/js/actor2d.js(인물 그림 자리) · saga-web/saga-dungeon/assets/sprites2d_sheets/index.json · saga-web/saga-dungeon/js/core.js(`mode2d.poolH`)
**단계**: ① (K-0206 끝난 뒤) `mt_*` 풀 poolH 를 `pw-sheet-bbox.mjs` 로 재서 core.js 에 ② actor2d: `mount.current()` 가 있으면 탈것 풀(`mt_*`)을 먼저 그리고 그 위에 주인공(`elf_001` 앉기 `sit` 또는 서기)을 안장 높이에 겹쳐 그림 — 방향은 탈것과 같게 ③ 비행(학·용)은 `lift` 만큼 띄우고 그림자 유지 ④ 손잡이 `mount2d.on` 기본 0(옛 그대로)로 시험 → 눈 확인 뒤 1
**검증**: `node tools/test-web.mjs saga-dungeon` RESULT n/n · `node saga-web/tools/playcheck/pw-look2d.mjs saga-dungeon <png>` 로 말 타기·학 타기 촬영 · `node tools/qc.mjs --game saga-dungeon`
**완료 조건**: 말 3·학·용을 타면 2D 에서 탈것 + 주인공이 8방향으로 보이고 내리면 사라짐 · 손잡이 0 이면 옛 화면 그대로 · 3D 는 안 건드림
**불변**: 세이브 키·`save.mount` 모양 · 3D 탈것 · 에셋은 안 만든다(K-0206 몫)
**대기**: K-0206
