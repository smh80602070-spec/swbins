# W-0028 사가국지 RTS 개편 — 심시티(도시 건설)+스타크래프트(실시간 전투) 설계(R-0)
종류: 새기능 · 웹(사가국지) · 설계      상태: **진행중**(R-0 2026-10-03, 사용자 결정) — P0·P1 = W-0029, P2 = W-0030, P3a = W-0031 코드분 끝, 다음 P3b(전투·습격)      등급 목표: D1(단계마다)

**사용자 결정(2026-10-03)**: "건설 시뮬도 있고 전투도 있고, 전략 시뮬레이션 — 스타크래프트 같은 느낌, **심시티+스타크래프트**". 선택: ① 전체를 **실시간 전략(RTS)** 으로 개편 ② 건설은 **기지 건설(지도 위 자유 배치)**. 이전 W-0027(턴제 전략 HUD)은 방향이 바뀌어 **코드분 끝에서 멈춘다** — 패널·배너·미니맵·영토 면은 재사용 후보.

**목표(한 줄)**: 지도 위에 도로·구획·건물을 직접 놓아 도시를 키우고(경제·인구·세금), 그 힘으로 유닛을 뽑아 실시간으로 싸우는 한 판 — 시간이 흐르는 지도, 드래그로 부대 선택, 일시정지·배속.

**버리지 않는 것(재사용)**: 장수 258명(능력치 무·지·통, 특성)·세력·시나리오 11단계 얼개·지도 지리(성 135곳)·초상·전투 계산 일부·세이브 키 `saga-realm/save/<프로필>`(불변). 장수는 **영웅 유닛**이 된다.

**핵심 설계 안(R-0 권장 — 사용자가 뒤집을 수 있음)**
1. **지도**: 지금의 SVG 점 지도 대신 **격자 타일 지도**(예 128×96, 타일 = 지형 하나)를 2D 캔버스로 그린다. 성 135곳은 **거점**(점령하면 그 둘레 반경이 내 땅이 되어 건설 가능)으로 유지 — 실제 지리는 그대로.
2. **건설(심시티)**: 도로 → 구획(주거·농지·시장·공방·군영)·시설(우물·창고·성벽·망루) 배치. 구획은 도로에 닿아야 돌고, 인구·세금·식량·금이 시간당 쌓인다. 수요(주거↔일자리↔식량)를 숫자와 색(히트맵)으로 보여 준다.
3. **전투(스타크래프트)**: 유닛은 군영 건물에서 **생산 큐**로 나온다. 드래그 박스 선택·우클릭 이동/공격·사거리·상성(보병>창>기병>궁…, 성벽·망루 보정)·집결지. 영웅 유닛은 스킬 1개.
4. **시간**: 고정 틱(10Hz) 시뮬 + 렌더 분리, 일시정지·1×/2×/4×. 한 판 20~40분 목표.
5. **AI 세력**: 건설 순서 스크립트 + 일정 주기 공격 파도. 난이도 3단.
6. **시점·그림**: 2D 탑다운(또는 얕은 사선) 캔버스 — 3D 지도(`realm3d`)는 이 모드에서 쓰지 않는다. 건물·유닛·지형 스프라이트가 대량으로 필요하므로 **에셋은 K 티켓**(K-0060 확장 + 신규).
7. **호환**: 새 모드는 `save.rts` 칸을 새로 쓰고 기존 턴제 코드는 **RTS 가 동등해질 때까지 그대로 둔다**(삭제 안 함, 기본 모드만 나중에 바꾼다). 세이브 키·성 id 불변.

**단계(각각 새 W 티켓, 모두 진단+폰 점검+precheck)**
- P0 이 문서 확정·모듈 뼈대(`js/rts/` 새 폴더, 큰 파일 한도 지킴)
- P1 격자 지도·카메라(이동·확대·미니맵)·**건설 샌드박스**(도로·구획·건물, 자원 틱) — 먼저 "심시티 부분"만 재미가 있는지 본다
- P2 인구·세금·수요 경제 루프, 일시정지·배속
- P3 유닛 생산·선택·이동(경로)·전투
- P4 AI 세력·시나리오 연결(장수 영웅 유닛, 승리 조건)
- P5 세이브·폰 입력(탭·드래그·핀치)·성능(유닛 300+)·밸런스

**위험**: 규모가 **판 하나를 새로 짜는** 수준(턴제 코어 ~2만 줄과 별개) · 경로 탐색·충돌·선택 UX · 폰에서 RTS 조작 · 에셋 양 · 이름 정책(원작 이름·에셋 금지, **문법만**). 경영·문답은 `saga-realm` 안에서만(이미 규칙).

**결정된 기본값(10-03 "응 순서대로 해봐" — 권장안 채택)**: ① 턴제는 RTS 가 동등해질 때까지 **보존**(새 입구 `rts.html`, 기본 전환은 나중) ② 한 판 20~40분·난이도 3단 ③ **PC 우선**(마우스 드래그·휠), 폰은 탭·끌기·핀치로 같은 조작을 받는다 ④ 자원은 **식량·금 2종**(뒤에 목재·철 검토).

**검증(R-0)**: 이 문서가 끝. 다음 세션이 P0 티켓을 쓴다. 규칙 변경이 없으므로 precheck 만.
