# W-0500 2D 맵 형식 맞추기 — 2나락·3마을 바깥을 1만리 들판식으로 · 1만리 건물을 사람 키에 맞게(사용자 10-31)
종류: 그래픽(2D 지도)      상태: 작성됨(10-31 Opus R-0)      등급 목표: D2

**사용자 말**: "2d 버전은 2,3은 1나락 맵 형식으로 변경 하고 1나락 건물은 사람 크기에 맞게 수정" — "1나락" = 1번 판(1만리)으로 읽음.
**목표**: ① 1만리 2D 건물(역참·성채·랜드마크)을 사람 키 기준 공용 크기 표로 ② 2나락 2D 바깥(마을·세계 지도 들판)을 1만리 `field2d.js` 식(48 칸 땅 종류 타일 → 결 → 경계 → 소품, 좌표 해시라 안 지글거림)으로 ③ 3마을 2D 마을 땅도 같은 식. **3마을 구면 투영은 걷어낸다**(사용자 10-31 「구면 투영 유지하지마」 — 땅이 휘지 않는 1만리식 평면 탑다운으로, 집 안은 원래 안 휨), 2나락 던전 굴혈 안은 그대로.
**파일**: 1만리 `saga-web/saga-go/js/core.js`:484(`unitH: 50, scale: { house: 2.2, tower: 3 }` — 공용 `shared/js/mode2d.js` SCALE house 2.6·tower 4 보다 낮춤) · `world.js`:1514 `bodyK()`·1606 랜드마크 그리기 · 2나락 `saga-dungeon/js/town.js`·`world-map.js`·`dungeon-view.js`(바깥 그리기 갈래만)·`core.js` `cfg.mode2d.tile` · 3마을 `saga-forest/js/village-view.js`(`project()`·`unproject()`·`horizonY`·R0)·`autotile2d.js`·`core.js` `cfg.mode2d.tile`·`saga-forest/PLAN.md` 구면 절·루트 `CLAUDE.md` "구면 투영 되돌리기 금지" 줄(이 티켓이 사용자 결정으로 지움) · 판별 `_test.html` 진단 하나씩. 본보기 = `saga-go/js/field2d.js`(①~④ 머리글). 그림은 있는 타일(`dungeon_*`·`forest_*`·`go_*`)만, 모자라면 수신함 K 줄(이 갈래는 그림 안 만듦).
**단계**: ① 1만리 — 화면에서 사람 몸 높이(px)와 집·탑 높이를 PC·폰 두 배율로 재 표로 적고, core.js 판 표를 지워 공용 2.6·4 를 쓰거나 잰 비율로 판 값 조정, 건물에도 몸과 같은 `bodyK` 배율이 걸리는지 확인 ② 2나락 — 마을·들판 바깥 칸을 땅 종류 → 타일·경계·소품 순서로 그리는 길을 field2d 에서 옮기거나 shared 로 빼서 부른다(던전 방은 옛 길) ③ 3마을 — `project()`/`unproject()` 의 구면(원통 휨·좌우 처짐·지평선)을 평면 탑다운으로 바꾸고 땅 칸을 같은 순서로(autotile 이음 유지, 나무·집·사람도 같은 투영을 타 어긋남 없게, 클릭 좌표도 함께) ④ 판마다 진단 1 + QC.
**검증**: `node tools/test-web.mjs saga-go`·`saga-dungeon`·`saga-forest` 각 RESULT n/n(진단 +1씩: 1만리 "집 높이 ÷ 사람 높이 = 표 값 ±10%", 2나락 "마을 바깥 칸이 field 타일 길로 그려짐", 3마을 "project() 가 평면(칸 간격 일정·지평선 없음) + 땅 칸 타일 길 + unproject(project(p)) = p") · `node tools/build-parts.mjs --check` · `node tools/qc.mjs --game saga-go`·`--game saga-dungeon`·`--game saga-forest` 촬영 PNG Read 로 ○△×(건물·사람 비율, 들판 결).
