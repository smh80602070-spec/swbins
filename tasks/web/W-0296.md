# W-0296 4종횡 메이플식 2D 판 — 타일 발판·밧줄·시차 층·시트 애니로 "진짜 2D 화면" 만들기(코드분)
종류: 새 기능(2D 화면) · 웹(4종횡)      상태: **작성됨**(페이블 R-0 10-17 — 사용자 "4번 메이플 버전 2d 버전은 구현이 안되어 있어")

**목표(한 줄)**: 지금 4종횡 2D(🧊 끔)는 배경 그림 한 장 + 풀 띠 발판 + 3D 몸을 한 컷 찍은 인물이라 "2D 판"이 아니다(촬영 `tools/playcheck/shots/st_2d_now.png` 10-17) → 메이플식 2D 화면의 뼈대를 코드로 세운다: ① 타일 발판·밧줄·사다리·벽이 **타일 조각**으로 그려지고 ② 시차 배경(먼·중·가까운 층 + 앞 풀 층)이 2D 캔버스에서도 흐르고 ③ 인물·적이 **시트 애니**(서기·걷기·점프·공격·피격)로 움직이고 ④ 카메라가 픽셀에 맞춰 붙고(흔들림 없음) ⑤ 시간대 색(아침·낮·저녁·밤)이 2D 에도 든다. 그림은 자체툴 몫(K-0135) — 이 티켓은 **구조와 배선**, 그림이 오기 전엔 지금 있는 시트·타일(`assets/sprites2d/tile_*.png`·`sprites2d_sheets/pool_*`)로 돈다.

**잰 것(R-0)**: `assets/sprites2d/` 사람 PNG 14(한 컷)·몬스터 webp 11(한 컷)·타일 3 · `sprites2d_sheets/` 몬스터 풀 5(idle·attack·hit·death 시트 ○ — 걷기 없음) · 2D 배경 층(K-0020 `assets/web2d/bg/<지역>.layers.json`)은 **3D 시차 층(st.parallax3d)만 쓰고 2D 는 한 장으로** 깔고 있음(`mode2d.js` 369~) · 인물 2D 는 `actor2d.me`(VRoid 한 컷) → 걷기·점프 몸짓 없음. 즉 2D 에 빠진 것: 타일 맵 · 시차 · 시트 애니(사람) · 픽셀 카메라 · 시간대 색.

**파일**: `saga-web/saga-story/js/side-view.js`(2D 그리기 1,407줄 — 상한 1,500 이라 새 코드는 새 파일로) · 새 `saga-web/saga-story/js/side-tiles2d.js`(발판·밧줄·사다리·벽 타일 조각 그리기 — 판정 `side.js` 의 발판·줄 좌표를 읽기만) · 새 `saga-web/saga-story/js/side-bg2d.js`(시차 층 2D — `<지역>.layers.json` 그대로 깊이별 배율) · `saga-web/saga-story/js/actor2d.js`(시트 애니 — 걷기·점프·공격 프레임 표, 시트 없으면 지금 한 컷) · `saga-web/saga-story/js/mode2d.js`(타일 로더 확장) · `js/manifest.json`(gen-index --add ×2) · `_test.html` · `dist/app*.js`·`sw.js`.

**단계**: ① side-tiles2d — 발판 한 장(픽셀 48 단위 타일 왼끝·가운데·오른끝 셋) · 밧줄/사다리(세로 타일 반복) · 벽(세로 띠) · 바닥(땅 타일 반복 + 위 풀 한 줄) — 타일 그림 키는 `assets/web2d/tile/<지역>-{plat_l,plat_m,plat_r,rope,ladder,wall,ground}.png`, 없으면 지금 도형 ② side-bg2d — 층 셋(far 0.2·mid 0.5·near 0.8 배율)+앞 풀(1.15 배율, 발 살짝 가림) 2D 캔버스 ③ actor2d — 시트 규격 `assets/web2d/people/<몸id>/{idle,walk,jump,attack,hit}.webp` + manifest(프레임 수·fps), 없으면 한 컷. 몬스터는 기존 풀 시트에 walk 가 없으니 idle 로 걷되 좌우 흔들림 ④ 카메라 픽셀 스냅(정수 좌표·CSS 확대는 정수 배) ⑤ 시간대 색(2D) — 층·타일에 곱하는 색 하나(`side.js` 시간 읽기만) ⑥ 진단 "발판이 타일 셋으로 나뉜다"·"시차 층 배율이 깊이대로"·"시트 있으면 프레임이 바뀐다"·"없으면 한 컷" ⑦ pw-look2d 촬영 한 장 + 장부 줄.

**검증**: `node tools/test-web.mjs saga-story` · `node saga-web/tools/playcheck/pw-play.mjs saga-story`(3D 끄고 — 손잡이 `sideView3d.on=0`) PC·폰 OK · `node tools/qc.mjs --game saga-story` · 2D 한 장(`shots/qc/saga-story-2d.png`) Claude 눈 — 타일 발판·시차·인물 걷기 프레임.
