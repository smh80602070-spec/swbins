**단계**
1. `mode2d.js` 를 사가국지에 싣는다(FILES 3째 칸·manifest `--add`·sw)·`core.js` cfg `mode2d`(`on: !realm3d.active()`, `tileBase`, `tile`: 지방/`land`→`realm_*` 표, `prop2d`: 성 크기 3단→`silkroad_house_01`/`chinese_hall_01`/`stone_tower_01`).
2. 바닥: `.rmap` 뒤에 지형 바닥을 깐다 — SVG 안 `<pattern>`(타일 webp)·성 둘레 `land` 별 큰 원 번짐, 또는 `#realm` 의 CSS 배경. 2D 모드 아닐 때(3D)·자료 없을 때는 옛 어두운 배경 그대로.
3. 성 그림: 점 `<circle>` 위에(점은 손가락 목표·병력 표시라 **남김**) `<image>` 로 성 스프라이트. 크기는 병력 단계, 세력색 고리·내 땅 `ring`·포위·재난 이모지는 그대로. 이름표 겹침은 확대 단계에서만 그림을 켠다(멀리서는 점).
4. (선택) 지도 뒤 층 배경 `realm_*`(4 지방)을 지도 이동에 맞춰 느리게 — 효과·비용을 보고 한다/안 한다를 메모에.
