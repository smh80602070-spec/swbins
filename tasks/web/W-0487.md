**핵심 = ⑥**(사용자 10-27 「6번이 제일 핵심임」) — ⑥ 을 맨 먼저·가장 오래, 나머지는 그 뒤. ⑥ 은 D2 가 아니라 끝까지(모든 동작 ○).
**목표·단계**(⑥ → ① → ② → ③ → ④ → ⑤, 한 단계 끝날 때마다 커밋):
① 4종횡 스페이스 → 3D 전환 버그(버그라 맨 앞). 2D 에서 스페이스(점프) 누를 때 3D 로 바뀌는 길을 찾아 끊는다 — keydown 의 ' '/Space 가 모드 단추(포커스된 버튼 클릭)·단축키에 닿는지부터(포커스 버튼 + 스페이스 = 클릭이 의심 1순위: 모드 단추 blur/preventDefault). 2D 로 열고 스페이스 20번 → 모드 그대로 확인.
② 3마을 2D 앞 배경(화면에 고정된 앞겹/전경 띠) 제거 — 손잡이로 끄지 말고 그리는 줄을 지운다(안 쓰는 그림은 그 자리에서 정리). 집 안·구면 투영은 안 건드림.
③ 1만리 2D 카메라 — 지금보다 멀게(기본 줌 아웃) + 사용자가 더 멀게/가깝게 고르게(휠·핀치·설정 칸, 저장). 「전체 틀은 3마을이 제일 좋다」→ 3마을 2D 의 화면 틀(몸 크기 대 화면 비·HUD 배치·여백)을 재서 1만리 기본값을 그쪽에 맞춘다. 2D 척도는 몸 높이/초 규칙(W-0226~0231) 유지.
④ 2나락 맵(구역) 넘김 — 위로 갈 때 「하늘을 날아서」 보이는 넘김 연출, 아래로는 화면이 가려진 채 넘어가는 것 → 1만리 넘김 방식(구역 넘김 막 W-0408~0419)과 같은 연출로 위·아래·좌우 다 통일.
⑤ 5천하 3D — 언제·왜 3D 진입이 빠졌는지 git log 로 찾아(10-26 W-0447 「2D 묶기」·W-0450 장 흐름 근처) 3D 판을 다시 고를 수 있게 되살린다(단추·모바일 기본은 2D 유지). 2D 재미: 랑그릿사·창세기전 문법(규칙·흐름)을 따라가는 부족분 목록을 장부 realm.md 와 대조해 빠진 것(용병 부대·지휘 범위·상성 삼각·전직 분기·장 사이 상점/편성·턴 시작 컷 등)을 한 장 표로 → 크면 후속 티켓으로 쪼갠다. 원작 에셋·이름·대사·수치는 안 베낌(이름 정책).
