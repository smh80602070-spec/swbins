# W-0310 1만리 — "웹엔 한계가 없다" 시연 — 한 들판에서 다섯 가지를 한꺼번에, **예산 안에서**
종류: 새 기능(그래픽·기술 시연) · 웹(1만리, 플래그십)      상태: **진행중**(페이블 10-18 ①군중·②날씨·③물리 끝 — ✔ 체크포인트, 다음 ④ 임포스터 → ⑤ WebGPU 축소판)

**목표(한 줄)**: 브라우저에서 안 된다고 여기는 것 다섯을 1만리 들판 한 장면(`_demo.html#limitless`, 공개 Pages 주소로 바로 열림)에 같이 띄운다 — ① **군중 300**(같은 몸을 인스턴싱 + 뼈 애니메이션 텍스처(VAT)로 300명이 제각각 걷기·앉기) ② **날씨·빛**(해 궤도 + 볼류메트릭 빛줄기 + GPU 비·눈 파티클 2만, 번개 섬광) ③ **물리**(쓰러진 적 래그돌 20·굴러가는 돌·풀 눕힘) ④ **지평선까지**(멀리 산·숲은 임포스터 빌보드 + 지형 LOD, 안개 없이 2km) ⑤ **WebGPU 길**(three r165 WebGPURenderer 를 켜는 손잡이 `go3d.webgpu=1`, 안 되는 기기는 자동으로 WebGL) — 한 화면 60fps(PC 중급)·폰 30fps(자동 단계) 를 숫자로 찍는다.

**예산(넘으면 실패 — 사용자 10-18 "개적화면 안 됨 · 좋은 그래픽에 최적화가 진정한 게임")**: PC 중급(GTX1650 급·1080p) 60fps 유지 · 폰(중급 안드로이드·0.75 해상도) 자동 단계 30fps · 첫 받는 용량 +3MB 이내(VAT 텍스처 포함) · 메모리 +150MB 이내 · draw call 300 이하(군중은 인스턴스 1~4 call) · 기능마다 끄는 손잡이와 ms 비용표(기능 하나 = 몇 ms 인지). 하나라도 넘으면 그 기능을 줄여서 맞춘 뒤에야 끝 — "된다" 가 아니라 "예산 안에서 된다" 가 시연이다.

**참고**: 원신·젤다(들판 밀도)·three.js 공식 예제(instancing·VAT·WebGPU) — 구조·기법만, 에셋 없음(지금 있는 몸·소품·땅 PBR 재사용) · 장부 `tasks/gameplay/README.md` 그래픽 절.

**파일**: 새 `saga-web/saga-go/js/_expansion/limitless.js`(장면 조립, `_` 파일 — .nojekyll 로 Pages 에 실린다) · 새 `saga-web/shared/js/crowd3d.js`(인스턴싱+VAT) · `shared/js/weather3d.js`(파티클·빛줄기 — 있으면 확장) · `shared/js/ragdoll3d.js`(간단 버릿 물리, 외부 라이브러리 없이) · `src/world3d/*`(임포스터·LOD 손잡이 한 줄) · 렌더러 고르기 `shared/js/renderer3d.js`(WebGPU/WebGL) · `_demo.html`(#limitless 장면) · 측정 `saga-web/tools/playcheck/pw-limitless.mjs`(fps·draw call·메모리 표 → `tasks/sheets/web-limitless-20261018.md`) · `dist/app.js`·`sw.js`

**단계**: ① 군중(VAT 굽기 = anim-own 클립을 텍스처로, 300 인스턴스·그림자 받기) ② 날씨·빛(파티클 GPU, 빛줄기 포스트) ③ 래그돌(10 관절 버릿, 쓰러짐 1.5초 뒤 사라짐) ④ 임포스터·LOD(먼 산·숲 8방향 빌보드) ⑤ WebGPU 손잡이(실패하면 WebGL 로, 콘솔 한 줄) ⑥ 측정 표(기능별 ms·draw call·메모리·용량, W-0302 의 pw-phone-budget 틀 재사용)·촬영 셋(PC 60fps·폰 자동 단계·WebGPU on) — 예산 넘는 기능은 밀도부터 줄인다(군중 300→200, 파티클 2만→1만) ⑦ README "한계 없음" 절에 공개 주소·수치 한 줄 ⑧ 본 게임엔 손잡이로만(군중 밀도·날씨 세기) — 기본값은 그대로
