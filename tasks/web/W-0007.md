# W-0007 `perf.js` 다섯 판 (`?perf`)
종류: 통합      판: 웹 다섯      등급 목표: (체제) — SAGA-DESIGN §6.1-B ① "재기 먼저"

**목표(한 줄)**: 사가고에만 있는 `js/perf.js`(266줄, `?perf` HUD: fps·99분위·긴 프레임·호출·삼각형·텍스처) 를 나머지 네 판에 같은 파일로 붙여 폰 계측이 다섯 판에서 된다.

**파일**: `saga-web/saga-dungeon/js/perf.js`·`saga-forest/js/perf.js`·`saga-story/js/perf.js`·`saga-realm/js/perf.js`(새, 사가고 사본) · 네 판 `index.html`(script 한 줄 + 디버그 줄) · 네 판 `js/game.js`(프레임 상한 손잡이 호출 1~2줄) · 네 판 `sw.js`(VERSION +1)

**본보기**: `saga-web/saga-go/index.html` 109행(script)·218~227행(디버그 줄) · `saga-go/js/game.js` 353행 근처(`perf.fps` 손잡이). 렌더 수치는 각 판 3D 파일의 `renderer.info` 에서: `dungeon3d.js`·`village-view3d.js`·`side-view3d.js`·`realm3d.js` 에 `grep -n "renderer.info\|WebGLRenderer"`.

**단계**
1. `perf.js` 를 네 판에 복사. 사가고 전용 참조(`DG.world3d`)가 있으면 `grep -n "world3d" perf.js` 로 찾아 그 판 3D 모듈 이름으로 바꾼다(없으면 그대로).
2. `index.html`: `perf.js` script 를 `game.js` 바로 앞에. 디버그 줄은 사가고 218~227 을 그대로 옮기되 모듈 이름만 바꾼다.
3. `game.js`: 사가고 353행 손잡이(프레임 상한)를 같은 자리(메인 루프 rAF)에. 기본값은 바꾸지 않는다.
4. `sw.js` VERSION +1 ×4.
5. `node tools/test-web.mjs saga-story` 로 회귀 없음(진단 수 그대로).

**검증**
```
node tools/test-web.mjs saga-story saga-realm    → RESULT n/n 둘 다 실행 전과 같은 n
grep -c "perf.js" saga-web/*/index.html           → 다섯 판 전부 1 이상
```

**완료 조건**: 위 둘 · 네 판 `?perf` 가 HUD 를 띄운다(코드 경로만 확인, 실기는 시트로).

**불변 규칙 확인**: 화질 손잡이 기본값 변경 0(§6.1-B "화질 안 깎기") · 세이브 무관.
