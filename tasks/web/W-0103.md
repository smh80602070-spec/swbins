# W-0103 사가마을 — 제작대(짓기) + 도구 승급 3택 (리뉴얼 ③, 마인크래프트 참고 · 재미표준 D)
종류: 새기능 · 웹(사가마을)      상태: 작성됨(R-0 페이블 2026-10-07)      등급 목표: D2

**목표(한 줄)**: 성장 선택이 없는(재미표준 D ×: 도구·옷·가구는 "사면 끝") 판에 **제작대**를 둔다 — 채집물이 재료가 되어 도구를 **승급**하고 가구·울타리 조각을 짓는다. 승급마다 **3택**(속도/수확/희귀 — 서로 다른 축, 거절하면 벨 소량). "모아도 마을이 안 변한다"(G) 에도 한 걸음(지은 것이 마을에 놓인다).

**설계(페이블)**
- 제작대 = 집 앞 고정 소품 1(기존 3D 소품 중 작업대·탁자류 id 를 `assets3d-ids.js` 에서 고른다, 없으면 상자 GLB 임시 — 에셋 요청은 K 티켓으로). 곁에서 F → 제작대 화면.
- 레시피 12(`data-village.js` 새 표 `RECIPES`): 도구 승급 6(잠자리채·삽 각 Lv2·3·4 — `TOOLS` 에 `lv` 칸), 가구 4(기존 `FURNITURE` 중 넷을 "짓기" 로도 얻게 — 사는 길은 그대로), 울타리·징검다리 2(기존 공사 조각 `terrain.js` 가 놓는 것 재사용). 재료는 전부 지금 채집되는 품목(열매·견과·광석·꽃·약초·화석·조개·나무)만.
- 도구 승급 3택 축: **속도**(채집 1회 시간 −20%) / **수확**(+1개 확률 30%) / **희귀**(희귀 등급 확률 ×1.5). 같은 축 둘이 한 화면에 안 나온다(규격 D). 거절 = 100벨, 다음 승급 때 다시. 세이브 `save.village.tools[key] = {lv, perks:[]}` — 옛 `true` 는 `{lv:1, perks:[]}` 로 마이그레이션(`hasTool` 은 lv≥1 로 그대로 참).
- 채집(`village.js` 채집 함수)이 `toolPerk(key)` 를 읽어 보정 — 수치는 위 셋뿐, 다른 수치 안 건드림.
