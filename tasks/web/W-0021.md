- 읽는 곳: `shared/assets/world3d/<id>.glb`(42개, 12~60KB) · `shared/assets/characters3d/<영웅id>.glb`(299, 영웅 id = `data.js` HEROES id 그대로, 공용 `tex/` 450장 같이). 둘 다 **Meshopt+WebP 압축, 애니메이션 0**(몸 GLB 는 스킨 22·`KHR_materials_unlit`). 판별 9칸 = `tools/world-forge/data/set_plan.json`(건물3·지물3·지형2·탈것1)

- 새 `shared/js/assets3d.js`(`sync-shared` FILES) · `DG.cfg.assets3d`(판별 id 표) · `sw.js` VERSION

**단계**
1. **서빙 결정(막힌 곳)**: 판 폴더 서버(`run.bat`·`start_server.bat` = `python -m http.server`)는 `../shared` 를 못 읽는다. 2D 는 판별 복사(≤0.6MB)로 풀었으나 몸 174MB 는 다섯 벌 복사 불가. **추천**: 새 `tools/serve-game.mjs`(node, 판 폴더 + `/_shared/` → `saga-web/shared` 매핑)로 두 bat 교체(포트·허브 카드 불변), 로더는 기준 주소를 순서대로 시험(`../shared/assets/`(Pages) → `_shared/assets/`(로컬)). 건물·지물 2.2MB 는 2D 처럼 복사도 가능. 사용자 확인 필요.
2. `assets3d.js`: `url(kind,id)`·`hero(id)`·`ready(id)` — 주소를 못 찾으면 null → 호출부가 옛 경로로.
3. 건물·지물·지형·탈것: 판별 9칸을 호출부 상수 한 줄씩 교체. **있는 자리만**(새 자리 만들지 않음). 툰 중복(`toon3d.js` 가 이미 툰 텍스처에 또 입히는지)을 건물 하나로 비교해 결정.
4. 인물: `heroRecipe()` 맨 앞에 `assets3d.hero(id)` → `{key, body:url}`, `wantsOwnAnim` 에 새 경로 추가. `vroid-variant.js` 의 `shade`·무늬(`KHR_materials_unlit` 재질에 맞는지)를 한 명으로 확인. 폴백 = 옛 `FIXED_HERO`·풀.
5. 판 순서: 사가고 → 사가블로 → 사가의숲 → 사가스토리 → 사가국지. 판마다 `sw.js` +1.
