# W-0136 웹 2D 장비 겉모습 — 층 시트 겹쳐 그리기(몸 → 갑옷 → 무기)
종류: 그래픽 · 웹(다섯 판 — 장비 보이는 주인공·동료)      상태: 작성됨 — K 갑옷 층 굽기 뒤(페이블 R-0 10-10 · Opus 초안 10-09 — 수신함 K-0037 단계 4 산출)      등급 목표: D2

**목표(한 줄)**: 2D 인물 시트에 장비 층 시트를 같은 칸(128px·8프레임·방향 0~4+뒤집기·발 기준점)으로 겹쳐, 입은 벌이 2D 에서도 보이게.

**파일(확인함, 10-10)**
- `saga-web/shared/js/mode2d.js` 225행 `draw` · 230행 `getImg` · `saga-web/saga-dungeon/js/belt2d.js` 123행 · 규약 `tools/char-forge/COSTUME-SYSTEM.md` §9(63행~: 층 셋 몸→갑옷→무기, 가림판, 용량)
- 선행: K 갑옷 층 굽기 본판(~10-19 뒤) — 산출 경로는 그 K 티켓 메모
- 규약·한도 `tools/char-forge/COSTUME-SYSTEM.md` §9
- 그리기 `saga-web/shared/js/mode2d.js`(시트 그리기)
- **선행**: 자체툴 갑옷 층 굽기 본판(새 K 동결 ~10-19 뒤 — 굽기 전엔 실행 안 함)

**단계**
1. `shared/js/mode2d.js` 225행 `draw(ctx, o)` 에 `o.layers`(['armor:<벌 id>', 'weapon:<무기 id>'] 순서 고정 몸 → 갑옷 → 무기): 몸을 찍은 뒤 같은 role·frame·facing 으로 층 시트를 겹쳐 찍는다. 층 시트 경로·manifest 꼴은 K-0037 단계 4 산출 메모(`tools/char-forge/COSTUME-SYSTEM.md` §9 — 128px·8프레임·방향 0~4+뒤집기·발 기준점 같음)의 표를 그대로. 없는 층은 건너뜀(404 안 냄 — manifest 먼저).
2. 받기 예산(§9: 갑옷 한 벌 ≈0.44MB·무기 ≈0.06MB): 입은 벌만 받고 캐시는 최근 8벌 LRU — 벗으면 바로 안 지움.
3. 게임 쪽: 사가나락 주인공·동행(`js/belt2d.js` 123행 `drawSprite`)에 `dungeon_equipment_state` 의 입은 벌 → layers · 사가만리 동료(`js/world.js` 2D 스탬프)는 벌 id 가 있을 때만. 나머지 세 판은 이번엔 안 함(장비가 안 보이는 판).
4. 진단 +1(사가나락): layers 를 준 draw 가 몸·갑옷·무기 순으로 세 번 찍힌다(ctx 가짜로 drawImage 횟수 셈) · 층 없으면 한 번.
5. `sync-shared` · 번들 둘 · sw VERSION +1.
