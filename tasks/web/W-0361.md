# W-0361 다섯 판 공용 「내 정보」 창 — 입은 장비·전투 능력치 한눈에
종류: UI(게임성) · 웹(다섯 판 + 새 공용 `shared/js/me-panel.js`)      상태: **작성됨**(오퍼스 R-0 10-21 — 수신함 10-20 사용자 "다섯판 내 장비랑 내 상태가 보는데 없어(공격력·스텟 설정)")

**목표(한 줄)**: 판마다 장비·능력치가 흩어져 있거나(2나락 gear 창·4종횡 가방 창) 숫자가 아예 안 보인다(1만리 전투 hpMax·def 는 계산만) → ☰ 메뉴에서 여는 같은 꼴 「내 정보」 창 하나: 왼쪽 몸 칸(입은 장비 칸 그림) · 오른쪽 능력치 표(공격력·방어·체력 + 판 고유 무/지/통) · 아래 "어디서 올리나"(판의 패시브 그물 단추). 스탯 직접 배분 체계는 어느 판에도 없다(점수 쓰기 = 공용 passive-web) → 새로 만들지 않고 그물로 잇는다(아래 메모 — 거부권).
