# W-0383 3마을 자동 퀘스트가 지금 구할 수 없는 부탁(화석·밤 벌레)에 붙들려 다음 목표로 못 넘어간다(첫 10분 막힘)
종류: 버그 · 웹(3마을)      상태: **초안**(10-23 W-0381 첫 10분 점검이 찾음 — 나머지 칸은 R-0)

**재현**:
1. `node saga-web/tools/playcheck/pw-first10.mjs saga-forest --min=10`(새 계정 → 자동 퀘스트 ▶)
2. 주민 부탁 "🤝 용맹 — 삼엽충 화석 0/4"(다른 실행에선 "🤝 경적 — 거미 0/3")이 맨 앞 목표가 되어 4분 넘게 그대로 — 자동 마을살이는 "🌳 꽃 으로" 만 되풀이
3. 화석(삽 파기)·거미(밤·계절)는 자동 마을살이가 구하지 못하는 것인데 auto-quest-fs.js goals() 는 가방 몫이 찬 부탁만 앞으로 당기고 나머지는 차례대로 → 못 구하는 부탁이 앞을 막음

**기대**: 지금 자동으로 구할 수 없는 부탁은 뒤로 미루거나 건너뛰고(왜인지 한 줄), 마을 일·다른 부탁으로 넘어가 첫 10분에 목표가 넘어간다.

**메모**: 결과 `saga-web/tools/playcheck/results/pw-first10.json` log · 판정 바꾸지 않음(부탁 자체·보상 그대로) — 어댑터 차례만.
