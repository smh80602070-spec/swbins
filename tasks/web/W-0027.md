# W-0027 사가국지 화면 리뉴얼 — 전략 시뮬레이션 화면(영토 지도·성 정보 패널·커맨드 바·상단 배너)
종류: 새기능 · 웹(사가국지)      상태: **멈춤**(단계 1~4 코드분 끝, 2026-10-03) — 사용자가 같은 날 방향을 **RTS(심시티+스타크래프트)** 로 바꿔 W-0028 이 이어받는다. 단계 5 는 K-0060 도착해도 RTS 화면에 맞게 다시 정한다      등급 목표: D2

**목표(한 줄)**: 사용자 지적(10-03) "화면이 삼국지 같은 스타일이 아님 — 전략 시뮬레이션 같은 화면이면 좋겠다". 지금은 어두운 바탕 위 점·이름표에 오른쪽 아이콘 독이 시트를 여는 앱 꼴이다. **지도가 화면 전체의 주인이고, 세력이 색 면으로 보이며, 고른 성의 정보와 명령이 한 화면에 상시 붙는** 전략 시뮬 배치로 바꾼다. 문법만 따른다(이름·에셋·데이터는 원작에서 안 가져옴 — 루트 CLAUDE.md 이름 정책).

**파일(확인함)**: `saga-realm/js/map2d.js`(2D 지도 꾸밈, 사가국지 전용) · `src/ui-rtk/02.js` `renderMap()`·시트(→ `js/ui-rtk.js`, `tools/build-parts.mjs`, **큰 파일 목록 — 줄 수 못 늘림**) · `index.html`(#top·#dock·#realm·#rlegend·시트) · `css/style.css`(1492줄, 상한 1500 근처 → 새 CSS 는 파일을 나눠 `css/strategy.css`) · `js/realm3d.js`(3D 는 그대로 둔다) · `_test.html`

**단계**
1. ✔ **영토 면·국경선**: `map2d.territory()` — 같은 세력 성을 굵은 둥근 선·원으로 이어 한 덩어리(불투명 .46·번짐)로 칠하고, 같은 모양에서 바깥 테두리만 따로 그린다(SVG 필터 `rtedge`). 물길은 안 잇는다. 진단 +1.
2. ✔ **성 정보 패널 + 커맨드 바**: 넓은 화면(>780px)·2D 지도에서 성을 누르면 오른쪽에 `js/cpanel.js` 패널(이름·세력·인구·병력·군량·농업·상업·성벽·치안·태수)이 뜨고 `성 열기` 가 기존 시트(명령·계략)를 연다. 독은 아래 가운데 가로 커맨드 바로 눕힘(`css/strategy.css`). **폰·3D 는 예전처럼 곧바로 시트** — 폰 아래서 올라오는 패널은 남음. 진단 +1.
3. ✔ **날짜 배너·미니맵**: `js/hud.js` — 위 가운데 "194년 1월 · 초봄" 배너, 오른쪽 아래 전체 지도(성 점 세력색·보이는 창 사각형, 누르거나 끌면 이동 `DG.ui.centerAt`). 넓은 화면·2D 만. 자원 줄은 기존 지갑 줄 그대로. **기본 지도를 2D 로**(`realm3d.on` 기본 1→0, 3D 는 🧊 단추). 진단 +1.
4. ✔ **틀·색·글꼴**: `css/strategy.css` 끝 — 넓은 화면(>780×>500)에서 패널·배너·미니맵·프로필·지갑·독을 먹칠 옻칠 바탕+금 테두리 두 겹으로, 날짜·성 이름은 세리프(시스템 명조 계열 — 번들 글꼴은 라이선스 확인 뒤). 에셋이 오면 `border-image` 로 갈아 끼운다.
5. **그림 입히기**(K-0060 도착 뒤): 틀은 `border-image`, 성 그림은 `prop2d` 설정, 깃발은 세력색 틴트, 지방 글씨는 지도 워터마크로 연결.
