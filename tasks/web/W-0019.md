# W-0019 2D 모드 전환 — 2D 단추를 누르면 화면 전체가 2D 그림으로(코드 배선만)
종류: 새기능 · 웹 다섯      상태: **작성됨**(R-0 2026-10-01, 사용자 지시로 범위 확대)      등급 목표: D2

**목표(한 줄)**: 사용자 지시(2026-10-01) "2D 스프라이트 웹 버전은 2D 단추를 누를 때 바뀐다 · 2D 모드로 전환하면 **전체가** 2D 로 바뀐다". 2D 가 되면 인물·괴물(걷기·전투 시트) + 배경(층 3겹) + 바닥 타일 + 건물·지물 스프라이트를 모두 2D 그림으로 그리고, 2.5D/3D 로 돌아가면 기존 3D 그대로. **에셋 파일은 이 티켓이 만들지도 고치지도 않는다**(자체툴 K-0015·K-0017·K-0020 산출을 K-0019 가 `assets/` 에 놓는다).

**파일(확인함)**: 사가고 전환 단추 `saga-web/saga-go/index.html` 의 `#btn-tilt`("2D / 2.5D / 3D 전환", 지금 2.5D 표시)·`js/core.js`(`camZoom2d`) · 나머지 네 판은 같은 단추가 `index.html` 에 안 보인다 → 단계 1에서 전환 구조 확인 · `saga-web/saga-*/js/sprite.js`(다섯 벌) · 읽을 자료(이미 놓임) `assets/sprites2d_sheets/index.json`(판별 4벌) · 새 `saga-web/shared/js/mode2d.js`(전환·시트·층 로더, `tools/sync-shared.mjs` FILES) · 각 판 `js/core.js` 끝 `DG.cfg.mode2d` · `sw.js` VERSION

**본보기**: W-0016 `shared/js/bgm.js` + `DG.cfg.bgm`(자료 없으면 오류 0·기존 동작).

**단계**
1. 전환 구조 파악: 사가고 `#btn-tilt` 가 누르면 무엇을 바꾸는지(`grep -n "btn-tilt\|tilt"`), 나머지 네 판에 2D/3D 전환이 있는지. 없으면 **판별 2D 단추를 같은 모양으로** 추가(코드·UI 만).
2. `mode2d.js`: 모드가 2D 일 때 `DG.mode2d.sheet(벌id, 동작, 방향, 프레임)`·`layers(지역)`(far·mid·near, 속도 0.2/0.5/1.0)·`tile(종류)`·`prop(id)` 를 돌려준다. 자료 없으면 null → 그 항목은 기존 그림(오류 0).
3. 렌더 연결: 2D 일 때 3D 씬 대신 2D 캔버스(바닥 타일 + 층 배경 + 정렬된 스프라이트)로 그린다. 3D 로직(충돌·전투 수치)은 안 건드리고 그림만 바꾼다.
4. 판별 cfg: 벌 id ↔ 인물·괴물 종류 연결표(**도감 id·세이브 키 불변**, 새 표만).
5. `sw.js` VERSION +1 ×5.
