# W-0019 2D 스프라이트 시트 배선 — 걷기·전투 그림을 새 128px 시트로
종류: 새기능 · 에셋 적용 · 웹 다섯      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2 — 2D 모드에서 시트가 그려진다

**목표(한 줄)**: K-0015 가 굽고 각 판 `assets/sprites2d_sheets/` 에 넣은 20벌(판별 4벌, `index.json`·벌별 `manifest.json`: 128px·8프레임·방향 3 0정면·1옆·2뒤, 반대 옆은 뒤집기, 동작 idle/walk/attack/hit/death)을 `sprite.js` 의 2D 모드가 읽어 걷기·전투 때 그린다. 지금은 파일만 있고 아무 코드도 안 읽는다(`grep sprites2d_sheets saga-web/*/js` = 0).

**파일(확인함)**: `saga-web/saga-{go,dungeon,forest,story,realm}/js/sprite.js`(다섯 벌 복사, 100KB급 — 심볼로 grep 해 그 자리만) · `saga-web/<판>/assets/sprites2d_sheets/index.json`(읽기) · 새 `saga-web/shared/js/sheet2d.js`(공용 로더, `tools/sync-shared.mjs` FILES 에 추가) · 각 판 `js/core.js` 끝 `DG.cfg.sheet2d`(벌 id → 인물·괴물 종류 표, 판 몫) · `sw.js` VERSION

**본보기**: W-0016 `shared/js/bgm.js` + `DG.cfg.bgm`(판별 차이는 cfg, 곡·파일 없어도 오류 0).

**단계**
1. `sprite.js` 에서 2D 모드 걷기(`PHASES`)·그리기 자리를 grep 로 찾아 메모(코드 모양이 판마다 같은지 확인, 사가고 `sprite.js` 100KB 는 통째 Read 금지).
2. `sheet2d.js`: `DG.sheet2d.get(벌id, 동작, 방향, 프레임)` → 이미지+사각형. `index.json` 비동기 로드, 없으면 null(오류 0, 기존 코드 그림 그대로).
3. 판별 cfg: 벌 id ↔ 종류 연결(예: dungeon 의 `pool_basem_demon_104` = 악마류 적). **도감 id·세이브 키 불변**, 연결은 새 표만.
4. 걷기·공격·피격·사망 호출부에서 시트가 있으면 시트, 없으면 기존. 2D 모드에서만(3D 는 안 건드림).
5. `sw.js` VERSION +1 ×5.

**검증**
```
node tools/sync-shared.mjs --check          → OK
node tools/test-web.mjs saga-dungeon saga-story   → 값 전후 같음(실패 이름도 같다)

```

**완료 조건**: 단계 1~5 · 진단 값 불변 · 시트 있는 종류가 2D 모드에서 시트로 그려짐(사용자 확인 시트 1장) · 시트 없는 종류는 기존 그림.
