# W-0121 2D 주민 회색 조각상 — 사가마을·사가나락 2D 사람에 옷 색 되살리기
종류: 버그 · 웹(사가마을·사가나락, 공용 mode2d)      상태: 작성됨(R-0 Opus 10-09, W-0118 산출)      등급 목표: D2

**목표(한 줄)**: 2D 모드의 주민·마을 사람이 색 없는 회색·흰 조각상으로 서는 것을, 3D 처럼 사람마다 다른 옷 색이 보이게 되돌린다(기준 09-28 은 색 있는 작은 주민).

**파일(확인함, 10-09)**
- 판정 근거 `tasks/sheets/sonnet-regress-20261010.md` 사가마을 「2-sphere2d·2D」 ×, 사가나락 「2D」 메모
- 원인 커밋 `47f0feca3`(Opus 10-06 W-0074 2D — 도감 밖 사람은 빌린 VRoid 시트 `shared/assets/characters2d/<id>/*.webp`). 시트 그림 자체가 검정·회색 옷(예 `characters2d/rf_xuchu/walk.webp`)이고, 3D 에서 사람마다 입히는 옷 색 변형(`shared/js/vroid-variant.js`)이 2D 엔 없다
- 정본 `saga-web/shared/js/mode2d.js`(빌린 몸 고르기 45~60행 부근, 그리기 `drawSprite`) → `node tools/sync-shared.mjs` · 몸 고르기 `shared/js/assets3d.js` `borrowRecipe`
- 화면은 판별 `dist/app.js`(`node saga-web/shared/build/bundle.mjs saga-forest`·`saga-dungeon`) + 두 판 `sw.js` VERSION

**단계**
1. 빌린 몸 2D 그리기에 사람 씨앗(id)으로 정한 옷 색 한 겹 — 시트를 한 번 오프스크린에 그려 어두운 옷 부분(밝기 낮고 채도 낮은 화소)만 씨앗 색으로 곱하기(multiply)·색조 입히기, 결과를 (시트·색) 키로 캐시. 얼굴·피부는 건드리지 않는다. 손잡이 `core.tuned('mode2d.borrowTint', 1)`.
2. 도감·장수 제 시트(set hero)는 그대로(이미 고유 그림).
3. `pw-look2d.mjs saga-forest village` · `saga-dungeon town` 전후 촬영 Read — 주민이 서로 다른 색으로 보이고 회색 조각상이 없으면 ○.

**검증**: `node tools/sync-shared.mjs --check` · `node tools/test-web.mjs saga-forest saga-dungeon` 전부 통과(진단 수 안 줄음, 색 입히기 순수 함수 진단 +1) · `node tools/qc.mjs --game saga-forest` · `--game saga-dungeon` PASS + 2D PNG 눈 ○ · `bash tools/precheck.sh` OK

**완료 조건**: 두 판 2D 주민 색 ○(전후 PNG 경로·판정 메모) · 커밋·푸시.

**불변 규칙**: 에셋(시트 webp) 안 고침 — 색은 코드로만 · 세이브 키·id 안 바꿈 · 사가마을 구면 투영 그대로 · 매 프레임 새 캔버스 금지(캐시).

**본보기**: `saga-web/shared/js/vroid-variant.js`(3D 옷 색 씨앗 고르기) · `tasks/web/done/W-0114.md`(2D 배선 촬영 전후).
