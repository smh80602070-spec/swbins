# W-0162 1만리 3D 젤다 읽힘새 — 지역 랜드마크를 3D 로 세우고, 카메라 자유 회전·멀리 보기(야숨식 탐험 유도)

**목표(한 줄)**: 야숨의 "저기 보이는 곳으로 간다" — 지역 랜드마크(biome.js §5 ⑩, 2D 는 탑 그림+이름)를 3D 에서 멀리서도 보이는 **큰 구조물**(탑·거목·바위기둥·사원, 지역 색)로 세우고, 카메라를 드래그로 돌려(yaw 는 이미 있음) 멀리 볼 수 있게 pitch 도 손잡이 안에서 열며, 랜드마크엔 거리 표시 이름표. 에셋 0(prop3d 도형·있는 건물 GLB 재사용).

**단계**
1. `landmark3d.js`: `landmarks(x, y, R)` 로 반경 1.2km 안 랜드마크 → 지역별 구조물 하나(탑 = 세운 상자 3단 + 지붕, 거목 = 원뿔 2단, 바위기둥, 사원 = 있는 건물 GLB) 높이 18~30m, 지역 색(biome 색), `FAR_NEAR` 밖에서도 안 지움(먼 거리 LOD 는 단색 실루엣).
2. 이름표: 거리 400m 밖이면 "이름 · 1.2km" 빌보드, 안이면 이름만. 2D 의 탑 그림은 그대로.
3. 카메라: 드래그 세로로 pitch(손잡이 pitchMax 안), 놓으면 0.6초에 기본 각으로 되돌림(원작식 낮은 카메라 유지). 멀리 보기 중엔 안개 far 를 1.3배(W-0153 수치 뒤).
4. 진단 +2: ① 반경 안 랜드마크 수 = 세운 구조물 수 ② pitch 가 손잡이 밖으로 못 나감. 번들 · sw VERSION +1 · 그리기 예산(pw-go-render-budget.mjs) 전후 같음.
