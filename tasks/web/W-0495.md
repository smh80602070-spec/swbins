# W-0495 2나락·1만리도 3마을처럼 깊이 원근(멀면 작게·가운데로 모임)
종류: 화면 · 웹(2나락 먼저, 1만리 뒤)      상태: 2나락 마을·들판 시제품 끝(손잡이 기본 0) · 나머지 남음      등급 목표: D2

**까닭**: 사용자 10-29 — 3마을 2D(원통 투영: 먼 곳 작게·아래 크게·좌우 처짐)의 느낌이 좋아 "1·2도 3처럼". 3마을은 이미 project() 의 배율 s(0.42~1.55)를 사물·사람이 함께 쓴다. 2나락은 던전앤파이터식 벨트(방 y → 깊이 띠, 배율 s 고정)라 먼 사람도 같은 크기.
**파일**: saga-web/saga-dungeon/js/belt2d.js(metrics 의 belt·unbelt·ellipse·sAt) · src/dungeon-view/02.js(인물 넷 `sf`) · 1만리는 투영 자리 먼저 조사
**한 일(10-29)**: 손잡이 `dg.beltDepth`(0 = 옛 그대로, 기본 0). 마을·들판(town)만: 화면 깊이 d(띠 위 0·아래 1)마다 f = 1 + 손잡이 × (d − 0.5) 를 가로 폭·인물 크기에 곱한다. belt·unbelt 가 같은 f 라 클릭 되짚기가 맞는다. 인물(나·적·NPC·동료)은 `m.sAt(y)` 로 크기. 진단 604/604(기본 0). 1.0 에서 먼 NPC 작고 앞 사람 큼 확인(마을 촬영).
**남음**: ① (건물·소품 크기는 10-29 같은 f 로 맞춤 — 남은 것: 땅 타일·이름표·HP 막대·글자 크기) ② 던전 방은 바닥이 직사각형 띠라 사다리꼴 바닥·벽이 필요(손 안 댐) ③ 몹 소환 거리(spawnView.minDist)·조준·범위 표시가 f 를 쓰는지 ④ 기본값을 올릴지(사용자 눈) ⑤ 1만리: 지도 타일 위라 투영 구조부터 조사 ⑥ dungeon-view.js 가 1500줄 상한 — 더 고치려면 조각을 쪼갠다
**검증**: node tools/test-web.mjs saga-dungeon RESULT n/n · pw-look2d.mjs saga-dungeon <png> town (LOOK_TUNE=dg.beltDepth=1.0)
**불변**: 세이브 키·id · 손잡이 0 = 옛 화면 · 에셋 안 만듦 · 3D 안 건드림
**10-29 ⑤ 1만리 조사(코드 변경 없음)**: 1만리 2D(tilt 0)는 평평한 위에서 본 화면 — world.js `project(u,v)` 에 원근(tilt 44°·persp 1200 → 배율 s)이 이미 있으나 tilt 1·2 는 3D 지도(world3d)를 켜는 길이라 2D 본판에선 안 쓰인다(`LOOK_EVAL="DG.core.save.settings.tilt=1"` 로 확인 — 3D 화면이 나옴). 3마을식을 2D 에 넣으려면 ⓐ 땅 캔버스(돌 타일)·오브젝트 캔버스·클릭 되짚기(unproject)를 한 투영으로 묶고 ⓑ 사람·건물·무리·이름표가 같은 배율을 쓰게 해야 한다 — world.js 가 이미 1819줄(상한 초과 목록)이라 src/world 조각 분리부터. 2나락(벨트, 배율 한 줄 곱)보다 몇 배 큼 → 2나락 기본값을 사용자가 정한 뒤 착수.
**10-29 ⑤ 1만리 시제품**: 위 조사의 쉬운 길 — 2D 에서 기존 CSS 눕힘(computeGeom)만 쓰는 새 모드 3. 손잡이 `go.depth2d`(땅 눕힘 각도, 0 = 옛 평평 그대로, 기본 0)·persp 1500·플레이어 화면 60% 높이. 3D 는 안 켠다(settings.tilt 0 그대로, world3d.wanted 불변). project/unproject 가 이미 원근을 알아 사람·건물·무리 배율과 클릭 되짚기는 그대로 따라감. 34 에서 돌 타일이 위로 좁아지고 먼 말·사람 작아짐 확인. 진단 1008/1008(기본 0). 남음: 이름표·글자 크기·기본값(사용자 눈)·구역 안개·폰 확인.
**10-29 남은 것 맞춤(사용자 「다 맞쳐」)**: 2나락 — 이름표·HP 막대·표식 위치를 그 인물 y 의 배율(`m.sAt`)로, 땅 타일은 평평하게 두 배 폭으로 한 번 그린 뒤 가로줄 3px 띠마다 f 로 좁혀 붙임(위로 갈수록 좁아짐, belt2d.js townStage·gOC). 1만리 — 구역 안개가 `geom.tilt` 에서 통째로 꺼져 있던 것(깊이 원근 기본 켬 때문에 사라질 뻔) 구역 사각형 네 모서리를 투영한 사다리꼴 바깥 덮음+안쪽 띠 세 겹으로(zoneFogTilt, go.zoneM=150 촬영 확인). 진단 1009/1009·604/604. 남음: 던전 방(사다리꼴 바닥·벽) · 이름표 글자 크기는 읽기 위해 그대로 · 폰 실기.
