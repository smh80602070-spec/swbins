# W-0033 사가국지 RTS P3b — 전투·습격(적 파도)·망루 발사·성벽 방어·거점 체력
종류: 새기능 · 웹(사가국지)      상태: **코드분 끝**(2026-10-04) — 사용자 눈 확인 대기(교전 손맛·습격 난이도)      등급 목표: D1→D2

**목표(한 줄)**: W-0028 P3 의 뒤 절반. 만든 군대가 **싸운다** — 사거리 교전·상성, 망루·거점 발사, 적 파도가 가장자리에서 와서 거점을 치고, 성벽이 길을 막는다. 거점 체력 0 이면 진다.

**파일**: 새 `js/rts/combat.js`(순수 모델) · `js/rts/state.js`(cHp·raid·kills·over 저장, 옛 저장 호환) · `js/rts/view.js`(틱에 combat.tick·HUD 거점 체력·습격 남은 날·승수·함락 안내) · `rts.html`·`sw.js`·`_test.html`

**규칙(안)**
- 교전: 한 번 치는 데 쿨다운 10틱(1초). 피해 = 공격력 × (상성 이기면 1.5). 사거리 안의 가장 가까운 적을 친다. 내 유닛은 가만히 서 있으면 시야 8칸 안의 적에게 다가가고, 이동 명령 중엔 쫓지 않고 걸으며 쏜다.
- 망루: 7칸 안 적에게 6/10틱 · 거점: 6칸 안 적에게 5/10틱. 적을 쓰러뜨리면 금 8.
- 습격: 첫 파도 250틱(5일), 이후 200틱(4일)마다. n번째 파도 = (2+n)기, 보병·궁병·기병 순환, 체력 +10%×n, 가장자리(북·동·남·서 차례)에서 거점으로 온다.
- 적: 사거리 안 내 유닛 먼저 → 거점에 닿으면 거점 체력(400) 깎기 → 길이 막히면 가까운 성벽(체력 40)을 부순다.
- 거점 체력 0 → 함락(속도 0·저장 비움, 새로고침하면 새 판).

**단계**: 1 combat.js(+진단) → 2 state 저장 → 3 view HUD·루프 → 4 헤드리스 확인(`pw-rts-raid.mjs`) → 5 precheck·큐.

**검증**: `node tools/test-web.mjs saga-realm` → 296/296(289 + 새 진단 7) · `node saga-web/tools/playcheck/serve.mjs C:/swbins/saga-web 8871` 띄우고 `pw-rts-raid.mjs`(파도 2기·HUD·함락 안내) · `bash tools/precheck.sh` OK.

**완료 조건**: 단계 1~5 · 파도가 오고 싸우고 성벽·망루가 듣는다 · 옛 저장 열림 · P1~P3a 진단 그대로.

**불변 규칙**: 에셋 안 만든다 · 세이브 키 불변(`save.rts` 안) · 난수 없음 · 원작 이름 금지.
