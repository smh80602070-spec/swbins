# W-0382 2나락 자동 퀘스트가 첫 들판 토벌 목표로 못 가고 마을에서 오간다(첫 10분 막힘)
종류: 버그 · 웹(2나락)      상태: **초안**(10-23 W-0381 첫 10분 점검이 찾음 — 나머지 칸은 R-0)

**재현**:
1. `node saga-web/tools/playcheck/pw-first10.mjs saga-dungeon --min=10`(새 계정 → 출사표 첫 셋 → 자동 퀘스트 ▶)
2. 첫 목표 "🌾 흑기 도적의 밤 · 토벌 0/10 — 625보" 로 걷다가 "📜 막혀서 옆으로 돌아가는 중" 과 원래 길을 4분 넘게 번갈아 함(마을 밖으로 못 나감)
3. autoquest 멈춤 수(stuck)는 0 — 옆으로 돌아가며 계속 움직여 막힘으로 안 셈 → 자동이 스스로 멈추지도 않음

**기대**: 새 계정 첫 10분 안에 마을을 나가 첫 들판 토벌을 시작한다(또는 갈 수 없으면 다음 목표로 넘어가고 까닭을 알린다).

**메모**: 결과 `saga-web/tools/playcheck/results/pw-first10.json` log · 원인 후보 = auto.js 들판 사연 길찾기의 "옆으로 돌아가기" 가 같은 벽에서 되풀이(돌아간 뒤 다시 직선 경로) · 막힘 판정이 "1m 안 30초" 라 오가기를 못 잡음.
