# W-0015 첫 10분 사명(튜토리얼) 사가고
종류: 새기능(P0) · 사가고      상태: **작성됨**(R-0 완료 2026-10-01)

**목표(한 줄)**: 새 세이브 첫 실행에 5단계(걷기 → 인물 등용 → 짐승 포획 → 보물 상자 → 사명 창 열기)가 **목표판 첫 줄**(`goalNowText`)에 차례로 뜨고, 끝나면 사라진다. 옛 세이브(`tut` 없음)는 처음부터 끝난 것으로 본다.

**확인한 사실**: 튜토리얼 코드 0개. 목표판 첫 줄 = `ui.js goalNowText()`(가장 가까운 상호작용; 마무리 카드 "다음" 줄도 이걸 씀). 단계를 알릴 이벤트가 이미 있다 — `core.emit('dex:new',{cat:'heroes'|'pets',id})`(`encounter.js registerDex`) · `core.emit('treasure:open',{id,grade})`(`treasure.js open`) · 걷기는 `core.save.player.distance`(m). **없는 것**: 사명 창을 열었다는 이벤트(`ui.js openSheet` 는 emit 안 함). 세이브 기본값은 `core.js freshSave()`(SAVE_VERSION 1, 마이그레이션 불필요).

**파일**: `saga-web/saga-go/js/tutorial.js`(새, `DG.tut`) · `js/core.js`(`freshSave` 에 `tut:{done:[],d0:0}` 한 칸) · `js/ui.js`(`goalNowText` 머리 3줄 + `openSheet` 에 `core.emit('sheet:open',{name:name})` 한 줄) · `index.html`·`_test.html`(`node tools/gen-index.mjs --add saga-go js/tutorial.js --after js/quest.js`) · `_demo.html`(quest.js 줄 뒤 한 줄) · `sw.js`(SHELL + VERSION) · `_test.html`(진단 2) · `features.json`(`go.tutorial` 한 항목)

**본보기**: `js/quest.js`(표 `KINDS`·`core.save` 칸 `st()` 지연 초기화) · 이벤트 구독은 `audio.js` 의 `c.on('dex:new', …)` 꼴.

**단계**
1. `tutorial.js`: 표 `STEPS` = `[{key:'walk', text:'🚶 걸어 보세요 — 50m', test: 이동 ≥50m}, {key:'recruit', text:'🤝 인물을 만나 등용해 보세요', on:'dex:new', cat:'heroes'}, {key:'catch', text:'🐾 짐승을 포획해 보세요', cat:'pets'}, {key:'chest', text:'📦 보물 상자를 열어 보세요', on:'treasure:open'}, {key:'quest', text:'🎯 사명 창을 열어 보세요', on:'sheet:open', name:'quest'}]` 와 보상(금 30씩, 마지막 100). 시작 때 `d0 = player.distance`. API: `line()`(지금 단계 문구, 끝났거나 `save.tut` 없으면 `''`) · `step()`(번호) · `done()` · `_feed(evt,payload)`(진단용 — 이벤트를 직접 먹임). 단계는 **순서대로**만 진행(앞 단계 전엔 뒤 이벤트 무시). 완료 때 토스트·`tut.done` 에 key 추가·`core.persist()`.
2. `goalNowText`: 맨 앞에 `var T = global.DG.tut, tl = T && T.line(); if (tl) { return tl; }`.
3. `core.js freshSave`·`ui.js openSheet` 한 줄씩. 사명 창 이름은 `SHEET_TITLE` 의 `quest`(확인됨).
4. 진단 2: ① 새 세이브(`C.save.tut={done:[],d0:C.save.player.distance}`)면 `DG.ui.goalNowText()` 가 1단계 문구 ② `_feed` 로 5단계를 차례로 먹이면 `tut.done.length===5`·`line()===''`, 순서가 바뀌면(상자 먼저) 진행 안 됨.

**검증**
```
node tools/gen-index.mjs --check && bash tools/precheck.sh      → OK (먼저 따로 돌려 확인한 뒤 커밋)
node tools/test-web.mjs saga-go                                 → 839 (837+2), 새 2개 통과, 실패는 기존 ⑲-10 불안정 1 이하
```

**완료 조건**: 위 둘 · 옛 세이브(진단이 `tut` 를 지운 상태)에서 `goalNowText` 가 전과 같다 · `go.tutorial` features D1.

**불변 규칙 확인**: 세이브 키·id 불변 · 판정(전투·포획)에 한 줄도 안 닿는다 · 단독판·`DG_NO_DRAW` 진단 무영향.
