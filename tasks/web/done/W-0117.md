# W-0117 탈것·몬스터 도감 — 사가만리 도감에 탈것 칸 · 사가나락 몬스터 도감

**목표(한 줄)**: 인물·펫 말고 **탈것·몬스터 도감**을 연다. 그림은 이미 있다(탈것 = 연결 펫 초상, 몬스터 = K-0032 초상 32) — 이 티켓은 데이터·화면만.

**파일(확인함, 10-08)**
- 사가만리 도감 화면 `saga-web/saga-go/js/codex.js`(277줄, 213~214행 인물+펫 합계) · 탈것 표 `saga-web/saga-go/js/mount.js` 25행 `MOUNTS`(5: mt_farm·mt_brown·mt_white·mt_crane·mt_dragon, 각 `pet` 칸 = 펫 id → 펫 초상 그대로)
- 사가나락 몬스터 초상 `saga-web/saga-dungeon/assets/portraits-monster/`(boss_01~12 · 몸 계열 20, `<id>_s.webp` 192 · `<id>_c.webp` 300×344) · 그리는 함수 `saga-web/saga-dungeon/js/monster-portrait.js`(`DG.monsterPortrait.html(ref, boss, px)`, 4행: 초상은 몬스터 한 마리가 아니라 **몸 계열**) · 쓰는 곳 `dungeon-view.js` 803행

**단계**
1. 사가만리: `codex.js` 에 탈것 칸 — `MOUNTS` 를 읽어 얻음/못 얻음(지금 세이브의 탈것 해금 칸 — mount.js 에서 해금 판정 함수 grep), 초상 = `pet` 의 펫 초상, 설명 `desc`·속도 `mul`·나는 것 `kind`. 합계(213~214행)에 탈것 더함.
2. 사가나락: 몬스터 도감 화면(새 `js/bestiary.js`) — 몬스터 종류별 처치 수 세이브 칸(`save.kills[<종 id>]`, 없으면 0 — 세이브 판 올림 없이 빈 칸 허용) · 칸 = 종 이름·계열 초상(`monsterPortrait`)·처치 수·처음 만난 층. 처치 지점 grep 해서 한 줄로 셈.
3. 진입 단추: 사가나락 마을 메뉴(기존 메뉴 단추 줄 옆) · 사가만리는 도감 탭.
4. 2D 모드에서도 같은 화면(초상은 이미 2D 그림).

**검증**: `node -c` · `node tools/test-web.mjs saga-go`·`saga-dungeon` n/n(진단 수 안 줄음) · `node tools/qc.mjs --game saga-go`·`--game saga-dungeon` 도감 PNG 눈 ○(칸이 차 있고 초상이 보임) · `bash tools/precheck.sh` OK
