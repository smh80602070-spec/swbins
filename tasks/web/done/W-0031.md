# W-0031 사가국지 RTS P3a — 군영 생산 큐·유닛 선택·이동(길찾기)
종류: 새기능 · 웹(사가국지)      상태: **코드분 끝**(2026-10-04) — 사용자 눈 확인 대기(조작감)      등급 목표: D1→D2

**목표(한 줄)**: W-0028 P3 의 앞 절반. 군영에서 유닛을 **생산 큐**로 뽑고, 드래그 박스로 고르고, 우클릭으로 움직인다(길을 돌아간다). 전투·습격·망루 발사는 P3b(W-0032).

**파일(새·수정)**: 새 `js/rts/units.js`(유닛 표·생산 큐·길찾기 A*·이동 틱) · `js/rts/econ.js`(군 유지비: 식량) · `js/rts/state.js`(유닛·큐 저장·복원) · `js/rts/view.js`(선택 도구·박스 선택·우클릭 명령·군영 패널·유닛 그리기) · `css/rts.css` · `rts.html`·`sw.js`·`_test.html`

**규칙(안)**
- 유닛 3종(가위바위보): **보병**(hp 60·공 8·사거리 1.2·속도 2.2타일/초·20금+10식량·생산 8초, 기병에 강함) · **궁병**(hp 40·공 7·사거리 5.5·속도 2·30금+10식량·10초, 보병에 강함) · **기병**(hp 80·공 11·사거리 1.2·속도 3.4·50금+20식량·14초, 궁병에 강함). 강한 쪽 피해 ×1.5(P3b).
- 군영(도로로 이어진 것)이 큐 5칸까지 쌓고, 비용은 넣을 때 낸다. 끝나면 군영 아래쪽 빈 칸에 나온다.
- 길찾기: 8방향 A*, 모서리 끼어 지나지 않기, **물·건물·성벽은 막고 도로는 지난다**, 막힌 곳을 찍으면 가장 가까운 갈 수 있는 칸으로. 한 번에 최대 8000칸까지 본다.
- 군 유지비: 유닛 1기당 식량 0.2/일(경제 통계에 반영).
- 조작: 기본 도구 **선택** — 왼쪽 끌기 박스 선택·클릭 선택(유닛·군영) · **우클릭(안 끌고)** 이동 명령 · 우클릭 끌기·중간 버튼은 지도 이동 · 선택한 무리는 목적지 둘레에 흩어져 선다.

**단계**: 1 units.js 순수 모델(+진단) → 2 econ·state 연결 → 3 view(선택·명령·군영 패널·그리기) → 4 헤드리스 확인(군영 짓고 생산·박스 선택·이동) → 5 저장 왕복·폰 점검·precheck.

**검증**
```
node tools/test-web.mjs saga-realm   → 284 + 새 진단(길찾기·생산 큐·이동·유지비·저장)
bash tools/precheck.sh → OK · 폰 점검 0건
화면: 헤드리스로 군영→보병 3기 생산→박스 선택→우클릭 이동(물·건물 돌아서)
```

**완료 조건**: 단계 1~5 · 군영 생산→선택→이동이 돌고 새로고침 뒤 유닛이 남는다 · 턴제·P1·P2 진단 그대로.

**불변 규칙**: 에셋 안 만든다(유닛은 색 원+글자) · 세이브 키 불변(`save.rts` 안) · 큐 줄 수 한도 · 원작 이름 금지.
