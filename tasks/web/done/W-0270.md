# W-0270 플레이 QC — 다섯 판을 사람처럼 조작해 보는 자동 검증(pw-play.mjs, PC·폰)
종류: 체제(QC) · 웹(도구)      상태: **끝**(페이블 10-17 — 사용자 "다섯판 플레이 하면 이상한점이 많아 · 2번은 3D 당시 움직이지 못함 · qc를 꼼꼼하게 잘 만들어 놓아봐 · 오퍼스도 충분히 할 수 있게")

**목표(한 줄)**: 지금 QC 는 함수 진단(_test.html)·한 장 촬영·배포 흐름(가입→☰)만 보고 **조작**은 안 본다 — 새 `pw-play.mjs` 가 판마다 PC(1280×720)·폰(390×844 터치) 두 기기로 실제 입력(키 4방향·마우스 끌기·터치 조이스틱/패드/화면 누르기)을 넣어 **정말 움직이는지**, 창을 열고 닫은 뒤에도 움직이는지, 장면을 넘긴 뒤 움직이는지, HUD 가 서로 덮지 않는지, 새로 고침 뒤 이어지는지, 예외가 없는지를 재고 `tools/qc.mjs` "플레이" 줄로 올린다.

**잰 것(R-0, 10-17)**: 2나락 로컬 최신판 — 마을·던전 모두 키(WASD·화살표)·마우스 끌기·터치 누르기로 움직임(dg-walk·dg-probe 임시 탐침, PC·폰 에뮬레이션). 그러니 사용자 "2번 3D 못 움직임" 은 ① 배포본(pw-deploy 10-16: 배포 .137 < 로컬 .138) ② 새 ☰ 메뉴가 Esc 로 열려 화면을 덮은 상태 ③ 장면(컷신)이 떠 키를 먹는 상태 중 하나로 보인다 — 이 셋이 전부 이 QC 의 측정 항목이다. 던전 방은 카메라가 방에 고정이라 **카메라 자리로 이동을 재면 틀린다**(dg-walk 의 가짜 FAIL) — 위치는 판 API 로 읽는다.

**파일**: 새 `saga-web/tools/playcheck/pw-play.mjs` · `tools/qc.mjs`("플레이" 영역 — 기본 PC+폰, `--no-shots` 면 생략) · `saga-web/saga-dungeon/js/town.js`(`DG.town.me()` 위치 노출 한 줄) + `saga-web/saga-dungeon/dist/app.js`·`sw.js` VERSION · 결과 `saga-web/tools/playcheck/results/pw-play.json` · 촬영 `shots/play/`(커밋 안 함) · 임시 탐침 `dg-walk.mjs`·`dg-probe.mjs` 는 지운다.

**단계**:
① `pw-play.mjs [판…] [--pc|--phone]` — 판×기기마다 새 컨텍스트(SW 막음, 씨앗 mulberry32): 가입 → 판별 첫 관문(5천하 시나리오·세력, 2나락 출사표) → 장면 걷기 → 들어감 → 측정 묶음:
   부팅(ms) · 예외 0 · FPS(1초 rAF, 0 이면 FAIL) · 키 4방향(각 1.2초, 판 API 위치 변화 — 3/4 이상) · PC 끌기 / 폰 터치(조이스틱 #gjoy·#vjoy·#rjoy 는 손잡이 밀기, 4종횡 #touchpad 는 오른쪽 단추 누르기, 2나락은 화면 오른쪽 누르기) · ☰ → 첫 칸 창 → 닫기 → 다시 키 이동 · HUD 겹침(보이는 fixed/absolute 요소 쌍, 포함 관계 아님, 작은 쪽 50% 이상 덮이면 WARN·쌍 이름) · 새로 고침 → 이어하기 → 들어감 · 판별 덤(2나락 던전 입장 뒤 키 이동 · 4종횡 사냥터 입장 뒤 이동 · 5천하 3D 지도 끌기)
② 위치 읽기: 1만리 `DG.core.save.player.pos` · 2나락 마을 `DG.town.me()`(새) / 던전 `DG.dungeon.raw().player` · 3마을 `DG.village.raw().player` · 4종횡 `DG.side.raw().player` · 5천하 `DG.realm3d.focusMap()`(3D 지도 초점)
③ `tools/qc.mjs` — `checkPlay()`: 서버 띄워 pw-play 를 돌리고 판마다 "플레이 · PC / 폰" 두 줄(FAIL 항목 이름 나열). `--no-shots` 면 생략.
④ 다섯 판 돌려 나온 FAIL 은 **이 티켓 메모에 적고**, 판 코드 고침은 각자 티켓(R-0)으로 — 단 한 줄짜리(선택자·닫기 단추) 는 여기서.

**검증**: `node saga-web/tools/playcheck/pw-play.mjs saga-go saga-dungeon saga-forest saga-story saga-realm` → 판×기기 10 묶음 결과 줄 · `node tools/qc.mjs --game saga-dungeon` 표에 "플레이" 두 줄.

**완료 조건**: 다섯 판 PC·폰 조작이 QC 에 들어감 · 측정 항목·임계가 이 티켓과 pw-play.mjs 머리 주석에 있어 Opus 가 항목을 더할 수 있음 · 임시 탐침 삭제 · done/.

**불변 규칙**: 판 코드는 위치 노출 한 줄 말고 안 건드린다 · 헤드리스는 스스로 띄우고 끈다 · 촬영은 shots/play/ 에만(커밋 안 함).

**Opus 가 항목 더하는 법**: pw-play.mjs 의 `ADAPT[판]` 에 `extra` 배열 하나 추가(이름·실행 함수·판정) — 공통 측정은 `measure()` 한 곳. 임계는 `ADAPT[판].minMove`.
