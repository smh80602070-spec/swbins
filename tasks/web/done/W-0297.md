# W-0297 1만리 — 쉼터 — 쉬면 부활 자리가 바뀌고 들판 적이 다시 선다

**목표(한 줄)**: 쓰러지면 늘 집 앞으로 돌아가고 들판은 한 번 비우면 비어 있다 → 들판 곳곳의 쉼터(🔥 모닥불 자리)에 앉으면 ① 체력·회피 회복 ② 부활 자리가 그 쉼터로 ③ 그 들판의 잡몹이 다시 선다(보스·숨은 터는 그대로). 쉼터는 처음 앉을 때 "불을 지핀다"(발견), 지도에 표시.

**참고**: 엘든 링(축복)·고스트 오브 쓰시마(구조만 — 이름·수치·그림 안 가져옴) · 채우는 표준 B D · 장부 `tasks/gameplay/go.md`.

**단계**: ① 쉼터 표(지역마다 1~2, 좌표는 들판 시드로) `save.rest = { lit: [id…], at: id|null }` ② 앉기(상호작용 한 줄 → `focus()`/`interact()` 분기) — 회복 + at 갱신 + respawnSweep(force) ③ 쓰러진 뒤 자리 = at 쉼터(없으면 옛 집 앞) ④ 2D·3D 모닥불 표시(불 지핀 것만 빛) · 지도 아이콘 ⑤ 진단 "앉으면 부활 자리"·"잡몹 다시 섬·보스는 안 섬"·"안 지핀 쉼터는 부활 자리 아님" ⑥ build-parts
