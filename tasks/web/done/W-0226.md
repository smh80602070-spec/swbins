# W-0226 1만리 2D 걷기 — 젤다처럼 빠르고 자연스럽게
종류: 손맛 · 웹(1만리, 플래그십)      상태: **끝**(Opus 10-15) · 작성됨(Opus R-0 10-15 — 사용자 "2d 1번 걸어다닌게 넘 느리고 자연스럽지 않은데" · "포켓몬 같이 걷는걸 표현한 것 같은데 2d도 자연스럽게 걷는거 젤다처럼")      등급 목표: D2

**목표(한 줄)**: 1만리 2D(평면·2.5D)에서 키보드·스틱·탭으로 걸을 때 화면 속 걸음이 젤다 「신들의 트라이포스」처럼 몸 높이 2배쯤/초로 가고, 다리 박자가 그 빠르기에 맞는다.

**잰 것(R-0)**
- 걷기 = 3D 와 같은 8m/초(`src/world/01.js` moveSpeed). 2D 는 몸(≈120px)이 지도 칸(48m ≈ 100px)만 해서 화면 2.1px/m — **17px/초 = 0.15 몸/초**(제자리걸음).
- 걷기 시트 보폭(W-0203, 공용 `mode2d.pace`)은 한 바퀴 0.9 몸 — 빨라지면 종종걸음.
- 걸은 거리(`player.distance`)에 보상이 많이 걸려 있다(동행 정·버디·보급·사건·주변 소리).

**파일**: `js/field2d.js`(walkMps·strideMul) · `src/world/01.js`(→ `js/world.js`, 상한 1921 — 줄 안 늘림) · `js/actor2d.js` · `_test.html` · `dist/app.js` · `sw.js`

**단계**
1. field2d.walkMps(몸 높이 m, 3D 빠르기) = 손잡이 `world.walk2dBps` 1.8 × 몸 높이(3D 보다 느려지지 않음, 0 이면 옛 걸음).
2. moveSpeed: 3D 아님·들판 전투 안 붙음이면 2D 빠르기(몸 높이 = 그리는 배율 × 48 / scale — 확대해도 화면 몸/초 같음). 달리기 ×2.2·탈것·성도 그대로 곱함.
3. 걸은 거리는 `moved × credit2d`(= 8 / 2D 빠르기) — 시간당 보상은 3D 와 같다. GPS 는 그대로. 발자국은 반 보폭마다.
4. actor2d: 보폭 한 바퀴 ×`world.stride2d` 1.45(≈1.3 몸).
5. 진단 +1 · bundle · sw +1.

**검증**: `node tools/test-web.mjs saga-go` n/n · `node tools/qc.mjs --game saga-go` PASS · `saga-web/tools/playcheck/tmp/w226-walk2d.mjs`(→ 걸음 m/초·다리 Hz·걷는 중 4장)

**완료 조건**: 2D 화면 걸음 ≈ 1.8 몸/초, 다리가 미끄러지지 않음 · 보상 셈 그대로 · done/ 로.

**불변 규칙**: 3D·GPS·들판 전투 판정 안 바꿈 · 공용 mode2d.js 안 고침(다섯 벌 md5 같음) · 그림 안 고침.
