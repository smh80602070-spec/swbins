# W-0372 1만리 2D — 인물이 나무를 밟고 다님(소품 깊이 정렬·나무 칸 막기)
종류: 그래픽·게임성(2D 들판) · 웹(1만리 field2d·world)      상태: **끝**(10-22 오퍼스) · 작성(오퍼스 R-0 10-22 — 사용자 10-22 아이폰 세로 2D "1번은 나무를 밟고 다니네")

**목표(한 줄)**: 1만리 2D 들판 소품(나무·바위·풀포기)은 `field2d.decorate()` 가 땅 칠하기 단계에서 먼저 그려, 나·주민·떠돌이가 언제나 그 위에 덧그려진다(나무 줄기 앞에 서도·뒤에 서도 몸이 나무를 덮음 = 밟고 다니는 것처럼 보임) → ① 키 큰 소품(나무·큰 바위)은 땅 단계에서 빼서 인물과 같은 깊이 줄(`items` v 정렬)에 넣어 발 y 가 아래인 쪽이 앞에 오게 ② 나무 줄기 칸은 2D 걷기에서 밀어내기(작은 원 충돌 — 길 찾기·GPS 모드는 그대로).

**파일**: `saga-web/saga-go/js/field2d.js`(decorate·propsAt — 키 큰 소품 표 · 새 `tallProps()` 로 넘김) · `saga-go/src/world/01.js`(땅 그리기 decorate 부름 ~563) · `saga-go/src/world/02.js`(items 깊이 줄 ~600~660 · 2D 걷기 이동) · `js/world.js`(조립 — 줄 상한 1921, 기존 줄 끝) · `_test.html` · `dist`·`sw.js`

**단계**: ① 폰 390×844 pw-look2d saga-go map 으로 나무 옆을 지나는 장면 전(나 위치를 나무 줄기 위·뒤·앞 셋으로 옮겨 찍기) ② decorate 가 키 큰 소품을 그리지 않고 목록으로 돌려줌(손잡이 `go.propDepth` 1 · 0 = 옛) ③ world items 에 v = 소품 발 y(화면) − 나 y 로 넣어 정렬 ④ 2D 걷기 이동에 줄기 원(반지름 몸 폭 0.35) 밀어내기 — 손잡이 `go.treeBlock` 1 ⑤ 같은 세 장 후 Read ⑥ 진단

**검증**: `node tools/test-web.mjs saga-go` n/n(+1 "나무 발 y 가 나보다 아래면 나 뒤에 그림 · 줄기 원 안으로 못 들어감 · 손잡이 0 이면 옛") · 전후 세 장 Read · `node tools/qc.mjs --game saga-go`
