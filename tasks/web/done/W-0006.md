# W-0006 `saga-web/RULES.md` + 판별 CLAUDE.md 를 큐로
종류: 통합      판: 웹 다섯      등급 목표: (체제) — 첫 턴 20KB

**목표(한 줄)**: 다섯 판 PLAN §2 "반드시 지킬 것"과 판별 CLAUDE.md 를 `saga-web/RULES.md`(8KB 안) 하나로 모으고, 판별 CLAUDE.md 는 "다음 일 = tasks/web/QUEUE.md" 두 줄로 줄인다.

**파일**: `saga-web/RULES.md`(새) · `saga-web/saga-go/CLAUDE.md`·`saga-dungeon/CLAUDE.md`·`saga-forest/CLAUDE.md`·`saga-story/CLAUDE.md`·`saga-realm/CLAUDE.md`

**본보기**: 루트 `CLAUDE.md` 의 "하지 말 것" 절 꼴(한 줄 = 규칙 하나, 이유는 괄호 한 토막).

**단계**
1. 판마다 `grep -n "^## 2" saga-web/<판>/PLAN.md` → 그 절만 `sed -n`. 규칙 문장만 뽑는다(설명·이력은 버린다).
2. `RULES.md` 짜임: 머리 3줄(이 파일의 뜻·8KB·PLAN §2 가 원본) → "## 공통(다섯 판)" → "## 사가고" … 다섯 절. 판별 10줄 안.
3. PLAN §2 는 지우지 않는다(원본). RULES 는 요약본이고 충돌하면 PLAN §2 가 이긴다고 머리에 적는다.
4. 판별 CLAUDE.md 를 다음 두 줄로: `다음 일 = ../../tasks/web/QUEUE.md 맨 위(절차 tasks/README.md). 규칙 = ../RULES.md, 설계 = 이 폴더 PLAN.md(절만 sed -n).` + `세이브 키·포트는 루트 CLAUDE.md 표.`
5. `wc -c saga-web/RULES.md` < 8192.

**검증**
```
wc -c saga-web/RULES.md saga-web/*/CLAUDE.md     → RULES < 8192, CLAUDE 각 < 400
bash tools/precheck.sh                             → PRECHECK OK
```

**완료 조건**: 위 둘 · 다섯 판 규칙이 빠짐없이(PLAN §2 불릿 수 ≥ RULES 그 판 줄 수 — 합쳐도 되지만 빠뜨리진 않는다).

**불변 규칙 확인**: PLAN 수정 0 · 게임 코드 0.

**메모(체크포인트)**:
- saga-web/RULES.md 6310B(공통 7줄 + 판별 6·7·6·5·6줄, 전부 PLAN §2 불릿 수보다 적음) · 판별 CLAUDE.md 다섯 개 211~220B. 판별 CLAUDE.md 에만 있던 규칙(사가블로 옛 절 번호·사가의숲 구면 투영·사가국지 quiz 예외/옛 절 번호)은 RULES 로 옮김. "README·HANDOFF 통째 금지"·"세션 기록은 HANDOFF 에만"은 루트 CLAUDE.md 에 있어 뺌.
- RULES.md 8KB 상한은 precheck 에 아직 없음(W-0004 범위 밖) — 다음 precheck 손볼 때 limit 한 줄.
