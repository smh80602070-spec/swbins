# W-0104 사가종횡 — 레벨업 무예 3택 + 사냥터 결과 등급 (리뉴얼 ④, 던파 참고 · 재미표준 D·B)
종류: 새기능 · 웹(사가종횡)      상태: 끝(2026-10-08) — features st.job-2 D2      등급 목표: D2

**목표(한 줄)**: 무예 96 을 거의 다 찍어 고르는 재미가 없는(재미표준 D × — Lv.70 SP 207 vs 한 벌 만렙 240, 86%) 구조를 **레벨업마다 3택**으로 바꾼다 — 서로 다른 사슬(유파)에서 하나씩 세 무예가 뜨고 고른 것만 +1. 그리고 사냥터 한 판이 끝날 때 **결과 등급**(S·A·B·C: 걸린 시간·피격 수·최대 콤보)을 세션 카드에 얹어 "이번 판이 어땠나" 가 남게 한다(B).

**설계(페이블, 옛 세이브 보호가 핵심)**
- SP 는 파생값(`job.js` 머리말: `(레벨-1)×SP_PER_LEVEL` − 찍은 합). 바꾸는 법: `save.spCutLv`(없으면 **지금 레벨**로 마이그레이션 — 옛 세이브는 여태 SP 그대로, 새 세이브는 1) 를 두고 `spTotal = (min(level, spCutLv) − 1) × SP_PER_LEVEL`. 그 뒤 레벨은 SP 대신 **3택**(`save.offers = [{lv, keys:[k1,k2,k3], picked}]`, 레벨마다 1장).
- 3택 규칙: 지금 직업의 무예 중 `canRaise` 가 참인 것에서 **사슬(school) 서로 다른 셋**(규격 D "같은 축 둘 금지"), 100회 굴려 중복 0. 고르면 `raise(key)` 를 SP 검사 없이 통과시키는 `raiseFree(key)`. 거절 = SP 1(기존 `raise` 로 쓸 수 있는 "강화 점수").
- 결과 등급: 사냥터 들어갈 때 `run = {t0, hits, comboMax}` 를 `side.js` 가 세고(피격·콤보는 이미 계산되는 값을 기록만), 나올 때(마을 복귀·사망) `rankOf(run)` = 시간·피격·콤보를 PLAN §5-7 손맛 수치 기준으로 S/A/B/C → 세션 카드 한 줄 "⭐ 이번 판 등급 A — 피격 3 · 콤보 12 · 2:40".
- 결과 등급 진단은 순수 함수(화면 없이) · 3택은 `hero:levelup`(hero.js 141행 gainExp 가 쏜다) 을 받아 **주인공만**(`core.save.party[0]`) 띄운다.
