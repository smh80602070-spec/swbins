**결과(10-05)**: ✔ 고친 것은 하나 — 탭이 숨겨지면 주 루프가 0.5초마다 다음 프레임을 다시 예약하던 것(`setTimeout→rAF`)을 **예약 자체를 멈추고** `visibilitychange`·`focus`·`pageshow` 가 깨운다(`loopGate()`·`wakeLoop()`, 멈춰 있을 때만 한 번 — 사슬이 둘이 되지 않게). 사가고·사가블로·사가의숲·사가스토리 `game.js`(같은 모양). 포커스만 잃은 보이는 창은 예전처럼 0.5초 들여다봄. 진단 사가고 +2(문지기·"결투를 도망으로 끝내면 예약 프레임 0") 860/860, 나머지 셋 +1 씩 462·411·282, 번들 재생성·VERSION +1.

**하지 않은 것(이유)**: ② "시트 열림 render 0" 은 안 했다 — 시트가 유리처럼 비치는 부분 덮개(폰 76%·데스크톱 392px)라 뒤 3D 가 보이는 채라, 멈추면 **보이는 화면이 달라진다**(불변 규칙 위반). 이미 폰은 시트 열림 30fps cap. ③ 2D 모드는 처음부터 render 0. 결투·인카운터·rogue-action 루프는 끝날 때 `cancelAnimationFrame` 이 이미 있어 누락 없음(진단으로 고정). 사가국지는 3D 장면 루프(realm3d·city3d·battle3d)가 숨김일 때 렌더 없이 0.5초 타이머만 돌고 RTS 루프는 브라우저가 숨김 때 rAF 를 멈추므로 손대지 않음(실익 없음, 수치 미측정).
