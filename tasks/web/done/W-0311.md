# W-0311 다섯 판 — 2D 16방향·여러 장 모션 — 시트 규격을 8방향 8프레임에서 16방향·동작별 프레임 수로
종류: 새 기능(그래픽·2D) · 웹(다섯 판, 공용 mode2d)      상태: **끝**(10-18 오퍼스 — 코드분 D1, D2 는 K 시트 뒤)

**목표(한 줄)**: 2D 인물은 8방향(실제 5행 + 뒤집기) × 8프레임 고정이라 대각 사이가 뚝 끊기고 동작이 짧다 → ① 방향 16(22.5° 칸, 9행 + 뒤집기) ② 동작마다 프레임 수가 다름(걷기 12·달리기 8·공격 10·강공격 14·앉기 6·시전 12·피격 4·쓰러짐 10, 표로) ③ 동작 종류는 모션 묶음 1(W-0303)의 열 가지를 포함 — `mode2d` 가 시트 규격을 폴더의 `sheet.json`(dirs·rows·frames·fps·foot)으로 읽어 8방향 옛 시트와 16방향 새 시트를 **섞어 쓴다**(새 시트가 온 인물부터 16, 없으면 8로 그대로). 같은 사람인지(K 그림 붙일 때 원본 대조) 확인은 그대로.

**참고**: 디아블로 2(16방향 8~16프레임)·옥토패스(HD-2D 프레임) — 구조만 · 장부 `tasks/gameplay/README.md` 그래픽 절 "2D 반은 참고작만큼(10-14)".

**파일**: `saga-web/shared/js/mode2d.js`(cell8·dirOf8·frameAt·roleOf — 정본, 다섯 판 사본은 sync-shared) · 새 `saga-web/shared/js/sheetspec.js`(sheet.json 읽기·캐시·16방향 행 계산·동작별 프레임) · 판마다 `js/actor2d.js`(호출 인자 한 줄) · 1만리 `src/field-combat/*`(동작 상태 → 역할 이름 한 줄) · `_test.html`(공용 값 층 진단) · manifest · `dist/app*.js`·`sw.js` · K 몫: `characters2d16/<id>/<역할>.webp` + `sheet.json`(INBOX 10-18 줄 — 굽기는 자체툴)

**단계**: ① sheetspec — 규격 표 기본값(16방향·동작별 프레임)과 `sheet.json` 읽기, 없으면 옛 8방향 규격 ② dirOf16(22.5° 칸·뒤집기 표) · cellOf(spec, natW) ③ frameAt(role, ms, spec.frames[role], spec.fps) — 걷기는 보폭 위상 그대로 ④ 역할 이름 열 가지(W-0303 과 같은 키) → 시트에 없으면 가까운 역할(표) ⑤ 다섯 판 호출 한 줄 · 사본 sync ⑥ 진단 "16방향 행·뒤집기 표"·"동작별 프레임 수"·"새 시트 없으면 8방향 그대로"·"보폭 위상 유지" ⑦ 대역: K 시트 오기 전엔 8방향 시트를 16방향 칸에 가장 가까운 행으로 매핑(끊김은 같지만 코드 길은 열린다) ⑧ 촬영 한 장(16방향 시트가 하나라도 오면 그 인물로, 아니면 대역)

**검증**: `node tools/test-web.mjs saga-go` · `saga-forest` · `node tools/qc.mjs --branch web` · 2D 촬영.
