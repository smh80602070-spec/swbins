# W-0011 사가고 `world3d.js` 쪼개기 (소스 분할 + 조립)
종류: 통합 · 사가고      상태: **작성됨**(R-0 완료 2026-10-01)

**목표(한 줄)**: 3,503줄 `world3d.js` 를 절 경계 따라 5개 소스 조각(각 1,500줄 미만)으로 나눠 `saga-go/src/world3d/` 에 두고, `tools/build-parts.mjs` 가 이어 붙여 **지금과 바이트까지 같은** `js/world3d.js` 를 만든다. 런타임·호출부·로드 순서 변경 0.

**확인한 사실**: 파일 전체가 `(function(global){…})(window)` **하나의 클로저**다. 최상위 심볼 232개 중 **다른 절이 쓰는 것이 137개**(변수 50 — `T`·`renderer`·`scene`·`camera`·`actors`·`frame`·`stageAt`·`duelFoe` … · 함수 87)라, 조각을 따로 `<script>` 로 싣는 "진짜 쪼개기"는 이 50개를 공유 상태 객체(`S.x`)로 바꾸는 수천 곳 치환이 된다(지역 변수와 이름이 겹쳐 오치환 위험, 진단이 못 잡는 화면 회귀). 그래서 **소스만 나누고 실행 파일은 조립**한다(`sync-shared` 와 같은 꼴). 진짜 분리는 별도 결정.

**파일**: `saga-web/saga-go/src/world3d/01-core.js`…`05-render.js`(새) · `tools/build-parts.mjs`(새) · `tools/precheck.sh`(절 하나) · `tools/README.md`(한 줄) · `saga-web/RULES.md`(사가고 한 줄: "world3d 는 src/world3d/ 조각을 고치고 build-parts 로 조립") · `saga-web/saga-go/js/world3d.js`(**글자 불변**)

**본보기**: `tools/sync-shared.mjs`(`--check` 꼴) · 절 경계 = 주석 줄 `  /* ── ` (현재 17곳).

**단계**
1. 조각(줄 번호는 지금 기준, **줄 단위로 자르고 바이트 그대로**): `01-core` 1~429(머리·규칙값·시간대 조명·켜기·지면·땅칠) · `02-ground` 430~954(땅 소재 텍스처·높낮이) · `03-props` 955~2113(건물·나무·인스턴싱) · `04-actors` 2114~2862(배우·동행 모션·조우·전투·교전 상대) · `05-render` 2863~끝(카메라·빛·그린다·내보내기·`})(window);`). 조각 파일은 단독으로는 문법이 안 맞는다(한 클로저의 토막) — 괜찮다.
2. `build-parts.mjs`: 표 `{out: saga-go/js/world3d.js, dir: saga-go/src/world3d}` → `dir` 의 `*.js` 를 이름순으로 바이트 그대로 이어 `out` 에 쓴다. `--check` = 이어 붙인 md5 와 `out` md5 를 비교, 다르면 "조각을 고쳤으면 node tools/build-parts.mjs, world3d.js 를 직접 고쳤으면 조각에 옮길 것" 찍고 종료 1.
3. 처음 한 번: 현재 `world3d.js` 를 위 줄 범위로 잘라 조각을 만든 뒤 조립 → md5 가 **처음 것과 같음**을 확인.
4. precheck: "== world3d 조립" 절에서 `node tools/build-parts.mjs --check || fail=1`. 조각은 `js/` 밖이라 구문 검사에서 빠진다(조립본이 검사됨).
5. README·RULES 한 줄.

**검증**
```
md5sum saga-web/saga-go/js/world3d.js   → 시작 전에 적어 둔 값 그대로(조립 뒤에도)
node tools/build-parts.mjs --check      → OK, 종료 0 ; wc -l saga-web/saga-go/src/world3d/*.js → 각 1,500 미만
node tools/test-web.mjs saga-go         → 828/828 (불안정 진단 때문에 827/828 도 가능, 실패 이름은 같은 것)
```
