# W-0450 5천하 = 조조전식 장 흐름(노선도 → 이야기 → 진영 → 격자 전투 → 결과)

**까닭**: 사용자 10-26 「5천하는 삼국지처럼 지도 화면이 아니고 전략 시물 알피지 처럼 화면을 구성해주면 좋겠네」 → 고름 「조조전식 장 흐름」(노선도 → 이야기 → 진영(편성·장비·상점·대화) → 격자 전투 → 결과 → 다음 장. 성 운영·지역 지도는 뒤로). 전투는 이미 격자 SRPG(W-0401), 바깥이 코에이식 지역 지도(W-0400)라 그 바깥만 바꾼다.
**잰 것(10-26 조사)**: 이야기 = data-scenario.js CARDS 19(본 사슬 1~16 = 6막 「천하의 끝」까지, 17~19 = 7막) · 카드 = {id, act, title, text, choices[k atk/def/util, fx]} · 컷 그림 cutscene.url('realm', id). 격자 전투는 혼자 열림 — tacticsView.open(host, {seed, land, siege, srpg:true, goal(rout/leader/gate/hold), mine[≤3], foes[≤3], foeTroops[1], myTroops[1], where, name, face}, done(out{kind win/rout/lose…, fallen, wounded})). 명부 DG.off(ofForce·lordOf·gainExp·equip) · 보물 DG.item.ITEMS 11(한 장수 하나) · **상점 없음**. 부팅 ui-rtk init(시작 전 = 시나리오·세력 고르기 → R().setup).
**목표**: 손잡이 `realm.campaign`(1 = 장 흐름이 첫 화면, 0 = 옛 지역 지도 그대로) — 세력 고르기 뒤 전체 화면 `#campaign` 이 노선도부터.
- 노선도: 막별 장 노드(깬 장 ✓·지금 장 빛남·잠김), 지금 장을 누르면 이야기.
- 이야기: 컷 그림 + 제목·본문 + 고름 셋(atk = 내 병력 +15% · def = 적 병력 −10% · util = 금 +200, 이번 장 한정).
- 진영: 탭 넷 — 편성(내 장수 초상·능력 → 출진 셋 고름) · 장비(보물 끼우기/빼기, 가방) · 상점(보물 사기 — 값은 bonus 로) · 대화(장수 한 줄·관계). 「출진 ▶」.
- 전투: 장마다 표(땅·공성·승리 조건·적 세기 단계) · 적 장수 = 내 세력 밖 살아 있는 장수를 세기 순으로 장 단계만큼 · 병력 = 장 번호로 늘림.
- 결과: 이기면 금·경험(출진 셋)·보물 하나(확률)·다음 장 열림, 지면 「다시 도전」(진영으로). 쓰러진 장수는 기존 permadeath 손잡이 따름(기본 중상만).
- 세이브 `save.rtk.campaign` = {ch, step, party[], gold, bag[], cleared{}, bonus}. 옛 세이브는 ch 1 부터.
