종류: 새기능(그래픽) · 웹(사가나락)      상태: 끝(10-09 · Opus 10-09, 사용자 "2d 모드에서 액션 알피지 같은 화면들로" · "던전앤 파이터 같은 화면" · "찾아서 추천해서 해줘" · "지금은 2d 넘 구림" · "티켓에 추가해서 작업해줘")      등급 목표: D2

**목표(한 줄)**: 2D 모드 던전 방을 아이소 마름모(작은 인물이 점처럼 섬) 대신 **던전앤파이터식 벨트 스크롤** — 옆에서 본 화면, 화면 아래 깊이 띠에서 움직이고, 인물이 화면 높이 ⅕ 안팎으로 크게, 카메라가 나를 따라 좌우로 흐른다.

**추천 근거**: 2D 액션 RPG 중 던전앤파이터(방 → 문 → 다음 방, 벨트 스크롤)가 사가나락 던전 구조(`run.room`·`doors`)와 뼈대가 같다. 드래곤즈 크라운(겹 그림 배경)·캐슬 크래셔즈도 같은 계열. 사가종횡(원작 메이플, 이미 옆 화면)·사가마을·사가천하(액션 아님)는 대상 아님 — 2차는 사가나락 마을·들판, 사가만리 들판 전투(따로 티켓).
