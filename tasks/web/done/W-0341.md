# W-0341 다섯 판 폰 글자 12px 아래 없애기 — 11px `.p-sub`·`.p-title`·`small`·`.tag` 를 공용 바닥값으로
종류: 버그(모바일 글자) · 웹(다섯 판 공용)      상태: **끝**(오퍼스 10-19 · 작성 R-0 10-19 — W-0335 시트 ⑦: 1만리 9 · 2나락 7 · 3마을 19 · 4종횡 20 · 5천하 110)

**목표(한 줄)**: 폰에서 11px 글자(`div.p-sub`·`div.p-title`·`small`·`b.mm-range`·`div.dg-tip`·`div.coin`·`span.tag`·목표 줄 `.p-goal`)가 판마다 7~110 개. 공용 `ui-kit.css` 에 폰 글자 바닥값(본문 13px · 보조 12px — CSS 변수 `--fs-min`) 하나로 올리고, 5천하처럼 표·목록이 많은 판은 줄 높이·칸 너비를 같이 맞춰 넘침이 생기지 않게.

**파일**: `saga-web/shared/css/ui-kit.css`(정본 + sync-shared) · 판별 `style.css` 의 11px 규칙(5천하 `ui-rtk`·`cpanel` 쪽 표·태그가 대부분) · 번들·sw 다섯

**단계**: ① 판별 11px 출처 규칙 grep(`font-size: *11px`·`.68rem` 류) ② 공용 변수·폰 미디어 규칙 ③ 판별 규칙을 변수로 ④ `pw-mobile.mjs` 다시 ⑤ 사진 세로·가로 — 글자 잘림·두 줄 꺾임 늘지 않음

**검증**: `node saga-web/tools/playcheck/pw-mobile.mjs` 다섯 판 글자<12 = 0(남으면 그 요소·이유 메모, 5천하 ≤ 10) · 넘침 0 · `node tools/test-web.mjs <판>` 다섯 판 n/n · `node tools/qc.mjs --branch web --no-shots`

**완료 조건**: 공용 바닥값 · 다섯 판 전/후 표 · 사진 · done/.

**불변 규칙**: PC 그대로 · 세이브 키 그대로 · 글자 내용·이름 정책 안 건드림.
