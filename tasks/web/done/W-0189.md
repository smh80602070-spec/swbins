# W-0189 3마을 2D⇄3D 단추를 눈에 띄게 — 3D 기본은 그대로
종류: UI · 웹(3마을)      상태: 끝 D2(10-13) — 작성 Opus R-0 10-12 — 사용자 모바일 검증 "3번은 2d구현이 안된거지?", 답 "지금대로 두기 — 3D 기본 유지, 2D 단추만 더 눈에 띄게")      등급 목표: D2

**목표(한 줄)**: 3마을을 3D 로 시작하는 건 그대로 두고, 2D(구면 마을)로 바꾸는 단추를 폰에서도 한눈에 보이게 — 「⋯」 안에 숨지 않게.

**잰 것(R-0, 10-12)**
- 3D 기본 = `village-view3d.js` 52행 `ON()` → `village3d.on` 기본 1(09-09 결정). 바꾸는 단추 = `index.html` 46행 `#btn-3d`(🧊, 제목 "3D 로 걷기 (실험…)") — **`#btn-more`(⋯) 팝오버 안**이라 폰 첫 화면엔 안 보인다(폰 흉내 사진 `shots/mobile_play_saga-forest.png`: 상단 오른쪽 넷 = 👤·🤖·✋·⋯).
- 단추 글은 🧊 그림뿐 — 지금 3D 인지 2D 인지 글자로 안 나온다.

**파일(확인함, 10-12)**
- `saga-web/saga-forest/index.html` 40~50행(상단 단추·`#btn-more` 안 목록) · `saga-web/saga-forest/js/ui.js` 상단 단추 묶음(조각 정본 `src/ui/01.js` — `grep -n "btn-3d\|btn-more" src/ui/*.js` 로 확정) · `saga-web/saga-forest/js/village-view3d.js` 1257행 토글 · `css/style.css`

**설계(정해 둠)**
- 🧊 를 `⋯` 밖 상단 줄로 꺼내고 글자 표시 「3D」/「2D」(지금 모드)를 붙인다. 누르면 바뀌고 토스트 "2D 마을로 바꿨습니다 — 🧊 로 다시 3D".
- 첫 실행 때 한 번만 안내 거품 "2D 로도 볼 수 있어요"(세이브 칸 하나 — 키 새로 안 만들고 `core.save.ui` 안에).
- 폰 상단 줄이 넘치면 ✋(손) 단추는 하단 행동 카드가 이미 있으니 `⋯` 안으로 — 자리 바꿈만.

**단계**: 1. 단추 자리·글자 2. 토스트·첫 안내 3. `_test.html` 진단(단추가 ⋯ 밖·글자가 모드와 맞음·누르면 village3d.on 뒤집힘) 4. 폰 흉내 사진 2장(3D·2D) 5. bundle·sw VERSION.

**검증**: `node tools/test-web.mjs saga-forest` → RESULT n/n · `node saga-web/tools/playcheck/mobile-probe.mjs saga-forest`(로컬) 사진 Read ○ · `node tools/qc.mjs --game saga-forest` PASS.

**완료 조건**: 폰 첫 화면에 2D/3D 단추가 보이고 글자로 지금 모드를 알려 줌 · 3D 기본 그대로 · 진단 초록.

**불변 규칙**: 3D 기본값·구면 투영 안 바꿈 · 세이브 키 그대로 · 큰 파일 줄 수 상한(ui.js 1977).
