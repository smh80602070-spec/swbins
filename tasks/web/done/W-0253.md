# W-0253 메뉴 UI 갈아엎기 ② ☰ 메뉴 화면(아이콘 격자) — 독 단추 줄을 접는다, 1만리 먼저
종류: 화면(메뉴 배치) · 웹(공용 → 1만리)      상태: **끝**(Opus 10-16) · 작성됨(Opus R-0 10-16 — 수신함 17행 "메뉴 UI 전체 변경", W-0252 다음)      등급 목표: D2

**목표(한 줄)**: 아래 독에 단추 10~14개가 한 줄로 늘어선 것(1만리 11: 나·사명·동행·성도·행낭·천거·도감·사관·기록·키설정·설정)을 — 독엔 자주 쓰는 넷 + **☰ 메뉴**만 남기고, ☰(또는 Esc)를 누르면 화면을 덮는 **메뉴 화면**(원신 일시정지 메뉴 꼴: 판 색 옷 카드 격자, 큰 아이콘 + 이름, 알림 점)이 열린다.

**잰 것(R-0)**: 독은 다섯 판 다 `nav#dock > button[data-sheet]`(+ id 단추 `#btn-star` 같은 것) — 아이콘은 `<span data-icon>`(Lucide, 1만리·2나락·4종횡) 또는 이모지, 이름은 `<small>`. 누르면 판별 ui 가 `openSheet` — **메뉴 화면은 독 단추를 읽어 격자를 만들고 누르면 그 독 단추를 click()** 하면 판별 데이터·JS 를 안 건드리고 다섯 판에 같은 파일로 붙는다.

**파일**: 새 `saga-web/shared/js/menu-grid.js`(sync-shared, 다섯 판 목록은 붙이는 티켓이 더함 — 이 티켓은 1만리만) · `saga-web/shared/css/ui-kit.css`(메뉴 화면 절) · `saga-go/js/manifest.json`(gen-index --add, ui 뒤) · `saga-go/js/core.js`(`DG.cfg.menu = { keep: ['me','quest','party','bag'] }`) · `saga-go/_test.html` · `dist/app.js` · `sw.js`

**단계**: ① menu-grid.js — 시작 때 `#dock` 앞에 ☰ 단추 하나, `cfg.menu.keep` 밖 단추에 `data-menu-only` 붙여 독에서 숨김(CSS) · 격자는 열 때마다 독 단추에서 만든다(아이콘 span·small·title·`.dot`/배지 그대로 복사) · 칸 누르면 메뉴 닫고 원래 단추 click() · Esc: 시트·모달이 열려 있으면 그쪽이 먼저(기존 Esc 처리 존중 — 아무것도 안 열렸을 때만 메뉴 토글) · 패드: 열렸을 때 화살표·A ② CSS — 덮개(어둡게+흐림) 위 가운데 격자, 칸 = card 9-slice, PC 4~5열·폰 3열, 칸 최소 96px(ui_parts min_touch_px) ③ cfg 없으면 아무것도 안 함(다른 판 안전) ④ 진단: 1만리에서 ☰ 단추 있음 · 숨긴 독 단추 수 = 전체 − keep · 격자 칸 수 = 독 단추 수 · 칸 click → 원래 단추 click 이 불림(가짜 단추로) · cfg 없으면 no-op ⑤ pw-menu-sheet.mjs 에 메뉴 화면 한 장(PC·폰) 더함.

**검증**: `node tools/sync-shared.mjs --check` OK · `node tools/test-web.mjs saga-go --runs=2` n/n SAME · `node saga-web/tools/playcheck/pw-menu-sheet.mjs saga-go` 두 장 Read ○ · `node tools/qc.mjs --game saga-go` PASS

**완료 조건**: 1만리 독 = 넷 + ☰ · 메뉴 화면에서 11개 다 열림(진단) · Esc 겹침 없음 · Claude 눈 ○ · qc PASS · done/ 로.
