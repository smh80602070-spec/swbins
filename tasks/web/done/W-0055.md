# W-0055 레벨업 버스트 — 사가블로·사가스토리 레벨업에 K-0039 levelup_burst(W-0054 후속)
종류: 새기능 · 웹(사가블로·사가스토리)      상태: **닫음 2026-10-05**(눈 확인 — Claude 직접 촬영, 시트 web-visual-20261004 12번 ○)      등급 목표: D1→D2

**목표(한 줄)**: 레벨이 오르는 순간 플레이어 자리에서 K-0039 `levelup_burst` 가 터지게 한다. 게임 규칙 코드는 안 건드린다(알림만 듣는다). 에셋은 만들지 않는다.

**지금 상태(확인함)**: 두 판 모두 `core.js gainExp` 가 `levelup` 알림을 낸다. 사가스토리는 이미 `side.js` 가 그 알림으로 배너 fx(`levelup`)를 쌓는다. 사가블로는 알림만 있고 화면 효과가 없다.

**연결**: 공용 `vfx2d.js` 가 판 `cfg.vfx.levelup` 이 있으면 `levelup` 알림을 들어 그 함수를 부르고, 함수는 자기 fx 목록에 `{t:'lvl'}` 를 쌓는다 → `fxLayer` 가 `levelup_burst`(170px) 로 그린다. 사가블로는 2D 아이소일 때만(3D 는 파티클 몫). 사가스토리는 기존 `levelup` 배너 fx 를 `side-view.js vfxLayer` 가 플레이어 가슴께 버스트로 겸해 그린다.

**파일**: `shared/js/vfx2d.js`(`lvl`·알림 듣기) · `saga-dungeon/js/core.js`(`cfg.vfx.levelup`·프리로드) · `src/dungeon-view/02.js`(`lvl` 도 얹음, 줄 수 불변) · `saga-story/js/side-view.js` · `tools/sync-shared.mjs`(`levelup_burst` 두 판) · `sw.js`(dungeon-v0.199.16·side-v0.118.17)·`_test.html`

**검증**: `node tools/test-web.mjs saga-dungeon saga-story` 통과(459/459·280/280) · `precheck` OK · 레벨업(`gainExp`)을 일으켜 촬영.
