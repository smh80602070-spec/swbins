   - `st.side-3` 사냥터에서 채집물 위로 **실제 키로** 지나가면 가방 증가·그 자리 잠깐 비고 시간 뒤 다시 돋음(`DG.side.buildForageZone` 상태) · 만들기 재료 모자라면 안 덜림, 차면 탕약 지급 · 보물상자 열어 보상.

   - `st.sfx` 적을 때리면 `DG.sfx._tail()` 에 hit·hit2·hit3 가 라운드로빈 · 효과음 끈 채(`setEnabled(false)`)도 요청이 남는다 · 적을 잡으면 죽음 소리 기록.
