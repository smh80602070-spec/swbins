# W-0275 2나락 3D 카메라가 너무 멀다 · 로딩 때 상자가 보였다 바뀐다
종류: 손맛·화면 · 웹(2나락)      상태: **끝**(Opus 10-17 — 사용자 사진 "카메라 앵글이 문제고 왜 캐릭터가 시작할 때 저기 있는거야" · "화면 로딩 되는 부분이 보기 싫어")

**목표(한 줄)**: 사용자 PC(1911×917) 2나락 마을 3D 가 마을 전체가 들어올 만큼 멀어 인물이 점이었다 → 벨트 카메라에선 끝까지 오므려도 기본의 1.4배까지만. 마을·던전에 들어설 때 갈색 대역 상자가 섰다가 모델로 툭 바뀌는 것 → 건물 먼저 받고, 다 올 때까지 가림막.

**잰 것**: `dg-town-cam.mjs 1911 917 0.32` 로 사용자 사진 그대로 재현 — 줌은 세이브(`settings.camZoom`)에 남고 3D 거리는 그 값으로 **나눈다**. 하한 0.32 는 옛 마을 camAim(거리 0.4배) 시절 값이라 벨트 카메라에선 3.1배 멀어졌다. `dg-load-seq.mjs` — 마을 들어선 뒤 받을 모델 36, PC 는 마을 사람 몸(각 ~600KB)이 먼저 줄을 서 건물이 상자로 남았다(폰만 "사람 몸 뒤로" 규칙이 켜져 있었다, W-0214).

**파일**: `saga-web/saga-dungeon/src/dungeon3d/04.js`(→ js/dungeon3d.js) · `js/asset3d.js` · 새 `js/load-veil.js` · `js/manifest.json`·`index.html`·`_demo.html`(gen-index) · `dist/app.js` · `sw.js` · 도구 `saga-web/tools/playcheck/dg-town-cam.mjs`·`dg-load-seq.mjs`.

**단계(한 것)**: ① 벨트 카메라일 때 줌 하한 0.7(손잡이 `dungeon3d.beltZoomMin`) ② asset3d `lazyNpc` auto = 모든 기기(사람 몸은 낮은 줄 — 건물·내 몸·동료 먼저) + `hiPending()` ③ load-veil.js — 들어선 지 80ms 에 높은 줄이 남아 있으면 짙은 막·지명·진행 막대, 다 오면(최대 6초) 0.35초에 걷음. 첫 화면·이야기 장면 동안은 안 뜸, 이미 받아 둔 곳은 안 뜸. 손잡이 `loadVeil.on`·`loadVeil.maxMs`.

**검증**: `dg-town-cam.mjs 1911 917 0.32` 사진 — 인물이 화면 가운데 보통 크기 · `dg-veil-shot`(일회성, 지움) 던전 내려가는 순간 "제 1 층으로 내려가는 중" 막 · `test-web.mjs saga-dungeon` 529/529 · `pw-play.mjs saga-dungeon` PC·폰 OK.

**메모**:
- 시작 자리: 2나락은 마지막으로 선 세계 좌표(`save.town.pos`)에서 이어 시작한다(던전에서 막 나왔으면 모루골 굴혈 앞). 사용자 사진은 절차 마을 하나의 광장 — 그 자리에 서 있다 끈 것. "늘 모루골에서 시작" 으로 바꿀지는 사용자 결정(답 오면 R-0).
- 헤드리스는 모델을 풀 때 화면 스레드가 몇 초씩 멈춰 가림막이 6초 상한에 걸린다(실기기 아님). 던전은 높은 줄이 200~300 까지 늘어(방 소품) 느린 기기에선 상한에 걸릴 수 있다 — 다음 후보: 높은 줄 중 "화면 안" 것만 세기.
