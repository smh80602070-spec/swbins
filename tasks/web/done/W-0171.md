# W-0171 2나락 3D 무기·연속 단 몸짓 + 자체 타격음(무기 생김새별)
종류: 손맛 · 웹(2나락)      상태: 끝(10-11 Opus — 손맛 묶음 W-0169·0170 의 2나락 판, 사용자 "넘 재미가 모두 없어서"·"묻지말고 최대한 해봐")      등급 목표: D2

**목표(한 줄)**: 2나락 3D 주인공은 무기와 상관없이 'attack' 한 가지, 타격음은 합성음 셋 — 1만리와 같은 무기 몸짓 15(anim-own)와 자체 효과음 92를 붙인다.

**파일**: `shared/js/anim-own.js`(`WPN_OF` 무기 생김새 → 다섯 갈래 · `attackSlot(st, 남은 공격 시간, now, look(), step())` — 새 공격이 시작될 때만 자리를 정하고 공격이 이어지는 동안 붙듦) · `saga-dungeon/js/asset3d.js`(1만리와 같은 네 자리, 줄 수 그대로) · `src/dungeon3d/04.js`(주인공 anim 한 줄 · `_meMix` 진단 문) · `js/sfx.js`(`sx`·`hitOf` — 같은 WebAudio master 로 샘플, 받기 전·못 받으면 합성음) · `src/dungeon/01-core.js` `hitSfx` 한 줄 · `_test.html` 진단 1 · `tools/playcheck/dg-wpn-probe.mjs`

**대응**: 검·단검·관도 → 검 몸짓(관도는 큰날) · 도끼·곤봉 → 큰날 · 창·극 → 창 · 활·총 → 활 · 부채·지팡이·붓·병서 → 서책. 소리: 검·관도 sword · 도끼·곤봉 axe · 창·극 spear · 활 bow · 총 gun · 단검 dagger · 기공류 staff.

**함정(고침)**: 자동 공격이 쉬지 않으면 "새 공격"을 못 알아채 'attack' 으로 샜다 → 남은 공격 시간이 다시 차오르는 순간을 새 공격으로 · 틱이 느리면 몸짓(벽시계)이 먼저 끝나 'attack' 으로 샜다 → 공격이 이어지는 동안 몸짓 끝 자세를 붙듦.

**검증**: test-web saga-dungeon 491/491 · saga-go 890/890 · 브라우저 실측 `dg-wpn-probe.mjs` — 주인공 몸 자체 몸짓 VRoid, 공격 여섯 = Wpn_sword_0→1→2→0→1→2(그 사이 'attack' 0), 맞는 소리 전부 샘플(합성 0).

**메모**: △ 이번 계정 주인공은 맨손(look none → 검 몸짓). 맨손 몸짓(주먹)은 아직 없음 — 다음 묶음 후보.
