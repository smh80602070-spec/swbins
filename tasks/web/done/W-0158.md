**목표(한 줄)**: 3D 던전(`dungeon3d.js`, 등 뒤 추적 카메라)을 벨트 스크롤 문법으로 — 카메라는 방을 옆에서 3/4 로 내려다보며 가로로만 따라가고, 방은 문 방향이 늘 오른쪽(또는 위)으로 보이게 돌려 세운다. 판정(`dungeon.js`)·방 자료(`run.room`·`doors`)는 한 줄도 안 바꿈. 2D 벨트(W-0128)와 같은 방 → 문 → 다음 방 체감.

**파일(확인함, 10-10)**
- `saga-web/saga-dungeon/js/dungeon3d.js` 3069~3070행 `camera.position.copy(camPos); camera.lookAt(camLook)`(카메라 최종 적용) · 421행 주석(방 밖 뒤처짐) · 1208~1210행 `r.doors` 세우기 — **큰 파일 3202 = 상한**(tools/big-files.txt) → 새 카메라는 **새 파일** `js/belt-cam3d.js`(manifest.json 에 dungeon3d 앞 줄, `node tools/gen-index.mjs`) 가 `camPos·camLook` 을 계산해 주고 dungeon3d 는 기존 줄 안에서 그 값을 받기만
- 2D 벨트 규칙 참고 `js/belt2d.js` 11행(배경 층·카메라 x 만 따라감) · 방 문 방향 `js/dungeon.js` `doors` 자료(`grep -n "doors" js/dungeon.js | head`)
- 손잡이: `dungeon3d.belt`(1 기본, 0 = 옛 추적 카메라 — 되돌리기용) · `dungeon3d.beltPitch`(내려다보는 각, 처음 값 32°) · `dungeon3d.beltDist`
- 촬영 `node saga-web/tools/playcheck/pw-visual-close.mjs`(visual-20261007/saga-dungeon-1-town·2-room·3-door·4-next)

**단계**
1. `belt-cam3d.js`: 입력(나 위치·방 사각형·문 방향) → 출력 `{pos, look}`. 카메라는 방의 긴 축을 화면 가로로 두고, x 만 나를 따라가며 방 양 끝에서 멈춘다(2D 벨트와 같은 규칙), y·pitch 고정. 문을 지나 다음 방으로 넘어갈 때 0.4초 보간.
2. dungeon3d 3069행 앞의 camPos·camLook 계산 자리에서 손잡이가 1 이면 belt-cam3d 결과를 쓰는 **한 줄 분기**(줄 수 그대로).
3. 방 세우기(1208행 둘레)는 안 바꿈 — 문이 화면 오른쪽에 오도록 **카메라 yaw** 를 문 방향에서 정한다(방을 돌리지 않는다 — 판정 좌표 보존).
4. 이름표·피해 숫자(1752행 빌보드)는 그대로 카메라를 마주 봄. 가림(updateOcclusion 3075행)은 새 각도에서도 돌아야 — 촬영으로 확인.
5. 진단 +2: ① 순수 함수 `beltCam(me, room, door)` — 방 양 끝에서 x 가 멈춘다·pitch 고정 ② 손잡이 0 이면 옛 값과 같다. 번들 · sw VERSION +1.
