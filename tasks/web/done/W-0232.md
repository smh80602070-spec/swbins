# W-0232 1만리 2D 마을 사람 걸음을 화면 몸 높이로
종류: 손맛·그래픽 · 웹(1만리)      상태: **끝**(Opus 10-15) · 작성됨(Opus R-0 10-15 — W-0228 메모 남은 것, 사용자 "자연스럽지 않은데"의 같은 척도 문제)      등급 목표: D2

**목표(한 줄)**: 2D 에서 주민이 1.15m/초(화면 2.4px/초)로 일과 자리를 옮겨 미끄러지듯 멈춰 보이던 것을, 화면 몸 높이 0.6/초로 걸어 옮기게 한다.

**잰 것(R-0)**: `js/npc.js` posAt 은 시각의 순수 함수 — 구간 시간 need = 거리 / WALK(). WALK 만 바꾸면 같은 시점(2D/3D)에서는 같은 t 에 같은 답이 그대로다(일찍 닿아 서 있을 뿐).

**파일**: `js/npc.js` · `js/field2d.js`(npcMps) · `src/world/02.js`(→ `js/world.js`, 상한 1921 — 내보내기 줄에 body2dM) · `_test.html` · `dist/app.js` · `sw.js`

**단계**: ① world.body2dM() = 2D 화면 몸 높이(m), 3D 면 null ② field2d.npcMps(몸) = 손잡이 world.npc2dBps 0.6 × 몸 ③ npc WALK = max(1.15, 2D 값) ④ 진단 +1 · 옛 진단 "자리를 옮기는 동안은 걷는다" 는 손잡이 0 으로 3D 값에서 잼.

**검증**: `node tools/test-web.mjs saga-go --runs=2` n/n SAME · `node tools/qc.mjs --game saga-go` PASS

**완료 조건**: 2D 주민 걸음 ≈ 0.6 몸/초 · 3D 그대로 · done/ 로.
