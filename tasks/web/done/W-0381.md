# W-0381 첫 10분 자동 점검 — 새 계정으로 판마다 10분을 자동으로 놀아 "막힘 0" 을 잰다(QC 한 줄)
종류: 도구(체제 · QC) · 웹(다섯 판)      상태: **끝**(10-23 오퍼스 — 1만리·5천하 PASS, 세 판 막힘은 버그 W-0382~0384)

**목표(한 줄)**: 새로 들어온 사람이 처음 10분에 막히는 자리(창이 안 닫힘·목표가 안 보임·자동이 멈춤·예외)를 사람이 놀아 봐야 알았다 → `pw-first10.mjs <판…>` 가 새 프로필·새 계정으로 판을 열어 실제 단추·자동 퀘스트로 10분(손잡이 `--min`)을 굴리고, 막힘·예외·목표 진척·가림 창을 재서 `results/pw-first10.json` 에 남긴다 · `qc.mjs` 에 "첫 10분" 줄(PASS = 막힘 0·예외 0·진척 > 0).

**참고**: 플레이 QC 본보기 `saga-web/tools/playcheck/pw-play.mjs`(W-0270 — 판마다 PC·폰 조작·결과 json) · 장면 손질 `pw-look2d.mjs`(새 계정 만들기·title-continue·skip/beforeShot 공용 `overlay.mjs`) · 자동 퀘스트 공용 `shared/js/autoquest.js`(q.status() → { on, goal, doing, why, stuck, done }) · 판 어댑터 `DG.autoQuestGo`·`autoQuestDg`·`autoQuestFs`·`autoQuestSt`(start·stop·status·goals) · 5천하는 자동 퀘스트가 없음 → `pw-rk-sheet.mjs` 처럼 실제 단추(pick-scen·pick-force·▶ 다음 달) · 「오늘」 창 `DG.goalsAdapter.model()`(W-0380 — 오늘 줄 진척을 진척 지표로) · qc 줄 넣는 자리 `tools/qc.mjs` ④-3 플레이 QC 옆.

**파일**: 새 `saga-web/tools/playcheck/pw-first10.mjs` · `tools/qc.mjs`(--first10 · 기본 묶음에 한 줄, 판마다 결과 없으면 WARN) · `saga-web/tools/playcheck/README`(있으면 한 줄)

**단계**: ① 판마다 전용 새 프로필(PC_PROF·user-data-dir 판별) → 새 계정 → 첫 화면 이어하기 → 안내·이야기 창은 판 함수로 넘김(overlay.mjs skip) ② 네 판: 어댑터 start() 뒤 30초마다 status() 를 적고, 멈춰 있으면(on false · why '목표 없음' 아님) 다시 start — 10분 동안 멈춤 횟수·같은 목표에 머문 최장 초·stuck 최대 · 5천하: ▶ 다음 달 30번(달마다 1초) + 명령 하나씩(rtk.order 개발) · 2D 기본(10-19 방향) · 손잡이 `--min=10`·`--games`·`--phone`(390×844) ③ 재는 것: 페이지 예외·console.error 수 · 막힘(같은 목표 120초 넘게 · 자동 멈춤 why 가 '막힘') · 진척(시작·끝의 「오늘」 줄 완료 수 + 판 지표 하나: 1만리 걸음·2나락 층·3마을 일과·4종횡 처치·5천하 성 수/달) · 끝에 덮인 창(listOverlays) · 끝 화면 PNG 한 장 ④ PASS 규칙 = 예외 0 · 막힘 0 · 진척 > 0 (WARN = 진척 0) ⑤ qc.mjs 줄 + `--first10` 단독 ⑥ 처음 돌린 결과로 판별 막힘이 나오면 이 티켓 안에서 고치지 말고 판별 버그 티켓 초안(제목·재현 3줄·기대 1줄)

**검증**: `node saga-web/tools/playcheck/pw-first10.mjs saga-go saga-dungeon saga-forest saga-story saga-realm --min=10`(서버는 스크립트가 띄우고 끔) · 결과 json 다섯 판 · 끝 PNG 다섯 장 Read · `node tools/qc.mjs --first10`

**완료 조건**: 위 검증 · 다섯 판 결과가 PASS 이거나, FAIL 이면 판별 버그 티켓 초안이 큐에 있음 · 장부 proposals ⑤ `끝 W-0381` · done/

**불변 규칙**: 판 코드 안 고침(도구만 — 막힘은 버그 티켓으로) · 세이브 키 안 바꿈(새 프로필이라 남의 세이브 안 건드림) · 크롬은 그 PID 만 끔(`//IM chrome.exe` 금지) · 서버도 띄운 PID 만 · 진단 씨앗·시각 의존은 그대로(실제 시각으로 놀되 결과는 막힘·예외 중심이라 흔들리지 않게)
