# W-0488 3마을·2나락 맵을 1만리 맵 형태로 — 열린 구역 격자(576m 칸)·구역 넘김·안개 벽
종류: 게임성·구조(R-0 설계 먼저) · 웹(3마을·2나락, 정본 = 1만리)      상태: 작성됨(10-28 오퍼스 R-0 — 사용자 「3마을 1만리 맵으로 바꿔 2나락 1만리 맵 형태로」)      등급 목표: D2

**배경(사용자 말)**: 「3마을 1만리 맵으로 바꿔 2나락 1만리 맵 형태로」 · W-0487 ④ 「2나락은 맵 넘어갈 때… 1만리가 좋네」 · ② 「3마을도 배경 1만리 스타일로」. 1만리 맵 = 열린 땅을 구역(go.zoneM 576m 정사각)으로 나눠 경계를 걸어 넘으면 넘김 막이 덮고 새 구역을 짓는 구조(zone-wire.js·shared/js/zone-cut.js·world.js 2D 안개 벽).

**해석(묻지 않고 고른 기본 — 사용자가 뒤집으면 그때 바꾼다)**:
- 3마을: 마을 한 장(투영 구면)을 중심 구역으로 두고, 둘레에 들판·숲·물가 구역 격자를 이어 붙여 걸어서 나간다. 구면 투영·집 안 평면은 그대로(불변). 구역 경계 = 1만리 넘김 막·안개 벽 한 벌.
- 2나락: 들판(필드)을 구역 격자 열린 지도로, 던전 입구는 구역 안 입구. 방 단위 던전 진행·전투·세이브는 안 뜯는다. 방·층 바뀔 때 넘김은 지금의 load-veil.cut 그대로(W-0487 ④ 와 한 묶음).

**단계**(단계마다 커밋):
① 설계 한 장 — 구역 자료 꼴(구역 번호→지형·소품·출입구)을 1만리 것과 공용으로 뽑을 수 있나 표. 3마을·2나락 현재 맵 자료(village 타일·dungeon 필드)와 대조. 크면 후속 티켓으로 쪼갠다(구현 금지).
② 3마을: 구역 격자 + 경계 넘김(공용 zoneCut.hookKey) + 바깥 구역 땅(1만리 2D 땅 그리기 shared).
③ 2나락: 들판 구역 격자 + 경계 넘김 + 던전 입구 배치.
④ 두 판 2D·3D 모두 같은 규칙(사용자 10-25 「2d,3d 모두」) — 안개 벽(zoneCut.walls)·손잡이 zoneCut.on.
