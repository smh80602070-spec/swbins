# W-0403 5천하 방어전 = SRPG 판(내 성을 AI 가 칠 때 「N턴 버티기」 판)
종류: 기능(전투 진입) · 웹(5천하)      상태: **끝**(10-25 오퍼스 ①~⑥ · D2)(10-25 오퍼스 R-0 — W-0401 남은 것 · 사용자 10-25 "역사/전략 턴제 SRPG")      등급 목표: D2

**잰 것(10-25)**: 출진은 W-0401 로 늘 격자판인데, **내 성이 맞는 싸움은 판이 없다** — AI 차례(`src/rtk/02.js` `rtkAI.runAll()` → `js/rtk-ai.js` 303줄 `war.march(from, to, lead, real)`)가 달 넘김 안에서 곧바로 `fight()` 로 끝내고 결과 카드만 뜬다. 규칙 층엔 hold 목표(`tactics.makeBoardSrpg(…, 'hold')`, 6턴 버팀 = 승)가 이미 있고 쓰는 곳이 없다. 판 보정은 `war.js` 883줄 `atk.grid {give, take}` 한 곳(stepRound)뿐.
**목표**: AI 가 **내 성**을 치면(맞닿은 출진만 — 원정 도착 `journey.js` 는 그대로 자동) 그 공격을 달 넘김 끝으로 미뤄 두고, 화면이 「⚔️ ○○군이 □□성을 친다」 카드 → 격자판(내 편 = 그 성 장수 셋·성 병력 부대, 적 = 공격 장수·부대, 목표 = 6턴 버티기, 공성이면 내가 성벽 쪽) → 결과를 공격 쪽 보정으로 바꿔 **같은 `war.march()` 한 번**(판정 두 벌 금지).
- 보정: 방어 판 결과 A(`tactics.apply`) → 공격군 `atk.grid = { give: 1 − A.winPct/100, take: A.kind === 'rout' ? 1.3 : 1, kind }`(내가 대승하면 적 위력 −25%·적 피해 ×1.3, 지면 적 +25%). `war.march(from, to, lead, troops, { grid })` 다섯째 인자(없으면 지금 그대로).
- 미루기: `rtk-ai` tryAttack 이 대상 성 force === 나 · 손잡이 `rtk.srpgDefend` 1 · 화면 훅(`war.onDefend` 가 걸려 있음)일 때만 `R.state()`가 아닌 **같은 화면 전용 줄**(`war.pendingDefense[]`, 저장 안 함)에 넣고 병력·장수 `done` 은 지금처럼 묶는다. 달 넘김 처리 끝(`rtk:month` 뒤) 화면이 줄을 하나씩 판으로. 화면이 없으면(진단·자동 대국·탭 닫힘) 그 자리에서 옛 `war.march()` — 세이브에 반쪽 상태 없음.
- 「🤖 자동 전투」·「↩️ 물러나기(= 무승부)」 그대로. 한 달에 두 번 넘게 맞으면 셋째부터 자동(피로 방지, 손잡이 `rtk.defendMax` 2).
- 내 장수가 쓰러지면 W-0401 과 같은 전사·중상·열전(`marchApply` 의 몫을 방어 쪽에도 — 공용 함수로 뽑기).
