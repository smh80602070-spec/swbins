# W-0024 사가블로 2D 마을 — 집·우물·여관·종탑 등 마을 건물을 2D 방에도 세운다(코드만)
종류: 새기능 · 웹      상태: **코드분 끝**(2026-10-03) — 사용자 눈 확인 대기      등급 목표: D2

**목표(한 줄)**: 사가블로 마을(`run.town`)의 건물은 3D(`dungeon3d.js`)에서만 서고, 2D 방(`dungeon-view`)은 벽 횃불·기둥·항아리만 그린다. 그래서 2D 모드에서는 마을이 빈 방처럼 보인다. 마을 장식 데이터에 이미 있는 건물을 K-0017 2D 스프라이트(`world2d`)로 2D 방에도 세워 "2D 모드 전체가 2D"를 마을에서도 맞춘다.

**파일(확인함)**
- 데이터 `saga-dungeon/js/town.js` 마을 장식 목록 — `{ t:'house'|'well'|'inn'|'blacksmith'|'stable'|'mill'|'belltower'|'pillar'|'torch'|'crack', x, y, h, seed }`(방 좌표). 3D 가 이걸 읽어 세운다(`dungeon3d.js` house/well 렌더)
- 2D 그리기 `saga-dungeon/src/dungeon-view/02.js`(→ `js/dungeon-view.js`, `tools/build-parts.mjs`): 방 장식 루프(`dec[]` — `torch`·`pillar`·`jar` 만 분기, 줄 166·206~208), 좌표 변환 `proj(m,x,y)`·발 밑 정렬은 같은 파일의 `items` 정렬
- 읽는 쪽 `shared/js/mode2d.js` `drawKind/drawSprite`, 설정 `DG.cfg.mode2d.prop2d`(사가고·사가의숲 본보기). 자료 `shared/assets/world2d/` — 사가블로 칸: `stone_tower_01`·`chinese_hall_01`·`dungeon_gate_01`·`torch_stand_01`·`altar_01`·`iron_fence_01`, 그 밖에 `inn_01`·`well_01`·`eu_house_01`·`stone_tower_01`(종탑)·`hanok_01` 등 42개 중 어울리는 것

**단계**
1. 대응표 `prop2d` 종류 → id: `house`(시대 섞임 3) ← `eu_house_01`·`hanok_01`·`chinese_hall_01`, `well` ← `well_01`, `inn` ← `inn_01`, `belltower` ← `stone_tower_01`, 나머지(`blacksmith`·`stable`·`mill`)는 짝이 없으면 옛 방식(안 그림) — 새 에셋은 K 티켓.
2. `dungeon-view` 2D 방 그리기의 장식 루프에 `town` 일 때 위 종류를 정렬 목록(`items`)에 넣어 `mode2d.drawKind` 로 그린다(없거나 못 받으면 안 그림 = 지금과 같음). 크기는 `dec.h`(방 좌표 높이) × `m.s`.
3. 진단 +1(표 id·시험 전 false), `pw-web2d.mjs saga-dungeon` 지물 점검, `sw.js` VERSION.
