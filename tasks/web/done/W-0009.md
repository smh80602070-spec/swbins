# W-0009 `account.js` 다섯 벌 합침
종류: 통합      판: 웹 다섯      상태: **작성됨**(R-0 완료 2026-10-01)

**목표(한 줄)**: 다섯 판 `js/account.js` 를 사가고 것 기준 하나(`saga-web/shared/js/account.js`)로 합치고, 판별 차이는 각 판 `core.js` 끝의 `DG.cfg.account` 한 덩이로 뺀다.

**확인한 사실(diff)**: 코드로 다른 곳은 다섯뿐 — ① `GAME_NAME` ② 타이틀 이모지·한 줄 소개(`titleHero`) ③ 진행 조각 `'Lv.'+level`(사가국지만 `realmBit(s)` 함수, `DG.account.realmBit` 로도 내줌 — `ai.js:81` 이 부른다) ④ 타이틀 "⚙️ 설정" 단추(사가스토리만, `ui.openSheet('settings')`) ⑤ 👤 단추 자리(사가고만 `#tools-drawer` 안으로, 나머지 넷은 도구줄 맨 앞 — **사가블로·사가스토리 index 에도 `tools-drawer` 가 있으나 지금 동작을 안 바꾼다**). 나머지는 주석뿐. 세이브 키는 `core.SAVE_BASE` 에서 오므로 account.js 가 키를 안 쥔다.

**파일**: `saga-web/shared/js/account.js`(새) · 다섯 `js/account.js`(복사로 대체) · 다섯 `js/core.js`(끝에 cfg 블록 추가만) · 다섯 `sw.js`(VERSION +1) · `tools/sync-shared.mjs`(FILES 한 줄)

**본보기**: `saga-go/js/account.js`(바탕) · 사가국지 `account.js` 의 `realmBit`·사가스토리 `showTitle` 설정 단추(옮길 코드).

**단계**
1. 사가고 `account.js` 를 `shared/js/` 로 복사하고 위 ①~⑤ 를 `var CFG = (global.DG.cfg && global.DG.cfg.account) || {};` 로 읽게 고친다: `GAME_NAME = CFG.name || '게임'` · `CFG.emoji`·`CFG.tag` · `function bit(s){ return CFG.bit ? CFG.bit(s) : 'Lv.' + ((s&&s.player&&s.player.level)||1); }` 를 진행 조각 두 곳(`bits` 첫 칸·`summaryLegacy`)에 · `if (CFG.settings)` 일 때만 설정 단추·핸들러(사가스토리 코드 그대로) · `if (CFG.drawer)` 일 때만 서랍 분기 · 내보내기에 `realmBit: CFG.bit`.
2. 각 판 `core.js` 맨 끝에 `DG.cfg.account = {…}` (값 그대로): go `{name:'사가고', emoji:'🗺️', tag:'역사 인물로 노는 위치기반 수집 게임', drawer:true}` · dungeon `'사가블로','⚔️','역사 인물로 여는 핵앤슬래시 던전 크롤러'` · forest `'사가의숲','🌳','역사 인물과 함께하는 마을 생활 게임'` · story `'사가스토리','🏃','역사 인물로 노는 옆으로 걷는 액션', settings:true` · realm `'사가국지','🏯','역사 인물로 여는 천하 정복 시뮬레이션', bit:` 사가국지 기존 `realmBit` 함수. (`DG.cfg = DG.cfg || {}` 먼저.)
3. `sync-shared.mjs` FILES 에 `['js/account.js','js/account.js']` → 실행 → `--check` OK.
4. `sw.js` VERSION +1 ×5.
