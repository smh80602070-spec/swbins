# W-0417 폰 발열 — 구역 밖 안 짓기·안개 경계·폰 30fps 상한(다섯 판)
종류: 성능(발열) · 웹(다섯 판)      상태: **끝**(10-25 오퍼스 — 사용자 「사양이 너무 타서 폰이 발열해」「그래서 나누라는거임」「자연스러우면 됨 그리고 느리거나 안끊기면 됨」, W-0414 뒤)      등급 목표: D2

**고침**:
- 폰 30fps 상한: 공용 device-mode fpsCap()(폰이면 손잡이 perf.phoneFps 30) → 1만리·3마을·4종횡 frameGapMs · 2나락 loop · 5천하 realm3d tick. PC 는 그대로 60.
- 1만리 3D 땅: 반경 3장(7×7=49 타일) → 구역(go.zoneM 576)+160m 만(≈9장, 손잡이 go.zoneGround) · 구역 경계 안개 벽(shared zone-cut walls — 아래 짙고 위로 옅은 판 넷, 깊이 안 씀) · 구역 격자 반 칸 밀림(출발 마을(0,0)이 구역 가운데 — 전엔 네 구역 모서리라 마을에 안개).
- 1만리 2D: 구역 밖 안개(경계 안쪽 120px 띠에서 짙어짐, 평면 2D 만 · 손잡이 zoneCut.fog2d).
- 3마을 3D: 구역(64m) 경계 안개 벽(인물 기준 자리).
**잰 것**: go-zone3d PC GPU 구역 안 걷기 뒤 — 옛 121 호출·131k 삼각형 → 103·81k(-15%·-38%). CPU 3.1→3.9ms 는 흔들림 안. 촬영: 1만리 3D 북쪽 경계 안개 띠 ○ · 2D 마을 깨끗·동쪽 경계 안개 ○ · 3마을 3D 경계 흰 안개 ○.
**검증**: 진단 990·592·515·381·456 n/n · sw 다섯 판
**남은 것**: 실기 폰 발열 체감 — 사용자 보고로. 3마을 2D·4종횡·2나락·5천하는 원래 화면 단위라 상한만.
