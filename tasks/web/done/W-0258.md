# W-0258 QC 에 "배포 확인" — 공개 Pages 주소에서 다섯 판을 실제 사용자처럼(Playwright)
종류: 체제(QC) · 웹(도구)      상태: **끝**(Opus 10-16) · 작성됨(Opus R-0 10-16 — 사용자 "qc테스트가 개판이네 플레이라이트가 테스트를 더 잘해?" · 5천하 공개 주소 "사이트에 연결할 수 없음" 신고 · "응 웹이어해 계속")      등급 목표: D2

**목표(한 줄)**: 지금 QC 는 로컬 서버에서 진단(함수 단위 _test.html)·촬영만 해서 **공개 배포 주소는 한 번도 안 연다** — 새 `pw-deploy.mjs` 가 Pages 주소에서 서비스 워커를 켠 채 다섯 판을 가입 → 판 시작 → ☰ 메뉴 → 창 하나 → 새로 고침 → 이어하기까지 실제 클릭으로 돌리고, 오류·404·막힘·배포 버전 어긋남을 QC 표에 "배포 확인" 줄로 올린다.

**잰 것(R-0)**: 10-16 수동 재현(임시 스크립트) — 5천하 공개 주소 PC·폰 모두 가입~진행 중 새로 고침까지 오류 0·404 0, Pages 배포 기록 전부 success → 사용자 "연결할 수 없음"은 그 기기·네트워크 단계(이 도구도 그건 못 잡는다 — 한계를 표에 적는다). QC 는 `tools/qc.mjs`(행 = area·target·PASS/FAIL/WARN) · Playwright 공용 `saga-web/tools/playcheck/pw.mjs`(serviceWorkers:'block' — 이 도구는 SW 를 켜야 해서 직접 띄움).

**파일**: 새 `saga-web/tools/playcheck/pw-deploy.mjs` · `tools/qc.mjs`(--deploy 와 --branch web 에 "배포 확인") · 결과 `saga-web/tools/playcheck/results/pw-deploy.json` · 촬영 `shots/deploy/<판>.png`(git 무시)

**단계**: ① pw-deploy.mjs <판…> [--base URL](기본 https://smh80602070-spec.github.io/swbins/saga-web/) — 판마다 새 컨텍스트(SW 켬): 첫 방문 응답 코드 → 가입 카드에 이름·동의 → 시작 → 판별 첫 관문(5천하 시나리오·세력 / 2나락 출사표 셋 / 나머지 이야기 장면 건너뛰기) → 들어감 판정(가입 카드 없음·boot-guard 없음·#dock 보임) → ☰ → 첫 칸 → 창 열림(#sheet.show·#encounter.show·패시브 그물·큰 지도 중 하나) → 새로 고침 → 이어하기 → 다시 들어감 · 배포 sw.js VERSION ↔ 로컬 sw.js VERSION · pageerror·console.error·4xx/5xx 모음 ② 결과 JSON(판마다 단계별 ok·ms·오류) + 마지막 화면 PNG ③ qc.mjs: 판마다 "배포 확인" 행 — 단계 실패·오류 = FAIL, VERSION 어긋남(푸시 뒤 배포 몇 분 지연) = WARN ④ --branch web 에 넣고, 단독 --deploy 도.

**검증**: `node saga-web/tools/playcheck/pw-deploy.mjs saga-go saga-dungeon saga-forest saga-story saga-realm` 다섯 판 ok · `node tools/qc.mjs --deploy` 표에 배포 확인 다섯 줄 PASS(또는 VERSION WARN)

**완료 조건**: 공개 주소 실제 흐름이 QC 에 들어감 · 한계(사용자 기기 네트워크 차단은 못 잡음) 명시 · done/ 로.

**불변 규칙**: 공개 주소엔 GET 과 브라우저 저장소만(서버에 쓰는 것 없음 — 판엔 서버 저장이 없다) · 판 코드 안 건드림.

**메모(체크포인트)**:
