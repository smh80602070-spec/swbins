# W-0462 다섯 판 2D 자동 퀘스트 확인
종류: 확인(조사) · 웹(다섯 판)      상태: **끝**(10-26 오퍼스)      등급 목표: D2

**까닭**: 사용자 10-26 「1번 2d는 자동퀘스트 있는지 확인해줘」 → 「다섯판 2d 모두 자동퀘스트 확인」.
**한 것**: 새 탐침 saga-web/tools/playcheck/aq-2d-all.mjs [판…] — 판마다 `?mode=2d` 새 계정 → 첫 시작 화면 넘김(2나락 출사표 셋·서막 「건너뛰기」) → ▶(#aq-go) 보이나 · 누르고 3초마다 ⏸ 유지·위치(판 어댑터 pos() 와 같은 곳) · 앞뒤 촬영(shots/aq2d-<판>-{0,1}.png).
**결과**(10-26):

|---|---|---|---|
| 1만리 | ○ | ⏸ 유지 · (0,0) → (−209,782) | 목표 쪽으로 걸음 |
| 2나락 | ○ | ⏸ 유지 · (390,480) → (−165,1374) | 「자동 순행 · 막혀서 옆으로 돌아가는 중」 띠 — 건물 곁에서 옆걸음 |

**남은 것(후보)**: 5천하 장 흐름 자동 진행(▶ 노선도에서 장 고름·이야기 고름·출진·자동 전투·결과까지, 지면 멈춤) · 3마을 자동이 빈 나무로 가는 것 · 2나락 출사표 깨진 초상.
