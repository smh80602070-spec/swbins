# W-0025 아이템 아이콘 배선 — 다섯 판의 아이템·장비·재료 칸에 K-0035 그림을 쓴다(코드만)
종류: 새기능 · 웹      상태: **코드분 끝**(2026-10-03) — 사용자 눈 확인 대기      등급 목표: D2

**목표(한 줄)**: 다섯 판의 아이템 칸은 이모지·글자뿐이다(`tools/ai-art/data/icon_inventory.json`: 사가블로 장비·유니크·세트 그림 없음·보석·룬은 글리프, 사가스토리 장비·주문서 없음, 사가국지 보물·사가고 가방·재료·사가의숲 물건·가구·도구·옷은 이모지). K-0035 가 만든 128/64px 아이콘(등급 틀 포함 합성본 `icon64/<키>_g<등급>.png`)을 칸마다 쓰고, 그림이 없는 id 는 옛 표시로 남긴다.

**파일(확인함)**: 읽는 정본 `saga-assets/icons/map.json`(`<판>:<종류>:<id>` → `{key,grade,mode,name}`) · 아이콘 `saga-web/shared/assets/icons/<키>_g<등급>.png`(놓기는 K-0019 `place.py`, 이 티켓은 안 놓는다) · 새 `saga-web/shared/js/itemicon.js`(`DG.itemicon.html(game,id)` → `<img>` 또는 null, 본보기 `shared/js/mode2d.js` 의 `spriteReady` 방식) · 칸을 그리는 곳은 단계 1 에서 확정: 판별 `js/item.js`·`bag.js`·`cooking.js`·`data-item.js`·`data-village.js` 의 이모지 필드(`icon`·`emoji`·`glyph`) 쓰는 자리 · `js/manifest.json`·`index.html`·`_test.html`(`node tools/gen-index.mjs`) · `sw.js` VERSION

**단계**
1. 판 다섯의 칸 그리는 자리를 `grep -n "emoji\|\.icon\|glyph"` 로 확정해 표로 메모에 적는다. 자리가 없는 종류는 안 한다.
2. `itemicon.js`(공용, `sync-shared.mjs` 로 다섯 벌) — 지도에서 키를 찾아 `<img class="ico" width=… loading="lazy">`. 없으면 null → 호출부가 이모지 그대로.
3. 판별 호출부 교체(이모지는 `alt`·폴백으로 남긴다). 룬은 `mode:glyph` 라 기존 글리프 유지, 염색은 색 견본 그림.
4. 진단 +1(지도 항목 수 = 자리, 없는 id 폴백), `sw.js` VERSION ×5, 아이콘 파일 용량 판당 ≤ 3MB 확인.

**검증**
```
node tools/gen-index.mjs && node tools/sync-shared.mjs --check
node tools/test-web.mjs saga-dungeon saga-story saga-realm saga-go saga-forest   → 전후 값 같음(+새 진단)
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 판별 아이템 칸에 그림이 뜨고 그림 없는 id 는 이모지 폴백 · 사용자 눈 확인 시트.

**불변 규칙**: 에셋은 이 갈래가 안 만든다(K-0035·0019) · 세이브 키·id 불변 · 도감 `data.js` 안 건드림(표시만).
