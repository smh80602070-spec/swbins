종류: 게이트 · 체제(precheck)      상태: 끝(10-07, 수신함 10-05 "페이블에서 소넷으로 해도 문제 없도록 안 했나?")      등급 목표: —

**목표(한 줄)**: 자체툴 티켓이 "정본 배치 끝"으로만 닫혀 화면에선 안 쓰이는 일을 막는다 — `reflect.py --categories` 의 WARN 을, 지금 있는 2개(허용 목록)만 봐주고 **새로 생긴 미반영 범주는 FAIL** 로 올린다(`tools/big-files.txt` 와 같은 꼴).

**지금(확인함)**: `tools/precheck.sh:105-106` 이 `py tools/asset-audit/reflect.py --categories` 를 돌려 출력만 한다(WARN, 실패 아님). 10-07 출력 = `WARN 정본 범주가 어느 트랙 코드에도 안 나옴(배선 티켓 후보): competition, web2d/realm-ui`. 출력 꼴은 `reflect.py` 의 `quick()`(줄 261 근처 `print('WARN …: ' + ', '.join(warn))`).

**파일**: `tools/precheck.sh`(105~106줄 절) · `tools/reflect-allow.txt`(새)

**단계**
1. `tools/reflect-allow.txt` — 머리 주석 한 줄(`# 아직 화면에 안 쓰이는 정본 범주(봐줌). 배선되면 지운다. 생성 2026-10-07 W-0086`) + `competition` · `web2d/realm-ui` 두 줄.
2. `precheck.sh` 105~106 절: reflect 출력을 변수로 받아 `WARN …: ` 뒤 쉼표 목록을 나눈다 → 허용 목록에 없는 범주가 하나라도 있으면 `FAIL 새 정본 범주가 화면에 안 쓰임: <이름> — 배선 티켓을 먼저 닫거나 tools/reflect-allow.txt 에 이유와 함께` 를 찍고 `fail=1`. 허용 목록 것만 있으면 지금처럼 WARN. `saga-assets` 가 없거나 py 실행 실패면 지금처럼 WARN(FAIL 아님 — 다른 PC 보호). 절 제목 줄의 "WARN 만" 을 "새 범주 FAIL" 로.
3. 허용 목록에 있는데 이제 쓰이는 범주는 `ok   허용 목록에서 지워도 됨: <이름>` 한 줄(실패 아님).

**검증**: `bash tools/precheck.sh` → 이 절 WARN(지금 둘) · 전체 OK · 허용 목록에서 `competition` 줄을 잠깐 지우고 다시 → 이 절 FAIL, 되돌리고 다시 → OK(되돌림 확인 `git diff tools/reflect-allow.txt` 비어 있음).

**완료 조건**: 단계 1~3 · 위 세 번 결과 그대로 · precheck 다른 절 결과 안 바뀜.

**불변 규칙**: `reflect.py` 는 안 고친다(자체툴 갈래 파일) · 허용 목록에 넣는 건 사람이나 R-0 만(티켓 메모에 이유).
