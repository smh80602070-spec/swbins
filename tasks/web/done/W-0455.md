# W-0455 5천하 격자 전투 = 랑그릿사·창세기전식 — 지휘관·용병 부대 · 지휘 범위 · 맞붙음 반격
종류: 새 기능(게임성) · 웹(5천하 tactics·campaign)      상태: **끝**(10-26 오퍼스)      등급 목표: D2

**까닭**: 사용자 10-26 「웹 이어해 랑그릿사나 창세기전 같은 턴 방식이고 잼나야함」·「5번 말하는거임」. 지금 판 = 장수 셋 + 병력 덩어리 하나(부대 1) · 반격은 고유 스킬 「반격」 가진 사람만 → 장수 한 명이 혼자 싸우는 꼴, 랑그릿사의 핵심(지휘관이 용병을 이끌고, 지휘관을 잡으면 그 부대가 무너짐)이 없다.
**잰 것(10-26)**: tactics.js SRPG 층 — 병종 상성 창>기>궁>창 ±20%p · 높이 · 뒤치기 · 책략 셋 · 고유 스킬(hero-skill.js) · 장비(realm-gear.js) 이미 있음. 판 = unitsOfSrpg(내 장수 ≤3 + 내 부대 ≤2, 적 장수 ≤3 + 적 부대). campaign.battleOpts = myTroops/foeTroops 한 덩어리.
**목표**(손잡이 `rtk.command` 1, 0 = 옛 판 그대로):
1. **용병** — 장수(양쪽)마다 휘하 용병 둘(병력 덩어리를 장수 수×2 로 나눈 체력), 병종 창·기·궁. 지휘관 곁에 선다. 내 쪽은 진영 편성에서 장수마다 병종 고름(누르면 창→기→궁), 적 병종은 씨앗으로 정해져 진영 「적 편성」에 미리 보임 → 상성 맞춰 고르는 재미.
2. **지휘 범위** — 지휘관 통솔로 범위(2 + 통솔/45칸). 범위 안 용병은 칠 때 명중 +(6+통솔/10)%p, 맞을 때 같은 만큼 −. 장수를 고르면 범위를 금빛으로.
3. **지휘관 격파 = 휘하 궤주** — 장수가 쓰러지면 그 용병이 모두 흩어진다(랑그릿사). 지휘관 곁(맞닿음) 용병은 턴이 열릴 때 체력 +25%.
4. **맞붙음 반격** — 맞닿아 맞고 버티면 50% 힘으로 되받아친다(활·책사의 두 칸 공격엔 반격 없음 → 궁병 값). 고유 스킬 「반격」 가진 사람은 그 스킬로(겹치지 않게).
5. **용병 맡김** — 턴 끝에 이번 턴 손대지 않은 내 용병은 AI 로 움직인다(폰에서 아홉을 다 누르지 않아도 됨).
