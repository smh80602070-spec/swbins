# W-0144 사가만리 2D 시작 광장 이름표 겹침
종류: 버그 · 웹(사가만리)      상태: 끝(10-10 Opus) · 작성(페이블 R-0 10-10 · Opus 초안 10-09 — QC 10-09 눈 판정 — qc/saga-go-2d·visual saga-go-5-2d)      등급 목표: D2

**목표(한 줄)**: 시작 광장에 사람·NPC 가 몰려 이름표 다섯 개가 한 점에 겹쳐 안 읽힌다 — 겹치면 위아래로 밀거나 가까운 것만.

**파일(확인함, 10-10)**
- 사가만리 `saga-web/saga-go/js/world.js` 1853~1855행 `ctx.fillText(s.ref.name …)`(1864행 거리 흐림 주석) · 사가마을 `src/village-view/01.js` 1100행 `ctx.fillText(name …)`(시트 web-2d-20261007 "이름표 겹침" 두 판 모두)
- 촬영 `saga-web/tools/playcheck/shots/qc/saga-go-2d.png`
- 2D 이름표 그리기 `saga-web/saga-go/js/`(R-0 가 grep 으로 자리 확인)

**단계**
1. 순수 함수 `layoutLabels(items, opt)`(사가만리 `js/world.js` 이름표 그리기 1853행 앞, 사가마을은 `src/village-view/01.js` 1100행 앞 — 같은 알고리즘, 각 판 복사): 입력 [{x, y, w, h, dist}] → y 순으로 훑어 겹치면 아래로 `h+2` 씩 밀되 한 자리에 셋까지, 넷째부터는 `dist` 가 먼 것을 `alpha 0`(숨김). 플레이어와 가장 가까운 것은 항상 보임.
2. 두 판 그리기에서 프레임마다 보이는 이름표를 모아 1 을 거친 뒤 찍는다(겹침 검사는 화면 좌표, 한 프레임에 ≤40개라 O(n²) 허용).
3. 진단 +1 두 판: 같은 점 여섯 개 → 세 개는 y 가 다르고 세 개는 숨김, 가장 가까운 것 alpha 1.
4. 번들 둘 · sw VERSION +1.
