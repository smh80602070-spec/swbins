# W-0188 4종횡 관문 대장을 마을 밖에서 — 마을(안전지대)에 두목이 나오지 않게

**목표(한 줄)**: 관문 대장(주간 두목, §5-4)과의 싸움이 마을 지도 안이 아니라 **마을 문 밖 전용 자리(관문)** 에서 벌어지게 — 마을은 늘 적 0 인 안전지대.

**잰 것(R-0, 10-12)**
- 마을 다섯(`data-side.js` 38·47·71·94·117행, `town: true`·`spawn: 0`)마다 `gateBoss`(몽골 만호장·왜장·왜구 선장·거란 도통·산채 두령, hpMul 40·dmgMul 2.5)가 있고, `side.js` 723행 `challengeGate(key)` 가 **그 마을에 들어가서**(없으면 `enter(key)`) 두목을 세운다 — 주석 "마을은 spawn:0(안전지대)라 여기서 명시적으로 불러야만 나온다". 화면 입구는 `ui.js` 208행 "대장 문" 단추.
- 그래서 마을 사람(NPC)·대화·상점이 있는 지도에 두목 체력 막대가 뜨고 싸움이 난다 — 사용자 눈엔 "마을에서 보스사냥". 폰 흉내 첫 입장(신야성)에선 적 0 — 대장 문을 눌렀을 때 나는 일.
- 설계 정본: `saga-web/saga-story/PLAN.md` 97행 §5-4(구현 09-19, 접은 글 `archive/web/saga-story-PLAN-5절-접음.md` 5-4)
