# W-0016 `bgm.js` 정본 하나로 — 사가의숲·사가스토리 통합(곡·새 판 배선은 W-0017)
종류: 통합 · 웹      상태: **작성됨**(R-0 완료 2026-10-01, 초안에서 쪼갬)

**목표(한 줄)**: 사가의숲(트랙 1개)·사가스토리(town/forest/battle 셋) 두 벌 `bgm.js` 를 `saga-web/shared/js/bgm.js` 하나로 합친다. 판별 차이는 `core.js` 끝 `DG.cfg.bgm` 로. **소리·동작 변경 0**, 새 곡 없음(K-0004 대기).

**쪼갠 이유**: 초안은 "다섯 판 배선+설정 UI+곡"을 한 번에 시켰다. 곡 파일(`shared/audio/bgm/`)은 아직 없고(K-0004 작성됨), 사가고·사가블로는 `ui.js` 가 큰 파일 목록 상한이며 판마다 설정 시트가 달라 따로 다뤄야 한다 → W-0017.

**확인한 사실**: 두 파일은 공통 뼈대가 같고(설정 `music`·`musicVol`, 첫 클릭 unlock, `setEnabled`·`setVolume`) 다른 곳만 다르다 — 사가스토리: `TRACKS={town,forest,battle}`·기본 음량 0.4·`desiredTrack()`(사냥 상태 → town/forest/battle)·`core.on('changed', tick)`·내보냄 `desiredTrack`·`current`·`unlocked`. 사가의숲: 트랙 `forest.mp3` 하나·기본 0.35·늘 재생·내보냄 `hasEl`. 호출부는 `ui.js`(음량·토글)뿐이고 두 판 `_test.html` 이 `desiredTrack`(story)·`hasEl`(forest)을 본다. `sw.js` 에 `./js/bgm.js`.

**파일**: `saga-web/shared/js/bgm.js`(새) · 두 판 `js/bgm.js`(복사로 대체) · 두 판 `js/core.js`(끝에 `DG.cfg.bgm` 블록 추가만) · `tools/sync-shared.mjs`(FILES 에 판 목록 3째 칸 지원 + bgm.js 는 `['saga-forest','saga-story']`) · 두 판 `sw.js`(VERSION)

**본보기**: W-0009 `account.js`(`var CFG = DG.cfg.account` 꼴, core.js 끝 블록).

**단계**
1. 정본 = 사가스토리 것 바탕. `var CFG = (DG.cfg && DG.cfg.bgm) || {}`: `base`(기본 `assets/audio/bgm/`)·`tracks`(키→파일)·`vol`(기본 음량)·`first`(재생 전 기본 키)·`desired()`(지금 틀 키 — 없으면 `first`). 내보냄은 합집합: `enabled setEnabled volume setVolume desiredTrack current unlocked hasEl`(`hasEl` = `<audio>` 가 하나라도 만들어졌나).
2. cfg 값: story `{tracks:{town:'town.mp3',forest:'forest.mp3',battle:'battle.mp3'}, vol:0.4, first:'town', desired: 지금 `desiredTrack` 본문 그대로}` · forest `{tracks:{forest:'forest.mp3'}, vol:0.35, first:'forest'}`(desired 없음 = first).
3. `sync-shared.mjs`: 항목 3째 칸(판 배열, 없으면 다섯) 지원 → 실행. 두 판만 복사됨을 확인(`--check` OK, 나머지 세 판에 파일이 안 생긴다).
4. `sw.js` VERSION +1 ×2.
