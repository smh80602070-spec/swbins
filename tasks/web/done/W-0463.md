# W-0463 5천하 장 흐름 자동 진행(▶) — 다섯 판 자동 퀘스트 맞추기
종류: 새 기능(편의) · 웹(5천하 campaign)      상태: **끝**(10-26 오퍼스)      등급 목표: D2

**까닭**: 사용자 10-26 「다섯판 2d 모두 자동퀘스트 확인」 → W-0462 에서 5천하만 장 흐름이 ▶(#aq-go, 옛 지역 지도용 시정 위임)를 숨겨 자동이 없음 → 「이어해」·「자동 퀘스트가 진행되도록」.
**목표**(손잡이 `realm.campaignAuto` 1 · 전투를 펼쳐 보이는 시간 `realm.campaignAutoWait` 1800ms):
1. 장 흐름 위 띠에 ▶/⏸(#aq-cp) — 누르면 노선도(지금 장) → 이야기(첫째 고름 · 후일담은 「이어서」) → 진영 → 설전·일기토 → 격자 전투(tacticsView.auto) → 결과 → 다음 장을 이어 간다. 사람이 누르는 단추([data-cp]·tacticsView.auto/go)를 그대로 누른다.
2. 진영 준비 prep(no) — 전직할 수 있으면 능력 갈래대로(지력 → 군사·귀모 · 통솔 > 무력 → 기장·대장군 · 그 밖 → 맹장·패왕) · 용병은 적 편성 보고 상성 맞춤(셋째 칸까지).
3. 설전·일기토 — 미니게임 대신 능력 비교(일기토 무력 · 설전 지력, 같거나 높으면 이김).
4. 멈춤 — 지면(「진영에서 다시 도전」) · 결말 · 장 흐름이 닫히면 · ⏸. 전투 화면엔 위 띠가 없어 떠 있는 「⏸ 자동 진행」(#aq-cp-float).
5. 고침 — tacticsView.auto(🤖 자동 전투 단추도)로 한 번에 끝낸 판은 밀린 피해 숫자·필살 컷·대사를 결과 위에 겹쳐 띄우지 않는다(실기 촬영에서 겹침 확인).
**파일**: 새 saga-realm/js/campaign-auto.js · js/campaign-view.js(위 띠 단추·클릭) · js/tactics-view.js(auto 뒤 밀린 연출 비움) · manifest.json · _test.html · _demo.html · dist/app.js · sw.js · tools/playcheck/aq-2d-all.mjs(5천하 = #aq-cp·장 진행 기록)
**검증**: `node tools/test-web.mjs saga-realm` 472/472(새 「W-0463」 — 화면 열고 박자 돌려 1장 → 2장) · `node saga-web/tools/playcheck/aq-2d-all.mjs saga-realm` 36초에 1장 → 5장 · 촬영(5장 시작: 마을·상자·대본·떠 있는 ⏸) ○ · QC 5천하 PASS(게이트는 남의 문서 OVER).
