# W-0081 사가국지 전장 턴 전투 — 화면(고르기·이동 칸·공격·턴 끝·자동)
종류: 새기능 · 웹(사가국지)      상태: **닫음 2026-10-07**      등급 목표: D1→D2

WIP 예외: W-0080 과 같은 사용자 확정(10-05 INBOX "조조전식 턴 전투 방향 확정") — 옛 RTS 화면의 대체.

**목표(한 줄)**: `rts.html` 을 열면 건설·생산 없이 바로 턴 전투가 뜨고, 폰·PC 에서 유닛을 눌러 파란 이동 칸·빨간 공격 칸을 보고 움직여 치며, "턴 끝"·"자동" 단추로 끝까지 할 수 있다. 옛 RTS 는 `rts.html?mode=rts` 로만 남긴다(지우기는 나중 통합).

**지금(확인함)**: `js/rts/view.js` 491줄 — `loop`(449)가 10Hz 로 `units.tick`·`combat.tick`·`econ.dayTick` 을 돌리고, `selPanel`(207)이 생산·정지·A 단추, `tapAt`(270)·`commandMove`(281)가 실시간 이동, 저장은 `core.save.rts`(446·478). 안개(`fog.js`)·미니맵·`drawUnits`(122)는 `s.units` 만 읽으므로 그대로 쓴다.

**파일**: `saga-web/saga-realm/js/rts/view.js` · `css/rts.css` · `rts.html`(tactics.js script·제목 "사가국지 전장 — 턴 전투") · `index.html`(32줄 단추 title) · `sw.js`(목록에 `./js/rts/tactics.js`·VERSION +1) · `features.json`(`rk.rts-turn` D2) · `saga-web/tools/playcheck/pw-rts-turn.mjs`(새) · `saga-web/tools/playcheck/pw-rts-*.mjs`(주소에 `&mode=rts`)

**단계**
1. `view.js` 에 모드 둘: 주소 `mode=rts` 면 지금 그대로, 아니면 턴 모드. 턴 모드는 `tactics.start(seed, diff)`(난이도 창 `askDiff` 재사용), 저장은 **새 칸** `core.save.rtsTb`(옛 `save.rts` 는 안 건드림), 틱 루프 대신 그리기만.
2. 고르기: 내 유닛 누르면 `reach` 칸 파랑·`targets` 빨강 → 칸 누르면 이동(250ms 미끄러짐) → 공격 대상 있으면 빨강만 남기고 누르면 공격, 없으면 "대기". 패널 단추: 공격·일격(쿨 n턴)·대기·취소. 행동 끝난 유닛은 회색.
3. 위 줄: `n턴 · 아군 차례 · 남은 행동 a/b` + 단추 **턴 끝**·**자동**(켜면 아군도 `autoTurn`). 적 차례는 유닛마다 300ms 씩 움직여 보이고, 피해 숫자를 띄운다. 끝나면 승패 창(`finishBox` 재사용)·저장 비움.
4. 건설 팔레트·생산·자원·세율 줄은 턴 모드에서 숨김(css 클래스 하나). 안내 줄은 "유닛을 눌러 움직이세요 / 턴 끝을 누르세요" 두 가지.
5. `pw-rts-turn.mjs`(본보기 `pw-rts-sheet.mjs` 의 session 꼴): 1280×720·폰 390×844 각각 — 콘솔 오류 0 · 열림(유닛 ≥2편) · 유닛 클릭 → 파란 칸 >0 · 이동 → 위치 바뀜 · 적과 붙인 뒤 공격 → 적 hp 줄어듦 · 턴 끝 → 턴 2 · 자동 켜고 30턴 안 결판 창 · 새로고침 뒤 턴·유닛 수 같음. 옛 `pw-rts-*.mjs` 주소에 `&mode=rts`.
