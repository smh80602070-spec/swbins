# W-0252 메뉴 UI 갈아엎기 ① 공용 창 틀(ui-kit.css) — 1만리 먼저
종류: 화면(메뉴 UI 전체) · 웹(공용 → 1만리, 플래그십)      상태: **끝**(Opus 10-16) · 작성됨(Opus R-0 10-16 — 수신함 17행 사용자 "메뉴 ui가 전체적으로 변경이 되어야 할것 같아" · "묻지말고 계속" → 정본 제안대로, 사용자 거부권)      등급 목표: D2

**목표(한 줄)**: 다섯 판이 같은 창 체계(상단 바·아래 독·슬라이드 시트 `#sheet`·모달 카드 `.enc-card`·`.btn`·탭)를 판마다 복사한 CSS 로 따로 그려 왔다 — 정본 하나 `shared/css/ui-kit.css` 로 **같은 틀**(배치·크기·8px 격자·글꼴 1+1·동작)을 만들고, 판마다 다른 건 **색 옷**(K-0040 9-slice 세트 `shared/assets/ui/<판>/`)뿐이게. 1만리부터 입힌다.

**잰 것(R-0)**: 공용 CSS 없음 · 토큰·창 마크업 다섯 판 같음 · 9-slice 세트(ui_parts.json)는 다섯 판 다 있으나 5천하 strategy.css(W-0088, 넓은 화면만·../../shared 경로)만 씀 · 스킨 시트 Claude 눈 ○(같은 모양 색만 다름).

**결정(정본 제안 — 사용자 거부권)**: ① 틀은 하나, 색 옷만 판별 ② 9-slice 는 CSS `border-image`(fill) — 시트 = window, 모달 카드 = popup, `.card` = card, 탭 = tab_on/off, `.btn` = btn_* 넷 ③ 8px 격자(안쪽 여백 16·24, 사이 8) · 글꼴 본문 Pretendard 하나 + 숫자 `tabular-nums` ④ 제목 띠: 시트 머리 아래 금빛 가는 줄(색 옷의 accent) · 닫기 40px 둥근 단추 ⑤ 폰(≤780px)에도 입힌다(5천하 W-0088 은 넓은 화면만이었다).

**파일**: 새 `saga-web/shared/css/ui-kit.css` · `tools/sync-shared.mjs`(css 한 줄 + 스킨 복사 `shared/assets/ui/<판 짧은 이름>/*.png` → `<판>/assets/ui/`, 출처 .license.json 은 정본에만 — web2d 복사와 같은 꼴) · `saga-go/index.html`·`_test.html`·`_demo.html`(style.css 다음 줄에 `<link rel="stylesheet" href="css/ui-kit.css">`) · `saga-go/sw.js`(precache `./css/ui-kit.css`·`./assets/ui/*.png`, VERSION) · `saga-go/css/style.css`(kit 와 겹쳐 싸우는 규칙만 지움 — 줄 수 줄어듦) · 새 `saga-web/tools/playcheck/pw-menu-sheet.mjs`

**단계**: ① ui-kit.css — 토큰은 이름 그대로 두고 `--ui-*` 만 더함(`--ui-window: url(../assets/ui/window.png)` 식, 판 폴더 기준 상대 경로 → 같은 파일이 다섯 판에서 제 색 옷) · 덮는 선택자는 마크업 공통분만(`#sheet`·`.sheet-head`·`#sheet-close`·`.enc-card`·`.btn`·`.btn.primary`·`.tabs > button`·`.card`) — 특이도는 style.css 와 같거나 낮게 하고 **style.css 뒤**에 실어 이기게 ② sync-shared 에 css·스킨 복사(`--check` 도 같이) ③ 1만리 세 html 에 link · sw ④ style.css 에서 kit 와 같은 속성을 다른 값으로 주는 규칙 정리(배경·테두리·radius — 레이아웃은 그대로) ⑤ pw-menu-sheet.mjs: 새 계정 → 독의 `data-sheet` 단추를 차례로 눌러 시트마다 한 장 + 조우 모달(enc-card) 한 장, PC 1280×720 과 폰 390×844 둘, 한 장 모음 PNG(`tools/playcheck/shots/menu/<판>-pc.png`·`-phone.png`) ⑥ 모음 PNG 를 Claude 눈으로 판정(틀 깨짐·글자 넘침·대비) — ○ 면 D2 · 고칠 것 있으면 같은 티켓에서.
