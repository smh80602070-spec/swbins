# W-0078 3D 바탕 위 2D 전투 이펙트 둘레에 검은 네모가 찍힌다(공용 vfx2d)
종류: 버그 · 웹(공용 `shared/js/vfx2d.js` — 쓰는 판 사가스토리·사가블로)      상태: **닫음 2026-10-06**(Claude 화면 확인)      등급 목표: D1→D2

**목표(한 줄)**: 타격 불꽃·레벨업·원소·투사체·등급 이펙트가 3D 바탕 위 투명 2D 캔버스에서도 검은 칸 없이 빛만 얹힌다.

**재현(10-06 Claude 화면 판정, 시트 saga-story-20261004 3번 메모)**: ① 사가스토리 사냥터(3D 바탕 기본) ② 무예(1)·평타로 적을 친다 ③ 불꽃·빛 둘레에 불투명한 검은 정사각형이 보인다.

**기대**: 검은 바탕 없이 빛만.

**지금(확인함)**: 시트 `vfx_<이름>_k.webp`·`rarity_*_k.webp` 는 검은 바탕(알파 없음). `draw`(51~61)·`proj`(85~95)가 `globalCompositeOperation='lighter'` 로 얹는다. lighter 는 알파도 더한다 — 3D 바탕일 때 2D 층은 `clearRect` 로 투명(사가스토리 `js/side-view.js:247·270`)이라 검은 픽셀이 알파 1 검정으로 남는다.

**고치는 법(정함)**: 받은 시트를 한 번 캔버스로 옮겨 **밝기 → 알파**(a = max(r,g,b), rgb = rgb×255/a, 원래 알파와 곱)로 바꾸고, 그리기는 그대로 `lighter`. 불투명 바탕 위 결과는 지금과 같다. 에셋 파일은 안 고친다(K 몫).

**파일**: `saga-web/shared/js/vfx2d.js`(정본 → `node tools/sync-shared.mjs`) · `saga-web/saga-dungeon/_test.html`(진단) · 번들 `saga-dungeon`·`saga-story`
