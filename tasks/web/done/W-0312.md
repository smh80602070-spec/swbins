# W-0312 체제 — 사람 몫(`human:true`) 칸 폐지 · 끝 판정을 자동 QC 하나로

**목표(한 줄)**: `features.json` 의 `human` 칸(웹 21개 — 전부 D3 `qc+claude`, 2나락 `dg.dungeon3d` 만 D2)을 없애고, 끝 판정을 "D2 이상" 하나로 통일한다. D3 는 남되 뜻이 "사용자 ○" 가 아니라 **QC 통과 + Claude 촬영·측정 판정 ○**(SAGA-ARCH §3.1 의 둘째 길)뿐이고, 사용자는 거부권만 — 사람 확인 시트(§3.2·RECURRING R-2) 는 폐지하고 그 자리를 "촬영 판정 세션"(Claude 가 QC 의 eyes PNG 를 보고 ○/△, △ 는 티켓) 으로 바꾼다.
