# W-0075 한 폴더에서 갈래 세션 충돌 줄이기 — 커밋 검사는 내 경로만, 푸시는 임시 트리 자동
종류: 도구(체제) · 공통(이 티켓이 tasks/README·루트 CLAUDE.md git 절·tools/hooks 손대기를 허락한다)      상태: **끝**(2026-10-06 — ④ sw.js 충돌 자동 풀기는 실전 대기)      등급 목표: D2

**목표(한 줄)**: 작업 폴더는 `C:\swbins` 하나 그대로. 네 갈래 세션이 같은 트리를 써도 ① 남의 미커밋 파일이 내 커밋 검사(precheck)를 막지 않고 ② 남의 미커밋 파일 때문에 pull·push 가 막히지 않게 한다.

**왜(확인함, 10-06)**: 오늘 웹 세션에서 pull 차단(자체툴 미커밋) 2회·push 거부(sw.js 버전 겹침) 2회 → 손으로 임시 worktree 체리픽 푸시 4회. 메모리 함정 7개 남짓이 같은 원인(`feedback_push_rejected_shared_dirty_tree`·`feedback_autostash_eats_uncommitted`·`feedback_worktree_commit_gate_checks_main_tree`·`saga_main_tree_stale_hook_block_1002` 등).

**확인한 사실**
- `tools/precheck.sh` "파일 크기"·"sw.js 버전"·"data.js md5"·"에셋 빠른 점검" 절이 `git diff`·`git diff --cached`·`ls-files --others`(트리 전체)를 본다 → 남의 작업 중 파일이 내 커밋을 FAIL 시킨다.
- 훅 `tools/hooks/gate.js` 는 `git commit` 명령 문자열을 받는다 — `-- <경로>` 를 읽을 수 있다.
- 손으로 해 온 푸시 절차(성공 4/4): `git worktree add --detach <짧은 경로> origin/main` → `cherry-pick <내 커밋>` → sw.js 겹치면 VERSION +1 커밋 → `push HEAD:main` → worktree 지움. 로컬 main 은 그 뒤 origin 과 갈라진 채 남는다(남이 dirty 라 reset 못 함).

**파일**: `tools/precheck.sh`(범위 인자) · `tools/hooks/gate.js`(커밋 경로 → 범위 전달) · 새 `tools/push.sh`(임시 트리 푸시) · `tasks/README.md`(절차 ④) · 루트 `CLAUDE.md` git 절(≤6KB 유지).

**단계**
1. precheck 범위: 환경변수 `PRECHECK_PATHS`(줄바꿈 목록)가 있으면 "바뀐 파일"을 보는 절들은 그 경로만 본다(없으면 지금처럼 트리 전체 — 손으로 돌릴 때 그대로). 트리 전체가 기준인 절(js 구문·shared 사본 md5·문서 크기)은 **내 경로가 그 대상일 때만** FAIL, 아니면 WARN 으로 낮춘다.
2. gate.js: `git commit … -- <경로…>` 면 그 경로(+ `git diff --cached --name-only`)를 `PRECHECK_PATHS` 로 넘긴다. `--` 없는 커밋은 지금처럼 트리 전체(규칙상 `--` 필수라 경고 한 줄).
3. `tools/push.sh [커밋…]`(기본 = origin/main 에 없는 내 HEAD 커밋 중 이 세션 것 — 인자로 받는다): 위 손 절차 그대로 자동. 짧은 경로 `C:/swt-<pid>`·`core.longpaths`. 체리픽 충돌이 sw.js VERSION 줄뿐이면 큰 쪽 +1 로 풀고, 그 밖 충돌이면 worktree 를 지우고 멈춰 보고(reset·강제 푸시 없음). 끝나면 worktree 지움. push 거부면 fetch 뒤 한 번 더.
4. 로컬 main 정리: 트리에 남의 dirty 가 **없을 때만** `reset --soft origin/main` + 내 경로만 checkout 하는 `push.sh --align`(dirty 있으면 아무 것도 안 하고 "갈라짐 n개" 한 줄).
5. 문서: tasks/README ④ "커밋 = `git commit -F … -- <경로>`, 푸시 = `bash tools/push.sh`" · 루트 CLAUDE.md git 절 두 줄 교체 · 메모리 함정 항목들에 "W-0075 뒤로는 push.sh" 한 줄.
