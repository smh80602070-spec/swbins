# W-0173 1만리 3D 검기 띠 + 칠 때 대상 쪽으로 돌기
종류: 손맛 · 웹(1만리 — 플래그십)      상태: 끝(10-11 Opus — 손맛 묶음 W-0169~0172 이어서, 사용자 "넘 재미가 모두 없어서"·"묻지말고 최대한 해봐")      등급 목표: D2

**목표(한 줄)**: 무기 몸짓만으로는 어디를 베었는지 안 읽히고, 뒤의 적을 치면 허공을 벴다 — 휘두를 때마다 무기·단별 빛 띠를 남기고 대상 쪽으로 몸을 돌린다.

**파일**: 새 `saga-go/js/slash3d.js`(`arcSpec(w, step)` 순수 · `swing(w, step, x, y, ang)` — world3d.addFx 에 가산 띠, 0.18~0.28초 퍼지며 사라짐, 인물 키 world3d.actorH 에 맞춤, 손잡이 `field.slashFx`) · `js/manifest.json`(+ `gen-index --add … --after js/field-combat.js`) · `src/world3d/04-actors.js`·`05-render.js`(`faceTo(x,y,ms)`·`meAng()`, 줄 수 그대로) · `src/field-combat/02.js` swing·heavy 줄 안 · `_test.html` 진단 1 · `tools/playcheck/go-slash-shot.mjs`

**모양**: 한손검 1타 허리 높이 가로 · 2타 반대 방향 비스듬 · 3타 크게 세로 내려찍기 · 큰날 더 넓고 두껍게(금빛) · 창 앞으로 곧은 찌르기 띠(3타 길게) · 서책·활 없음(쏘는 무기는 기존 고리).

**검증**: test-web saga-go 893/893 · `go-slash-shot.mjs` 다섯 컷 눈(C) ○ — 첫 시도는 높이 1.05 가 무릎(이 판 인물 키 3.4 단위)이라 가슴 높이·반지름을 키에 맞춤.
- ✔ 10-11 실전 확인(go-fight-shot.mjs, 자동 전투 12컷): **띠가 등 뒤로 그려지던 버그** — 원판을 −90° 로 눕혀 호 가운데가 −z 로 갔다(적 없는 단독 촬영에선 안 보였다) → +90°. 고친 뒤 띠가 적 쪽으로 ○.
