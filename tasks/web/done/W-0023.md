**목표(한 줄)**: 다섯 판 중 사가국지만 W-0019 의 2D 모드 반영이 0 이다(`mode2d.js` 도 안 붙어 있음). 사가국지의 2D 는 **국토 지도 SVG**(`#realm` 안 `.rmap` — 성 점·길·이름표, `btn-3d` 로 2D↔3D)뿐이고 전장(`battle3d`)·성 안(`city3d`)은 3D 전용이다. 이 티켓은 **지도 2D 를 K-0020 지형·K-0017 성 그림으로** 꾸민다. 2D 전장·성 안은 새 화면이라 이 티켓 밖(아래 메모).

**파일(확인함)**
- 지도 그리기: `saga-realm/src/ui-rtk/02.js:34` `renderMap()`(→ `js/ui-rtk.js`, `tools/build-parts.mjs`) — SVG `.rmap`(viewBox 이동·확대 `mapViewBox()`), 성 `<g class="rcity" data-city>` 의 점 `<circle>`(크기 = 병력)·이름표·재난·포위 이모지. 성 데이터 `js/data-city.js` `CITIES`: `{id,name,prov,x,y,land('hill'|'plain'…)}` — **지방 `prov` 와 땅 종류 `land` 가 있다**
- 2D 판정: `DG.realm3d.active()`(`js/realm3d.js`, 3D 가 안 서 있을 때). 설정 자리 = `js/core.js` 끝 `DG.cfg.mode2d`(다른 판 본보기). `sync-shared.mjs` FILES 의 `mode2d.js` 3째 칸에 `saga-realm` 이 **없다**(추가)
- 자료(이미 있음, 사가국지 접두어): `shared/assets/web2d/bg/realm_{central_city,frost_highland,river_harbor,silk_oasis}`(층 3겹) · `tile/realm_{dirt,grass,sand,snow,stone,water}.webp` · `world2d/{chinese_hall_01,stone_tower_01,silkroad_house_01,city_wall_segment_01,banner_pole_01,brazier_01}.webp`. 조회 `assets3d`(realm 에 이미 있음)

**단계**
1. `mode2d.js` 를 사가국지에 싣는다(FILES 3째 칸·manifest `--add`·sw)·`core.js` cfg `mode2d`(`on: !realm3d.active()`, `tileBase`, `tile`: 지방/`land`→`realm_*` 표, `prop2d`: 성 크기 3단→`silkroad_house_01`/`chinese_hall_01`/`stone_tower_01`).
2. 바닥: `.rmap` 뒤에 지형 바닥을 깐다 — SVG 안 `<pattern>`(타일 webp)·성 둘레 `land` 별 큰 원 번짐, 또는 `#realm` 의 CSS 배경. 2D 모드 아닐 때(3D)·자료 없을 때는 옛 어두운 배경 그대로.
3. 성 그림: 점 `<circle>` 위에(점은 손가락 목표·병력 표시라 **남김**) `<image>` 로 성 스프라이트. 크기는 병력 단계, 세력색 고리·내 땅 `ring`·포위·재난 이모지는 그대로. 이름표 겹침은 확대 단계에서만 그림을 켠다(멀리서는 점).
4. (선택) 지도 뒤 층 배경 `realm_*`(4 지방)을 지도 이동에 맞춰 느리게 — 효과·비용을 보고 한다/안 한다를 메모에.
5. 진단 +1~2(표 id·자료 없으면 옛 지도), `playcheck/pw-web2d.mjs saga-realm` 점검에 SVG 확인 추가, `sw.js` VERSION.
