# W-0060 사가블로 2D 아이소 기본 확대 — "너무 작다"(1.20 → 1.80)
종류: 버그(체감) · 웹(사가블로)      상태: **코드분 끝**(2026-10-05) — 사용자 눈 확인 대기      등급 목표: D1→D2

**목표(한 줄)**: 2D 아이소 화면에서 캐릭터·적이 PC 큰 화면에서도 작지 않게 기본 배율을 올린다.

**재현(10-05 사용자 "사가블로는 너무 작고")**: 1920×1080 으로 사가블로를 2D 로 두고 굴혈에 들어가면 방 전체(마름모)가 한 화면에 들어가도록 맞춰져 몸이 약 100px. `ZOOM = 1.20`(`src/dungeon-view/01.js`) × 사용자 확대 `camZoom` 1.0.

**고침**: `ZOOM` 1.20 → 1.80(1.5배). 카메라는 원래 인물을 따라가고 방 밖 여백은 가둔다(`metrics()`). 핀치·휠 확대·프로필 `camZoom` 은 그대로 곱해진다. 2D 아이소만 — 3D(`dungeon3d`)는 별도. 촬영: 몸 100px → 140px(`camZoom` 2.0 이면 190px). 진단 461/461 3회 동일 · `sw.js` dungeon-v0.199.19.

**해석 메모**: "작다"를 "화면을 더 당긴다" 쪽으로 읽었다 — 캐릭터·건물 자체 크기를 키우는 쪽이 맞으면 `cfg.mode2d.targetH`(몸 높이 기준 40px)를 키우는 후속. 폰 세로는 방 폭에 맞춰져 있어 같은 1.5배가 과할 수 있다(사용자 눈).

**검증 · 완료 조건**: 진단 461/461 · 촬영 · 사용자 눈("작다" 해소 여부, 폰 세로).

**닫음(10-05, 큐 순서 정리)**: D2 끝 — `pw-web-2d-sheet` 사가블로 2D 마을 · "작다" 체감은 사람 몫(시트 web-human)
