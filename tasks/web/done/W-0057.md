# W-0057 등급 연출 — 사가블로 바닥 장비 후광·줍기 연출·금 동전(K-0048 rarity·K-0039 coin_pop)
종류: 새기능 · 웹(사가블로)      상태: **닫음 2026-10-05**(눈 확인 — Claude 직접 촬영, 시트 web-visual-20261004 14번 ○)      등급 목표: D1→D2

**목표(한 줄)**: 좋은 장비가 바닥에 떨어졌을 때 눈에 띄게(후광), 주울 때 터지게(획득 연출), 금을 주울 때 동전이 튀게 한다. 에셋은 만들지 않는다.

**지금 상태(확인함)**: 사가블로 장비 등급은 `data-item.js TIERS`(0 상품 · 1 양품 · 2 명품 노랑 · 3 보물 초록 · 4 전설 금). 바닥 장비는 등급색 마름모+이름표뿐. 줍기(`take`)는 글자 fx(`get`). K-0048 `rarity_acquire_N`(12프레임 1회)·`rarity_aura_N`(8프레임 루프) 5등급, 팔레트는 `data.js RARITY`(회색·초록·파랑·보라·주황금) — **사가블로 장비 등급색과 팔레트가 다르다**.

**연결표(이름표 색과 색상이 가까운 시트로)**: 명품(노랑)·전설(금) = 시트 5(주황금), 보물(초록) = 시트 2(초록), 상품·양품 = 없음. 전설은 후광을 더 크게(108 vs 76). 처음엔 `tier+1` 로 짝지었다가 노란 명품 밑에 파란 링이 떠 이름표와 어긋나 고침. 금 줍기 = `coin_pop`.

**파일**: `shared/js/vfx2d.js`(`rarOfTier`·`aura`·등급 시트 표·`urlOf`·`fxLayer` 의 `get` 갈래) · `saga-dungeon/src/dungeon/06-skill.js`→`js/dungeon.js`(줍기 `get` fx 에 `rar`·금에 `k:'gold'` 필드만 덧붙임, 줄 수 불변) · `src/dungeon-view/02.js`→`js/dungeon-view.js`(바닥 장비 후광 한 줄) · `js/core.js`(`cfg.vfx.preload`) · `tools/sync-shared.mjs`(`VFX_GAMES` 가 `rarity_` 이름은 `assets/rarity/` 로) · `sw.js`(dungeon-v0.199.18)·`_test.html`
