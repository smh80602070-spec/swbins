# W-0050 타이틀 키 아트 — 다섯 판 계정(타이틀) 화면 배경에 K-0041 키 아트
종류: 새기능 · 웹(다섯 판)      상태: **닫음 2026-10-05**(눈 확인 — Claude 직접 촬영, 시트 web-visual-20261004 1번 ○)      등급 목표: D1→D2

**목표(한 줄)**: 자체툴이 `saga-assets/store/<판>/` 에 만든 판별 키 아트(가로 1920×1080·세로 1080×1920)를 다섯 판 계정·타이틀 화면(`#acc-host`) 배경으로 깐다. 에셋은 만들지 않는다(웹은 복사·배선만). 앱 아이콘·스토어 이미지·로딩 3장은 상용화 빌드 티켓 몫이라 안 씀.

**지금 상태(확인함)**: 타이틀 화면은 공용 `shared/js/account.js` 가 그리는 단색 그라데이션 + 이모지 + 카드. 그림이 없다. K-0041 메모: 키 아트는 판마다 임시 선택, `saga-assets/store` 에만 있고 웹 대상 배치가 없었다 → 웹이 `shared/assets/store/<판>_key_h|v.webp`(+출처 `.license.json`, id 를 파일명으로)로 복사.

**파일**: `shared/assets/store/`(10장 + 출처 10) · `shared/js/account.js`(`CFG.art` 가 있으면 가로/세로 배경 + 어두운 막) → 다섯 판 복사 · 판별 `js/core.js` `DG.cfg.account.art` 한 줄 · `saga-dungeon/css/diablo.css`(타이틀 배경을 `!important` 로 덮고 있어 같은 비네팅 위에 그림) · `tools/sync-shared.mjs`(`STORE_GAMES` — 판마다 두 장 → `<판>/assets/store/`) · `sw.js` 다섯 판 · `_test.html` 다섯 판

**검증**: `node tools/test-web.mjs <다섯 판>` 전부 통과(+판마다 키 아트 주소·스타일) · `precheck` OK · 가로·세로 타이틀 촬영(사가의숲 세로, 사가블로·사가고·사가스토리·사가국지 가로).

**완료 조건**: 사용자 눈.

**불변 규칙**: 세이브·id 불변 · 에셋 안 만든다 · 이름 정책 · 그림이 없거나 늦으면 지금처럼(색 그라데이션) · 글자는 그림에 없고 게임이 얹는다.

**결과(10-04)**: ✔ 위 파일 전부. 촬영 확인: 사가의숲 세로(큰 나무집 숲이 카드 뒤)·사가블로(디아블로 비네팅 위 불타는 계단 문)·사가고(석양 마을)·사가스토리(떠다니는 섬). **세로 그림(`_v`)은 위아래에 흐린 띠가 박혀 있다**(K 산출 그대로) — 불편하면 K 에 재생성 요청하거나 가로 그림을 세로에도 쓰도록 바꾼다. 고르기는 K 세션 임시(사용자가 바꾸면 K 가 교체 → `shared/assets/store` 를 다시 복사).
