**단계**
1. `mode2d.pace(key, wx, wy, ppu, bodyPx)` — 키별 누적 d = hypot(Δwx, Δwy)·ppu(화면 px). d > 3·bodyPx 면 순간이동이라 안 쌓음. 반환 t = (acc / (K·bodyPx)) mod 1. 손잡이 `mode2d.strideK`(0.9 = 두 발 한 바퀴가 몸 높이 0.9) · `mode2d.strideMaxHz`(3.2 — 넘으면 한 바퀴 시간을 묶음, 4종횡 달리기 다리 깜박임 방지) · `mode2d.strideMinHz`(0.6 — 1만리처럼 화면 속도가 아주 느릴 때 최소 걸음).
2. `draw`: `o.stride`(0~1)가 있고 걷기면 칸 = floor(o.stride·8)(`o.t` 와 같은 길). 한 장 모드 `stillPose` 의 걷기 위상도 o.stride.
3. 네 판 actor2d: `o.wx, o.wy, o.ppu` 를 받아 `M.pace(key, …)` → stride. 부르는 자리는 세계 좌표·그 판 배율(px/단위)을 넘김.
4. 진단(2나락 `_test.html`, 공용 함수): 몸 100px·ppu 1 로 90px 가면 한 바퀴 · 멈추면 그대로 · 300px 순간이동은 안 쌓임 · maxHz 묶임.
5. `build-parts` · 번들 넷 · sw VERSION +1(넷).
