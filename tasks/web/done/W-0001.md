# W-0001 웹 헤드리스 러너 `tools/test-web.mjs`
종류: 통합      판: 웹 다섯      등급 목표: (체제) — 이후 모든 D1 판정의 근거

**목표(한 줄)**: 명령 하나로 웹 판의 `_test.html` 을 빈 포트에 띄워 헤드리스 크롬으로 돌리고 `RESULT n/m`·실패 줄을 찍고 종료 코드를 낸다.

**파일**: `tools/test-web.mjs`(새) · `tools/precheck.sh`(`--full` 분기 4줄) · `tools/README.md`(점검 표에 한 줄) · `.gitignore`(`tools/_prof/` 한 줄)

**본보기(이 파일처럼)**: `saga-web/tools/mobile-layout/probe.js` — 서버(`gameserve.handle`, 포트 0 = 빈 포트)·크롬 `spawn`(전용 `--user-data-dir`)·끝나면 **그 PID 만** `taskkill /T /F /PID`. 그대로 베낀다. CDP 는 쓰지 않는다(`--dump-dom` 이면 충분).

**단계**
1. 인자: 판 이름들(없으면 다섯 전부, `all` 도 같음) · `--runs=N`(기본 1) · `--budget=ms`(기본 45000, 사가국지는 기본 180000).
2. `http.createServer` 로 `saga-web/` 뿌리를 `gameserve.handle(req,res,u,ROOT,[판])` 으로 서빙, `listen(0)` 뒤 실제 포트를 읽는다.
3. 판마다 `spawn(CHROME, ['--headless=new','--disable-gpu','--user-data-dir=<tools/_prof/<판>>','--virtual-time-budget=<budget>','--dump-dom','http://127.0.0.1:<port>/play/<판>/_test.html'])`. `CHROME` 은 probe.js 와 같은 경로·환경변수. stdout 을 모으고 10분 타임아웃(넘으면 PID 종료·FAIL).
4. 파싱: `<title>RESULT n/m</title>` → n,m. 실패 줄 = `<span class="fail">FAIL</span> <이름>` 을 정규식으로 뽑아 이름만. PASS/FAIL 이름 목록의 md5 를 run 마다 남긴다(전체 DOM 을 비교하지 않는다 — 시각·HUD 줄이 흔들린다).
5. 출력(판마다 한 줄): `saga-story RESULT 259/259 runs=1 SAME` · 실패가 있으면 그 아래 이름을 한 줄씩. `--runs>1` 이고 목록 md5 가 다르면 `DIFF`. 종료 코드: 실패 0·DIFF 없음 → 0, 아니면 1.
6. `tools/precheck.sh`: `--full` 인자가 있을 때만 `node tools/test-web.mjs all` 을 돌리고 종료 코드로 fail 을 올린다. 기본 실행은 지금과 같다(서버·크롬 안 띄움).
7. 결과 파일: `tools/_out/test-web.json`(gitignore) 에 `{판:{n,m,fails:[…],at}}` — W-0003 이 읽는다.

**검증**
```
node tools/test-web.mjs saga-story            → "saga-story RESULT n/n runs=1 SAME", 종료 0, 크롬 프로세스 남지 않음(tasklist | grep -c chrome 이 실행 전과 같다)
node tools/test-web.mjs saga-go --runs=2       → SAME
```
전체 다섯·사가국지는 이 티켓에서 돌리지 않는다(R-1 에서).

**완료 조건**: 위 두 줄 · precheck `--full` 분기 · README 한 줄 · `.gitignore` · 실패가 있어도 러너는 정상 종료(종료 1)하고 이름을 찍는다.

**불변 규칙 확인**: 판 파일(`saga-web/*/`) 수정 0 · 사용자 크롬(`//IM chrome.exe`) 안 죽임 · 서버는 명령 끝에 `close()` · 씨앗·날씨 고정은 `_test.html` 이 이미 한다.

- 측정: saga-story 258/259(탱커형 실패 1, SAME) · saga-go 827/828 runs=2 **DIFF**(회차마다 실패 1개가 달라짐 — ⑰ 지형·⑲-10 들판 보스, 불안정 진단) → W-0002/R-1 에서 다룬다.
