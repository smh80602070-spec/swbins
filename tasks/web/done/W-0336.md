# W-0336 다섯 판 2D 오딘스피어식 — 공용 컷아웃 뼈대(cutout2d)·겹 배경(parallax2d) 엔진 + 대역 그림
종류: 그래픽(2D 본판) · 웹(다섯 판 공용)      상태: **끝**(D1 — 그림 K 대기, 오퍼스 10-19 · 작성 R-0 10-19 — 수신함 "2D 는 오딘스피어 같은 그래픽 · 다섯 판 동일")

**목표(한 줄)**: 지금 2D 사람·괴물은 VRoid 렌더 8칸 시트(`shared/js/mode2d.js`, 128px)라 "3D 를 찍은 그림"으로 보이고 다섯 판 배경도 제각각이다. 오딘스피어 문법 — ① **큰 손그림 인물을 부위(머리·몸통·팔 위/아래·손·다리 위/아래·발·옷자락·머리카락 2~3)로 잘라 뼈에 붙여 움직이는 컷아웃 애니**(숨쉬기·옷자락 흔들림·관성) ② **5~7 겹 그림 배경**(먼 하늘·산·중경·땅·앞가림, 깊이별 속도·안개색·빛 띠) — 을 **공용 엔진 둘**로 만들고 다섯 판 2D 화면이 같은 엔진·같은 규격을 쓰게 한다. 그림은 K 몫이라 이 티켓은 **엔진 + 대역 그림(코드로 그린 부위 도형·색 층)** 까지, K 그림이 오면 표만 바꿔 갈아 끼운다.

**파일**: 새 `saga-web/shared/js/cutout2d.js`(부위 그림 + 뼈 트리 + 클립 JSON 규격 `cutout/<id>/rig.json`·`<부위>.webp` — 자체 형식, 바깥 런타임 없음) · 새 `shared/js/parallax2d.js`(층 표 `bg2d/<장소>/layers.json` — 층마다 그림·깊이·반복·안개) · `tools/sync-shared.mjs`(사본 다섯) · 각 판 `js/manifest.json`(mode2d 뒤) · 판별 2D 그리기 자리(1만리 `world.js` 2D 칠·2나락 `town2d`/`dungeon-view`·3마을 `village-view.js`·4종횡 `side-bg2d.js`·5천하 2D 지도 바탕) 한 줄씩 — `DG.cutout2d.has(id)` 면 컷아웃, 없으면 mode2d 그대로 · `_demo.html#cutout`(다섯 판) · `_test.html` 다섯 판 · 번들·sw 다섯

**단계**: ① 규격 문서를 cutout2d.js 머리에(뼈 이름 16 고정·부위 축 원점·클립 = 뼈별 회전/이동 키, 보간·관성 2차 흔들림) ② 엔진 — 캔버스 2D 로 뼈 순서대로 drawImage(변환 행렬), 클립 idle·walk·run·attack·hit·death·jump 일곱 ③ 대역 rig 하나(`cutout/_stub/` 코드 그림 — 둥근 부위 도형·옷 색 칸) ④ parallax2d — 카메라 x·y 로 층별 이동, 층 사이 안개색 섞기, 앞가림 층은 인물 위 ⑤ 대역 층 표 다섯 판(장소 하나씩) ⑥ 판별 연결(손잡이 `<판>.cutout2d`·`<판>.parallax2d` 기본 0 → 대역으로 켜 보고 촬영) ⑦ 진단 2(rig 읽기·클립 보간 값 / 층 이동 비율) ⑧ 촬영 다섯 판 폰 세로·PC

**검증**: `node tools/test-web.mjs <판>` 다섯 판 RESULT n/n(+2씩) · `_demo.html#cutout` 다섯 판 촬영(대역 인물이 걷기·공격에서 부위가 떨어지지 않음, 배경 층이 다른 속도로 흐름) · `node tools/qc.mjs --branch web --no-shots` · 폰 예산(`pw-phone-budget.mjs`) 2D 장면 FPS 가 켜기 전보다 10% 넘게 안 떨어짐

**완료 조건**: 엔진 둘 · 규격 문서 · 대역으로 다섯 판 연결(손잡이 0 이 기본 — K 그림 오면 1) · 진단 · 촬영 · K 요청 수신함 한 줄(부위 그림·배경 층 규격) · features 한 줄씩(D1) · done/.

**불변 규칙**: 그림은 K 몫(대역은 코드 도형만, 원작 그림·실명 금지) · mode2d 는 지우지 않음(없으면 되돌아감) · 세이브 키 그대로 · 공용은 정본 `shared/js` 고치고 sync-shared.
