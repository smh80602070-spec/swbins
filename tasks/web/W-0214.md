# W-0214 2나락 폰 마을 — 건물·나무 먼저, 마을 사람 몸은 받기 줄이 빈 뒤
종류: 성능 · 웹(2나락 3D, 폰)      상태: 작성됨(Opus R-0 10-14 — W-0213 뒤 측정 "45초가 지나도 건물·나무가 상자")      등급 목표: D2

**목표(한 줄)**: 폰(4G)으로 마을에 들어서면 미리 받기가 주민 몸 9개(각 ~600KB)를 먼저 줄 세워 45초가 지나도 큰 건물·들판 나무가 상자로 남는다 — 폰에선 주민 몸을 받기 줄이 빌 때까지 미뤄 건물·나무·내 부대가 먼저 서게.

**잰 것(R-0, 10-14)**
- `PLAY_MS=45000 mobile-probe.mjs saga-dungeon --local --play`: 45초에 받은 13,921KB/201개 · GLB 12개 5,249KB 중 9개가 characters3d(주민) · 소품은 집 둘(house_stone·house_wooden 352KB)뿐 · 화면(Read) 왼쪽 큰 건물·아래 들판 나무가 도형 상자.
- 받기 줄 = `saga-web/saga-dungeon/js/asset3d.js` 966~1010 `startQ`(FIFO, MAX_INFLIGHT 3) · 마을 진입 미리 받기 = `src/dungeon3d/03.js` 101 `prefetchActors`(나 + 주민 전원 touch) · 주민 몸 세우기 = `03.js` 612~614(`AS3.build`/`AS3.buildHero('npc:…')`).
- 품질 등급(QUALITY_PRESET)은 GLB 를 끄지 않는다 — 상자는 받기 순서 탓.
- `dungeon3d.js` 3,040 줄(big-files) — 기존 줄에만 덧붙인다.

**파일**: `saga-web/saga-dungeon/js/asset3d.js` · `saga-web/saga-dungeon/src/dungeon3d/03.js`(→ `node tools/build-parts.mjs`) · `_test.html` · `sw.js` · `features.json` · 번들 · 측정 `saga-web/tools/playcheck/mobile-probe.mjs`(PLAY_MS)

**단계**
1. asset3d: 손잡이 `asset3d.lazyNpc`(auto = 폰 표 light() · 1 · 0). `withLazy(fn)` 안에서 세운 몸(buildHero·build)은 acquire 를 바로 부르지 않고 줄 밖(lazyQ)에 둔다 — 받기 줄이 비면(inflight 0·startQ 빔) 차례로 풀고, 25초 지나면 무조건 푼다.
2. dungeon3d: 주민 몸 세우기(612~614)를 withLazy 로 · prefetchActors 는 lazyNpc 면 주민 touch 를 건너뜀(나·동료는 그대로).
3. 진단 +1: lazyNpc 1 이면 withLazy 로 세운 몸은 받기 전(줄 밖) · 줄이 비면 풀림 · lazyNpc 0 이면 바로.
4. 번들 · sw VERSION +1.
