# W-0022 2D 모드 건물·지물 — 사가고 역참·성채·랜드마크 + 사가블로 마을·방 지물을 통일 스프라이트로(코드만)
종류: 새기능 · 웹      상태: **작성됨**(R-0 2026-10-03, W-0019 후속·사용자 "다섯 판 2D" 지시)      등급 목표: D2

**목표(한 줄)**: W-0019 가 사가의숲 집·우편함만 K-0017 스프라이트(`shared/assets/world2d/<id>.webp`, 3D 와 같은 id)로 바꿨다. 사가고·사가블로 2D 에도 **이미 건물·지물을 그리는 자리가 있는데** 옛 그림(`sprite.buildingImg`·코드 도형)이라 같은 방식으로 잇는다. 에셋은 안 만든다(없는 것은 K 티켓).

**파일(확인함)**
- 읽는 쪽 `saga-web/shared/js/mode2d.js` — `drawSprite(ctx,{id,x,y,h})`·`drawKind(ctx,kind,x,y,k)`·`spriteReady(id)`, 주소 `assets3d.spriteUrl(id)`. 판 설정 `DG.cfg.mode2d.prop2d = { 종류: { id, h } }`(사가의숲 `core.js` 가 본보기)
- 사가고 2D: `saga-go/src/world/02.js`(→ `js/world.js`, `tools/build-parts.mjs`) — `drawStation`(역참)·`drawFort`(성채 등급 1~3, 지금 `sp.buildingImg('Watchtower'|'Tower'|'tower_round')`)·`drawLandmark`(바이옴 랜드마크, `biome.js`). 마을 칸(`terrainAt==='town'`)은 2D 에 집을 안 그림(옛 점·색 타일만)
- 사가블로 2D: `saga-dungeon/src/dungeon-view/02.js`(→ `js/dungeon-view.js`) — 벽 횃불 `drawTorch`·기둥 `drawPillar`·항아리 `drawJar`·문·샘·사당은 이모지 `thingItem`. 마을(`run.town`) 장면의 집·우물 그림 자리는 **단계 1 에서 확인**

**단계**
1. 사가블로 `run.town`·방에서 건물·지물이 어디서 그려지는지 `grep -n "town\|house\|well\|drawThing"` 로 확정해 표로 적는다. 자리가 없으면 그 종류는 하지 않고 메모에(새 자리 안 만듦).
2. 사가고: 역참 ← `inn_01`·성채 등급 1·2·3 ← `stone_tower_01`/`chinese_hall_01`(키 다르게)·랜드마크 ← `stone_tower_01`·`ridge_01` 등 바이옴별 표(`prop2d` 키 `fort:t1`…). `drawFort` 의 `sp.building(...,img:)` 은 이미 이미지를 받으므로 **이미지만** 통일본으로(`mode2d.spriteImage(id)` 새로 — 알파 범위·`img` 규격은 `sprite.building` 이 받는 모양을 읽어 맞춘다). 깃발·세력색·고리는 코드가 그대로.
3. 사가블로: 단계 1 에서 자리가 있는 것만(횃불 `torch_stand_01` 등). 이모지 아이콘(상자·샘)은 아이콘 계열이라 이번엔 안 건드림.
4. 진단 +1씩(표의 id 가 `assets3d.has('world')`·못 받으면 false), `playcheck/pw-web2d.mjs <판>` 지물 점검, `sw.js` VERSION ×2.

**검증**
```
node tools/build-parts.mjs && node tools/sync-shared.mjs --check
node tools/test-web.mjs saga-go saga-dungeon   → 전후 값 같음(+새 진단)
node saga-web/tools/playcheck/pw-web2d.mjs saga-go / saga-dungeon  → 지물 OK
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 사가고 역참·성채·랜드마크가 2D 에서 통일 스프라이트로 선다(사용자 눈 확인 시트) · 자리 없는 것은 옛 그림.

**불변 규칙**: 에셋 수정 0·새 에셋은 K 티켓 · 세이브 키·도감 `id` 불변 · 큰 파일 줄 수 불변(src 조각) · 2D 가 아닌 3D 경로는 안 건드림.

**메모**: 마을 칸에 집을 새로 세우는 것(2D 지도 마을 장식)은 새 기능이라 이 티켓에 안 넣음 — 필요하면 별도 티켓.
