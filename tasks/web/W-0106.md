# W-0106 웹 2D 모드 리뉴얼 1차 — 다섯 판 2D 화면을 QC 로 찍어 Claude 가 판정하고 흠을 고친다
종류: 닫기+버그 · 웹(다섯 판)      상태: 작성됨(R-0 페이블 2026-10-07)      등급 목표: D2(2D 장면)

**목표(한 줄)**: 사용자 10-07 "웹은 2D 버전도 리뉴얼이 필요해 보여" — 2D 모드(3D 못 쓰는 폰의 비상 경로이자 "웹 2D 단추 = 전체 2D", ARCH §8-10 유지 결정)가 3D 와 **같은 게임으로 보이게**. 1차 = 다섯 판 2D 장면을 기계로 찍고(QC `2D 한 장` + 장면 추가) Claude 가 눈으로 판정해 흠 목록을 만들고, 코드로 고칠 수 있는 흠은 이 티켓에서 고치고 에셋 흠은 K 요청 티켓으로 넘긴다. 사람 눈은 안 쓴다(INTAKE §4).

**아는 흠(10-06 메모·메모리)**: 옆모습 걷기가 뒷걸음처럼 보임 · B 그림체 잔존 · 상자가 3D 로 섞임 · 인물 크기 비율(`targetH`·`poolH`) 판마다 들쭉 · 8방향 시트(299명 `characters2d8`) 배치 뒤 공격·피격 동작 확인은 사가나락만.

**파일**: `saga-web/shared/js/mode2d.js`(**정본** — 판별 사본은 `node tools/sync-shared.mjs` 가 만든다, 직접 안 고침) · 각 판 `js/core.js` 끝 `DG.cfg.mode2d`(pools·poolH·targetH·foot) · 각 판 2D 그리기 조각(`saga-go/js/overworld.js`·`saga-dungeon/js/dungeon-view.js`(src/dungeon-view)·`saga-forest/js/village-view.js`(src/village-view)·`saga-story/js/side-view.js`·`saga-realm/js/map2d.js` — 단계 1 `grep -ln "mode2d\." js/*.js` 로 확정) · `saga-web/tools/playcheck/pw-look2d.mjs`(장면 추가: 판마다 전투·실내·밤 등 2~3) · `saga-web/tools/playcheck/pw-web-2d-sheet.mjs`(장면 수 반영) · 새 시트 `tasks/sheets/web-2d-20261007.md`(Claude 판정표 ○△×, 사람에게 보내는 글 아님) · 각 판 `features.json` 2D 항목 note(`go.sprite`·`dg.x`·`fs.village-view`·`st.side`·`rk.ui-rtk` 중 2D 를 뜻하는 것) · 바뀐 판 `sw.js` VERSION

**단계**
1. `pw-look2d.mjs` 에 판마다 장면 2~3 추가(사가만리 map·전투·밤 / 사가나락 town·room·boss / 사가마을 village·집 안·축제 / 사가종횡 field·cave·gorge(있음) / 사가천하 map·전투 2D) → `node tools/qc.mjs --no-shots` 가 아니라 `node tools/qc.mjs` 다섯 판으로 PNG 를 찍는다(`shots/qc/`).
2. Claude 가 PNG 전부를 Read 로 보고 시트에 장면마다 ○△×·흠 한 줄(크기 비율·방향·그림체·UI 겹침·3D 혼입·배경 타일 어울림). 시트를 먼저 커밋(체크포인트).
3. 코드 흠 고치기(이 티켓 범위): 방향(`dirOf8`·옆모습 뒤집기) · `targetH`·`poolH` 판 간 통일(보통 몸 = 화면 높이의 1/7, PLAN §2.4 폰 규격) · 3D 소품이 2D 에 섞이는 분기 · UI 겹침. 에셋 흠(그림체 B 잔존·배경 타일·소품 2D 없음)은 `tasks/tools/K-NNNN.md`(번호 = 그 폴더 최대+1) **요청**으로(무엇을·왜·어느 경로, 유니티 큐 규약과 같은 꼴) 남기고 그 자리는 메모만.
4. `node tools/sync-shared.mjs` → 판별 번들(`bundle.mjs <판>` 바뀐 판) → sw → features note("2D 1차 ○ n/m, W-0106") → 큐 줄·메모.

**검증**: `cd saga-web/tools/playcheck && node pw-web-2d-sheet.mjs` 5/5(서버는 스크립트가 띄우고 끈다) · `node tools/qc.mjs` QC PASS(2D 한 장 다섯 PASS) · `node tools/test-web.mjs all` RESULT 다섯 n/n · `bash tools/precheck.sh` OK.

**완료 조건**: 시트에 장면 ≥12 판정 · 코드 흠 전부 고침(△ 이상) · 에셋 흠은 K 요청 티켓에 전부 적힘 · 2D 진단(`2D 앞·뒤 모습(W-0073)` 등) 그대로 PASS.

**불변 규칙**: 에셋 안 만듦·안 고침(K 몫) · 3D 그리기 안 건드림 · 세이브 키 불변 · 2D 모드 끄기/지우기 금지(ARCH §8-10, 사용자 10-07 리뉴얼 지시).
