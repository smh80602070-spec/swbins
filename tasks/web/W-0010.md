# W-0010 `js/manifest.json` + `tools/gen-index.mjs`
종류: 통합      판: 웹 다섯      상태: **작성됨**(R-0 완료 2026-10-01)

**목표(한 줄)**: 판마다 `index.html`·`_test.html` 의 `<script src>` 나열을 `js/manifest.json` 하나가 쥐고, `tools/gen-index.mjs` 가 html 에 다시 쓰고(`--check` 는 비교만) 새 파일은 한 줄 명령(`--add`)으로 끼운다. **지금 순서를 한 글자도 안 바꾼다.**

**확인한 사실**: 다섯 판 index 는 script 줄이 37~107개, `_test.html` 은 33~106개. 둘의 순서는 같지 않다 — `_test` 는 three(`js/vendor/three.iife.js`)·몬스터 매니페스트·`errlog.js` 자리가 다르고(사가블로 3·사가의숲 1·사가스토리 1 곳 순서 이동) index 에만 있는 줄(`perf.js`·`icon.js`·`portraits/manifest.js` 등)이 있다. 또 사이에 **줄 단위가 아닌 것**이 끼어 있다: `_test` 의 `<script>window.DG_NO_DRAW…</script>` 인라인(사가블로·사가의숲), 사가스토리 index 의 `async` three 태그+주석. 그래서 "한 목록에서 둘을 뽑기"는 안 하고 **파일마다 목록을 따로 두되 한 json 에 둔다**.

**파일**: 다섯 `js/manifest.json`(새) · `tools/gen-index.mjs`(새) · `tools/precheck.sh`(절 하나) · `tools/README.md`(한 줄). 다섯 html 은 글자가 안 바뀐다(바뀌면 실패).

**본보기**: `tools/sync-shared.mjs`(`--check` 꼴) · 줄 형식은 `<script src="X"></script>` 한 줄짜리만 다룬다.

**단계**
1. 형식: `{"index": [[run…],[run…]], "test": [[…],…]}` — **run** = html 에서 `<script src="X"></script>` 한 줄짜리가 **연속**한 덩어리(사이의 인라인·주석·`async` 태그는 run 을 가른다). 각 run 은 src 문자열 배열.
2. `gen-index.mjs --init`: 지금 html 두 파일을 읽어 run 으로 쪼개 `js/manifest.json` 을 만든다(처음 한 번, 이후도 안전하게 덮어쓰지 않고 "있음" 출력).
3. 기본 실행 = 각 html 의 run 자리를 manifest 순서대로 다시 쓴다(들여쓰기·줄바꿈 CRLF/LF 는 그 파일 것 그대로). `--check` = 쓰지 않고 html 의 run 들이 manifest 와 같은지 비교, 다르면 파일·줄을 찍고 종료 1.
4. `--add <판> <js/새.js> --after <js/앞.js> [--test|--index]`: 앞 파일이 든 run 에 끼운다(옵션 없으면 index·_test 둘 다에 `--after` 가 있는 쪽). 쓰고 나서 `sw.js` SHELL 에 `'./<새>'` 가 없으면 경고 한 줄(자동 수정은 안 함).
5. precheck: "== script 순서 manifest" 절 `node tools/gen-index.mjs --check || fail=1`. README 표 한 줄.

**검증**
```
node tools/gen-index.mjs --init && node tools/gen-index.mjs     → git diff --stat saga-web/*/index.html saga-web/*/_test.html 가 비어 있다(글자 그대로)
node tools/gen-index.mjs --check                                  → OK 5판, 종료 0
node tools/test-web.mjs saga-story saga-forest                    → 391/392 · 258/259 그대로
```
`--add` 시험: 임시로 `saga-forest` 에 `--add saga-forest js/x.js --after js/core.js` → html 에 한 줄 생김, `--check` OK → `git checkout -- saga-web/saga-forest` 로 되돌린다.

**완료 조건**: 위 셋 · manifest 다섯 · precheck OK · html 글자 변화 0 · `--add` 시험 통과.

**불변 규칙 확인**: 게임 코드·로드 순서 변경 0 · sw.js VERSION 불변(js 안 바뀜) · `_demo.html`·`_admin.html` 은 이번 범위 밖(후속) · build-single 은 index.html 에서 뽑으므로 영향 없음.
