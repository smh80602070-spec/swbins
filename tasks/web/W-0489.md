# W-0489 3마을 숲 구역 경계에 1만리식 넘김 막·안개 벽(W-0488 ②)
종류: 화면·구조 · 웹(3마을)      상태: 작성됨(10-28 W-0488 ① 설계 결과)      등급 목표: D2

**배경**: 3마을은 이미 마을(30×20칸) 둘레에 이름 있는 숲 여덟(village.js FORESTS, 방위 sector·BIOME_CELL 22칸)이 고정으로 선 열린 땅이다 — 구역 자료는 새로 안 만든다. 없는 것은 1만리의 경계 넘김 막(zoneCut.hookKey)·안개 벽(zoneCut.walls, W-0417)·2D 안개뿐(village-view·village.js 에 zoneCut 0건).
**목표**: 걸어서 숲 방위가 바뀌거나 마을↔숲 경계를 넘으면 공용 넘김 막이 덮고 새 구역 소품을 짓는 동안 기다렸다 걷는다. 구역 밖은 안개 벽. 판정·세이브·구면 투영 불변.
**단계**: ① 구역 키 함수 `forestZoneKey(p)` = 마을 칸이면 'village' 아니면 FORESTS sector(끈끈하게 zoneStick 24 단위 — 1만리 goZoneIdx 꼴). ② village-view 에서 DG.zoneCut.hookKey(키, {wait}) 걸기(wait = 소품 짓기 줄·zoneCut.netBusy). ③ 3D(village-view3d)는 zoneCut.walls·threeBusy. ④ 손잡이 zoneCut.on 0 이면 옛 그대로.
**파일**: saga-web/saga-forest/js/village-view.js(src 조각 있으면 조각)·village-view3d.js·village.js · 정본 참고 saga-web/saga-go/js/zone-wire.js. 새 js 는 _admin·_autoprobe 에도.
**검증**: `node tools/test-web.mjs saga-forest` RESULT n/n(SAME) · 진단 추가(키 함수 순수: 경계 ±24 안은 안 바뀜) · `node tools/qc.mjs --game saga-forest`.
