# W-0078 3D 바탕 위 2D 전투 이펙트 둘레에 검은 네모가 찍힌다(공용 vfx2d)
종류: 버그 · 웹(공용 `shared/js/vfx2d.js` — 확인은 사가스토리, 다른 판도 같은 층이면 같음)      상태: **초안**(R-2 10-06 — 단계·검증·완료 조건은 페이블 R-0)      등급 목표: D1→D2

**재현(10-06 Claude 화면 판정, 시트 saga-story-20261004 3번 메모)**: ① 사가스토리 사냥터(3D 바탕 켜진 기본) ② 무예(1)·평타로 적을 친다, 또는 레벨업 ③ 타격 불꽃·레벨업 빛 둘레에 불투명한 검은 정사각형(이펙트 칸 크기)이 보인다.

**기대**: 검은 바탕 없이 빛만 얹힌다(2D 바탕일 때와 같은 모습).

**확인한 것(실마리)**: 시트 `vfx_<이름>_k.webp` 는 검은 바탕이라 `draw`·`proj` 가 `globalCompositeOperation='lighter'` 로 얹는다. 3D 바탕일 때 2D 캔버스는 `clearRect` 로 투명 — lighter 는 알파도 더해 검은 칸이 불투명 검정이 된다. 에셋은 K 몫이라 웹은 받은 뒤 코드로 알파를 만드는 쪽(밝기→알파)이 후보.
