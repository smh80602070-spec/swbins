**잰 것(10-25 조사)**: 사용자 「2나락 3d,2d 는 맵 로딩이 되는 부분이 있어서 맵들을 분리해줘 화면이 넘어가면 넘어가는 형식으로 · 2d 는 마을로 가면 화면이 기존처럼 변경되는거 확인」. 3D 들판은 걸으며 스트리밍(src/dungeon3d/04.js:82-105 fwRk 바뀌면 buildField · 02.js fieldJobStep 프레임당 4ms) → 칸이 하나씩 솟는다. 2D 는 타일·소품 그림을 처음 그릴 때 받아 늦게 뜬다(mode2d 466·636·703·846, belt2d 92·172). 방 넘김 goRoom(src/dungeon/02-run.js:512-545)은 페이드 없이 즉시. 마을↔던전은 town.js:963 exit_dungeon → ui.js:966 enterGate. 가리개는 load-veil.js(3D 첫 진입만).
