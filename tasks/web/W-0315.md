**파일**: `saga-web/tools/playcheck/pw-cpu-profile.mjs`(결과 `results/pw-cpu-<판>.json` 이미 있음 — 상위 함수 표의 키가 `이름@파일:줄` 인지 확인, 줄 번호는 빼고 `이름@파일` 로 맞춘다 — 줄이 바뀌면 다른 함수로 보이지 않게) · 새 `saga-web/tools/playcheck/baseline/cpu-{saga-go,saga-dungeon,saga-forest,saga-story,saga-realm}.json`(첫 기준선 = 이번 측정, 상위 30 함수 `{name, self%}`) · `tools/qc.mjs` 새 `checkCpu()`(`--profile` 이면 재고, 아니면 마지막 결과; 결과가 7일 넘게 묵으면 WARN — `checkBudget()` 의 묵음 규칙 그대로) · `tasks/RECURRING.md` R-1 에 한 줄("주 1회 `node tools/qc.mjs --branch web --budget --profile` — 실제 GPU, 표 두 장 갱신")

**검증**: `node saga-web/tools/playcheck/pw-cpu-profile.mjs saga-go --base <서버>` 결과 키에 줄 번호 없음 · `node tools/qc.mjs --game saga-go --profile` "CPU 상위" PASS · ④ 의 임시 회귀에서 WARN(함수 이름·%) · `bash tools/precheck.sh` OK

**완료 조건**: 기준선 다섯 장 커밋 · QC 줄 다섯 판 PASS · 임시 회귀가 WARN 으로 잡힘(메모) · RECURRING 한 줄 · done/.
