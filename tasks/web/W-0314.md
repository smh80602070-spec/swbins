# W-0314 QC 빈틈 ②③ — 플레이·그래픽 촬영을 실제 GPU(d3d11)로 · FPS 를 판정 숫자로 · 자동 품질 갇힘 줄
종류: 체제(QC 도구) · 웹(다섯 판)      상태: **작성됨**(페이블 R-0 10-18 — `tasks/sheets/qc-gaps-20261018.md` #2·#3, 도구 선택 표 권장 ①)

**목표(한 줄)**: QC 의 플레이(`pw-play`)·그래픽 기준선(`pw-gfx`)·3D 장면(`pw-visual-close`) 촬영이 늘 swiftshader(3~5fps) 라 "플레이 FPS" 줄이 정보 없는 WARN 이었다 → 크롬 인자를 한 곳(`cdp.mjs` 의 공용 `chromeArgs({gpu})`)으로 모으고 기본을 **d3d11**(W-0302 가 검증, Radeon Pro 570X 에서 1만리 HIGH 41~58fps) 로 하되 실제로 GPU 로 그렸는지 `WEBGL_debug_renderer_info` 의 renderer 문자열로 확인해 결과 json `gpu` 칸에 남긴다. FPS 줄은 GPU 일 때만 판정(PC 1280×720 HIGH ≥30 PASS · 20~30 WARN · <20 FAIL), swiftshader 면 "상대값" 표시만. 새 줄 **"자동 품질"**: 폰 흉내(CPU 4배)에서 3마을·5천하의 `autoq` 단계가 3초 안에 HIGH 아래로 내려가거나 fps ≥30 이면 PASS, 아니면 FAIL(W-0302 가 잡은 갇힘의 재발 방지).

**파일**: `saga-web/tools/playcheck/cdp.mjs`(14 — 공용 `chromeArgs`·`gpuInfo(page)` export) · `pw-play.mjs`:250 · `pw-gfx.mjs`:135 · `pw-visual-close.mjs`(launch 줄) · `pw-phone-budget.mjs`:98(같은 공용으로 갈아 끼움, `--gpu` 는 기본값이 되고 `PW_GPU=0` 으로 끔) · `pw-look2d.mjs` 는 **그대로**(그림 비교 재현성 — swiftshader) · `tools/qc.mjs` `checkPlay()`(FPS 판정)·새 `checkAutoq()`(폰 예산 결과의 장면 `quality` 칸 읽기 — 없으면 pw-phone-budget 에 칸 추가) · `saga-web/shared/js/autoq.js`(현재 단계를 읽는 `aq.level` 또는 `DG.autoq.last` 노출 — 판마다 `make()` 한 곳만)

**단계**: ① cdp.mjs 공용 인자(+`PW_GPU=0` 되돌림)·renderer 문자열 ② 세 촬영 스크립트가 공용을 쓰고 결과 json 에 `gpu` ③ qc 플레이 줄 FPS 판정 ④ autoq 단계 노출 + 폰 예산 결과에 `quality` ⑤ qc "자동 품질" 줄 ⑥ 다섯 판 한 번 돌려 숫자 메모(GPU 없는 PC 에선 swiftshader 로 떨어져 "상대값" 이 찍히는지 `PW_GPU=0` 으로 흉내)

**검증**: `node saga-web/tools/playcheck/pw-play.mjs saga-go --base <서버>` 결과에 `gpu: "ANGLE (AMD…d3d11…)"` · `node tools/qc.mjs --branch web` 플레이 줄에 fps 숫자와 PASS/WARN/FAIL, "자동 품질" 줄 다섯 판 · `PW_GPU=0 node tools/qc.mjs --game saga-go` 플레이 줄에 "swiftshader(상대값)" · `node tools/test-web.mjs saga-forest`(autoq 진단 그대로 통과)

**완료 조건**: QC 플레이 줄이 GPU 일 때 숫자로 판정되고 swiftshader 면 그 사실을 적음 · "자동 품질" 줄이 다섯 판 PASS(안 되면 그 판 티켓 초안) · 그림 비교(2D 한 장)는 swiftshader 그대로 · done/.

**불변 규칙**: 판의 품질 손잡이·기본값은 안 바꾼다(재는 쪽만) · 헤드리스 크롬은 전용 `--user-data-dir`·그 PID 만 끈다 · 유료·클라우드 기기 안 씀 · 실폰 adb 는 이 티켓 밖(사용자 결정).
