# W-0063 사가국지 RTS 적 AI 세력 — 정해진 파도(디펜스)에서 "자라서 쳐들어오는 적"으로
종류: 새기능 · 웹(사가국지 RTS)      상태: **코드분 끝**(2026-10-05) — 사용자 눈 확인 대기("디펜스가 아니라 RTS 같은가")      등급 목표: D1→D2

**목표(한 줄)**: 적 기지가 스포너가 아니라 **자기 경제로 병력을 뽑고, 모이면 스스로 판단해 출정하고, 맞으면 물러나고, 기지를 지키는** 세력이 되게 한다 — 그래야 "막기만 하는 판"이 아니라 서로 키우고 치는 RTS 가 된다.

**지금 상태(확인함, `combat.js`·`state.js`)**
- 적 = `s.buildings[-1]`(고정 기지, 체력만 있음) + `s.raid { n, next }`. `next` 틱이 되면 `spawnWave` 가 `waveOf(n, diff)` 표대로 유닛을 기지 앞에 **그냥 만들어 낸다**(`RAID_GAP` 마다, 파도마다 +10% 체력). 적에게 **금·식량·생산 큐·건설·병력 판단이 없다.**
- `raiderAI`(적 유닛): 사거리 안 내 유닛을 치고, 아니면 **무조건 내 거점**(`s.buildings[1]`)으로 가며, 길이 막히면 성벽을 부순다. 건물·농지는 노리지 않고, 맞아도 후퇴하지 않으며, 기지를 지키지도 않는다.
- 내가 기지를 치면(`baseAI`) 기지는 체력만 깎인다 — **반격 병력이 안 나온다**(파도는 시간표라 내 공격과 무관).
- 그래서 판의 모양이 "도시를 키우고 파도를 버티다 때가 되면 기지를 치러 간다" = 디펜스. 스타크래프트의 **견제·교환·정찰에 따른 선택**이 없다.

**제안(확정 — 되묻지 않고 단계로 쪼개 진행)**
1. **적 경제**: 적도 일 소득(금·식량, 난이도별 배율)을 쌓고 **생산 큐**로 보병·궁병·기병을 뽑는다(내 병종 구성을 보고 상성 반대로 섞음). 병력 상한이 시간에 따라 오른다. 기존 `waveOf` 표는 "AI 가 뽑을 수 있는 최대"로 재활용.
2. **행동 상태**: ① 집결(기지 둘레 모으기) → ② 병력이 기준(난이도·경과일)에 차면 **출정** → ③ 목표는 거점 직행이 아니라 **내 바깥 건물(농지·주거·시장) 중 가장 가깝거나 약한 것** 먼저, 병력이 크면 거점 → ④ 병력이 절반 이하로 줄면 **후퇴**해 다시 집결.
3. **수비**: 내 유닛이 적 기지 시야(8칸)에 들어오면 적은 **집결 병력 + 새로 뽑은 병력**으로 막는다(기지 둘레 망루 1~2 개 상주, 난이도별). 기지 체력이 깎이는 동안 생산 속도 가산.
4. **정찰·안개와 맞물림**: 출정이 안개 속에서 다가오므로 망루·정찰 가치가 생긴다(W-0062). 출정 시작·병력 크기 단서(경고음·화면 가장자리 표시)는 별도 티켓.
5. **호환**: `s.raid` 는 유지하되 의미를 "출정 기준 타이머"로 바꾼다(저장 칸 이름·`n` 보존, 옛 저장은 `s.ai` 없이 열려도 기본값으로). 세이브 키 불변.

**파일**: 새 `js/rts/ai.js`(적 경제·생산·상태 기계 — `combat.js` 가 커지지 않게) · `combat.js`(`spawnWave` 호출을 `ai.tick` 으로, `raiderAI` 목표 선택) · `state.js`(`s.ai = { gold, food, q, mode, group }` 저장·복원) · `rts.html`·`_test.html`·`sw.js`·`js/manifest.json`(스크립트 한 줄) · 진단 · `view.js`(HUD "다음 습격 n일" 문구를 AI 상태에 맞게).

**단계**: 1. 적 경제·생산(출정 없이 병력이 자라는지) 2. 집결→출정→후퇴 상태 기계, 목표 선택 3. 수비(시야 안 내 유닛에 대응) 4. 난이도 3단 값 조정·옛 저장 호환 5. 진단 + 헤드리스로 60일 시뮬(적 병력 곡선·출정 횟수·거점 함락 여부)·촬영 6. 눈 확인 시트.

**검증**: `node tools/test-web.mjs saga-realm`(현재 318/318 에서 줄지 않을 것) 3 회 동일 · 헤드리스 시뮬(난이도별 몇 일째 첫 출정·평균 병력·내가 아무것도 안 했을 때 거점이 며칠에 무너지는지) · `precheck` OK.

**완료 조건**: 단계 1~6 · 사용자 눈("디펜스가 아니라 RTS 같은가"). 안 같으면 어느 부분인지 한 줄 받아 다음 티켓(자원 거점·확장·병종 기술 단계는 후보).

**불변 규칙**: 세이브 키·id 불변 · 에셋 안 만든다 · 이름 정책 · 경영·문답 규칙 안 건드림(`ui-rtk` 불변) · 도감 안 건드림.
