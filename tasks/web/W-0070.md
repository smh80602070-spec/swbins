# W-0070 다섯 판 `_demo.html` 이 `index.html` 스크립트 절반을 안 싣는다 — 데모·요청 로그에서 shared 3D·무늬·초상이 안 보임
종류: 버그 · 웹(다섯 판)      상태: **작성됨**(페이블 2026-10-05, 수신함 K-0073 검사기 결과)      등급 목표: D2

**목표(한 줄)**: `_demo.html#<장면>` 이 `index.html` 과 같은 스크립트 목록을 실어, 데모·`net-log.mjs`·반영 검사기가 진짜 게임과 같은 에셋을 요청하게 한다.

**재현(확인함, 10-05)**: `<script src=` 개수 — 사가고 index 116 / demo 65 / test 115 · 사가블로 75/46/71 · 숲 54/31/50 · 스토리 57/32/52 · 국지 48/30/55. 사가고 demo 에 빠진 것: `assets/portraits/manifest.js`·`js/assets3d.js`·`js/assets3d-ids.js`·`js/vroid-variant.js`·`js/bgm.js`·`js/biome.js` … (`comm -23` 으로 51개). 그래서 데모 장면에 통일 3D 몸·옷 무늬·초상이 안 뜨고 K-0073 반영 검사가 "shared 요청 거의 0" 으로 나왔다.

**파일**: `saga-web/<판>/_demo.html` 다섯 · (데모 전용 스크립트가 있으면 그대로 뒤에 둔다) · `tools/precheck.sh` 한 줄(아래 검사).

**단계**
1. 판마다 `index.html` 의 `<script src=…>` 줄을 **순서 그대로** `_demo.html` 의 같은 자리에 넣는다(데모 전용 `js/_demo*.js`·`_expansion/` 은 맨 뒤 유지). 서비스워커 등록 줄은 데모엔 넣지 않는다.
2. 다섯 판 끝나면 `_test.html` 도 같은 방식으로 빠진 것만 보충(국지는 test 가 더 많으니 건드리지 않는다).
3. `tools/precheck.sh` 에 WARN 한 줄: 판마다 `index.html` 에 있고 `_demo.html` 에 없는 `js/*.js` 스크립트 수(0 아니면 WARN).

**검증**: `for g in saga-go saga-dungeon saga-forest saga-story saga-realm; do comm -23 <(grep -o 'src="js/[^"]*"' saga-web/$g/index.html|sort) <(grep -o 'src="js/[^"]*"' saga-web/$g/_demo.html|sort); done` 출력 0줄 · `node tools/test-web.mjs saga-go saga-forest` 858/858·410/410 그대로 · `node saga-web/tools/playcheck/net-log.mjs saga-go` 끝 줄 `requested` 가 전(기존 `tools/asset-audit/out/netlog_saga-go.json`)보다 크다.

**완료 조건**: 다섯 판 검증 0줄 · 진단 수 그대로 · net-log `requested` 증가 · precheck WARN 줄 있음.

**본보기**: `saga-web/saga-realm/_test.html`(index 보다 많은 쪽 — 빠짐 없이 싣는 예).
