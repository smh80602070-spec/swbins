# W-0179 공용 패시브 그물(PoE식 광범위 스킬 트리) 엔진 — 로직·캔버스 화면·생성기
종류: 새기능 · 웹(다섯 판 공통 — 첫 연결은 W-0180 2나락)      상태: 작성됨(Opus R-0 10-11 — 사용자 "웹 이어해 다섯판 모두 스킬 트리가 패스오브 엑자일 처럼 광범위 하면 좋겠어")      등급 목표: D1

**목표(한 줄)**: 다섯 판이 같이 쓰는 "그물형 패시브 나무" 엔진 — 수백 마디가 한 장으로 이어진 그물, 시작점 여럿, 작은 마디·이름난 마디(notable)·규칙을 바꾸는 마디(keystone), **이미 찍은 마디에 이웃해야 찍힌다**. 판은 어휘 파일만 내고 엔진은 손대지 않는다.

**파일(확인함, 10-11)**
- 새 `saga-web/shared/js/passive-web.js` — `DG.passiveWeb`(로직·세이브만, DOM 없음). 본보기 틀: `saga-web/shared/js/vfx2d.js`(IIFE·`global.DG` 붙이기)
- 새 `saga-web/shared/js/passive-web-ui.js` — `DG.passiveWebUI`(캔버스 겹창)
- 새 `saga-web/tools/passive-web/gen.mjs` · `test.mjs` · `demo.vocab.mjs`(시험 어휘)
- `tools/sync-shared.mjs` FILES 표는 **이 티켓에서 안 건드린다** — 판을 잇는 티켓(W-0180~)이 3째 칸에 자기 판을 더한다(안 쓰는 판에 파일을 뿌리지 않게)

**설계(정해 둠)**
- 정의 `DG.passiveDef = { v, seed, starts:[{key,name,x,y,color}], nodes:[{id,k:'s'|'n'|'k'|'o',x,y,name,stats:{키:값},rule?,desc?}], edges:[[i,j]] }` — `k` = 작은·이름난·규칙·시작점. 판별 `js/data-passive.js` 로 **생성기가 쓴다**(손으로 안 고침).
- `PW.make(def, store, opt)` — `store` 는 세이브 안 평범한 객체 `{ start:null, taken:[] }`(키만 더하고 기존 세이브 키 안 바꿈), `opt.points()` 는 판이 주는 총점. 돌려주는 것: `canTake(id)`(이웃·점수·시작점) · `take(id)` · `canDrop(id)`(남은 것이 시작점과 끊기면 거절 — BFS) · `drop(id)` · `pathTo(id)`(찍은 곳에서 가장 짧은 길·필요 점수) · `sum(키)` · `has(rule)` · `left()` · `reset()` · `onChange(fn)`.
- 생성기 `node saga-web/tools/passive-web/gen.mjs <판> [--vocab <파일>]` → `saga-web/<판>/js/data-passive.js`. mulberry32(20260824) 고정. 모양: 시작점은 반지름 0.55 고리에 고르게(가운데 시작점 하나 허용), 바퀴 묶음(이름난 1 + 작은 4~6)을 고리 셋에 흩고, 가까운 이웃으로 이은 뒤 **고리를 만드는 가외 줄**(나무가 아니라 그물), keystone 은 바깥 고리에서 외길 2~3마디 끝. **id 안정**: 옛 `data-passive.js` 가 있으면 그 id·좌표를 그대로 두고 새 마디만 더한다 — 옛 id 가 사라지면 FAIL(세이브가 id 를 쥔다).
- 크기(사용자 "광범위" — 원작 문법: 다 못 찍고 1~2할만 골라 찍는다): 마디 ≥ 300 · 이름난 ≥ 40 · 규칙 ≥ 8 · 시작점 = 어휘가 준 수(4~7). 판이 끝까지 주는 총점은 마디의 12~18%(연결 티켓이 맞춘다).
- 화면 `PWUI.open(api, def, {title, fmt(stats)→글, colors})`: 끌어 옮기기·휠/집기 확대(0.4~3) · 찍은 마디 금색, 찍을 수 있는 이웃 밝게, 나머지 흐림 · 마디 누르면 카드(이름·효과·"찍기 (경로 n점)"/"되돌리기") · 위 검색칸(이름·효과 글자 → 둥근 표시) · 남은 점수 · **바뀔 때만 다시 그림**(상시 rAF 금지) · 390×844 에서 카드·검색칸 겹침 없음 · 닫기 Esc/✕.
