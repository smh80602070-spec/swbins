**확인한 사실(ls·md5sum)**: 세 js 는 다섯 판 md5 가 이미 같다(`62f1a98e`·`b2fcc9e6`·`115b349e`). `build/build-single.mjs` 는 다섯이 **다 다르다** — 차이는 결과 파일 이름·배너 글자(`사가고` 등)와 단독판에서 빼는 에셋 스크립트 줄(사가고 portraits / 사가블로 portraits+sprites2d 매니페스트 셋 / 사가스토리는 없음)뿐. `perf.js` 는 W-0007 로 사가고와 나머지 넷이 **다른 파일**이니 여기 넣지 않는다.

**파일**: `saga-web/shared/js/{net,anim-own,vroid-variant}.js`·`saga-web/shared/build/build-single.mjs`(새) · `tools/sync-shared.mjs`(새) · `tools/precheck.sh`(절 하나) · `tools/README.md`(한 줄)

**본보기**: `precheck.sh` 의 "도감 data.js 다섯 벌 md5" 절 · 합칠 build 는 `saga-go/build/build-single.mjs`.

**단계**
1. 세 js 를 `saga-go/js/` 에서 `shared/js/` 로 복사(글자 그대로).
2. `shared/build/build-single.mjs` = 사가고 것에서 ① `OUT_NAME`·배너·사용법 첫 줄을 `path.basename(SRC)` 로 고르는 표 `NAMES`(다섯 판 → 사가고·사가블로·사가의숲·사가스토리·사가국지, 현재 각 판 글자 그대로) ② 스크립트 제외 정규식 `/^assets\/(portraits|sprites2d)\//` ③ 매니페스트 줄 제거 `/<script src="assets\/(?:portraits|sprites2d)\/[^"]*manifest\.js"><\/script>\s*/g`.
3. `tools/sync-shared.mjs`: 표 `{shared 경로 → 판별 경로}`(js 셋 → `<판>/js/`, build → `<판>/build/`). 기본 = 복사, `--check` = 다섯×4 md5 비교 후 다르면 줄을 찍고 종료 1.
4. 복사 실행 → 다섯 판 `build-single.mjs` 가 정본으로 바뀜. `sw.js` VERSION 은 그대로(js 글자 변화 0).
5. `precheck.sh`: "== shared 정본" 절에서 `node tools/sync-shared.mjs --check || fail=1`. README 표에 한 줄.

**검증**
```
node tools/sync-shared.mjs --check          → 종료 0, 줄 "OK 4×5"
```
