## 도구 선택(사용자 10-18 "헤드리스가 좋아 플레이라이트가 좋아? 더 좋은 방법") — 오퍼스 확인

플레이라이트와 헤드리스는 둘 중 하나가 아니다 — 지금 QC 는 **플레이라이트(playwright-core 1.63)로 헤드리스 크롬을 조종**한다. 갈리는 건 크롬의 그래픽과 기기다.

| 길 | 이 PC 확인 | 장점 | 단점 |
| --- | --- | --- | --- |
| 헤드리스 + swiftshader(지금 QC) | 1만리 3~5fps | 어디서나 같게 돈다(그림 비교에 좋음) | FPS·한 번 도는 몸짓·자동 품질 판정이 무의미 |
| **헤드리스 + 실제 GPU**(`--use-angle=d3d11`) | 된다 — Radeon Pro 570X, 1만리 HIGH 41~58fps(W-0302) | 같은 스크립트 그대로, 창 안 뜸, FPS 가 진짜 | GPU 없는 PC·원격에선 swiftshader 로 떨어짐(그때 표시) |
| 창 띄운 크롬(headed) | 시험 안 함 | 진짜 합성기·포커스 | 사용자 화면에 창이 뜸 — 헤드리스 GPU 로 충분 |
| **실폰**(플레이라이트 `_android` + adb, USB 연결 폰의 크롬) | 플레이라이트엔 있음, 이 PC 에 adb 없음 | 진짜 폰 FPS·발열·터치 — 폰 흉내(CPU 4배)가 비관적인지 판정 | 폰을 USB 로 꽂아 둬야 함(adb 설치·개발자 옵션) |
| 실기기 클라우드(BrowserStack 등) | — | 기기 여럿 | 유료 — 유료 API 는 뺀다는 기존 방침 |
| 그림 비교(플레이라이트 toHaveScreenshot 픽셀 차) | — | 그래픽 회귀 자동 | swiftshader 로 찍어야 같게 나옴(GPU 는 드라이버마다 미세 차) |
