## 3. 이득 나누기
| | 플레이어 체감 | 개발 쪽 |
|---|---|---|
| 한 루프 층(+ 멈춤 한 곳) | **있다** — 창 뒤 세계 멈춤이 늘 같음, 보조 사슬도 숨김·dt 상한을 같이 따름(포획 바늘이 탭 돌아오면 튀는 것 같은 일), 프레임당 콜백 1 | 새 창·새 tick 을 붙일 때 목록 손질 없음, 순서가 한 표 |
| ES 모듈 | **거의 없다**(번들이 이미 한 파일·압축) | 의존 보이기·죽은 코드 찾기 — 다만 큰 순환 때문에 얻는 정리가 적고, 진단·번들·사본 체계를 다 바꿔야 한다 |
가설("ES 모듈은 개발 쪽, 한 루프는 체감도 일부")은 **맞다**. 체감 이득은 사가만리에 몰려 있다(보조 사슬 넷 + 어긋난 멈춤 목록) — 나머지 네 판은 본 루프 하나라 이득이 작다.
