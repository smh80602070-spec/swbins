# 두 저장소 개선·기획 재검토 — 2026-10-31

지침·큐·상태표·코드 표본과 읽기 전용 검사에 근거한 제안이다. 큐 순서는 변경하지 않았다.
전체 코드 감사·플레이·모션 영상 판정·GPU 추론·엔진 빌드는 수행하지 않았다.

## 판단과 근거

우선 과제는 기존 산출물의 게임 연결, 검증 기록 갱신, 생성 재개 신뢰성이다.
게임 다섯 장르·두 엔진과 생성/녹화 백엔드의 분업을 유지한다. 새 모델·서비스는 추가하지 않는다.

| 확인 | 근거·판단 |
|---|---|
| 오래된 QC | 10-29 공용 사본·크레딧 FAIL을 현재 실패로 인용하지 않기 |
| 사본 재검사 | sync-shared.mjs --check: 537개 일치. 게임 동작 검증은 아님 |
| 크레딧 | credits.py --check: 통과, 수량 차이 70묶음 경고. PC별 로컬 누락을 삭제로 간주하지 않기 |
| 콘솔 | 기본 py는 cp949 오류, py -X utf8로 통과 |
| 완료율 | STATE의 D2 이상 완료 집계는 시각·성능·출시 준비 완료율이 아님 |
| 생성 재개 | 기존 gen.py는 PNG 존재만으로 제외. 출처 누락·손상·입력 변경·실패 종료 전달을 K-0213으로 개선 |
| 적용 대기 | K-0202 게임 배선/복사, K-0198 엔진 배선 잔여. 생성 완료와 소비 완료 분리 |
| K-0212 | 입력 그림·실행 환경 선행 조건 미충족 기록. 입력 복사만으로 모두 해결된다고 판단하지 않기 |
| 녹화 웹 | localhost·로컬 IP·POST 확인 있음. CSRF 토큰/Origin 검사 후속 검토, 공격 재현 안 함 |

기존 QC의 던전 24.2fps·폰 적 생성 경고는 과거 특정 환경 측정이다. 현재 PC 성능으로 쓰지 않는다.
라이선스는 기존 티켓/장부를 참조했으며 이번에 법적 적합성을 재판정하지 않았다.

## 판별 검증 단위

새 기능 발행·큐 재정렬이 아니라 기존 기획의 완료 기준을 짧은 플레이 흐름으로 묶는 제안이다.

| 판 | 유지할 중심 | 다음 검증 흐름 |
|---|---|---|
| 1만리 | 탐험·동료·발견 | 목표 → 이동/조우 → 보상 → 저장·재접속 |
| 2나락 | 전투·빌드 | 대표 무기·네 모션 → 전투 → 전리품 → 재도전, 폰 성능 별도 |
| 3마을 | 생활·주민·변화 | 채집 → 제작/배치 → 주민 반응 → 다음 날 진행 보존 |
| 4종횡 | 횡스크롤·직업 조작 | 이동·발판 → 공격 연계 → 귀환, 입력·카메라 회귀 |
| 5천하 | 장 흐름·격자 SRPG | 장 진입 → 선택 → 전투 → 결과·저장·다음 장 |

연결: W-0487·W-0500(화면·모션), U-0249(대표 모션), U-0250→0251→0252(5천하).
Godot은 기존 기능 회귀와 자산 호환을 우선한다. 웹/Godot 구현은 담당 머신 분담을 유지한다.

## 세션별 실행 계획

계정 잔여 토큰은 조회할 수 없어 검토·수정·검증을 한 번에 마칠 범위로 나눴다.

1. 짧은 세션: 정본 충돌·깨진 경로·검사 명령 정리. 상태 생성 문서 중복 제작 금지.
2. 보통 세션: K-0213 생성 재개·실패 계약. 기존 gen.py·러너를 확장하고 임시 출력에 실패를 주입한다.
3. 긴 세션: K-0205·0188·0198 산출물로 대표 한 세트의 방향·무기 출처, 네 모션 GIF/영상, 게임 배율·공격 접촉·이동 속도를 연결 검증한다.
4. 후속: K-0202 UI 슬롯 가독성·상태 구분. K-0212는 선행 조건 확보 후 대표 한 종 비교, 그 뒤 확장 판단.

생성 장수보다 재사용률·검증까지 시간·배포 후 결함을 측정한다. 본보기·실패 사례·명령·증거 경로를 티켓에 명시한다.

## 후속 구현 기록

사용자 “할 수 있는 건 우선 진행해”에 따라 [K-0213](../tools/K-0213.md)을 진행했다.
새 출력의 입력/출력 해시, 기존 쌍 검사, 배타적 저장·잠금, 오류 코드·요약, 로컬 러너 실패 전달을 구현했다.
옛 정상 출력은 보존하며 해시 미검증으로 구분한다. 원격 러너 완료 판단은 이번 범위 밖이다.
GPU 없이 회귀 테스트 19개 통과. 자체툴 QC 결과와 완료 여부는 K-0213에 기록한다.
다른 세션 변경·원본 에셋·큐는 보존했다. 수신함 미체크 패턴 20줄은 별도 R-0 정리가 필요하다.
