# G-0070 저장 슬롯 셋 — 세이브 옮기기 화면에 "슬롯 1·2·3", 슬롯 1 = 지금 세이브 파일 그대로
종류: 새기능 · 고돗(전 판)      상태: **진행중**(2026-10-07)      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.6 "저장 슬롯 3개". 다섯 판 세이브를 판마다 셋으로 — **슬롯 1 은 지금 파일 이름 그대로**(옛 진행이 사라지지 않게), 2·3 은 `<이름>_slot2.json` 식. 고른 슬롯은 user://save_slots.cfg 에 남는다. 세이브 옮기기 화면(HUD "옮기기"·사가고 메뉴)에 슬롯 줄을 더하고, 바꾸면 지금을 저장한 뒤 그 슬롯을 불러와 장면을 다시 띄운다(불러오기와 같은 길). **빈 슬롯으로 바꾸면 지금 진행을 복사해 그 슬롯에서 이어 간다**(갈래 저장 — 판마다 "새 게임 초기화"가 따로 없어 빈 상태로 시작하지 않는다).

**파일**: 새 `saga_core/data/save_slots.gd`(정적: 지금 슬롯·경로·있는지·글) · 다섯 판 `*_save_state.gd` `save_path()`(슬롯 경로) + 네 판 save()/try_load() 의 `SAVE_PATH` 직접 쓰기 여덟 줄 → `save_path()` · `saga_core/ui/save_transfer_screen.gd`(슬롯 줄·switch_slot) · 새 `tools/scene_probes/save_slots.gd` + `tools/probe_save_slots.gd` · `features.json`.

**단계**
1. save_slots.gd: `current(game)`·`set_current(game, n)`·`path_for(game, base)`(1 → base, n → `<base 줄기>_slot<n>.json`)·`slot_label(game, base, n)`(비어 있음/저장 시각). cfg 경로는 점검이 바꿀 수 있게 정적 변수.
2. 다섯 판 save_path() 를 SaveSlots.path_for 로(사가고는 path_override 가 먼저). SAVE_PATH 직접 쓰기 여덟 줄 고침.
3. 화면: 제목 아래 "슬롯" 줄(단추 셋, 지금 것 ▶), `switch_slot(n)` — 같으면 그대로, 아니면 save_call → 슬롯 바꿈 → 새 경로에 파일이 없으면 옛 파일 복사 → 자동 저장 노드 치움 → (load_before_reload 면 try_load) → 장면 다시.
4. 점검 save_slots: ① 슬롯 1 경로 = 옛 상수(다섯 판) ② 2·3 경로 다름 ③ cfg 왕복 ④ 빈 슬롯 바꾸기 → 파일 복사됨(임시 경로) ⑤ 화면에 슬롯 단추 셋. 진짜 세이브·cfg 는 안 건드린다(임시 cfg·reload_after=false·임시 base 경로).
