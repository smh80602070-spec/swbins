# G-0185 2나락 3D 벨트 카메라 — 옆 3/4 고정 시점, 방이 왼→오로 이어지고 방 끝에서 카메라가 멈춘다(던파·드래곤즈 크라운 3D)
종류: 그래픽·조작 · 고돗(2나락)      상태: 작성됨(오퍼스 R-0 10-11 — 사용자 10-11 "웹 리뉴얼 요청한 스타일" "둘 다". 웹 W-0158 의 고돗 짝)      등급 목표: D2

**목표(한 줄)**: 지금의 디아블로식 위 55° 고정 카메라(플레이어 자식, 방이 화면 위쪽(−z)으로 이어짐)를 벨트 문법으로 — 카메라는 방 옆(+x)에서 3/4(pitch 35°) 로 보아 방이 **왼→오** 로 이어지고, 플레이어를 가로로만 따라가다 방 양 끝에서 멈추며, 통로를 지나 다음 방으로 넘어갈 때 0.4초 보간. 판정·방 배치는 안 바꾼다.

**파일(확인함, 10-11)**
- `saga_core/player/dungeon_camera_rig.gd`(69줄, `pitch_deg` 55·`spring_length` 12, 3마을 `ForestPlayer.tscn` 도 같은 스크립트를 62°/14 로 씀 — **마을은 건드리지 않는다**) — 새 export `belt := false`. 참이면 `set_as_top_level(true)`, yaw 90°(+x 에서 −x 를 봄 → 화면 오른쪽 = −z = 다음 방), pitch 35°, 위치 = (플레이어.x + 거리, 높이, clamp(플레이어.z, 방 앞끝+여백, 방 뒤끝−여백)). 흔들림(shake, `_rest_pos`)은 새 자리 둘레로 그대로.
- `games/saga_dungeon/player/DungeonPlayer.tscn` — CameraRig(100행)에 `belt = true`.
- 방 자료: `games/saga_dungeon/world/test_room.gd` — `ROOM_HALF` (6,0,6)(115행)·`ROOM_SPACING`(124행)·방 원점 `_room_origin_z`(127·164행, 방 i 는 z = −i×ROOM_SPACING). 카메라가 지금 방을 알도록 test_room 이 `camera_rig` 그룹 노드에 방 z 범위 배열을 한 번 넘김(세터 하나).
- 이동 방향: `saga_core/player/player.gd` `_world_direction()`(198행)이 이미 카메라 basis 기준이라 화면 위 = 화면 위로 감(손댈 것 없음 — 점검으로 확인만).
- 점검: `tools/probe_dungeon_world.gd`(있는 SceneTree 점검)에 보탬 또는 새 `tools/probe_dungeon_belt.gd`.
- 비교용 옛 시점: 환경변수 `SAGA_DG_CAM=diablo` 면 belt 끔(촬영 전후 비교·사용자 판정용).

**단계**
1. 리그에 belt 갈래(순수 함수 `belt_pos(player_pos, room_z0, room_z1) -> Vector3` 를 static 으로 — 점검 대상).
2. test_room → 리그로 방 범위 넘기기 · 통로 안에선 두 방 사이 보간(0.4초).
