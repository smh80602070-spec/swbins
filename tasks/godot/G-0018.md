# G-0018 사가고 전투·이동 손맛 다듬기 — 타격감·입력 반응·이동/카메라·적 행동 (코드만)
종류: 새기능 · 고돗      상태: **진행중**(단계 1~3b ✔·4~5 코드분 2026-10-03, 판정 대기)      등급 목표: D2

**목표(한 줄)**: 사용자가 고른 네 축("타격감, 입력 반응, 이동·점프·카메라, 적 행동·난이도")을 **측정 → 한 축씩 고침 → 사용자가 직접 해 보고 판정**으로 다듬는다. 값은 상수 한 곳(손잡이)에 모아 눈으로 보고 조정한다. 에셋 불필요(기존 sfx·`combat_fx.gd`).

**현황(코드에서 확인함)**
- **타격감**: 공용 `saga_core/combat_feel.gd hit()` 이 히트스톱(70ms·치명 120)·흔들림·플래시·숫자·타격음 5요소를 낸다. 사가고 적 피격도 `field_enemy.gd apply_damage` 에서 이미 부른다(처음 "안 쓴다"고 적은 것은 오류였음). 문제는 **강도가 공격 종류와 무관하게 똑같다**는 것.
- **입력 반응**: 점프만 코요테 0.1s·버퍼 0.12s. 공격은 후딜 중 누른 입력이 **버려졌다**(측정). 콤보 `COMBO_SEC [0.32, 0.32, 0.45]`·연결 창 0.9s.
- **이동·점프·카메라**: `JUMP_VELOCITY 7.5`·`DODGE_COST 15`·카메라 `player/camera_rig.gd`(`shake(강도, 초)`).
- **적 행동**: `field_enemy.gd` 는 "쫓음 → 예고(붉게 부풀고 \"!\") → 덤빔 → 쉼" 한 가지. 보스 `field_boss.gd` 별도.

**파일**: `games/saga_go/combat/`(`field_combat.gd`·`field_enemy.gd`·`field_boss.gd`·`combat_fx.gd`·`feel_tuning.gd` 손잡이) · `games/saga_go/player/`(`go_player.gd`·`camera_rig.gd`) · `saga_core/combat_feel.gd`(수정 시 사가블로·스토리 점검 영향) · `tools/probe_feel.gd`

**단계**
1. ✔ 측정 하네스 `tools/probe_feel.gd`(`SAGA_FEEL_PROBE=1`). 기준선: 선딜 0 · 첫 후딜 0.32s · 연타 간격 383~650ms(히트스톱) · 후딜 중 입력 버려짐 · 회피 5.0m(0.3s) · 점프 1.47m·767ms.
2. ✔ 타격감: `hit(…, tune={})` 선택 인자(기본 불변) + `feel_tuning.gd` 표(히트스톱 ms/흔들림 배율: 기본 70/1.0·마지막 타 100/1.5·강공격 130/2.0·낙하 150/2.5·스킬 90/1.5·폭발 160/2.5·반응 40/0.6·지속피해 0·소리 없음). 적 지속피해 틱의 히트스톱·소리 제거. `SAGA_FEEL_OLD=1` = 옛 방식. 판정 대기.
3. ✔ 입력 반응: 공격 후딜 중 누른 단추를 0.15초 안이면 기억했다가 끝나는 즉시 낸다(마지막 하나, 단추를 이미 뗐으면 충전 없이 일반 공격). 손잡이 `INPUT_BUFFER_SEC`, 옛 방식이면 0. 측정: 끝 0.12초 전 입력 나감·0.27초 전 버려짐. 회피·스킬·폭발 버퍼와 회피 취소는 판정 뒤. 판정 대기.
4. ◐(코드분 10-03 · 판정 대기) 이동: **환경변수 `SAGA_MOVE=0|1|2`**(기본 0 = 옛 방식, 결정은 사용자) — 1 산뜻(가속 60·정지 80·공중 25 m/s²)·2 묵직(30·40·14 + 높은 착지 0.12초 이동 ×0.5). 표 `feel_tuning.gd MOVE_PRESETS`·`go_player._steer`. 측정: 0.1초 뒤 속도 0=6.0·1=6.0·2=3.0, 회피 거리는 셋 다 5.0m 불변(회피 끝에 속도를 끊어 미끄러짐 방지). 점프 높이·체공 불변. 카메라 흔들림은 이미 최대 0.15m 라 상한을 두지 않음, "공격 시 당김"·락온 전환은 미착수(사용자가 이동 느낌을 고른 뒤). 옛 4.(원문): 이동·카메라: 가속 곡선·공중 제어·착지 경직을 기준선과 비교해 조정안 2~3개를 사용자가 환경변수/키로 바꿔 보게(결정은 사용자). 카메라: 공격 시 살짝 당김·락온 전환 완화·흔들림 상한.
5. ◐(코드분 10-03 · 판정 대기) 적 행동·난이도: 환경변수 `SAGA_ENEMY_DMG`(적이 주는 피해 배율, 보스 기술 포함, `field_combat.take_damage` 한 곳)·`SAGA_ENEMY_TELL`(일반 적 예고 시간 배율)·`SAGA_ENEMY_STRAFE=0`(끄기) — 기본 1.0/켬, `SAGA_FEEL_OLD=1` 이면 전부 옛 방식. 쉬는 동안(RECOVER) 플레이어 둘레를 옆으로 돌고 1.4m 안이면 한 걸음 물러난다(속도 0.45배, 방향은 공격마다 무작위; probe_feel 0.4초에 1.2m, 옛 방식 0.00). 예고 시간의 "등급별 표"는 종마다 `KINDS.tell` 이 이미 있어 그대로 두고 배율만 얹음. Godot 판엔 어드민이 없어 환경변수로 노출. 보스 기술 예고(`skill_t`)는 건드리지 않음. 옛 5.(원문): 적 행동·난이도: 예고 시간을 등급별 표로, 근접 적 후퇴/측면 이동 하나, 난이도 손잡이(피해·예고 배율, 기본 1.0)를 어드민에 노출. 보스 패턴 추가는 이 티켓 밖.

**검증**: `probe_feel` 기준선 대비 · `probe_all` 전투 관련 fails=0(`combat` 은 부하가 걸리면 가끔 흔들림 — 단독 재실행) · `godot_regress.sh` REGRESS OK · 사가블로·스토리 점검 불변 · **사용자 직접 플레이 판정(축마다 한 줄)**.

**완료 조건**: 단계 1~5 · 축별 사용자 판정 한 줄(좋다/수정/되돌려).

**불변 규칙**: 에셋 안 만든다 · 세이브 키·id·피해 공식 수치 불변(손맛만, 밸런스 변경 금지) · 사가블로·스토리 동작 불변 · 새 입력 키는 `project.godot`·`probe_help` 표와 겹침 확인.

**단계 3b ✔(사용자 "점프 모션 없고 때리는 모션이 부자연")**: 공격 클립 1.57s 를 후딜 0.32s 만 틀어 준비 동작만 반복되던 것 → `go_player.CLIP_WINDOW`(attack 0.30~0.95s·dodge 0.05~0.85s, 시간대별로 찍어 정함)로 동작 구간만 후딜에 맞춰 재생·끝나면 속도 1.0 복귀. 점프·낙하·착지 클립은 **에셋에 없음** → K-0059 로 자체툴 요청.

**메모**: 한 축씩 별도 커밋, 판정은 몰아서 받는다. 측정 함정: 단추를 눌렀으면 떼는 신호도 보낼 것(안 떼면 강공격 충전이 저절로 완료돼 측정이 틀어짐) · 콤보 번호는 0.9초 뒤 저절로 리셋돼 입력 여부 판단에 못 씀 · 다른 적은 측정 중 처리를 멈출 것.
