# G-0018 사가고 전투·이동 손맛 다듬기 — 타격감·입력 반응·이동/카메라·적 행동 (코드만)
종류: 새기능 · 고돗      상태: **작성됨**(R-0 2026-10-03) — 사용자 선택: 아쉬운 점 "타격감, 입력 반응, 이동·점프·카메라, 적 행동·난이도" 전부      등급 목표: D2

**목표(한 줄)**: 사가고의 전투·이동은 생명이라는 방침(사용자 "16만원 투자가 0원보다 못하다" 평가 이후)에 따라, 느낌이 약한 네 축을 **측정 → 한 축씩 고침 → 사용자가 직접 해 보고 판정**으로 다듬는다. 값은 전부 상수 한 곳(손잡이)에 모아 사용자가 눈으로 보고 조정할 수 있게 한다. 에셋 불필요(효과음·입자는 기존 `assets/generated/sfx`·`combat_fx.gd`).

**현황(코드에서 확인함 — 추측 아님)**
- **타격감**: 공용 `saga_core/combat_feel.gd` 의 `hit()` 한 호출이 히트스톱(70ms·치명 120ms)·카메라 흔들림·피격 플래시·숫자 팝·타격음 5요소를 낸다. 사가블로·사가스토리는 연결돼 있다. **사가고는 "내가 맞을 때"(`field_combat.gd take_damage`)와 UI 클릭에만 쓰고, 내가 적을 때리는 `_deal()` 에는 히트스톱·플래시·팝 호출이 없다**(카메라 흔들림은 일부 스킬에만 `rig.shake`). combat_feel 머리말도 "GO 화면 플래시는 다음 몫"으로 남겨 뒀다.
- **입력 반응**: 점프는 코요테 0.1s·버퍼 0.12s 가 있다. 공격·회피·스킬의 **입력 선행(버퍼) 코드는 못 찾음**(`grep buffer` 가 점프에서만 나옴). 기본 공격은 3타 `COMBO_SEC [0.32, 0.32, 0.45]`·연결 창 `COMBO_LINK_SEC 0.9` — 후딜 중 누른 입력이 버려지는지는 단계 1에서 측정.
- **이동·점프·카메라**: `JUMP_VELOCITY 7.5`(정점 약 1.4m·중력 20)·`MAX_FALL_SPEED 30`·`DODGE_COST 15` 스태미나. 카메라 `player/camera_rig.gd`(13KB, `shake(강도, 초)` 있음).
- **적 행동**: `field_enemy.gd` 는 "쫓음 → 공격 예고(몸이 붉게 부풀고 \"!\") → 한 번 덤빔 → 잠깐 쉼" 한 가지 패턴. 보스 `field_boss.gd` 는 별도(흔들림 0.18/0.3).

**파일**: `games/saga_go/combat/field_combat.gd`(`_deal`·`attack`·`charged_attack`·`skill`·`burst`)·`field_combat_ui.gd`·`field_enemy.gd`·`field_boss.gd`·`combat_fx.gd` · `games/saga_go/player/go_player.gd`·`camera_rig.gd` · `saga_core/combat_feel.gd`(수정 시 사가블로·스토리 점검 영향) · 새 `games/saga_go/combat/feel_tuning.gd`(손잡이 상수 한 곳)

**단계**
1. **측정 하네스** `tools/probe_feel.gd`: 헤드리스로 ① 공격 입력→피해가 들어간 프레임 지연 ② 후딜 중 입력의 운명(버려짐/선행) ③ 적 피격 시 히트스톱·플래시·팝 신호 유무 ④ 회피 시작 지연 ⑤ 점프 정점·체공 시간. 결과 표를 티켓 메모에 적는다(현재 수치 기준선).
2. **타격감**: `_deal()` 에 `CombatFeel.hit` 연결 — 공격 종류별 강도 표(기본/강공격/낙하/스킬/폭발: 히트스톱 ms·흔들림·팝 크기). 다중 타격 겹침 규칙은 combat_feel 기존 "더 긴 쪽" 유지. 보스는 약하게(연타에 멈춤 누적 금지).
3. **입력 반응**: 공격·회피·스킬·폭발 입력 선행 0.15s(마지막 입력 1개만 보존), 후딜 일부를 회피로 취소(스태미나 규칙 그대로), 콤보 입력 창 점검.
4. **이동·카메라**: 달리기/대시 가속 곡선·공중 제어·착지 경직을 기준선과 비교해 조정안 2~3개를 **사용자가 환경변수/키로 바꿔 보게** 한다(결정은 사용자). 카메라: 공격 시 살짝 당김·락온 시점 전환 완화·흔들림 상한.
5. **적 행동·난이도**: 예고 시간을 적 등급별 표로(약한 적 길게·강한 적 짧게), 근접 적 후퇴/측면 이동 한 가지, 난이도 손잡이(피해 배율·예고 배율)를 어드민에 노출. 보스 패턴 추가는 이 티켓 밖.

**검증**: `probe_feel` 기준선 대비 표 · `probe_all` 전투 관련(combat·kit·element·weapon·archery·sight·traversal) fails=0 · `godot_regress.sh` REGRESS OK(md5 변하면 의도한 것만) · 사가블로·스토리 점검(combat_feel 수정 시) 불변 · 창 모드 촬영/영상 + **사용자 직접 플레이 판정(축마다 한 줄)**.

**완료 조건**: 단계 1~5 · 축별 사용자 판정 한 줄(좋다/수정/되돌려).

**불변 규칙**: 에셋 안 만든다 · 세이브 키·id·피해 공식 수치 불변(손맛만, 밸런스 변경 금지 — 난이도 손잡이는 기본값 1.0) · 사가블로·스토리 동작 불변 · 새 입력 키는 `project.godot` physical_keycode·`probe_help` 표와 겹침 확인.

**메모**: 한 축씩 커밋하고 사용자 판정 전에 다음 축으로 넘어가지 않는다(느낌 값이 서로 영향). 단계 1 부터 시작.
