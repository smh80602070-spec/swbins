# G-0036 사가스토리 들판 쓰러짐 — 체력 0 이면 이번 사냥터 금 절반을 잃고 허도로(재미 표준 F, 웹 die() 이식)

**목표(한 줄)**: 큐가 비어 SAGA-BACKLOG P1 "Godot 다섯 — 표준 A·C·F 진단"에서. A(목표판 probe_goal_boards)·C(손맛 probe_combat_feel)는 다섯 판에 있고 F 도 사가고(probe_defeat)·사가블로(probe_dungeon_run 유품 20%)엔 있는데, **사가스토리 사냥터는 hp 가 0 에서 멈추고 아무 일도 없다**(story_player_base.gd "죽음은 범위 밖" — 사실상 무적, 비경만 "패퇴"). 웹 정본 `saga-web/saga-story/src/side/02.js` `die()` 를 옮긴다: 이번 사냥터에서 주운 금의 절반만 남기고(`goldKept = round(run.gold*0.5)`) 마을로. 경험치·장비·도감은 그대로(표준 F "죽어도 남는 것").

**파일**: `games/saga_story/data/story_combat.gd`(상수·규칙 함수) · `games/saga_story/data/story_save_state.gd`(apply_fall) · `games/saga_story/world/story_field.gd`(사냥터 넷의 관찰자 — 본보기 `world/story_labyrinth.gd` `_process`·`_on_defeated`) · 새 점검 `tools/probe_story_fall.gd`(본보기 `tools/probe_story_player.gd`) · `features.json`(gd.st.fall) · `docs/HOW_TO_PLAYTEST.md`(한 줄).

**단계**
1. 규칙: `StoryCombat.FALL_GOLD_KEEP = 0.5` · `fall_gold_lost(gained)` = gained − round(gained×0.5), 음수·0 은 0. `StorySaveState.apply_fall(start_gold)` 이 금을 줄이고 잃은 양을 돌려준다(add_gold 를 안 거쳐 사명 되먹임 없음).
2. 사냥터(story_field.gd): 들어온 때 금을 기억 → 매 프레임 플레이어 hp ≤ 0 이면 한 번만 쓰러짐: 금 차감·저장·토스트("💀 쓰러졌다 — 주운 금 n 을 잃고 허도로 · 경험치·장비는 그대로")·플레이어 멈춤 → 1.5초 뒤 허도(`HeodoField.tscn`, 도착 x 24 — 비경 귀환과 같은 자리). 조작 0회(표준 F ≤3). 비경 씬은 손대지 않는다(따로 패퇴).
3. 점검 probe_story_fall: ① 규칙(0·음수·7→3·100→50) ② apply_fall(금 1000·시작 800 → 100 잃음, 상점에서 써서 시작보다 적으면 0) ③ 사냥터 노드 + StoryPlayer: hp>0 이면 안 쓰러짐 · hp=0 → 한 번만 쓰러짐·금 절반·플레이어 멈춤·귀환 타이머 1.5초 · 점검은 진짜 세이브에 안 쓴다(save_on_fall=false).
