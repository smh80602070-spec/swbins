# G-0037 세이브 옮기기 화면을 네 판에도 — 공용 화면(saga_core)으로 빼고 사가블로·사가의숲·사가스토리·사가국지 HUD 에 "옮기기" 단추
종류: 새기능 · 고돗      상태: 진행중      등급 목표: D2

**목표(한 줄)**: G-0035 메모 "다른 네 판은 부모에 기능이 생겼지만 화면은 아직 사가고만". `games/saga_go/ui/save_transfer.gd` 의 화면을 `saga_core/ui/save_transfer_screen.gd` 로 옮겨 다섯 판이 같이 쓰고(사가고 동작·점검 그대로), 네 판 HUD 의 "저장" 옆에 "옮기기" 단추를 단다. 판 이름(`SAGA1|dungeon|…` 등)이 달라 판끼리 섞이지 않는다.

**파일**: 새 `saga_core/ui/save_transfer_screen.gd`(본보기 `games/saga_go/ui/save_transfer.gd`) · 새 `saga_core/ui/save_transfer_button.gd` · `games/saga_go/ui/save_transfer.gd`(공용을 상속하는 얇은 껍데기로) · `games/saga_dungeon/ui/DungeonHUD.tscn` · `games/saga_forest/ui/ForestHUD.tscn` · `games/saga_story/ui/StoryHUD.tscn` · `games/saga_realm/ui/RealmHUD.tscn` · 새 점검 `tools/probe_save_transfer4.gd`(본보기 `tools/probe_story_fall.gd`) · `features.json`(gd.go.save_transfer 설명·새 항목 넷) · `docs/HOW_TO_PLAYTEST.md`(한 줄).

**단계**
1. 공용 화면: 판 이름·세이브 autoload·저장 함수·자동 저장 그룹을 설정으로 받는다. 플레이어가 있으면 멈추고(`frozen` 이 있으면 그것, 없으면 물리 처리 끔), 없는 판(국지)도 열린다. 불러오기 성공이면 자동 저장(`go_autosave`·`autosave_timer`)을 치우고, `load_before_reload` 면 autoload 에 try_load 한 뒤 장면을 다시 띄운다. 사가고 껍데기는 그룹 `go_save_transfer`·공개 함수 이름 그대로.
2. 단추: `game_id` 를 받아 화면을 만들고 누르면 연다. 저장 함수 — 사가블로 `DungeonSaveState.save(플레이어)`, 나머지 `save()`.
3. HUD 넷: 숲·스토리·국지는 "저장" 왼쪽 같은 줄(offset −300~−170), 사가블로는 오른쪽 단추 줄 맨 위(hud_column_layout 이 다시 쌓음).
4. 점검 probe_save_transfer4: 네 판 단추가 화면을 만들고 열림·저장 함수는 점검이 막음(진짜 세이브 안 씀)·내보내기는 `SAGA1|<판>|` 이거나 빈 세이브 안내·다른 판 글 거절(파일 그대로)·불러오기 두 번 눌러야·닫으면 플레이어 풀림 · HUD 넷에 단추와 판 이름.
