# G-0047 사가의숲 집 안 — 벽지·장판에 무늬, 가구를 GLB 로(단색 면·네모 도형 → 있는 텍스처·모델 배선)
종류: 버그 · 고돗      상태: 진행중      등급 목표: D3

**목표(한 줄)**: G-0045 촬영 wallpaper △ "방 안이 무늬 없는 단색 면" · furniture △ "놓인 모습 못 봄"(그리고 `forest_house.gd` `_furniture_shape` 는 상자·원기둥 도형). 이미 있는 `assets/wardrobe/patterns/*.webp`(K-0019 무늬 64)를 벽지·장판 무늬로, `assets/world/*.glb` 가구(방석·소반·등잔·항아리·화로·궤·병풍)를 가구 모양으로 연결한다. 에셋은 안 만든다·안 고친다. 집 안은 곡률을 안 쓰니(머리말 "집 안만 일부러 안 휜다") 표준 재질 그대로.

**파일**: `games/saga_forest/world/forest_house.gd`(`_apply_finish_visuals`·`_spawn_furniture_visual`) · `tools/shot_scene.gd`(단계 `set`·`call` 인자, 컷 fs_room) · 시트 두 줄 · `features.json`.

**단계**
1. 벽지 일곱·장판 일곱 → 무늬 텍스처 표(어울리는 것: 흙벽=ochre_hemp, 한지벽=knit_cream, 솔빛=bamboo_green, 먹빛=pinstripe_charcoal, 단청=damask_crimson, 청화=floral_blue, 금박=brocade_gold / 마루=herringbone_camel, 돗자리=canvas_beige, 장판=corduroy_brown, 박석=tweed_grey, 구들장=leather_brown, 홍목마루=herringbone_camel(붉게), 옥돌=jade_peony_silk). 월드 삼면 투영(1m 남짓 반복). 키가 바뀔 때만 바꾼다(매 프레임 불림).
2. 가구 모양 → GLB(방석 cushion_01·상 low_table_01·등잔 candlestick_01·항아리 jar_01·화로 brazier_01·궤 trunk_01·병풍 screen_folding_01), 목표 높이로 배율. 족자·거문고는 맞는 모델이 없어 도형 그대로.
3. 촬영 fs_room — 집에 들어가 벽지 한지·장판 마루, 가구 여섯을 컷 동안만 놓아(세이브 안 건드림) 찍는다 → 읽히면 시트 ○(C).

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=forest_rules,forest_world,save_forest   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=fs_room,fs_house_in "$GODOT" --path saga-godot … --script res://tools/shot_scene.gd → SHOT_SCENE_DONE shots=2
bash tools/precheck.sh → OK
```
