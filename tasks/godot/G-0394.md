# G-0394 앉기 자세 고침 — 엉덩이가 땅에 닿게·팔은 무릎 위로(다섯 판 공용 life_pose)
종류: 버그(몸짓) · 고돗(다섯 판 — saga_core)      상태: 대기(10-25 오퍼스 R-0 — 사용자 「앉아 있는게 엉덩이가 땅에 안닿고 팔이 불편해보여」「웹,고돗,유니티가 다 동일할거야」)      등급 목표: D2

**까닭**: 앉기는 클립이 아니라 코드 뼈 자세(`saga_core/world/life_pose.gd` sit — 웹 W-0303 pose3d.js 이식, 유니티도 같은 수치). 그래서 자체툴 몫이 아니라 세 갈래 각자 코드 몫(웹·유니티는 수신함 줄).
- 엉덩이: `hp.origin.y = ankle_y + SIT_HIP_UP(0.08)`(376줄) — 엉덩이 뼈(골반 가운데)는 엉덩이 살보다 10cm 남짓 위라, 발목 높이 기준이면 살이 땅에서 뜬다.
- 팔: 윗팔을 앞으로 `SIT_ARM −42°` 만(401줄) — 옆으로 내리는 돌림이 없어 쉬는 자세(A자) 팔을 그대로 앞으로 든 꼴.

**목표(한 줄)**: 앉으면 엉덩이 살 아래가 땅(발바닥과 같은 높이) ±2cm, 두 손은 무릎 위(손목이 무릎 뼈 15cm 안), 어깨는 자연스럽게 내려감(윗팔이 몸통 옆에서 아래로 −50°쯤 + 앞으로).

**파일**: `saga_core/world/life_pose.gd`(SIT_HIP_UP → 땅 기준 `ground_y + SIT_PELVIS`(엉덩이 뼈 쉬는 높이와 다리 시작 높이 차로 몸마다 잼) · 팔 = 아래로(roll) + 앞으로(pitch) 두 돌림 + 아래팔 굽힘 · 손목 목표 무릎 IK 는 안 씀(두 돌림으로 충분하면)) · 새 `tools/probe_life_sit.gd`(VRoid 몸 하나·dex 몸 하나 앉혀 엉덩이 살 높이 = 엉덩이 뼈 y − 골반 두께, 손목–무릎 거리 잼) · 촬영 probe_shots 앉기 한 장(창 모드 옆·앞).

**단계**: ① 몸 둘에서 지금 숫자 재기(엉덩이 뜬 높이·손목–무릎 거리) ② 엉덩이 높이 고침 ③ 팔 두 돌림 ④ 전후 촬영 Read ○ ⑤ 웹·유니티 줄에 고친 수치 적기(같은 숫자로 맞추게).

**검증**: `"$GODOT" --headless --path saga-godot --script res://tools/probe_life_sit.gd` OK(엉덩이 ±2cm·손목–무릎 ≤15cm 두 몸 다) · `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=life_sit,life_pose,<몸짓 점검 이름 — 실행 때 확인>` 0 · 촬영 전후 ○.

**완료 조건**: 점검 0 · 촬영 ○ · 수신함 웹·유니티 줄에 수치 · done/.

**불변 규칙**: 다른 몸짓(wave·look·shift)·걷기 발 고정 그대로 · 에셋 안 만듦.
