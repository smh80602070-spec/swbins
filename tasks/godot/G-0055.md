# G-0055 사가고 대화 건너뛰기 — Esc·"건너뛰기 ▶▶" 단추로 고르는 줄 앞(없으면 끝)까지
종류: 새기능 · 고돗      상태: **진행중**(2026-10-07)      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.6 "컷신 스킵·대화 빨리 감기"를 사가고 이야기 대화(story_quest.gd — 두 번 눌러 넘김만 있음)에 단다. Esc 또는 대화창 오른쪽 아래 "건너뛰기 ▶▶" 를 누르면 고르는 줄 앞까지 한 번에(고르는 줄이 없으면 대화 끝 — 끝 콜백(보상·다음 단계)은 그대로 돈다). 고르는 줄은 건너뛰지 않는다.

**파일**: `games/saga_go/world/story_quest.gd`(skip_dialogue · 단추 · Esc · 안내 글) · 새 `tools/probe_dlgskip.gd`(GO 장면 점검) · `games/saga_go/world/test_village.gd`(SAGA_DLGSKIP_PROBE 한 줄) · `docs/HOW_TO_PLAYTEST.md`(대화 줄에 Esc 건너뛰기).

**단계**
1. `skip_dialogue()`: 고르는 중이면 아무것도 안 함, 아니면 글자 흘림 끝내고 다음 고르는 줄까지 넘김(없으면 닫기).
2. 단추·Esc·안내 글("F · Space · 누르기 ▶   Esc 건너뛰기 ▶▶").
3. 점검 dlgskip: ① 고르는 줄 없는 네 줄 → 한 번에 닫히고 끝 콜백 1번 ② 셋째 줄이 고르는 줄 → 거기서 멈추고 고르기 전엔 더 안 넘어감 ③ 고른 뒤 다시 건너뛰기 → 끝 ④ 단추 있음 ⑤ 대화 밖에서 부르면 아무 일 없음.
4. 대화창 촬영(단추 자리).

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=dlgskip,story,story2   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=go_dialogue "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 세이브 폴더 앞뒤 같음.
