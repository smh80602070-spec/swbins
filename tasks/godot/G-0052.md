# G-0052 공용 선택 창 글씨·판 키우기 — 가로 화면에서 9px 로 찍히던 것
종류: 버그 · 고돗      상태: **진행중**(2026-10-07)      등급 목표: D2

**목표(한 줄)**: G-0050 에서 본 흠 "선택 창 글씨가 작고 반투명 판이라 제목이 옅다"를 고친다 — 기준 화면이 가로 1920×1280 이라 1280×720 창에선 0.56배인데 `saga_core/ui/choice_prompt.gd` 는 기본 글씨 16·폭 380 그대로라 9px 로 찍힌다. 다섯 판이 같이 쓰는 창 하나만 고친다.

**파일**: `saga_core/ui/choice_prompt.gd`(글씨 제목 32·단추 28, 폭 760, 단추 높이 72·긴 글 줄바꿈, 진한 판(StyleBoxFlat)·제목 금빛+외곽선, 가운데서 양쪽으로 자람, 화면 85% 넘으면 단추 줄을 ScrollContainer 로) · 나머지 파일 변경 0.

**단계**
1. 고친다(구조는 layer → panel → vbox → 제목·단추 그대로, 넘칠 때만 vbox 안에 ScrollContainer — 점검들은 단추를 find_children 으로 찾아 구조에 안 기댄다).
2. 전후 촬영: rk_debate(사가국지 설전) · fs_wear_menu(사가의숲 침선방) · rk_duel(일기토). 긴 글 명령 창도 한 장(사가국지 명령 열 개 — 넘침·줄바꿈 확인).
3. 영향 점검 돌린다.

**검증**
```
SHOT_DIR=<절대 경로> SHOT_ONLY=rk_debate,rk_duel,fs_wear_menu,rk_orders "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=4
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=story,eggs,growth,realm_state,forest_rules,dungeon_run   → fails=0
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~3 · 가로 1280×720 에서 단추 글씨 ≥ 15px · 세이브 폴더 앞뒤 같음.
