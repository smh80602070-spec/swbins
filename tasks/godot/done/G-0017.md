**설계 제약(코드에서 확인함 — 깨면 안 되는 것)**
- 나무는 MultiMesh + **바람 셰이더**(`vegetation_builder._apply_wind_shader`, 정점만 흔들림)와 LOD(`GLBUtils.with_lods`). 새 메시에도 같은 처리를 하고, 새 소품은 삼각형이 적어 LOD 가 안 만들어질 수 있으니 분기.
- 옛 변형마다 `scale`(실제 미터로 맞춘 역산 상수, 예 CommonTree_1 0.7598)이 붙어 있다. 새 GLB 는 AABB 실측(`tools/_out` 임시 스크립트로 높이 재기)으로 **같은 높이로 보이는 배율**을 새로 구한다(G-0014 방식).
- 재질이 달라진다(옛: 텍스처 PBR, 새: 흰 칠+색 곱 툰). 계절·바이옴 곱색이 있으면(`RUBBLE_COLOR`·`STELE_COLOR` 식 override) 새 재질 위에서 눈으로 확인.
- 점검 `probe_*` 의 기대값(마을 나무 수·MultiMesh 수)이 고정이면 같이 맞춘다.

**단계**
1. `grep` 으로 호출부별 옛 경로→새 id 대응표(종류·바이옴별: 마을/포구/폐허/고원/숲). 짝이 없는 옛 종류(RockPath 디딤돌·작물 `crops_wheat`·갈대·허수아비)는 건드리지 않는다 — K-0057 대기.
2. 새 GLB 높이 실측 → 배율 표. `WorldAsset.MAP` 을 `generated/props` 외 경로(`vegetation`·`variants`·`rocks`)도 받게 넓힐지, 별도 표(`data/nature_assets.gd`)로 둘지 결정 후 한 곳에 둔다.
3. 사가고 마을 먼저(`vegetation_builder.gd`) → 숲(`forest_*`) → 국지 성(`realm_city.gd`) → 스토리 배경 → 마당(`homestead.gd`) → `kinds.json`.
4. `probe_world_asset` 에 새 행 점검(열림·높이×배율≈옛 높이)을 더하고, 창 모드 촬영(마을 광장·고원·포구)으로 눈 확인. 삼각형 수 전후 기록.

**검증**: `bash tools/probe_all.sh`(전체) 중 마을 관련 probe fails=0 · `godot_regress.sh` REGRESS OK(md5 변하면 의도한 것만) · `probe_world_asset` OK · `check_refs.sh` 깨짐 0 · 촬영(작업 중 습관적으로 찍지 않는다 — 사용자가 확인을 요청한 세션) · `precheck` OK.

**완료 조건**: 단계 1~4 · 마을 기준 옛 변형 참조 0(짝 없는 종류 제외) · 사용자 눈 확인.
