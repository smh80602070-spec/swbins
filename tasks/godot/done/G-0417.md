# G-0417 5천하 장수의 지휘관·용병 부대
종류: 게임성 · 고돗(5천하) · 상태: **진행 중** · 목표 등급: D2

**목표**: 사용자 요청 10-26, 5천하 게임성 장부 우선순위 1, 웹 W-0455. 조조전식 캠페인 격자전투를 지휘관과 휘하 용병이 함께 싸우는 전투로 넓힌다.

**정본**: `tasks/web/done/W-0455.md`, `saga-web/saga-realm/js/command.js`, `js/tactics.js`, `js/campaign.js`.

**범위**: 장수마다 용병 2명(9장부터 내 편은 3명), 창·기·궁 병종 선택과 적 병종 결정 배정; 지휘 범위 `2+floor(통솔/45)`, 범위 안 용병 명중 ±`round(6+통솔/10)`%p; 장수 격파 시 휘하 궤주; 장수와 맞닿은 아군 용병 턴 시작 보급 +25%; 인접 공격 뒤 생존한 대상의 50% 반격(궁·책사 등 2칸 공격에는 없음, 기존 고유 반격과 중복 금지); 턴 종료 때 미행동 내 용병 자동 행동. 진영·적 편성·전술판에 병종/휘하/범위 표시, 기존 세이브 기본값 추가.

**불변**: 비캠페인 천하 모드, 장수 고유 기술과 세 칸 장비·별도 보물, 인물 id·기존 세이브 데이터는 회귀시키지 않는다. W-0455 수치를 따른다.

**검증**: 지휘 범위 경계와 명중/방어 보정, 고정 seed 적 병종, 용병 수·장수 배속, 보급·궤주·인접 반격과 원거리/기존 고유 반격 예외, 자동 용병 행동을 규칙 probe로 점검한다. G-0416 캠페인·SRPG·세이브 probe 회귀와 Forward+ 전술판/편성 UI를 확인한다.

**완료 조건**: W-0455 핵심 동작과 편성·전술 UI 작동, 기존 모드 및 고유 기술/장비 probe 통과, `features.json`·장부 반영, `done/` 이동.
