# G-0414 2나락·4종횡 오늘 보상 직접 받기
종류: 새 기능(기존 목표판 확장) · 고돗(2나락·4종횡) · 상태: **완료** (2026-10-28) · 등급 D1

**목표**: 오늘 창에서 완료한 2나락 현상금·4종횡 일일 사명 보상을 직접 받는다. 현재 자동 지급 동작을 수령 대기로 바꾸되, 비일일 사명·주간 보상과 전투 보상은 그대로 둔다.

**범위**:
- 2나락: 살아 나온 판의 현상금 금 보상을 저장 가능한 미수령 금으로 기록한다. 오늘 창의 받기 단추가 이를 금고에 더하고 중복 수령을 막는다. 쓰러진 판은 보상 0.
- 4종횡: d_hunt·d_gather만 완료 시 보상을 수령 대기로 기록하고, 오늘 창의 받기 단추로 경험치·금·주문서를 한 번 지급한다. 일반·반복 사명은 현재 자동 지급을 유지한다.
- 기존 목표판의 `claim` 모델을 사용한다. 새 에셋·새 판 규칙은 추가하지 않는다.

**파일**: `games/saga_dungeon/data/dungeon_bounty.gd`, `dungeon_rank.gd`, `DungeonSaveState` 및 `ui/goals_adapter.gd`; `games/saga_story/data/story_save_state.gd`, `ui/goals_adapter.gd`; 관련 점검과 `features.json`.

**단계**: ① 저장 필드·중복 방지 경계 확인 ② 현상금/일일 사명 완료와 보상 수령 분리 ③ 어댑터 버튼·상태 표시 연결 ④ 새 세이브 필드 기본값으로 구 저장 호환 ⑤ 표적 점검과 고돗 QC.

**불변**: 난이도·목표 수치·보상량은 바꾸지 않는다. 쓰러짐 보상 없음. 세이브 버전 증가는 기존 규칙에 따라 필요 여부를 결정한다.

**검증**: `probe_dungeon_bounty`, `probe_save_dungeon`, `probe_story_rules`, `probe_save_story`, `probe_goals_panel`에서 완료/미완료/패배/저장 왕복/중복 수령 확인.

**완료 기록**: 2나락 현상금 금은 생환 후 세이브의 미수령 칸에 쌓이고 오늘 창에서 한 번만 받는다. 4종횡 일일 사명은 지급 시점의 경험치·금 배율을 저장해 오늘 창에서 받으며, 비일일 사명은 자동 지급을 유지한다. 기존 세이브 필드는 기본값으로 읽어 SAVE_VERSION은 그대로 뒀다.

**검증 결과**: `probe_dungeon_bounty`, `probe_save_dungeon`, `probe_story_rules`, `probe_save_story` 통과. `probe_goals_panel`은 기본 5판 연속 실행에서 GO→2나락 전환 중 Godot 세그폴트가 났지만, `SAGA_GOALS_GAME=dungeon`과 `SAGA_GOALS_GAME=story`로 각각 분리 실행해 둘 다 통과. `precheck.sh saga-godot`은 기존 문서 상한 초과(CLAUDE.md, G-0412, 큐 등)로 FAIL, Python 부재로 에셋 감사를 건너뜀. 전체 QC 미실행.
