# G-0121 saga_core 가 판 세이브를 직접 읽음(mount.gd) — 참조 게이트가 못 잡던 것
종류: 정리 · 고돗(공통)      상태: 닫음 D2(10-09)      등급 목표: D2

**목표(한 줄)**: G-0118 감사(소넷 427ba497a). 공용 `saga_core/player/mount.gd` `game_progress()` 가 `DungeonSaveState`·`ForestSaveState`·`StorySaveState`(판 autoload)를 직접 읽는다 — "saga_core 는 판을 안 부른다" 규칙 위반인데 `tools/check_refs.sh` 는 `res://games/` 글자만 봐서 통과. 진행도를 플레이어(판 쪽)가 넘기게 하고, 게이트에 판 autoload 이름 검사를 더한다.

**파일**: `saga-godot/saga_core/player/mount.gd`(game_progress → 플레이어의 `mount_progress()` 를 부름, 없으면 99) · `saga-godot/games/saga_dungeon/…`·`saga_forest/…`·`saga_story/…` 플레이어 스크립트(그 판 진행도 함수 — 식은 지금 것 그대로) · `saga-godot/tools/check_refs.sh`(saga_core 안에 project.godot 의 `res://games/` autoload 이름이 나오면 FAIL) · 이 티켓

**단계**
1. 세 판 플레이어에 `mount_progress() -> int`(나락 rooms_cleared×4·마을 quests_done×5·종횡 min(quests,13)×2 — 지금 식 그대로).
2. mount.gd 는 `_player.call("mount_progress")` 만(메서드 없으면 99).
3. check_refs: project.godot `[autoload]` 중 경로가 `res://games/` 인 이름을 모아 saga_core 에서 단어로 grep.

**검증**: `bash saga-godot/tools/check_refs.sh` 종료 0 · `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=mount,story_player,forest_world,dungeon_run` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: saga_core 에 판 autoload 이름 0 · 탈것 열림 문턱 그대로(점검).

**불변 규칙**: 탈것 문턱 값 안 바꿈 · 세이브 안 건드림.
