1. `vroid_body.gd`: `build()` 는 늘 dex(같은 이름 몸 → 없으면 해시). 옛 `BODIES`·`HAIR/CLOTH_TINTS`·`boost` 경로 삭제. `build_pool(pool, seed, rarity)` 추가, `BANDIT_POOL`(폐허·막북 힘 쓰는 인물).
2. 플레이어: 장면의 Visual 을 빈 Node3D 로, 뿌리 노드에 `body_id`(GO·스토리 `self`=dj_haean · 블로 dj_gapju · 숲 dj_yuri). 군주 초상은 국지 주인공 몸.
3. 적·도적·어부·이야기 인물·도둑·주민: 옛 GLB 상수와 대비책을 지우고 dex/풀로.
4. 숲 주민: dex 몸 + 표면별 곡률 재질(투명 면은 컷아웃). 옷 갈아입기 노드 끔.
5. 옛 경로 문자열 0 확인: `grep -rnE "characters_cf/|assets/characters/|characters_vroid/[A-Za-z_]+\.glb" games saga_core`(동작 라이브러리 `anim_cc0` 제외).
