# G-0193 2나락 은총 자리 + 사망 카드 세 줄(엘든링, 웹 W-0102 의 고돗 짝)

**목표(한 줄)**: 고돗 나락은 쓰러지면 "그 자리에서 곧바로" 되살아나 죽음이 아무 일도 아니었다 — 첫 방·샘 방이 **은총 자리**(금빛 기둥 표식)가 되어 쓰러지면 마지막으로 밝힌 은총에서 다시 서고(유품은 쓰러진 자리 — 되찾으러 걸어간다), 사망 카드는 세 줄(어디서·누구에게·무슨 피해) + 남는 것·잃은 것.

**파일(확인함, 10-11)**: 새 `saga-godot/games/saga_dungeon/world/grace_sites.gd` · `saga-godot/games/saga_dungeon/world/test_room.gd`(방 다 지은 뒤 붙임) · `saga-godot/games/saga_dungeon/player/player_health.gd`(take_damage(amount, source) · _die_and_respawn · 카드) · `saga-godot/games/saga_dungeon/world/dungeon_enemy.gd`(who_label · _attack_player 가 self 를 넘김) · 새 `saga-godot/tools/probe_dungeon_grace.gd` · `saga-godot/tools/shot_dungeon_belt.gd`·`shot_scene.gd`(dg_death_card) · 참고 `tasks/web/done/W-0102.md`.

**단계**: 1. 은총 자리 노드(표식 둘·0.25초마다 선 방·샘 방이면 은총 옮김·토스트) 2. 마지막 한 대 기록 3. 쓰러지면 은총으로 옮김 + 카드 세 줄 4. 점검·촬영.
