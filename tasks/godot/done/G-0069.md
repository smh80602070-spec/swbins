# G-0069 자동 저장 표시 키우기 — 13px(가로 창 7px)·조이스틱 자리 겹침
종류: 버그 · 고돗(전 판)      상태: **완료**(2026-10-07) — 자동 저장 표시 26·외곽선·조이스틱 오른쪽      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.6 "자동 저장 표시"는 이미 있다(사가고 world/autosave.gd · 네 판 saga_core/world/autosave_timer.gd, "💾 자동 저장" 1.4초). 그런데 글씨 13(가로 1280×720 에서 7px)이고 왼쪽 아래 12px 자리라 폰 조이스틱과 겹친다 — 선택 창(G-0052)과 같은 결로 키우고 조이스틱 오른쪽 위로 옮긴다. 저장 슬롯 3개는 다섯 판 세이브 경로를 건드리는 큰 일이라 범위 밖(수신함/BACKLOG 그대로).

**파일**: `games/saga_go/world/autosave.gd` · `saga_core/world/autosave_timer.gd`(글씨 26·외곽선·자리 왼쪽 아래 조이스틱 오른쪽) · `tools/shot_scene.gd`(컷 rk_autosave_flash).

**단계**
1. 두 파일 같은 값: 글씨 26, 외곽선 6, offset_left 210·offset_top -110·offset_bottom -70.
2. 촬영: 사가국지 장면에서 표시를 띄워(`_label.visible = true`) 한 장.
3. 점검 autosave(사가고)·save_* 그대로.

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=autosave,save_realm,save_forest,save_story,save_dungeon   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=rk_autosave_flash "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~3 · 세이브 폴더 앞뒤 같음.

**메모(10-07 실행)**: ✔ 1~3. 촬영하려고 autosave_timer.gd 에 flash()(표시만, 저장 안 함 — try_save 도 이걸 부름)를 뒀다. shot_scene 은 경로로 못 찾으면 이름으로 찾기를 near 밖 모든 단계로 넓힘(attach 가 만든 AutosaveTimer). 촬영: 왼쪽 아래 "💾 자동 저장" ≈15px(전 7px). 세이브 폴더 md5 앞뒤 같음.
