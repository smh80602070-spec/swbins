# G-0137 풀밭 흙 얼룩이 올리브 진흙빛 — 흙 얼룩엔 초록 정점색 대신 흙빛, 넓이도 줄임
종류: 그래픽 · 고돗(사가만리)      상태: 닫음 D2(10-09)      등급 목표: D2

**목표(한 줄)**(실행 중 바뀜 — 아래 메모): 광장을 위에서 본 진단 컷(d_plaza_top)에서 풀밭 곳곳의 큰 올리브빛 얼룩 = 흙 얼룩(dirt_w). 지형 셰이더가 `ALBEDO = 정점색 × (풀·흙 텍스처 섞음)` 이라 흙 텍스처에도 풀밭의 초록 정점색이 곱해져 갈색 흙이 아니라 올리브 진흙이 된다. 흙 얼룩 자리는 정점색을 흙빛 쪽으로 옮기고, 덮는 넓이를 줄인다.

**지금 상태(확인함, 10-09)**: `terrain_triplanar.gdshader` — `dirt_w = smoothstep(0.68, 0.73, n1 + (n2-0.5)*0.14) * 0.5`(G-0134), `ALBEDO = mix(COLOR.rgb, cliff_color, steep) * detail_albedo`. 진단 컷 noshadow 에서도 그대로(그림자 아님).

**파일**: `saga-godot/saga_core/shaders/terrain_triplanar.gdshader`(dirt_tint uniform·한 줄) · `saga-godot/tools/probe_shots.gd`(진단 컷 셋 d_plaza_*) · 이 티켓

**단계**
1. `uniform vec3 dirt_tint = (0.6, 0.5, 0.36)` · 흙 몫(dirt_w / wsum)만큼 정점색 → dirt_tint(0.85). 문턱 0.71~0.76 로 넓이 줄임.
2. 같은 시간대 전후 d_plaza_top·v_village_plaza·v_old_station·r_statue·g38_vault_granary(가을빛) — 올리브 → 갈색 흙자리, 풀밭이 덜 지저분.

**검증**: 전후 촬영 판정·픽셀 · 셰이더 오류 0 · `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=triplanar,toon_look` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: 흙 얼룩이 흙빛 ○ · 올리브 진흙 자리 사라짐 · 다른 표시(눈·모래·절벽) 그대로.

**불변 규칙**: 텍스처·정점색 표·절벽·눈·모래 식 안 바꿈.
