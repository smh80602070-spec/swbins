# G-0363 바람 날 풀 눕힘 — 날씨가 풀 흔들림 세기를
종류: 그래픽 · 고돗(1만리 풀, 공용 weather_visual)      상태: **끝**(10-25)(오퍼스 R-0·실행 — PROJECT_STATE 다음 작업 후보 "바람 날씨 그림")      등급 목표: D2

**목표(한 줄)**: 1만리 날씨 "바람"은 HUD 글과 안개 배수뿐, 풀은 맑은 날과 똑같이 살랑였다 → 풀 셰이더(grass_blades) wind_strength 를 날씨 배율만큼(바람 ×2.6 · 비 ×1.6 · 눈 ×1.3) 초당 0.5 씩 다가가게. 들어올 때 이미 바람이면 이미 분다.

**파일**(확인함 10-25): `saga_core/world/weather_visual.gd`(GRASS_SHADER·WIND_MUL·wind_target 순수·grass_mats·_wet_tick 안에서 배율 — 처음 값은 meta, 안 넣은 손잡이는 셰이더 기본 0.16) · `games/saga_go/world/go_weather_fall.gd`(들어올 때 wind_k) · `tools/probe_go_weather.gd`(배율 셋).

**검증**: `"$GODOT" --headless --path saga-godot --script res://tools/probe_go_weather.gd` OK · 실행 확인(임시 컷, 커밋 안 함): SAGA_WEATHER=wind → 풀 wind_strength 0.42 · clear → 0.16 · `bash saga-godot/tools/godot_regress.sh` OK.

**완료 조건**: 바람 날 풀 세기 2.6배 · 점검 · done/.

**불변 규칙**: 맑음·흐림·안개 풀 그대로 · 풀 셰이더 안 고침 · 에셋 안 만듦.

**메모(체크포인트)**: 10-25 R-0·실행(오퍼스, 같은 세션). ✔ 끝. 함정: ShaderMaterial 에 넣은 적 없는 손잡이는 get_shader_parameter 가 null — float(null) 은 오류. 풀은 첫 훑기 뒤에 지어져 5초(WET_SCAN) 뒤에 잡힌다. 사진 한 장으론 흔들림 크기가 안 보여 값으로 확인.
