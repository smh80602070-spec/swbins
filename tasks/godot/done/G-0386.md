# G-0386 2나락 일곱 방 나눔 — 지금 방 ±1 만 켜기(폰 발열, 웹 W-0414 짝)
종류: 체제(성능) · 고돗(2나락)      상태: **끝 — 안 함(효과 0)**(10-25 오퍼스 측정)(10-25 오퍼스 R-0 — 수신함 맵 나눔, G-0384 뒤)      등급 목표: D2

**까닭**: `games/saga_dungeon/world/test_room.gd` 가 `ROOM_COUNT`(7) 방을 한 씬에 나란히 다 짓는다(166줄 `for i in range(ROOM_COUNT)` → `_spawn_room_mesh`). 웹 2나락은 방마다 load-veil 로 넘긴다.

**목표(한 줄)**: 지금 방과 앞뒤 한 칸만 켜고(방 노드·그 방 적·횃불·부술 것), 출구(`_on_exit_entered` → `_finish_exit`)를 지나면 G-0384 막 아래서 다음 방을 켜고 두 칸 뒤 방은 끔.

**파일**: `world/test_room.gd`(방마다 루트 노드 `Room<i>` 아래로 묶기 · `_set_room_live(i, on)` · 손잡이 SAGA_ROOM_SPLIT=0 끔) · `world/torch_flicker.gd`·`world/dungeon_breakables.gd`(방 루트 아래로 붙는지만 확인) · 새 `tools/probe_dungeon_rooms_live.gd`(방 0 에서 켜진 방 ≤2 → 출구 지나 1·2 켜짐·0 꺼짐 안 함·3 지나면 0 꺼짐, 깬 방 기록 그대로).

**단계**: ① 방 루트 묶기(지금 노드 좌표 그대로, 부모만) ② 켜기/끄기 + 출구 막 ③ 저주 상자·현상금·속박(`_sigil_pack_done` 672줄)이 꺼진 방 노드를 찾다 깨지지 않는지 ④ probe_perf_scenes 2나락 전후 숫자.

**검증**: `"$GODOT" --headless --path saga-godot --script res://tools/probe_dungeon_rooms_live.gd` OK · `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=dungeon_rooms_live,dungeon_boss,dungeon_boons,dungeon_cursed,dungeon_bounty,dungeon_grace,dungeon_foes` 0 · perf 전후 숫자 티켓 메모에.

**완료 조건**: 점검 0 · 켜진 방 ≤3 · perf 전후 숫자 · done/.

**불변 규칙**: 세이브 안 바꿈(rooms_cleared 그대로) · 방 순서·크기·적 수치 안 바꿈 · 에셋 안 만듦.

**메모**: 마을(던전 밖)은 따로 씬이면 건드리지 않는다.
