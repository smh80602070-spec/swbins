# G-0054 설정 "화질/성능" 2단 — 성능이면 30fps·3D 해상도 0.75·SSAO/SSIL/SDFGI·MSAA 끔
종류: 새기능 · 고돗      상태: **완료**(2026-10-07) — 다섯 판 화질/성능 고르기, 점검 graphics, features gd.go.graphics D2      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.6 "설정에 성능/화질 2단 + 30fps 고정"(SAGA-DESIGN §6.1-B ②)을 다섯 판에 단다. 기본은 지금 그대로(화질), "성능"을 고르면 30fps·3D 해상도 0.75·MSAA 끔·환경의 SSAO/SSIL/SDFGI 끔(env_pc 와 env_mobile 의 차이 그대로). 고른 값은 세이브와 별개 파일 `user://graphics.cfg` 에 남아 다음 실행·다른 판에도 간다.

**파일**: 새 `saga_core/data/graphics_settings.gd`(모드 읽기·쓰기·적용 — 정적, 오토로드 안 늘림) · 새 `saga_core/ui/graphics_menu.gd`(공용 선택 창 두 줄 + 정적 open) · 새 `saga_core/ui/graphics_button.gd`(네 판 HUD 단추 "화질") · `saga_core/world/environment_profile.gd`(그룹 `env_profile`·시작 때 적용) · HUD 넷 `DungeonHUD.tscn`·`ForestHUD.tscn`·`StoryHUD.tscn`·`RealmHUD.tscn`(옮기기 왼쪽에 단추 노드) · 사가고 `games/saga_go/world/hud_menu.gd`(항목 "화질·성능") + `test_village.gd`(그룹 `go_graphics` 노드) · 새 `tools/probe_graphics.gd`.

**단계**
1. GraphicsSettings: `mode()`·`set_mode(m, tree)`·`apply(tree)` — Engine.max_fps · 루트 뷰포트 scaling_3d_scale·msaa_3d · 그룹 env_profile 의 Environment 에서 ssao/ssil/sdfgi(처음 값은 메타로 기억해 화질로 돌아오면 되살림). 설정 파일 경로는 점검이 바꿀 수 있게 정적 변수.
2. 메뉴·단추·사가고 메뉴 항목·environment_profile 배선.
3. 점검 graphics: 기본 화질 · 성능 → fps 30·배율 0.75·MSAA 끔·환경 ssao 끔 · 파일 왕복 · 화질 → 되살림. 임시 경로에 쓰고 지운다.
4. 촬영: 사가국지 HUD(단추 자리) · 화질 메뉴 창 · 사가고 들판 화질/성능 전후(설정 파일 안 쓰고 메모리에서만 바꾼다).

**검증**
```

```

**메모(10-07 실행)**: ✔ 단계 1~4. 사가블로 HUD 는 hud_column_layout.gd 가 오른쪽 아래 단추를 원래 y 순으로 다시 쌓아, 옮기기 왼쪽에 둔 첫 자리는 왼쪽 위로 비켜 떴다 → 같은 열(x -180~-40)·옮기기 바로 위(-6980)로 옮겨 줄에 끼움. 다른 셋은 옮기기 왼쪽(-440~-310). 점검 함정: SceneTree `_initialize` 에선 한 프레임 기다려야 그룹·모달이 잡히고, 사가고 hud_menu.gd 를 preload 하면 오토로드(PartyState) 없어 컴파일이 깨져 글로 확인. 촬영(창 -4000 화면 밖): forward_plus "화질"은 검은 바탕에 네모 조각 — 적용을 끈 원래 상태도 똑같아 이 촬영 방식 한계(09-23 창 실측은 SDFGI 정상, HISTORY 8176), "성능"은 정상으로 찍힘 → 실기에서 화질이 검게 나오면 성능으로 피할 수 있다. 같은 프로세스에서 사가고를 두 번 불러오면 `set_count` on Nil 스크립트 오류 한 줄(촬영 도구 쪽, 따로 찍으면 없음). 세이브 폴더 md5 앞뒤 같음·graphics.cfg 안 생김. 기본(화질)은 엔진 기본값 그대로(max_fps 0·배율 1·MSAA 프로젝트 값) — fps·배율·MSAA 를 만지는 다른 코드 없음(grep).
