# G-0085 사가나락 이야기 1막(3장) — 고돗 굴혈 일곱 방에 장 엔진·대사·목표
종류: 새기능 · 고돗(사가나락)      상태: 닫음 D2(10-08)      등급 목표: D2

**목표(한 줄)**: 사용자 10-08 "네 판 이야기 1부"(사가나락부터). 정본 `scenario/saga-dungeon.md` 1막 세 장(a1_moru·a1_blackflag·a1_tomb)을 고돗 사가나락에 넣는다. 대사는 웹 구현(`saga-web/saga-dungeon/js/data-scenario.js` SCENES moru1~tomb2)을 그대로 옮기고, 단계는 고돗 슬라이스(방 일곱 = 1~7층, 3·6층 보스, 5층 미니보스, 마을·들판 없음)에 맞춰 바꾼다.

**파일**: 새 `saga-godot/games/saga_dungeon/data/scenario.gd`(표·순수 규칙) · 새 `saga-godot/games/saga_dungeon/world/scenario_runner.gd`(엔진: 대화 창·처치/보스/구출 셈·구출 표지·보상·저장) · `saga-godot/games/saga_dungeon/data/dungeon_save_state.gd`(`scenario` 칸 — 순수 추가, 버전 그대로) · `saga-godot/games/saga_dungeon/world/test_room.gd`(_ready 에 엔진 붙임·목표판 "지금"에 장 목표) · 새 `saga-godot/tools/probe_scenario_dungeon.gd` · `saga-godot/features.json` · `saga-godot/docs/PROJECT_STATE.md`

**단계 바꿈(웹 → 고돗)**: talk = 그 단계가 되면 바로(선택 창이 떠 있거나 멈춤이면 기다림, 대화 동안 게임 멈춤) · kill n = 단계 시작 뒤 처치(난입 적 포함 — 옛 세이브가 방을 다 비웠어도 난입으로 채움), 웹 10 → 5 · chain(jungwon) → boss 1(다음 보스 = 3층 "흑기 대장") · floor n = n층 방 출구를 나감(rooms_cleared) · landmark(tomb) → floor 5(5층 미니보스 방 = 왕릉) 와 합침 · rescue 1 = 6층 방(왕릉 안쪽 현실)에 그 단계 동안 "⌛ 갇힌 열두시" 표지(코드 도형)를 세우고 닿으면 구출. 보상은 금만(고돗 사가나락엔 경험치·공적이 없다) — 웹 금 300·800·1500.

**단계**
1. `scenario.gd`: CAST·SCENES·CHAPTERS 셋(정본 id·제목·무대·시대 섞기 셋)·`fresh()`·`current()`·`check(st, ctx)`(ctx = 처치·보스·구출 합계, rooms_cleared)·`finish_talk()`·`objective()`.
2. `dungeon_save_state.gd`: `var scenario := {}` · save/load 키 "scenario".
3. `scenario_runner.gd` + test_room 배선(목표판).
4. 점검 `probe_scenario_dungeon.gd`(표 규칙·흐름 흉내·실명 없음) + 사가나락 기존 점검(dungeon_world·save_dungeon·dungeon_run) 그대로.
5. 촬영 한 장(첫 대화 창) → Claude 판정 · features · PROJECT_STATE · 큐 · 메모. 진행표(`scenario/README.md` §7, K 갈래 경로)·`tools/scenario-count.mjs`(고돗 비사가만리 0 고정)는 이 갈래가 안 고친다 → 수신함 한 줄.

**검증**: `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=scenario_dungeon,dungeon_world,save_dungeon,dungeon_run` `PROBE_ALL fails=0` · 촬영 한 장 · `bash tools/precheck.sh` OK.

**완료 조건**: 새 판으로 시작하면 출사표 고른 뒤 1장 첫 대화 → 처치 5 → 대화 → 1층 출구 → 대화(1장 끝, 금 300) → 2장 → 3층 보스 → 3장 → 5층 → 6층 열두시 구출 → 대화(1막 끝) 이 점검 흉내로 끝까지 돈다 · 껐다 켜도 이어진다(scenario 칸) · 옛 세이브(scenario 칸 없음)는 1장부터, 이미 지난 층 단계는 바로 넘어간다.

**불변 규칙**: 에셋 안 만듦(표지는 코드 도형) · 인물 전부 가상(이름 정책) · 다른 네 판 안 건드림 · 세이브 버전 안 올림(추가만).

**본보기**: `games/saga_go/world/story_quest.gd`(대화 창 결) · 웹 `saga-web/saga-dungeon/js/scenario.js`.
