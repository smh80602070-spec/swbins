# G-0060 사가고 장비 외형 — 낀 성유물이 몸에 갑옷 조각으로 보이게(eq 54)
종류: 새기능 · 고돗(사가고)      상태: **완료**(2026-10-07) — 성유물 → 갑옷 조각 배선, 점검 armor, features gd.go.armor_visual D2      등급 목표: D2

**목표(한 줄)**: 사가고 성유물(꽃·깃·해시계·술잔·관, PartyState.artifacts)은 숫자만 바뀌고 겉모습엔 안 보인다. 안 쓰는 장비 부위 GLB 54(`eq_<past|present|future>_<1~3>_<head|chest|shoulder|arm|leg|boot>`, 붙일 뼈가 license.json `bone` 에 적혀 있음)를 지금 몸(VRoid)에 붙여 **성유물을 낄수록·강화할수록 갑옷이 늘고 좋아지게** 한다(101-3 G "성장 가시화"). 꾸밈 소품 acc 33 은 G-0063 으로 뗐다.

**파일**: 새 `games/saga_go/player/armor_visual.gd`(정적 attach/clear — weapon_visual.gd 와 같은 결) · `games/saga_go/player/go_player.gd`(`_refresh_weapon` 곁에 `_refresh_armor`, 몸 교체·`artifact_changed` 때) · 새 `tools/probe_armor.gd`(GO 장면 점검) · `games/saga_go/world/test_village.gd`(SAGA_ARMOR_PROBE 한 줄) · `tools/shot_scene.gd`(컷 go_armor_none·go_armor_full) · `features.json`.

**규칙(정함)**
- 부위: 꽃 → chest · 깃 → shoulder · 해시계 → arm · 술잔 → leg + boot · 관 → head. 다섯 다 끼면 여섯 부위 전부.
- 등급(그 성유물 하나 기준): ★4 는 Lv 0~7 → 1, 8~16 → 2 · ★5 는 Lv 0~7 → 1, 8~15 → 2, 16~20 → 3.
- 시대(인물 `era`, characters.gd): 삼국지·한국사·일본사 → past · 세계사 → present · 균열(가상)·폐허(가상) → future · 나머지 (가상) → past.
- `mirror: true` 인 부위(shoulder·arm·leg·boot — 뼈 J_Bip_L_*)는 오른쪽(J_Bip_R_*)에 X 뒤집은 사본을 하나 더.
- GLB 원점 = 붙일 뼈의 머리, 인물 앞 = Blender -Y(license.json `origin`). 뼈 축 → 몸 축 되돌리는 앵커는 weapon_visual.gd 의 손 앵커와 같은 방식.

**단계**
1. armor_visual.gd: `pieces_for(artifacts, era)` → [{slot, path, bone, mirror}] (순수 함수 — 점검이 화면 없이 부른다) · `attach(body, pieces)`(앞 것 지우고 BoneAttachment3D 마다 GLB, 툰 셰이더는 몸과 같은 CelShaderApply) · `clear(body)`.
2. go_player.gd: 몸 교체·`PartyState.artifact_changed` 때 `_refresh_armor()`. dex 몸이 없으면 아무것도 안 함(weapon 과 같은 조건).
3. 점검 armor: ① 성유물 0 → 조각 0 ② 꽃 하나 ★4 Lv0 → chest 등급 1 하나 ③ 다섯 ★5 Lv20 → 조각 10(head·chest 하나씩 + shoulder·arm·leg·boot 좌우 둘씩)·전부 등급 3 ④ 시대 표 세 갈래 ⑤ 빼면 그 조각 사라짐 ⑥ 몸에 BoneAttachment3D 가 그 뼈 이름으로 붙음. 진짜 세이브는 안 건드린다(점검 끝에 성유물 소유자 되돌림).
4. 촬영: 같은 인물 성유물 없음 / ★5 Lv20 다섯 — 팔 3.5m 근접(spring_length set 단계, G-0051 방식) 두 장. 조각이 몸을 뚫거나 떠 있으면 앵커 오프셋만 고친다(GLB 는 안 고침 — 크기가 안 맞으면 K 수신함 한 줄).

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=armor,artifact,weapon,party,dex_bodies   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=go_armor_none "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1 (go_armor_full 도 따로 한 번 — 사가고 장면은 한 프로세스에 하나씩)
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 세이브 폴더 앞뒤 같음 · 에셋 변경 0.
