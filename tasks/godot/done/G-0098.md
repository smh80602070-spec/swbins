**굴 조각 실측(10-08)**: 복도·계단 3.1×3.3×4m · 모퉁이·방 4.6×3.3×4.5m · 아치 4×3.3×0.8m · floor_01 16×5.2×16m(세 결 크기 같음) — 연결점은 `cave_interior.gd` PIECES. 배율 1.5.

**짓는 법(조각 15 = 결 셋 × 넷 + gate 둘 + floor 하나)**:
- 자리: 세상 밖 `Vector3(1400, 40, 0)`(비경 원판은 x −1400 · z 0~3000 이라 겹치지 않음). 원판처럼 떨어진 곳에 한 번 짓고 숨겨 둔다(들어갈 때 보임).
- 흙 구간: dirt corridor → corner → room(적 둘) → stairs. 석회 구간 시작에 `gate_01_limestone` 아치: limestone corridor → corner → room(적 둘) → stairs. 용암 구간 시작에 `gate_01_lava` 아치: lava corridor → corner → room(적 셋) → stairs → 끝 큰 방 `floor_01`(보물 + 들어온 쪽 나가는 빛).
- 충돌: 조각 메시마다 `create_trimesh_shape()`(정적 몸) — 벽·바닥·계단이 막는다. 떨어짐 방지로 굴 밑 4m 에 큰 상자 바닥 하나.
- 빛: 굴은 어둡게(들어간 동안 해·환경광을 낮춤, 나오면 되돌림 — 비경이 하는 대로 따라 하되 없으면 굴 안 WorldEnvironment 하나), 방마다 횃불 색 OmniLight, 용암 구간은 주황 빛 + 바닥 빛. 그림자 켠 빛은 셋 이하(성능).
- 적: 들판 적 kind 를 그대로(흙 = rock_bear·wolf, 석회 = ice_fox·water_turtle, 용암 = fire_imp·ember 꼴) — 생성은 비경 `_spawn_wave` 와 같은 길(`field_enemy`), 수치·KINDS 안 바꿈.
- 보물: 끝 방 상자 F → 기존 가방·금 보상 함수로 작은 보상. **저장하지 않는다**(한 번 실행에 한 번, 세이브 버전 안 올림).
- 들어감: 입구 3m 안에서 F(비경 `GATE_M` 과 같은 거리, 입구 표지 "⛰ 굴 안으로 [F]"). 나감: 들어온 자리(흙 복도 첫머리)의 빛 원판에서 F, 또는 끝 방의 나가는 빛에서 F → 입구 앞 3.5m 로. 비경 안·대화·선택 창(ui_modal) 중엔 안 열림.
