# G-0136 길(=) 칸 48m 통째가 흐린 진흙 사각형 — 칸은 들판빛, 가운데를 잇는 좁은 흙길 띠
종류: 그래픽 · 고돗(사가만리)      상태: 닫음 D2(10-09)      등급 목표: D2

**목표(한 줄)**: 기준 컷 v_village_plaza 의 큰 올리브-갈색 자리 = 길(=) 칸. 정점색만 흙빛(0.62,0.5,0.32)이고 풀 텍스처를 그대로 써서 48m 칸 하나가 통째로 흐린 진흙 사각형이 된다(정점 간격 6m 라 정점색으로는 좁은 길을 못 그림). 길 칸 바닥은 들판(.) 빛으로 두고, 칸 가운데에서 이어진 이웃 쪽으로 폭 4~5m 흙길 띠(가장자리 흐림)를 지형 위에 얹는다.

**지금 상태(확인함, 10-09)**: terrain_builder `_build` 의 칸 정점색 = `color_of(region, ch)`, 모서리 = 이웃 평균. 길 칸엔 풀잎이 안 난다(grass_field GRASS_COLOR_TILES). 서리봉은 REGION_SURFACES 로 "=" 가 밟힌 눈(0.5) — 이미 길로 읽혀 제외. `color_of` 는 지도(world_map.gd)도 쓰니 손대지 않는다.

**파일**: 새 `saga-godot/games/saga_go/world/road_builder.gd`(띠 메시 한 벌) · 새 `saga-godot/saga_core/shaders/road_dirt.gdshader` · `terrain_builder.gd`(_ready 한 줄·길 칸 바닥색 들판빛) · 이 티켓

**단계**
1. road_builder: 지역 rows 의 "=" 칸마다 가운데 → 이어진 이웃(=·B·건물 글자·지도 밖 고개) 쪽 변 가운데까지 1.5m 간격으로 지형 높이(height_at)+6cm 에 띠, 폭 4.5m + 양쪽 1.2m 흐림(정점 알파), 월드 좌표 노이즈로 살짝 굽이침(칸 경계에서 이어짐), 가운데 둥근 마당. 메시·재질 하나(그리기 +1).
2. road_dirt 셰이더: 길 정점색(선형) × 흙 텍스처 결·잔 얼룩, 알파 = 정점 알파 + 노이즈(가장자리 들쭉날쭉).
3. terrain_builder: "=" 칸(서리봉처럼 표시가 있는 지역 빼고)의 정점색·모서리 색에 "." 색을 씀.
4. 같은 시간대 전후 v_village_plaza·v_old_station·s_belfry·g38_amber_street·f_pass_view(제외 확인) — 진흙 사각형 → 들판 속 흙길.

**검증**: 전후 촬영 판정 · 창 모드 셰이더 오류 0 · `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=triplanar,toon_look,village,perf` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: 길이 좁은 흙길로 읽힘 ○ · 그리기 +1 이내 · 충돌·높이 안 바뀜.

**불변 규칙**: 높이·충돌·지도 색(color_of)·서리봉 눈길 안 바꿈 · 에셋 안 만듦(기존 dirt_512 씀).
