# G-0138 PC 화면 왼쪽 아래에 터치 조이스틱이 늘 떠 있음 — 터치 화면이 없으면 숨김
종류: 그래픽(UI) · 고돗(공용 saga_core — 사가만리·사가나락·사가마을 HUD)      상태: 닫음 D2(10-09)      등급 목표: D2

**목표(한 줄)**: 지금까지 찍은 모든 컷 왼쪽 아래에 반투명 회색 네모(가상 조이스틱)가 떠 있다. 다른 터치 전용 UI(field_combat_ui 터치 단추·go_player 조준·fishing·elemental_sight)는 이미 `DisplayServer.is_touchscreen_available()` 일 때만 나오는데 조이스틱만 늘 보인다. 같은 기준으로 터치 화면이 없으면 숨긴다.

**지금 상태(확인함, 10-09)**: `saga_core/ui/virtual_joystick.gd`(MobileHUD·DungeonHUD·ForestHUD 의 Joystick 노드, 그룹 virtual_joystick) — 숨김 조건 없음. player.gd 는 그룹에서 찾아 value 를 읽기만(숨겨도 0). 오른쪽 위 "renderer:" 글자는 PLAN 46장대로 디버그 빌드 전용이라 그대로.

**파일**: `saga-godot/saga_core/ui/virtual_joystick.gd`(_ready 몇 줄) · 이 티켓

**단계**
1. `_ready` — 헤드리스가 아니고 터치 화면이 없으면 `visible = false`(입력도 안 받음). 터치 노트북·폰은 그대로.
2. 전후 v_village_plaza — 왼쪽 아래 네모 사라짐.

**검증**: 전후 촬영 · `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=village,layout_walk,mount_dungeon,mount_forest` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: PC 촬영에 조이스틱 없음 ○ · 점검 fails=0.

**불변 규칙**: 조이스틱 동작·크기·자리·다른 HUD 안 바꿈.
