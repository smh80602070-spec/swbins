# G-0352 Forward+ 화면이 검은 네모로 깨짐 — MSAA 2배 끔
종류: 버그(그래픽) · 고돗(다섯 판 공용 — project.godot)      상태: **끝**(10-25)(오퍼스 R-0·실행 — 사용자 "4종횡 왜 뿌해" 조사 중 Forward+ A/B 촬영에서 발견)      등급 목표: D2

**목표(한 줄)**: 촬영은 늘 `--rendering-method mobile` 이라 몰랐는데, 기본 렌더러 Forward+ 로 찍으니 1만리 들판은 화면 대부분, 4종횡 사냥터는 아래 절반이 검은 네모(타일)로 깨졌다(900프레임 기다려도 그대로). 효과를 하나씩 끈 A/B — TAA·SDFGI·SSIL·안개·글로·색 보정을 꺼도 그대로, **MSAA 만 끄면 멀쩡** → 화질 모드 MSAA 를 0 으로(가장자리는 이미 켜진 TAA).

**파일**(확인함 10-25): `project.godot`(anti_aliasing/quality/msaa_3d 2 → 0, 모바일 줄 그대로) · `saga_core/data/graphics_settings.gd`(머리말 — 까닭 · 성능 모드는 원래 MSAA 끔).

**검증**: Forward+ 촬영 `SAGA_HOUR=12 SAGA_WEATHER=clear SHOT_ONLY=lg_go_wx,mn_dungeon,mn_story,mn_realm …shot_scene.gd`(--rendering-method 없이) 네 판 ○ · `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=graphics,gfx_baseline` 0 · `bash saga-godot/tools/godot_regress.sh` OK.

**완료 조건**: Forward+ 네 판 검은 네모 없음 · 점검·regress · done/.

**불변 규칙**: TAA·SSAO·SSIL·SDFGI·모바일 렌더러 값 안 바꿈 · 에셋 안 만듦.

**메모(체크포인트)**: 10-25 R-0·실행(오퍼스, 같은 세션).
- ✔ 끝. 이 PC GPU = Radeon Pro 570X(Vulkan). 다른 GPU 에서 나는지는 모름 — MSAA 2배는 TAA 와 겹치는 일이라 끄는 값이 작다.
- 함정: 촬영·점검 기본이 모바일 렌더러라 Forward+ 깨짐을 못 봤다 — 그래픽을 고친 뒤엔 Forward+(플래그 없이)로도 한 장.
