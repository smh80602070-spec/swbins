# G-0068 오류 기록 보기 — 화질 설정 창 셋째 줄, 최근 로그의 오류만 모아 복사
종류: 새기능 · 고돗(전 판)      상태: **완료**(2026-10-07) — 화질 창 셋째 줄 "오류 기록 보기", 점검 error_log      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.6 "크래시 로그 보기(Unity SagaCrashLog 있음 → Godot 도)". 폰·PC 에서 "멈췄다·이상하다"가 나오면 사용자가 오류 줄을 복사해 줄 수 있게 — 최근 Godot 로그 파일(user://logs, 지금 실행 + 직전 실행)에서 ERROR·SCRIPT ERROR·WARNING 줄과 그 바로 뒤 "at:" 줄만 모아 보여 주고 복사한다. 앱이 통째로 죽는 네이티브 충돌은 로그가 끊겨 일부만 남는다(스토어 콘솔 몫 — Unity 와 같은 한계).

**파일**: 새 `saga_core/data/error_log.gd`(정적: 로그 파일 고르기·오류 줄 모으기·같은 줄 횟수) · 새 `saga_core/ui/error_log_screen.gd`(창: 글 칸·복사·닫기) · `saga_core/ui/graphics_menu.gd`(셋째 줄 "오류 기록 보기") · `project.godot`(`debug/file_logging/enable_file_logging.mobile=true` — 폰도 로그를 남김) · 새 `tools/scene_probes/error_log.gd` + `tools/probe_error_log.gd` · `features.json`.

**단계**
1. error_log.gd: `log_files()`(최근 수정 순 둘) · `collect(text, max)`(오류 줄 + 다음 "at:" 줄, 같은 줄은 "×n", 마지막 max 개) · `report()`(머리줄: 판·버전·OS·시각 + 줄들).
2. 창·메뉴 줄.
3. 점검: ① 가짜 로그 글에서 ERROR·SCRIPT ERROR·WARNING 과 at: 만 뽑힘 ② 같은 줄 셋 → ×3 ③ max 넘으면 뒤쪽만 ④ 메뉴 셋째 줄 → 창 열림·복사 단추.
4. project.godot 한 줄 — `git diff -- project.godot` 로 그 줄만인지 확인.

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=error_log,graphics   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=rk_errlog "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 세이브 폴더 앞뒤 같음.

**메모(10-07 실행)**: ✔ 단계 1~4. 촬영 rk_errlog: 이번 실행의 실제 WARNING 넷(모바일 렌더러에서 PC 환경의 SSAO·SSIL·SDFGI·TAA — 촬영을 mobile 로 띄운 탓)이 at: 위치와 함께 보임, 복사·닫기. 머리줄 버전 칸은 config/version 이 비어 있으면 뺌. project.godot 은 [debug] enable_file_logging.mobile=true 네 줄만(git diff 확인). 화질 창 점검(graphics)은 세 줄로 고침. 세이브 폴더 md5 앞뒤 같음.
