# G-0426 · 첫 실행 첫걸음 사명 — 2나락·3마을·4종횡·5천하
종류: 기본기(P0) · 고돗 네 판 · 상태: **완료(D1, 2026-10-29)**

## 목표

GO의 `data/tutorial.gd` + `world/tutorial.gd` + `probe_tutorial.gd` 패턴을 따라, 새 세이브에서만 2나락·3마을·4종횡·5천하에 첫 실행 안내를 연결한다. 각 판의 핵심 행동을 다섯 단계로 안내하고, 마지막에 저장과 목표판 읽기까지 확인한다. 기존 세이브는 완료로 취급해 기존 이용자의 흐름을 가로막지 않는다.

## 9칸 설계

- **참고·표준**: GO G-0012/G-0215 구현을 본보기로, P0 첫 10분 안내를 네 판에 제공한다.
- **근거**: `SAGA-BACKLOG.md` §1 #1. Godot 코드 검색상 GO에만 `go_tutorial` 구현이 있다.
- **판정·수치**: 각 판의 실제 진행 신호로 순서 완료하는 첫 실행 5단계. 각 단계는 기존 핵심 행동을 쓰며 보상·난이도는 유지한다.
- **UI**: 기존 목표판 첫 줄에 `첫걸음 n/5`와 행동 힌트를 표시하고 완료 후 원래 내용으로 복귀.
- **저장**: 판별 SaveState에 완료 ID 배열. 신규 세이브는 빈 배열, 필드 없는 구 세이브는 전부 완료. 버전은 호환성 검토 뒤 필요한 경우만 올린다.
- **진단**: 신규/구 세이브, 순서·실제 신호, 저장 왕복, 문구·완료 후 복귀를 판별 probe로 확인.
- **범위**: 2나락·3마을·4종횡·5천하. GO·에셋은 수정하지 않는다.

## 파일

각 판의 `games/saga_{dungeon,forest,story,realm}/data/*_save_state.gd`, 대표 씬/게임 스크립트, tutorial 데이터·판정 코드, `tools/probe_tutorial.gd`, `features.json`, 티켓·큐. 공용 순서·세이브 호환은 `saga_core/data/first_run_guide.gd`; 걷기 감지는 `saga_core/world/first_run_walk_observer.gd`. 본보기: `games/saga_go/data/tutorial.gd`, `games/saga_go/world/tutorial.gd`, `tools/probe_tutorial.gd`.

## 단계

1. 네 판의 저장 경계와 실제 행동 신호를 확인하고 단계별 행동·힌트를 정한다.
2. 저장 호환을 구현하고 상태 판정·목표판 표시를 연결한다.
3. 판별 probe로 실제 행동·저장 호환·완료 복귀를 확인하고 `features.json`을 D1로 기록한다.

## 검증

PowerShell에서 `$env:SAGA_TUTORIAL_PROBE='1'` 후 각 씬을 `$godot --headless --path saga-godot <씬>`으로 실행: `res://games/saga_dungeon/world/TestRoom.tscn`, `res://games/saga_forest/world/TestVillageForest.tscn`, `res://games/saga_story/world/TestField.tscn`, `res://games/saga_realm/world/TestCity.tscn`. 네 probe 모두 `fails=0`, 이어 `bash tools/precheck.sh saga-godot`. 전체 probe runner는 실행하지 않는다.

## 완료 조건

네 판 모두 신규 세이브 0/5 진행, 구 세이브 완료 처리, 실제 걷기·행동 연결, 중간 저장 왕복, 완료 후 목표판 복귀 통과. `features.json` D1 기록.

## 실행 결과

- 네 판 목표판 첫 줄에 단계별 안내가 나오며 실제 행동 순서에 맞춰 진행한다. 2나락은 방 정리·동행·무예, 3마을은 채집·주민 대화·부탁, 4종횡은 처치·채집·대화, 5천하는 지도·명령·등용·월 넘김을 쓴다.
- 새 저장은 빈 완료 목록에서 시작하고, 저장 때 진행 ID를 기록한다. 키가 없는 기존 저장은 다섯 단계를 완료한 것으로 읽는다. 네 판 저장 버전은 올리지 않았다.
- `SAGA_TUTORIAL_PROBE=1` scene probe 결과: dungeon 0, forest 0, story 0, realm 0 failures. 순서 거부·실제 걷기·목표판 시작/복귀·저장 왕복·키 없는 구 저장 호환을 확인했다.
- `tools/precheck.sh saga-godot` 는 Git Bash로 실행했다. 자바스크립트·공유 파일·manifest·features schema 검사는 통과했으나 전체 precheck는 기존 상한 초과 항목으로 실패했다: 루트 `CLAUDE.md` 6527B, `tasks/godot/QUEUE.md` 6144B 초과, `games/saga_realm/world/realm_tactics_view.gd` 1576줄, 다른 티켓·갈래 문서들. Windows Git Bash `sed` 오류도 출력됐고 에셋 quick check·reflect는 Python 미설치로 건너뛰었다. 이 항목들은 본 티켓 범위 밖이라 수정하지 않았다.
