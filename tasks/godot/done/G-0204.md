# G-0204 2나락 보스 패턴 넷 — 강타·돌진·관통·연격(예고 뒤 터짐, 웹 bossPattern 이식)
종류: 손맛·전투 · 고돗(2나락)      상태: 끝(D2, 10-11)      등급 목표: D2

**목표(한 줄)**: 고돗 2나락 보스(방 보스·세계 보스)는 몸만 큰 곰일 뿐 공격이 잡몹과 같다(사거리 안이면 쿨마다 그 자리 피해, `dungeon_enemy.gd::_physics_process` 195~215 · 예고·패턴 0 — `grep slam` 0건) — 웹 `dungeon.js bossPattern()` 넷(강타 원형 AOE·돌진 순간 접근·관통 방향 고정 부채꼴·연격 세 번)을 **예고(바닥 표시가 차오름) 뒤 터지는** 리듬 그대로 옮겨 보스전에 읽을 거리·피할 거리를 만든다.

**파일(확인함, 10-11)**: `saga-godot/games/saga_dungeon/world/dungeon_enemy.gd`(404줄 — `is_boss` 102·124, `_init(floor_num, boss, …)` 122, `_physics_process` 195(평타: `ATTACK_RANGE*_scale_mul` 안·`_attack_cd_left` 0 이면 `_attack_player()` 357), `_spawn_visual` 177(보스 = creature "bear"), `who_label` 349) · 보스를 세우는 곳 `world/test_room.gd` 634 · `world/world_boss_director.gd` 54 · 맞는 쪽 `player/player_health.gd take_damage(amount, source)`(G-0203 붉은 신호가 이미 뜸) · 참고 웹 `saga-web/saga-dungeon/js/dungeon.js` 47~60(상수) · 1893 `bossPattern` · 1908 `bossSlam` · `bossCharge` · `bossThrust` · `bossFlurry` · 2966(평타와 같이 돈다) · `js/data-enemy.js` 259 BOSSES 무기(t1 club·axe / t2 sword·axe·halberd / t3 spear·sword·sword / t4 halberd·halberd) · 275 `tierOf(stage)`(≤5·≤12·≤25·그 위) · 예고 그림 본보기 `games/saga_go/combat/field_enemy.gd` 311 G-0172 TELL_FAN_SHADER(부채꼴·progress 로 차오름 — 판끼리 참조 금지라 그대로 부르지 말 것).

**단계**: 1. 무기 고르기: 웹엔 보스 표가 있지만 고돗엔 없다 — `tierOf(floor_num)` 의 위 무기 목록에서 `floor_num % 길이` 로(결정적, 무작위 아님). spear·halberd 는 관통 하나로 2. 상수는 웹 그대로 px→m(6/148): SLAM_WARN 0.7·SLAM_RANGE 110px(4.46m)·SLAM_MUL 1.8 · CHARGE_WARN 0.55·CHARGE_STEP 90px(3.65m)·CHARGE_MUL 1.6 · THRUST_WARN 0.5·THRUST_RANGE 170px(6.89m)·THRUST_HALF 0.5rad·THRUST_MUL 1.5 · FLURRY_WARN 0.4·HITS 3·GAP 0.22·MUL 0.7 · 첫 쿨(slamCd) 3.5~4·뒤 5~8초(웹 `5 + random*2` 등 그대로) 3. 보스 `_physics_process` 에서 평타와 **나란히** 패턴 타이머(웹 2966 처럼 둘 다 돈다) — 예고 중엔 그 자리에 서고(돌진은 끝날 때 순간 접근), 관통은 예고 시작 순간 방향을 고정 4. 예고 그림: `saga_core/combat_tell.gd` 새로(정적 `ring(host, pos, r, sec, color)`·`fan(host, pos, dir, r, half, sec, color)` — 바닥에 깔리고 남은 시간만큼 안쪽이 차오름, sec 뒤 스스로 지움, 셰이더는 G-0172 글자를 본떠 코드 안에) — 1만리 field_enemy 는 이번에 안 옮김(메모로 R-4 후보) 5. 터질 때: 맞으면 `take_damage(dmg × MUL, self)`(G-0203 신호), 안 맞아도 `CombatFx.element_burst`(강타·돌진 원형) / `slash`(관통·연격) 한 번 + 강타는 카메라 흔들림 6. `who_label` 은 그대로, 사망 카드 "누구에게" 에 패턴 이름(강타·돌진·찌르기·연격)을 웹처럼 덧붙일 수 있으면 `last_hit` 에 같이(선택) 7. 점검 새 `probe_dungeon_boss`: 층별 무기 고르기 표(1·6·13·26층) · 네 패턴 각각 예고 시간이 지나기 전엔 피해 0, 지나면 범위 안 플레이어만 맞음(강타 반경 안/밖·관통 부채꼴 안/옆 — 예고 시작 뒤 옆으로 비키면 안 맞음·연격 세 번·돌진은 거리 3.65m 만큼 다가섬) · 예고 그림 노드가 생기고 스스로 지워짐(실제 시간 프레임 루프 — create_timer 금지) · 잡몹(is_boss false)은 패턴 없음 8. 촬영 새 컷 `dg_boss_tell`(보스 방에서 강타 예고가 반쯤 찬 프레임).
