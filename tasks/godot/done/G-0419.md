# G-0419 5천하 전직 — Lv5 1차·Lv12 2차 직업
종류: 게임성 · 고돗(5천하) · 상태: **완료** · 목표 등급: D2

**목표**: 다음 5천하 게임성 장부 우선순위 1, 웹 W-0457 이식. 장수 레벨에 따라 전투 역할과 휘하 용병 구성이 달라지도록 만든다.

**정본**: `tasks/web/done/W-0457.md`, `saga-web/saga-realm/js/realm-class.js`, `js/campaign.js`, `js/tactics.js`, `js/ultimate.js`, `js/command.js`.

**범위**: 1차 직업(Lv5) 맹장·기장·군사 선택, 2차(Lv12) 각 둘 중 하나 선택. 직업별 능력치·용병 병종 보너스·필살 피해/사거리/보급/반격 효과를 웹 수치대로 적용. 내 편은 진영 탭에서 해금 표시와 선택 설명을 보고 전직하며, 적 장수 직업은 장 진행도와 결정 seed로 정한다. 진영 미리보기와 전술 카드에 직업/효과 표시.

**불변**: 캠페인 밖 전투 및 기존 세이브는 유지하고, 선택하지 않은 인물의 직업·레벨을 임의로 바꾸지 않는다. 새 이미지·외부 에셋은 만들지 않는다.

**검증**: 직업 해금 경계·선택/저장 왕복·적 직업 결정성·장수/용병 스탯·필살/총공격/반격 상호작용을 probe로 확인한다. 캠페인·기존 전투/세이브 회귀와 전직 UI Forward+ 캡처를 확인한다.

**완료 조건**: W-0457 전직 규칙과 진영/전술 UI 작동, 기존 캠페인·전투·세이브 probe 통과, `features.json`·장부 반영, `done/` 이동.

**구현**: `realm_class.gd`에 Lv5 1차·Lv12 2차 직업, 상위직의 앞 직업 보너스 계승, 용병 병종 보너스, 적 장수 장 진행도/seed 직업을 추가했다. 캠페인 저장 딕셔너리의 `cls`에 선택을 보존해 이전 세이브는 빈 선택으로 이어진다. 전술 생성 시 장수·용병 스탯, 뒤치기/방어 명중, 필살 배율·범위, 회복 책략·이웃 치유, 지휘 보정에 반영했다. 진영 편성에는 해금 버튼과 효과 설명, 적 편성 미리보기에 적 직업을 표시하고 전술 선택 설명에도 직업 효과를 붙였다.
