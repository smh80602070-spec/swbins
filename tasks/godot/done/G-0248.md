# G-0248 다섯 판 인물 얼굴 그림자(원신식) — 공용 cel_toon 얼굴 전용 명암
종류: 그래픽 · 고돗(다섯 판 공용 saga_core)      상태: **끝**(10-20)      등급 목표: D2

**목표(한 줄)**: 그래픽 기준선 표 1행 — 툰 띠·림·외곽선·dex 몸은 다섯 판 ○ 인데 얼굴만 몸과 같은 법선 띠 명암이라 코·입가·턱에 얼룩 그늘이 진다(원신은 얼굴 법선을 쓰지 않고 머리 앞 방향 기준으로 반쪽 그늘). 공용 셰이더 한 곳을 고쳐 다섯 판 인물이 같이 바뀐다.

**파일(확인함 10-20)**: `saga-godot/saga_core/shaders/cel_toon.gdshader` 17~32 uniform·67 `light()`(NORMAL·LIGHT 띠, 83 skin_warm) · `saga_core/shaders/cel_shader_apply.gd` 70 `_surface_kind`("skin"/"hair"/"face"/"cloth")·88 `_apply_one` · `saga_core/world/vroid_body.gd` 9 `HEAD_BONES`·124 head 뼈·158 `cel_applied` meta · 새 `saga_core/world/face_light.gd` · 본보기 `games/saga_go/world/talk_face.gd` 1(SkeletonModifier3D 로 머리 뼈 읽기) · 촬영 `saga-godot/tools/face_view.gd`.

**단계**: 1 cel_toon 에 `uniform float face_mode`(0/1)·`instance uniform vec3 head_fwd`·`uniform float face_flatten`(0.65) — face_mode 면 ndotl 을 `mix(NORMAL, head_fwd, face_flatten)·LIGHT` 로(코·입 얼룩 사라짐), 그늘 경계는 머리 좌우(수평 각) 기준으로 반쪽 2 `_apply_one`: 머리 뼈 아래 "skin"·"face" 표면만 face_mode=1(몸 살갗은 0 — 메시 이름·부모 뼈로 가름, 손·목은 몸) 3 새 `face_light.gd`(SkeletonModifier3D): 매 틱 Head 뼈 global basis 의 앞 방향을 그 몸의 face 표면 `set_instance_shader_parameter("head_fwd")` 로 — vroid_body 가 cel 적용 직후 한 번 단다(다섯 판 공용 경로라 판 코드 수정 없음) 4 앞머리 그림자 띠·SDF 얼굴 그림자 텍스처는 **K 대기** — uniform `face_sdf` 자리만 비워 두고 없으면 1 의 결과 그대로 5 손잡이 `SAGA_FACE_LIGHT=0` 이면 옛 그대로(전후 촬영) 6 `features.json` 공용 줄 `gd.core.face-light` D1→D2(꼴 `gd.fs.real_ground`).

**검증**: 새 `saga-godot/tools/probe_face_light.gd`(SceneTree, 본보기 `probe_dex_bodies.gd`: 몸 셋 build → 머리 skin·face 표면 face_mode=1·몸 살갗·옷 0 · 한 프레임 뒤 head_fwd 가 0 벡터 아님 · 손잡이 0 이면 face_mode 0) → `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=face_light,dex_bodies,player_bodies,monster_body` fails=0 · `bash saga-godot/tools/godot_regress.sh` OK(재질 감사 포함) · `bash saga-godot/tools/check_refs.sh` 빔 · 촬영: `face_view.gd` 전후(SAGA_FACE_LIGHT=0/1, 창 모드 `--rendering-method mobile --position -4000,0`) + 1만리 `v_village_plaza`·3마을 `fs_villager`(`tools/shot_scene.gd`) 각 한 장 → 코·입가 얼룩 없음·반쪽 그늘 ○△× 를 메모에.

**완료 조건**: probe fails=0 · regress OK · 얼굴 얼룩 그늘 없음 ○ · 몸·옷·머리 명암 그대로 · features D2 · 장부 `tasks/gameplay/README.md` 그래픽 표 1행 고돗 칸 `○(G-0248)` · 큐 줄 끝 · done/.   **불변**: 그림·모델·.import 안 만듦(SDF 텍스처는 K) · 외곽선 두께·rim·skin_warm 값 안 바꿈 · 눈(anime_eye)·입(anime_mouth) 그대로 · draw call 안 늘림(instance uniform 은 재질 수 안 늘림) · 티켓 3KB.   **함정**: instance uniform 은 forward_plus·mobile 둘 다 되지만 `gl_compatibility` 에선 무시된다 — 그때 face_flatten 만으로 떨어지게 · 머리 뼈 이름은 `HEAD_BONES` 둘뿐(없는 몸은 face_mode 0) · 촬영 .import 되돌림(G-0143 메모).

**메모(체크포인트)**: ✔ 1~6. 셰이더 face_ndotl: 얼굴 법선·빛을 둘 다 수평(월드 위 성분 뺌)으로 눌러 head_fwd 와 0.65 섞음 — 코·턱 밑 그늘 없음, 해가 높으면(lv 0.8~0.98) 고르게 밝음, 경계는 세로 반쪽. head_fwd 0(compat)이면 그늘 바닥만 0.7 로.
