# G-0035 세이브 옮기기 — 문자열 내보내기/불러오기(다섯 판 공용 + 사가고 메뉴 화면, 코드만)
종류: 새기능 · 고돗      상태: **완료**(2026-10-06) — 코드·점검·창 촬영 끝, 실제 두 PC 사이 옮기기는 사람 몫(D2)      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG P0 #6 "클라우드 세이브·기기 이동" 최소안(큐가 비어 P0 에서). 서버 없이 세이브를 글 하나(`SAGA1|<판>|<길이>|<base64(gzip(JSON))>`)로 내보내고 다른 PC·기기에서 붙여 넣어 불러온다. 진짜 클라우드는 사용자 결정(§10-Q6)이라 안 함.

**파일**: `saga-godot/saga_core/data/save_base.gd`(export_string·import_string — 다섯 판 세이브 부모) · 새 `games/saga_go/ui/save_transfer.gd`(본보기 `world/achievements.gd`) · `games/saga_go/world/hud_menu.gd`(메뉴 항목) · `games/saga_go/world/test_village.gd` · 새 점검 `tools/probe_savemove.gd` · `tools/probe_shots.gd`(ui_savemove 컷) · `docs/HOW_TO_PLAYTEST.md`.

**단계**
1. `save_base.gd`: 내보내기(세이브 파일 → 압축 문자열), 불러오기(머리·판 이름·압축·JSON·_migrate 를 다 통과해야 씀, 지금 파일은 `<경로>.before_import` 로 — `.bak` 은 다음 자동 저장에 덮이므로 따로).
2. 사가고 메뉴 "세이브 옮기기": 내보내기(저장 후 칸·클립보드) · 붙여넣기 · 불러오기(두 번 눌러야) · 성공이면 자동 저장을 치우고 장면 다시 띄움.
3. 점검: 내보내기 형식 · 덮은 뒤 불러오면 원본과 같음·직전본 남음 · 엉터리/다른 판/깨진 글/더 새 버전 거절·파일 그대로 · 화면·메뉴 · 다섯 판 다 있음.

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=savemove,home,autosave,save_dungeon,save_forest,save_story,save_realm   → fails=0
GODOT=<콘솔 exe> bash saga-godot/tools/godot_regress.sh   → REGRESS OK
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~3 · 세이브 키·형식 불변(파일 그대로 옮김) · 진짜 세이브는 점검이 안 건드림(path_override).

**메모(10-06 실행)**: ✔ 단계 1~3. 새 세이브 문자열 약 1KB. 거절 이유: "세이브 문자열이 아니다"·"다른 게임의 세이브다 (dungeon)"·"문자열이 깨졌다"·"이 판보다 새 버전이거나 옮길 수 없는 세이브다". 깨진 글은 엔진이 압축 풀기 오류 한 줄을 찍지만 거절은 정상. 다른 네 판은 부모에 기능이 생겼지만 화면은 아직 사가고만(필요하면 같은 화면을 붙이면 된다). 창 촬영: 안내·칸·단추 넷 정상.
