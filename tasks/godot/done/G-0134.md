# G-0134 풀밭의 흙 얼룩이 흐린 진흙 자국 — 경계를 좁히고 들쭉날쭉하게
종류: 그래픽 · 고돗(사가만리)      상태: 닫음 D2(10-09)      등급 목표: D2

**목표(한 줄)**: 마을 광장·옛 역·폐허·집 앞 컷의 풀밭에 갈색 얼룩이 넓고 흐리게 번져 흙자리가 아니라 더러운 진흙 자국처럼 보인다. 흙 얼룩 경계를 좁히고(또렷한 흙자리) 잔 노이즈로 가장자리를 들쭉날쭉하게.

**지금 상태(확인함, 10-09)**: `terrain_triplanar.gdshader` 평지 흙 섞기 `dirt_w = smoothstep(0.55, 0.75, n1) * 0.6`(n1 = 값 노이즈, patch_scale 0.12 → 얼룩 지름 수십 m). 경계 폭 0.2 라 얼룩 대부분이 풀·흙 반반 섞인 흐린 갈색.

**파일**: `saga-godot/saga_core/shaders/terrain_triplanar.gdshader`(dirt_w 한 줄) · 이 티켓

**단계**
1. `dirt_w = smoothstep(0.61, 0.67, n1 + (n2 - 0.5) * 0.14) * 0.55` 안팎 — 경계 폭 0.06·n2 로 가장자리 흔들기, 넓이는 비슷하게.
2. 같은 시간대 전후 v_old_station·v_village_plaza·r_statue·v_house·g38_vault_granary(가을빛 지역) — 진흙 번짐이 또렷한 흙자리로, 풀밭이 더러워 보이지 않나.

**검증**: 전후 촬영 판정·픽셀 · 창 모드 셰이더 오류 0 · `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=triplanar,toon_look` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: 흙 얼룩이 또렷한 흙자리로 읽힘 ○ · 풀밭 전체 빛깔 그대로.

**불변 규칙**: 경사 돌·절벽·눈·모래·이끼 식 안 바꿈 · 텍스처·정점색 안 바꿈.

**메모(체크포인트)**:

- 10-09 끝: 첫 값(0.61~0.67·0.55)은 경계는 또렷했으나 흙자리가 넓어져 갈색 띠가 더 도드라짐 → `smoothstep(0.68, 0.73, n1 + (n2 - 0.5) * 0.14) * 0.5`. 같은 시간대 전후(15:33·15:36): v_old_station 흐린 진흙 번짐 → 또렷한 흙자리 몇 개 ○. 셰이더 오류 0 · triplanar·toon_look fails=0.
