# G-0415 3마을 Mobile 집 안 흰 십자 번짐
종류: 버그(그래픽) · 고돗(코어/3마을) · 상태: **완료** (2026-10-28) · 목표 등급: D2

**목표**: Mobile 렌더러에서 3마을 집 안 화면 중앙에 남는 흰 십자형 번짐을 없앤다. 재현상 `CombatFx.warm()`의 카메라 앞 작은 번쩍임이 원인이며, 별빛 `BILLBOARD_ENABLED` 재질이 MeshInstance 크기를 버려 `WARM_SCALE`을 따르지 않는다. `billboard_keep_scale`로 의도한 크기를 보존한다.

**파일**: `saga-godot/saga_core/combat_fx.gd`, `saga-godot/tools/shot_scene.gd`(검증).

**단계**: ① Mobile `fs_room`에서 재현하고 `SAGA_FX_WARM=0`으로 warm 이펙트를 분리한다. ② 번쩍임 재질에 billboard scale 보존을 설정한다. ③ Mobile `fs_room`·`fs_exit_villager`와 Forward+ `fs_room`을 비교한다. ④ Mobile `ac_dg_attack`으로 실제 전투 번쩍임이 의도한 월드 크기로 보이는지 확인한다. ⑤ 검토 뒤 임시 캡처 파일을 지운다.

**검증**: 창 모드 `shot_scene.gd`로 Mobile `SHOT_ONLY=fs_room`을 기본값과 `SAGA_FX_WARM=0` 양쪽에서 비교한다. Forward+ `fs_room`, Mobile `fs_exit_villager`, Mobile `ac_dg_attack`도 찍는다. 집 안 십자 번짐은 없어야 하고 실제 공격 번쩍임은 보이며 기존 집 안 조명·바깥 컷은 유지되어야 한다.

**완료 조건**: 수정과 표적 점검 통과, 네 컷 시각 비교에서 위 조건 확인. 게임 규칙·에셋·환경 프로파일은 바꾸지 않는다. 검토 PNG는 `tools/_out/`에서 확인 후 삭제한다.

**본보기**: `tasks/godot/done/G-0358.md`의 Mobile 잔여 현상.

**완료 기록**: spark 빌보드 재질에 `billboard_keep_scale = true`를 설정했다. Mobile `fs_room`의 십자 번짐은 사라졌고, warm 비활성 대조도 같은 정상 결과였다. Mobile 바깥 `fs_exit_villager`, Mobile `ac_dg_attack`, Forward+ `fs_room`을 확인했다.

**검증**: `combat_fx.gd --check-only` 통과 · `probe_combat_feel` 통과 · 창 모드 촬영 `fs_room`, `fs_exit_villager`, `ac_dg_attack`(Mobile)·`fs_room`(Forward+) 전부 `err=0`. PNG는 검토 후 제거.
