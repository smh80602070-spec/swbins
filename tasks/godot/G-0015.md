# G-0015 사가고 지역 다섯을 지역 배치표(layout.json)로 짠다 — 코드만
종류: 새기능 · 고돗      상태: **코드분 끝**(2026-10-03) — 사용자 눈(시안과 같은 구도·빛 세기) 확인 대기      등급 목표: D2

**목표(한 줄)**: `saga-godot/assets/regions/` 의 조각(`pieces/` 29 GLB)·지역별 배치표·땅 재질·풍경 메시·하늘 파노라마로 지역 다섯(village·galaxy_ferry·frost_peak·time_rift·crossroads)을 시안과 같은 구도로 짠다. 로더는 하나(`RegionLoader`), 지역은 데이터. 에셋은 고치지 않는다.

**결정(R-0)**
- **지역 구경 장면**이다 — `games/saga_go/world/RegionShowcase.tscn`(`SAGA_REGION=<지역>`, 기본 village, WASD·QE·우클릭 드래그). 기존 사가고 지역 10곳·타일 지도·세이브·전투는 안 건드린다. 게임 지역과의 짝짓기·이동 연결은 사용자 결정 뒤 별도 티켓.
- 배치표 모양이 지역마다 다르다 — 있는 키만 읽고 없으면 건너뛴다. village: `pieces 22`·`roads 3`·`trees 130`·`flowers 238`·`plaza`·`terrain`(높이만). 나머지: `schema 1`(`pieces 21/26/13/65`·`lights 18/23/18/64`·`scenery`·`fog`·`camera`·`water`/`fx`/`gate`/`roads` 지역별).
- village 나무·꽃은 위치뿐이라 기존 CC0 `generated/variants` 나무 3종·`Flower_3_Single` 을 얹는다.
- 빛 예산: 점광원은 구경 카메라에서 가까운 순 모바일 8·PC 16, 그림자는 해·달(SUN) 하나.

**단계(전부 코드분 끝, 10-03)**
1. ✔ `region_loader.gd`: 좌표 (x,z,-y), 조각 종류별 MultiMesh, 지형 격자→메시 한 장(`height` null=땅 없음→칸 비움), 광장·길 띠, 나무·꽃, 하늘 파노라마(showcase).
2. ✔ `region_ground.gdshader`: `terrain.materials` low/high 를 max(높이, 경사) 램프로 섞음(region_hero.py `pbr_blend` 와 같은 식, tile=그림 한 장이 덮는 미터).
3. ✔ 풍경 GLB 그대로 올림·`water` 평면·`fog`(Environment)·`fx` 반딧불/눈발(CPUParticles3D, `count` 그대로)·`lights`(SUN→DirectionalLight, POINT→예산만큼 Omni)·`camera`(lens→fov).
4. ✔ 진단 `SAGA_REGION_PROBE=1`: 지역 다섯 짜서 조각·나무·꽃·길 수 = 배치표, 풍경·물·지형 있음, 점광원 ≤ 예산 → `REGION_PROBE_DONE fails=0`.
5. 실기 발열·프레임·시안 비교는 사용자 몫(몰아서).

**검증(10-03)**: 진단 세 번 출력 md5 동일·fails=0 · `godot_regress.sh` REGRESS OK(md5 불변) · `check_refs.sh` 깨짐 0. 헤드리스라 그림은 안 봤다.
측정(지역별 MultiMesh 수·조각 종류·지형 삼각형): village 21·17·12160 · galaxy 4·4·6846 · frost 6·6·8762 · rift 4·4·0 · crossroads 9·9·10102. 풍경 메시 수 4/3/14/9. 켜진 점광원 16(PC).

**남은 것(사용자 눈에서 정함)**: 와트→Omni 세기 환산(`WATT_TO_ENERGY`=1/80, 범위 √W×1.2)은 눈대중 · `sky.moon`·`gate`·`rift_rings`·`islands_material` 은 풍경 GLB 안에 이미 구워져 있다고 보고 안 읽음(밋밋하면 추가) · 땅 셰이더는 cel 밴드 없이 단색 확산 · 조각은 glTF 재질 그대로(cel_toon 미적용).

**불변 규칙**: 에셋 수정 금지(필요하면 K-0051 에 요청 — 예: village 전용 나무·꽃 GLB) · 이름 정책 · 세이브 키 불변 · 노드 폭주 금지(같은 조각 반복은 MultiMesh).

**함정**: 새 `class_name`·`.gdshader` 는 `godot --headless --editor --path . --quit` 한 번으로 캐시에 올라야 헤드리스가 찾는다(컴파일 오류가 나면 진단이 quit 에 못 닿아 걸린다 — `timeout` 을 건다). Godot enum 이름은 `TEXTURE_FILTER_LINEAR_WITH_MIPMAPS_ANISOTROPIC`.
