# G-0015 사가고 지역 다섯을 지역 배치표(layout.json)로 짠다 — 코드만
종류: 새기능 · 고돗      상태: **초안**(2026-10-03) — 사용자 "마을부터 게임 트랙에 연결, 다른 지역도 같은 방식으로" · 에셋은 자체툴 K-0051·K-0019 가 이미 놓음      등급 목표: D2

**목표(한 줄)**: `saga-godot/assets/regions/` 의 조각(`pieces/` 23)·지역별 배치표·땅 재질·풍경 메시로 지역 다섯(village·galaxy_ferry·frost_peak·time_rift·crossroads)을 시안과 같은 구도로 짠다. 로더는 하나(`region_loader.gd`), 지역은 데이터. 에셋은 고치지 않는다.

**파일(확인함)**: `assets/regions/<지역>/layout.json`(조각 위치·회전·크기, 빛, 길, 지형 높이 격자+땅 재질 섞기 규칙, 하늘·안개·효과 값, 카메라) · `<지역>_scenery.glb`(소나무·바위·갈대·부두·섬·고리 등 4천~1.8만 삼각형) · `tex/*.jpg`(1024px) · `pieces/*.glb`(툰, 바탕색 1024px) · 시안 `tools/world-forge/_out/hero_<지역>_pbr.png`(기준 그림, git 밖)

**단계**
1. 로더: 좌표 변환(Blender x·y·z → (x, z, -y), 미터), 조각은 `MultiMeshInstance3D`(같은 조각 반복) — 노드 수 폭주 금지. 마을 먼저.
2. 지형: `terrain` 높이 격자 → 메시 한 장, 재질은 `materials` 규칙(낮은·평평=low 그림, 높거나 가파름=high 그림, 경사·높이로 섞음 — cel_toon 에 섞기 한 줄 필요) · 길(`roads`)은 지형 위 띠.
3. 풍경 메시·물(`water`)·하늘(`sky.kind`)·안개(`fog`)·효과(`fx` 반딧불·눈발은 파티클) · 빛 `lights`(점광원이 수십 개 — 모바일은 가까운 몇 개만 켜거나 구움, 사용자 "발열").
4. 지역 다섯 모두 진단: 조각 수 = 배치표 수 · 로드 오류 0 · 기존 진단 불변.
5. 실기 발열·프레임은 사용자 몫(몰아서).

**검증**: 지역별 진단 RESULT n/n 세 번 같음 · 드로우콜·삼각형 수 기록(추측 금지) · `precheck` OK.

**완료 조건**: 단계 1~4(마을 → 나머지 순서), 시안과 같은 구도 확인(사용자 눈).

**불변 규칙**: 에셋 수정 금지(필요하면 K-0051 에 요청) · 이름 정책 · 세이브 키 불변 · 화질은 안 깎고 낭비만 줄인다.

**메모**: `.import` 는 Godot 세션이 한 번 임포트로 만든다. 수치(그림자 크기·광원 수)는 R-0 에서 채운다.
