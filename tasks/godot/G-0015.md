# G-0015 사가고 지역 다섯을 지역 배치표(layout.json)로 짠다 — 코드만
종류: 새기능 · 고돗      상태: **작성됨**(R-0 2026-10-03) — 사용자 "마을부터 게임 트랙에 연결, 다른 지역도 같은 방식으로" · 에셋은 자체툴 K-0051·K-0019 가 이미 놓음      등급 목표: D2

**목표(한 줄)**: `saga-godot/assets/regions/` 의 조각(`pieces/` 29 GLB)·지역별 배치표·땅 재질·풍경 메시·하늘 파노라마로 지역 다섯(village·galaxy_ferry·frost_peak·time_rift·crossroads)을 시안과 같은 구도로 짠다. 로더는 하나(`RegionLoader`), 지역은 데이터. 에셋은 고치지 않는다.

**결정(R-0, 묻지 않고 정본 제안대로)**
- 이 티켓은 **지역 구경 장면**이다 — 새 `games/saga_go/world/RegionShowcase.tscn` + `region_loader.gd`(`class_name RegionLoader`). 환경변수 `SAGA_REGION=<지역>`(없으면 village)로 한 지역을 연다. 기존 사가고 지역 10곳(`region2_coast`~`region10_fork`·`TestVillage`)·타일 지도·세이브·전투는 **건드리지 않는다**(지역 5 와 게임 지역의 짝짓기·이동 연결은 사용자 결정 뒤 별도 티켓).
- 배치표는 **지역마다 모양이 다르다**(확인함): village 는 옛 모양(`pieces 22`·`roads 3`·`trees 130`·`flowers 238`·`plaza`·`terrain` 높이만, `lights`·`scenery`·`water`·`camera` 없음), 나머지 넷은 `schema 1`(`pieces 21/26/13/65`·`lights 18/23/18/64`·`scenery`·`fog`·`camera`; galaxy 는 `water`·`fx.fireflies`, frost 는 `fx.snowfall`, time_rift 는 `terrain` 없이 `islands_material`·`sky.rift_rings`, crossroads 는 `roads 4`·`gate`·`terrain.materials`). 로더는 **있는 키만 읽고 없으면 건너뛴다**.
- village 의 `trees`(`[x,y,z,크기,회전]`)·`flowers`(`[x,y,z]`)는 위치만 있고 메시가 없다 → 기존 CC0 `assets/generated/variants` 나무·들꽃(`CommonTree_*`·`Flower_*`)을 `vegetation_builder.gd` 와 같은 방식으로 얹는다. 풍경 GLB 가 없는 village 의 언덕은 `terrain` 격자만으로.
- 빛 예산: 점광원은 카메라에서 가까운 순 **모바일 8·PC 16** 만 켠다(`env_mobile`/`env_pc` 구분을 따름). 나머지 등롱·횃불은 조각 자체의 발광(`emission`)으로만 보이게 둔다. 그림자는 달·태양 한 개만.

**파일(확인함)**
- 읽는 곳: `assets/regions/<지역>/layout.json`(village 37KB) · `<지역>_scenery.glb`(time_rift 1.7MB·galaxy 0.95MB) · `tex/*.jpg`(1024px) · `sky_<지역>.jpg`(4096)·`_2k.jpg`(모바일) · `pieces/*.glb`(최대 1.0MB, 툰 바탕색) · 조각 종류 28 = 배치 합계 147(22+21+26+13+65). 시안 `tools/world-forge/_out/hero_<지역>_pbr.png`(git 밖, 기준 그림)
- 쓰는 곳: 새 `games/saga_go/world/region_loader.gd`·`RegionShowcase.tscn`·`region_showcase.gd`(진단) · 읽기만 `saga_core/shaders/cel_toon.gdshader`·`world_curve_material.gd`(구면 휨을 끌지 말지 단계 1에서 확인)·`terrain_builder.gd`(옛 지도용, 안 씀)
- 환경: `assets/environment/env_pc.tres`·`env_mobile.tres`(안개·하늘 참고)

**단계**
1. 로더 뼈대 + village: 좌표 변환(Blender x·y·z → Godot (x, z, -y), 미터), 조각은 종류별 `MultiMeshInstance3D`(노드 수 = 종류 수 28 이하) · 지형 높이 격자(`x0,y0,step,nx,ny`) → `ArrayMesh` 한 장 · `roads` 띠 · `plaza` 원 · 나무·꽃(MultiMesh). 하늘 파노라마(`sky.panorama`, equirect, `forward:+y`).
2. 땅 재질: `terrain.materials`(low·high 그림, `z0/z1` 높이·`slope0/1` 경사로 섞음, `tile_*` 반복, `tint_*`) → 땅 셰이더 하나(`region_ground.gdshader`, cel_toon 밴드와 맞춤). 길은 `mat`(dirt·asphalt) 그림.
3. 나머지 넷: 풍경 GLB·`water`(평면 + 거칠기)·`fog`(`density`·`color`·`box`)·`fx`(fireflies·snowfall 파티클, `count` 그대로)·`lights`(위 예산)·`gate`(갈림길 문 고리)·`rift_rings`·`islands_material`·`camera`(구경 카메라 시작 자리·`lens`→fov).
4. 진단 `RegionShowcase` `SAGA_REGION_PROBE=1`: 지역 다섯을 차례로 열어 **조각 수 = 배치표 수**·로드 오류 0·MultiMesh 수·점광원 수 ≤ 예산·`REGION_PROBE_DONE fails=0` 출력. 기존 진단 불변.
5. 실기 발열·프레임·시안과 비교는 사용자 몫(몰아서).

**검증**: `GODOT=$(which godot) bash tools/godot_regress.sh` REGRESS OK(기존 다섯 판 불변) · `godot --headless --path . res://games/saga_go/world/RegionShowcase.tscn` 진단 세 번 출력 같음 · 지역별 드로우콜·삼각형·MultiMesh 수 기록(헤드리스 더미 렌더라 삼각형은 메시 합으로 계산, 추측 금지) · `check_refs.sh` · `precheck` OK.

**완료 조건**: 단계 1~4(village → galaxy_ferry → crossroads → frost_peak → time_rift 순), 시안과 같은 구도 확인(사용자 눈).
