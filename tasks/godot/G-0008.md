# G-0008 `assets/generated/variants` 참조 조사 보고
종류: 측정 · 에셋      상태: **작성됨**      등급 목표: (체제) — 에셋 정리 근거(삭제는 K-0010)

**목표(한 줄)**: `saga-godot/assets/generated/variants/` 1,572파일·1,010MB 중 코드가 안 부르는 것의 목록과 용량을 `saga-godot/docs/variants_unused.txt` 로 낸다. **지우지 않는다**(ARCH §8-10).

**측정(2026-10-01)**: glb 317개 521MB · png 469개 483MB · `.import` 786개 1MB. 경로는 전부 **리터럴**(`res://assets/generated/variants/<이름>__<팔레트>.glb`, 동적 조립 0 — `"__"`·`variants/%` 검색 0건)이고 `.gd` 6개(vegetation_builder·landmarks_builder·homestead·realm_city·test_room·loot_pickup)가 부른다. 코드가 부르는 고유 glb = **94** → 안 부르는 glb ≈ 223(70%). png 는 이름 `<glb이름>_<N>.png`(309 묶음)인데 glb 안에 질감이 내장돼(`.glb` 에 png 이름 0회) **어느 코드도 png 를 안 부른다**.

**파일**: `saga-godot/tools/variants_audit.sh`(새, grep 만 — 의존 없음) · `saga-godot/docs/variants_unused.txt`(산출)

**본보기**: `tools/check_refs.sh` 의 머리 주석·종료 코드 형식.

**단계**
1. 참조 집합: `grep -rIoh "variants/[A-Za-z0-9_.-]*\.glb"` 를 `--include=*.gd --include=*.tscn --include=*.tres --include=*.json --include=*.cfg --include=*.sh --include=*.mjs` 로, `assets/generated/variants`·`docs`·`.godot` 는 뺀다. `uid://` 참조도 센다(`*.glb.import` 의 `uid="…"` 를 `.tscn`·`.tres`·`.gd` 에서 grep).
2. 세 묶음으로 나눈다: **A** 안 부르는 glb(경로·바이트) · **B** A 의 png 묶음(`<glb이름>_<N>.png`) · **C** 부르는 glb 의 png 묶음("내장 추정 — 코드 참조 0, 삭제 가부는 K-0010").
3. 보고서 머리에 총계 두 줄: `참조됨 N개/MB` · `안 됨 N개/MB`(glb+png+import 합), 그 아래 A·B·C 소계와 목록. 참조는 있는데 파일이 없는 것은 `깨진 참조` 절.

**검증**
```
bash saga-godot/tools/variants_audit.sh        → 종료 0, 보고서 생성
head -3 saga-godot/docs/variants_unused.txt     → 총계 두 줄(참조됨 94 glb 안팎)
참조된 것 표본 3개를 grep -rn 으로, 안 된 것 표본 3개를 grep -rn 으로 재확인(0건)
bash saga-godot/tools/godot_regress.sh          → REGRESS OK(파일 안 건드렸으니 그대로)
```
**완료 조건**: 위 · 총계 합 = 1,010MB(±1) · A+참조된 glb = 317 · 삭제·이동 0.

**불변 규칙**: `assets/` 아래 수정 0 · 게임 코드 0 · `.godot` 캐시 안 건드림.
