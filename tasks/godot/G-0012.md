# G-0012 첫 10분 사명(GO)
종류: 새기능(P0) · GO      상태: **작성됨**      등급 목표: D1(probe)

**목표(한 줄)**: 새 세이브에 첫걸음 사명 5개가 목표판 **첫 줄**에 차례로 뜬다 — ① 이동·등반 ② 동행 등용 ③ 상자 ④ 원소 반응 1회 ⑤ 저장. 다섯 다 하면 평소 줄(사명/도감)로 돌아간다. 세이브 `tut`. 옛 세이브(`tut` 없음)는 전부 완료로 간주(마이그레이션·SAVE_VERSION 변경 0 — 순수 추가 필드).

**측정(2026-10-01)**: 후크가 이미 있다 — ③ `world/treasure_chest.gd` `signal opened(chest)` · ④ `combat/field_combat.gd:168` `signal reacted(reaction)` · ⑤ `world/autosave.gd:11` `signal saved(reason)`(+`SaveState.save()`) · ② `PartyState.members`(`recruit(id)` 257행, 시작 명단 빈 배열) · ① `player/go_player.gd` 의 `Mode.CLIMB`(176행 `_tick_climb`)+이동 거리. 첫 줄은 `test_village.gd::_refresh_goal_board`(`now` 문자열) 한 곳. 기존 `world/help_guide.gd`(도움말·첫 걸음 **말풍선**, `PartyState.tips`)와 겹치지 않게 — 이쪽은 "해야 할 일" 목표판, 저쪽은 안내 줄. 웹 W-0015 와 같은 사명 표(웹은 포획이 셋째, 여기는 상자·원소 반응).

**파일**: `games/saga_go/data/tutorial.gd`(새, 표 5행 `{id,name,hint}`) · `games/saga_go/world/tutorial.gd`(새 Node, 이벤트 연결·`current()`·`complete(id)`) · `data/party_state.gd`(`var tut: Array[String]`) · `data/save_state.gd`(`"tut"` 저장·`.get("tut", ALL)` 읽기) · `world/test_village.gd`(붙이기+PROBES 에 `TUTORIAL`+`_refresh_goal_board` 첫 줄) · `tools/probe_tutorial.gd`(새) · `features.json`(`gd.go.tutorial` D1)

**본보기**: `world/help_guide.gd`(test_village 가 붙이는 Node·그룹) · `tools/probe_help.gd`(씬 probe 틀) · 저장 필드는 `"commissions": PartyState.commissions` 줄.

**단계**
1. 표·`PartyState.tut`·저장/불러오기(`try_load` 에 키가 없으면 `tut` = 전체 id).
2. `tutorial.gd`: 신호 3개를 연결, ②·①은 `POLL_SEC` 1초 폴링(help_guide 방식). `complete(id)` 는 처음 한 번만 `tut` 에 추가+`changed` 방출→`_refresh_goal_board`. 첫 줄 = `"첫걸음 %d/5: %s"` + hint(미완 첫 사명).
3. `probe_tutorial.gd`: ① 새 세이브(임시 `path_override`) → 목표판 1줄 = 사명1 ② `complete` 를 신호 경로로 차례 발생(상자 `opened.emit`·`reacted.emit` 등) → 1줄이 차례로 바뀜 ③ 다섯 뒤 1줄 = 평소 줄 · `tut` 길이 5 ④ 저장→불러오기 왕복 유지 ⑤ `tut` 없는 옛 dict → 전부 완료. 끝에 `TUTORIAL_PROBE_DONE fails=N`.

