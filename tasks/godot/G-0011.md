# G-0011 배경음 `saga_core/audio/bgm.gd`(곡은 K-0004)
종류: 새기능(P0) · 다섯      상태: **작성됨**      등급 목표: D1(probe) — 곡이 오면 D2

**목표(한 줄)**: 코어에 배경음 재생기 하나를 두고 판·장면 키(`<game>-<scene>`)로 곡을 **크로스페이드**로 바꾼다. 곡 파일이 없으면 조용히(경고·로그 0). 곡 복사는 K-0004 가 끝난 뒤.

**측정**: Godot 음악 코드 0 · 설정 화면 없음(UI 는 이 티켓 밖) · 키 A~Z·0~9 전부 배정 → 키 안 만든다. 곡은 K-0004 가 `saga-web/shared/audio/bgm/<game>-<scene>.ogg` 15개로 낸다.

**파일**: `saga-godot/saga_core/audio/bgm.gd`(새) · 진입 한 줄 ×5 · `tools/probe_bgm.gd`(새) · (곡 도착 뒤) `assets/audio/bgm/*.ogg`+`*.license.json`

**설계(autoload 안 늘림)**: `const Bgm := preload("res://saga_core/audio/bgm.gd")` · `Bgm.play(node, "go-town")` · `Bgm.stop(node)`. 첫 호출이 `/root/SagaBgm`(Node, 플레이어 둘 A/B)을 만든다. 곡 찾기 = `res://assets/audio/bgm/<키>.ogg`, 없으면 `.wav`, 없으면 아무것도 안 함. 같은 키 재호출은 무시. 새 곡이면 A→B 페이드 `FADE` 초. 루프 켬. 전용 버스 `BGM` 을 `AudioServer.add_bus` 로 런타임 생성(효과음 영향 0). 켜기·음량은 `user://audio.cfg`(`[bgm] enabled, volume`) + `Bgm.set_enabled(b)`·`set_volume(0~1)` — UI 없이 API 만. 시험용 `Bgm.dir`·`Bgm.cfg_path`·`Bgm.FADE` 는 var 로 덮어쓸 수 있게.

**단계**
1. `bgm.gd` + `probe_bgm.gd`(SceneTree, `_initialize` 에서 `await process_frame`): ① 곡 없는 키 → 오류·경고 0, 현재 키 "" ② `user://bgm_probe/` 에 0.2초 사인 wav 둘을 `AudioStreamWAV.save_to_wav` 로 만들고 `Bgm.dir` 를 거기로 → `play("a")` 스트림 경로 a, 재생 중 ③ `play("b")` + FADE 지난 뒤 현재 b·A 정지 ④ `set_enabled(false)` 정지, 재시작해도(새 인스턴스) 설정 유지 ⑤ 임시 파일 삭제. 각 check, 끝에 `PROBE bgm OK`.
2. 진입 한 줄: GO `test_village.gd`(마을 지역 `go-town`·그 밖 `go-field`) · `saga_dungeon/world/test_room.gd`(`dg-field`) · `saga_forest/world/forest_village.gd`(`fs-town`) · `saga_story/world/story_field.gd`(`st-field`) · `saga_realm/world/realm_city.gd`(`rk-field`). 전투 곡 전환은 후속.
3. 곡 오면(`ls saga-web/shared/audio/bgm/*.ogg` ≥ 1): `assets/audio/bgm/` 로 복사(+`license.json`), 크기 15곡 ≤ 25MB. 없으면 건너뛰고 메모.

**검증**
```
probe_all.sh --only=bgm → fails=0
godot_regress.sh → REGRESS OK (md5 3회 동일 — 곡 없으니 로그에 새 줄 0)
bash saga-godot/tools/check_refs.sh → 0
```
**완료 조건**: 위 · 곡 없이도 부팅 오류 0 · `assets/` 수정은 3단계 해당 시만.

**불변 규칙**: 효과음·`CombatFeel` 수정 0 · 새 입력 키·설정 UI 0 · 원작 곡 금지(K-0004 규칙).
