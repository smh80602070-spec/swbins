# G-0063 사가의숲 옷 머리·덧옷·갑옷을 자체툴 GLB 로 — 그림 없던 머리 다섯·판 도형 덧옷

**목표(한 줄)**: 사가의숲 옷(forest_wear_visual.gd)은 옷 빛만 몸에 보이고, 머리(댕기·유건·갓·족두리·전립)는 그림 없이 사고팔기만, 덧옷은 얇은 판 도형(G-0051 △), 겉옷 "갑옷"도 안 보인다. 안 쓰는 자체툴 GLB(acc_·eq_ — 붙일 뼈가 license.json 에 있음)를 G-0060 과 같은 뼈 붙이기로 몸에 입힌다.

**짝(정함)**: 머리 — 댕기 → acc_ribbon · 유건 → acc_headband · 갓 → acc_hat_wide · 족두리 → acc_crown · 전립 → acc_hat_pointed · 맨머리·상투 → 없음. 덧옷 on → acc_cape_long(판 도형 대신). 겉옷 갑옷 → eq_past_2_chest + eq_past_2_shoulder(좌우). 평상복·도포·두루마기 → 없음(그림 없음 — 그대로).

**파일**: 새 `saga_core/world/bone_gear.gd`(정적 — 뼈 찾기·앵커·배율 = 머리 뼈 높이/1.5·거울·치우기, G-0060 armor_visual.gd 의 `_put`·`body_scale`·`clear` 를 옮김) · `games/saga_go/player/armor_visual.gd`(bone_gear 를 부르게 — 동작 같음) · `games/saga_forest/world/forest_wear_visual.gd`(머리·덧옷·겉옷 갑옷 붙이기, `_build_cape` 판 도형 걷어냄) · 새 `tools/scene_probes/forest_gear.gd` + `tools/probe_forest_gear.gd`(scene_probe_host 래퍼, loot_glow 와 같은 결) · `tools/shot_scene.gd`(컷 fs_wear_gat — 갓·덧옷·갑옷 근접) · `features.json`(gd.fs.wear 메모).
