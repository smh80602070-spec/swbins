# G-0059 사가고 들판 적·보스 몸을 자체툴 몬스터 GLB 로 — mon 20·boss 12 안 씀
종류: 새기능 · 고돗(사가고)      상태: 작성됨(R-0 10-07) — **선행 K 대기**: mon 20·boss 12 `.glb.import` 없음      등급 목표: D2

**목표(한 줄)**: `assets/world` 의 몬스터 몸 32벌(docs/unused_world_glb.md — `mon_` cons·quad·serp·spir·wing × 변형 넷, `boss_01~12` 같은 다섯 갈래)을 들판 적·들판/주간 보스 몸으로 배선한다. 지금 몸은 코드 짐승(creature_builder, 애니 idle/walk 둘)이고 GLB 는 뼈 없이 애니 일곱(Idle·Walk·Run·Attack·Hit·Death·Special)이라 걷기·공격·맞기·죽기가 몸으로 보인다.

**선행(K)**: mon·boss 32 만 `.glb.import` 가 없다(K-0043 몸 교체 뒤 — 다른 묶음 308 은 있음). 고돗 갈래는 `.import` 를 만들지 않는다 → K 가 임포트해 커밋한 뒤 시작. 시작 전 `ls saga-godot/assets/world/mon_cons_01.glb.import` 로 확인, 없으면 "선행 K 대기" 한 줄로 끝.

**파일**: `games/saga_go/combat/field_enemy.gd`(KINDS 에 `"glb": "<갈래>"`·`_build_visual` GLB 갈래·`_play` 이름 짝·공격/맞기/죽기 애니) · 새 `saga_core/world/monster_body.gd`(정적: 경로 고르기·불러오기·키 맞춤·AnimationPlayer 이름 짝 — Idle/Walk/Run/Attack/Hit/Death/Special) · 새 `tools/probe_monster_body.gd`(GO 장면 점검) · `games/saga_go/world/test_village.gd`(SAGA_MONSTER_BODY_PROBE 한 줄) · `tools/shot_scene.gd`(컷 go_monsters) · `features.json`.

**짝(정함)**: 갈래 = 모양 — wolf·thunder_cat·ice_fox·rock_bear → quad · wind_hawk → wing · grass_snake → serp · fire_imp → spir · water_turtle → cons. 변형 01~04 = 개체 이름 해시 % 4(도적 몸 고르기 VroidBody.build_pool 과 같은 결). 보스(hp ≥ 3000 이고 `vroid` 아닌 KINDS): 같은 갈래 boss_ 를 KINDS 순서대로 돌려 준다(storm_serpent → serp boss_06, gale_roc → wing boss_04, tide_turtle → cons boss_08, ember_king → spir boss_10, snow_bear_king → quad boss_01 … 나머지도 같은 규칙). 사람 몸 보스(vroid)·도적은 그대로.

**단계**
1. monster_body.gd: `path_for(kind_def, name)`·`build(path, height)`(GLB 씬 인스턴스 → 키 = def.height 로 맞춤, 발이 0) · `anim_name(player, want)`(소문자 "idle"/"walk" → 대문자 짝).
2. field_enemy.gd: `def.has("glb")` 면 GLB 몸, 없으면 지금 코드 짐승(되돌릴 길). 환경 `SAGA_CODE_CREATURES=1` 이면 전부 코드 짐승(전후 비교 촬영용). 예고(tell)엔 Attack, 맞으면 Hit, 죽으면 Death 한 번. 원소 적은 머리 위 원소 점이 이미 있으니 몸 빛은 안 넣는다.
3. 점검 monster_body: ① 짝 표의 여덟 종 + 보스 다섯이 GLB 몸(메시 이름이 mon_/boss_) ② AnimationPlayer 에 Idle·Walk·Attack·Hit·Death ③ 키가 def.height ±10% ④ 변형이 개체 이름마다 갈림(같은 종 넷 이상 세우면 서로 다른 변형 ≥ 2) ⑤ SAGA_CODE_CREATURES=1 면 코드 짐승.
4. 촬영 go_monsters: 플레이어 앞에 여덟 종을 줄 세워(shot_scene static 단계로 field_enemy 세우기) 전(SAGA_CODE_CREATURES=1)·후 두 장.

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=monster_body,combat_feel,field_combat,field_bosses,weekly_boss,adventure   → fails=0
SHOT_DIR=<절대 경로> SHOT_ONLY=go_monsters "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1 (SAGA_CODE_CREATURES=1 로 한 번 더)
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 기존 전투 점검 fails=0 · 세이브 폴더 앞뒤 같음 · 에셋·.import 변경 0.
