# G-0022 고돗 인물 299명(K-0024)을 NPC·손님·군중에 연결 — `characters_dex` 설치부터
종류: 새기능 · 고돗      상태: **코드분 끝**(2026-10-04) — 사용자 눈 대기      등급 목표: D1

**목표(한 줄)**: 웹이 쓰는 인물 299명(`saga-assets/characters/web3d/dj_*.glb`, VRoid 샘플 옷 이식본)을 고돗도 같은 몸으로 쓴다. 도감 105 주역은 기존 VRoid 몸 그대로, 이 티켓은 그 밖의 사람(마을 행인·상인·병사·인간형 적).

**먼저 할 일 — 다른 PC 는 인물 파일이 없다(저장소 밖)**: 웹 GLB 는 Meshopt+WebP 압축이라 Godot 이 못 읽는다. 변환본 `saga-godot/assets/characters_dex/`(299 × `<id>.gltf`+`.bin`+`.license.json`, 공용 `tex/`, 546MB)는 `saga-godot/.gitignore` 에 있어 **PC 마다 한 번 만든다**.
```
git pull
cd tools/glb-compress && npm install && cd ../..      # node_modules 는 저장소에 없다
bash tools/char-forge/engine_characters.sh --install godot     # 변환(몇 분) + saga-godot/assets/characters_dex 로 복사
```
Node 만 쓴다(Blender·GPU 불필요). 이미 변환된 건 건너뛰니 다시 돌려도 안전. `.import` 는 엔진을 한 번 열어 만든다(다른 세션이 엔진을 쓰는 중이면 먼저 확인).

**파일(확인함)**: `tools/char-forge/engine_characters.sh`·`tools/glb-compress/decode.mjs`(변환) · 인물 id·조합 규칙 `tasks/tools/K-0024.md` · 동작 클립은 `tools/char-forge/_out/vroid/<id>/<id>_anims.glb`(로컬 산출, `vroid_batch.sh` 18종, 같은 J_Bip 뼈 이름이라 그대로 붙는다) · 군중 조합표 `tools/char-forge/data/npc_swap_plan.json`(K-0033, 굽기 전) · 고돗의 NPC 자리 `grep -rln "VroidBody\|npc" saga-godot/games`.

**현황(R-0 조사)**: 몸을 고르는 곳은 **`saga_core/world/vroid_body.gd::build(id, rarity, cloth_override)` 한 곳** — `BODIES`(`assets/characters_cf/npc_*` 6종)에서 `_hash(id) % 6`, 머리·옷색 `_tint`(공방 몸은 옷 그림이 어두워 `boost`). 부르는 쪽: `npc_builder.gd:111`(마을 주민, rarity 2) · `region2_coast.gd:444`(어부) · `story_quest.gd:348·513`(이야기 인물·도둑) · `story_npc_body.gd`(사가스토리) · 주역 `hero_encounter`·`dungeon_hero_encounter` · 인간형 적 `field_enemy.gd:664~673`·`bandit_encounter.gd:174`(`cloth_override` 로 무리 색을 묶고 마스크·왕관을 붙임). "군중"이라 부를 별도 시스템은 없다(주민 NPC 가 곧 군중).
**동작**: dex 몸 glTF 에는 동작이 없다. VRoid 뼈 이름(`J_Bip_*`)이 같아 `assets/characters_vroid/anim_cc0/*_lib.res`(idle·walk·sprint 등, 10벌 동일 구성)를 `AnimationPlayer` 에 붙이면 된다 — `_out/vroid` 가 없는 PC 도 가능. K-0059 의 새 이동 클립(jump·climb …)은 이 티켓 범위 밖(플레이어 몸 몫, 별도 티켓).

**설계 결정**: ① `assets/characters_dex` 는 저장소 밖이라 없는 PC 가 있다 → **폴더가 없으면 지금 `BODIES` 6종으로 물러선다**(regress·점검이 설치 없이도 통과해야 한다). ② 대상은 **마을 주민·어부·이야기 인물(비주역)·사가스토리 NPC**. 인간형 적·도적은 `cloth_override` 색 신호·마스크 때문에 이번엔 제외(옛 `BODIES` 유지). 주역(도감 105)은 기존 VRoid 그대로. ③ dex 몸은 옷·머리가 텍스처로 이미 입혀져 있어 `_tint`(곱하기)·`boost` 를 **걸지 않는다**(색이 탁해짐). rarity 5 금 테두리만 유지. ④ id→몸은 해시로 정하되 `DirAccess` 로 읽은 정렬 목록(`*.gltf`)을 쓴다 — 목록이 바뀌어도 같은 id 가 늘 같은 몸이도록 299개 이름 정렬 고정. ⑤ draw call 예산: 몸당 메시 조각 수·뼈 91~272 를 먼저 재고(마을 동시 주민 수 × 조각 수), 넘으면 `tune_lod`·표시 거리 컷을 건다(PERF 마을 ≤260 draw·삼각형 평균 ≤35만).
