# G-0022 고돗 인물 299명(K-0024)을 NPC·손님·군중에 연결 — `characters_dex` 설치부터
종류: 새기능 · 고돗      상태: **초안**(2026-10-04, 자체툴 세션이 남김) — R-0 필요(고돗 세션이 단계·검증 완성)      등급 목표: D1

**목표(한 줄)**: 웹이 쓰는 인물 299명(`saga-assets/characters/web3d/dj_*.glb`, VRoid 샘플 옷 이식본)을 고돗도 같은 몸으로 쓴다. 도감 105 주역은 기존 VRoid 몸 그대로, 이 티켓은 그 밖의 사람(마을 행인·상인·병사·인간형 적).

**먼저 할 일 — 다른 PC 는 인물 파일이 없다(저장소 밖)**: 웹 GLB 는 Meshopt+WebP 압축이라 Godot 이 못 읽는다. 변환본 `saga-godot/assets/characters_dex/`(299 × `<id>.gltf`+`.bin`+`.license.json`, 공용 `tex/`, 546MB)는 `saga-godot/.gitignore` 에 있어 **PC 마다 한 번 만든다**.
```
git pull
cd tools/glb-compress && npm install && cd ../..      # node_modules 는 저장소에 없다
bash tools/char-forge/engine_characters.sh --install godot     # 변환(몇 분) + saga-godot/assets/characters_dex 로 복사
```
Node 만 쓴다(Blender·GPU 불필요). 이미 변환된 건 건너뛰니 다시 돌려도 안전. `.import` 는 엔진을 한 번 열어 만든다(다른 세션이 엔진을 쓰는 중이면 먼저 확인).

**파일(확인함)**: `tools/char-forge/engine_characters.sh`·`tools/glb-compress/decode.mjs`(변환) · 인물 id·조합 규칙 `tasks/tools/K-0024.md` · 동작 클립은 `tools/char-forge/_out/vroid/<id>/<id>_anims.glb`(로컬 산출, `vroid_batch.sh` 18종, 같은 J_Bip 뼈 이름이라 그대로 붙는다) · 군중 조합표 `tools/char-forge/data/npc_swap_plan.json`(K-0033, 굽기 전) · 고돗의 NPC 자리 `grep -rln "VroidBody\|npc" saga-godot/games`.

**단계(초안)**
1. 현황: 고돗 NPC·손님·군중 자리(판·수)와 지금 쓰는 몸 표, 299 id 를 나누는 방법(해시로 고르기) 정하기.
2. 위 설치가 된 PC 에서 `characters_dex` 가 읽히는지(임포트·스킨·텍스처) 한 벌로 확인 → 몸 불러오는 코드(`UniqueBodyPicker` 류)와 NPC 자리 연결.
3. 진단·창 모드 촬영 한 컷, 사용자 눈.

**검증**: `bash saga-godot/tools/godot_regress.sh` REGRESS OK · `check_refs.sh` 깨짐 0 · `bash tools/precheck.sh`(파이프 금지) OK.
