# G-0009 그래픽 기준 촬영 폴더 + 차이 수치
종류: 측정 · GO 먼저      상태: **작성됨**      등급 목표: (체제) — SAGA-ARCH §4.5 그래픽 게이트

**목표(한 줄)**: GO 네 컷(마을·포구·폐허·고원)의 **기준 촬영 폴더 구조와 비교 도구**를 만든다. 새 촬영과 기준의 차이를 SSIM·히스토그램 숫자로 내고 문턱을 넘으면 종료 1. **이 티켓은 도구까지 — 게임 스크린샷은 한 장도 안 찍는다**(루트 CLAUDE.md "작업 중 스크린샷 금지, 사용자 요청 때만"). 첫 기준 촬영·승인은 사용자가 "기준 촬영" 을 요청한 세션.

**측정**: 이 PC 에 `py` 없음(메모 `reference_no_py_this_pc`) → 도구는 **node `.mjs`**(zlib 내장으로 PNG 직접 읽기, 의존 0). `probe_shots.gd` 는 `SHOTS` 표(이름·지역…)에서 컷을 고르고 `SAGA_SHOT_ONLY=이름,…`·`SAGA_SHOT_DIR` 를 받으며 파일을 `<이름>_<W>x<H>.png`(창 모드, `--resolution 1280x720`)로 쓴다. 네 컷 이름(표에 있음): `v_village_plaza`(마을) · `c_sea`(포구) · `r_statue`(폐허) · `f_pass_view`(고원).

**파일**: `saga-godot/tools/shot_diff.mjs`(새) · `saga-godot/tools/shot_baseline.sh`(새, 촬영 명령 래퍼 — 이 티켓에선 실행 안 함) · `saga-godot/graphics/baseline/go/.gitkeep`(새) · `docs/HOW_TO_PLAYTEST.md` 두 줄

**본보기**: `tools/probe_all.sh`·`check_refs.sh` 의 머리 주석·종료 코드 형식 · 촬영 명령은 `probe_shots.gd` 3~6행.

**단계**
1. `shot_diff.mjs <기준폴더> <새폴더>`: 두 폴더의 `<이름>_*.png` 를 이름으로 짝지어(해상도 다르면 종료 2) 컷마다 한 줄 — `이름 ssim=0.xxx hist=0.xxx mad=0.xxx OK|FAIL`. SSIM = 회색조 8×8 블록 평균(C1=6.5025·C2=58.5225), hist = RGB 32구간 정규화 L1 거리의 평균(0~1), mad = 평균 절대차/255. 문턱 기본 `ssim<0.90 또는 hist>0.15` → FAIL(`--ssim=` `--hist=` 로 조정). 한쪽에만 있는 컷은 FAIL. 마지막 줄 `SHOT_DIFF fails=N cuts=M`, N>0 이면 종료 1. PNG: 8비트 RGB/RGBA 비인터레이스(필터 0~4 전부).
2. `shot_diff.mjs --selftest`: 임시 폴더에 합성 PNG(그라디언트+도형)를 직접 써서 ① 같은 그림 → ssim=1.000 ② 약한 잡음 → OK ③ 색 반전 → FAIL ④ 크기 다름 → 종료 2 를 확인하고 `SELFTEST OK`.
3. `shot_baseline.sh <출력폴더>`: 네 컷만(`SAGA_SHOT_ONLY=…`) 창 모드로 찍는 명령 한 벌(GODOT 환경변수·`--position -4000,0`·전용 폴더, 끝나면 그 PID 만 정리). 실행 방법만 `HOW_TO_PLAYTEST.md` 에 두 줄.

**검증**
```
node saga-godot/tools/shot_diff.mjs --selftest   → SELFTEST OK
bash -n saga-godot/tools/shot_baseline.sh         → 구문 오류 0
```
**완료 조건**: 위 둘 · 게임 실행·촬영 0 · `graphics/baseline/go/` 에 PNG 0(.gitkeep 만).

**불변 규칙**: 게임 코드·`probe_shots.gd` 수정 0 · 기준 PNG 는 사용자 승인 전엔 안 커밋.
