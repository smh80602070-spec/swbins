# G-0057 사가고 사진 모드 — HUD 없이 찍고, 워터마크, 찾을 수 있는 폴더에 저장
종류: 새기능 · 고돗      상태: **진행중**(2026-10-07)      등급 목표: D2

**목표(한 줄)**: SAGA-BACKLOG §4.1 "사진 모드 공유 — 워터마크·저장만(서버 없음)". 지금 사진(photo_mode_button.gd)은 ① MobileHUD 만 숨겨 목표판·미니맵·위쪽 단추 등 다른 HUD 층이 같이 찍히고 ② 워터마크가 없고 ③ 숨은 앱 폴더 user://photos 에 저장돼 사용자가 못 찾는다. 찍는 한 프레임 동안 모든 CanvasLayer 를 숨기고, 오른쪽 아래에 "사가고 · 지역 · 날짜" 워터마크를 얹어 찍고, PC 는 사진 폴더/사가고 에 저장한다(폰은 그대로 user://photos).

**파일**: `games/saga_go/ui/photo_mode_button.gd`(photo_dir·watermark_text·_hide_layers/_restore_layers·워터마크 층·찍기 흐름) · 새 `tools/probe_photo.gd`(GO 장면 점검) · `games/saga_go/world/test_village.gd`(SAGA_PHOTO_PROBE 한 줄) · `tools/shot_scene.gd`(컷 go_photo — SAGA_PHOTO_DIR 로 스크래치에 저장) · `docs/HOW_TO_PLAYTEST.md`(사진 줄).

**단계**
1. `photo_dir()`: 환경 SAGA_PHOTO_DIR → PC 면 OS 사진 폴더/사가고 → 아니면 user://photos. `watermark_text(pos)`: "사가고 · <지역 이름> · YYYY-MM-DD".
2. 찍기: 보이는 CanvasLayer 를 다 숨기고 워터마크 층만 켠 채 frame_post_draw 를 기다려 화면을 읽고, 되돌린 뒤 사진 도감(go_album) → 저장.
3. 점검 photo: ① 환경 경로가 이긴다 ② 워터마크 글(지역·날짜) ③ 숨기기→되돌리기 뒤 층 보임 그대로(원래 숨은 층은 숨은 채) ④ 워터마크 층은 평소 숨김.
4. 촬영: 사진 모드 켜고 찍기 → 저장된 PNG 를 본다(HUD 없음·워터마크).

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=photo,album   → fails=0
SAGA_PHOTO_DIR=<절대 경로> SHOT_DIR=<절대 경로> SHOT_ONLY=go_photo "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=1 + 사진 PNG 하나
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 세이브 폴더 앞뒤 같음 · 사용자 사진 폴더에 시험 파일 안 남김.
