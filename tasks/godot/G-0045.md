# G-0045 네 판 화면 촬영 도구 + 사가의숲 못 본 화면 넷 판정(주민·집 안 벽지/장판·가구·낚시)
종류: 측정 · 고돗      상태: 진행중      등급 목표: D3

**목표(한 줄)**: 시트 `tasks/sheets/godot-four-20261006.md` 의 "화면 못 봄" △ 는 GO 전용 `tools/probe_shots.gd` 로는 못 찍는다(사가고 마을 씬에 붙는 노드). 아무 판 씬이나 띄워 노드 경로로 플레이어를 옮기고·함수를 불러·찍는 SceneTree 촬영 도구를 만들고, 사가의숲 villagers·wallpaper·furniture·fishing 을 먼저 판정한다. 흠은 고치지 않고 이유만.

**파일**: 새 `tools/shot_scene.gd`(본보기 `tools/probe_shots.gd` — 컷 표·SHOT_ONLY·SHOT_DIR 규칙 같게) · 시트 네 줄 · `features.json`.

**단계**
1. `shot_scene.gd`: 컷 표 [이름, 씬, 단계들] — 단계 `near:<노드 경로>:<dx>:<dz>`(그 노드 곁에 플레이어) · `touch:<노드 경로>:<함수>`(플레이어를 넘겨 부름 — 영역 들어감 흉내) · `call:<노드 경로>:<함수>`. 컷마다 씬을 새로 띄우고 30프레임 뒤 단계, 120프레임에 찍는다. 저장은 안 한다.
2. 숲 컷: fs_villager(관리인 곁 — 말풍선) · fs_house_in(집 안) · fs_finish_menu(벽지·장판 가게) · fs_place_menu(가구 놓기) · fs_fishing(낚시터 곁).
3. 찍어 보고 시트 ○(C) → features D3, 아니면 △ 이유.

**검증**
```
SHOT_DIR=<절대 경로> SHOT_ONLY=fs_villager,fs_house_in,fs_finish_menu,fs_place_menu,fs_fishing "$GODOT" --path saga-godot --rendering-method mobile --position -4000,0 --resolution 1280x720 --script res://tools/shot_scene.gd   → SHOT_SCENE_DONE shots=5
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=forest_rules,forest_world,save_forest   → fails=0
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~3 · 게임 코드 변경 0 · 세이브 파일 앞뒤 같음.
