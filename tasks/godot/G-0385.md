# G-0385 1만리 열 지역 구역째 짓기 — 지금 지역만 켜기(폰 발열, 웹 W-0414 ② 짝)
종류: 체제(성능) · 고돗(1만리)      상태: 대기(10-25 오퍼스 R-0 — 수신함 맵 나눔, G-0384 뒤)      등급 목표: D2

**까닭**: `games/saga_go/world/test_village.gd _ready` 가 열 지역(village·coast·ruins + region4_frost~region10_fork)을 처음에 한꺼번에 짓고 늘 켜 둔다 — 멀리 있는 지역도 노드·_process·그림자 후보로 남는다(발열 1순위 후보). 지역 판별은 이미 있다: `data/test_map.gd region_at(world)`.

**목표(한 줄)**: 주인공이 선 지역 + 맞닿은 지역만 켜고(visible·process_mode), 나머지는 `PROCESS_MODE_DISABLED`+숨김 — 지역이 바뀌면 G-0384 막을 덮고 켜고/끄고 → 걷음. 경계는 이미 있는 고개·안개(먼 지역 실루엣은 G-0184 landmark_reads 가 맡음).

**파일**: 새 `games/saga_go/world/go_zone_gate.gd`(지역 노드 표 · `_process` 는 0.5초마다 region_at 한 번 · 맞닿음 표는 origin_of·size 로 계산 · 손잡이 SAGA_ZONE_SPLIT=0 끔) · `world/test_village.gd`(지역 노드를 gate 에 등록 한 줄씩 + 붙임 한 줄) · 새 `tools/probe_go_zone_gate.gd`(마을 → 포구 → 서리봉 옮기며 켜진 지역 수·막 1→0) · `tools/probe_perf.gd`(지역별 보고에 켜짐/꺼짐 같이 — 손대지 않아도 되면 그대로).

**단계**: ① 지역 노드 묶기(지역 짓는 스크립트가 한 노드 아래에 짓는지 확인 — 땅 타일·덤·풀(grass_field·field_clutter 는 카메라 둘레라 그대로) 따로 짓는 것은 지역 id 로 표에) ② gate + probe ③ 들판 적·보스·의뢰가 꺼진 지역에서 멈췄다 돌아와도 상태 그대로인지(field_spawner·field_bosses) ④ `probe_perf` 창 모드 전후(마을 한가운데 그리기 수·노드 수) — 줄었는지 숫자로.

**검증**: `"$GODOT" --headless --path saga-godot --script res://tools/probe_go_zone_gate.gd` OK · `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=go_zone_gate,hunt,field_env,field_bosses,landmark_reads,adventure,combat_feel` 0 · probe_perf 전후 숫자 티켓 메모에.

**완료 조건**: 점검 0 · 마을에서 켜진 지역 ≤ 4 · perf 전후 숫자 · done/.

**불변 규칙**: 세이브 안 바꿈 · 지역 모양·좌표 안 바꿈 · 적 수치 안 바꿈 · 에셋 안 만듦 · 순간이동(waypoints)은 도착 지역을 먼저 켠 뒤 옮김.

**메모**: 웹은 576m 정사각 구역, 고돗은 지역 격자가 이미 있으니 지역 = 구역. 카메라를 구역 안에 묶지 않음(웹 ③ 안 함과 같음 — 경계에서 앞이 안 보임).
