# G-0119 탈것 키 V·B 가 사가나락·사가종횡·사가만리 기존 키와 겹침
종류: 버그 · 고돗(공통 saga_core/player/mount.gd)      상태: 작성됨(키 고르기 사용자 결정)      등급 목표: D2

**목표(한 줄)**: G-0118 감사(소넷 64fe24c66·cec419762). mount.gd 가 `go_mount`=V·`go_mount_next`=B 를 다섯 판에 똑같이 단다 → 사가나락 V=기술 4(돌진)·B=기술 5(버프), 사가종횡 V=직업 기술 4·B=직업 기술 2-1, 사가만리 V=원소 시야(키보드)·B=가방. 한 번 누르면 둘 다 일어난다. 판마다 비어 있는 키로.

**파일**: `saga-godot/saga_core/player/mount.gd`(판별 키 표 — 부르는 플레이어가 넘기거나 씬 경로로) · `saga-godot/project.godot`(입력 표 확인만) · `saga-godot/games/saga_go/data/help.gd`·`docs/HOW_TO_PLAYTEST.md`(키 글) · `saga-godot/tools/probe_mount.gd`(판마다 탈것 키가 다른 동작과 안 겹침) · 이 티켓

**단계**
1. 판별 빈 키 목록(project.godot `[input]` + 코드 `_ensure_action`·`physical_keycode`): 사가나락은 글자·숫자·F1~F12·기호 거의 다 씀 — 남는 것 `-` `=` `'` 정도. 사가종횡은 `[` `]` `\` `` ` `` · 사가마을은 V·B 그대로 비어 있음 · 사가만리는 코드 키 다시 셈.
2. 사용자에게 판별 키 제안(예: 나락 `=`/`-`, 종횡 `]`/`[`, 만리 `G`?) — 결정 받기.
3. mount.gd 에 판별 키, 점검: 다섯 판 입력 표에서 탈것 키와 같은 physical_keycode 를 가진 다른 동작 0.

**검증**: `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=mount,help,dungeon_skills,story_player` fails=0 · `bash tools/precheck.sh` OK.

**완료 조건**: 다섯 판 어디서도 탈것 키가 다른 동작과 안 겹침(점검) · 도움말 글 맞음.

**불변 규칙**: 기존 기술 키 안 옮김 · 패드 배치(gamepad.gd) 안 바꿈 · 세이브 안 건드림.
