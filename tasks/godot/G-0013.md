# G-0013 Godot 에셋 적용 — 배경음 네 판 연결 + 옷 무늬 읽기 + `.import`
종류: 새기능 · 에셋 적용 · 고돗      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2

**목표(한 줄)**: (1) `saga-godot/assets/audio/bgm/` 에 이미 들어간 곡 15(`<판>-<장면>.ogg`, 키 = 파일 이름)를 사가블로·사가의숲·사가스토리·사가국지 장면에서 `Bgm.play` 로 틀게 한다(사가고 `go-town`·`go-field` 는 `world/go_bgm.gd` 로 연결돼 있음, `go-battle` 도 전투에서). (2) `world/wardrobe.gd` 가 `assets/wardrobe/patterns/patterns.json`(64장)을 읽어 옷 변형에 무늬를 입힌다. (3) 새 파일의 `.import` 를 Godot 에서 만든다.

**파일(확인함)**: `saga-godot/saga_core/audio/bgm.gd`(규약: `Bgm.play(self, "<판>-<장면>")`, 곡 없으면 조용) · `games/saga_go/world/go_bgm.gd`(본보기) · 장면 스크립트 후보 `games/saga_dungeon/world/test_room.gd`·`games/saga_forest/world/`·`games/saga_story/world/`·`games/saga_realm/`(어느 줄에 붙일지는 단계 1에서 확인) · `games/saga_go/world/wardrobe.gd` · `assets/wardrobe/patterns/*.webp`·`patterns.json` · `tools/probe_bgm.gd`

**단계**
1. 판별 장면 스크립트에서 "마을/들판/전투" 를 가르는 상태(예: dungeon 의 `horde`·보스, realm 의 전투 카드)를 찾아 키를 정한다. 키 목록은 `ls assets/audio/bgm/*.ogg`.
2. `go_bgm.gd` 꼴로 판별 연결 노드(또는 한 줄) 추가. 곡 키가 파일에 있는지 `probe_bgm.gd` 에 한 줄.
3. `wardrobe.gd` 에 `patterns.json` 로더(없으면 지금 그대로). 시대 20/20/20/4 중 인물 시대에 맞는 것 선택.
4. Godot 를 한 번 열어 `.import` 생성(오디오 15 + 무늬 64) 후 함께 커밋 — Godot exe 가 없으면 이 단계만 Godot 세션에 넘긴다(메모).

**검증**: `bash saga-godot/tools/godot_regress.sh`(GODOT=콘솔 exe) REGRESS OK · `probe_bgm.gd` 15키 모두 열림 · `audit.py --quick` pair 🟡 0(해당 폴더) · `precheck.sh` OK.

**완료 조건**: 단계 1~4 · 다섯 판 장면에서 곡이 바뀜(사용자 확인 시트) · 무늬 입힘.

**불변 규칙**: 세이브 키 불변 · 이름 정책 · 큰 파일 상한 · 사용자 확인 전 소리 크기 기본값(`BASE_DB`) 안 바꿈.
