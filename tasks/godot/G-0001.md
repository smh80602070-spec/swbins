# G-0001 `tools/probe_all.sh` + 네 판 세이브 왕복 probe
종류: 닫기      판: DUNGEON·FOREST·STORY·REALM(+GO 기존)      등급 목표: D1 — 네 판 첫 자동 진단

**목표(한 줄)**: probe 61개(전부 GO)를 한 명령으로 돌려 fails 합계를 내고, 나머지 네 판에 "세이브 왕복·마이그레이션" SceneTree probe 를 하나씩 붙인다.

**파일**: `saga-godot/tools/probe_all.sh`(새) · `tools/probe_save_dungeon.gd`·`probe_save_forest.gd`·`probe_save_story.gd`·`probe_save_realm.gd`(새 4) · `docs/HOW_TO_PLAYTEST.md`(명령 두 줄 추가)

**본보기**: `saga-godot/tools/probe_wardrobe.gd`(`extends SceneTree`, `check()`, 끝에 `PROBE <이름> OK`/fails) — 그대로 베낀다. 실행은 `"$GODOT" --headless --path saga-godot --script res://tools/probe_save_dungeon.gd`.
GO 씬 probe 는 `SAGA_<이름>_PROBE=1 "$GODOT" --headless --path saga-godot res://games/saga_go/world/TestVillage.tscn`(`test_village.gd` 25행 PROBES 목록이 이름 정본).

**단계**
0. `git status --short saga-godot` — 내 것이 아닌 미커밋 파일(`orientation_scale.gd` 등)은 건드리지 않는다.
1. `probe_all.sh`: `GODOT` 환경변수 필수(`godot_regress.sh` 와 같은 방식). ① `test_village.gd` 의 `PROBES` 배열을 grep 으로 읽어 GO 씬 probe 실행, 로그의 `fails=(\d+)` 또는 `FAIL` 줄 수를 센다 ② `tools/probe_*.gd` 중 `extends SceneTree` 인 것은 `--script` 로 실행 ③ 표 한 줄씩 `이름 fails=N 초` · 끝에 `PROBE_ALL fails=합계 probes=개수` · 합계 0 이면 종료 0 · 결과를 `tools/_out/probe_all.json` 에도. 타임아웃 probe 당 180초(`timeout 180`). `--only=<이름,…>` 로 골라 돌리기.
2. `probe_save_<판>.gd` 넷: 그 판 `data/<판>_save_state.gd` 를 preload → ① `save()` 가 요구하는 인자를 만들 수 없으면 내부 dict 조립 함수(`grep -n "^func _collect\|^func build\|\"version\": SAVE_VERSION" <파일>`)를 부른다 ② `user://` 임시 경로에 쓰고 다시 읽어 `version == SAVE_VERSION` ③ `version = 1` 인 최소 dict 를 `_migrate()` 에 넣어 null 이 아니고 version 이 SAVE_VERSION 이 되는지 ④ 이 빌드보다 높은 version 은 거부(null) ⑤ 끝에 임시 파일 삭제. 각 5 check.
3. `HOW_TO_PLAYTEST.md` 맨 위 "자동 점검" 절에 `bash tools/probe_all.sh` 와 `--only` 두 줄.

**검증**
```
GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=save_dungeon,save_forest,save_story,save_realm   → 네 줄 fails=0, PROBE_ALL fails=0
bash saga-godot/tools/godot_regress.sh                                                                           → REGRESS OK (project.godot·*.import 잡음은 되돌린다)
```
전체 61개 실행은 R-1 에서(15분 넘음).

**완료 조건**: 위 둘 · probe 넷 각 5 check · `probe_all.sh` 가 GO 이름 목록을 하드코딩하지 않고 `test_village.gd` 에서 읽는다.

**불변 규칙 확인**: 게임 스크립트 수정 0 · 실제 세이브(`user://save_*.json`) 안 건드림(임시 경로만) · `--headless --editor` 안 씀 · 백그라운드 Godot 는 `</dev/null`(메모리: stdin 없으면 멈춤).
