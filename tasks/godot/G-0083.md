# G-0083 사가만리 장비 외형 — 갑옷 조각을 VRoid 몸 비율에 맞춤(K-0081 규약 `fit.chest`·`hide_match`)
종류: 버그 · 고돗(사가만리)      상태: 작성됨(R-0 페이블 2026-10-07)      등급 목표: D2

**목표(한 줄)**: 수신함 10-07(K-0081 산출) — 가슴판이 허리~턱을 덮는 상자처럼 커 보이던 것(G-0060 촬영 관찰)을 K 가 VRoid 실측으로 다시 지었고 붙일 때 규약 두 칸을 더했다. `tools/world-forge/data/equip_slots.json` 의 ① `fit.chest`(가슴판만 X 배율 × 어깨 폭/k/0.145, 0.75~1.15 로 자름; 어깨 폭 = |J_Bip_L_UpperArm.x − J_Bip_C_Chest.x|) ② `hide_match`(입은 슬롯의 hides 칸 → 재질 이름에 `_Hair_`·`_Shoes_` 가 든 몸 메시 숨김; 상의·소매·바지는 빈칸) 을 고돗 붙이기 코드에 적용한다. 확인 렌더 도구 `tools/char-forge/render/render_equip_fit.py` 와 같은 규칙.

**파일**: `saga-godot/saga_core/world/bone_gear.gd`(36행 `body_scale`·44행 `attach`·58행 `_put` — `model.scale` 에 X 배율 인자) · `saga-godot/games/saga_go/player/armor_visual.gd`(45행 `pieces_for` — 조각마다 `fit`·`hides` 를 equip_slots 에서 읽어 넘김 · 57행 `attach` · 72행 `clear` 에서 숨긴 메시 복원) · `saga-godot/tools/shot_scene.gd`(컷 장비 외형 — G-0060 때 컷 이름은 단계 1 `grep -n "gear\|armor" tools/shot_scene.gd`) · `saga-godot/features.json`(장비 외형 항목 note)
※ `equip_slots.json` 은 K 정본 — **읽기만**(고돗이 복사본을 두지 않고 `res://` 밖이면 `tools/world-forge/data/equip_slots.json` 을 빌드 때 `assets/world/equip_slots.json` 로 놓는 K 배치가 있는지 단계 1 `ls saga-godot/assets/world | grep equip` 로 확인, 없으면 K-0081 메모의 값 둘을 상수로 적고 출처 주석).

**단계**
1. `pieces_for`: 슬롯 표에서 `fit`(chest 만 참)·`hides`(재질 이름 조각 배열) 를 조각 사전에 넣는다.
2. `bone_gear._put`: `k` 외에 `kx`(가슴판이면 어깨 폭/k/0.145 를 0.75~1.15 로 자른 값, 아니면 1) → `model.scale = Vector3(±k*kx, k, k)`. 어깨 폭은 `skel.get_bone_global_rest(J_Bip_L_UpperArm).origin.x − …Chest.origin.x` 절댓값.
3. `hide_match`: 몸의 `MeshInstance3D` 재질 이름(`get_active_material(i).resource_name`)에 hides 조각이 들면 그 surface 를 투명 재질로 바꾸거나 `visible=false`(메시 하나에 표면 여럿이면 표면 단위 — `set_surface_override_material`). `clear()` 가 되돌린다(원 재질을 메타에 보관).
4. 촬영 전·후 두 장(기본 몸 + 가슴판·투구·장화) → Claude 가 Read 로 보고 상자 꼴 사라짐·머리카락/신발 뚫림 없음 ○△× → features note · 큐 줄 · 메모.

**검증**: `GODOT=<콘솔 exe> bash saga-godot/tools/probe_all.sh --only=wardrobe` 또는 장비 probe 이름(단계 1 `ls tools/probe_*.gd | grep -i "gear\|armor\|equip"`) `fails=0` · 촬영 두 장 판정 · `bash tools/precheck.sh` OK.

**완료 조건**: 가슴판 X 배율이 몸마다 0.75~1.15 안 로그 · 머리카락·신발 숨김 동작 · `clear()` 뒤 몸 원상 · 촬영 ○.
