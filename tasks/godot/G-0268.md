# G-0268 mount_* 점검의 "p_scene" ERROR — mount_host 가 current_scene 을 손자에 걸음
종류: 버그(도구) · 고돗(tools)      상태: **작성됨**(오퍼스 R-0 10-21 — G-0264·G-0266 메모 "mount_* p_scene ERROR 는 기존 것")      등급 목표: D1

**목표(한 줄)**: `probe_all.sh --only=mount_dungeon,mount_forest,mount_story` 는 fails=0 이지만 로그 첫머리마다 `ERROR: Condition "p_scene && p_scene->get_parent() != root" is true. at set_current_scene … mount_host.gd:19` 가 난다(10-21 재현 셋 다). 대상 씬을 host 의 자식으로 단 채 `current_scene` 에 걸어서다 — 대상 씬은 current_scene 이 아니게 남아 `get_tree().current_scene` 을 쓰는 코드가 host 를 보게 된다. 대상 씬을 root 아래로 달아 ERROR 0.

**파일(확인함 10-21)**: `saga-godot/tools/mount_host.gd` 12~19 `_ready`(17 instantiate·18 `add_child`·19 `current_scene`)·20~21 물리 30 프레임 · `tools/mount_host.tscn` · `tools/probe_all.sh` 40·54~56(mount_* 실행·결과 줄 `MOUNT_HOST_DONE`) · 비슷한 꼴 찾기: `grep -rn "current_scene =" saga-godot/tools`.

**단계**: 1 `mount_host.gd` 18~19: `get_tree().root.add_child.call_deferred(_scene)` → `await get_tree().process_frame` → `get_tree().current_scene = _scene`(대상이 root 의 직속). host 는 그대로 남아 검사만 2 같은 꼴(`add_child` 뒤 `current_scene =`)이 tools 의 다른 host 에 있으면 같이 고침 — 없으면 메모에 "없음" 3 probe_all.sh 에 로그 ERROR 셈은 넣지 않음(다른 기존 ERROR 가 많아 범위 밖) — 대신 이 티켓 검증에서 grep.

**검증**: `GODOT=<exe> bash saga-godot/tools/probe_all.sh --only=mount_dungeon,mount_forest,mount_story,mount,gait` fails=0 · 세 로그 `grep -c "p_scene"` = 0 · `bash saga-godot/tools/check_refs.sh` 빔.

**완료 조건**: fails=0 · p_scene 0(셋) · 큐 줄 끝 · done/.   **불변**: 판 코드·씬·탈것 수치 안 고침(도구만) · 에셋 안 만듦.   **함정**: `_ready` 안에서 root 에 바로 add_child 하면 "parent busy" — 꼭 call_deferred · 대상 씬 _ready 가 이제 한 프레임 늦게 돈다 — 뒤 30 물리 프레임 대기는 그대로라 영향 없음.
