# G-0016 사가고 무기·재료 아이콘 배선 — 캐릭터 화면·요리 화면에 K-0035 그림을 쓴다(코드만)
종류: 새기능 · 고돗      상태: **작성됨**(R-0 2026-10-03) — 시작 조건: K-0035 ⑤(정본 `saga-assets/icons/` + `map.json`)와 K-0019 배치(`.import` 포함)가 올라간 뒤      등급 목표: D2

**목표(한 줄)**: 고돗 사가고의 무기 16종(`data/weapons.gd`)·요리 재료는 글자 라벨이다(`ui/character_screen.gd` 의 `_weapon_label`, `ui/cooking_screen.gd`). K-0035 아이콘(무기 열여섯 키 `gw_*`·재료 `mint`·`honey_flower`·`go_apple`·`mushroom`·`clam`·`go_orchid`·`conch`·`ash_flower`·`snow_bloom`·`meat`, 성유물 세트 `af_*` 다섯)을 `TextureRect` 로 보인다. 그림이 없는 id 는 글자만.

**파일(확인함)**: `saga-godot/games/saga_go/ui/character_screen.gd`·`ui/cooking_screen.gd` · 읽는 `data/weapons.gd`·`data/cooking.gd`·`data/artifacts.gd` · 새 `data/item_icons.gd`(id → `res://…/icons/<키>_g<등급>.png`, 지도는 정본 `map.json` 에서 옮긴 표 — 손으로 안 고침, 본보기 `data/` 의 다른 표) · 아이콘·`.import` 는 K-0019 가 놓는다(이 티켓은 안 놓는다) · 점검 `saga-godot/tools/`(`check_refs.sh`)

**단계**
1. `character_screen.gd`·`cooking_screen.gd`·성유물 화면의 글자 라벨 자리를 `grep -n "Label\|weapon\|ingredient"` 로 표로 메모. 없는 화면은 안 한다.
2. `item_icons.gd`: `icon_for(kind, id)` → `Texture2D` 또는 null(`ResourceLoader.exists` 먼저).
3. 위 화면에 `TextureRect`(64px, 등급 틀 합성본) 추가. 무기 희귀도 1·3·4 는 틀 0·1·2.
4. `godot_regress.sh` 통과(새 `class_name` 이 있으면 먼저 `godot --headless --editor --path . --quit` 한 번 — G-0015 함정).

**검증**
```
bash saga-godot/tools/check_refs.sh   → 참조 OK
bash saga-godot/tools/godot_regress.sh   → REGRESS OK(md5 불변)
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 무기·재료·성유물 화면에 그림이 뜨고 없는 id 는 글자 · 사용자 눈 확인.

**불변 규칙**: 에셋 안 만든다 · `weapons.gd` 의 id·수치 불변 · 미커밋 `orientation_scale.gd` 는 다른 세션 것.
