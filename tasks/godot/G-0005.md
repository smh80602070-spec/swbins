# G-0005 PLAN 222KB → `PLAN.md`(≤100KB) + `docs/spec/` 분할
종류: 통합 · 문서      상태: **작성됨**      등급 목표: (체제) — 문서 3층

**목표(한 줄)**: `saga-godot/PLAN.md`(222,155B·106장) 의 덩치는 `# 106.` 한 장(132KB, 표 120KB) — 그 표·이야기 부 문단을 `docs/spec/` 여섯 파일로 **그대로 옮기고** PLAN 엔 장 제목·머리글·"→ docs/spec/…" 줄만 남긴다. 내용은 지우지 않는다.

**파일**: `saga-godot/PLAN.md` · `saga-godot/docs/spec/106-a.md`~`106-e.md`·`106-story-parts.md`(새 6) · `saga-godot/docs/ARCHITECTURE.md` 는 안 건드림.

**본보기**: 없음(첫 spec). 머리는 `# 106. GO 원신 기준 — <범위>` + `> PLAN.md 106장에서 옮김(내용 불변)` 한 줄.

**측정(2026-10-01 HEAD, `LC_ALL=C awk` 바이트)**: 표 머리·구분 2941~2942, 행 2943~3054(120,311B 누계), 문단 3056~3078(이야기 부 설명 ~13KB), 3080~3081 불릿. 줄 번호는 실행 때 `grep -n "^| ① \|^| ㉒ \|^| ㉞ \|^| ㊺-1 \|^| 51-1 \|^\*\*남은 격차\|^\*\*웹 사가고" saga-godot/PLAN.md` 로 다시 잰다(다른 세션이 PLAN 을 고쳤을 수 있다).

**단계** (한 묶음 옮길 때마다 커밋)
1. `106-a` = 행 ①~㉑(2943~2977, ≈20KB) · `106-b` = ㉒~㉝(2978~2993, ≈21KB) · `106-c` = ㉞~㊹(2995~3008, ≈27KB) · `106-d` = ㊺~㊿(3009~3030, ≈27KB) · `106-e` = 51~56(3031~3054, ≈26KB). 각 파일 머리에 표 머리 두 줄(2941~2942)을 복사.
2. `106-story-parts` = 문단 3056~3078(**남은 격차**·이야기 2~11부·웹 이식). 3080~3081 불릿은 PLAN 에 남긴다.
3. PLAN 106장 자리엔: 원래 머리글(2939 문단)·불릿 둘·`- ①~㉑ → docs/spec/106-a.md` 식 여섯 줄. 장 제목 `# 106.` 줄은 그대로.
4. 옮긴 줄은 `sed -n` 으로 잘라 붙인다(손으로 안 친다). 한글은 바이트 그대로: 스크래치패드 `.mjs`(utf8 Buffer) 또는 `sed -n 'a,bp'` 리다이렉트, CRLF 유지.
