# E-0001 환경 확인 · 빈 C++ 프로젝트 · 헤드리스 컴파일 게이트

**목표(한 줄)**: 언리얼 5.8 이 이 PC 에 있는지 확인하고, 블루프린트 없는 C++ 프로젝트 `saga-unreal/SagaUnreal.uproject`(모듈 SagaCore·SagaGo)를 만들어 `bash saga-unreal/tools/ue_build.sh` 한 줄로 헤드리스 컴파일이 OK 가 되게 한다. 엔진이 없으면 사람 몫을 메모에 적고 엔진 없이 되는 부분(프로젝트 파일·소스·도구·gitignore)까지만 한다.

**파일**: `saga-unreal/SagaUnreal.uproject`(새) · `saga-unreal/Source/SagaUnreal.Target.cs`·`SagaUnrealEditor.Target.cs`(새) · `saga-unreal/Source/SagaCore/{SagaCore.Build.cs,SagaCore.h,SagaCore.cpp}`·`saga-unreal/Source/SagaGo/{SagaGo.Build.cs,SagaGo.h,SagaGo.cpp}`(새) · `saga-unreal/Config/DefaultEngine.ini`·`DefaultGame.ini`(새) · `saga-unreal/tools/ue_env.sh`·`ue_build.sh`(새) · `saga-unreal/.gitignore`(새) · `saga-unreal/docs/PROJECT_STATE.md`(새) · `tools/precheck.sh`(블루프린트 0 게이트 한 절만 추가) · 이 티켓 메모 · 큐 줄

**단계**
0. 디스크·엔진 확인: `df -h /c` · `ls "/c/Program Files/Epic Games" 2>&1` · `ls "/c/Program Files (x86)/Microsoft Visual Studio/2022/BuildTools/VC" 2>&1`. 없으면 메모에 `사람 몫: ① C: 20GB 비우기 ② Epic Games Launcher → UE 5.8 설치 ③ VS Build Tools 2022 C++ 데스크톱 워크로드 + Windows SDK + .NET 8 SDK ④ 끝나면 "사가언리얼 이어해"` 네 줄을 적고 1 로 간다(멈추지 않는다).
1. `ue_env.sh`: `UE_ROOT="${UE_ROOT:-/c/Program Files/Epic Games/UE_5.8}"`, 없으면 `echo "엔진 없음 — $UE_ROOT"; exit 0`(**0 으로** — precheck 를 막지 않는다). 개인 경로 금지.
2. 프로젝트 뼈대: `.uproject`(EngineAssociation "5.8", Modules SagaCore·SagaGo, Plugins: Interchange 켬·블루프린트 관련 추가 없음) · Target.cs 둘 · Build.cs 둘(SagaGo 가 SagaCore 의존) · 모듈 h/cpp 는 `IMPLEMENT_MODULE`/`IMPLEMENT_PRIMARY_GAME_MODULE` 만. `DefaultEngine.ini`: `r.DynamicGlobalIlluminationMethod=0`·`r.ReflectionMethod=0`(Lumen 끔)·`r.Nanite=0`·기본 맵 비움. `DefaultGame.ini`: ProjectName SagaUnreal.
3. `ue_build.sh`: `source ue_env.sh` → `"$UE_ROOT/Engine/Build/BatchFiles/Build.bat" SagaUnrealEditor Win64 Development -Project="$(cygpath -w "$PWD/saga-unreal/SagaUnreal.uproject")" -WaitMutex </dev/null` → 끝에 `BUILD OK`/`BUILD FAIL` 한 줄. 로그는 `saga-unreal/Saved/`(커밋 안 함).
4. `.gitignore`: `Binaries/ Intermediate/ DerivedDataCache/ Saved/ .vs/ *.sln *.suo .idea/ Build/`. `docs/PROJECT_STATE.md` 10줄(상태 표·엔진 유무·다음 티켓).
5. precheck 게이트 한 절: `git ls-files -- 'saga-unreal/Content/**/*.uasset'` 중 `grep -l "/Script/Engine.Blueprint"`(바이너리 grep `-a`) 가 하나라도 있으면 FAIL. 그리고 `saga-unreal/Binaries|Intermediate|DerivedDataCache|Saved` 가 추적되면 FAIL. 절 하나·10줄 안.
6. 엔진이 있으면 3 을 돌려 BUILD OK(첫 빌드 수 분, 백그라운드 + `</dev/null`). 없으면 메모에 "컴파일 미실행(엔진 없음)" 적고 D0 로 둔다.

**검증**: `bash tools/precheck.sh` OK · `bash saga-unreal/tools/ue_build.sh` → `BUILD OK`(엔진 있을 때) 또는 `엔진 없음` 한 줄(없을 때, exit 0) · `git status --short saga-unreal` 에 Binaries·Intermediate·Saved 0줄.
