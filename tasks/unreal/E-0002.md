# E-0002 정본 데이터 로더 · 인물 glb 299 + 공용 동작 반입 · 인물 5벌 레벨
종류: 도구·통합(반입) · 언리얼      판: GO      상태: 작성됨(R-0 2026-10-07)      등급 목표: D1

**목표(한 줄)**: 웹 정본 `saga-web/saga-go/js/data.js` 의 `HEROES` 를 JSON 으로 뽑아 C++ 로더가 읽고, VRoid 인물 glb 299 와 공용 동작 glb(22종) 를 Interchange 로 헤드리스 반입해, 인물 5벌이 레벨 `L_CharTest` 에 서서 idle·walk 를 재생하게 한다(블루프린트 0).

**파일**: `saga-unreal/tools/gen_data.mjs`(새) · `saga-unreal/Content/Data/heroes.json`(생성물) · `saga-unreal/Source/SagaCore/{HeroData.h,HeroData.cpp,SagaDataLoader.h,SagaDataLoader.cpp}`(새, 각 ≤300줄) · `saga-unreal/tools/ue_import.py`·`ue_import.sh`(새) · `saga-unreal/Content/Chars/`(반입 .uasset) · `saga-unreal/Source/SagaGo/{CharTestLevel.h,CharTestLevel.cpp}`(새, 레벨을 코드로 채우는 AActor/GameMode) · `saga-unreal/Content/Maps/L_CharTest.umap`(새, 빈 맵 + GameMode 지정만) · `saga-unreal/tools/ue_test.sh`(새) · `saga-unreal/Source/SagaCore/Tests/HeroDataTest.cpp`(새) · PROJECT_STATE · 메모 · 큐 줄

**단계**
1. `gen_data.mjs`: `data.js` 를 `vm` 으로 평가해 `HEROES` 를 `{id,name,hanja,rarity,element,...}` 배열 JSON 으로. 필드는 웹 것 그대로(이름 바꾸지 않음). 정본 `data/heroes.json` 이 생기면 그걸 우선 읽게 분기 한 줄. `node saga-unreal/tools/gen_data.mjs` → `Content/Data/heroes.json`, 수 = 웹 HEROES 수(`grep -c "id:" ` 로 대조).
2. 로더: `USagaDataLoader::LoadHeroes()` 가 `FPaths::ProjectContentDir()/Data/heroes.json` 을 `FJsonSerializer` 로 읽어 `TArray<FHeroData>`. 자동화 테스트 `Saga.Data.Heroes`: 수 = JSON 수, id 중복 0, name 빈칸 0.
3. 반입 스크립트 `ue_import.py`(에디터 파이썬): `saga-assets/characters/web3d/*.glb` 를 `unreal.InterchangeManager` 로 SkeletalMesh 반입 → `Content/Chars/<id>`. 첫 벌(`dj_doseo`)에서 스켈레톤 `SK_VRoid` 를 만들고 나머지는 그 스켈레톤 지정. 동작은 `tools/char-forge/_out/vroid/dj_doseo/dj_doseo_anims.glb`(없으면 `saga-unity/Assets/Art/CharactersDex/anims/crowd_anims.glb`, 둘 다 없으면 메모 "사람 몫: vroid_batch.sh --only dj_doseo") 를 애니메이션만 반입 → `Content/Chars/Anims/`. `ue_import.sh` 는 `UnrealEditor-Cmd.exe <proj> -run=pythonscript -script=<py> -unattended -nopause -NullRHI </dev/null` 로 부르고 끝에 반입 수를 센다. **먼저 5벌만**(인자 `--limit 5`) 돌려 보고 OK 면 299.
4. 동작 반입이 깨지면(뼈 안 맞음·T 자세·길이 0): Blender(`tools/char-forge/_blender`) 로 glb→fbx 변환 스크립트 `tools/glb2fbx.py` 를 **이 폴더에** 두고 FBX 로 반입. 어느 길이었는지 메모에 남긴다(PLAN §5 함정).
5. `CharTestLevel`: GameMode `BeginPlay` 에서 heroes.json 앞 5명 id 로 `Content/Chars/<id>` 를 `LoadObject` 해 x 간격 1.2m 로 세우고 `UAnimSequence` idle 재생, 셋째만 walk. 카메라 고정(정면 3m). 레벨 `.umap` 은 빈 맵에 GameMode 만 지정(에디터 파이썬으로 만들고 저장 — 블루프린트 아님).
6. `ue_test.sh`: `UnrealEditor-Cmd <proj> -ExecCmds="Automation RunTests Saga; Quit" -unattended -nopause -NullRHI -log </dev/null` → 실패 0 이면 `TEST OK`.

**검증**: `node saga-unreal/tools/gen_data.mjs` 수 = 웹 HEROES 수 · `bash saga-unreal/tools/ue_import.sh` 반입 수 = 299(+동작 22) · `bash saga-unreal/tools/ue_test.sh` → `TEST OK` · `bash saga-unreal/tools/ue_build.sh` → `BUILD OK` · `bash tools/precheck.sh` OK(블루프린트 0). 엔진 없는 PC 면 1·2(gen·소스)만 하고 나머지는 메모에 "엔진 없음".

**완료 조건**: heroes.json 커밋 · 로더+테스트 · Chars 299·Anims 커밋(총 크기 메모에 적음, 500MB 넘으면 멈추고 보고) · `L_CharTest` 에 5벌 · PROJECT_STATE 갱신.
