# E-0003 마을 지역 1곳 · 하늘 · 툰 조명·후처리
종류: 도구·통합(반입·렌더) · 언리얼      판: GO      상태: 작성됨(R-0 2026-10-07)      등급 목표: D1

**목표(한 줄)**: `saga-assets/regions/village/layout.json` 이 가리키는 땅·소품(`regions/pieces`·`world/toon` glb)과 하늘 jpg 를 반입해 고돗·유니티와 **같은 자리**에 놓은 레벨 `L_Village` 를 만들고, 두 트랙과 같은 단수·외곽선 두께의 툰 셰이딩(후처리 머티리얼 1 + 2단 램프)과 조명 한 벌을 `UToonParams` 데이터 에셋 값으로 건다. Lumen·Nanite 끔.

**파일**: `saga-unreal/tools/ue_import.py`(지역·소품 반입 절 추가) · `saga-unreal/Content/World/`(반입 .uasset) · `saga-unreal/Content/Sky/`(하늘 텍스처) · `saga-unreal/Source/SagaCore/{ToonParams.h,ToonParams.cpp,ToonSetup.h,ToonSetup.cpp}`(새, 후처리 볼륨·방향광·스카이돔을 코드로 세움) · `saga-unreal/Source/SagaGo/{VillageLevel.h,VillageLevel.cpp}`(새, layout.json 읽어 StaticMesh 배치) · `saga-unreal/Content/Toon/{M_ToonPost,M_Toon,MI_Toon_*}.uasset`(머티리얼 — 에디터 파이썬으로 생성·파라미터는 ToonParams 에서) · `saga-unreal/Content/Toon/DA_ToonParams.uasset` · `saga-unreal/Content/Maps/L_Village.umap` · `saga-unreal/Source/SagaCore/Tests/LayoutTest.cpp` · PROJECT_STATE · 메모 · 큐 줄

**단계**
1. layout.json 규약 읽기: `saga-assets/regions/village/layout.json` 의 키(조각 id·위치·회전·배율·땅 높이)를 `grep -n` 으로 확인하고, 고돗 쪽 읽는 코드(`grep -rn "layout.json" saga-godot/saga_core saga-godot/games/saga_go | head`)에서 **좌표계 변환**(고돗 -Z 앞·m ↔ 언리얼 +X 앞·cm)을 한 줄로 적는다. 테스트 `Saga.Layout.Village`: 조각 수 = json 수, 빠진 glb 0.
2. 반입: layout 이 쓰는 조각만(`pieces` 58 중 쓰는 것 + `world/toon` 중 쓰는 것) StaticMesh 로 `Content/World/<id>`. 730 전부가 아니라 **쓰는 것만**. 하늘 `sky_village_2k.jpg` → `Content/Sky/T_SkyVillage`.
3. `VillageLevel`(GameMode BeginPlay): layout 을 읽어 `UStaticMeshComponent` 를 자리마다 스폰. 땅 조각도 같은 방법(지형 액터 안 씀). 인물 5벌(E-0002)을 마을 광장 자리에 세움.
4. 툰: `UToonParams`(UDataAsset — 램프 단수 2, 외곽선 두께 px, 외곽선 색, 그림자 색, 하이라이트 끔 여부) · 에디터 파이썬으로 `M_ToonPost`(SceneDepth·Normal 외곽선 + 2단 램프 — 노드는 파이썬 `MaterialEditingLibrary` 로 생성, 손 편집 안 함) · 인물·소품 머티리얼 `M_Toon`(BaseColor 텍스처 + Unlit 에 가까운 2단) · `ToonSetup` 이 PostProcessVolume(Unbound)·DirectionalLight(각도는 고돗 TestVillage 햇빛과 같게)·SkyLight·스카이돔을 코드로 세운다. **단수·두께 값은 고돗 `toon` 재질·유니티 셀 셰이더에서 grep 해 같은 수로**(비교 공정성 — 값·출처를 메모에).
5. `DefaultEngine.ini`: TAA 대신 TSR 끔·FXAA(툰 외곽선 번짐 방지), 그림자 캐스케이드 2, `r.DefaultFeature.AutoExposure=False`(노출 고정 — 비교 공정성).
6. 빌드·테스트·반입 명령 셋 돌려 OK. 작업 중 촬영 금지(촬영은 E-0004).

**검증**: `bash saga-unreal/tools/ue_import.sh` 반입 수 = layout 이 쓰는 조각 수 + 하늘 1 · `bash saga-unreal/tools/ue_test.sh` → `TEST OK`(Layout 테스트 포함) · `bash saga-unreal/tools/ue_build.sh` → `BUILD OK` · `bash tools/precheck.sh` OK · `git diff -- saga-unreal/Config` 가 의도한 줄만.

**완료 조건**: `L_Village` 가 헤드리스 `-game -NullRHI` 로 열려 오류 로그 0 · 툰 값이 DA_ToonParams 한 곳 · Lumen·Nanite 0 · PROJECT_STATE 갱신.
