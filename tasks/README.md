# tasks/ — 소넷 세션이 집어 가는 일 (규약)

체제 전체는 `SAGA-ARCH.md` §6. 여기는 **매 세션 그대로 따르는 절차**만 적는다. 2KB 안쪽.

## 세션 절차 (매번 같다)

1. 읽기: 루트 `CLAUDE.md` → `tasks/QUEUE.md` 맨 위 티켓 파일 → 티켓이 가리키는 트랙 문서만. 다른 문서는 티켓이 시키지 않으면 열지 않는다.
2. 티켓 검사: `목표·파일·단계·검증·완료 조건` 다섯 칸이 다 있나. 하나라도 비면 **"T-NNNN 에 <칸> 없음"** 만 보고하고 멈춘다.
3. 구현: `파일` 칸 밖은 손대지 않는다. 필요하면 `메모` 에 적고 멈춘다.
4. 검증: `검증` 칸 명령을 그대로 돌린다. 실패면 고치고 다시. **3회 실패면 되돌리고**(`git checkout -- <파일>`) 멈춘다.
5. 마무리: `git commit -F <메시지파일> -- <파일들>` (훅이 precheck) → `git push` → 티켓을 `tasks/done/` 으로 옮기고 QUEUE 에서 지운다(`git mv`). 메모 칸 2줄.
6. 보고: 바뀐 파일 · 검증 결과 한 줄 · 남은 것 세 줄. 그 이상 쓰지 않는다.

## 토큰·시간 절약 (사용자 09-30 "토큰 아끼고 쓸데없이 도는 것 없어야")

- 첫 턴 읽기 20KB 안: CLAUDE.md + 티켓 + 티켓의 `파일` 칸 파일만. 파일은 `grep -n` 으로 자리를 찾고 `sed -n` 으로 그 절만. 통째 Read 는 500줄 아래 파일만.
- 같은 파일을 두 번 읽지 않는다. 탐색 grep 은 티켓 `파일` 칸 안에서만. 저장소 전체 grep 은 티켓이 시킬 때만.
- 검증은 티켓 `검증` 칸 명령 **그대로 한 번**. 통과하면 다시 돌리지 않는다. 다섯 판 전체·사가국지(7분)·3회 반복은 R-1 주간에서만.
- 에이전트(서브에이전트)·워크플로는 쓰지 않는다. 한 티켓은 한 세션이 직접 한다.
- 보고는 6절 형식 그대로 5줄 안. 중간 진행 설명은 한 줄씩만. 결과를 되풀이해 요약하지 않는다.
- 서버·크롬은 검증 명령이 스스로 띄우고 스스로 끈다. 손으로 띄우지 않는다.

## 금지

- 티켓 없는 새 기능 · 큐 순서 바꾸기 · 티켓을 소넷이 새로 쓰기(제목만 있는 "미작성" 티켓은 건너뛰지 말고 **멈춘다**).
- HANDOFF·HISTORY 통째 읽기 · 서버·크롬을 띄운 채 두기 · 다섯 판 동시 수정(티켓이 명시할 때만).
- "이어해" = QUEUE 맨 위. 큐가 비면 `RECURRING.md` 의 다음 반복 티켓.

## 파일

- `QUEUE.md` 순서. 맨 위가 다음 일. 사람(또는 페이블 세션)이 채운다.
- `T-NNNN.md` 티켓 하나. 틀은 `SAGA-ARCH.md` §6.2. 2KB 안쪽.
- `RECURRING.md` 반복 티켓(주간 상태·확인 시트·닫기·통합·리뷰). 큐가 비거나 비율(닫기 40/통합 20/새기능 30/측정 10)이 기울면 여기서 뽑는다.
- `done/` 끝난 티켓. 세션 기록은 여기 메모 칸과 커밋 메시지뿐이다(HANDOFF append 안 함).
