# tasks/ — 실행 세션이 집어 가는 일 (규약)

체제 전체는 `SAGA-ARCH.md` §6. 여기는 **매 세션 그대로 따르는 절차**만. 세션은 전부 **Opus 5.5**(10-07 사용자 — 소넷 5.5 폐지), 갈래 넷이 동시에 돈다(`QUEUE.md`).

## 세션 절차 (매번 같다)

1. 갈래 확인 → 루트 `CLAUDE.md` → `tasks/<갈래>/QUEUE.md` 맨 위 티켓 → 티켓 `파일` 칸 파일만. 다른 문서는 티켓이 시킬 때만. `INBOX.md` 미처리 줄 수를 보고에 적는다(처리 안 함). **세션 중 들어온 새 말은 `INTAKE.md` 대로**(수신함 한 줄, 하던 티켓 계속).
2. 티켓 검사: `목표·파일·단계·검증·완료 조건` 다섯 칸. 상태가 **초안**이면 실행하지 않고 §R-0(아래)로 티켓을 완성만 하고 끝낸다. 빈 칸이 있는 **작성됨** 티켓은 "W-NNNN 에 <칸> 없음" 보고 후 멈춘다.
3. 구현: `파일` 칸 밖은 손대지 않는다. 필요하면 `메모` 에 적고 멈춘다.
4. 검증: `검증` 칸 명령 그대로 한 번. 실패면 고치고 다시. **3회 실패면 되돌리고**(`git checkout -- <파일>`) 멈춘다.
5. 마무리: `git commit -F <메시지파일> -- <파일들>`(훅이 precheck) → `bash tools/push.sh`(임시 트리로 옮겨 푸시·sw 버전 겹침 자동·로컬 main 맞춤 — `git pull`·autostash 금지, 받기만은 `--pull`) → 티켓을 `<갈래>/done/` 으로 `git mv`, 큐에서 그 줄 삭제, 메모 2줄. 이것도 커밋.
6. 보고 5줄: 바뀐 파일 · 검증 결과 · 남은 것.

## 끊긴 세션 이어받기 (사용자 09-30 "세션마다 중간에 끊기면 이어해로 계속")

- 시작할 때 큐 줄 상태를 `진행중` 으로 바꿔 **먼저 커밋**한다(한 줄 커밋). 단계 하나 끝날 때마다 티켓 `메모(체크포인트)` 에 `✔ 단계 n` 을 적고 그 단계 파일과 함께 커밋한다. 큰 단계는 잘게(파일 하나 옮길 때마다).
- "이어해"로 들어온 세션은 큐 맨 위가 `진행중` 이면 ① 티켓 메모의 마지막 ✔ ② `git status --short <파일 칸 경로>` ③ `git log --oneline -5 -- <경로>` 셋만 보고 **다음 단계부터** 잇는다. 처음부터 다시 하지 않는다. 미커밋 변경이 있으면 그 단계가 하다 만 것이다 — 이어서 완성하고 커밋.
- 끊긴 세션의 미커밋 파일이 티켓 `파일` 칸 밖이면 건드리지 않는다(다른 세션 것일 수 있다).

## R-0 티켓 작성 = **페이블 또는 Opus 5.5 세션**(수신함 처리 · 큐 순서 — 10-07 사용자 "오퍼스도 할 수 있잖아"). 실행만 하는 세션은 초안(요청)만 만들고 `작성됨` 으로 바꾸지 않는다(사용자 10-05 — 쓴 눈 ≠ 실행 눈, 설계는 페이블)

- 초안 티켓의 `단계`·`검증`·`완료 조건` 을 채운다. 규칙: ① `파일` 칸의 파일이 실제로 있는지 `ls`·`grep -n` 으로 확인하고 없는 이름은 쓰지 않는다 ② 수치는 `SAGA-DESIGN.md` §3·§6 표나 그 판 PLAN §5 에서 **인용**한다(지어내지 않는다) ③ `검증` 은 지금 당장 실행 가능한 명령이어야 한다 ④ 본보기 파일을 한 줄 지정한다 ⑤ 3KB 안.
- 완성하면 상태를 `작성됨` 으로 바꾸고 큐 줄을 고쳐 **커밋만** 하고 세션을 끝낸다. 실행은 다음 "이어해" 세션이 한다(쓴 눈 ≠ 실행하는 눈).
- 큐가 비면: `SAGA-BACKLOG.md` 의 그 갈래 줄 하나를 골라(P0 → P1 → P2 순, 플래그십 먼저) 초안 티켓을 만든다. 새 기능(P3)은 그 판 `features.json` 의 D0+D1 이 10 미만일 때만.
