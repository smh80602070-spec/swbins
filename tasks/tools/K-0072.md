# K-0072 VRM 조합 변형기 — VRoid 샘플을 재료로 머리·얼굴 레이어·체형을 코드로 섞고 **판정기가 고른다**(사람 디자인 0)
종류: 통합·도구      상태: **단계 0·2·4 끝, 3 보류**(소넷 10-05) — 5 는 별도 K      등급 목표: D2

**목표(한 줄)**: 공방(char-forge)이 "VRoid 를 대신"하려다 얼굴에서 미달 판정(09-26·09-30)을 받았다. 얼굴을 **만들지 않고** VRoid 공식 샘플(상업·개작·재배포 허용, K-0022)을 재료로 ① 머리 메시 교환 ② 얼굴 텍스처 레이어 합성 ③ 뼈 비율 조정을 코드로 해서, 사용자가 VRoid Studio 를 안 열어도 서로 다른 인물이 나오게 한다. **고르기도 사람이 아니라 판정기**(사용자 10-05 "디자인 단계만 수동도 자동으로, 직접 판단해서 좋은 걸로"). 옷은 K-0024 이식 + AI 무늬 그대로.

**지금 상태(확인함, 10-05)**
- VRM 몸 = 샘플 4벌(`avatar_sample_a·b·c`, `avatar_custom_01`), 사용자 디자인 0. 샘플 A~Z 는 더 받을 수 있다(`vroid_samples.py`).
- 자동인 것: 들이기 `vroid_intake.sh` · 색 변형 `vroid-variant.js`(머리·눈·옷 색) · 옷 이식 `outfit_swap.py`(299명) · 옷 무늬 `make_wardrobe_textures.py` · 동작 `bake_for_rig.py`.
- 없는 것: 머리 메시 교환 · 얼굴 레이어(눈·눈썹·입·피부·홍조·흉터) · 뼈 비율. 그래서 "같은 얼굴 넷에 색만 다름"(CHARACTER_UNIQUENESS.md).
- VRoid 얼굴 텍스처는 UV 아틀라스 한 장 — AI 가 직접 그리면 UV 가 깨진다. **레이어 PNG 합성만** 쓴다(AI 는 눈동자 무늬·옷 무늬 같은 조각만).

**파일**: 새 `tools/char-forge/vrm_mix.py`(Blender 헤드리스 + VRM 애드온: 머리 교환·뼈 비율) · 새 `tools/char-forge/face_layers.py`(PIL: 레이어 합성 → 얼굴 텍스처) · `tools/char-forge/data/face_layers/`(레이어 PNG — CC0 또는 자체 제작, 샘플 텍스처에서 **잘라 쓰지 않는다**: 개작 허용이라도 출처 기록은 샘플로) · `data/vrm_mix_plan.json`(인물 id → 몸·머리·레이어·비율) · `tools/char-forge/README.md` §10 갱신(8KB 안) · 렌더 점검 `render/render_wardrobe.py` 재사용.

**단계**
0. **밑몸 고르기도 자동**: 샘플 A~Z 를 정면·반측면으로 렌더(`render_wardrobe.py`) → 판정기 `--spec portrait` 점수 + dHash 로 서로 다른 얼굴 상위 6벌을 밑몸으로 확정(표를 메모에). 사람이 고르지 않는다.
1. 샘플 Z 까지 받기(`vroid_samples.py`) → 머리 메시 목록·뼈 이름 일치 확인(표).
2. `vrm_mix.py --body a --hair c --scale head=1.05,arm=0.97 --out <id>.vrm` 한 명 → `vroid_intake.sh` 로 Godot 들이기 → 렌더 1장. 머리 교환 때 머리 뼈·VRM 스프링본(흔들림) 이 따라오는지.
3. `face_layers.py`: 레이어 6종(눈 모양 4·눈동자 색 8·눈썹 3·입 3·피부 5·장식 4) → 조합표 → 텍스처 PNG. 레이어 그림은 **사람이 아니라 코드**(도형·그라데이션)로 시작하고, 부족한 것만 AI 조각(판정기 통과분).
4. 인물 60명 후보 생산 → 렌더 60장 → **판정기 `--spec portrait --per-group 1`** 이 묶음(같은 밑몸·머리 조합)마다 1등을 고르고 치명 결함·중복(dHash) 을 떨어뜨려 20명 확정. 모음표 한 장은 사용자 거부권용으로 남기되 **답 없어도 진행**.
5. 통과하면 299명 계획표(`vrm_mix_plan.json`)를 만들고 `outfit_swap_plan.json` 과 합쳐 일괄(별도 K 티켓, 양이 커서 범위 밖).

**검증**: 단계 2 렌더 1장 존재 · 단계 4 모음표에서 dHash 중복 0·`JUDGE_OK 20/20`(치명 결함 0) · `bash tools/precheck.sh` OK · `credits.py --check` OK(샘플 출처).

**완료 조건**: 단계 0~4 · README §10 에 "조합 변형(사람 디자인 0)" 절 · 거부권 모음표 한 장(답 없어도 5 로).

**본보기**: `tools/char-forge/outfit_swap.py`(Blender 헤드리스 호출·계획표 방식) · `saga-web/shared/js/vroid-variant.js`(변형 축 이름).

**불변 규칙**: 얼굴 **생성** 금지(ARCH §8-6·9, 공방 몸 생성 동결 유지) · 샘플 라이선스 기록 · 실명 금지(id·표시 이름) · 게임 폴더 직접 수정 금지(K-0019 배치) · 사용자 손 디자인 몸은 **기대하지 않는다**(들어오면 같은 재료로 취급).
