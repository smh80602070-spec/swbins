# K-0063 Unity 에 인물 299명(K-0024) 배치 — NPC·손님·군중이 쓰는 몸
종류: 새기능 · 에셋      상태: **요청**(2026-10-04, 유니티 U-0040 이 요청) — R-0 필요      등급 목표: D2

**무엇을**: K-0024 가 만든 인물 299명(`saga-assets/characters/web3d/*.glb` + `.license.json`, 정본)을 Unity `saga-unity/Assets/` 에 올린다. 지금 웹 3D·2D 에만 배치돼 있고 유니티에는 한 벌도 없다(`find saga-unity/Assets -name "dj_*"` 가 비어 있음).

**왜**: 유니티 NPC·손님·군중이 쓸 몸이 필요하다(도감 105 인물은 U-0034, 이 요청은 그 밖의 사람). 모델이 올라가야 U-0040 이 고르는 코드를 만든다.

**어디에**: `saga-unity/Assets/Art/CharactersCrowd/`(새 폴더, K-0019 `asset-place.json` 새 항목 `crowd-bodies`) — `.meta`(glTFast 임포트·mipmap 설정)는 K-0019 가 같이 놓는다. 이름은 정본 그대로(`dj_*` 등). 용량이 크면(299 × 수십 KB~) 압축본(`glb-compress`)을 쓰고 용량을 메모.

**Unity 가 읽는 규칙(요청 사항)**: 키·피봇 발 통일(`calib_height.py` 1.70m 기준) · 뼈 이름은 VRoid 와 같게(U-0034 의 K-0062 몸과 같은 동작 클립을 쓸 수 있게) · 이름 정책·출처 `.license.json` 100%.

**Unity 쪽 후속**: `tasks/unity/U-0040.md` 단계 3 — 올라오면 NPC·손님·군중 자리에 해시로 골라 연결한다.
