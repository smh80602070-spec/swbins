# K-0099 자체 PBR 12세트(K-0093) 유니티 배치 — PNG 바탕·법선·거칠기·높이를 `saga-unity/Assets/Art/TexturesReal/` 에
종류: 에셋 · 자체툴      상태: **요청**(유니티 갈래 2026-10-13, U-0084·U-0085 2단계)      등급 목표: D1

**왜**: K-0093 이 끝나 수신함 19행이 "웹·유니티 사실 재질에 재사용"을 넘겼다. 그런데 유니티에는 아직 놓인 것이 없다.
- 정본 `saga-assets/textures_real/<세트>/` 에는 바탕색 `*_color.png` 와 `.license.json` 만 있다.
- 법선·거칠기·높이(`_n`·`_r`·`_h`)는 고돗 `saga-godot/assets/generated/tiles_real/*.webp` 에만 있다. 유니티 텍스처 임포터는 WebP 를 못 읽는다.
- 유니티 갈래는 에셋·`.meta` 를 만들지 않는다(유니티 큐 머리 규칙).

**쓰려는 곳(U 갈래 몫, 배치 뒤)**:
- U-0084 2단계(땅): grass·dirt·gravel·rock·sand·snow 를 땅 셰이더 `Shaders/SagaGroundPBR.hlsl` 에 쓴다. 쓰는 셰이더는 1만리 VertexColorLit, 3마을 ForestWorldCurve, RegionGround 이다. 높이 맵으로 경계를 섞는다.
- U-0085 2단계(소품·건물): stonewall·planks·plaster·rooftile·rust·paving 을 재질 이름에 연결하고, 상자 투영 UV 를 쓴다.

**바라는 것**:
1. 세트 12개 × 네 장(바탕 `_color`·법선 `_n`·거칠기 `_r`·높이 `_h`)을 PNG 로 놓는다.
   - 크기는 고돗과 같은 둘(512, hi). 폰 대상이라 hi 는 K 판단으로 1024 이하.
   - 법선은 OpenGL Y+ 그대로 둔다. 유니티도 OpenGL 규약이다.
2. 놓는 자리는 `saga-unity/Assets/Art/TexturesReal/<세트>/` 이고, 각 세트에 `.license.json` 을 둔다(정본 복사).
3. `.meta` 임포트 설정:
   - 법선은 Texture Type Normal map 이다.
   - 거칠기·높이는 sRGB 끔(선형)이다.
   - 바탕은 sRGB 켬이다.
   - 반복 Wrap Repeat, 밉맵 켬, Android ASTC 를 쓴다.
4. 가능하면 `tools/asset-place/asset-place.json` 에 `track: "unity"` 항목을 둬서, 다시 구우면 같은 자리에 놓이게 한다.

**완료 조건**:
- 세트 12 × 4장이 `Assets/Art/TexturesReal/` 에 PNG 와 `.meta` 로 있다.
- 유니티 배치 컴파일·임포트 오류가 0 이다(`bash saga-unity/tools/unity-batch.sh` 로 한 번).
- `PlaytestHeadless` OK 이다.
- credits·audit OK 이다. 남의 사진·스캔은 0 이다(K-0093 그대로).
- 표시 이름에 실명이 없다.

**유니티 갈래가 이어서 할 일**: 놓이면 U-0084·U-0085 를 "작성됨"으로 바꾸고 2단계를 실행한다. 셰이더 배선·재질 연결은 U 몫이다.
