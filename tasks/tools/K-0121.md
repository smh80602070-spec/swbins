# K-0121 몬스터 초상 = **종 몸 단위**(creatures3d id 마다 한 장) + 사람 적 초상
종류: 에셋 · 자체툴      상태: 작성됨(Opus R-0 10-16 → **페이블 판단 10-17 로 개정**, 웹 감사 §D-4)      등급 목표: D2

**목표(한 줄)**: 지금 적 카드 초상은 몸 계열 32장(보스 12 + 기계·네발·뱀·넋·날개 각 4)을 이름 해시로 나눠 쓴다. 적마다가 아니라 **적이 실제로 입는 종 몸(`data-enemy.js` `body` → `creatures3d/<id>.glb`)마다 초상 한 장**을 만든다 — 그러면 초상과 3D 몸이 늘 같은 생물이고, 종이 다른 적은 서로 다르게 보인다. 사람 적은 VRoid 몸 렌더 초상.

**실측(10-17 페이블)**: 2나락 적 134 = `body` 있음 114(종 이름 **58 가지**: beast_boar·skeleton_minion·snake·wasp·rat·frog·pink_slime·glub·mushnub·ghost·orc·demon·dino_*·yeti·treant·cyclops…) + body 없음 20(들개·강철랑 등 — 옛 계열 해시 그대로) + 사람 18. 종 몸 자체판 = `saga-assets/creatures3d/` 111(TRELLIS, K-0133 고침, 51MB) — 빌린 이름은 `shared/js/assets3d.js` `CREATURE_OF` 가 id 로 잇는다(예 Snake→snake, Pink_Slime→pink_slime). **웹 함정**: `dungeon3d.js` 2043 이 `crea:<계열 id>` 를 종 몸보다 먼저 잡아 116 마리가 계열 17 몸으로 보인다 → 수신함 웹 줄(종 몸 먼저, 계열은 body 없을 때만).

**파일(확인함)**: 규칙 `saga-web/saga-dungeon/js/monster-portrait.js`(`IDS`·`family`·`idOf`, `BASE='assets/portraits-monster/'`) · 적 표 `saga-dungeon/js/data-enemy.js`(`body`·`kind`·`look`) · 몸 `saga-assets/creatures3d/<id>.glb` · 빌린 이름→id `saga-web/shared/js/assets3d.js` `CREATURE_OF` · 렌더 `tools/world-forge/render_sprite.py`(`--az 35 --el 15`, 512) · i2i 본보기 `tools/ai-art/make_late_i2i_batch.py`·`make_monster_dex.py`(K-0032 규격, `_c.webp` 정사각) · 생성 `prompt_kit.py build`(spec `portrait`, 그림체 C) → `gen.py --variants 4 --judge` → `tools/asset-audit/judge/judge.sh pick` · 포장 `pack_web_portraits.py` · 정본 `saga-assets/portraits-monster/`(지금 64 = 32×2) · 배치 `place.py --item portraits-monster`(항목 이름 확인) · 사람 몸 `tools/char-forge/_out/vroid/<id>/<id>.glb` + `render_busts.py`.

**단계**
1. 목록 `tools/ai-art/data/k121_targets.json`: 2나락 `body` 58 → `CREATURE_OF`/같은 이름으로 creatures3d id 를 맞춤(짝 없는 것 — 해골 KayKit 계열 등 — 은 `pending: K-0122` 로 표시만) + 사람 18(`FIXED_HERO` 표 `asset3d.js` 707 의 몸 id). 1만리·4종횡·5천하 괴물은 **세기만**(`crea:`·`body` 가짓수) 하고 2차 티켓 한 줄.
2. 몸 렌더: creatures3d id 마다 3/4 정면 512(`render_sprite.py`, Cycles CPU 는 `WF_CPU=1` — SD 사슬 중이면 CPU) → `_out/k121_init/<id>.png`.
3. i2i 배치(`_in/k121_portraits_C.json`, spec portrait, denoise 0.55~0.6, 프롬프트 = 종 이름 뜻 + 2나락 어둠) → `gen.py --variants 4 --judge` → `judge.sh pick`. 사람 18 은 VRoid 몸 `render_busts.py` 반신 → 같은 길.
4. `pack_web_portraits.py` 규격으로 `saga-assets/portraits-monster/<id>_c.webp` + `.license.json`(init 그림 출처 포함) → `place.py --write`.
5. 수신함 웹 줄: "① `monster-portrait.js idOf` — `ref.body` 의 creatures3d id 그림이 있으면 그것, 없으면 옛 계열 해시 · 사람(kind human)은 `FIXED_HERO` 몸 id 그림 ② `dungeon3d.js` 2043 foeBody 순서: 종 몸(`enemyDef.body`) 먼저, `crea:계열` 은 body 없을 때만".

**검증**: 목록 수(짝 있는 종 + 사람 18) = 새 `_c.webp` 수 · 무작위 24장 시트 Claude 눈 ○(그 몸과 같은 생물 · 서로 다름 · 그림체 C · 실명 없음) · `py tools/asset-place/place.py --check` 0 · `py tools/asset-audit/credits.py --check` OK · `node tools/qc.mjs --branch tools` PASS.
