# K-0036 음성(대사) — 판정이 통과하면 인물·시스템 대사를 한국어 음성으로 굽는다
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-02) — 시작 조건: K-0011 음성 시트(`tasks/sheets/voice-20261002.md`) 사용자 ○/× 판정 통과      등급 목표: D2

**목표(한 줄)**: 음성이 "쓸 만하다" 판정이면, 모든 인물 대사 전체를 만드는 대신 **짧은 대사 위주**(전투 외침·획득·인사·시스템 안내)로 음성 에셋을 만든다. 긴 이야기 대사는 글자만(음성 반쯤, ARCH §4.5). 인물 299명에게 목소리 10종(남 5·여 5)을 배정해 같은 인물은 늘 같은 목소리.

**파일(확인함)**: `C:\swbins3\voice-gen\`(Supertonic 3, ko·en·ja, M1~M5·F1~F5, 속도 0.7~2.0 — **별도 저장소, 그쪽 규칙으로 따로 커밋**) · `tasks/sheets/voice-20261002.md`(판정 시트) · `tools/asset-forge/sfxgen.py`(효과음 선례) · 배치 K-0019 · 목소리 배정은 `tools/char-forge/data/outfit_swap_plan.json` 의 성별(근거 없는 해시 값이라 도감 쪽 확정 뒤 다시 확인)

**단계**
1. **판정 확인**: 시트 ○ 비율이 낮으면 이 티켓은 "취소" 로 닫는다(되풀이 금지).
2. 대사 목록: 종류(외침·획득·인사·안내) × 20 문장 정도, 이름 정책·실명 금지·시대 혼합 말투. 인물 → 목소리 배정표.
3. 일괄 합성(서버 없이 직접, 낮은 우선순위) → WAV → OGG 변환·길이·음량 정규화 → 용량(인물 합계 ≤ 40MB 한도, 압축 후).
4. 시험 20개 판정 → 일괄 → K-0019 배치(`.license.json`: 모델·목소리·문장).

**검증**: 대사 수 = 파일 수 · 음량 편차 ≤ 3dB · 총 용량 한도 · 모델 라이선스 상업 허용 확인(음성 모델 이용 조건 문구 첨부) · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~4 (1에서 취소될 수 있음).

**불변 규칙**: 실존 배우·성우 목소리 모사 금지 · 실존 인물·원작 대사 금지 · 모델 이용 조건이 상업 불가면 즉시 중단 · 산출 공개 저장소 용량 한도 준수.
