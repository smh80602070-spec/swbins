# K-0081 장비 외형 조각을 VRoid 몸 비율로 — 가슴판이 상자처럼 큼 · 입으면 옷이 안 숨겨짐 (K-0037 후속, G-0060 촬영)
종류: 버그 · 에셋      상태: 작성됨(R-0 10-07, 수신함 G-0060 촬영 관찰)      등급 목표: D2

**목표(한 줄)**: 고돗 G-0060 이 성유물을 갑옷 조각(`eq_<시대>_<1~3>_<부위>` 54)으로 몸에 붙였더니, 애니풍 VRoid 몸에서 가슴판이 허리~턱을 덮는 상자처럼 크고 입어도 몸 옷이 그대로 비친다. 조각을 지금 몸(VRoid dex 299 · 샘플)에 맞게 다시 짓고 숨길 옷을 엔진이 찾게 한다.

**지금 상태(확인함, 10-07)**
- `tools/world-forge/build_equip.py`(713줄) 머리말: "기준 몸 = UAL 표준 몸(골반 0.92m·어깨 1.44m)" — 사실 체형 몸 단면으로 가슴판(`cuirass`)·어깨 돔·정강이를 짓는다. 3D 사람 몸은 이제 전부 VRoid(K-0022)인데 기준이 안 바뀌었다.
- `tools/world-forge/data/equip_slots.json`: 몸마다 배율 = `J_Bip_C_Head` 높이 / 1.5 **균등** 하나 — 키만 맞고 몸통 굵기·가슴 길이는 안 맞는다(G-0060: k=0.997 인데도 큼).
- `hides`(hair_top·clothing_top·sleeve·bottom_lower·shoes)는 이름만 있고 몸의 어느 조각인지 규칙이 없다. VRoid 몸 재질 이름에 `_Tops_`·`_Bottoms_`·`_Shoes_`·`_HAIR` 가 들어 있다(`kr_yisunsin` 실측: `N00_007_01_Tops_01_CLOTH_01` 등).

**파일**: `tools/world-forge/build_equip.py`(기준 몸 치수·단면) · `tools/world-forge/data/equip_slots.json`(기준 치수·`hide_match` 재질 이름 규칙) · 새 `tools/char-forge/measure_vroid_section.py`(Blender: 뼈 둘레 단면 재기, `measure_shape.py` 본보기) · 렌더 `tools/char-forge/render/render_bodies.py` · 배치 `tools/asset-place/asset-place.json`(world-toon) · 수신함(고돗 짝).

**단계**
1. **재기**: dex 299 원본 몸(`_out/vroid/<id>/<id>.glb`)에서 뼈마다 단면 — 가슴(`J_Bip_C_Chest`~`UpperChest`) 폭·두께, 가슴뼈 → 목뼈·허리뼈 길이, 위팔·아래팔·종아리 둘레, 발 길이, 머리 폭. 남·녀 중앙값·90분위를 표로(메모). 옷 두께 포함(바깥 정점).
2. **다시 짓기**: `build_equip.py` 기준 몸을 VRoid 90분위(몸 대부분이 안 뚫리게) + 여유 1.5cm 로 — 가슴판 세로는 가슴뼈~목뼈 아래(턱을 안 덮게)·허리뼈 위까지. 머리·어깨·팔·정강이·신도 같은 표로. 시대 셋 × 등급 셋 × 부위 여섯 = 54 다시.
3. **숨김 규칙**: `equip_slots.json` 에 `hide_match`(clothing_top = 재질 이름 `_Tops_`, bottom_lower = `_Bottoms_`, shoes = `_Shoes_`, hair_top = `_HAIR`) — 엔진이 그 슬롯을 입으면 그 재질 메시를 숨긴다. 소매만 따로 숨길 수 없으면(상의 한 메시) 표에 그렇게 적는다.
4. **확인 렌더**: 몸 셋(마른 여·보통 남·큰 남) × 갑옷 다섯 부위 다 입힘(옷 숨김 적용) 앞·옆 → Claude 눈(뚫림·뜸·상자 꼴 없음). 통과하면 정본 → place(고돗·유니티) → 고돗 `.glb.import` 다시(바뀐 것만 add -f) → 고돗 짝 요청(hide_match 적용).

**검증**: 단계 1 표(남·녀 중앙값·90분위) 메모 · 확인 렌더 시트 Claude 눈 ○(가슴판이 턱·허리를 안 덮음, 몸을 안 뚫음) · `WORLDFORGE ok` 54 · `place.py --check` 불일치 0 · `bash tools/precheck.sh` OK.
