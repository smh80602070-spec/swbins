**목표(한 줄)**: 지금 3D 건물(K-0017, 12종)은 겉만 있고 속이 비어 있다. 건물마다 **들어가는 방 하나**(벽·바닥·천장·창·가구 모듈)를 `world-forge` 레시피에서 만들어 세 트랙이 같은 GLB 를 쓰게 한다. 입장은 "건물 밖 → 실내 장면으로 교체" 방식(실내를 건물 안에 이어 붙이지 않는다).

**파일(확인함)**: `tools/world-forge/build_building.py`·`build_prop.py`·`wf_common.py`·`recipes/*.json`(건물 12) · 새 `build_interior.py`·`recipes/interior/<건물>.json` · 재질 `sources.json`(Poly Haven CC0) · 툰 규칙 = K-0017 Godot 툰 GLB 와 같다 · 산출 `tools/world-forge/_out/`(git 밖) → 정본 `saga-assets/world/interior/` → K-0019 배치(`asset-place.json` 항목 `world-interior`)

**단계**
1. 규약: 방 크기 3종(소 4×4·중 6×5·대 9×7 m) · 문 위치 = 건물 레시피 `door.at` 와 같은 쪽 · 시작점·창·조명 자리를 GLB 안 빈 노드 이름(`spawn_in`·`light_*`·`door_out`)으로 표시.
2. `build_interior.py` + 레시피 12(건물 한 종에 방 1~2). 가구는 `build_prop.py` 소품 재사용(탁자·침상·선반·화로 등).
3. 툰 재질 변환(바탕색 한 장 + 외곽선 규칙) · 웹용 경량본(Meshopt, 건물당 ≤ 0.5MB).
4. 미리보기 시트(`preview.py`) → 사용자 고르기 → K-0019 배치.
