**파일(확인함)**: 규격 `saga-web/shared/js/cutout2d.js` 머리(뼈 16 고정 · rig.json 부위 사각형·sway·clips · `index.json` 풀↔rig · 오른쪽 봄) · `saga-web/shared/js/parallax2d.js` 머리(layers.json depth·top/bottom·h·fog·front·light · 장소 id = mode2d `o.region`) · 자리 `assets/web2d/cutout/`·`assets/web2d/bg2d/<region>/` · 기존 도구 `tools/ai-art/split_bg_layers.py`(3층 — 5~7층으로 넓힘)·`make_bg_batch.py` · 몸 `tools/char-forge/_out/vroid/<id>/<id>.glb` · 렌더 `tools/world-forge/render_sprite.py` · 원격 `tools/ai-art/remote/push_batch.py`.

**단계**
1. 장소 정하기 — 판마다 mode2d `drawBg` 에 넘어오는 region 중 첫 화면 하나(`grep -n "region" saga-web/*/js/*.js` 로 이름 확정, 다섯 이름 표 `tools/ai-art/data/k150_places.json`).
2. 겹 배경: 장소마다 층을 **따로** 그림(하늘·먼 산·중경·근경·땅·앞가림 6, 그림체 C · 가로 1920×540 이음 · 하늘 말고는 알파 — 흰 바탕 생성 → matte) → `layers.json`(depth 0.02·0.15·0.4·0.75·1.0·1.25 = parallax2d 머리 예시 값) → `bg2d/<region>/`.
3. 컷아웃: 새 `tools/char-forge/cutout_parts.py`(Blender) — VRoid 몸을 옆모습(오른쪽)·팔다리 벌린 자세로 렌더 + 뼈 16 마다 정점 그룹 색 마스크·뼈 축 자리 → 렌더 밑그림 img2img(그림체 C, denoise 0.45 — 윤곽 유지) → 마스크로 부위 16 잘라 `<부위>.webp` · `rig.json`(bones 축 = 뼈 자리, parts 사각형, sway hair·cape) · 주역 둘(1차: `sg_zhugeliang`·`hl_mukhyang`).
4. 시트 `_out/k150/sheet.jpg` — 장소 다섯(층 겹친 한 장 + 층 분해) · 인물 둘 쉬는 자세 + 부위 분해. Claude 눈(이음매·층 경계·부위 틈).
5. 정본 `saga-assets/web2d/{cutout,bg2d}/`(새 place 항목 → 다섯 판 `assets/web2d/`) · credits.
6. 수신함 웹 줄 "컷아웃 2·겹 배경 5 도착 — 손잡이 cutout2d.on·parallax2d.on 1 로 켜 보고 촬영".
