# K-0162 2D 지형 이음 타일셋 — 네모 칸 경계 없애기(풀·흙·돌길·물가 오토타일, 판별 테마 다섯)

**목표(한 줄)**: 다섯 판 2D 바닥이 같은 크기 네모 칸을 붙인 것이라 풀·흙·돌바닥 경계가 직선 계단으로 보이고(1만리 들판 풀 칸·흙 칸, 3마을 마을 바닥 칸 무늬), 강은 파란 L자 직사각형이다 → 땅 종류 쌍마다 **이음 타일(16칸 꼴: 모서리·변·안쪽 모서리)** 과 물가·길 가장자리를 만들어, 웹이 이웃 칸을 보고 고르게(웹 쪽 배선은 수신함 → 새 W). 판 테마: 1만리 들·숲 / 2나락 마을 흙·던전 돌 / 3마을 동숲풍 풀·모래 / 4종횡 옆보기 땅 윗면(별도 — K-0164) / 5천하 지도 바닥.
