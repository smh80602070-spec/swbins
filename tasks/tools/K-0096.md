**단계**
1. 대상 표 `tools/ai-art/remote3d/k96_targets.json`(종 id · 묶음 ①~⑤ · 빌린 파일·판 · 입력 그림 · 있음/새로).
2. ① CC-BY 14 + ② 탈것 5: 입력 그림 준비 → Kaggle 한 번(19장) → 시트 눈 판정 → ✗ 는 그림을 다시 뽑아 재실행.
