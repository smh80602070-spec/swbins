# K-0019 에셋 배치 도구 — 자체툴 산출을 세 트랙 폴더로 놓고 출처·`.import`·`.meta` 까지
종류: 통합 · 도구      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2

**목표(한 줄)**: 사용자 지시(2026-10-01) "웹·고돗·유니티 갈래는 에셋을 안 고친다, 자체툴로 다 한다" 를 도구로 굳힌다. `data/asset-place.json`(어느 산출 → 어느 트랙·판 폴더, 이름 규칙, 출처 문구)을 읽는 `tools/asset-place/place.py` 가 복사·`ASSET_LICENSES`/`ASSET_GUIDE` 문단·(Godot) `.import`·(Unity) `.meta` 까지 한 번에 만든다. 웹·고돗·유니티 티켓은 **코드 배선만** 한다.

**파일(확인함)**: 새 `tools/asset-place/place.py`·`data/asset-place.json` · 읽는 산출 `saga-web/shared/audio/bgm/`(15곡) · `saga-web/shared/assets/patterns/`(64) · `tools/char-forge/_out/sprites/`(20벌) · K-0017·K-0018 산출 · 놓는 곳 `saga-web/<판>/assets/…` · `saga-godot/assets/…` · `saga-unity/Assets/Resources/…` · 점검 `tools/asset-audit/audit.py --quick` · 이미 놓인 것(2026-10-01): 웹 3판 배경음 8 · 웹 5판 `sprites2d_sheets` · Godot `assets/audio/bgm` 15 · Godot·웹 무늬 64

**구조 결정(사용자 2026-10-01 "전체 에셋이 같을 테니 모아서 해도 된다")**: 에셋 **정본은 한 곳** `saga-assets/`(루트, 추적) — `bgm/ patterns/ sprites2d/ portraits/ glb/ bg2d/ tiles/` + `manifest.json`(id·종류·출처·배포 대상). `place.py` 가 거기서 **배포만** 한다: 웹 = `saga-web/shared/assets/<종류>/` **한 벌**(판은 `../shared/` 로 읽고 판 폴더엔 안 둔다 — 다섯 벌 복사 폐기, 단 판 폴더 단독 서버·오프라인용은 `sync-shared` 식 복사 옵션) · Godot = `saga-godot/assets/…`(엔진이 `res://` 안만 읽어 복사) · Unity = `saga-unity/Assets/Resources/…`(같은 이유). 같은 내용의 파일은 git 에서 한 번만 저장돼(내용 해시) 저장소 용량은 늘지 않고 작업 폴더 디스크만 늘어난다. 이미 놓인 것(웹 판별 곡·시트·무늬 사본)은 정본으로 옮기고 사본 폴더는 배포 결과로만 둔다.

**단계**
1. `asset-place.json` 에 이미 놓인 위 항목을 **현재 상태 그대로** 등록(도구가 다시 돌려도 diff 0 = 멱등).
2. `place.py` 가 복사 + 출처 문단(마커 `<!-- asset-place:<id> -->` 블록 덮어쓰기)을 만든다. 없는 폴더·이름 충돌은 중단하고 보고.
3. Godot `.import`: `GODOT=<exe> godot --headless --import` 를 부르는 단계(exe 없으면 건너뛰고 "Godot 세션 필요" 보고). Unity `.meta`: `bash tools/unity-batch.sh -- -executeMethod …Refresh`(다른 세션이 Unity 를 쓰면 기다림).
4. 새 배치 등록 규칙을 `tools/README.md` 색인 한 줄에.

**검증**: `py tools/asset-place/place.py --check` → 등록 항목 전부 대상 폴더에 있고 md5 같음 · 두 번 실행 diff 0 · `audit.py --quick` 🔴 0 · `precheck.sh` OK.
