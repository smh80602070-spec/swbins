# K-0198 손그림 컷아웃 앞모습·뒷모습 — 위에서 보는 판(1만리·2나락·3마을·5천하) 위아래 걸음용 (K-0188 옆모습 짝)
종류: 에셋(2D 그림체) · 자체툴(ai-art · k188 컷아웃 길)      상태: **진행중**(10-25 ① 앞모습 시험 ○) · **작성됨**(10-25 오퍼스 R-0 — 사용자 「앞모습 됫모습이 있어야지」)      등급 목표: D2

**왜**: K-0188 컷아웃은 오딘스피어·드래곤즈 크라운 문법 그대로 **옆모습 한 방향**(오른쪽, 왼쪽은 거울)뿐이다 — 그 두 게임은 옆보기라 앞·뒤 걸음 그림이 없다. 그런데 웹 `cutout2d.on` 기본 1 이라 다섯 판 2D 모두에서 컷아웃 51명이 8·16방향 시트보다 먼저 그려져, 위에서 보는 판에서 위아래로 걸어도 옆모습이다(10-25 사용자 지적).
**목표**: 컷아웃 인물마다 **앞(front)·뒤(back)** 한 벌씩 더 — 같은 사람·같은 옷·같은 그림체(C). 엔진이 이동 방향으로 고른다(웹 W 줄): 아래 = front · 위 = back · 좌우 = side(지금) · 대각 = 가까운 쪽.

**규격(엔진과 약속 — 웹 W 줄과 같이)**: `cutout/<rig>/` 옆(지금 그대로) + `cutout/<rig>~front/`·`cutout/<rig>~back/` 같은 꼴(`rig.json`·부위 webp·`rig.license.json`) · `index.json` 에 `"dirs": { "<rig>": ["side", "front", "back"] }`(없으면 옆만 — 지금과 같음).
앞·뒤 rig 은 뼈 16 같은 이름: L = 화면 왼쪽 팔·다리, R = 오른쪽(옆모습의 안·바깥 대신) · 몸 뒤 가림 없음(앞에선 두 팔이 몸통 옆) · 클립은 rig.json `clips` 로 앞·뒤용 키(걷기 = 다리 위아래 굽힘·팔 앞뒤 대신 위아래 흔들림 — 엔진 기본 CLIPS 는 옆 기준이라 앞·뒤 rig 은 clips 를 꼭 싣는다).

**그림 원본**: 앞 = 기존 정면 스탠딩 일러스트(`saga-assets/illust/shared/<id>/stand.webp`, K-0178·0183·0185 — 초상과 같은 사람)가 있으면 그것부터(옷이 옆모습과 같은지 눈 판정, 다르면 옆모습을 img2img 밑그림으로 새로) · 뒤 = 옆모습·앞모습을 밑그림으로 `back view` 새로(로컬 SD, 그림체 C, 상업 허용 모델 §7.4).
