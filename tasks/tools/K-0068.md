# K-0068 웹 2D 그림체 재시험 — 굵은 먹선 회화풍(P) vs 부드러운 동화풍(C), 사용자가 고른 쪽으로 그림체 고정(K-0056 후속)

**요청 배경(사용자 직접 확인 10-05)**: 웹 다섯 판 2D 화면을 직접 보고 "5개 다 별로야 · 2D 스타일이 다 별로야 · 이게 최선인가". 다만 "AI 생성해서 하면 좋긴 하더라" — 방식(로컬 AI)은 유지, **그림체와 결과 품질**이 문제. 사가블로 "너무 작다"·사가국지 "스타크래프트 화면이 아니다"는 그림체와 별개라 웹 쪽 티켓으로 따로 간다(이 티켓 아님).

**목표(한 줄)**: 지금 그림체(B = 부드러운 채색 + 얇은 윤곽, Animagine, 3D 스프라이트 밑그림 img2img — K-0056 10-03 확정)를 대체할 후보 두 방향을 같은 주제로 뽑아 사용자가 고르게 하고, 고른 방향을 `STYLE` 상수로 고정한다.
