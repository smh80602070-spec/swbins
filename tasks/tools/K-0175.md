# K-0175 2D 공장 병렬화 — 굽기 Blender 여럿·그림체 프로세스 여럿, 엔진 떠 있으면 줄임
종류: 자체툴(char-forge factory)      상태: **진행중**(오퍼스 10-22 — 사용자 "응 그렇게 넣고 이어해")

**목표(한 줄)**: 공장(factory.py)이 풀 하나씩 한 줄로 돌아 그림체 단계 중 CPU 16%(12스레드 중 하나) · 42풀 2시간 남짓 → 굽기·그림체를 풀 단위로 동시에 돌려 1/3 이하로. 사용자 Unity·Godot 작업이 우선이라 엔진이 떠 있으면 저절로 줄인다.

**파일**: `tools/char-forge/factory.py`(limits·bake_one 자리·style_one 프로세스 풀) · `tools/char-forge/README.md` §13(공장) 한 줄

**단계**: ① limits(): 엔진(Unity.exe·Godot*) 떠 있으면 굽기 1·그림체 2, 아니면 RAM 여유 12GB↑ 굽기 3·5 / 그 밖 2·5, 30초마다 다시 잼, FACTORY_BAKE·FACTORY_STYLE 로 덮음(1 = 옛 한 줄) ② 굽기: 스레드 3 + 자리(condition) — 새 굽기 전에 limits() 를 보고 기다림, 실패는 모아서 끝에 2 ③ 그림체: 최상위 style_one 을 ProcessPoolExecutor(limits 그림체 수) ④ 실제 사슬(K-0160 창 다섯·K-0171 villager_a)로 시간 재기 ⑤ README 한 줄

**검증**: `py tools/char-forge/factory.py <계획> --only a,b,c --stage style` 동시 줄 · 사슬 로그에 "동시 개수" 줄·굽기 겹침·실패 0 · 풀당 시간(throughput.json) 옛 값과 비교 · 판정 결과 옛 한 줄과 같음(그림체는 결정적) · `node tools/qc.mjs --branch tools`

**완료 조건**: 병렬 굽기·그림체 실측(풀 n 개 걸린 시간 옛/새) 메모 · 엔진 감지 확인 · README · done/.

**불변 규칙**: 화질·규격 안 바꿈(돌리는 방식만) · Blender 낮은 우선순위 유지 · 사용자 엔진 작업 우선(떠 있으면 1) · 무거운 SD·MOSS 와 겹칠 때는 FACTORY_BAKE=1.
