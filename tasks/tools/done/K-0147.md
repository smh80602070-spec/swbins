# K-0147 precheck 실패 원인 표시 — 끝줄에 실패한 검사 이름
종류: 체제 · 자체툴      상태: 끝(10-20)      등급 목표: D2

**목표(한 줄)**: 커밋 훅이 "PRECHECK FAIL" 만 보여 주고 어느 검사인지 안 알려 주던 것(10-19 실제 — 그때 check_refs 단독은 통과)을, 끝줄 `PRECHECK FAIL — <검사 이름>` 과 훅 출력으로 바로 알게 한다.

**원인**: `tools/hooks/gate.js` 는 precheck 출력에서 `FAIL|OVER|MISMATCH` 줄만 골라 보여 준다. 그런데 `audit.py --quick || fail=1`·`sync-shared --check || bad` 처럼 FAIL 줄을 안 찍고 실패하는 검사가 있어, 남는 줄이 끝줄 "PRECHECK FAIL" 하나뿐이었다.

**파일(확인함)**: `tools/precheck.sh`(검사 머리 `echo "== …"` 15곳 · 끝줄) · `tools/hooks/gate.js`(PreToolUse git commit 차단 메시지).

**단계**
1. precheck: `sec "<검사>"` 함수가 머리를 찍고, 앞 검사에서 `fail=1` 이 됐으면 그 검사 이름(괄호 앞)을 `failed` 에 모은다 → 끝줄 `PRECHECK FAIL — 이름 · 이름`. 범위 밖 WARN 규칙·검사 내용은 그대로.
2. gate.js: 고른 줄이 1줄 이하(= 끝줄뿐)면 출력 끝 15줄을 대신 보여 준다.

**검증**: `bash -n tools/precheck.sh` · `node -c tools/hooks/gate.js` · `bash tools/precheck.sh` 한 번 — 통과면 `PRECHECK OK`, 실패면 끝줄에 검사 이름.

**완료 조건**: 위 검증 + 이 티켓 커밋이 훅을 지난다.

**불변 규칙**: 검사 추가·완화 없음(표시만) · 커밋 범위 규칙(W-0075) 그대로.
