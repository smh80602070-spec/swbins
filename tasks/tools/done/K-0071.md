# K-0071 웹 3D 에셋 압축 — GLB meshopt + 텍스처 WebP, 화질 그대로
종류: 통합·도구(웹 최적화)      상태: **끝**(페이블 2026-10-05)      등급 목표: D2

**목표(한 줄)**: 웹 다섯 판이 읽는 GLB(사가고 280개 평균 656KB, shared/assets 261MB)와 PNG 텍스처를 **보이는 품질은 그대로** 두고 크기만 줄인다. 폰 첫 로딩·메모리의 가장 큰 덩어리다. 사용자 규칙: 최적화는 화질을 깎지 않는다.

**지금 상태(확인함, 10-05)**
- `tools/glb-compress/` 가 있다(Godot variants 압축에 쓴 도구, K-0010). 웹 GLB 에는 아직 안 돌렸다.
- 웹 GLB 는 `saga-web/shared/assets/`(한 벌, `../shared/assets` 참조)와 판별 `saga-web/<판>/assets/`(판 전용) 둘. three.js r16x 는 `GLTFLoader.setMeshoptDecoder` 로 meshopt 를 읽는다(vendor 에 `meshopt_decoder.js` 추가 필요 — MIT).
- 그림은 PNG 749장(사가고). 1MB 넘는 PNG 는 0 이지만 합이 크다.

**파일**: `tools/glb-compress/*`(웹 모드 추가) · `saga-web/shared/assets/**/*.glb` · `saga-web/<판>/assets/**/*.glb` · `saga-web/<판>/js/vendor/meshopt_decoder.js`(새, 다섯 벌은 `tools/sync-shared.mjs` FILES 에 추가) · 텍스처 `*.png → *.webp` 는 **이름 표**(`tools/gen-assets3d-ids.mjs`)가 참조하는 경로만.

**단계**
1. 측정 먼저: `node tools/glb-compress/measure.mjs saga-web`(없으면 만든다 — 개수·합계·평균, 판별) → 티켓 메모에 표.
2. GLB: gltfpack(meshopt, `-cc` 금지 → `-c` 만, 정점 양자화 기본, **텍스처는 건드리지 않음**) 로 `_out/` 에 산출 → 원본과 삼각형 수·바운딩 박스 같은지 검사(`glb-compress/verify.mjs`) → 통과분만 제자리 교체. 압축 전후 크기 표.
3. 로더: 다섯 판 `assets3d.js`(shared 정본) 에 `MeshoptDecoder` 연결 한 줄 + vendor 파일 + sync-shared.
4. 텍스처: GLB 밖 PNG 중 알파 없는 배경·타일만 WebP q90(무손실 아님, 눈으로 구분 안 되는 범위) — 알파 스프라이트·아이콘은 **건드리지 않는다**(테두리 번짐). 이름 표 갱신.
5. 진단: `node tools/test-web.mjs saga-go`(수 안 줄 것) · 사가고·사가의숲 3D 장면 촬영 1장씩 전후 비교(`saga-web/tools/playcheck/`) — 차이 수치가 README 그래픽 게이트 문턱 안.

**검증**: `node tools/test-web.mjs saga-go saga-forest` 전후 같음 · `node tools/sync-shared.mjs --check` OK · `node tools/gen-assets3d-ids.mjs --check` OK · `bash tools/precheck.sh` OK · 크기 표(전후).

**완료 조건**: 단계 1~5 · GLB 합계 40% 이상 감소(목표, 못 미치면 수치와 이유만 적고 끝) · 촬영 전후 차이 문턱 안 · 화질 손잡이(그림자·해상도)는 손대지 않음.

**본보기**: `tools/glb-compress/README.md`(K-0010 방식) · `tools/sync-shared.mjs` FILES 표.

**불변 규칙**: 화질 안 깎기(텍스처 해상도·그림자·AA 금지) · 알파 그림 WebP 금지 · 에셋 파일 교체는 이 K 티켓만(웹 갈래는 로더 한 줄도 shared 정본 경유) · 출처 `.license.json`·CREDITS 그대로.
