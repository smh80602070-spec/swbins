# K-0006 옷 무늬 타일 64종 → wardrobe/vroid-variant 규격
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2 — 타일 + 표 + 출처 기록

**목표(한 줄)**: 지금 32종인 옷 무늬 타일을 64종(과거 20·현대 20·미래 20 + 문장 4)으로 늘려, 이음매 검사를 통과한 것만 `saga-godot/assets/wardrobe/patterns/` 와 `saga-web/shared/assets/patterns/` 에 두고 `patterns.json` 표를 만든다. 옷 변형은 이 타일을 `tools/char-forge/make_wardrobe_textures.py --patterns 64` 가 읽어 만든다.

**파일(확인함)**: `tools/ai-art/make_pattern_batch.py`(32종 사전, 확장) · `tools/ai-art/batches/web_patterns_32.json`(→ `web_patterns_64.json`) · `tools/ai-art/make_seamless.py`(이음매) · `tools/char-forge/make_wardrobe_textures.py`(소비, `PATS` 경로·`--patterns` 인자) · 산출 `saga-godot/assets/wardrobe/patterns/*.webp`+`patterns.json` · `saga-web/shared/assets/patterns/` · 읽는 쪽 `saga-godot/games/saga_go/world/wardrobe.gd`·`saga-web/*/js/vroid-variant.js`(**읽기만**, 표 형식을 맞춘다)

**본보기**: 기존 32종 사전(천·무늬 묘사만) · 교훈(`K-0015`): 애니풍 모델은 "top down view" 에 사람을 그리니 **`sd_xl_base_1.0`** + 사람 금지어.

**단계**
1. 현재 32종을 시대(과거·현대·미래·문장)로 분류해 표로 센다 → 모자란 시대만 새 32종을 `PATTERNS` 에 더한다(이름·원작·작가 금지, 천·무늬 묘사만). `web_patterns_64.json` 생성(`--dry` 로 금지어 검사).
2. 새 32종만 생성: 모델 `sd_xl_base_1.0`, 640×640, negative 에 `person, people, body, skin, hands, face, nude, anime`. 이미 있는 그림은 `gen.py` 가 건너뛴다. `start_sd.ps1` → 생성 → **`stop_sd.ps1`**(PC 안 멈추게 규칙).
3. 눈으로 확인(사람 몸이 섞이면 그 장 삭제·재생성 — 시트는 Artifact 한 장).
4. `py tools/ai-art/make_seamless.py <out>` → 256px 타일 + 3×3 시트. 가장자리 평균 절대차 ≤ 8/255 아니면 재생성.
5. webp 로 굽기(품질 85, 각 ≤ 60KB) → 두 폴더에 복사 + `patterns.json`(`{id, era, name(가명·일반명사), file}`) + 출처 `*.license.json`.
6. `make_wardrobe_textures.py` 가 64종으로 도는지 `--patterns 64` 로 한 번.

**검증**
```
ls saga-godot/assets/wardrobe/patterns/*.webp | wc -l        → 64
du -ch saga-godot/assets/wardrobe/patterns/*.webp | tail -1  → 4MB 이하 · 각 ≤ 60KB
py tools/char-forge/make_wardrobe_textures.py --patterns 64  → 오류 0, items.json 갱신
bash tools/precheck.sh                                       → OK
```
