# K-0173 UI 스킨(K-0040) 유니티 배치 — 다섯 판 9-slice 스프라이트 (U-0153 요청)
종류: 에셋 배치(asset-place)      상태: **끝**(10-22 유니티 U-0153 요청 → 오퍼스 R-0·실행 10-22)      등급 목표: D2

**왜**: 유니티 U-0153 이 `SagaUi.NewPanel`·`NewButton` 을 웹 W-0252 와 같은 "틀 하나·판별 색 옷" 으로 바꾼다. 코드는 `Resources.Load<Sprite>("UI/<판>/<부품>")` 을 부르고 없으면 지금 단색으로 돈다. 유니티엔 UI 스킨이 하나도 없다(`SagaCore/Resources/` 에 UI 폴더 없음) — `asset-place.json` 의 `ui-skin` 목표가 web·godot 둘뿐이고 note 에 "Unity 스프라이트 설정은 U 갈래" 라 적혀 있지만 `.meta` 는 K 몫(유니티 큐 머리 규칙)이라 여기 요청한다.

**만들 것**: `asset-place.json` `ui-skin` 에 unity 목표 `saga-unity/Assets/SagaCore/Resources/UI`(sidecar `.meta`) — 결과 `UI/<go|dungeon|forest|story|realm>/<부품>.png` + `.meta`, 출처 `.license.json` 그대로(ui_parts.json 도 같이).

**`.meta` 설정**(부품 19 × 5 = 95장):
- textureType Sprite(2D and UI) · spriteMode Single · mipmaps 끔 · filter Bilinear · wrap Clamp · 압축 없음(또는 고품질) · alphaIsTransparency 켬 · meshType **Full Rect**(Sliced 필수)
- spriteBorder(왼·아래·오른·위 px) = `ui_parts.json` 의 `slice`: window 32 · popup 36 · card 28 · tab_on/off 14 · btn_* 24 · grade_1~5 24 · bubble 28 · gauge_frame `x14` → (14,0,14,0) · gauge_fill_* null → 0
- pixelsPerUnit 100(코드가 `pixelsPerUnitMultiplier` 로 맞춤)

**유니티가 쓰는 자리**: `SagaCore/SagaUi.cs` `NewPanel`·`NewButton`(창 window·모달 popup·카드 card·탭 tab_on/off·단추 btn_normal/hover/pressed/disabled). 판 이름 = 씬 이름의 짧은 이름(go·dungeon·forest·story·realm).

**이름 정책**: 그림에 글자·인물 없음(부품 틀만) — 해당 없음.

**완료 조건**: 95 png + `.meta` 가 위 경로에 · border 값 표대로(`.meta` grep `spriteBorder`) · 유니티 배치에서 임포트 오류 0 · U-0153 메모에 "K-0173 끝" 한 줄.

**메모(체크포인트)**:
- 10-22 끝(오퍼스, 요청이 이미 실행 칸을 다 담아 R-0 = 이 메모): asset-place `ui-skin` 에 unity 목표 `saga-unity/Assets/SagaCore/Resources/UI`(sidecar .meta) → 복사 191(png 95 + license 95 + ui_parts.json). 유니티 배치로 만들면 기본 텍스처 메타(테두리 0)라 새 `tools/asset-place/unity_sprite_meta.py` 가 .meta 를 직접 씀 — Sprite·Single·**Full Rect**·밉맵 끔·Bilinear·Clamp·압축 없음·alpha 투명·100px/unit · spriteBorder = slice(숫자 n → 넷 n · "x14" → (14,0,14,0) · null → 0) · guid·spriteID = 경로 md5(다시 돌려도 같음, 있는 .meta 는 guid 유지). `--check` UI_META 어긋남 0/95 (window 32·gauge_frame 14,0,14,0 grep 확인). json·폴더 .meta 와 임포트 오류 0 확인은 유니티를 여는 쪽(다른 세션 Unity 겹침 피함) → 수신함 유니티 줄.
