# K-0003 `data/heroes.json` + `tools/gen/gen-web.mjs`
종류: 통합      판: 웹 다섯(데이터)      등급 목표: (체제) — 도감 손 편집 한 곳

**목표(한 줄)**: 다섯 벌 같은 `data.js`(507줄: `HEROES`·`PETS`·`BIOS` + 조회 함수) 의 데이터를 `data/heroes.json`·`data/pets.json`·`data/bios.json` 정본으로 빼고, 생성기가 다섯 `js/data.js` 를 다시 써서 **의미가 같고 md5 가 다섯 다 같게** 만든다.

**파일**: `data/heroes.json`·`pets.json`·`bios.json`(새) · `tools/gen/gen-web.mjs`·`tools/gen/data.template.js`(새) · 다섯 `saga-web/<판>/js/data.js`(생성물) · 다섯 `sw.js`(VERSION +1) · `tools/precheck.sh`(생성물 일치 검사 3줄)

**본보기**: `saga-web/saga-go/js/data.js` 22~30행(IIFE 머리)·144·270행(PETS·BIOS 시작)·499행(조회 함수). 함수 부분은 템플릿에 **문자 그대로** 둔다.

**단계**
1. 추출: `node -e` 로 사가고 `data.js` 를 `vm` 에 로드해(`global.DG={}` 준비; 노출 이름은 `grep -n "global.DG\|DG.data\s*=" data.js` 로 확인) `HEROES`·`PETS`·`BIOS` 를 JSON 으로(`JSON.stringify(obj, null, 2)`, 키 순서 유지). → 커밋.
2. `gen-web.mjs`: 템플릿 = 사가고 data.js 에서 배열 리터럴 세 덩어리를 `/*__HEROES__*/` 같은 표식으로 바꾼 파일. JSON 을 2칸 들여쓰기로 박아 다섯 `js/data.js` 에 쓴다. `--check` 는 쓰지 않고 현재 파일과 비교만(종료 0/1).
3. 검사: 생성된 data.js 를 다시 vm 로 로드해 원본 객체와 `assert.deepStrictEqual` · 다섯 md5 같음 · `node -c`.
4. 이름 정책(실명 금지) 검사: `saga-web/tools/content-editor/` 의 실명 가드 목록(`grep -rln "realname\|실명" saga-web/tools/content-editor/`)을 `heroes.json` 의 `name`·`hanja`·`bios.desc` 에 돌리는 함수로 gen 에 포함(걸리면 생성 거부).
5. precheck 절: `node tools/gen/gen-web.mjs --check` 종료 1 이면 FAIL.

**검증**
```
node tools/gen/gen-web.mjs            → "5 files written, deepEqual OK, md5 <같은 값> ×5"
node tools/gen/gen-web.mjs --check    → 종료 0
node tools/test-web.mjs saga-story    → n 그대로
bash tools/precheck.sh                → OK
```

**완료 조건**: 위 넷 · `data/*.json` 셋 · 템플릿 · `tools/README.md` "게임 만들기" 표 한 줄.

**불변 규칙 확인**: 인물·펫 `id` 변경 0(deepEqual 이 보장) · 세이브 키 무관 · content-editor 가 data.js 를 직접 쓰는 경로가 있으면(`grep -rn "data.js" saga-web/tools/content-editor/`) 메모에(다음 티켓에서 정본으로 돌림).
