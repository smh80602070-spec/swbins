# K-0189 탈것 소리 — 말굽(무른 땅·단단한 땅)·날갯짓(학)·큰 날개(용) 효과음 (유니티 요청 — 큐 머리글 후속 후보 "말·탈것 위 발소리")
종류: 에셋(소리) · 자체툴(asset-forge sfxset)      상태: **끝**(10-24 유니티 Opus 요청 → 10-25 오퍼스 R-0)      등급 목표: D2

**왜**: 유니티 다섯 판엔 탈것이 있다(1만리 농마·갈색 말·흰 말·학·푸른 용, 다른 판 사슴 등 — `saga-unity/Assets/Games/*/Data/*Mounts.cs`). 걸을 때는 지면별 발소리(U-0051, `sfx_step_{dirt,grass,sand,snow,stone,wood}_N` — `tools/asset-forge/sfxset.py` 코드 합성 CC0)가 나지만, 말을 타면 같은 사람 발소리이거나 소리가 없고 날 때는 아무 소리도 없다. 유니티 갈래는 에셋을 만들지 않으므로(QUEUE 머리글) 요청한다.

**만들 것**(규격은 기존 `sfx_step_*` 와 같게 — 44.1kHz 모노 ogg + `<id>.license.json`, 코드 합성 CC0, 외부 입력 없음):
- `sfx_hoof_soft_1~3` — 무른 땅(흙·풀·모래·눈) 말굽 한 번, 둔탁, 120ms 안팎.
- `sfx_hoof_hard_1~3` — 단단한 땅(돌·나무) 말굽 한 번, 또각, 100ms 안팎.
- `sfx_wing_flap_1~3` — 학·새 날갯짓 한 번(깃 스치는 바람), 250ms 안팎.
- `sfx_wing_heavy_1~2` — 용 큰 날개 한 번(낮은 바람 덩이), 400ms 안팎.
- 크기는 `sfx_step_*` rms(-27dB 언저리)와 어울리게.

**어디에**: `saga-unity/Assets/SagaCore/Resources/Audio/Sfx/`(기존 `sfx_step_*` 옆 — `.meta` 는 K-0019 배치가 올림). 웹·고돗도 쓰고 싶으면 같은 레시피에서 각 트랙 자리로(세계 자산 = 프로젝트×다섯 판 원칙) — 그건 K 판단.

**유니티 쪽(K 가 끝나면 U 가 함)**: 판별 `FootstepSfx`(1만리 `Games/SagaGo/Player/FootstepSfx.cs` Tick 의 `riding`)·다른 네 판 발소리 자리에서 탔으면 지면 → soft/hard 말굽, 날면 날갯짓(학·새 = flap · 용 = heavy) — U 티켓은 이 요청이 끝나면 R-0.

**이름 정책**: 소리라 해당 없음. 출처 = 코드 합성(크레딧 `--check` 0 유지).

**파일**: `tools/asset-forge/sfxset.py`(목록에 `foot` 카테고리 11 줄 더함 — 말굽 soft 3·hard 3 = 둔탁/또각 노이즈 펄스 + 낮은 tone · 날갯짓 flap 3 = 밴드패스 노이즈 휙 · heavy 2 = 낮은 로우패스 덩이 두 번) · 정본 `saga-assets/sfx/` · 유니티 사본 `saga-unity/Assets/SagaCore/Resources/Audio/Sfx/`
**단계**: ① sfxset.py 에 11 id(같은 씨앗 → 같은 소리) ② `py tools/asset-forge/sfxset.py` → `_out/sfx` ③ 정본·유니티 자리로 복사(.license.json 함께) ④ 수신함 유니티 줄(위 "유니티 쪽") · 웹·고돗 쓰려면 수신함 줄만
**검증**: `py tools/asset-forge/sfxset.py --check` → SFX_OK(foot RMS 편차 ≤3dB) · `py tools/asset-audit/credits.py --check` 0 · 길이 재기(soft≈120·hard≈100·flap≈250·heavy≈400ms, ±30%)
**완료 조건**: 11 ogg + license 정본·유니티 자리 · SFX_OK · done/ · 수신함 U 줄
**불변**: 기존 sfx id·소리 안 바뀜(같은 씨앗) · 외부 입력 없음

**메모**:
- 10-25 끝(오퍼스): sfxset.py `mount()`·`swell()` + plan MOUNT 11(foot 카테고리) → sfx_hoof_soft_1~3(120ms)·hoof_hard_1~3(80ms)·wing_flap_1~3(250ms)·wing_heavy_1~2(420ms), RMS -27.0 · `--check` SFX_OK(foot 23종 편차 0.6dB) · credits OK · 정본 `saga-assets/sfx` 에 새 22 파일만(옛 96 은 ogg 인코딩이 바이트로 안 같아 안 덮음) → place sfx 웹·고돗·유니티 빠짐 0 · 수신함 유니티 줄.
