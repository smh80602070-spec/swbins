# K-0089 사가나락 문 아치·기둥 모델 — 돌 타일이 늘어나지 않게 UV 펼친 판
종류: 에셋 요청 · 자체툴      요청: U-0066(유니티 갈래, 2026-10-09)      상태: **끝**(10-09 Opus — K-0090 세션)

**무엇을·왜**: 유니티 사가나락 방 문 아치·기둥(`saga-unity/Assets/Art/Dungeon/gate.glb`, CC0 Kenney Modular Cave Kit)은 UV 가 색 아틀라스(colormap) 전용이다. PBR 경로(`DungeonRoomBuilder.BuildGateArch` → `EnvironmentMaterial.MakeTiled(wallMaterial, …)`)가 벽과 같은 돌 텍스처를 씌우면 **세로 줄무늬로 늘어난다**(U-0063 촬영 `saga-unity/.utmp/shots-u0063/dungeon/nameEraDecor_*`·`typeEraFolk_1`, 10-08 `shots-u0058/TestDungeon`). 같은 치수·원점으로 **돌 타일용 UV(미터당 일정, 상자 투영이면 충분)**를 펼친 문 모델이 필요하다.

**어디에 쓰나**: 같은 경로 `Assets/Art/Dungeon/gate.glb` 를 갈아 끼우거나(치수·원점·문 폭 4.4m 그대로 — `GateModelWidth`·`RoomDoorWidth` 가 이 값을 쓴다), 새 이름이면 U 가 `BuildTestDungeonScene.GateGlbPath` 를 바꾼다. 마모 3단(`wearTier`)은 재질 쪽이라 모델은 한 벌.

**완료 조건(제안)**: 실측 폭 4.4m·원점 바닥 가운데 유지 · UV 0~1 넘어 반복 가능(타일) · 출처 `.license.json`(자체 제작 또는 CC0) · `world-forge` 레시피 또는 Kenney 원본 UV 재투영 도구로.

**이름 정책**: 해당 없음(소품). **에셋 배치**: K-0019 배치가 `Assets/` 에 올린다 — U 는 놓인 뒤 씬 재빌드 없이 확인(문은 런타임 생성).

**메모(끝, 10-09)**: 새 도구 `tools/world-forge/retile_uv.py`(상자 투영, UV 0~1 = unit 미터) → 정본 `saga-assets/world/dungeon-kit/gate_tiled.glb`(+license, Kenney CC0 모양 그대로) → 새 place 항목 `dungeon-kit` → 유니티 `Assets/Art/Dungeon/gate_tiled.glb`. 원본과 삼각형 592·경계·원점·재질·노드 같음, UV 넓이비 0 → 중앙 1.0(5% 0.7). **새 이름**으로 둔 까닭: 원본 UV 는 아틀라스 경로(PBR 끔)가 계속 씀. 배선 = U-0069(유니티 큐 2번).
