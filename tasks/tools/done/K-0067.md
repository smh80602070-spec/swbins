# K-0067 하늘 파노라마 해·달 위치를 그림과 맞게 — 해를 실제로 그리고 `sky_markers.json` 을 그림에서 읽은 값으로(U-0041 후속)
종류: 새기능 · 에셋      상태: **닫음**(10-07 큐 정리 — 자체툴 몫 끝, 사용자 거부권·다른 갈래 연결은 그대로) · **끝**(10-05) — 해·달을 그림에 그려 표식 측정값 기록, 유니티가 `sun_uv` 로 방위 변환      등급 목표: D2

**무엇을**: 하늘 파노라마 12장(`sky_<새벽·낮·노을·밤>_<과거·현재·미래>`, K-0034/K-0064)에서 **해(새벽·낮·노을)와 달(밤)이 그림에 실제로 보이게** 하고, `sky_markers.json` 의 `sun_az`·`sun_el`(달은 `moon_az`·`moon_el`)을 **그림에서 읽은 값**으로 바꾼다. 방위 규약은 기존 그대로(0 = 북 · 90 = 동 · 180 = 남 · 270 = 서, 고도 0 = 지평선).

**왜**: 유니티가 이 표식으로 조명(Sun 의 방향·고도·색)을 하늘에 맞추려는데, 지금은 검증이 안 된다 — 낮 하늘엔 해가 안 그려져 있고(푸른 하늘·비행기구름), 노을은 빛 번짐이 표식 자리(방위 265°·고도 6°)와 이미지상 위치가 안 맞는다(밝은 점 검출도 지평선 아래로 나옴). 표식이 "의도한 위치"일 뿐 그림에서 읽은 값이 아니라서다.

**어떻게(제안)**: 둘 중 쉬운 쪽 — (a) 생성 때 해를 넣은 후보만 고르거나 합성으로 해 원반·빛무리를 얹고 그 자리를 표식으로 기록 / (b) 지금 그림 그대로 두고 **가장 밝은 번짐을 이미지 u·v 로 측정해 표식을 정정**(해가 없는 낮은 "해는 화면 밖 위쪽"이라 적고 고도를 높게). 투영은 등장방형(2:1), 유니티 `Skybox/Panoramic`(`_Rotation` 270)이 쓰는 방식 — 표식에 이미지 좌표(u, v)도 같이 적어 두면 유니티가 방위를 변환한다.

**어디에**: 기존 위치 `tools/ai-art/_out/sky_final/` → K-0019 배치가 `saga-unity/Assets/SagaCore/Resources/Sky/` 로(그림·`sky_markers.json`). 이름·크기(2048×1024 jpg)·파일명 규칙은 그대로.

**이름 정책**: 표시 글자 아님 · 출처 `.license.json` 갱신 · 비상업 모델 금지(§7.4).

**Unity 쪽 후속**: `tasks/unity/U-0041.md` — 표식이 그림과 맞으면 `GoSkyPass` 가 Sun 의 방향을 표식으로 맞춘다. **K 가 "그림에 해를 못 넣는다/표식을 못 믿는다" 면 폴백 A**(시간대별 고도·색온도만) 로 간다.

**메모(10-05)**: ✔ (a)+(b) 합친 길 — `tools/ai-art/sky_sun.py`(apply·check): 원본 `_out/sky_final` 12장에 **해(새벽·낮·노을)·달(밤) 원반 + 빛무리를 구면 각거리로 합성**(등장방형 위쪽에서도 원, screen 이라 구름 밑으로 안 눌림) → `_out/sky_sun`. 위치는 기본 자리 둘레에 그림의 작고 밝은 점(행성·구름 덩이)이 40 넘게 있으면 범위 안에서 그런 점이 가장 약한 자리로 옮김(noon_past 184°/70° · noon_future 157°/66° · dawn_present 107°/6° · sunset_present 259°/4° · night_past 212°/56° 등). **표식 `sky_markers.json`**: `sun_az·sun_el`(밤은 `moon_az·moon_el` + 조명용 `sun_*` 같은 값·`light:"moon"`)에 **`sun_uv`·`moon_uv` [u,v]**·`drawn:true`, 미래 밤은 `moon2`. 규약 `az=u·360` · `el=90−v·180`(0=북·90=동·180=남·270=서) — 유니티 `Skybox/Panoramic`(`_Rotation` 270)은 uv 에서 자기 방위를 구한다. 검사 `sky_sun.py check`: 표식 둘레 ±14° 에서 읽은 가장 밝고 작은 점이 표식과 ≤2.5°(12장 오차 0.1~2.1°) · SKYSUN_OK. 정본 `saga-assets/sky`(webp 12+1k 12+표식) 갱신 → 웹·고돗, `unity_sky.py` 로 jpg 다시 → `saga-assets/sky-unity` → `Resources/Sky`(25 파일 갱신, `.meta` 는 그대로). 일부 하늘(dawn_present 등)은 그림 아래쪽(극점 보정 띠)에 더 밝은 점이 있으나 해 자리와 무관.
