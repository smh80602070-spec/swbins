# K-0038 크레딧·라이선스 화면 자동 생성 — `.license.json`·ASSET_LICENSES 를 모아 게임 안 크레딧 문서로
종류: 새기능 · 도구      상태: **닫음**(10-07 큐 정리 — 자체툴 몫 끝, 사용자 거부권·다른 갈래 연결은 그대로) · **끝**(10-04 — 단계 3 은 사용자 "큐 순서대로 다 적용"에 따라 precheck 연결) — 시작 조건: 바로 가능(작음)      등급 목표: D2

**목표(한 줄)**: 상용에는 크레딧 표기가 필수다(VRoid 샘플 `creditNotation: required`, CC0 도 출처 기록 권장). 산출마다 있는 `.license.json` 과 판별 `ASSET_LICENSES.md` 를 집계해 **한 벌의 크레딧 문서(웹·Godot·Unity 공용 JSON + 사람이 읽는 MD)** 를 자동 생성한다. 손으로 쓰지 않는다.

**파일(확인함)**: `tools/asset-audit/audit.py`(출처 점검, 읽기 선례)·`saga-assets/**/*.license.json`·`saga-web/<판>/assets/ASSET_LICENSES.md`(5)·`saga-godot/docs/ASSET_GUIDE.md`·`saga-unity/docs/ASSET_GUIDE.md`·`tools/char-forge/data/vroid_licenses.json`(VRoid 샘플 조건) · 새 `tools/asset-audit/credits.py`·`saga-assets/credits.json` · 배치 K-0019

**단계**
1. 출처 종류 표: 모델 라이선스(CC0·OpenRAIL++·Apache·VRoid 샘플 조건…)별로 요구 문구(크레딧 필수 여부·성명 표시)를 정리.
2. `credits.py`: 모든 `.license.json`·ASSET_LICENSES 를 읽어 (에셋 묶음 · 출처 · 라이선스 · 요구 문구) 로 묶고 중복 제거 → `credits.json`·`CREDITS.md`.
3. 크레딧 필수 출처(VRoid 샘플 등)가 한 줄이라도 빠지면 FAIL 하는 검사(`--check`)를 `precheck.sh` 에 연결할지 사용자에게 묻는다.
4. 게임 안 크레딧 화면은 각 갈래가 `credits.json` 을 읽어 그린다(여기선 데이터만).

**검증**: `credits.py --check` 통과 · 라이선스 없는 에셋 0 · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3.

**불변 규칙**: 출처 모르는 것은 목록에 "미상" 으로 올리고 숨기지 않는다 · 비상업 에셋이 섞이면 FAIL.

**메모(체크포인트)**: 10-03 `tools/asset-audit/credits.py`(--check) → `saga-assets/credits.json`·`CREDITS.md`. 모은 것: .license.json 709(묶음 9)·VRoid 샘플 35벌(크레딧 필수 0)·문서 261절(표기 줄·CC-BY 표 행 → 필수 표기 7줄, 자동으로 못 가른 줄·낱말 못 찾은 절 48은 숨기지 않고 목록). 주의: shebang 있는 .py 는 `py` 가 스토어 python 을 불러 종료 49 — shebang 빼거나 `py -3`. 남은 것: precheck 에 --check 연결할지 사용자에게 묻기(단계 3), 갈래별 크레딧 화면(단계 4 는 각 갈래 몫).
✔ 10-04: 새 에셋 묶음(자연·마을·필드·실내·무기·장비·하늘·국지 UI 등) 반영해 `credits.py` 재생성 → 묶음 28(필수 표기 7줄 그대로). 단계 3: `tools/precheck.sh` 에 `credits.py --check` 연결(크레딧 필수 출처가 빠지면 FAIL — 지금 `credits OK`). 게임 안 크레딧 화면은 각 갈래가 `credits.json` 을 읽어 그린다.
