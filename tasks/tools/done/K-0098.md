# K-0098 VS Code 대화 세션 자동 이어하기 — 티켓 끝나면 같은 창에서 다음 "이어해", 문맥 70% 면 멈춤

**목표(한 줄)**: 사용자 10-12 "오토런툴이 vs code 이어해 자동으로 해주고 70ctx면 멈추는 기능" · "백그라운드면 필요 없을듯" · "vs code 에서 여러 개 열어서 해" — 켜 둔 VS Code 세션에서 "<갈래> 이어해" 를 한 번 치면, 티켓을 끝내고 멈추려 할 때 Stop 훅이 같은 창·같은 대화에 다음 "이어해" 를 돌려 넣는다. 문맥 70% 면 체크포인트 커밋 후 그 창에서 멈춘다. K-0079 의 백그라운드 넘김(autorun 데몬 POST)은 뺀다.

**지금 상태(확인함, 10-12)**

- 사용자는 VS Code 창 여럿을 갈래마다 띄워 같은 트리에서 동시에 돌린다.

**파일**: `tools/claude-home/ctx-guard.js` · `tools/claude-home/statusline.js`(pct 에 창 크기 `size` 도) · `tools/claude-home/install.js`(옛 bash 상태줄이면 statusline.js 로 바꿈) · `tools/autorun/README.md` 절 · `tasks/tools/QUEUE.md` 끝 줄.

**단계**
1. Stop 훅 이어하기: 그 턴이 "이어해"(또는 훅의 이어하기)로 시작했고 · 갈래 잠금 주인이고 · 문맥 < 70% 이고 · 마지막 말이 질문·"⏸" 가 아니고 · 그 턴에 **자기 갈래 티켓 번호(W-/G-/U-/K-NNNN)가 붙은 커밋**이 생겼으면 `decision: block` 로 "<갈래> 이어해" 를 돌려 넣는다. 사용자가 다른 말을 치면 그 세션은 자동 이어하기를 끈다. 상한 `SAGA_LOOP_MAX`(30).
2. 70%: 지시 한 번(UserPromptSubmit·PostToolUse·Stop 한 번 막기) — 체크포인트 커밋·푸시 후 "⏹ 문맥 70% — 새 대화에서 '<갈래> 이어해'" 로 끝. 그 뒤 Stop 은 통과, 갈래 잠금 풂. 데몬 POST 삭제.
3. 여러 창: 갈래 잠금 `_ctx/lane-<갈래>.lock`(세션 id·ts, 20분 소식 없으면 풀림). 두 번째 창은 "다른 창이 돌리는 중" 알림만 받고 자동 이어하기 안 함.
4. 문맥 %: 상태줄 `.pct`(15분 안) 우선, 없으면 transcript 끝의 usage(input+cache+output) ÷ 창 크기(`.pct` 의 size → `SAGA_CTX_WINDOW` → 1000000).
5. install.js: statusLine 이 옛 `statusline-command.sh` 면 statusline.js 로 바꾼다(같은 모양, 파일 쓰기만 더함). 끄기 = `_ctx/LOOP-OFF` 파일 또는 `SAGA_LOOP=0`.

**검증**: `node -c` 세 파일 · 훅 직접 호출 시험(가짜 `_ctx`·임시 git 커밋 없이 `SAGA_TEST_COMMITS` 로): 커밋 있음 → block · 커밋 없음/질문/⏸/LOOP-OFF/다른 말 → 무출력 · 70% → 지시 한 번 뒤 통과 · 두 세션 같은 갈래 → 두 번째 무출력 · install.js 두 번 → settings 같음 · `bash tools/precheck.sh` OK.
