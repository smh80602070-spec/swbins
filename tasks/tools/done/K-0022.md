# K-0022 VRoid 대량 들이기 — 인물 3D·2D 에셋을 이어하기로 자동 처리하고 진행표를 낸다
종류: 새기능 · 도구      상태: **완료**(2026-10-02) — 500명 들이기 자체는 사람(VRoid)과 이 도구의 반복 실행      등급 목표: D2

**목표(한 줄)**: 사용자 결정(2026-10-02) "**인물 에셋은 VRoid 로 다 한다**". VRM 이 폴더에 쌓이면 새로 들어온 것만 골라 인물마다 **3D 에셋(툰 GLB·CC0 동작 8, 웹 3D·Godot·Unity 동일)** 과 **2D 에셋(128px 시트)** 을 만들고, 인물별 진행표를 낸다. **도감은 VRoid 가 아니다** — 도감(데이터·초상)은 기존에 추가하던 방식(`data.js` 다섯 벌 md5 동일 + `tools/ai-art` 초상)으로 늘려 500명을 만든다(이 티켓 밖). 폐기: MakeHuman 실물풍·무작위 장비·범용 시트 20벌.

**파일**: `tools/char-forge/` 의 `vroid_intake.sh`·`bake_for_rig.py`·`verify.py`·`bake_sprite_batch.py`·`data/roster.json`(299) · 놓기 K-0019

**규약**: VRM = `_in/vroid/<id>.vrm`(git 밖, id 영문 소문자·숫자·`_`) → 산출 `_out/vroid/<id>/` → 통과분만 K-0019.
**받는 법(10-02 실측)**: 쓸 수 있는 건 공식 샘플 `AvatarSample_A`~`Z`(VRoid Studio 내장 샘플을 VRM 으로 내보낸 것, 상업·개작·재배포 허용)와 직접 만든 VRM. VRoid Hub 에서 받은 것은 대개 `personalNonProfit`·`modification: prohibited`·`allowRedistribution: false` 라 못 쓴다(옷 추출도 개작). 판정은 `vroid_samples.py` 가 VRM 메타로 한다(`data/vroid_licenses.json`) — `--copy` 는 허용인 것만 `_in/vroid` 로 복사. 26벌 ≠ 500명이라 변주(옷 조각·무늬 64·색)와 새 VRM 을 섞는다. 옷 추출은 체형이 같은 몸끼리만 맞는다.

**단계**
1. `vroid_status.py`: 명단 id + `_in/vroid` 의 신규 id × 단계(`vrm`·`glb`·`anim`·`sheet2d`) 표, 요약("n명 완료/들어옴/대기"), `--missing`.
2. `vroid_batch.sh`: `_in/vroid/*.vrm` 중 결과가 없는 것만 차례로 공통부(GLB 사본·동작 굽기+검증·2D 시트)를 돈다. 낮은 우선순위·`</dev/null`·실패는 로그에 남기고 계속·3회 실패면 건너뜀 표시.
3. Godot 부(`anim_cc0/<id>_lib.res` 등, Godot exe 필요)는 분리 — exe 가 없으면 "대기"로 두고 나머지 진행(압축 `scratchpad/keep/Godot.zip` 은 푼 뒤 `GODOT=` 지정).
3b. **경량화**: 웹용은 모프 제거 + Meshopt·WebP 1024px(벌당 ≤ 0.8MB), 웹 3D 는 한 판에만(Pages 한도). 사람 몸 삼각형은 안 줄인다(허용치 6.5만).
4. 시험: 사용자 VRM 1개(또는 시험용 `saga-godot/assets/characters_vroid/AvatarSample_A.vrm`)로 3D·2D 가 나오고 `audit.py --quick` 🔴 0.
