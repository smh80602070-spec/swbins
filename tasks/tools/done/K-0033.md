# K-0033 NPC·병사·적 인간형 군중 — 옷 이식 도구로 수백 명을 싸게 뽑는다
종류: 새기능 · 에셋      상태: **닫음**(10-07 큐 정리 — 자체툴 몫 끝, 사용자 거부권·다른 갈래 연결은 그대로) · **굽기 끝**(10-04) — 판정 대기(산출은 로컬 전용)      등급 목표: D2

**목표(한 줄)**: 도감 인물(299+200)과 별개로 게임에는 마을 행인·상인·병사·인간형 적이 대량으로 필요한데, 지금은 소수 몸을 색만 바꿔 쓴다("색만 다른 건 다른 게 아니다"). K-0024 의 옷 이식(`outfit_swap.py`)으로 **역할별 풀**(행인 남·여, 상인, 병사, 도적, 학자, 시대별 3종)을 몸 25 × 옷 조합에서 뽑아 서로 다른 모습 200여 벌을 한 번에 굽는다. 얼굴·머리 반복은 허용(사용자 "약간 다르게만").

**파일(확인함)**: `tools/char-forge/outfit_swap_plan.py`·`outfit_swap.py`·`export_parts_all.sh`·`vroid_batch.sh`·`vroid_status.py`·`data/outfit_swap_plan.json`(도감 299, 겹침 0 검사) · 새 `data/npc_swap_plan.json`(역할 × 풀) · 허용 판정 `data/vroid_licenses.json` · 무늬 `saga-assets/patterns`(64, 선택) · 배치 K-0019

**단계**
1. 역할표: 역할 × 성별 × 시대(과거·현대·미래 한 자리) × 수. 옷 풀은 샘플 옷 모양에서 역할에 맞는 것만(병사=갑옷형·재킷형, 학자=긴 옷 등 — 옷 모양 분류는 렌더 시트 한 장으로 사람이 한 번 표시).
2. 조합표를 도감 인물과 **겹치지 않게** 생성 → `outfit_swap.py --plan` 으로 굽기(도감과 같은 몸이라도 옷 조합이 달라야 함) → `vroid_batch.sh`(동작·웹·2D).
3. 군중용 경량본(삼각형·텍스처 낮춤, 웹 군중 인스턴스용)과 2D 시트.
4. 결과 시트 → 사용자 판정 → K-0019 배치(용량은 K-0024 단계 5 정책).

**검증**: 조합 겹침 0(도감 포함) · `vroid_status.py` 신규 전부 완료 · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~4.

**불변 규칙**: 샘플 이용 조건 허용분만(T 제외) · 산출 공개 저장소 금지(조합표만 커밋) · 이름 정책 · 헤드리스 Blender `</dev/null`·낮은 우선순위.
