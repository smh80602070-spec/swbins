# K-0004 배경음 파이프라인(swbins3 ACE-Step) — 판별 3곡 × 5 + 모델 기록
종류: 새기능(P0)      판: 다섯(자산)      등급 목표: D2 — 곡 파일 + 라이선스 기록. 배선은 W-0016·G-0011·U-0014

**목표(한 줄)**: `data/bgm-plan.json`(판·장면·분위기·길이·씨앗 15줄)을 읽어 `C:\swbins3\music-gen` 의 ACE-Step 1.5(상업 허용)로 슬롯마다 후보 2곡을 만들고, 사용자가 고른 1곡을 `saga-web/shared/audio/bgm/<판>-<장면>.ogg` + `.license.json` 으로 둔다.

**파일**: `data/bgm-plan.json`(새, 이 저장소) · `C:\swbins3\music-gen\batch_saga.py`(새, **swbins3 저장소** — 그쪽 CLAUDE.md 규칙으로 따로 커밋) · `saga-web/shared/audio/bgm/*.ogg`·`*.license.json`(산출) · `tasks/sheets/bgm-pick-<날짜>.md`(고르기 시트)

**본보기**: `C:\swbins3\music-gen\server.py`(ACE-Step 호출 방식 — `grep -n "def \|acestep" server.py`) · 출처 기록 꼴 = `saga-godot/assets/characters_cf/*.license.json` 하나의 키.

**단계**
1. `bgm-plan.json`: 판 5 × 장면 3(마을/거점 · 들판/던전/사냥터/전략지도 · 전투). 줄마다 `{id, game, scene, prompt(영문 분위기 한 줄, 원작 곡명·아티스트 금지), seconds: 75, loop: true, seed}`. 프롬프트는 판 정체성(PLAN §1 한 줄)에서. → 커밋.
2. `batch_saga.py`: plan 을 읽어 슬롯마다 seed·seed+1 로 2곡 → wav → `ffmpeg -i in.wav -c:a libvorbis -q:a 3 out.ogg` → `_out/bgm/<id>-a.ogg`·`-b.ogg` + `.license.json`(`{model:"ACE-Step 1.5", license:"<COMMERCIAL_SWAP_TODO.md 표 문구 그대로>", prompt, seed, date, edited_by_human:false}`). 슬롯 하나 끝날 때마다 진행 파일(`_out/bgm/progress.json`)을 써서 끊겨도 이어서. GPU 는 AMD ROCm — 실패하면 `SETUP_GUIDE_RADEON.md` 절 이름을 메모에 적고 멈춘다(재시도 3회 금지).
3. 고르기 시트: 30곡을 `tasks/sheets/bgm-pick-<날짜>.md` 표(id · a/b 경로 · ○ 칸)로. 사용자가 고르면 다음 세션이 고른 곡을 `shared/audio/bgm/<game>-<scene>.ogg` 로 복사하고 license 의 `edited_by_human` 을 `true` 로.
4. 크기: 곡당 2MB 미만(넘으면 `-q:a 2`). 15곡 합 ≤ 25MB.
5. `tools/asset-audit/audit.py --quick` 통과.

**검증**
```
ls C:/swbins3/music-gen/_out/bgm/*.ogg | wc -l        → 30
ls C:/swbins3/music-gen/_out/bgm/*.license.json | wc -l  → 30
(고른 뒤) ls saga-web/shared/audio/bgm/*.ogg | wc -l   → 15 · du -sh 그 폴더 ≤ 25M · bash tools/precheck.sh OK
```

**완료 조건**: plan 15줄 · 후보 30 · 시트 · (사람 고르기 뒤) 15곡 + license 15 커밋.
