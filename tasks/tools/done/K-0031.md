**단계**
1. **현황표 먼저**: 종(펫·몬스터·탈것) × 동작(대기·걷기·달리기·공격·피격·죽음·특수) 중 이미 있는 칸/없는 칸 — 파일에서 클립 이름을 읽어 표로(추측 금지). 계통 5 로 묶는다.
2. 계통마다 표준 이름 사전 · 있는 클립은 이름만 바꿔 맞춘다(리네임 도구) · 없는 칸은 CC0 동물 동작 재사용 가능한지 먼저 확인, 불가한 칸만 목록으로.
3. 불가 칸의 처리 방안(자체 키프레임 `keyframes.py` 식 또는 대체 동작)을 **사용자에게 선택받는다** — 몬스터·탈것은 모양이 제각각이라 일괄 굽기가 안 되는 부분.
4. 시험 계통별 1종 → 동작 점검 시트 → 판정 → 일괄 → K-0019 배치.

**검증**: 현황표 칸 수 = 파일 클립 수 · 표준 이름 100% · 시험 시트 · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3 + 판정 통과 계통의 4. 판정이 안 된 계통은 목록으로 남긴다.
