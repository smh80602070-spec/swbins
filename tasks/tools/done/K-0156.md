# K-0156 웹 배치 중복 감사 — 같은 파일이 판마다 따로 놓인 406MB(Pages 용량) 표와 shared 로 모을 계획
종류: 감사(읽기만) + place 표 · 자체툴(asset-audit·asset-place)      상태: **끝**(Opus 10-21 — R-0 10-21 작성, K-0138 메모 "saga-web 1.58GB, Pages 권장 1GB 넘음")      등급 목표: D1

**목표(한 줄)**: 10-21 실측 `saga-web` 추적 1,563MB 중 **같은 내용(blob)이 2벌 이상인 파일 2,633종·여분 6,835벌·406MB**(판별 `assets/models` 113·104·86·34MB, `portraits` 8MB씩 …) — Pages 는 벌마다 따로 올라간다 → 어느 place 항목이 몇 판에 같은 파일을 복사하는지 표로 만들고, `shared/assets/` 한 벌로 모을 항목 목록(옮기면 줄어드는 MB 순)을 웹 갈래에 넘긴다. 이 티켓은 웹 파일을 옮기지 않는다.

**파일(확인함 10-21)**: 배치 정의 `tools/asset-place/asset-place.json`(항목마다 `targets[].dir`) · `tools/asset-place/place.py`(`--check`) · 감사 본보기 `tools/asset-audit/models_inventory.py`(git 파일 목록·md5 꼴) · `tools/asset-audit/reflect.py`(코드가 이름으로 닿는지 — 엄격 기준) · 새 `tools/asset-audit/web_dups.py` · 결과 `tools/asset-audit/out/web_dups.{json,md}`.

**단계**
1. 새 `web_dups.py`(읽기만): `git ls-tree -r -l HEAD saga-web` → blob 해시로 묶음 → 2벌 이상 묶음마다 경로·크기·여분 MB · 묶음을 place 항목에 짝지움(경로가 그 항목 target dir 아래) · 짝 없는 것은 "손 배치" 로.
2. 표 `out/web_dups.md`: ① place 항목별 여분 MB 순 ② 판 폴더별 ③ 각 묶음이 판 코드에서 어떤 경로 글자로 읽히는지(`reflect.py` 엄격 기준 함수 재사용 — 경로 접두 `assets/models/…` 를 grep, 줄 수만) ④ shared 로 옮길 때 고칠 코드 자리 수 · 끝 줄 `WEB_DUPS groups=<n> extra_mb=<m>`.
3. 권고 칸(K 판단): 판마다 **다른 내용이 같은 이름**이면 못 모음(표에서 뺌) · 1MB 미만 묶음은 뒤로 · 세이브·도감 id 와 무관함 확인.
4. place 쪽 준비만: 상위 항목 셋에 `targets` 를 `saga-web/shared/assets/<…>` 하나로 바꾼 **초안**을 `out/web_dups_place_draft.json` 에(실제 asset-place.json 은 안 고침 — 웹이 코드 경로를 바꾼 뒤 K 후속).
5. 수신함 웹 줄: "웹 배치 중복 406MB — 표 `tools/asset-audit/out/web_dups.md`, 상위 항목부터 shared 로 모으면 −nMB(코드 경로 m자리) · 끝나면 K 가 place 갱신" .

**검증**: `py tools/asset-audit/web_dups.py` 끝 줄 `WEB_DUPS` 의 extra_mb 가 10-21 실측(≈406)과 ±5% · 표 ① 상위 10 항목 합 ≥ 전체 여분의 70%(아니면 메모에 이유) · 읽기만(실행 전후 `git status --short saga-web tools/asset-place/asset-place.json` 같음) · `py tools/asset-place/place.py --check` 0 · `bash tools/precheck.sh` OK.

**완료 조건**: 표·초안·수신함 줄 · 큐 줄 끝 · done/.

**불변 규칙**: 웹 파일·코드·asset-place.json 안 고침(읽기만, 초안은 out/) · 저장소 밖으로 안 보냄.

**함정**: `du`·`find` 로 saga-web 를 훑으면 2분 넘게 멈춘다 — git ls-tree 만 · 같은 blob 이 `shared/` 안에서도 겹친다(bgm 10MB·characters2d8 5MB — 표에 따로) · Windows 경로 대소문자.
