**목표(한 줄)**: 고돗 다섯 판 숲·둘레에 깔린 Quaternius Stylized Nature(정육면체 잎 덩이 — 점검 시트 ×)를 배경 사실 기준의 자체 나무·바위로 바꾼다.

**파일(확인함)**: 빌린 것 `saga-godot/assets/vegetation`(103 파일, .import 빼고)·`saga-godot/assets/rocks`(52) · 쓰는 곳 `saga-godot/games/saga_go/world/vegetation_builder.gd`·`saga-godot/games/saga_forest/world/forest_vegetation_builder.gd`·`saga-godot/tools/layout/kinds.json`·`_generated/hebei_layout.tscn` · 점검 `tasks/sheets/godot-graphics-audit-20261013.md`(1만리 숲·3마을 둘레·4종횡 뒤 숲) · 자체 빌더 `tools/world-forge/build_nature.py`(tree_broadleaf·pine·birch·dead)·`build_foliage.py`+`foliage_atlas.py`(잎 카드)·K-0104 들풀 · 고돗 사본 자리 = K-0104 가 쓴 곳(`tasks/tools/done/K-0104.md`).

**단계**
1. 쓰이는 이름 목록: 위 세 파일이 부르는 vegetation/rocks 이름 → `tools/world-forge/data/k127_godot_nature.json`(이름 → 자체 id·배율).
2. 사실판 나무: 잎은 **잎 카드 층**(foliage_atlas 잎 장 + 알파) — 정육면체 덩이 금지. 줄기 자체 PBR 결. 바위는 자체 PBR rock 결 + 휘어진 덩이. 종류 수는 옛 쓰임 수만큼(같은 종 변종 셋 이상).
3. Godot 용 굽기(툰 아닌 사실 재질) → `place.py --write` 로 고돗 자리 → Godot 4.7 `--import`(K-0113 메모 ②, `</dev/null`).
4. 수신함 고돗 줄: "builder·kinds.json 이름 표 → 새 id, 옛 vegetation·rocks 지움".
