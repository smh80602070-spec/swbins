# K-0214 — 원격 생성 실패·완료 계약

상태: 구현·검증 완료 · Codex · 현재 Windows 세션 · 원격 GPU 실행 없음
근거: K-0213 완료 뒤 사용자 “33프로정도 남았는데 더 할일 없어?” 후속 작업.

## 목표·파일
원격 생성 실패·누락 결과를 done으로 기록하지 않고, PNG/출처 쌍을 검증한 뒤 원본 보존하며 배치한다.
- `tools/ai-art/remote/sd_kaggle.py`
- `tools/ai-art/remote/push_batch.py`
- `tools/ai-art/test_remote.py` (신규)
- `tools/ai-art/README.md`, 이 티켓

## 단계
1. 원격 워커가 gen.py 종료 코드·GEN_RESULT를 검사하고 실패/반복 한도 초과를 보고한다.
2. 다운로드 결과와 현재 요청의 해시·출처 쌍·기대 수를 대조한다. 기존 로컬 원본은 보존한다.
3. 임시 파일·모의 CLI/프로세스로 누락·손상·부분 실패·정상 재개를 검증한다.

## 검증·완료 조건
`py -X utf8 -m unittest discover -s tools/ai-art -p "test_*.py" -v`
`node tools/qc.mjs --branch tools`, `git diff --check`.
실패·누락·미완료에는 비영 종료·failed 상태, 검증된 작업 완료에만 done을 기록한다.
계정·토큰·모델 다운로드·원격 실행·실제 GPU 추론은 하지 않는다.

## 재사용·실패 주입
강화 기획 `asset-tool-strengthening.md` §3·4, `asset-tool-validation.md` §5~7 적용.
K-0213 gen.py의 해시·쌍 검사·잠금·배타적 저장 재사용. 대표는 임시 16×16 PNG/JSON.
생성기 실패, 결과 요약 누락, ZIP 누락, 출처 누락, 다른 입력 해시, 기존 출력 재사용을 검증한다.

## 결과
- 총 40개 회귀 통과(K-0213 19개 + 원격 21개). 업로드 전 검사·variants seed·입력 경로 이동·오류 상태 전달 포함.
- 자체툴 QC PASS, FAIL 0/WARN 0(34초). 증거 `tools/_out/qc/20261030-2308.md`(QC 기록 시각). diff 공백 검사 통과.
- 원격 워커 종료 코드/요약·진행 정지·반복 한도 검사, 생존 GPU의 실제 포트 유지. 현재 times.json·기대 결과 쌍·입출력 해시가 맞아야 완료한다.
- 다운로드한 옛 해시 없는 결과는 배치 거부, 기존 로컬 정상 legacy는 경고 후 보존. 검증 가능한 부분 결과는 보존하되 전체 작업은 실패 처리한다.
- 실제 Kaggle 전송·계정 조회·GPU 추론은 하지 않았다. 기존 산출물과 다른 세션 변경은 보존했다.
