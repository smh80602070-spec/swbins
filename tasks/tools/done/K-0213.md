# K-0213 — 생성 재개와 실패 전달 검증

상태: 구현·검증 완료 · Codex · 현재 Windows 세션 · GPU 사용 없음
근거: 2026-10-31 두 저장소 재검토 뒤 사용자 “할 수 있는 건 우선 진행해”. 큐 순서는 변경하지 않는다.

## 목표
PNG 존재만으로 완료로 보는 재개 조건을 보강하고 생성·판정 실패를 호출자에게 전달한다.
원본은 보존하며 기존 정상 산출물은 재생성하지 않는다. 새 모델·서비스는 도입하지 않는다.

## 파일
- `tools/ai-art/gen.py`
- `tools/ai-art/run_all.sh`
- `tools/ai-art/test_gen.py` (신규)
- `tools/ai-art/README.md`
- `tasks/gameplay/project-review-20261031.md`
- `tasks/gameplay/asset-tool-validation.md` (변경된 dry 검사 계약 안내)
- 이 티켓

## 단계
1. PNG·출처 JSON 쌍 검사, 새 산출물에 입력·출력 해시 기록. 옛 정상 쌍은 해시 미검증 경고와 함께 보존.
2. 신규 저장 시 기존 경로 덮어쓰기 방지. 생성·RAM 중단·판정 실패 및 검사 수를 결과에 표시.
3. 로컬 러너의 실패 상태 전달, 원격 러너의 미적용 범위 기록.
4. 임시 디렉터리와 모의 API로 실패 주입 검증. GPU·서버·원본 산출물에 접근하지 않는다.

## 완료 조건
정상 재사용·PNG/출처 누락·손상·입력 변경·생성 실패·메모리 중단·판정 실패를 구별한다.
오류 시 원본 파일 바이트가 보존되고 성공으로 종료하지 않는다. 0건 및 dry는 품질 통과가 아니다.

## 강화 기획 적용
`tasks/gameplay/asset-tool-strengthening.md` §3·4 및 `asset-tool-validation.md` §5~7 적용.
기존 `gen.py`·로컬 러너를 확장한다. 본보기는 임시 16×16 PNG/JSON 한 쌍이며 시각 품질 판정 대상이 아니다.
실패 주입: 출처 누락·출력 손상·입력 변경·중복 실행·생성 및 판정 실패. 모션·배포는 이 티켓 범위 밖.
