# K-0002 `archive/` 이동 — 이력 문서 전부
종류: 통합      판: 저장소 전체(문서만)      등급 목표: (체제) — 세션이 이력을 우연히 읽지 않게

**목표(한 줄)**: append-only 이력(SAGA-HISTORY·판 HANDOFF 다섯·3D HISTORY 둘·VERTICAL_SLICE 셋·PROJECT_STATE 둘)을 `archive/` 로 `git mv` 하고, 그 경로를 적은 안내 줄만 고친다.

**파일**: `archive/README.md`(새, 5줄) · `SAGA-HISTORY.md`→`archive/SAGA-HISTORY.md` · `saga-web/<판>/HANDOFF.md`→`archive/web/<판>-HANDOFF.md`(5) · `saga-godot/docs/HISTORY.md`→`archive/godot/HISTORY.md` · `saga-godot/docs/VERTICAL_SLICE_*.md`(3)→`archive/godot/` · `saga-unity/docs/HISTORY.md`→`archive/unity/HISTORY.md` · `saga-godot/docs/PROJECT_STATE.md`·`saga-unity/docs/PROJECT_STATE.md`→`archive/<트랙>/PROJECT_STATE-2026-09-30.md`(STATE.md 가 생긴 뒤에만 — G-0002·U-0004 안 끝났으면 이 둘은 남긴다) · 경로를 적은 줄: 루트 `CLAUDE.md`·`README.md` 문서 지도·`SAGA-DESIGN.md` §9 표·`SAGA-HANDOFF.md` 한눈에 표·`saga-godot/CLAUDE.md`·`saga-unity/CLAUDE.md`·판별 `CLAUDE.md` — **한 줄씩만**(이 티켓만 다른 갈래 문서의 경로 줄을 고치는 예외)

**본보기**: 없음. `git mv` 만 쓴다(내용 편집 0).

**단계**
1. 다른 세션이 이 파일들을 고치고 있지 않은지 `git status --short` 로 본다(`M` 이면 그 파일은 건너뛰고 메모).
2. `git mv` 전부 → **바로 커밋**(경로 줄 고치기 전에. 끊겨도 옮김은 남는다). `archive/README.md`: "이력 보관. append 하지 않는다. grep 으로만 읽는다. 세션 기록은 tasks/<갈래>/done 메모와 커밋 메시지."
3. 경로 줄 고치기: `grep -rn "SAGA-HISTORY.md\|HANDOFF.md\|docs/HISTORY.md\|VERTICAL_SLICE" --include=CLAUDE.md --include=README.md --include=SAGA-DESIGN.md --include=SAGA-HANDOFF.md . | grep -v archive/` 로 나온 줄만 새 경로로. PLAN·HISTORY 안의 옛 상대경로는 **안 고친다**.
4. `grep -n HANDOFF tools/hooks/gate.js` — 있으면 W 갈래 메모로 넘기고 손대지 않는다.
5. precheck OK · 푸시 거부 시 `git pull --rebase --autostash`; 이름 바꿈 충돌이면 `git rebase --abort` 하고 다른 세션 푸시 뒤 다시.

**검증**
```
ls archive archive/web archive/godot archive/unity    → 파일 12~14개
grep -rn "SAGA-HISTORY.md" CLAUDE.md README.md SAGA-DESIGN.md SAGA-HANDOFF.md | grep -vc archive/   → 0
bash tools/precheck.sh   → OK
```
