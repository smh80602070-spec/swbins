# K-0073 에셋 반영 검사기 — 정본(saga-assets)이 게임 화면까지 실제로 닿는지 기계로 센다
종류: 통합·도구      상태: **닫음**(10-07 큐 정리 — 자체툴 몫 끝, 사용자 거부권·다른 갈래 연결은 그대로) · **끝**(페이블 2026-10-05, 단계 1~4)      등급 목표: D2

**목표(한 줄)**: "배치 끝"과 "화면에 나옴"은 다르다. 정본 5,232파일 중 ① 어느 트랙 코드에서도 이름이 안 나오는 것 ② 이름 표(`*-ids.js`·manifest)에만 있고 그리는 코드가 안 부르는 것 ③ 실제로 게임을 띄웠을 때 한 번도 요청되지 않는 것, 셋을 숫자로 내서 "반영 안 됨"을 사람 눈 없이 잡는다.

**결과(10-05, 도구 돌린 값 — `out/reflect.md` 가 정본, 덮어쓰기)**
- `reflect.py` 5,232 파일 · 범주 32: **느슨 안 쓰임 400** · **엄격 2,687**(1차 2,721 과 비슷) · 흔한 이름이라 판정 불가 140(store 45·ui 95 — `go/btn.png` 식). 엄격 0 = competition·patterns·portraits-monster·sfx·sky·sky-unity·store·vfx·web2d/bg·web2d/rts·web2d/realm-ui. precheck WARN(범주 참조 0) = **competition·portraits-monster·web2d/realm-ui**.
- `net-log.mjs`(판별 데모 5장면 + index.html, 서버 요청 기록): 요청 에셋 go 95·dungeon 99·forest 50·story 31·realm 14 — 전부 `<판>/assets/models|textures|sprites2d|vfx|store`, **`shared/assets/*`(K 배치 정본) 는 사가고 index 의 world3d 6 뿐**. 배치됐으나 요청 안 됨 4,434(하한).
- 왜 적은가(웹 버그 후보, 수신함): ① 다섯 판 `_demo.html` 이 `index.html` 스크립트의 절반가량(assets3d.js 포함)을 안 실어 데모에선 shared 3D·무늬에 못 닿는다. ② 다섯 판 모두 `<판>/assets/patterns/patterns.json` 404 — 무늬는 `shared/assets/patterns` 에 있고 `vroid-variant.js` 가 assets3d 뿌리 확정 전에 받아 `assets/patterns/` 로 떨어진다(경주). ③ index 는 타이틀만 1초라 깊은 화면은 세이브·자동 플레이가 있어야 센다(후속).
- 함정: `#!/usr/bin/env python3` 셔뱅은 `py` 가 스토어 껍데기로 보내 "Python"만 찍고 49 로 끝난다(지움) · 3D 데모는 dump-dom 이 가상 시간 안에 안 끝나 장면당 2분에서 끊는다(요청은 앞쪽에 몰림).

**파일**: 새 `tools/asset-audit/reflect.py`(①②: 토큰 검사, 범주×트랙 표, 끝 줄 REFLECT n/m) · 새 `saga-web/tools/playcheck/net-log.mjs`(③: 헤드리스 크롬 CDP 로 판마다 `_demo.html#<장면>` 다섯 장면을 열어 요청된 에셋 URL 로그 → 정본 이름과 대조) · `tools/precheck.sh`(새 범주가 추가됐는데 어느 트랙에도 참조 0 이면 WARN 한 줄) · 보고 `tools/asset-audit/out/reflect.md`(덮어쓰기).

**단계**
1. `reflect.py`: 범주×트랙 표 두 벌(느슨/엄격) + "안 쓰는 파일 목록" → `out/reflect.md`. 10-05 수치와 비교해 늘었는지.
2. `net-log.mjs saga-go`: 전용 `--user-data-dir`, 45초 가상 시간, 요청 URL 중 `assets/`·`shared/assets/` 를 모아 정본 이름과 대조 → "배치됐으나 한 번도 요청 안 됨" 목록. 끝나면 그 PID 만 종료(규칙).
3. 다섯 판 반복 → 표. 요청 0 인 범주는 **배선 티켓 후보**로 티켓 메모에(새 티켓은 만들지 않는다 — 수신함 한 줄).
4. precheck WARN 한 줄(새 정본 범주 참조 0).

**검증**: `py tools/asset-audit/reflect.py` → REFLECT 수치 · `node saga-web/tools/playcheck/net-log.mjs saga-go` → 요청 에셋 수 > 0 · 크롬 프로세스 잔존 0(`tasklist` 확인) · `bash tools/precheck.sh` OK.

**완료 조건**: 단계 1~4 · `out/reflect.md` 에 범주×트랙 두 표 + 요청 0 목록 · 수신함에 배선 후보 줄.
