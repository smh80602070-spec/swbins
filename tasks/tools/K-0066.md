**무엇을**: 공용 동작 한 벌 `<id>_anims.glb`(= 유니티 `Assets/Art/CharactersDex/anims/crowd_anims.glb`, 지금 18종: attack·burst·climb·death·dodge·fall·glide·hit·idle·jump·land·mantle·pickup·plunge·skill·sprint·swim·walk)에 **소문자 이름 클립 넷**을 더한다.

**왜**: U-0034 가 사람 42자리를 VRoid 로 바꾸는데, 위 두 자리는 게임 코드가 이 동작을 기대한다(`AllyFighter` 무사 도발·방패 막기·술사 치유, `DungeonCaptive` 무릎 꿇기 진단). 공용 한 벌에 없어 지금은 **이 두 자리만 기존 몸(Mixamo)으로 둔다**(보류). 클립이 놓이면 유니티가 보류를 풀고 VRoid 로 굽는다(코드는 `VroidMissingExtras` 가 자동 판단 — 클립 이름만 맞으면 된다).

**어디에**: 공방이 이미 가진 자체 동작(`tools/char-forge/keyframes.py` 의 무릎 꿇기·치유 — `c6399d7b`)을 VRoid 리그용으로 굽는 길을 재사용할 수 있으면 한 번에. 산출은 기존 `vroid_batch` 의 `_anims.glb` 와 같은 자리(git 밖) → `engine_characters.sh --install unity` 가 `crowd_anims.glb` 로 설치. 클립 이름·뼈 경로(`Armature/Root/J_Bip_*`)는 기존 18종과 같게.
