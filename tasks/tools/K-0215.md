# K-0215 다섯 판 장비·세트·고유·스킬 이름·수치 표 생성기 (웹 W-0436·W-0435 의 K 짝)
종류: 데이터 생성 · 자체툴(코드)      상태: **작성됨**(10-31 R-0 — 웹 W-0436 이 이 표를 기다리는데 K 티켓이 없었다. 수신함 10-25 (W-0435) 줄이 처음 요청)      등급 목표: D2

**목표**: 2나락 장비 다양성을 디아블로·PoE 결로 늘릴 **이름·수치 표**를 규칙으로 생성해 JSON 으로 낸다 — 세트 30(세트마다 4 세트 효과 + 세트 스킬 1)·고유 100·스킬 300·바탕 70. 웹은 이 JSON 을 데이터 파일로 받기만 한다(손으로 수백 줄 안 씀).
**선행 조건**: 시작 전 `bash tools/push.sh --pull` · 현재 수(세트 10·고유 31·스킬 120)와 항목 모양은 `saga-web/saga-dungeon/js/data-set.js`·`data-unique.js`·`data-skill.js` 에서 grep 으로 그 자리만 읽는다(통째 Read 금지).
**파일**: 새 `tools/data-forge/gen_gear_tables.py`(시드 고정 mulberry32 20260824 식) · 출력 `saga-assets/tables/dungeon/{sets,uniques,skills,bases}.json` · 웹 사본은 `place` 항목으로.
**단계**: ① 현재 항목 모양·수치 범위 표로 정리(세트 bonus 누적 꼴·고유 효과 칸·스킬 칸) ② 이름 규칙(가명 조합, 원작 실명·시리즈 이름 0 — 사전 검사 목록 만들기) ③ 수치 규칙(레벨 대역·등급별 예산, 원작 수치 안 가져옴) ④ 생성 + 중복·실명 검사 ⑤ 옛 id 는 그대로 두고 새 id 만 추가(`n_` 접두)
**검증**: `py tools/data-forge/gen_gear_tables.py --check`(개수 30/100/300/70·id 유일·실명 목록 0건·수치 범위) · 두 번 돌려 같은 출력(DIFF 0) · 표 샘플 20줄 Read ○
**완료 조건**: JSON 네 개 + 검사 통과 · 수신함에 웹 줄(경로·받는 법) 한 줄 · done/
**불변**: 기존 id·세이브 키·옛 항목 수치 안 바꿈 · 실명·원작 수치 금지 · 웹 코드는 안 고침
