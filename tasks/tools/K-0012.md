# K-0012 그래픽 게이트 공통 도구(세 트랙)
종류: 통합 · 도구      상태: **작성됨**(R-0 2026-10-02)

**목표(한 줄)**: G-0009 의 `saga-godot/tools/shot_diff.mjs`(node, 의존 0, `compareDirs`·`decodePng`·`encodePng` export)를 **고치지 않고 감싸는** `tools/graphics-gate/diff.mjs` 를 만든다. 세 트랙의 기준·새 촬영을 한 규격 폴더로 모아 판별로 비교하고, 문턱 초과 컷을 사용자 판정 시트로 낸다(SAGA-ARCH §4.5). **촬영은 안 한다**(루트 CLAUDE.md: 사용자 요청 때만).

**파일(확인함)**: `saga-godot/tools/shot_diff.mjs`·`shot_baseline.sh`(GO 네 컷, 기준 폴더 `saga-godot/graphics/baseline/go/` — 기준이 아직 없고 `.gitkeep` 만 있음) · `saga-web/tools/playcheck/cdp.mjs`(`shot(name)` → `playcheck/shots/<name>.png`, git 제외) · `saga-unity/Assets/Editor/Playtest*Gui.cs`(ScreenCapture 쓰는 에디터 점검 — 배치 촬영 명령은 **아직 없음**) · 새 `tools/graphics-gate/{diff.mjs,README.md}` · `.gitignore` 에 `graphics/latest/` 한 줄

**규격**: 기준 = 사용자 승인 PNG. 트랙→기준 폴더: godot `saga-godot/graphics/baseline/<판>/`(Godot 갈래 경로라 안 옮김) · web `graphics/baseline/web/<판>/` · unity `graphics/baseline/unity/<판>/`. 새 촬영 = `graphics/latest/<트랙>/<판>/`(git 제외). 파일명 `<장면>.png` 또는 `<장면>_<W>x<H>.png`(shot_diff 가 둘 다 짝지음). 판 = go·dungeon·forest·story·realm. 문턱은 shot_diff 기본(ssim 0.90·hist 0.15).

**단계**
1. `diff.mjs`: `--all`(트랙×판 순회, 기준 폴더에 PNG 가 있는 칸만 비교 — 없으면 "기준 없음 — 건너뜀", FAIL 아님) · `--track godot --game go` 한 칸 · `--selftest`. shot_diff 를 import 해 `compareDirs` 호출, 칸마다 표(컷·ssim·hist·OK/FAIL)와 끝 줄 `GFX_GATE fails=N cuts=M skipped=K`. 해상도 다름은 종료 2, FAIL 있으면 1, 아니면 0.
2. `--collect <트랙> <판> <원본폴더>`: 원본 PNG 를 `graphics/latest/<트랙>/<판>/` 로 복사(IHDR 로 `_<W>x<H>` 를 붙임 — 웹 `playcheck/shots/` 용).
3. FAIL 이 있으면 `tasks/sheets/gfx-<날짜>.md` 를 쓴다: 표 `컷 | 트랙/판 | 수치 | 기준 | 새 촬영 | ○/×(사용자 판정 대기)`. 없으면 파일을 안 만든다.
4. `README.md`: 촬영 명령 3줄(Godot `bash saga-godot/tools/shot_baseline.sh <폴더>` · 웹 playcheck 가 만든 `shots/` 를 `--collect web <판> …` · Unity "촬영 명령 없음 — 별도 U 티켓 필요") · 첫 기준 승인 절차(사용자가 본 PNG 만 baseline 으로 복사·커밋).

**본보기**: `saga-godot/tools/shot_diff.mjs` 머리 주석·종료 코드 꼴.

**검증**: `node tools/graphics-gate/diff.mjs --selftest`(합성 PNG 두 쌍을 `encodePng` 로 임시 폴더에 만들어 같은 쌍 OK·뒤집은 쌍 FAIL·기준 없는 칸 건너뜀을 확인, 종료 0) → `node tools/graphics-gate/diff.mjs --all`(지금은 기준이 없어 전부 건너뜀, 종료 0) → `bash tools/precheck.sh` OK.

**완료 조건**: 단계 1~4 + 검증. 기준 촬영·승인은 사용자 몫(이 티켓 밖).

**불변 규칙**: `shot_diff.mjs`·`shot_baseline.sh` 수정 금지(Godot 갈래) · 스크린샷 안 찍음 · 기준 PNG 는 사용자 승인분만 · Godot 호출엔 `</dev/null`.

**메모(체크포인트)**: 초안의 `shot_diff.py` 는 실제로 `.mjs` — G-0009 가 py 없는 PC 를 기준으로 node 로 만들었다. 도구도 node 로 맞춘다.
