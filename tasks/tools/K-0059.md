# K-0059 인물 이동 모션 보강 — 점프·낙하·착지 + 등반·활공·수영·시전 (K-0029 후속)
종류: 새기능 · 에셋      상태: **초안**(요청 2026-10-03, 고돗 — 사용자 "점프 모션이 없네") — R-0 는 자체툴 세션      등급 목표: D2

**목표(한 줄)**: 사가고(원신식 이동) 플레이어 몸에는 동작이 8개뿐이라 **점프하면 서 있는 자세 그대로 떠오른다**. 이동 모션 세트를 채워 모든 인물 몸(VRoid·이식)이 같은 이름의 클립을 갖게 한다. K-0029(전투 모션)에는 점프·낙하·착지가 없다(공격·방어·피격·기절·승리 위주).

**실측(고돗, 플레이어 `AnimationPlayer` 목록)**: `attack`(1.57s) · `death`(2.43) · `dodge`(1.5) · `hit`(0.37) · `idle`(2.53, 루프) · `pickup`(0.87) · `sprint`(0.7, 루프) · `walk`(1.37, 루프). **`jump`·`fall`·`land`·`skill`·`burst` 없음**, 등반·활공·수영도 `walk`/`idle` 로 때운다(`go_player.gd` 모드 GROUND·GLIDE·CLIMB·SWIM·MANTLE).

**요청(안, 우선순위 순)**
1. **`jump`**(도약 0.2~0.3s) · **`fall`**(공중 루프) · **`land`**(착지 0.2~0.3s, 높이에 따라 얕게/깊게 2종이면 좋다) — 가장 급함.
2. **`climb`**(벽 오르기 루프, 상하 방향) · **`glide`**(활공 루프) · **`swim`**(헤엄 루프) · **`mantle`**(턱 넘어 오르기 0.28s).
3. **`skill`**(원소 스킬 시전 0.3~0.6s) · **`burst`**(폭발 시전 0.6s) — 지금은 전부 `attack` 하나로 쓴다.
4. **`plunge`**(낙하 공격: 공중에서 내리꽂는 자세 루프 + 착지 내려찍기). 지금은 `attack` 클립을 그대로 쓴다(`go_player.gd start_plunge`).
5. **공격 클립 이름 규칙(K-0029 와 맞춤)**: 고돗은 지금 3타 모두 `attack` 하나를 쓴다. K-0029 의 무기별 2~3타 클립이 오면 `attack_<무기종류>_<타번호>`(예 `attack_sword_2`, 무기종류는 `sword·claymore·polearm·catalyst·bow`)로 고르게 할 테니, 클립 이름을 이 규칙이나 `combat_clips.json` 의 대응표로 알려 달라. 강공격은 `attack_heavy_<무기종류>`.
이름은 위 그대로(고돗 코드가 이 이름을 찾는다. 없으면 조용히 건너뛴다 — 에셋이 오면 코드 변경 없이 쓰이게 고돗이 연결해 둔다). 루프 클립은 루프 설정 포함, 모든 몸(VRoid 28 + 이식 + 공방 몸) 공통.

**참고(공격·회피 클립 형태, 고돗이 시간대별로 찍어 확인)**: `attack` 은 0~0.3s 준비(몸 기울임) → **0.3~0.95s 찌르기** → 0.95~1.57s 복귀. `dodge` 는 0~0.05 웅크림 → 0.05~0.85 도약·구르기 → 0.85~1.5 일어남. 게임은 후딜(0.3초대)에 맞춰 "실제 동작 구간"만 빠르게 재생한다(고돗이 `CLIP_WINDOW` 로 처리). **새 클립은 군더더기 없이 동작 구간이 클립 전체에 가깝게** 만들어 주면 그대로 쓸 수 있다.

**파일(확인할 것 — R-0)**: K-0029 의 `tools/char-forge/keyframes.py`(`CF_*`)·`bake_for_rig.py`·`data/combat_clips.json`(현황표에 이동 칸 추가) · 배치 K-0019.

**단계·검증·완료 조건**: R-0 에서 채움. 고돗 쪽 확인은 `tools/probe_feel.gd` 와 창 모드 촬영(점프 시퀀스).

**불변 규칙**: 인간형 모션은 체제상 원칙적으로 안 하지만 사용자 예외(K-0029 와 동일) · CC0 입력 우선 · 게임 폴더 직접 수정 금지(K-0019) · 원작 이름 금지.
