# K-0054 웹 2D 시트 풀 보강 — 짐승·펫 풀 + 사가스토리 인물(주인공·NPC·동행) 풀
종류: 새기능 · 에셋      상태: **K-0056 단계 3 으로 대체**(10-04 — 사람 8·짐승 6 = 요청 목록 전부 한 장 모드 40장, 사용자 판정·웹 한 장 모드 대기) — **사용자 긴급 지시**: 웹 2D·3D 화면이 옛 그림과 새 그림이 섞여 "허접하다", 에셋이 시급(2026-10-03). 큐 맨 위에서 먼저 한다      등급 목표: D2

**목표(한 줄)**: 웹 2D 모드(W-0019)는 K-0015 시트 20벌만 읽는데 **짐승 풀이 없고 사가스토리엔 사람 풀이 없다**. 그래서 짐승·펫은 옛 코드 스탬프로 남고, 사가스토리의 인물·NPC·동행은 2D 에서 옛 그림 그대로다("2D 모드로 전환하면 전체가 2D" 지시 미충족 부분). 아래 풀을 같은 규격으로 만들어 웹이 풀 표(`DG.cfg.mode2d.pools`)에 한 줄씩 잇게 한다.

**요청한 쪽이 확인한 것(사실)**
- 규격(`saga-web/shared/js/mode2d.js` 머리말): 풀 하나 = `<풀>/<동작>.webp` — 가로 프레임 8 × 세로 방향 3행(0 정면·1 옆·2 뒤, 반대 옆은 좌우 뒤집기)·프레임 128px·동작 `idle walk attack hit death` + `manifest.json` + 판별 `index.json`(`sheets` 목록). 몸 높이는 웹이 `poolH`(프레임 안 몸 픽셀)로 맞추므로 **풀마다 알파 범위가 일정**하면 된다.
- 지금 판별 풀: go 사람 2·악마·언데드 / dungeon 고블린·오크·언데드·악마 / forest 노인 2·청소년·아이 / **story 몬스터 넷(고블린·오크·언데드·악마)뿐 — 사람 없음**.
- 웹 쪽이 시트를 쓸 자리: story 주인공·마을 사람(`side-view`)·동행, 사가고 펫(`actor2d`), 사가의숲 동물, 사가블로 짐승형 적.

**받고 싶은 것(안)**: ① 사가스토리 사람 풀 — 주인공 남·녀, 마을 사람 2~3, 동행(전사·궁수·법사 계열) ② 짐승 풀 — 네발(개·늑대 계열)·새·작은 동물·물고기(헤엄)·큰 짐승 각 1~2. 도감 펫 `id` 는 불변이고 웹은 종류→풀 표로 잇는다. K-0033(NPC·병사 군중, 2D 시트 포함)·K-0031/K-0043(펫·몬스터)와 겹치면 **그 티켓의 2D 시트 단계를 이 규격으로** 하면 된다(R-0 가 정리).

**파일(확인할 것 — R-0)**: `tools/char-forge`(시트 굽기 `sheet_*`·`_out/sprites`·K-0015 산출) · 배치 K-0019(`characters-sprites2d` 처럼 `saga-web/<판>/assets/sprites2d_sheets/`)

**단계**
1. 풀 목록표 `tools/char-forge/data/sheet_pools_web.json`: 사람 풀(주인공 남·녀·마을 사람 3·동행 3) + 짐승 풀(네발 2·새·작은 동물·물고기·큰 짐승). 사람은 K-0024·K-0033 의 299/NPC 몸 중에서(겹침 없이), 짐승은 K-0031/K-0043 의 3D 몸(없으면 그 티켓이 먼저).
2. `bake_sprite_batch.py`(동작 8프레임×방향 3행·128px 시트 굽기, `sheet_from_frames`)로 풀마다 `idle walk attack hit death` 다섯 장 + `manifest.json`. 짐승 동작은 K-0031 산출(걷기·공격·죽음)을 쓰고, 없는 동작은 걷기 프레임 재사용(웹은 없는 동작을 idle 로 대신 그린다).
3. 알파 범위(몸 높이 px)를 `pw-sheet-bbox.mjs` 방식으로 재 `manifest` 에 적는다(웹이 `poolH` 로 맞춤).
4. 판별 `index.json`(`sheets` 목록)를 갱신하고 사용자 판정 → K-0019 `characters-sprites2d` 등에 풀 추가.

**검증**: 풀마다 시트 8×3 규격·알파 범위 일정 · `audit.py --quick` 🔴 0 · `precheck.sh` OK. 웹은 `pw-sheet-bbox.mjs`·`pw-web2d.mjs`.

**완료 조건**: 단계 1~4. **웹이 먼저 쓸 자리: 사가스토리 주인공·NPC·동행(지금 옛 그림), 사가고 펫·사가의숲 동물(지금 옛 스탬프).**

**정정(사용자 2026-10-03 "2D 는 다 AI 생성")**: 이 티켓의 **2D 스프라이트는 3D 렌더가 아니라 AI 생성**으로 만든다 — 방식·그림체는 **K-0056** 이 정한다(그림체 고정 판정 뒤). 3D GLB 단계는 그대로.

**불변 규칙**: 실명·원작 이름 금지 · 상업 허용 입력만 · 얼굴·머리 반복은 허용 · 게임 폴더 직접 수정 금지(K-0019).
