# K-0054 웹 2D 시트 풀 보강 — 짐승·펫 풀 + 사가스토리 인물(주인공·NPC·동행) 풀
종류: 새기능 · 에셋      상태: **초안**(요청 2026-10-03, 웹 갈래 W-0019 "남음") — R-0 는 자체툴 세션      등급 목표: D2

**목표(한 줄)**: 웹 2D 모드(W-0019)는 K-0015 시트 20벌만 읽는데 **짐승 풀이 없고 사가스토리엔 사람 풀이 없다**. 그래서 짐승·펫은 옛 코드 스탬프로 남고, 사가스토리의 인물·NPC·동행은 2D 에서 옛 그림 그대로다("2D 모드로 전환하면 전체가 2D" 지시 미충족 부분). 아래 풀을 같은 규격으로 만들어 웹이 풀 표(`DG.cfg.mode2d.pools`)에 한 줄씩 잇게 한다.

**요청한 쪽이 확인한 것(사실)**
- 규격(`saga-web/shared/js/mode2d.js` 머리말): 풀 하나 = `<풀>/<동작>.webp` — 가로 프레임 8 × 세로 방향 3행(0 정면·1 옆·2 뒤, 반대 옆은 좌우 뒤집기)·프레임 128px·동작 `idle walk attack hit death` + `manifest.json` + 판별 `index.json`(`sheets` 목록). 몸 높이는 웹이 `poolH`(프레임 안 몸 픽셀)로 맞추므로 **풀마다 알파 범위가 일정**하면 된다.
- 지금 판별 풀: go 사람 2·악마·언데드 / dungeon 고블린·오크·언데드·악마 / forest 노인 2·청소년·아이 / **story 몬스터 넷(고블린·오크·언데드·악마)뿐 — 사람 없음**.
- 웹 쪽이 시트를 쓸 자리: story 주인공·마을 사람(`side-view`)·동행, 사가고 펫(`actor2d`), 사가의숲 동물, 사가블로 짐승형 적.

**받고 싶은 것(안)**: ① 사가스토리 사람 풀 — 주인공 남·녀, 마을 사람 2~3, 동행(전사·궁수·법사 계열) ② 짐승 풀 — 네발(개·늑대 계열)·새·작은 동물·물고기(헤엄)·큰 짐승 각 1~2. 도감 펫 `id` 는 불변이고 웹은 종류→풀 표로 잇는다. K-0033(NPC·병사 군중, 2D 시트 포함)·K-0031/K-0043(펫·몬스터)와 겹치면 **그 티켓의 2D 시트 단계를 이 규격으로** 하면 된다(R-0 가 정리).

**파일(확인할 것 — R-0)**: `tools/char-forge`(시트 굽기 `sheet_*`·`_out/sprites`·K-0015 산출) · 배치 K-0019(`characters-sprites2d` 처럼 `saga-web/<판>/assets/sprites2d_sheets/`)

**단계·검증·완료 조건**: R-0 에서 채움. 웹 쪽 검증은 `saga-web/tools/playcheck/pw-sheet-bbox.mjs`(알파 범위)·`pw-web2d.mjs`.
