# K-0008 비인간 소품·괴물 이미지→3D 파이프라인
종류: 새기능 · 에셋      상태: **막힘 — 사용자 결정**(R-0 2026-10-01, 실행 시도 뒤 정정)      등급 목표: D2 — 소품 6 + 검사 통과 + 출처 기록

**목표(한 줄)**: `C:\swbins3\3d-gen`(로컬 Shap-E, MIT·상업 OK, `POST /generate` 포트 7864, `run.bat` 으로 켬) 결과 GLB 를 받아 팔레트 스냅(`asset-forge/palette.py snap-glb`)·삼각형 상한·바닥 접지·스케일 정규화·Meshopt(`glb-compress`)까지 **한 명령**으로. **사람·얼굴 입력 금지**(09-30 TripoSR 실패). 첫 대상 = 사가블로 명소 층 소품 6(5 왕릉 석관 · 10 부서진 망루 기둥 · 15 산채 깃발 말뚝 · 20 용궁 산호 기둥 · 25 대문 화로 · 30 구름 금궐 향로 — 돌·쇠·천 묘사만, 원작·실명 금지).

**파일(확인함)**: `tools/asset-forge/img2glb.py`(새, 본보기 `retex_glb.py`·`palette.py` 머리말) · `tools/asset-forge/data/props_dungeon.json`(새, 소품 6의 프롬프트·층·팔레트 역할) · 호출 `tools/asset-forge/palette.py`(build·snap-glb)·`tools/glb-compress/compress.mjs <폴더>` · 읽기만 `C:\swbins3\3d-gen\server.py`(body: prompt|image(base64)·steps·guidance_scale, 응답에 출처 PROVENANCE) · 점검 `saga-web/saga-dungeon/_glbcheck.html?f=<경로>` · 산출 `saga-web/saga-dungeon/assets/models/props/*.glb`(폴더 새로 만듦)+`props.license.json`

**단계**
1. `palette.py build` 로 던전 팔레트 JSON 한 번(출력 경로는 머리말·`--help` 로 확인). `3d-gen` 서버 켜기(`run.bat` 백그라운드, VRAM 때문에 **끝나면 끈다**).
2. `img2glb.py`: 소품 하나 = 프롬프트(또는 `ai-art/gen.py` 로 만든 흰 배경 이미지) → `/generate` → GLB → trimesh 로 정리(바닥 y=0·중심 x/z 0·높이 1.0m 정규화·삼각형 8k 이하 `simplify_quadric_decimation`) → `snap-glb` → 저장. `--only <id>` 로 1개, 기본 일괄.
3. **시험 1개**(석관)만 먼저: 눈으로 확인(`preview_scene.py` 시트 1장을 Artifact 로) — 뭉개짐이 심하면 `steps`·`guidance_scale` 만 두 번 조정, 그래도 미달이면 **중단하고 메모**(TripoSR 처럼 되풀이 금지).
4. 통과하면 6개 일괄 → `compress.mjs saga-web/saga-dungeon/assets/models/props` → 각 GLB 출처(응답 PROVENANCE·모델·MIT·날짜)를 `props.license.json` 에 기록.

**검증**
```
py tools/asset-forge/img2glb.py --batch tools/asset-forge/data/props_dungeon.json  → 6개 모두 OK 줄
각 GLB ≤ 8,000 삼각형 · ≤ 500KB · 바닥 y=0 · 높이 0.8~1.2m (img2glb 가 스스로 검사해 출력)
_glbcheck.html?f=assets/models/props/<파일> → 6개 열림(로더 오류 0)
asset-audit --quick → 🔴 0  (`py audit.py` 는 shebang 때문에 스토어 껍데기로 빠진다 — 인터프리터 경로 직접)
bash tools/precheck.sh → OK
```

**완료 조건**: 단계 1~4 · 소품 6 검사 통과 · 출처 6 · 서버 꺼짐 · 시트 한 장 사용자 판정(좋다/수정/중단).
