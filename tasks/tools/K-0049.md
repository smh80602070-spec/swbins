# K-0049 움직이는 대화 초상 — 시나리오 대화에서 만화 일러스트가 숨 쉬고 눈 깜빡이고 말하는 연출 에셋

**목표(한 줄)**: 시나리오 대화에서 초상이 정지 그림이면 밋밋하다. 사용자 요청("대화할 때 만화 일러스트가 움직이면 좋겠다")에 따라 **초상 한 장을 부위(눈·입·앞머리·몸통·배경)로 나눈 레이어 세트**와 움직임 규격(숨쉬기·눈 깜빡임·입 열고 닫기·머리카락 흔들림·살짝 고개 기울임)을 만든다. Live2D 같은 상용 도구는 쓰지 않고 **프레임 교체 + 레이어 변형(코드)** 으로 한다.

**파일(확인함)**: `tools/ai-art/gen.py`·`i2i_meta.py`·`pack_web_portraits.py`·`render_busts.py`(초상·밑그림) · 표정 K-0047 · 3D 몸 렌더 `tools/char-forge/_out/vroid/<id>/`(K-0024, 3D 모델에서 레이어 직접 분리 가능) · 새 `tools/ai-art/split_portrait_layers.py`·`data/live_portrait_plan.json` · 배치 K-0019

1. 방식 비교 시험 1명: (a) AI 초상을 부위별로 분리(눈·입 영역 자동 검출 + 가려진 부분 보충 생성) (b) 3D 몸 반신 렌더에서 부위별 레이어를 따로 렌더(눈·입·앞머리 메시 분리) — 품질·자동화를 비교해 하나를 채택.
2. 규격: 레이어 PNG(WebP) 세트 + `live.json`(레이어 순서·움직임 파라미터: 숨쉬기 폭·주기, 깜빡임 간격 3~6초 무작위(게임이 씨앗으로), 입 열림 단계 3, 머리 흔들림 축).
