# K-0205 2D 인물 시트 — 방향마다 무기·몸이 달라 보임(사용자 10-27 「2번 2d 옆으로 이동할 때 바뀜」)
종류: 에셋(2D 시트) · 자체툴      상태: 작성됨(R-0 완료 10-28)

**목표**: 2나락 2D 에서 같은 인물이 서 있을 때(뒷모습)와 옆으로 걸을 때(옆모습) 손에 든 무기가 다른 물건으로 보인다 — 서 있을 땐 네모난 흰 망치 머리, 옆으로 걸으면 가늘고 긴 칼. 방향 시트를 방향마다 따로 구워서 무기 모델·크기·잡은 손이 달라진다. 같은 모델·같은 크기·같은 손으로 방향 시트를 다시 굽는다.
**확인(10-27, 웹 소넷)**: 2나락 굴 1층, 명품 프리셋, 같은 자리 서 있기(`facing` 위) vs 오른쪽 걷기(`dirX 1`)를 PC 1280×720 으로 찍어 대 봤다(키 높이는 비슷, 무기 모양만 다름). 서 있는 쪽 누런 빛은 위 조명이라 그림 차이 아님. 3마을·4종횡은 같은 증상일 수 있으나 아직 안 찍음.
**산출물**: 방향 8(또는 3행) 시트에서 무기 모델·크기가 방향 간 일치하는 새 시트 + 대표 인물 2~3명 방향별 비교 표(서기·걷기·공격). 웹은 배선만 한다(`shared/js/mode2d.js` `draw0` — 시트 이름이 같으면 교체만).
**검증/완료**: 방향 간 무기 실루엣이 같은 물건으로 읽힘(눈 확인 ○) · 기존 시트 이름·칸 크기 유지 · 실명·원작 에셋 금지.
**파일**: `tools/char-forge/gear_sprites.py`(무기 influence 분기 ~l.648 · 방향 루프 ~l.678) · `bake_sprite_batch.py`(무기별 시트 굽기, `e['weapon']`·`COMBAT_CLIPS`·`WEAPON_UPRIGHT`) · `weapon_attach.py`(손뼈 붙임) · 읽기 `saga-web/shared/js/mode2d.js` `draw0`(시트 이름·칸 그대로)
**원인 가설(R-0 10-28, 코드만 읽음 — 눈 확인 전)**: 무기 GLB 는 한 번 붙이지만 `upright` 제약 influence 가 동작마다 다르다(전투 동작 0 · 걷기 등 비전투 0.85, 활은 늘 1) → 서기(idle=전투 동작)와 걷기 시트의 날 기울기가 갈린다. 서기·걷기가 서로 다른 시트 항목(무기 모델이 다른 e)에서 오는지도 manifest `weapon` 칸으로 확인해야 한다.
**단계**: ① 2나락 대표 인물 2~3명의 `idle`·`walk`·`attack` manifest.json `weapon`/`clipmap`·plan 항목을 대조 — 같은 무기 GLB 인지 ② 다르면 plan(`make_combat_sprite_plan.py`)에서 무기 항목 통일, 같으면 influence 분기(비전투 0.85)를 방향 시트 간 일치하게 고침 ③ 해당 인물만 `bake_sprite_batch.py` 로 다시 굽기(Blender 한 번에 하나, GPU 사슬과 겹치지 않게) ④ 서기·걷기·공격 × 방향 비교 표 PNG 를 만들어 눈 확인 ⑤ 시트 이름·칸 크기 그대로 두고 교체, `node tools/qc.mjs --game saga-dungeon`
**정정(사용자 10-28 「동작은 괜찮아 근데 에셋이 비어 있는 부분 때문에」)**: 원인 가설의 influence 분기는 접는다 — 동작이 아니라 **시트·컷아웃 그림의 빈 부분**(가려졌던 팔·몸통·무기 쪽)이 방향마다 달리 비어 무기가 다른 물건처럼 보인다. 단계 ①~②는 "빈 칸이 어느 방향·부위인지 찾기"로 바꾸고, K-0201(`k201_apose.py` 가려진 데 없는 그림)·K-0188 컷아웃과 묶어 푼다. 실행 전 사용자에게 「정확히 어떤 시트(컷아웃 인물 시트 vs 3D 시트)인지」 한 번 확인.
**원인 확정(10-28, 코드 `saga-dungeon/js/mode2d.js` draw → `cutout2d.js` drawFor l.242)**: 방향마다 **다른 그림 출처**를 쓴다. `cutout2d.sideOnly=1` 이라 **옆모습만 손그림 컷아웃**(가늘고 긴 칼)이고, 서기·앞·뒤·대각은 **옛 방향 시트**(VRoid 구움 — 네모난 망치 머리). 컷아웃에 앞·뒤 그림이 아직 없어서(K-0198) 임시로 갈라 둔 것. → 해결 = **K-0198(컷아웃 앞·뒤)을 하거나**, 옛 시트의 무기를 컷아웃 칼과 같은 모양으로 맞춤. 단계 ①②는 이걸로 대체: 컷아웃 무기 부위 그림 → 옛 시트 무기(`hero_m` 등은 무기 없음 → 무기가 어디서 붙는지 `draw0` 경로) 대조 후 K-0198 순서로 앞당길지 결정.
