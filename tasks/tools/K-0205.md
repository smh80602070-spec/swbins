# K-0205 2D 인물 시트 — 방향마다 무기·몸이 달라 보임(사용자 10-27 「2번 2d 옆으로 이동할 때 바뀜」)
종류: 에셋(2D 시트) · 자체툴      상태: 작성됨

**목표**: 2나락 2D 에서 같은 인물이 서 있을 때(뒷모습)와 옆으로 걸을 때(옆모습) 손에 든 무기가 다른 물건으로 보인다 — 서 있을 땐 네모난 흰 망치 머리, 옆으로 걸으면 가늘고 긴 칼. 방향 시트를 방향마다 따로 구워서 무기 모델·크기·잡은 손이 달라진다. 같은 모델·같은 크기·같은 손으로 방향 시트를 다시 굽는다.
**확인(10-27, 웹 소넷)**: 2나락 굴 1층, 명품 프리셋, 같은 자리 서 있기(`facing` 위) vs 오른쪽 걷기(`dirX 1`)를 PC 1280×720 으로 찍어 대 봤다(키 높이는 비슷, 무기 모양만 다름). 서 있는 쪽 누런 빛은 위 조명이라 그림 차이 아님. 3마을·4종횡은 같은 증상일 수 있으나 아직 안 찍음.
**산출물**: 방향 8(또는 3행) 시트에서 무기 모델·크기가 방향 간 일치하는 새 시트 + 대표 인물 2~3명 방향별 비교 표(서기·걷기·공격). 웹은 배선만 한다(`shared/js/mode2d.js` `draw0` — 시트 이름이 같으면 교체만).
**검증/완료**: 방향 간 무기 실루엣이 같은 물건으로 읽힘(눈 확인 ○) · 기존 시트 이름·칸 크기 유지 · 실명·원작 에셋 금지.
