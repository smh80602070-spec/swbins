**목표(한 줄)**: 사용자 지시(2026-10-01) "웹·고돗·유니티는 에셋을 안 고친다, **자체툴로 다 한다**" + "유니티도 사가고돗과 동일하게(파판식 사실풍 안 감)" 에 따라, `tools/world-forge` 한 레시피에서 **툰 GLB 한 벌(웹 3D·Godot·Unity 세 트랙이 똑같이 씀, `--style toon`)** 과 **2D 스프라이트(웹 2D 모드, `render_sprite.py`)** 만 뽑는다(사용자 2026-10-01 "3D 는 세 트랙 에셋이 동일"). 원본 GLB 는 하나, 트랙별 차이는 압축뿐: 웹 = `glb-compress`(Meshopt+WebP), Godot·Unity = 무압축(Godot 은 Meshopt 디코더 없음). 사실 PBR(`--style real`)은 더 늘리지 않는다. 판 5 × 종류(건물·지물·지형·탈것) 세트를 만든다.

**파일(확인함)**: `tools/world-forge/{build_building.py,wf_common.py,preview.py,render_sprite.py,fetch_sources.py,sources.json}` · `recipes/*.json` 9개(`eu_house_01`·`hanok_01`·`chinese_hall_01`·`jp_minka_01`·`stone_tower_01`·`forest_cottage_01`·`barn_01`·`inn_01`·`modern_block_01`) · README "순서(건물→지물→지형→탈것)" · 산출 `tools/world-forge/_out/`(gitignore)

**단계**
1. 판별 세트표 `tools/world-forge/data/set_plan.json`: 판마다 건물 3 · 지물 3(바위·나무·돌담·등불…) · 지형 조각 2 · 탈것 1(수레·배·뗏목) — 시대 혼합(과거·현대·미래 한 자리)·이름 정책. 건물은 기존 9레시피 재사용 우선.
2. 지물 `build_prop.py`(코드 형태 + CC0 재질) → 지형 조각(높이맵+침식) → 탈것(수레·배·뗏목, 코드). 한 종류씩 만들어 `preview.py` 3방향 시트로 눈 확인.
3. 출력: 원본 `--style toon` GLB(바탕색 256px, ≤ 0.5MB, 삼각형 ≤ 5k) 하나 + 웹용 압축본(`glb-compress`) + 웹 2D 스프라이트(`render_sprite.py`, 128~256px WebP). 출처는 산출마다 `*.license.json`(재질 Poly Haven CC0 + 코드).
4. 사용자 판정 시트 한 장 → 통과분만 K-0019(에셋 배치)로 넘긴다.
