# K-0057 고돗 빈 자리 보강 — 밭 작물·갈대·허수아비·디딤돌·폐허 기둥/담 + 사가블로 방 키트 + 노획물 지상 모델 (툰 GLB)
종류: 새기능 · 에셋      상태: **초안**(요청 2026-10-03, 고돗 G-0014·G-0015 로 확인) — R-0 는 자체툴 세션. 사용자 "에셋이 더 필요한 거 자체툴에 요청해"

**목표(한 줄)**: K-0052(자연)·K-0053(마을·장터)이 이미 받은 것 **말고**, 고돗이 지금 옛 에셋(Quaternius·Kenney·KayKit·procgen)으로 세우고 있어 "3 트랙 3D 에셋 동일"이 안 지켜지는 자리를 같은 툰 노선으로 채운다. 고돗은 에셋을 안 만든다 — 배치되면 `WorldAsset` 표(G-0014)만 늘려 쓴다.

**요청한 쪽이 확인한 것(사실, `grep` 호출 수)**
1. **밭 작물**: `vegetation/crops_wheatStageB` 호출 **86곳**(사가고·숲 밭 칸). K-0052 목록에 작물 없음 → 밀·보리 이삭 포기 2~3단계(싹·익어 가는·다 익은), 채소 밭 이랑 하나.
2. **K-0052/0053 에 빠진 것**: 갈대 `reed_s*` 3곳 · 허수아비 `scare_s*` 3곳 · 디딤돌/돌길 `RockPath_*` 8종(마을 길)·조약돌 `Pebble_*` · 폐허 기둥 `pillar-stone` 15곳 · 담 블록 `wall-block` 18곳·`planks`(널다리) 5곳·`roof-gable` 4곳(사원/폐허 지붕). 폐허용은 **무너진 변형**도(기둥 부러진·담 허물어진).
3. **사가블로 방 키트**: 굴혈 `room-small`·`gate`·`corridor` × 재질 셋(흙·석회암·용암) 9벌(`games/saga_dungeon/world/test_room.gd`). K-0026 은 "건물 안 방"이라 던전 모듈과 다름 → 방·문·복도·모서리·계단 모듈 + 재질 3(같은 GLB 에 텍스처만 교체 가능하면 그 방식).
4. **노획물 지상 모델**: `loot_pickup.gd` 가 검·도끼·단검·지팡이 × **등급 5(g0~g4)** = 20벌을 바닥에 놓는다. K-0030(무기 9종×**3등급**)과 등급 수가 다름 → K-0030 산출에 g0~g4 5단계 외형(또는 3등급을 5단계 색 입히기로 매핑)을 포함해 달라.

**예산**: K-0052·0053 과 같다(GLB ≤0.5MB·삼각형 ≤5000·텍스처 ≤256px, 작물·풀 포기는 ≤1500 권장). 고돗은 같은 조각을 MultiMesh 로 수백 개 깔므로 **원점 = 발 밑 중심, 한 개당 가벼움**.

**파일(확인할 것 — R-0)**: `tools/world-forge/build_prop.py`·`data/set_plan.json`(칸 추가) · 배치 K-0019. 이름은 일반 명사(`wheat_patch_01`·`rubble_pillar_01` 식), 원작·실존 이름 금지.

**단계·검증·완료 조건**: R-0 에서 채움. 고돗 쪽 확인은 `saga-godot/tools/probe_world_asset.gd`(표의 새 행이 열리고 높이×배율이 옛 것과 맞는지)와 창 모드 촬영.
