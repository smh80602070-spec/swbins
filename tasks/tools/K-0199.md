# K-0199 컷아웃 모션 늘리기 — 3D 동작(모캡·자체 키프레임 ≈ 90)을 2D 컷아웃 뼈 각도로 옮겨 걷기·전투가 어설프지 않게 (K-0188·0198 짝)
종류: 에셋(2D 동작 데이터) · 자체툴(char-forge 동작 → cutout 클립)      상태: **진행중**(10-25 ①② 옆 98 동작 팩 끝 · ④ 앞뒤 남음) · **작성됨**(10-25 오퍼스 R-0 — 사용자 「모션이 엄청 많아야 할것 같아 현재 너무없어서 걷는 모션이나 전투 모션이 어설프네」「그림은 괜찮아」)      등급 목표: D2

**잰 것(10-25)**: 컷아웃 엔진 `cutout2d.js` 기본 클립 **7개**(idle·walk·run·attack·hit·death·jump)뿐 · 뼈마다 키 2~5개(걷기 = 다리 앞뒤 두 자세 사이 직선 보간) · 모든 사람·모든 무기 같은 동작 · 덧뼈(소매·망토·머리) 흔들림 없음(`sway` 비어 있음). 그림은 괜찮다(사용자).
**프레임 수가 아니라 키 수**: 컷아웃은 그림을 프레임마다 따로 그리지 않고 뼈 각도를 화면 매 프레임(60fps) 사이 보간해 돌린다 — 부드러움·손맛은 클립의 키가 몇 개·어떤 자세냐로 정해진다. 오딘스피어도 같은 방식(덧뼈 많고 키 촘촘·과장·여운).
**이미 있는 재료**: 3D 동작 — CMU 모캡 12(`vroid_mocap_anims.glb`: 걷기·달리기·서기 둘·돌기·앉고 서기·줍기·인사·시전·힘쓰기·맞기·죽음) + 모션 30·32(`vroid_clips30_anims.glb`, K-0161·0197) + 자체 키프레임 46(`keyframes.py` — 검 베기 A·B·C·강공·창 찌르기·쓸기·강공·도끼 셋·단검 셋·활 셋·지팡이 내려치기·주먹 어퍼·방패 막기·밀치기·넘어짐·기절·승리·도발·치유·매달리기 …) ≈ **90 동작**.

**목표**: 그 3D 동작을 컷아웃 뼈 16 의 **옆모습 2D 각도**(+ 앞·뒤 K-0198 용 투영)로 자동 변환해 클립 표 한 벌 — 사람마다 rig 를 다시 굽지 않고 **공용 클립 팩**(`cutout/_clips/side.json`·`front.json`) 하나를 엔진이 읽는다. 그 위에 손으로 오딘스피어식 과장(앞 걸음 높이·공격 전 움츠림·끝 여운)을 표에서 손잡이로.
**만들 것**: ① 새 `tools/char-forge/clips_to_cutout.py`(Blender) — 팩 GLB 를 열어 클립마다 30fps 로 VRoid 뼈(J_Bip) 월드 방향 → 컷아웃 뼈 짝(hip←Hips·chest←UpperChest·head←Head·armU/armL/hand←UpperArm/LowerArm/Hand·legU/legL/foot←UpperLeg/LowerLeg/Foot, R = 화면 앞 = 캐릭터 오른쪽) → 옆 평면(앞=+x·위=−y)에 투영한 부모 기준 각도 차(쉼 자세 0) · 골반 높이 dy → `[t, 각, dx, dy]` 키(3프레임마다 · 각 변화 1° 안이면 줄임) ② 앞·뒤 투영(옆 대신 정면 평면 — 다리 들림은 dy 로) ③ 이름 표 `data/cutout_clips.json`(엔진 이름 ← 3D 클립 · 무기 종류별 공격 콤보 · loop) ④ 덧뼈 흔들림 기본값(소매·망토·머리 — 관절 json 에 `extra` 있는 사람만) ⑤ 미리보기 시트(3명 × 20 동작) ⑥ 수신함 웹 줄(엔진: `_clips` 팩 읽기 · `CLIP_OF` 를 게임 행동 → 새 클립으로 넓힘 · 무기 종류별 공격 고르기)
**파일**: `saga-assets/characters/anim-src/mocap/vroid_mocap_anims.glb`·`vroid_clips30_anims.glb` · `tools/char-forge/keyframes.py`·`mocap_retarget.py`(CF 동작 굽기 — 팩에 없는 CF 는 같은 길로 한 팩 더) · 새 `tools/char-forge/clips_to_cutout.py` · 새 `tools/char-forge/data/cutout_clips.json` · 정본 `saga-assets/web2d/cutout/_clips/` · `tools/ai-art/k188_cutout.py preview`(rig 에 팩 클립 얹어 보기)
**단계**: ① 걷기·달리기·서기 셋 먼저 변환 → 지금 기본과 나란히 시트(눈: 무릎 굽힘·발 디딤·팔 흔들림이 사람 같나) ② 전투(무기 9종 공격·막기·맞기·넘어짐·죽음) ③ 생활(줍기·인사·앉기·마시기 …) ④ 앞·뒤 투영(K-0198) ⑤ 팩·이름 표·시트 ⑥ 웹 줄
**검증**: 변환 클립 수 ≥ 60 · 미리보기 시트 Read(○ 가 걷기·달리기·공격 셋 다) · 발 미끄러짐(디딘 발 x 이동 ≤ 몸 2%) · credits(동작 출처 CMU 허가·자체 키프레임 — 기존 license 그대로)
**완료 조건**: `_clips/side.json`·`front.json` + 이름 표 · 시트 · done/ · 수신함 웹 줄
**불변**: 사람별 rig.json·그림은 안 건드림(클립만 공용) · 3D 팩 그대로
**함정**: VRoid 뼈 롤(팔 비틀림)은 2D 에서 안 보이니 버림 · 옆 투영에서 팔이 몸통 뒤로 지나가면 z 순서는 엔진 몫(R 팔은 늘 앞)
