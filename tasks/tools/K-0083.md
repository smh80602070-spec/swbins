# K-0083 웹 2D 모드 에셋 흠 — 마을 사람 무기·성 그림 한 가지·그림체 섞임 (W-0106 판정에서 나온 요청)
종류: 에셋 요청 · 자체툴      상태: 요청(W-0106, 2026-10-08)      등급 목표: D2(2D 장면)

**요청한 곳**: [W-0106](../web/done/W-0106.md) — 다섯 판 2D 장면 14 를 찍어 Claude 가 판정한 시트 [web-2d-20261007](../sheets/web-2d-20261007.md). 코드 흠은 W-0106 이 고쳤고, 아래는 **에셋이라 웹 갈래가 못 고치는 것**.

**무엇을·왜·어느 경로**
1. **마을 사람(주민·마을 NPC)이 무기를 든 2D 시트** — `saga-web/shared/assets/characters2d8/<id>/{idle,walk}.webp`(VRoid 8방향 299)가 싸움용 몸이라 사가마을 주민·사가나락 마을 사람이 창을 가로로 들고 서 있다(마을 장면에 어울리지 않음). 원하는 것: 무기 없는 평상복 idle·walk 두 장(같은 규격 128px·8프레임·8방향 행), 경로 예 `characters2d8/<id>/idle_town.webp`·`walk_town.webp` — 배선(어느 판·어느 종류가 이걸 쓸지)은 웹 갈래가 W 티켓으로.
2. **사가천하 성 그림이 한 가지** — `cfg.mode2d.prop2d` 의 `city:s|m|l` 이 다 같은 벽돌 탑으로 보인다. 원하는 것: 크기 셋이 눈에 갈리는 그림(작은 고을·성·큰 도성), 가능하면 시대(과거·현대·미래) 변형 — 퓨전 방향(SAGA-DESIGN §13).
3. **사가마을 그림체 셋이 섞임** — 픽셀 나무(`world2d` 나무)·그림풍 건물·VRoid 사람. 원하는 것: 나무·바위 2D 를 건물과 같은 그림체로 다시 굽기(또는 건물을 픽셀로) — 그림체 고르기는 사용자 판정(사람 눈 셋 중 "그림체 고르기").

**이름 정책**: 실명 금지(가명), 원작 에셋 금지 — 로컬 AI·CC0·코드만(§7.4).
