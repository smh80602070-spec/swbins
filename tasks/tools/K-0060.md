# K-0060 사가국지 전략 화면 에셋 — UI 틀 9-slice·성 아이콘 3등급·깃발·지방 이름 글씨·서체
종류: 새기능 · 에셋      상태: **산출 38 배치 끝**(10-04, 사용자 "작업 무조건 다 하고 푸시" — 판정 대기)      등급 목표: D2

**목표(한 줄)**: 사가국지 화면을 전략 시뮬 모양으로 바꾸는 W-0027 의 코드분(영토 면·성 정보 패널·날짜 배너·미니맵·CSS 임시 틀)이 끝났다. 지금 틀·성 그림·글씨는 **코드로 만든 임시**라, 그림 에셋이 오면 같은 자리에서 갈아 끼운다(단계 5). 이 티켓은 그 그림·서체를 K-0056 그림체 B 와 같은 결로 만든다.

⑦ 은 **AI 가 한글을 틀리게 그리므로** OFL 붓글씨체(예: 나눔붓글씨류)로 `bake` 해 굽는 쪽을 권한다. 지방 28개 이름은 `DG.cityData.provName` 에서 뽑는다: 유주·기주·병주·청주·연주·사예·예주·서주·양주(揚)·양주(涼)·옹주·익주·형주·한국·일본·교주·서역·남중·천축·막북·임읍·균열·폐허·묘역·대진·선비·실크로드·남해.

**제약**: 사가국지 폴더 에셋 합계 ≤ 3MB(웹 판당 상한). 색은 먹 #17120d~#261d14 · 금 #d8b56a 계열(웹 CSS 토큰 `--sg-trim`·`--sg-lacquer` 와 맞춤). 출처 `.license.json` 100%. 이름 정책(원작·실존 이름 금지) — 글씨는 위 지방 이름만.

**웹 쪽**: 배치는 K-0019 `place.py`(웹 `shared/assets/…` → 판별 복사는 `sync-shared`). 규격이 정해지면 W 티켓(W-0027 단계 5)이 `border-image`·`prop2d` 설정만 바꿔 연결한다. 지금 임시 틀 CSS 는 `saga-realm/css/strategy.css` 끝 `@media` 블록.
