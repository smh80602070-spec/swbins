# K-0206 말 3종·꿀벌 2D 시트 풀 굽기 + 학·용 걷기 대용 (사용자 10-29 「다해 좋아」)
종류: 에셋(2D 시트) · 자체툴      상태: 초안

**목표**: 3D 모델의 자기 동작을 5방향×6동작(서기·걷기·달리기·공격·맞기·죽기) 2D 시트 풀로 굽는다 — 말 3(`horse`·`horse_farm`·`horse_white`), 꿀벌(`Armabee_de63aaf6`, 비행 동작 `Flying_Idle`·`Fast_Flying`), 학·푸른 용(`crane`·`dragon`, 비행 동작이 없어 걷기·달리기 대용). W-0497(2D 탈것)·W-0498(꿀벌 몬스터)의 재료.
**10-29 시험 결과**: 말 3·꿀벌은 구워 봤고 5방향이 같은 몸으로 읽힘(`tools/ai-art/_out/k205/mounts`·`armabee`, 로컬·gitignore). 아티팩트 https://claude.ai/artifact/DAn3xV4ACVZ2QzuPGR2Wsi. 로컬 이미지 생성(ControlNet)은 인물이 바뀌고 장당 5분이라 사람형 모션엔 부적합 — 3D 굽기만 쓴다.
**굽는 명령**: `CLIPS="idle=Flying_Idle,walk=Fast_Flying,run=Fast_Flying,attack=Headbutt,hit=HitReact,death=Death" DIR_STEP=45 DIR_LIST=0,1,2,3,4 SPRITE_PX=192 NFR=8 blender -b --factory-startup -P tools/char-forge/creature_sprites.py -- <몸.glb> <프레임 폴더>` (말은 `CLIPS=idle=Idle,walk=Walk,run=Run,attack=Attack,hit=Hit,death=Death`). 출력 경로는 **절대 경로**로(상대 경로면 블렌더가 `C:\tools\…` 에 쓴다). 프레임을 가로 8 × 세로 5방향 webp 로 묶고 manifest.json 은 `saga-dungeon/assets/sprites2d_sheets/elf_001/manifest.json` 꼴(px 192, `mirror`, `side_faces:"right"`).
**파일**: `tools/char-forge/creature_sprites.py`(읽기) · 몸 `saga-assets/creatures3d/{horse,horse_farm,horse_white,crane,dragon}.glb`·`saga-web/saga-dungeon/assets/models/monsters/quaternius/Armabee_de63aaf6.glb` · 새 풀 `saga-web/saga-dungeon/assets/sprites2d_sheets/<id>/` · 같은 폴더 `index.json` factory
**단계**: ① 굽는 명령으로 6개 몸을 5방향×6동작 프레임으로 ② 시트 webp + manifest 만들기(풀 id 는 `mt_farm`·`mt_brown`·`mt_white`·`mt_crane`·`mt_dragon`·`armabee` — `mount.js` 탈것 id 와 맞춤) ③ `index.json` factory 등록 ④ 방향 표 PNG 눈 확인(발 접지·키 일정)
**검증**: 시트 6개 × 6동작 webp 가 있고 manifest `clips` 여섯 · `node tools/test-web.mjs saga-dungeon` RESULT n/n · 각 풀 방향 표 PNG 에서 5방향이 같은 몸
**완료 조건**: 풀 6개가 `sprites2d_sheets/` 에 있고 factory 에 등록 · 학·용은 manifest `note` 에 "걷기 대용(비행 동작 없음)" 명시 · 게임 배선은 W-0497·W-0498
