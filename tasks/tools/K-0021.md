# K-0021 인물 300→500명 통일 세트 — 3D 에셋·3D 도감·2D 에셋·2D 도감을 다섯 판 모두 같게
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2

**목표(한 줄)**: 사용자 지시(2026-10-01) "300명 모두 3D·3D 도감·2D·2D 도감이 다섯 판에 동일, 3D 는 세 트랙 동일". 인물 전원(도감 105 + 사가국지 장수 194 = 299, "300명"의 정확한 수는 단계 1에서 센다)이 **네 가지 세트**를 모두 갖고, 다섯 판 어디서나 같은 파일·같은 모습이다. 에셋은 전부 자체툴이 만들고 K-0019 가 놓는다(웹·고돗·유니티 갈래는 안 고침).

**파일(확인함)**: 정본 인물 `saga-web/saga-go/js/data.js`(도감 105)·`saga-web/saga-realm/js/data-force.js`(장수 194) · 초상 `saga-web/saga-*/assets/portraits/hero/<id>_s|_c.webp` · 공방 `tools/char-forge/`(`gear_sprites.py`·`bake_sprite_batch.py`·`render/`·무늬 `saga-assets/patterns/`) · 고유성 기준 `tools/asset-audit/CHARACTER_UNIQUENESS.md`  · 명단 `tools/char-forge/data/roster.json`(`make_roster.mjs`)

**규모(2026-10-02 "500명까지? 다섯 판 모두")**: 300 먼저, 500 까지 늘릴 수 있게(인원 하드코딩 금지). 인물당 약 0.45MB(슬림 시트 80KB+툰 GLB 300KB+3D 도감 60KB+초상 15KB) → 300명 135MB·500명 225MB, `saga-web` 이 이미 849MB 라 Pages 한도(권장 1GB)에 가깝다. 병목은 굽기(100벌≈1시간)보다 새 인물 200명의 데이터(가명·소개·수치, 다섯 판 `data.js` md5 동일)와 서로 다른 모습.

**산출 4종(인물마다)**: ① 3D 에셋 = 툰 GLB 한 벌(웹 3D·Godot·Unity 동일, 웹용만 Meshopt+WebP 압축) ② 3D 도감 = 앞·옆·뒤 3방향 렌더 WebP(도감 화면용) ③ 2D 에셋 = 128px 시트(idle·walk·attack·hit·death, 방향 3) ④ 2D 도감 = 초상 `_s`·`_c`(이미 299 있음, 나머지 네 판에 같게)

**단계**
1. 인물 id 목록을 정본에서 뽑아 `roster.json`(끝).
2. **용량(결정됨)**: 중앙 정본 `saga-assets/` + 웹 `shared/` 한 벌(K-0019 구조 결정) → 시트 ≈ 300KB/벌 × 300 = 약 90MB 를 **한 번만** 저장·배포. 슬림화(걷기 4프레임·동작 3개 ≈ 80KB/벌)는 용량이 모자랄 때만.
3. 몸 원본 정하기: 기존 인물별 몸(`_out/hero|realm`)을 쓰고 CHARACTER_UNIQUENESS 기준으로 겹침 검사. 주역·세력장은 사람 손(VRoid) 후보로 따로 보고.
4. 굽기: 10명씩 이어하기(`bake_sprite_batch.py`) · 3D 도감 렌더 · GLB. 묶음마다 접촉 시트로 눈 확인.
5. 점검기 `py tools/char-forge/roster_check.py`: 300명 × 4종 존재 + 다섯 판 사본 md5 같음 + 용량 예산. 미달은 목록으로.

**검증**: `roster_check.py` → 300×4 모두 OK·다섯 판 사본 동일 · 용량 예산 · `.license.json` 100% · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~5 · 사용자 확인 시트 한 줄.

**불변 규칙**: 도감 `id`·세이브 키 불변 · 이름 정책 · 몸 생성 동결 · 비상업 파일 공개 저장소 금지 · 게임 폴더 직접 수정 금지(배치 K-0019).

**메모**: ✔ 단계 1(2026-10-02) `make_roster.mjs`→`roster.json` 299명(도감105+장수194, 초상 전원 일치). ✘ 단계 3 시험: VRoid CC0 몸 + 무작위 장비로 10명을 구우니(`rand:human`) 거의 같은 모습(검은 정장 몸·어깨 날개 조각) → **299명엔 못 쓴다**(폐기, 되풀이 금지). 발견: 인물별 3D 몸이 이미 있다 — `tools/char-forge/_out/hero/hero_<id>.glb`(105)·`_out/realm/hero_<id>.glb`(194, MakeHuman 기반 실물풍, `gen_hero_recipes.py`·`gen_realm_recipes.py`). 다음: 이 몸을 3D 에셋 원본으로 삼고(툰 렌더 변환·K-0018), 2D 시트는 같은 몸을 Blender 로 굽는다(걷기·공격 동작 리타겟 가능 여부 확인이 첫 일). 성별 데이터는 없다(필요하면 id 로 확인된 값만).
