# K-0021 인물 300→500명 통일 세트 — 3D 에셋·3D 도감·2D 에셋·2D 도감을 다섯 판 모두 같게
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-01)      등급 목표: D2

**목표(한 줄)**: 사용자 지시(2026-10-01) "300명이 모두 3D 에셋·3D 도감·2D 에셋·2D 도감이 다섯 판에 동일" + "3D 에셋은 웹·고돗·유니티 동일, 엔진만 다름". 인물 전원(도감 105 + 사가국지 장수 194 = 299, "300명"의 정확한 수는 단계 1에서 센다)이 **네 가지 세트**를 모두 갖고, 다섯 판 어디서나 같은 파일·같은 모습이다. 에셋은 전부 자체툴이 만들고 K-0019 가 놓는다(웹·고돗·유니티 갈래는 안 고침).

**현황(2026-10-01)**: 2D 도감 초상 = 사가국지 599파일(299명)·사가블로 271·나머지 셋 211(105명+펫) → 판마다 다름 · 2D 시트 = 범용 20벌뿐 · 3D = Godot 짝 52 + VRoid 주역, Unity Mixamo(K-0018) · 3D 도감 없음.

**파일(확인함)**: 정본 인물 `saga-web/saga-go/js/data.js`(도감 105, 다섯 벌 복사)·`saga-web/saga-realm/js/data-force.js`(장수 194) · 초상 `saga-web/saga-*/assets/portraits/hero/<id>_s|_c.webp` + `manifest.js` · 공방 `tools/char-forge/`(들이기·옷 변형·무늬 64 `saga-web/shared/assets/patterns/`·`gear_sprites.py`·`bake_sprite_batch.py`·`render/`) · 고유성 기준 `tools/asset-audit/CHARACTER_UNIQUENESS.md`("색만 다른 건 다른 게 아니다") · 새 `tools/char-forge/data/roster300.json`(인물 id → 몸·옷·무늬·머리 레시피 → 산출 4종)

**규모(사용자 2026-10-02 "500명까지? 다섯 판 모두")**: 목표 300 으로 먼저 끝내고 **500 까지 늘릴 수 있게** 만든다(`roster300.json` → 인물 수를 하드코딩하지 않는다). 예산(인물당): 시트 슬림 ≈80KB · 툰 GLB ≈300KB · 3D 도감 3WebP ≈60KB · 초상 ≈15KB = 약 0.45MB → 300명 135MB · 500명 225MB(한 번만 저장). 웹 `saga-web` 이 이미 849MB 라 500 은 Pages 한도(권장 1GB) 근처 — 슬림 규격·정본 한 벌 필수. 병목은 굽기(100벌 ≈ 1시간)가 아니라 새 인물 200명의 데이터(가명·소개·수치, 다섯 판 `data.js` md5 동일)와 서로 다른 모습이다.

**산출 4종(인물마다)**: ① 3D 에셋 = 툰 GLB 한 벌(웹 3D·Godot·Unity 동일, 웹용만 Meshopt+WebP 압축) ② 3D 도감 = 앞·옆·뒤 3방향 렌더 WebP(도감 화면용) ③ 2D 에셋 = 128px 시트(idle·walk·attack·hit·death, 방향 3) ④ 2D 도감 = 초상 `_s`·`_c`(이미 299 있음, 나머지 네 판에 같게)

**단계**
1. 인물 id 목록을 정본 두 파일에서 뽑아 `roster300.json` 뼈대(수 확정, id·시대·성별·세력·체형).
2. **용량(결정됨)**: 중앙 정본 `saga-assets/` + 웹 `shared/` 한 벌(K-0019 구조 결정) → 시트 ≈ 300KB/벌 × 300 = 약 90MB 를 **한 번만** 저장·배포. 슬림화(걷기 4프레임·동작 3개 ≈ 80KB/벌)는 용량이 모자랄 때만.
3. 몸 레시피: 인물 고유 조합(몸×옷×무늬 64×머리·체형)이 CHARACTER_UNIQUENESS 기준을 넘는지 자동 검사(`audit` 색 겹침 재사용). 얼굴이 중요한 주역·세력장은 사람 손(VRoid) 후보로 따로 보고.
4. 굽기: 10명씩 이어하기(`bake_sprite_batch.py`) · 3D 도감 렌더 · GLB. 묶음마다 접촉 시트로 눈 확인.
5. 점검기 `py tools/char-forge/roster_check.py`: 300명 × 4종 존재 + 다섯 판 사본 md5 같음 + 용량 예산. 미달은 목록으로.

**검증**: `roster_check.py` → 300×4 모두 OK·다섯 판 사본 동일 · 용량 예산 · `.license.json` 100% · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~5 · 사용자 확인 시트(무작위 20명×4종) 한 줄.

**불변 규칙**: 도감 `id`·세이브 키 불변 · 이름 정책 · 몸 생성 동결 · 비상업 파일 공개 저장소 금지 · 게임 폴더 직접 수정 금지(배치 K-0019).
