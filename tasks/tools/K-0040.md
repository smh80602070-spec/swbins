# K-0040 UI 스킨 세트 — 버튼·창·카드 틀·등급 틀·게이지를 판별 테마로
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-03) — 시작 조건: K-0035(아이콘)와 같이 또는 먼저      등급 목표: D2

**목표(한 줄)**: UI 가 판마다 제각각이고 이모지·임시 그림이 섞여 있다. 다섯 판이 같은 **UI 부품 규격**(9분할 창·버튼 4상태·카드 틀·등급 틀 5·게이지·탭·팝업·말풍선)을 쓰고, 판별로 **색·장식만 다른 테마**를 입히게 한다. 부품은 코드 생성(벡터)을 기본으로 해 해상도에 무관하게 한다.

**파일(확인함)**: `tools/asset-forge/spritegen.py`·`palette.py`·`tilegen.py`(코드 생성 선례) · `tools/ai-art/gen.py`(장식 문양, 선택) · 현황 `saga-web/<판>/css`·`saga-godot/games/*/ui`·`saga-unity` UI 데이터(읽기만) · 새 `tools/asset-forge/uigen.py`·`data/ui_theme.json` · 배치 K-0019

**단계**
1. 현황표(추측 금지): 판·트랙별 UI 부품 종류와 임시 그림·이모지 개수를 읽어서 만든다.
2. 부품 규격 + 테마 5(판별 색·장식 문양) 정의 → `uigen.py` 로 SVG/PNG(9분할 메타 포함) 생성.
3. 시험 한 화면(인벤토리 틀) 미리보기 시트 → 사용자 판정 → 일괄 → K-0019.

**검증**: 부품 목록 = 산출 수 · 9분할 가장자리 점검 · 용량(판당 ≤ 1MB) · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3 · 사용자 판정 한 줄. 화면에 입히는 배선은 각 갈래.

**불변 규칙**: 원작 UI 모양 모사 금지 · 터치 최소 크기(폰 가로 기준 48dp) 규격 준수 · 게임 폴더 직접 수정 금지(배치는 K-0019) · 이름 정책 · 상업 허용·CC0 에셋만 · PC 안 멈추게(GPU 작업은 다른 GPU 작업과 동시 금지)
