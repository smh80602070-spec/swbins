# K-0030 무기 세트 3D·2D — 종류별 모양을 다시 만들고 손에 쥐는 규약(소켓)을 통일
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-02) — 사용자 2026-10-02 "무기 같은 것도 엉망"      등급 목표: D2

**목표(한 줄)**: 무기 모델이 트랙마다 제각각(Godot `assets/weapons` 20개는 외부 도끼·단검 등, 웹·Unity 는 따로)이고 손에 맞지 않는다. `world-forge` 소품 도구로 **무기 종류 9 × 등급 3(보통·희귀·전설) = 27벌**을 한 레시피에서 만들어 세 트랙이 같은 GLB 를 쓰고, 손에 쥐는 **소켓 규약**(손뼈 기준 위치·방향 노드 `grip`, 칼날 끝 `tip`)을 정해 모든 인물 몸에 같은 값으로 붙게 한다. 웹 2D 는 같은 모델의 아이콘·손에 든 스프라이트.

**파일(확인함)**: `tools/world-forge/build_prop.py`·`wf_common.py`·`recipes/`·`sources.json`(CC0 재질) · `tools/char-forge/gear_sprites.py`(2D 장비 스프라이트) · 기존 무기 `saga-godot/assets/weapons/`(20) · 새 `tools/world-forge/recipes/weapon/<종류>_<등급>.json` · 산출 정본 `saga-assets/world/weapon/` → K-0019 배치(항목 `weapon`)

**단계**
1. 규약: 종류 9(검·창·도끼·단검·활·지팡이·총·방패·맨손 장갑) · 길이·무게감 비율표 · 노드 `grip`(손바닥 중심, 손뼈 `J_Bip_R_Hand` 기준 오프셋)·`tip` · 활·방패는 왼손.
2. 레시피 27 → `build_prop.py` 확장으로 굽기. 등급 = 장식·광택·크기 단계(색만 바꾸지 않는다).
3. 시험: 인물 2몸에 K-0029 공격 동작으로 무기를 쥐게 해 **손에서 빠지거나 몸을 뚫는지** 프레임 점검(소켓 오프셋 조정).
4. 2D 아이콘·손에 든 스프라이트(`gear_sprites.py`) · 미리보기 시트 → 사용자 고르기 → K-0019 배치. 기존 외부 무기는 대체 후 미참조 처리(삭제는 사용자 확인 뒤).
