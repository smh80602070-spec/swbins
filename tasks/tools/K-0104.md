# K-0104 사실 들풀 묶음 — 잎 카드 덤불·풀포기·꽃무리·고사리(자체 그림 결) 고돗 배치
종류: 에셋 · 자체툴      상태: **진행중**(10-14 도구 끝 — 그림 생성 대기) · 작성됨(Opus R-0 10-14 — 고돗 G-0227 대기 "자체툴 사실 덤불·풀포기", 사용자 "티켓 만들어" 10-14)      등급 목표: D2

**목표(한 줄)**: 고돗 1만리 들판이 비어 보인다(G-0227). 지금 킷의 `bush_01/02` 는 정육면체 잎 덩이 로우폴리라 사실 땅(K-0093)과 따로 놀고, 잔돌·풀포기는 안 보이거나 잿빛 부스러기로 읽혔다 → **잎 카드(알파 잘라내기) + 자체 생성 잎·꽃 결**의 사실 들풀 6~8종을 만들어 고돗에 놓는다. 그러면 G-0227 이 KINDS 표만 바꿔 다시 한다.

**파일(확인함, 10-14)**
- 만들기 `tools/world-forge/build_nature.py`(K-0052, 도형 도우미 `blob`·`clump_crown`·`blade2`·`leaf_slots`, 삼각형 ≤ 1500, `--style` 기본 real) — 지금 재질이 `C.s('white_stucco', …)` 같은 **Poly Haven 사진**이라 빌린 것. 새 id 는 자체 결만 쓴다.
- 잎·꽃 결 그림 `tools/ai-art/gen.py --variants 4 --judge`(Z-Image) + 배경 지우기 `tools/ai-art/matte_util.py` · 땅 결 본보기 `tools/ai-art/make_tile_batch.py`·`pbr_from_albedo.py`(K-0093 — 법선·거칠기)
- 자체 PBR 정본 `saga-assets/textures_real/{grass,dirt,rock,…}`(줄기·밑동 바위에 재사용)
- 놓는 자리: 새 정본 `saga-assets/world/foliage/<id>.glb`+`.license.json` → asset-place 새 항목 `world-foliage`(대상 `godot: saga-godot/assets/world` — `world-toon` 과 같은 폴더, id 안 겹침). 웹·유니티 대상은 이 티켓 밖(수신함).
- 촬영 `tools/world-forge/render_sprite.py`(출력 `cygpath -aw` 절대) · 고돗 쓰는 자리 `saga-godot/games/saga_go/world/vegetation_builder.gd` 248행 둘레(G 몫, 읽기만)

**단계**
1. 결 배치 `tools/ai-art/batches/k104_foliage.json`: 잎 무리(넓은잎·가는잎)·풀잎 다발·들꽃 셋(흰·노랑·보라)·고사리 잎 — 흰 바탕 위 위에서/옆에서 본 낱장, 세로 결, 그림자 없음 · `gen.py --variants 4 --judge` → 눈 고름 → matte 알파 → 2048 아틀라스 하나(`saga-assets/world/foliage/_atlas/foliage_atlas.png` + 법선) + license(자체 생성).
2. `build_nature.py` 새 함수(새 id, 옛 id 안 고침): `bush_leafy_01`(둥근 덤불 0.9m)·`bush_leafy_02`(낮고 넓은)·`grass_clump_01`(무릎 높이)·`grass_clump_02`(이삭)·`flower_clump_01`(섞인 들꽃)·`flower_clump_02`·`fern_01` · 잎 카드 = 십자·별꼴 판 + 가지 끝 카드 무리, 재질 alphaMode MASK(잘라내기 0.5)·양면·밑동 쪽 어둡게(정점 색 AO) · 삼각형 ≤ 1500(덤불), ≤ 600(풀·꽃).
3. 렌더 시트: 새 7종 + 옛 bush_01·grass_tuft_01 을 K-0093 grass 땅 위에 같은 빛으로 나란히(앞·45°·위) → Claude 눈 ○(사실 땅과 어울림·카드 티 안 남·정육면체 아님). × 면 결·카드 배치 고쳐 다시(3회 ×면 멈추고 메모).
4. 정본 → asset-place `world-foliage` → `py tools/asset-place/place.py --write --item world-foliage` → 고돗 임포트 한 번(`.import` 생김 확인 — 고돗이 다른 세션에서 열려 있으면 그 세션 몫, 메모).
5. credits · 수신함에 G 줄 "K-0104 끝 — G-0227 KINDS 표에 새 id(크기 m 표)" · 고돗 큐 G-0227 대기 칸 "K-0104 끝" 한 줄(고돗 큐 파일은 이 줄만).
