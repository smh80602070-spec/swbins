# K-0011 음성 Supertonic 한국어 판정(사람이 듣는 시트)
종류: 측정 · 에셋      상태: **작성됨**(R-0 2026-10-02)

**목표(한 줄)**: swbins3 voice-gen(Supertonic 3)으로 한국어 문장 10개(NPC 감탄사 5·시스템 안내 5)를 WAV 로 만들고 `tasks/sheets/voice-<날짜>.md` 에 ○/× 칸을 둔다. 사용자가 듣고 ×(어색·알아듣기 힘듦)가 많으면 음성은 접는다(ARCH §4.5 "음성 반쯤").

**파일(확인함)**: `C:\swbins3\voice-gen\server.py`(Flask `/generate`, 목소리 M1~M5·F1~F5, 언어 ko·en·ja, 속도 0.7~2.0, 출력 WAV·`PROVENANCE` 출처 기록) · `C:\swbins3\voice-gen\venv\Scripts\python.exe`(supertonic·soundfile 설치) · `C:\swbins3\voice-gen\models\supertonic3`(모델) · 새 `C:\swbins3\voice-gen\batch_saga.py`(swbins3 저장소 — 그쪽 규칙으로 따로 커밋) · 새 `tasks/sheets/voice-<날짜>.md`(이 저장소) · 시트 본보기 `tasks/sheets/saga-go-20261001.md`

**단계**
1. `batch_saga.py` 작성: `server.py` 와 같은 방식(`TTS` 로드 → `get_voice_style(voice_name=)` → `synthesize(text, voice_style=, lang="ko", speed=1.05)`)으로 서버 없이 직접 합성. 문장 10개를 코드에 고정:
   - 감탄사(F1·M1·F2·M2·F3): "오오, 이게 다 뭐람!" · "으아악, 살려 줘요!" · "해냈다! 우리가 이겼어!" · "어라? 이런 데도 길이 있었네." · "흥, 두고 보자고!"
   - 안내(F1·M1 번갈아): "새 지역을 발견했습니다." · "저장이 완료되었습니다." · "배낭이 가득 찼습니다." · "일일 의뢰가 갱신되었습니다." · "연결이 끊어졌습니다. 다시 시도해 주세요."
   - 산출 `C:\swbins3\voice-gen\out\saga-<날짜>\01.wav`~`10.wav` + `provenance.json`(PROVENANCE 와 문장·목소리). 실존 인물·원작 대사는 쓰지 않는다.
2. 같은 스크립트가 시트(`tasks/sheets/voice-<날짜>.md`)를 쓴다: 표 `n | 문장 | 목소리 | 파일 경로 | ○/× | 메모`, 안내 "파일을 재생해 ○/× 만 적기 · 로컬 전용(이 저장소엔 음성 안 넣음)".
3. 실행 뒤 시트를 이 저장소에 커밋·푸시, swbins3 쪽은 그쪽에서 `batch_saga.py` 만 커밋.

**검증**: `C:/swbins3/voice-gen/venv/Scripts/python.exe C:/swbins3/voice-gen/batch_saga.py </dev/null` → 종료 0 · `ls C:/swbins3/voice-gen/out/saga-*/*.wav | wc -l` 이 10 · `py -c` 로 각 WAV 길이 0.5초 이상(soundfile) · 시트 표 10줄 · `bash tools/precheck.sh` OK.

**완료 조건**: 단계 1~3 + 검증. 판정(○/×)은 사용자 몫 — 비워 두고 "확인 전" 으로 둔다(실기 확인은 몰아서).

**불변 규칙**: 음성 파일은 공개 저장소에 안 넣는다 · 출처(OpenRAIL-M·금지 용도) 기록 유지 · 서버(7863)는 안 띄운다 · 이름 정책(실명 대사 금지).

**메모(체크포인트)**: 이전 초안은 ogg 라 했으나 서버 출력은 WAV — WAV 로 한다.
