# K-0043 몬스터·보스 3D 몸 세트 — 비인간형 몸을 계통별로 다양하게
종류: 새기능 · 에셋      상태: **재작업**(10-05 사용자 "허접") — 방식을 Skin 으로 바꾸는 중, 첫 시험 코드 있음      등급 목표: D2

**목표(한 줄)**: K-0031 은 동작만 다룬다. 몬스터 도감과 보스에는 **몸 자체의 종류**가 필요하다. 인간형이 아닌 몸(네발·날개·뱀형·거대·기계·정령 계통)을 `asset-forge` 로 조립해 계통마다 변형 여러 벌, 보스급 큰 몸 12종을 만든다.

**파일(확인함)**: `tools/asset-forge/kitbash.py`·`procgen.py`·`preview_scene.py`·`retex_glb.py`·`palette.py` · 기존 몸 `saga-web/saga-go/assets/models/animals/*.glb`·`saga-godot/assets/characters/` · 동작 규약 K-0031 · 새 `tools/asset-forge/data/monster_plan.json` · 배치 K-0019

**단계**
1. 현황표: 계통 × 기존 몸 수 × 부족 칸(K-0031 표와 합친다).
2. 계통별 기본 몸 + 부품(뿔·날개·갑각·꼬리) 조합 규칙 → 변형 N벌, 보스는 크기 3배·장식.
3. 뼈대는 K-0031 의 표준 뼈 이름을 따른다 · 시험 계통별 1종 미리보기 → 판정 → 일괄 → K-0019.

**검증**: 계획표 항목 수 = 산출 수 · 뼈 이름 규약 점검 · 용량(웹 경량본 ≤ 0.5MB) · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3 · 사용자 판정 한 줄.

**불변 규칙**: 인간형 몸은 만들지 않는다(ARCH §4.5) · 원작 몬스터 모양·이름 모사 금지 · 게임 폴더 직접 수정 금지(배치는 K-0019) · 이름 정책 · 상업 허용·CC0 에셋만 · PC 안 멈추게(GPU 작업은 다른 GPU 작업과 동시 금지)
