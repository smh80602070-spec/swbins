# K-0210 라데온 ComfyUI 장당 시간 줄이기 — Z-Image 768² 95~184초 중 그리기 19초뿐(10-31 점검)
종류: 툴 강화(속도) · 자체툴(ai-art)      상태: **작성됨**(라데온 전용)      등급 목표: D2

**목표**: RX 7600 에서 Z-Image 한 장 시간을 화질 그대로 절반 이하로. 10-31 점검: 샘플링 8단계 19초(2.37 s/it), 나머지는 CPU(ComfyUI CPU 88%) — 텍스트 인코더(Qwen3-4B Q8, `--lowvram` 이라 CPU·fp16) + 매 장 VAE 디코드 전 DiT 5.2GB 를 VRAM 에서 내렸다 다음 장에 다시 올림(`comfy.err.log` "Unloaded partially: 5223 MB").
**기각된 안**: `--fp32-text-enc` — 이 ROCm 토치는 MKL 없음(BLAS=open), CPU fp32 행렬곱이 fp16 보다 약 11배 느림(실측, 메모리 rocm-win-torch-cpu-fp16-faster).
**선행 조건**: K-0202 아이콘 사슬 끝(`tools/ai-art/_out/k202_icons_all_done.txt`) — 그 전엔 ComfyUI 재시작·GPU 시험 금지. 라데온 PC 만.
**파일**: `tools/ai-art/gen.py`(VAEDecodeTiled 타일 값·배치 단위 인코딩 경로) · `tools/ai-art/start_sd.ps1`(플래그) · 필요하면 자체 노드 `C:\swbins3\comfyui-saga\`(조건 저장·불러오기) · `tools/asset-audit/judge/judge.py`(CPU 경로 dtype) · 기록 `tools/ai-art/README.md` 측정 줄·swbins3 `SETUP_GUIDE.md` §6
**입력**: 기준 배치 = 이미 만든 `batches/k202_icons_dungeon_z1.json` 앞 5항목(같은 씨앗) — 결과는 `_out/k210_*` 새 폴더, 원본 불변
**단계**:
 ① 기준선: 같은 5장 장당 시간·ComfyUI 로그(로드/언로드 줄) 기록
 ② VAE 타일 512→256(overlap 32): DiT 언로드가 사라지는지·장당 시간·이음매(같은 씨앗 그림 픽셀 차·눈 확인)
 ③ 배치 단위 인코딩: 인코더를 GPU 에 올려 배치 프롬프트를 한꺼번에 인코딩해 두고(자체 노드, 라이선스 자체) DiT 만 상주시켜 샘플링 — 같은 씨앗 결과 동일성 확인
 ④ 판정기 CPU 경로 fp32→fp16: 표본 배치 하나로 점수 차·1등 고르기 일치율 확인(불일치면 fp32 유지)
 ⑤ 이긴 조합만 gen.py·start_sd.ps1 에 반영, 지포스 경로(AI_ART_API·CUDA)는 안 건드림
