# K-0029 인물 전투 모션 정리 — 무기 종류별 공격·방어·피격·스킬 동작 세트(CC0 라이브러리 재사용)
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-02) — 사용자 2026-10-02 "전투 모션도 엉망"      등급 목표: D2

**목표(한 줄)**: 지금 인물 동작은 CC0 8종(대기·걷기·달리기·공격 `Sword_Attack`·피격·구르기·죽음·줍기)이라 **무기가 뭐든 같은 칼 휘두르기**다. 무기 종류(검·창·도끼·단검·활·지팡이/마법·총·맨손·방패)마다 공격 2~3(연타 포함)·방어·피격 방향·스킬 시전·기절·승리 동작을 CC0 Universal Animation Library 에서 골라 모든 인물 몸(VRoid 28 + 이식 299)에 같은 이름으로 굽는다.

**주의(체제 예외)**: SAGA-ARCH §4.5 와 이 큐 머리말은 "인간형 모션은 자체툴에서 하지 않는다" 로 되어 있다. 이 티켓은 사용자 직접 요청이 그 예외이며, **새 동작을 만드는 게 아니라 CC0 동작을 고르고 굽는 것**만 한다(직접 키프레임은 `keyframes.py` 의 6종 외엔 만들지 않는다).

**파일(확인함)**: `tools/char-forge/bake_for_rig.py`(`--clips 이름=UAL이름,…`)·`verify.py`·`vroid_batch.sh`(`CLIPS` 변수)·`keyframes.py` · 원본 `tools/char-forge/_src/Animation Library[Standard]`(UAL, CC0) · 현재 8종 목록 `vroid_batch.sh` 의 `CLIPS` · 산출 `_out/vroid/<id>/<id>_anims.glb`(동작 GLB, 인물당 ≈1MB) · 배치 K-0019

**단계**
1. 동작표 `tools/char-forge/data/combat_clips.json`: 무기 종류 9 × (공격1·2·3, 강공격, 방어, 피격 앞·뒤, 스킬 시전, 기절, 승리) → UAL 이름 대응. UAL 에 없는 칸은 표에 "없음"으로 적고(만들지 않음) 가장 가까운 동작으로 대체.
2. 시험 2몸(여·남)에 전 동작을 굽고 **동작마다 렌더 한 프레임씩(시작·타격·끝)** 으로 어깨·손목 뚫림·무기 높이·발 미끄러짐 점검 시트.
3. 사용자 판정(동작 고르기). 통과 목록만 `vroid_batch.sh` 의 `CLIPS` 로 확정 → 299+28 재굽기(이어하기, 인물당 +~30초).
4. 웹 2D 는 같은 동작에서 공격·피격 시트를 무기별로 추가(`bake_sprite_batch.py`, 시트 용량 한도 확인).

**검증**: 표 칸 수 = 굽은 클립 수 · `verify.py` 뼈 방향 ≤5°·땅 ≤1cm 전부 통과 · 시험 시트 · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3(2D 시트 4 는 용량 한도 안에서). 사용자 판정 한 줄.

**불변 규칙**: 새 동작 직접 제작 금지(CC0 선택·굽기만) · 출처 `.license.json` · 게임 폴더 직접 수정 금지 · 헤드리스 Blender `</dev/null`.
