# K-0039 전투 이펙트 세트 — 타격·마법·치유·피격 번쩍임을 2D 시트와 3D 파티클 프리셋으로
종류: 새기능 · 에셋      상태: **산출 40종 배치 끝**(10-04, 판정 대기) — 사용자 "큐 순서대로 다 적용"을 SAGA-ARCH §4.5 예외 승인으로 보고 진행      등급 목표: D2

**목표(한 줄)**: 전투 모션(K-0029)이 정리돼도 맞는 순간의 번쩍임·마법 구체·치유 광륜이 없으면 전투가 심심하다. **원소 7종(불·물·번개·얼음·바람·땅·빛) × 동작 4(발사·타격·장판·상태)** 를 웹 2D 스프라이트 시트와 Godot·Unity 파티클 프리셋 설명서로 만든다.

**파일(확인함)**: `tools/asset-forge/spritegen.py`·`tilegen.py`(코드 생성 선례)·`tools/ai-art/gen.py`·`make_procedural_tiles.py`(AI 가 못 하는 것은 코드로) · 원소 7종 = Godot 사가고 PLAN 의 원소 반응 · 새 `tools/asset-forge/vfxgen.py`·`data/vfx_plan.json` · 배치 K-0019

**단계**
1. 예외 승인 확인 후 목록: 원소 7 × 4 + 공용(피격 스파크·치유·버프·사망 연기) 약 40종, 규격(2D 128/256px 8~12프레임, 3D 는 입자 수·수명·색 곡선 JSON).
2. `vfxgen.py` 로 절차 생성(노이즈·그라데이션·라디얼 — AI 불필요, 같은 코드면 같은 그림). 가산 합성 전제로 검은 배경 + 알파 둘 다 출력.
3. 시험 6종 → 사용자 판정 → 일괄. 3D 는 프리셋 JSON + 텍스처 시트(각 엔진 파티클 노드 설정은 갈래 몫).

**검증**: `vfx_plan.json` 항목 수 = 산출 수 · 용량 한도(판당 ≤ 3MB) · `.license.json` 100% · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3 · 사용자 판정 한 줄. 게임에서 이펙트를 띄우는 배선은 각 갈래.

**불변 규칙**: 원작 스킬·이펙트 모사 금지 · 깜빡임이 빠른 이펙트는 광과민 주의(초당 3회 이하 번쩍임) · 게임 폴더 직접 수정 금지(배치는 K-0019) · 이름 정책 · 상업 허용·CC0 에셋만 · PC 안 멈추게(GPU 작업은 다른 GPU 작업과 동시 금지)
