# K-0032 펫·탈것·몬스터 도감 — 초상·카드 그림을 3D 몸 렌더 밑그림으로 만들어 도감에 연결
종류: 새기능 · 에셋      상태: **작성됨**(R-0 2026-10-02) — 사용자 2026-10-02 "펫,탈것,몬스터 도감도 있고"      등급 목표: D2

**목표(한 줄)**: 인물 도감(K-0027)처럼 **펫·탈것·몬스터도 도감 그림(초상·카드)** 이 필요하다. 지금 도감은 인물(`HEROES`)과 펫(`PETS` 105, 초상 있음)뿐이고 탈것·몬스터 도감은 데이터도 그림도 확인되지 않는다. 이 티켓은 **그림 쪽(자체툴 몫)** — 종 목록·능력·`data.js` 항목은 웹 갈래가 먼저 추가한다.

**파일(확인함)**: `tools/ai-art/make_pet_batch.py`·`make_pet_i2i_batch.py`·`render_pets.py`·`pack_web_pet_portraits.py`·`gen.py`·`batches/web_pets_105_i2i.json`·`web_dungeon_30.json` · 도감 `saga-web/saga-go/js/data.js`(`PETS`·`HEROES`) · 몸 `saga-web/saga-go/assets/models/animals/*.glb`·K-0031 현황표 · 기존 초상 `saga-web/saga-go/assets/portraits/{hero,pet}` · 배치 K-0019

**단계**
1. **현황표(추측 금지)**: 도감 종류(인물·펫·탈것·몬스터) × 항목 수 × 그림 유무 × 3D 몸 유무 — 데이터·폴더를 읽어서 만든다. 탈것·몬스터 도감 데이터가 없으면 웹 갈래에 "도감 항목 추가" 티켓이 먼저 필요하다고 메모(이 티켓은 그림만).
2. 밑그림: 3D 몸(K-0031 동작 정리본·몬스터 몸) 전신 렌더 → img2img(Animagine XL 4.0). 펫의 "대역 모델 때 얼굴이 안 맞던" 시도(`render_pets.py`)는 채택 안 한 이력이 있어 종별 몸이 있는 칸부터.
3. 포장·확인 시트 → 사용자 고르기 → K-0019 로 웹 다섯 판 `assets/portraits/<종류>`(도감은 다섯 벌 같은 파일, md5).

**검증**: 도감 항목 수 = 그림 수 · `.license.json` 100% · 얼굴·모양 겹침 검사(`i2i_meta.py`) · `audit.py --quick` 🔴 0.

**완료 조건**: 단계 1~3 · 사용자 고르기 한 줄.

**불변 규칙**: 원작 캐릭터·작가 이름 프롬프트 금지(`gen.py BLOCK`) · 이름 정책(원작 펫·괴물 이름 금지) · 도감 `id`·세이브 키 불변 · PC 안 멈추게 · 게임 폴더 직접 수정 금지.

**메모(체크포인트)**: 시작 조건 K-0024 배치 끝(GPU). K-0027 과 같은 날 묶어 돌려도 된다.
