# K-0056 웹 2D 에셋 전체를 AI 생성으로 통일 — 건물·지물·자연·마을 소품·짐승·사람 (그림체 하나)
종류: 새기능 · 에셋      상태: **작성됨**(사용자 결정 2026-10-03 "2D 는 다 AI 생성해서 만들어야 할 듯" + "에셋이 시급") — **긴급, 큐 맨 위**      등급 목표: D2

**목표(한 줄)**: 웹 2D 모드 화면이 옛 픽셀(Kenney)·옛 코드 도형·3D 렌더 스프라이트(`world2d`)·AI 배경이 한 화면에 섞여 "허접하다"는 평(사용자 10-03). 2D 에 쓰는 그림 **전부**를 로컬 AI 생성으로 만들어 그림체 하나로 맞춘다. 3D(GLB)는 K-0052·0053·0017 그대로 두고, **2D 는 3D 렌더를 쓰지 않는다**(K-0052·0053·0054 의 "2D 스프라이트" 단계는 이 티켓 방식으로 대신한다).

**지금 있는 것(사실)**
- 로컬 AI: `tools/ai-art/gen.py`(sd-webui, 모델 SDXL base·Animagine XL 4.0 Opt·Illustrious, 프롬프트에 원작·실존 이름 금지 \`BLOCK\`)·\`start_sd.ps1\`/\`stop_sd.ps1\`(켜면 끝에 반드시 끔)·\`make_bg_batch.py\`·\`make_tile_batch.py\`·\`split_bg_layers.py\`·\`pack_web2d.py\`·\`check_web2d.py\`. 배경 20지역·타일 30은 이미 AI(K-0020). RX 7600 8GB — 한 장씩·768×1024 이내·장당 35초, Unity·Blender 와 동시 금지.
- 3D 몸 렌더 밑그림 → img2img 로 초상 105·펫 시험을 한 전례(\`make_pet_i2i_batch.py\`, 펫은 몸 안 맞아 채택 안 함). 인물 시트 20벌은 3D 굽기(K-0015, \`bake_sprite_batch.py\`).
- **규격(웹 읽는 쪽 \`shared/js/mode2d.js\`)**: 정적 지물 = 256px 알파 한 장 \`world2d/<id>.webp\`(발 밑이 아래 가운데) · 움직이는 것 = 풀 \`<풀>/<동작>.webp\`(8프레임×방향 3행·128px, idle walk attack hit death) + manifest + 판별 index.

**풀어야 할 것(어려운 점)**: AI 는 프레임마다 모양이 달라져 8프레임 걷기를 그리면 떨린다. 아래 **방식 두 가지**를 시험해 고른다(R-0 에서 결정 — 사용자 판정 한 줄).
- **방식 A(추천)** 움직이는 것도 **정면·옆·뒤 정지 그림 3장(AI)** + 웹 코드가 걸음·숨쉬기를 만든다(위아래 bob·기울임·찌그러짐·좌우 뒤집기). 프레임이 한 장이라 떨림 0, 용량 ≤ 1/8. 웹은 \`mode2d.draw\` 에 "한 장 모드"를 더하면 된다(웹 쪽 후속 티켓).
- 방식 B: 3D 렌더 프레임을 밑그림으로 프레임마다 img2img(고정 씨앗·낮은 강도). 몸은 맞지만 프레임 간 떨림이 남을 수 있다 — 전례 펫에서 실패.

**단계**
1. **그림체 고정**: 한 모델·한 프롬프트 꼬리(윤곽선 굵기·채도·그림자 방향·배경 단색)·네거티브를 정하고 건물 1·나무 1·짐승 1·사람 1 시험 4장 → 사용자 고르기(판정 시트). 이 값이 이후 전부의 \`STYLE\` 상수.
2. **정적 지물 세트**: 건물·지물 42 + K-0052(자연)·K-0053(마을·방 키트) 목록 전부 — 단색 배경 생성 → 배경 제거(알파)·발 밑 정렬·256px·\`.license.json\`(\`gen.py\` 가 남김). 이름은 3D id 와 같게(웹이 \`world2d/<id>.webp\` 자리에 그대로 갈아 끼움).
3. **움직이는 것**: 방식 A/B 시험 후 결정 → 짐승·펫·NPC·주인공·동행(K-0054 목록) 정면·옆·뒤. 풀 규격 호환이 필요하면 한 장을 8프레임 시트로 복제하지 말고 웹이 한 장 모드로 읽게 한다.
4. 포장·\`check_web2d.py\` 류 점검(알파 범위·발 밑·용량 ≤ 판당 6MB) → 사용자 판정 시트 → K-0019 \`world-sprite\`·\`web2d-*\` 항목으로 교체 배치.

**검증**: 산출 수 = 목록 수 · 알파 범위·발 밑 일정 · \`.license.json\` 100% · \`audit.py --quick\` 🔴 0 · \`precheck.sh\` OK. 웹은 \`playcheck/pw-web2d.mjs\`·\`pw-look2d.mjs\`(2D 화면 한 장)로 확인.

**완료 조건**: 단계 1~4 · 그림체 판정 한 줄 · 웹 2D 화면의 옛 그림이 전부 새 그림으로 바뀜(웹 W- 티켓이 설정 표만 바꿔 연결).

**불변 규칙**: 프롬프트에 원작·작가·실존 이름 금지(\`BLOCK\`) · 사람이 고른 것만 게임에(AI 그림은 사람 창작 기여가 적으면 저작권 보호가 약함 — \`ai-art/README\` 정책) · PC 안 멈추게(sd 켜기·끄기 짝·순차) · 게임 폴더 직접 수정 금지(K-0019) · 3D GLB 는 이 티켓이 안 건드림.

**순서 제안(새 세션)**: 단계 1(시험 4장·판정)부터. 판정이 나기 전에는 대량 생성 금지(그림체가 바뀌면 전부 버린다).
