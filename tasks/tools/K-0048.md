# K-0048 등급별 외형 연출 — 희귀도에 따라 오라·장식·테두리를 입힌다
종류: 새기능 · 에셋      상태: **산출 등급 5(틀·배경·오라·획득) 배치 끝**(10-04, 판정 대기)      등급 목표: D2

**목표(한 줄)**: 도감 인물·펫·장비는 희귀도 1~5 가 있으나 모습으로는 구분이 약하다. **등급 틀·오라 스프라이트·카드 배경·획득 연출용 그림**을 등급별로 만들어 "희귀한 것이 눈에 띄게" 한다. 능력치는 건드리지 않는다(외형만).

**파일(확인함)**: `tools/asset-forge/spritegen.py`·`vfxgen.py`(K-0039)·`uigen.py`(K-0040) · `tools/ai-art/gen.py`(카드 배경) · 새 `tools/asset-forge/data/rarity_plan.json` · 등급표 = 각 판 `data.js` `RARITY`(읽기만) · 배치 K-0019

**단계**
1. 등급표(읽어서): 판별 등급 이름·색.
2. 등급 5 × (카드 틀·카드 배경·오라 2D 시트·획득 번쩍임) 규격 → 코드 생성 + AI 배경.
3. 미리보기 → 사용자 판정 → K-0019.

**검증**: 계획표 = 산출 수 · 색 대비 점검(글자 가독성) · 용량 한도.

**완료 조건**: 단계 1~3.

**불변 규칙**: 등급 이름·색은 기존 `RARITY` 를 따른다(세이브·도감 `id` 불변) · 게임 폴더 직접 수정 금지(배치는 K-0019) · 이름 정책 · 상업 허용·CC0 에셋만 · PC 안 멈추게(GPU 작업은 다른 GPU 작업과 동시 금지)

**메모(체크포인트)**: ✔ 단계 1~3 (10-04, 사용자 "큐 순서대로 다 적용"): `tools/asset-forge/raritygen.py`(코드 생성, `--check`) — 등급표는 `data.js` `RARITY` 를 읽음(기본 #9aa4b2·상급 #5ec26a·희귀 #4aa3f0·영웅 #b06bf0·전설 #f0a53a). 등급 5 × 카드 틀(160×224, 9분할 28px)·카드 배경(1 민무늬 → 2 사선 → 3 빛 알갱이 → 4·5 광선)·오라 시트(8프레임 루프, 고리 겹·알갱이·반짝 별이 등급 따라 늘어남)·획득 연출(12프레임, 등급 따라 광선·고리 늘어남) + `rarity_plan.json`(배경 위 흰 글자 대비 계산). check → RARITY_OK(0.82MB, 대비 ≥4.5, 광과민 ≤3Hz). 미리보기 `tools/asset-forge/_out/rarity/rarity_sheet.jpg`. 정본 `saga-assets/rarity` → `place.py` 항목 `rarity` → 웹 `shared/assets/rarity`·Godot `assets/rarity`. 카드 배경에 AI 장식은 안 넣음(코드만).
**남은 것**: 사용자 판정 · 화면 배선(각 갈래).
