# K-0052 자연 소품 통일 세트 — 나무·덤불·풀·꽃·바위·통나무·버섯 (툰 GLB + 2D 스프라이트 한 쌍)
종류: 새기능 · 에셋      상태: **작성됨**(요청 10-03 + R-0 웹 갈래가 채움) — **사용자 긴급 지시**: 웹 2D·3D 화면이 옛 그림과 새 그림이 섞여 "허접하다", 에셋이 시급(2026-10-03). 큐 맨 위에서 먼저 한다      등급 목표: D2

**목표(한 줄)**: K-0017 의 `world3d` 42개에는 건물·인공 지물·지형 조각·탈것뿐이고 **자연 소품이 하나도 없다**. 웹·Godot·Unity 가 아직 옛 에셋(Quaternius·Poly Haven 실사)으로 나무·풀·바위를 세우고 있어 "3 트랙 3D 에셋 동일"(사용자 2026-10-01)이 이 자리에서만 안 지켜진다. 같은 툰 노선의 자연 소품 세트를 만들어 세 트랙이 같은 GLB 를, 웹 2D 모드가 같은 모양의 스프라이트를 쓰게 한다.

**요청한 쪽이 확인한 것(사실)**
- 웹 호출부 키(판별 `asset3d.js`/`prop3d.js`): go `tree·pine·rock·grass` · dungeon `tree·tree_dead·rock·grass·flower·bush·mushroom·log` · forest `tree:birch·bush·rock·rock:moss·grass·flower·plant·mushroom·stump·log·mountain` · story `tree:near·tree:far·rock·hill·bush·flower·grass·moss_rock`. Godot `vegetation_builder.gd` 도 같은 종류(G-0014 메모 "world 세트에 짝 없음").
- 예산(웹 폰 기준, `set_plan.json` budget): GLB ≤0.5MB·삼각형 ≤5000·텍스처 ≤256px·스프라이트 128/256px. 나무·풀·꽃은 화면에 수백 개 서므로 **한 개당 삼각형을 더 낮게**(≤1500 권장 — R-0 가 정한다).

**받고 싶은 것(안)**: 활엽수·침엽수·고목·자작(밝은 줄기) 각 2변형 · 덤불 · 풀 포기 · 꽃 무더기 · 바위 큰/작은/이끼 · 조약돌 한 줌 · 통나무 · 그루터기 · 버섯 · 산·언덕 조각(웹 story `hill`·forest `mountain`). 시대를 가리지 않는 일반 이름(`tree_broadleaf_01` 식). 계절(봄·여름·가을·겨울) 색 변형은 웹이 곱색으로 하므로 **기본 한 벌 + 눈 덮임 변형 1**이면 된다.

**파일(확인할 것 — R-0)**: `tools/world-forge/build_prop.py`(소품 빌더)·`render_sprite.py`(2D 스프라이트)·`data/set_plan.json`(칸 추가) · 배치 K-0019(`asset-place.json` 에 `world-web` 처럼 항목)

**단계**
1. `data/set_plan.json` 에 자연 소품 칸을 더한다(`game` 칸이 아니라 공용 `nature` 묶음 — 키는 위 웹 호출부 id 와 이름을 맞춘다: `tree_broadleaf_01·02`·`tree_pine_01·02`·`tree_dead_01`·`tree_birch_01`·`bush_01`·`grass_tuft_01`·`flower_patch_01`·`rock_small_01`·`rock_large_01`·`rock_moss_01`·`pebbles_01`·`log_01`·`stump_01`·`mushroom_01`·`hill_01`·`mountain_01`). `check_plan.py` 가 이 칸도 센다.
2. `build_prop.py` 에 같은 모양(`def tree_pine_01(C)` … `PROPS` 튜플에 추가)으로 만든다. 나무는 `tube`(줄기)+원뿔·구 층 잎, 바위는 노이즈 변형 구, 풀·꽃은 교차 판 몇 장(삼각형 ≤1500). 재질은 `sources.json` 의 기존 Poly Haven 사진(나무껍질·잎·바위·이끼)만 — 새 사진이 필요하면 `fetch_sources.py` 에 CC0 만 추가. 눈 덮임 변형 `*_snow` 는 같은 모양에 재질만 흰색.
3. `build_set.sh <절대 출력 폴더>` 로 툰 GLB → 웹 압축본 → 2D 스프라이트(`render_sprite.py`) → `check_plan.py --strict` 를 한 번에. `preview.py` 로 세 방향 미리보기 한 장을 사용자 판정용으로 `tasks/sheets/` 에.
4. 사용자 판정 → K-0019(`asset-place.json` `world-web`·`world-sprite`·고돗·유니티 항목에 id 추가, `place.py --write` 멱등).

**검증**: `py tools/world-forge/check_plan.py --out <폴더> --strict` 산출 수 = 칸 수 · 삼각형 ≤ 예산 · `.license.json` 100% · `audit.py --quick` 🔴 0 · `precheck.sh` OK. 웹은 `playcheck/pw-assets3d.mjs` 로 GLB 파싱.

**완료 조건**: 단계 1~4 · 판정 통과분이 세 트랙에 배치되어 웹 W- 티켓이 `DG.cfg.assets3d`·`prop2d` 표만 늘려 쓸 수 있다. **웹이 가장 먼저 쓸 자리: 사가의숲 나무·바위·꽃(옛 Kenney 픽셀)·사가스토리 배경 나무.**
