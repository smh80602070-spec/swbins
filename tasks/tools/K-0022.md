# K-0022 VRoid 대량 들이기 — 인물 3D·2D 에셋을 이어하기로 자동 처리하고 진행표를 낸다
종류: 새기능 · 도구      상태: **작성됨**(R-0 2026-10-02, 사용자 결정으로 범위 확정) — 첫 VRM 1개 필요      등급 목표: D2

**목표(한 줄)**: 사용자 결정(2026-10-02) "**인물 에셋은 VRoid 로 다 한다**". VRM 이 폴더에 쌓이면 새로 들어온 것만 골라 인물마다 **3D 에셋(툰 GLB·CC0 동작 8, 웹 3D·Godot·Unity 동일)** 과 **2D 에셋(128px 시트)** 을 만들고, 인물별 진행표를 낸다. **도감은 VRoid 가 아니다** — 도감(데이터·초상)은 기존에 추가하던 방식(`data.js` 다섯 벌 md5 동일 + `tools/ai-art` 초상)으로 늘려 500명을 만든다(이 티켓 밖). 폐기: MakeHuman 실물풍·무작위 장비·범용 시트 20벌.

**파일(확인함)**: `tools/char-forge/vroid_intake.sh`(1명: GLB 사본·얼굴 데칼·`bake_for_rig.py`+`verify.py`·Godot `ual_lib_build.gd`) · `gear_sprites.py`+`bake_sprite_batch.py`(VRM 몸 2D 시트) · `export_vrm_parts.py`(옷 조각) · `data/roster.json`(299) · 놓기 K-0019

**규약**: VRM = `tools/char-forge/_in/vroid/<id>.vrm`(git 밖, id 는 영문 소문자·숫자·`_`, 명단에 없으면 "신규"). 산출 `_out/vroid/<id>/` → 통과분만 K-0019 로 `saga-assets/`.
**받는 법(사용자 2026-10-02 "Z까지 받겠다")**: VRoid Studio 의 공식 샘플 `AvatarSample_A`~`Z`(26벌, 도움말 "VRoidPreset_A - Z")를 VRM 으로 내보내(또는 Hub 에서 받아) `tools/char-forge/_in/vroid/avatarsample_a.vrm` … `_z.vrm` 으로 둔다(이미 있는 A·D~G 포함). 공식 조건(검색 요약, 도움말은 403): 상업·편집·재배포 가능, CC0 로 재배포·캐릭터 생성 서비스 금지, A·B·C 는 별도 조건 — `vroid_samples.py`(끝, 폴더째 이름 정리·복사)가 VRM 안 메타를 `data/vroid_licenses.json` 에 적는다 — A 는 `creditNotation: required` 라 게임 크레딧에 넣고, 모델별 조건은 사람이 확인. 26벌 ≠ 500명이라 변주(옷 조각 교체 `export_vrm_parts.py`·무늬 64·색)와 사람이 새로 디자인한 VRM 을 섞는다. 옷 조각 추출은 되지만 체형 슬라이더가 같은 몸끼리만 맞는다(샘플 키가 1.41~1.82m 로 달라 그대로는 안 맞음).

**단계**
1. `vroid_status.py`: 명단 id + `_in/vroid` 의 신규 id × 단계(`vrm`·`glb`·`anim`·`sheet2d`) 표, 요약("n명 완료/들어옴/대기"), `--missing`.
2. `vroid_batch.sh`: `_in/vroid/*.vrm` 중 결과가 없는 것만 차례로 공통부(GLB 사본·동작 굽기+검증·2D 시트)를 돈다. 낮은 우선순위·`</dev/null`·실패는 로그에 남기고 계속·3회 실패면 건너뜀 표시.
3. Godot 부(`anim_cc0/<id>_lib.res` 등, Godot exe 필요)는 분리 — exe 가 없으면 "대기"로 두고 나머지 진행(압축 `scratchpad/keep/Godot.zip` 은 푼 뒤 `GODOT=` 지정).
3b. **경량화(실측)**: 지금 몸 9개 정점 약 9만(CC0 D~G 70~80만)·뼈 134~498 → 그대로면 인물당 수 MB. 툰 GLB 는 삼각형 ≤ 2만·텍스처 ≤ 1024·≤ 600KB(웹용은 Meshopt+WebP ≈ 1/4), 얼굴·머리 유지는 시트로 확인. 500명 ≈ 300MB — `saga-web` 849MB 라 Pages 한도 근처, 웹 3D 는 한 벌만.
4. 시험: 사용자 VRM 1개(또는 시험용 `saga-godot/assets/characters_vroid/AvatarSample_A.vrm`)로 3D·2D 가 나오고 `audit.py --quick` 🔴 0.
