# K-0163 인물 일러스트 — 전신 스탠딩 + 표정 4 (3D 몸 렌더를 참조로 같은 사람, 주역 30명 먼저)
종류: 에셋(2D 일러스트) · 자체툴(ai-art gen.py·judge · char-forge 렌더)      상태: **작성됨**(오퍼스 R-0 10-21 — 사용자 10-21 "캐릭터마다 일러스트는 아직이야?")

**목표(한 줄)**: 다섯 판 인물 ~500명에게 있는 것은 3D 몸에서 구운 작은 얼굴 초상(96px·150×172 카드)뿐이고 전신·표정 일러스트가 없다 → 인물마다 **전신 스탠딩 1(투명 배경, 세로 1024) + 표정 4(neutral·happy·angry·sad, 반신 512)**. 같은 사람이 되게 3D 몸 정면·¾ 렌더(옷·머리색)를 i2i/참조로 쓰고, 그림체 C(웹 2D 배경과 같은 집안)로. 주역 30명(다섯 판 이야기 1~3장에 나오는 순 — `scenario/` 등장 순) 먼저, 판정기로 고른다.

**파일**: `tools/ai-art/gen.py`(i2i·`--variants 4 --judge`) · `tools/ai-art/judge.sh pick` · `tools/ai-art/i2i_meta.py` · 새 `tools/ai-art/batches/k162_illust30.json`(인물 id → 참조 렌더 경로·옷·성격 한 줄 — 표시 이름은 가명만) · 참조 렌더 `tools/char-forge/render/`(정면·¾ 두 장 — 없으면 굽기) · 산출 `tools/ai-art/_out/illust/<id>/{stand,neutral,happy,angry,sad}.webp` · 배포 판별 `saga-web/<판>/assets/illust/<id>/` + `assets/illust/manifest.js` · 라이선스 json

**단계**: ① 주역 30 목록(판별 등장 순 — 메모 표) ② 참조 렌더 확보 ③ 스탠딩 생성(변형 4 → 판정기 고름) ④ 같은 사람 점검: 기존 초상·참조 렌더·새 일러스트 셋을 나란히(feedback_k_art_identity_check — 3명 이상 원본끼리 대 보기) Read ⑤ 표정 4(스탠딩 얼굴 i2i) ⑥ 배포 + 웹 수신함("W-0371 시작 가능") ⑦ 나머지 470 은 같은 배치를 판별로 나눠 다음 티켓 줄(수신함)

**검증**: `py tools/ai-art/gen.py tools/ai-art/batches/k162_illust30.json --variants 4 --judge` · 대조판 30 Read(같은 사람 ○ ≥ 27) · 라이선스 json 30 · `node tools/qc.mjs --branch tools`

**완료 조건**: 주역 30 스탠딩+표정 4 · 같은 사람 대조 통과 · 웹 수신함 줄 · 나머지 배치 계획 메모 · done/.

**불변 규칙**: **이름 정책** — 실존 인물·원작 캐릭터 얼굴/이름을 닮게 하지 않음(가명·창작 외모) · 상업 허용 모델만(swbins3 Z-Image·Illustrious·Animagine) · 원작 그림 참조 금지.

**함정**: 표정 i2i 에서 옷·머리색이 흐트러진다 — 얼굴 영역만 바꾸는 마스크 · 투명 배경은 defringe(`defringe_sprites.py`).
