# K-0015 2D 모드 에셋 굽기 — 걷기·전투·배경 전체 (3D 원본 → 2D 스프라이트 + AI 배경)
종류: 새기능·에셋      판: 웹 다섯(2D 모드)      등급 목표: D2 — 시트·배경 + 출처 기록. 게임 배선은 웹 갈래(W-0017)

**목표**: 사용자 지시(2026-10-01 "2d모드는 도감뿐 아니라 걸어다니고 전투하는 것도, 배경도 전체가 2D")에 따라 VRoid CC0 몸(K-0014)·괴물 변형·공방 몸을 Blender 로 방향·동작 스프라이트 시트로 굽고, 배경·타일은 Illustrious(K-0013)로 만든다.

**파일**: `tools/char-forge/gear_sprites.py`(정식 도구, 머리말에 사용법)·`bake_sprite_batch.py`·`data/sprite_plan_*.json` · `tools/ai-art/make_bg_batch.py`·`split_bg_layers.py`·`make_tile_batch.py`·`make_seamless.py`·`make_procedural_tiles.py` · 산출 `tools/char-forge/_out/sprites/`(gitignore)

**본보기**: `bake_for_rig.py` · `render/render_turn.py` · `ai-art/gen.py`

**규격(확정)**: 프레임 128px · 걷기 8프레임 · 방향 3(정면·옆·뒤, 반대 옆은 뒤집기) · `ORTHO=2.5` · 시트 1024×384 · 5동작(idle·walk·attack·hit·death) · WebP.

**단계(끝)**
1. 규격 확인 · 2. `gear_sprites.py` 정식화(6벌 걷기 시트) · 3. 괴물 변형(피부·체형·뿔·귀·엄니)·3b 옷 변형(`rand:<종류>[_fancy|_fancy_gm]:<씨앗>`)·3c 연령 축 child/teen/elder · 4. 6벌 미리보기 사용자 판정 "괜찮아"(2026-10-01)
5. 배경: 4지역×2, 층 분리 far·mid·near(속도 0.2/0.5/1.0), 타일(풀·흙·용암암·모래·얼음 OK / 눈·물은 AI 실패 → 코드 생성). 애니풍 모델은 바닥에 금지(사람이 그려짐).
6. 풀 48벌(CC0 몸 6종 × 8종류) 굽기 끝.

**검증(2026-10-01 통과)**: 시트 330장 크기 = 매니페스트(px×frames, px×dirs) 일치·불일치 0 · 총 15MB(≤20MB) · `audit.py --quick` 🔴 0 · 출처는 폴더별 `manifest.json` 의 `license` 칸(별도 `.license.json` 은 웹 산출로 옮길 때 W-0017).

**완료 조건**: 단계 1~4 + 배경 시험 4장 + 사용자 판정 한 줄(대량 굽기 결과 OK / 수정 / 중단) ← **대기**.

**불변 규칙**: 이름 정책 · 원작 에셋 금지 · 비상업 파일 공개 저장소 금지 · 웹 세이브 키·도감 id 불변 · `sprite.js` 등 다섯 벌 수정은 W 갈래 · 시트 미리보기는 산출물(스크린샷 금지 예외).
