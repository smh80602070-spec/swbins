# K-0212 TRELLIS 질감 굽기를 상업 허용 도구로 다시 — nvdiffrast·Inria 가우시안 래스터 걷어내기(사용자 10-31 "상용화 버전만")
종류: 에셋 재굽기 · 자체툴(ai-art/remote3d)      상태: **작성됨**(**지포스 PC 전담** — CUDA 필요, 라데온 불가)      등급 목표: D2

**목표**: `tools/ai-art/remote3d/trellis_batch.py` 의 `postprocessing_utils.to_glb`(질감 굽기)가 쓰는 도구 둘이 비상업이다 — nvdiffrast(NVIDIA Source Code License 1-Way Commercial §3.3 "non-commercially only"), diff-gaussian-rasterization(Inria Gaussian-Splatting License "research and/or evaluation purposes only", 원문 10-31 확인). 모델 TRELLIS 는 MIT 라 그대로. 굽기만 상업 허용 도구로 바꿔 짐승·펫 GLB 를 다시 굽는다. 대상: 출처 기록에 TRELLIS 가 적힌 356개(saga-assets creatures3d 147·pets3d 17·pets3d-engine 17·sprites2d_factory 175 — 이 175 는 같은 GLB 에서 렌더한 2D 시트라 GLB 가 바뀌면 다시 렌더).
**선행 조건**: 입력 그림 `tools/ai-art/_out/remote3d`(PC 로컬 — 지포스에 없으면 saga-assets 의 `.license.json` 입력 출처로 원 그림 찾기) · 시작 전 `bash tools/push.sh --pull` · 큐 줄에 PC 적고 푸시
**단계**:
 ① 라이선스 전수: TRELLIS 의존 전부(flexicubes 는 NVIDIA 계열일 수 있음 — 미확인, utils3d·spconv·xformers·kaolin 대역 포함) 원문 확인해 표로. 비상업이 더 나오면 이 티켓에 추가
 ② 대체안 시험(대표 1종 곰): 가우시안 렌더 → gsplat(Apache-2.0) · 메시 래스터/UV 굽기 → 상업 허용 대안(pytorch3d BSD 등) 또는 자체 Blender 굽기. 입력 그림 같음, 현재 GLB 와 나란히 렌더
 ③ 곰이 눈 ○ 이면 `trellis_batch.py` 굽기부 교체(Kaggle 또는 이 PC) — 한 종씩 늘려 전수. 같은 id·크기·뼈대 규칙 유지(finish.py·creature_rig 그대로)
 ④ 정본 교체: 원본은 덮지 않고 새 파일 → `credits.py`·`.license.json`(굽기 도구 이름·라이선스 갱신) → place → 2D 시트 다시 렌더
**검증**: 비교 시트 Read(옛/새) · `py tools/asset-audit/…` 에셋 점검 · `credits.py --check` · `gen-assets3d-ids --check` · 새 출처 기록에 nvdiffrast·diff-gaussian-rasterization 문자열 0건 grep
**완료 조건**: 356개 새 굽기 정본·place·2D 시트 · 라이선스 전수 표 · 비상업 도구 흔적 0 · 못 이긴 종은 목록과 이유(대체 불가면 사용자에게 올림)
**불변**: 모델 가중치 교체 없음(TRELLIS MIT 유지) · 화질 후퇴 시 사용자 확인 · 원본 덮어쓰기 금지 · 웹/고돗/유니티 코드 안 고침(id 같게)
