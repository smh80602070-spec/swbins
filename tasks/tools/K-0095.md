1. 밑그림 3장 준비(위). 한 장 = 한 종, 흰 배경, 그림자 없음.
2. 노트북: `git clone microsoft/TRELLIS` · `ATTN_BACKEND=xformers SPCONV_ALGO=native`(T4 는 flash-attn 불가) · 모델 `microsoft/TRELLIS-image-large` · 입력 zip → `pipeline.run(image)` → `postprocessing_utils.to_glb(simplify=0.95, texture_size=1024)` → `/kaggle/working/out/<id>.glb`. 있는 결과는 건너뛴다(이어 돌리기).
3. `py tools/ai-art/remote3d/run_kaggle.py --in <그림 폴더> --out tools/ai-art/_out/remote3d` — push → 5분마다 status → complete 면 output 받기. 한 번 돌 때 GPU 시간·한 장 걸린 초를 메모 표로.
4. 시트 렌더 → Claude 눈 판정(종 모양이 맞는가 · 뒤·아래 구멍 · 텍스처 번짐 · 삼각형 수). 압축 뒤 용량.
