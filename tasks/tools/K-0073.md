# K-0073 에셋 반영 검사기 — 정본(saga-assets)이 게임 화면까지 실제로 닿는지 기계로 센다
종류: 통합·도구      상태: **작성됨**(페이블 2026-10-05, 사용자 "에셋이 잘 반영 안 되는 부분도 확인")      등급 목표: D2

**목표(한 줄)**: "배치 끝"과 "화면에 나옴"은 다르다. 정본 5,232파일 중 ① 어느 트랙 코드에서도 이름이 안 나오는 것 ② 이름 표(`*-ids.js`·manifest)에만 있고 그리는 코드가 안 부르는 것 ③ 실제로 게임을 띄웠을 때 한 번도 요청되지 않는 것, 셋을 숫자로 내서 "반영 안 됨"을 사람 눈 없이 잡는다.

**지금 상태(10-05 페이블 1차 집계, 토큰 검사)**
- 느슨한 기준(이름 표·복사본 포함): 5,232 중 어디서도 안 쓰는 것 **164** — `portraits-monster` 64 전부(K-0032 몬스터 초상, 웹 도감 데이터 선행이라 멈춤) · `store` 80 전부(K-0041 스토어·타이틀 일러스트, 앱 연결 대기) · `characters` 20(해시 이름 조각).
- 트랙별 빈칸: 유니티는 `competition`·`cutscene`·`map`·`patterns`·`rarity`·`sfx`·`vfx` 0(배선 티켓 없음) · 웹은 `regions` 55 중 24.
- 엄격 기준(그리는 코드 js·gd·tscn·cs·prefab 만, 이름 표 제외): 안 쓰는 것 **2,721/5,232**. 0 인 범주 = bgm·competition·patterns·portraits-monster·sfx·store·vfx(강한 후보), 거의 0 = icons 837·world 507·web2d 222·ui 75·map 67·rarity 29·sky 26. 단 아이템 id·소품 kind 로 **표를 돌며 읽는** 코드는 이름이 안 나와 과소 집계 — 진짜 답은 단계 2 네트워크 로그.

**파일**: 새 `tools/asset-audit/reflect.py`(①②: 토큰 검사, 범주×트랙 표, 끝 줄 REFLECT n/m) · 새 `saga-web/tools/playcheck/net-log.mjs`(③: 헤드리스 크롬 CDP 로 판마다 `_demo.html#<장면>` 다섯 장면을 열어 요청된 에셋 URL 로그 → 정본 이름과 대조) · `tools/precheck.sh`(새 범주가 추가됐는데 어느 트랙에도 참조 0 이면 WARN 한 줄) · 보고 `tools/asset-audit/out/reflect.md`(덮어쓰기).

**단계**
1. `reflect.py`: 범주×트랙 표 두 벌(느슨/엄격) + "안 쓰는 파일 목록" → `out/reflect.md`. 10-05 수치와 비교해 늘었는지.
2. `net-log.mjs saga-go`: 전용 `--user-data-dir`, 45초 가상 시간, 요청 URL 중 `assets/`·`shared/assets/` 를 모아 정본 이름과 대조 → "배치됐으나 한 번도 요청 안 됨" 목록. 끝나면 그 PID 만 종료(규칙).
3. 다섯 판 반복 → 표. 요청 0 인 범주는 **배선 티켓 후보**로 티켓 메모에(새 티켓은 만들지 않는다 — 수신함 한 줄).
4. precheck WARN 한 줄(새 정본 범주 참조 0).

**검증**: `py tools/asset-audit/reflect.py` → REFLECT 수치 · `node saga-web/tools/playcheck/net-log.mjs saga-go` → 요청 에셋 수 > 0 · 크롬 프로세스 잔존 0(`tasklist` 확인) · `bash tools/precheck.sh` OK.

**완료 조건**: 단계 1~4 · `out/reflect.md` 에 범주×트랙 두 표 + 요청 0 목록 · 수신함에 배선 후보 줄.

**본보기**: `tools/asset-audit/audit.py`(범주 걷기·보고 형식) · `tools/test-web.mjs`(헤드리스 크롬 띄우고 끄는 방식).

**불변 규칙**: 검사만 한다(에셋·코드 수정 없음) · 헤드리스는 전용 프로필·그 PID 만 종료 · 스크린샷 없음(네트워크 로그만) · 수치는 덮어쓰는 보고 한 장.
