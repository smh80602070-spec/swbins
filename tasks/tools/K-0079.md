# K-0079 대화형 세션 문맥 70% 넘으면 체크포인트 커밋 후 멈추고 autorun 새 세션이 "이어해"로 잇기
종류: 도구 · autorun      상태: 초안(R-0 10-07, 수신함 10-07)      등급 목표: —

**사용자 말**: "vs코드에서 ctx가 70프로 넘어가면 다른 세션에서 이어 하고 세션 닫고 다른 세션에서 이어 할수 있어? 메크로 인 건지"

**지금(확인함)**: 그런 기능은 없다. autorun(`tools/autorun/`, K-0074)은 티켓마다 새 `claude -p` 라 문맥이 안 쌓이고, 대화형 세션은 Claude Code 가 자동 압축한다. 상태줄 `statusline.js`(메모리: node 단일 스크립트)가 문맥 % 를 이미 계산한다. 이 PC autorun 은 갈래 `tools` 로 등록, 10-06 실행은 "트리가 더럽다(1줄)"로 안 돎 → `.wrangler/` 무시(10-07 커밋)로 풀림.

**방향(초안)**: ① 상태줄이 문맥 % 를 파일(`tools/autorun/_ctx.json`)에 쓴다 ② UserPromptSubmit/Stop 훅이 70% 넘으면 "지금 단계 체크포인트(티켓 메모 ✔)를 커밋하고 멈춰라" 한 줄을 넣는다 ③ 세션이 멈추면 autorun 데몬이 그 갈래로 새 `claude -p "<갈래> 이어해"` 를 띄운다(트리 깨끗·HEAD 움직임 조건 그대로). VS Code 창 자체는 바깥 프로그램이 닫지 못한다 — 이어지는 건 백그라운드 세션.

**R-0 할 일(완성 전 확인)**: `~/.claude/` 상태줄·훅 자리(tools/claude-home 설치본) · 훅이 문맥 % 를 직접 받는지 · autorun 데몬에 "외부 신호로 지금 실행" 입구(제어 페이지 "지금 한 번 실행" 이 있음) 재사용. 사용자에게 한 번 묻기: 70% 에서 **멈추고 넘기기** vs **경고만**.
